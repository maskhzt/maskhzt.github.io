## 2. 术语表（一）概述与数据表示

为什么按"块"排而不按拼音排？

因为记术语靠位置感：知道它在哪一块，才想得起它和谁相对。

五条概述，十条数据表示。

**概述：**

```text
冯·诺依曼结构（von Neumann architecture）：存储程序，指令和数据放在同一存储器里
机器字长（word length）：CPU 一次能并行处理的二进制位数
主频（clock rate）：时钟频率，每秒的时钟周期数
CPI（cycles per instruction，每指令周期数）：执行一条指令平均需要的时钟周期数
MIPS（million instructions per second，每秒百万条指令）：每秒执行多少百万条指令
```

这两条缩略语要连起来看：CPI 是"一条指令摊几个周期"，MIPS 是"一秒能跑几百万条"，一个越小越好，一个越大越好，互为倒数关系。

**数据表示：**

```text
机器数 / 真值（machine number / true value）：编码后的 0/1 串 / 它真正代表的数
原码（sign-magnitude）：最高位是符号，其余是绝对值
反码（ones' complement）：负数按位取反，0 有两个编码
补码（two's complement）：负数取反加一，减法变加法，0 只有一个编码
移码（biased）：补码的符号位取反，用于浮点的阶码，方便比较大小
浮点数（floating point）：小数点位置浮动，用阶码加尾数表示
阶码 / 尾数（exponent / mantissa）：指数部分 / 有效数字部分
规格化（normalization）：尾数最高有效位为 1，保证表示唯一
IEEE 754：单精度 1+8+23，双精度 1+11+52，阶码用移码
溢出（overflow）：结果超出该编码能表示的范围
```

十加五，十五条。

**这一块最容易错在哪**：三条。

```text
① 把"主频高"直接当成"跑得快"。
   主频只说明一秒有多少个周期，CPI 大的话 MIPS 不动。

② 拿 MIPS 跨指令系统比快慢。
   它只看指令条数，不看一条指令干了多少活。

③ 把移码当成一种"独立的数"。
   移码就是补码的符号位取反，它存在的唯一理由，是让无符号比较等于大小比较，
   所以只用在浮点数的阶码上，不用来表示普通整数。
```

## 3. 术语表（二）存储系统

存储是七块里最大的一块，十四条。

```text
SRAM（static RAM）：用触发器存 0/1，不断电就保持，快、贵、集成度低
DRAM（dynamic RAM）：用电容存电荷，会漏，必须定期刷新，慢、便宜、集成度高
刷新（refresh）：DRAM 每隔一段时间把整行读出来重写一遍，按行进行
字扩展 / 位扩展（word / bit expansion）：增加存储单元数 / 增加每个单元的位数
低位交叉编址（low-order interleaving）：连续地址分布在不同的存储体，提高连续访问带宽
局部性（locality）：程序访问的地址和时间都扎堆，分时间局部性和空间局部性
命中率（hit rate）：命中次数 / 总访问次数
映射方式（mapping）：主存块能放到 Cache 的哪些位置，分直接、全相联、组相联
替换算法（replacement）：Cache 满了淘汰谁，常见 LRU（least recently used，最近最少使用）、FIFO（first in first out，先进先出）、随机
写策略（write policy）：写回（write-back，只写 Cache，淘汰时才写主存）/ 写直达（write-through，同时写）
AMAT（average memory access time）：平均访问时间 = 命中时间 + 缺失率 × 缺失代价
虚拟存储器（virtual memory）：用外存扩充地址空间，按页调入
TLB（translation lookaside buffer）：页表项的 Cache，快表
缺页（page fault）：要访问的页不在主存，从外存调入，是一种异常
```

以上十四条，是七块里最大的一块。

还有两条外存相关的，也算这一块：

```text
寻道时间（seek time）：磁头移到目标磁道的时间，机械硬盘随机访问的主要成本
旋转延迟（rotational latency）：等到目标扇区转到磁头下，平均半圈
```

**这一块最容易错在哪**：也是三条。

```text
① 把"命中率"代进 AMAT。
   公式乘的是缺失率。命中率 95% 要写成 0.05，写成 0.95 结果大 19 倍。

② 把 TLB 未命中当成缺页。
   TLB 只是页表的 Cache，未命中只说明要再查一次页表，
   页表里那一页在不在主存，才是缺页。

③ 把"块越大越好"当成规律。
   块大能吃到更多空间局部性，但块太大会把 Cache 里其他有用的块挤掉，
   也会让一次缺失搬更多用不上的数据。
```

## 4. 术语表（三）指令系统

八条。

```text
指令格式（instruction format）：操作码 + 地址码的布局，分定长和变长
扩展操作码（extended opcode）：操作码长度可变，短码不能是长码的前缀
寻址方式（addressing mode）：怎么算出操作数的地址
有效地址（effective address, EA）：寻址方式算出来的那个地址
基址寻址（base addressing）：EA = 基址寄存器 + 形式地址，面向系统，用于重定位
变址寻址（indexed addressing）：EA = 变址寄存器 + 形式地址，面向用户，用于数组
CISC / RISC：CISC（Complex Instruction Set Computer，复杂指令集计算机）变长、指令多、寻址方式多；RISC（Reduced Instruction Set Computer，精简指令集计算机）定长、指令少、只有 load/store 访存
```

补一条常考的：

```text
栈帧（stack frame）：一次函数调用在栈上占的那一段，存返回地址、旧帧指针、局部变量
```

**这一块最容易错在哪**：两条。

```text
① 把"基址"和"变址"弄反。
   记法看"谁变"：基址寻址里寄存器不变、形式地址变，用来做重定位（面向系统）；
   变址寻址里寄存器变、形式地址不变，用来扫数组（面向用户）。

② 把"间接寻址"当成"多算一次加法"。
   间接寻址是"地址的地址"：拿 A 去内存查一次，查到的东西才是地址，
   所以它多一次访存，拿速度换灵活。
```

## 5. 术语表（四）CPU

十二条。

```text
数据通路（datapath）：数据流经的部件和连线，分单总线和多总线
指令周期（instruction cycle）：取指、间址、执行、中断四个阶段
微程序（microprogram）：用微指令序列解释一条机器指令
硬布线（hardwired control）：用门电路直接产生控制信号，快但难改
异常（exception）：CPU 内部事件引起，如缺页、除零、溢出
中断（interrupt）：外部设备引起，如 I/O 完成、时钟
流水线（pipeline）：多条指令的不同阶段重叠执行
结构冒险（structural hazard）：多条指令争用同一个部件
数据冒险（data hazard）：后一条指令要用前一条的结果
控制冒险（control hazard）：转移指令导致下一条取指地址不确定
转发（forwarding）：把上一条的结果直接送给下一条，不等它写回
SISD / SIMD：SISD（Single Instruction Single Data，单指令单数据流，传统单核）/ SIMD（Single Instruction Multiple Data，单指令多数据流，向量指令与 GPU）
```

以上十二条，控制、冒险、并行各占一块。

**这一块最容易错在哪**：还是两条。

```text
① 把"异常"和"中断"的同步性说反。
   异常是 CPU 内部那条指令自己惹出来的（缺页、除零、溢出），所以同步于指令；
   中断是外部设备随时可能来的，所以异步于指令。

② 把"转发"当成万能的。
   转发能把上一条的结果提前送给下一条，但送不了"下一条要用、上一条还没算出来"的那种，
   也就是 load 之后立刻用它的结果（load-use），这类只能停顿。
```

## 6. 术语表（五）总线与 I/O

总线七条，I/O 八条。

**总线：**

```text
总线（bus）：能为多个部件分时共享的公共信息传送线路
总线宽度（bus width）：数据线根数，决定一次传多少位
总线带宽（bus bandwidth）：单位时间传输的字节数 = 宽度 / 8 × 频率
总线事务（bus transaction）：一次完整的请求—寻址—传数据—结束
同步定时（synchronous timing）：统一时钟，事务占固定拍数，按最慢设备设计
异步定时（asynchronous timing）：握手，REQ/ACK，灵活但慢
总线仲裁（bus arbitration）：多个主设备争用总线时决定谁先用
```

**I/O：**

```text
I/O 接口（interface，I/O 是 input/output，输入/输出）：CPU 与设备之间的翻译官兼门卫
端口（port）：接口里可被 CPU 访问的寄存器地址
统一编址（memory-mapped I/O）：端口占用主存地址空间，用访存指令访问
独立编址（isolated I/O）：端口单独一套地址空间，用 in/out 访问
程序查询（programmed I/O）：CPU 忙等，反复读状态寄存器
DMA（direct memory access，直接存储器访问）：设备与内存直接传数据，不经过 CPU 寄存器
周期挪用（cycle stealing）：DMA 每次偷一个存储周期，CPU 慢一拍但不停
通道（channel）：一台小 CPU，执行通道程序，一条指令启动一整批 I/O
```

**这一块最容易错在哪**：三条。

```text
① 把同步定时当成"永远更快"。
   同步一次事务确实快（不用握手），但它必须按总线上最慢的设备定拍数，
   真挂上一个慢设备时，反而被拖死。

② 比"CPU 占用"只比设备快慢，不比干预粒度。
   同样是 1 MB/s 的设备，每次传 1 B 和每次传 4 KB，CPU 占用能差上千倍。

③ 说"DMA 传输时 CPU 完全不参与"。
   传之前要写地址、计数器、控制字，传之后要进中断收尾，
   只是搬运那一段不用 CPU。
```

## 8. 公式速查

十二个，考前默写。

```text
① CPI = 总时钟周期数 / 指令条数
② MIPS = 主频 / (CPI × 10^6)
③ CPU 时间 = 指令条数 × CPI / 主频 = 指令条数 × CPI × 时钟周期
④ IPC = 1 / CPI
⑤ IEEE 754：值 = (−1)^S × 1.M × 2^(E − 偏置)
   单精度偏置 127，双精度偏置 1023
⑥ AMAT = 命中时间 + 缺失率 × 缺失代价
   多级：AMAT = L1 命中时间 + L1 缺失率 × (L2 命中时间 + L2 缺失率 × 主存代价)
⑦ Cache 组数 = 容量 / (块大小 × 路数)
   标记位数 = 地址位数 − log₂(组数) − log₂(块大小)
⑧ 交叉存储带宽 = 存储体数 × 单体带宽（连续访问、m ≥ 存取周期/总线周期时）
⑨ 扩展操作码：第 i 级可用编码数 = 上一级剩余编码 × 2^(借用的地址码位数)
⑩ 流水线：S = n·k / (k + n − 1)，TP = n / T流，E = S / k = n / (k + n − 1)
   理想 S → k，实际 S < k
⑪ 总线带宽 = 宽度(bit) / 8 × 频率(Hz)
⑫ 磁盘：T = 寻道时间 + 60/(转速 r/min × 2) + 数据量 / 传输率
   容量 = 磁头数 × 柱面数 × 每道扇区数 × 每扇区字节数
```

两个补充：

```text
字扩展片数 = 目标字数 / 单片字数
位扩展片数 = 目标字长 / 单片字长
总片数 = 两者相乘
```

```text
I/O 占用率 = 每秒干预次数 × 每次干预开销(周期) / 主频
```

三个最容易记错的公式，各补一句。

**CPI 与 MIPS 的关系是倒数，不是正比。**

```text
CPI 涨一倍，MIPS 掉一半
主频翻倍但 CPI 也翻倍，MIPS 不变
```

所以"主频高"和"跑得快"之间隔着一个 CPI。

**AMAT 里乘的是缺失率。**

```text
命中率 95%  → 缺失率 5%  → AMAT = 命中时间 + 0.05 × 缺失代价
命中率 95% 写成 0.95 乘 → 结果大 19 倍，直接错
```

**流水线效率 = 加速比 / k。**

```text
S = 4.81，k = 5  → E = 0.962 = 96.2%
```

E 恒等于 S/k，所以只要 S < k，E 就小于 1。

这两个量是一根绳上的两头，算错一个，另一个也对不了。

## 9. 20 组最容易混的概念

这一节是整份附录的重点。

每组只给一句话区分。

**第一组：原码 vs 补码**

```text
原码：符号位 + 绝对值，0 有两个编码，减法要做减法
补码：负数取反加一，0 只有一个编码，减法变加法
```

**第二组：补码 vs 移码**

```text
补码：符号位取反就得到移码；补码用于整数运算
移码：只用于阶码，因为无符号比较等价于大小比较
```

**第三组：定点 vs 浮点**

```text
定点：小数点位置固定，范围小、精度均匀
浮点：小数点浮动，范围大、精度不均匀（离 0 越远越稀）
```

**第四组：SRAM vs DRAM**

```text
SRAM：触发器，不需刷新，快、贵，做 Cache
DRAM：电容，需要刷新，慢、便宜，做主存
```

**第五组：字扩展 vs 位扩展**

```text
字扩展：增加单元数，靠片选区分，地址线增加
位扩展：增加字长，片选并联，地址线不增加
```

**第六组：Cache 三种映射**

```text
直接映射：一块只能放一个位置，冲突必然，比较器 1 个
全相联：任意放，冲突最少，比较器最多
组相联：组间直接、组内全相联，折中
```

**第七组：写回 vs 写直达**

```text
写回：只写 Cache，设脏位，淘汰时才写主存，省带宽但有一致性问题
写直达：同时写 Cache 和主存，简单但占用主存带宽
```

**第八组：虚拟存储器 vs Cache**

```text
虚拟存储：解决容量，用页，缺失代价是访问磁盘，由软件（OS）处理
Cache：解决速度，用块，缺失代价是访问主存，由硬件处理
```

**第九组：CISC vs RISC**

```text
CISC：变长指令、指令多、寻址方式多、微程序控制为主
RISC：定长指令、指令少、只有 load/store 访存、硬布线为主、流水线友好
```

**第十组：基址 vs 变址**

```text
基址：基址寄存器不变、形式地址变，面向系统（重定位、多道程序）
变址：变址寄存器变、形式地址不变，面向用户（数组、循环）
```

**第十一组：硬布线 vs 微程序**

```text
硬布线：门电路直接产生控制信号，快、难改、RISC 用
微程序：微指令序列解释，慢、易改、CISC 用
```

**第十二组：异常 vs 中断**

```text
异常：CPU 内部事件（缺页、除零、溢出），同步于指令
中断：外部设备事件（I/O 完成、时钟），异步于指令
```

**第十三组：结构冒险 vs 数据冒险 vs 控制冒险**

```text
结构冒险：抢同一个部件（内存、寄存器堆端口）
数据冒险：后一条要用前一条的结果
控制冒险：转移指令让下一条取指不确定
```

**第十四组：转发 vs 停顿**

```text
转发：把结果从流水线中间直接送回去，不写回也能用
停顿：插气泡，等结果真的写回，损失性能但一定正确
```

**第十五组：流水线 vs 超标量**

```text
流水线：时间上重叠，一个周期完成一条（理想）
超标量：空间上并行，一个周期发射多条，需要多套执行部件
```

**第十六组：总线同步 vs 异步**

```text
同步：统一时钟，快，但要按最慢设备设计
异步：握手，灵活，但每次多几个往返
```

**第十七组：程序查询 vs 中断 vs DMA**

```text
查询：CPU 问、CPU 搬，全程占用
中断：设备叫、CPU 搬，逐字节
DMA：设备搬、CPU 签字，逐块
```

**第十八组：统一编址 vs 独立编址**

```text
统一：端口占主存地址空间，用访存指令，灵活但要防缓存
独立：端口单独地址空间，用 in/out，干净但指令少
```

**第十九组：磁盘 vs SSD**

```text
磁盘：机械寻道，随机访问 ms 级，顺序访问才快
SSD（solid state drive，固态硬盘）：无机械部件，随机访问 μs 级，但有擦写寿命和写放大
```

**第二十组：SISD vs SIMD**

```text
SISD：一条指令处理一个数据，传统单核
SIMD：一条指令处理一组数据，向量指令、GPU
```

二十组。

每一组都是一道选择题的题干。

出题人造混淆项，就三种手法。

**手法一：对调定语。**

```text
把"写回的优点（省带宽）"说成写直达的优点
把"同步的特点（按最慢设备设计）"说成异步的特点
把"变址的用途（处理数组）"说成基址的用途
```

判定方法：只问一句"它到底在解决什么问题"。

```text
写回解决带宽 → 代价是一致性
同步解决简单 → 代价是迁就慢设备
变址解决用户程序 → 基址解决系统重定位
```

**手法二：偷换主语。**

```text
"DMA 传送时 CPU 完全不参与"  ← 主语偷换，省掉了初始化
"中断方式下 CPU 不需要等待"  ← 对，但搬运还是 CPU 干的
"Cache 命中时不需要访问主存" ← 对，但"命中"的定义就是"在主存里也有"
```

判定方法：把句子拆成"谁做什么"，一段一段查。

**手法三：混数量级。**

```text
"总线宽度 32 位，带宽 32 MB/s"  ← 忘了除 8
"转速 7200 r/m，旋转延迟 8.3 ms" ← 忘了除 2
"1 Gb/s 网卡，带宽 1000 MB/s"    ← 忘了除 8
```

判定方法：心算数量级，对不上就重算。

三种手法，对应三句话：

```text
定语错 → 问"它解决什么"
主语错 → 问"谁做这件"
单位错 → 问"乘除 8 了吗"
```

## 11. 反直觉：最值钱的不是术语表

术语表有 60 多条。

背下来要多久？

```text
每条 20 秒，60 条 = 20 分钟
```

背完能拿几分？

选择题里纯考术语定义的，最多两三道。

那 20 组对照呢？

```text
每组 1 分钟，20 组 = 20 分钟
```

同样的 20 分钟，覆盖的是选择题里最容易设陷阱的地方。

因为出题人做选择题，最省力的方式就是"拿两个近义概念对调"。

```text
把"写回"的优点说成"写直达"的
把"变址"的用途说成"基址"的
把"同步"的特点说成"异步"的
把"周期挪用"说成"停止 CPU 访存"
```

四个选项，三个是"看起来对"的混淆项。

你只要脑子里有那张对照表，一秒就能排掉。

**所以这份附录真正的作用，是把"模糊的熟悉"变成"清晰的区分"。**

熟悉是危险的。

"这个词我见过"和"我能说出它和那个词的区别"，在考场上差 2 分。

2 分 × 11 道选择题，就是 22 分里的七八分。

这也是为什么这一篇把 20 组放在自检题前面。

先建立区分，再自我检测。

顺序反了，检测就变成了"感觉都会"。

### 自检三问

**一问：如果把这 20 组对照全部删掉，只留术语表，会发生什么？**

答：术语表能让你"认出这个词"，但认不出"这两个词的区别"。而选择题的混淆项，恰恰是把两个近义概念的定语对调——把写回的优点安到写直达头上、把变址的用途安到基址头上。只背定义的人，四个选项看着都对；脑子里有对照表的人，一眼排掉三个。

**二问：为什么"背 60 条术语"不如"读 20 组对照"？**

答：因为两者花的时间差不多，覆盖的面却不一样。60 条术语，纯考定义的题最多两三道；20 组对照，覆盖的是选择题里最容易设陷阱的地方。术语是"查"的材料，对照是"防坑"的工具，用途不同，不该用同一种方式学。

**三问：给你 8 位补码 1000 0000，你能说出它的真值，还能说出它为什么特殊吗？**

答：真值是 −128。它特殊在两处：一是它是 −2^(n−1)，8 位补码里没有对应的正数，所以对它取负会溢出；二是它不能用"绝对值取反加一"求出来，因为 |−128| = 128，8 位机器数表示不了 128，只能直接写 1000 0000。答得出第一个是背的，答得出第二个才算读懂。
