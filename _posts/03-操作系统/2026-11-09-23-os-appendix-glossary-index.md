先做一道题。

不定项：下列关于"进程"的说法，正确的有几个？

```text
① 进程是资源分配的基本单位
② 进程是调度的基本单位
③ 一个程序只能对应一个进程
④ 进程切换比线程切换开销大
⑤ 进程终止后，它的 PCB 立刻消失
```

答案是 ①④。

② 错，调度的是线程。

③ 错，一个程序可以跑出多个进程。

⑤ 错，PCB 要等父进程回收才消失，否则会变成僵尸。

这道题不难。

但它考的五句话，散落在 03、04 两篇里，还和 17 篇的"文件引用计数"隐约相关。

**复习到后期，最缺的不是新知识，是把散点连起来的那根线。**

这份附录就是那根线。

## 2. 术语表：概述

- **操作系统（operating system）**：管理硬件资源、为程序提供运行环境的系统软件。
- **内核态 / 用户态（kernel / user mode）**：CPU 的两种特权级，决定能执行哪些指令。
- **特权指令（privileged instruction）**：只能在内核态执行的指令，如关中断、设置页表基址、I/O 指令。
- **系统调用（system call）**：用户程序请求内核服务的唯一入口，通过陷入指令进入。
- **中断（interrupt）**：来自 CPU 外部的异步事件，如时钟、键盘、磁盘完成。
- **异常（exception）**：由当前指令引起的同步事件，也称内中断，如缺页、除零、非法指令。
- **陷入（trap）**：主动进入内核的一类异常，是系统调用的实现基础。
- **微内核（microkernel）**：内核只保留最基本功能，文件系统、驱动等移到用户态。
- **引导（bootstrap）**：上电后由固件把内核装入内存并跳转执行的过程。
- **虚拟机（virtual machine）**：用软件模拟出一台完整计算机，可再跑一个操作系统。

## 3. 术语表：进程与调度

- **进程（process）**：程序的一次执行，资源分配的基本单位。
- **线程（thread）**：调度的基本单位，共享所在进程的资源。
- **进程控制块（PCB / `task_struct`）**：进程存在的唯一标志，保存状态、现场和资源信息。
- **上下文切换（context switch）**：保存旧进程现场、恢复新进程现场的过程。
- **原语（primitive）**：不可中断的一组操作，靠关中断或硬件指令保证原子性。
- **临界区（critical section）**：访问临界资源的那段代码。
- **信号量（semaphore）**：一个整数加一个等待队列，用 P/V 操作访问。
- **P / V（wait / signal）**：申请 / 释放，P 减一并可能阻塞，V 加一并可能唤醒。
- **管程（monitor）**：把共享变量和操作封装起来，同一时刻只允许一个进程进入。
- **死锁（deadlock）**：多个进程互相等待对方持有的资源，谁也走不了。
- **安全状态（safe state）**：存在一个安全序列，能按某个顺序让所有进程完成。
- **周转时间（turnaround time）**：完成时间减到达时间。
- **带权周转时间（weighted turnaround time）**：周转时间除以运行时间，越小越好。
- **时间片（time slice / quantum）**：轮转调度里一次分配给进程的运行时长。
- **多级反馈队列（MLFQ）**：多个优先级队列，时间片逐级增大，用完就降级。
- **饥饿（starvation）**：进程长期得不到调度，但并没有互相等待成环。

## 4. 术语表：内存

- **逻辑地址（logical address）**：CPU 产生的地址，也叫虚拟地址。
- **物理地址（physical address）**：内存单元的真实地址，由 MMU 翻译得到。
- **重定位（relocation）**：把逻辑地址转换成物理地址的过程。
- **页表（page table）**：页号到页框号的映射表，每个进程一张。
- **快表（TLB）**：页表项的硬件缓存，命中就不用访问内存里的页表。
- **缺页（page fault）**：要访问的页不在内存，需要从外存调入。
- **抖动（thrashing）**：刚换出又要换入，CPU 大量时间耗在换页上。
- **工作集（working set）**：最近 Δ 时间内访问过的页的集合。
- **内部碎片（internal fragmentation）**：分配给进程的块内部用不完的部分。
- **外部碎片（external fragmentation）**：空闲分区太小、分散，凑不出一个够大的连续区。
- **虚拟内存（virtual memory）**：地址空间加按需调入，让程序以为自己有大块连续内存。
- **有效访问时间（EAT）**：考虑 TLB 命中率与缺页率后的平均访问时间。
- **内存映射文件（memory-mapped file）**：把文件的一段映射进地址空间，读写内存即读写文件。

## 5. 术语表：文件与磁盘

- **索引结点（inode）**：文件的元数据与控制信息，不含文件名。
- **超级块（superblock）**：文件系统的全局信息，如块大小、空闲块数、根目录位置。
- **位示图（bitmap）**：一位对应一个块的空闲管理结构。
- **成组链接（grouped linking）**：把空闲块分组，组间用指针串起来，适合超大磁盘。
- **硬链接（hard link）**：多个目录项指向同一个 inode，引用计数加一。
- **软链接（symbolic link）**：一个存放路径字符串的特殊文件，原文件删了就失效。
- **文件分配表（FAT）**：把链接指针集中成一张表，放在卷首，可随机访问。
- **柱面（cylinder）**：所有盘面上半径相同的磁道集合，跨盘面寻道不用移臂。
- **寻道时间（seek time）**：磁头移动到目标磁道所需时间。
- **旋转延迟（rotational latency）**：等待目标扇区转到磁头下方的时间，平均为半圈。
- **格式化（formatting）**：在磁盘上建立文件系统所需的管理结构。
- **日志（journaling）**：先把元数据的改动写进日志区，再落盘，用于崩溃后恢复一致性。

## 6. 术语表：I/O 与设备

- **设备控制器（device controller）**：CPU 与设备之间的接口，含数据、状态、控制寄存器。
- **端口（port）**：控制器寄存器的地址，独立编址或统一编址。
- **DMA（direct memory access）**：设备与内存之间直接传送数据，不经过 CPU 的寄存器。
- **通道（channel）**：能执行通道程序的 I/O 处理机，CPU 只发一条启动指令。
- **中断向量（interrupt vector）**：中断号到中断服务程序入口的映射表项。
- **缓冲（buffer）**：内存中的临时区域，用于速度不匹配的双方之间中转数据。
- **缓冲池（buffer pool）**：系统统一管理的多个缓冲区，含收容/提取输入输出四个队列。
- **SPOOLing（假脱机）**：用磁盘上的输入井、输出井把独占设备改造成共享设备。
- **设备驱动程序（device driver）**：把抽象 I/O 请求翻译成设备寄存器操作的代码。
- **逻辑设备表（LUT）**：逻辑设备名到物理设备名与驱动入口的映射。
- **闪存翻译层（FTL）**：把逻辑块地址映射到闪存物理页，并负责垃圾回收。
- **磨损均衡（wear leveling）**：让各闪存块的擦除次数尽量接近，延长寿命。
- **写放大（write amplification）**：实际写入闪存的数据量与主机请求写入量之比。
- **TRIM**：文件系统告诉 SSD 哪些页已作废，减少垃圾回收时的无效搬移。
- **IOMMU（input-output memory management unit）**：给设备用的 MMU，把设备地址再翻译一次，挡住乱写内存的设备。

## 7. 公式速查

一张纸，考前扫一遍。

```text
【调度】
周转时间   = 完成时间 − 到达时间
带权周转   = 周转时间 / 运行时间
平均周转   = Σ 周转时间 / 进程数

【地址与页表】
页内偏移位数 n = log2(页大小)         4 KB → 12 位
页号      = 虚拟地址 >> n
偏移      = 虚拟地址 & (2^n − 1)
物理地址   = 页框号 × 页大小 + 偏移
页表项数   = 2^(虚拟地址位数 − n)
页表大小   = 页表项数 × 每项字节数
每级页号位数 = log2(页大小 / 每项字节数)
级数      = 页号位数 / 每级位数（向上取整）

【EAT】
EAT = 命中率 ×(TLB + 内存) + (1−命中率)×(TLB + 查页表 + 内存)
EAT(含缺页) = EAT + 缺页率 × 缺页处理时间

【缓冲】T=设备填缓冲，M=缓冲到用户区，C=CPU 处理
单缓冲每块   = max(C, T) + M
双缓冲每块   = max(C + M, T)
单缓冲 n 块  = T + M + (n−1)×[max(C,T)+M] + C
双缓冲 n 块  = T + M + (n−1)×max(C+M,T) + C

【磁盘】
平均旋转延迟 = 半圈 = 60 / (2 × 转速) 秒
访问时间     = 寻道时间 + 平均旋转延迟 + 传输时间
传输时间     = 数据量 / 传输率

【文件】
每块指针数 = 块大小 / 指针大小
最大文件   = 直接指针数×块 + 指针数×块 + 指针数²×块 + …
访问某块 I/O 次数 = 经过的索引块层数 + 1
位示图大小 = 磁盘总块数 / 8 字节（一位一块）
总块数     = 磁盘容量 / 块大小

【I/O 时间】
CPU 时间 = 干预次数 × 每次干预周期数 / 主频
占用比例 = CPU 时间 / 数据传输时间
```

三个数字当锚点。

```text
1 KB = 1024 B，1 MB = 1024 KB，1 GB = 1024 MB
4 KB 页 → 偏移 12 位，页表项 4 B 时每页 1024 项
1 GB = 2^30 B，1 TB = 2^40 B
```

再补一屏"记不住的常数"，考场上估数量级够用。

```text
4 KB 页        → 偏移 12 位，每页 1024 项（项 4 B 时）
1 GB           = 2^30 B       1 TB = 2^40 B
内存访问        ≈ 100 ns
TLB 访问        ≈ 10 ns
缺页处理        ≈ 10 ms（主要缺页，要读盘）
磁盘随机读      ≈ 5 ~ 10 ms
7200 r/min     → 一圈 8.33 ms，平均旋转延迟 4.17 ms
进程切换        ≈ 几 μs       线程切换 ≈ 1 μs 量级
```

最后记三个"容易漏算的一次"。

```text
漏一次内存：TLB 未命中，要额外查一次页表
漏一次磁盘：缺页处理里，要把读盘那次算进去
漏一个块：  间接索引，要把数据块本身也算进访问次数
```

这三条，正好对应 22 篇第 9 节的检查三和检查一。

考前扫到这里，能想起来，就够用了。

## 8. 20 组最容易混的概念

先说一句反直觉的。

> **这份附录里最值钱的不是术语表，是下面这 20 组对照。**
>
> 术语表解决"想不起定义"，那是翻书能补的。
> 20 组对照解决"两个都记得，但分不清"——那是翻书也补不回来的。
>
> 408 的单选题，失分八成发生在这 20 组里。
> 因为出题人最喜欢做的，就是把两个近义概念并排放在四个选项里。

**1. 进程 vs 线程。**

进程是资源分配的基本单位，有独立地址空间。

线程是调度的基本单位，共享进程的地址空间。

切换进程要换页表，切换线程不用。

**2. 并发 vs 并行。**

并发是"看起来同时"，一个核也能做到，靠切换。

并行是"真的同时"，必须有多个核或多个处理机。

一句话：并发是逻辑上的同时，并行是物理上的同时。

**3. 中断 vs 异常。**

中断来自 CPU 外部，异步，和当前指令无关。

异常由当前指令引起，同步，如缺页、除零、陷入。

缺页是异常，磁盘完成是中断。

**4. 系统调用 vs 库函数。**

库函数是用户态代码，`printf` 是库函数。

系统调用是内核入口，`write` 是系统调用。

`printf` 内部会调用 `write`，所以它俩是两层，不是并列。

**5. 死锁 vs 饥饿。**

死锁是循环等待，谁也走不了，必须外部干预。

饥饿是长期得不到调度，但系统整体还在动。

死锁一定包含饥饿，饥饿不一定有死锁。

**6. 抢占 vs 非抢占。**

抢占是"我还能跑，但被拿走了"。

非抢占是"我跑完，或者我自己让"。

时钟中断是抢占式调度的物理基础。

**7. 周转时间 vs 带权周转时间。**

周转时间看"等了多久"，绝对值。

带权周转看"等的时间是它自己运行时间的几倍"，相对值。

一个 1 秒的作业等 10 秒，带权是 10；一个 100 秒的作业等 10 秒，带权是 0.1。

**8. 用户级线程 vs 内核级线程。**

用户级线程由库管理，切换快，但一个阻塞全阻塞。

内核级线程由内核管理，能真正并行，但切换要进内核。

组合模型就是两者混用，`n` 个用户线程映射到 `m` 个内核线程。

**9. 信号量 vs 管程。**

信号量是"一个整数 + 队列"，P/V 要自己配平，写错了就死锁。

管程是"共享变量 + 操作"的封装，进入自动互斥。

管程里等条件要 `wait`，而 `wait` 会释放管程，这是它和 P 的关键区别。

**10. 分页 vs 分段。**

分页是物理单位，页大小固定，对用户不可见，解决碎片。

分段是逻辑单位，段大小可变，对用户可见，便于共享与保护。

段页式是"先分段，段内再分页"。

**11. 内部碎片 vs 外部碎片。**

内部碎片在分区内部，因为分配的单位比要用的多。

外部碎片在分区之间，因为空闲块太小、太散。

分页只有内部碎片，分段只有外部碎片。

**12. 逻辑地址 vs 物理地址。**

逻辑地址是 CPU 发出的，程序里写的都是它。

物理地址是内存收到的，由 MMU 翻译得到。

链接器处理的是逻辑地址，MMU 处理的是翻译。

**13. 页表 vs 快表。**

页表在内存里，容量大，访问慢。

快表在 MMU 里，容量小（几十到几千项），访问快。

快表是页表的缓存，不是页表的一部分。

**14. 缺页 vs 页面置换。**

缺页是"要的页不在内存"，是事件。

置换是"内存满了，得挑一个换出去"，是动作。

缺页不一定置换，内存有空页框时直接装入。

**15. 块设备 vs 字符设备。**

块设备以块为单位，可随机寻址，用 DMA，如磁盘。

字符设备以字节为单位，顺序流，用中断，如键盘。

网卡两者都不是，它是第三类。

**16. DMA vs 通道。**

DMA 一次交代一块，传完要 CPU 再交代。

通道一次交代一串（通道程序），能服务多台设备。

通道是"能执行程序的 DMA"。

**17. 程序查询 vs 中断驱动。**

查询是 CPU 主动问，问的时候不能干别的。

中断是设备主动报，报之前 CPU 可以干别的。

两者搬数据都要经过 CPU 的寄存器。

**18. 缓冲 vs SPOOLing。**

缓冲在内存，容量小，解决速度不匹配。

SPOOLing 在磁盘，容量大，解决独占变共享。

缓冲不会让一台设备变成两台，SPOOLing 会。

**19. SCAN vs LOOK。**

SCAN 走到端点（0 或最大磁道）再折返。

LOOK 只走到最远的那个请求就折返。

LOOK 少走一段空跑，所以总距离更短。

**20. 硬链接 vs 软链接。**

硬链接是多个目录项指向同一个 inode，引用计数加一，删掉一个不影响。

软链接是一个独立文件，内容是路径字符串，原文件删了就失效。

硬链接不能跨文件系统，软链接可以。

## 12. 收尾：带走一句话

整套 24 篇，如果要压成一句。

```text
操作系统，是把有限的硬件，虚拟成每个程序都以为自己独占的资源。
```

再展开一点。

```text
CPU    → 进程与线程：让你以为自己在独占 CPU
内存   → 地址空间：让你以为自己有一整块内存
磁盘   → 文件：让你以为数据是一个个有名字的对象
设备   → 统一接口：让你以为所有设备都长一个样
```

四张底牌，撑起这四次虚拟化。

```text
中断、页表、inode、DMA。
```

中断让内核能被叫醒。

页表让地址能被翻译。

inode 让数据能有名字。

DMA 让数据能绕开 CPU。

这四样东西，加上调度、同步、分配、置换这些"决定谁先用"的规则，就是全部。

408 考的是它们。

工作中用的是它们。

读内核源码时看到的，还是它们。

如果这套系列只让你记住一件事，那应该是这句：

**遇到任何一个操作系统的问题，先问"它在虚拟化哪一份资源，代价是什么"。**

答得出这个问题，剩下的都是细节。

```text
全系列 24 篇，到此结束。
回到 [学习地图](/posts/os-systematic-learning-map/)，或者从任意一篇重新开始。
```
