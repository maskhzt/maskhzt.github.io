> **读这篇之前，你只需要知道**：矩阵是数排成的矩形表格，行数不必等于列数；初等变换是"交换两行、某行乘非零数、某行加另一行的 k 倍"这三种动作，它们不改变矩阵所描述的信息；行列式只对方阵有定义，等于零表示这个方阵有冗余。
> **这篇讲什么**：一个矩阵里"真正独立的信息"有几条，这个数目叫秩；它决定了方程组有没有解、有多少解，也决定了矩阵能不能求逆；这一篇讲秩怎么定义、怎么手算、有哪些性质。
> **一个类比**：三个人汇报同一件事，第一个讲"库存 100 件"，第二个讲"库存 100 件"（重复），第三个讲"库存是前两位之和"（废话）。三个人说了三条，真正独立的信息只有一条。秩就是"去掉重复和废话之后，剩下几条"。


先看三行数：

```text
1   2   3
2   4   6
3   6   9
```

三条信息，对吗？

不对。

第二行是第一行的 2 倍，第三行是第一行的 3 倍。

三行说的是同一件事。

真正独立的信息只有一条。

再看：

```text
1   2   3
4   5   6
5   7   9
```

第三行是第一行加第二行。

三条里只有两条独立。

**反直觉的点在这里：**

```text
"有几行"不等于"有几条独立信息"。
```

前者一眼能数，后者要算。

这个"独立信息的条数"，就是秩。

这一篇讲它：怎么定义、怎么算、能用来判断什么。

## 1. 为什么需要它（不给会怎样）

假设没有秩。

拿到一个方程组，想知道有没有解，只能消元消到底，看最后是不是出现 0 = 5 这种矛盾。

三元、四元还行，考试里常出现带参数的方程组，参数一变，有没有解就变。

没有秩，你只能对每个参数值分别消一遍元。

更麻烦的是"有多少解"。

唯一解和无穷多解，都要靠秩来区分。

再往远看，三个地方都在等秩：

```text
向量组：这组向量里有几个是"多余的"
方程组：有没有解、有几个自由变量
特征值：特征值的重数与特征向量的个数对不对得上
```

所以秩要回答的是：

```text
这个矩阵里，真正独立的信息有几条？
```

**它在现实里也是这个意思**

一张 1000 行 1000 列的数据表，看着有一百万个数。

如果它的秩只有 10，说明这一百万个数其实由 10 组数线性拼出来。

存 10 组数加 10 个系数，就能还原整张表。

推荐系统、图像压缩、降维算法，做的都是这件事：找到那个远小于行数列数的秩。

所以"秩低"不是坏事，是"这张表可以压缩"。

## 2. 最小模型：秩在数什么

没有一个可数的定义，就只能靠"看起来独不独立"来判断，遇到四阶就没了主意。

**先从"行"看**

一个 m×n 矩阵有 m 行。

这 m 行里，有些行能被其他行凑出来：

```text
某一行 = 另一行的 k 倍
某一行 = 另外两行相加
某一行 = 前几行的某个组合
```

这种行叫"多余的"。

把多余的去掉，剩下那些谁也凑不出谁的行，叫"独立行"。

**独立行的条数，就是秩的直观含义。**

**例子**

```text
A = | 1  2  3 |
    | 2  4  6 |
    | 1  1  1 |
```

第 2 行是第 1 行的 2 倍，多余。

第 1 行和第 3 行不能互相表示。

所以独立行有 2 条，秩是 2。

**换一个**

```text
B = | 1  0  0 |
    | 0  1  0 |
    | 0  0  1 |
```

三行谁也凑不出谁，秩是 3。

```text
C = | 0  0  0 |
    | 0  0  0 |
    | 0  0  0 |
```

一行独立信息都没有，秩是 0。

**秩的记法**

```text
r(A)  读作"矩阵 A 的秩"
```

也可以写成 rank(A)。

它是**一个数**，不是矩阵。

**从"变换"看秩**

矩阵可以看成一个把向量搬来搬去的动作。

秩就是这个动作"留下的空间维数"，也叫像空间的维数。

```text
r(A) = 3：三维空间还是三维，只是被拉伸、旋转、剪切
r(A) = 2：立体被压成一个平面
r(A) = 1：整个空间被压成一条直线
r(A) = 0：全压成一个点
```

压到几维，秩就是几。

这也解释了为什么"秩不够就不能求逆"：压扁之后回不去。

三个例子说完，可以给一句总结：

```text
满秩：独立信息占满全部行列
降秩：有一部分行列是"重复的"
秩 0：一个独立信息都没有
```

"降秩"这个词在题目里常见，看到它就该想到"行列式为 0，不可逆"。

## 3. 定义：最高阶非零子式的阶数

"独立行的条数"是个直观说法，做题需要一个能算的定义。

**子式**

在矩阵里任取 k 行、k 列，交叉位置的 k² 个数按原顺序排成一个 k 阶行列式。

这个行列式叫矩阵的一个 k 阶子式。

**定义**

```text
矩阵 A 的秩 = A 中非零子式的最高阶数
记作 r(A)
```

也就是说：如果存在一个 r 阶子式不为零，而所有 r+1 阶子式全为零，那么 r(A) = r。

**这个定义为什么对**

一个 k 阶子式不为零，说明这 k 行、k 列是"各自独立"的。

最高的那种 k，就是独立信息的条数。

**用定义算一个小的**

```text
A = | 1  2  3  4 |
    | 2  4  6  8 |
    | 1  1  1  1 |
```

先看二阶子式。

取第 1、3 行和第 1、2 列：

```text
| 1  2 |
| 1  1 | = 1 − 2 = −1 ≠ 0
```

有二阶非零子式，所以 r(A) ≥ 2。

再看三阶子式。

第 2 行是第 1 行的 2 倍，任取三行必含第 1、2 行或第 1、2 行的倍数关系。

实际上第 1、2 行成比例，任何包含这两行的三阶子式都为零。

那取第 1、3 行和第 2 行呢？还是含第 1、2 行。

三行只有三种取法，每种都含第 1、2 行，所以三阶子式全为零。

于是 r(A) = 2。

**这个定义的问题**

四阶矩阵有 16 个三阶子式、1 个四阶子式。

五阶就更夸张。

按定义一个个试，考场上来不及。

**先算清"有多少个"**

从 m 行里取 k 行、n 列里取 k 列，组合数是：

```text
C(m, k) × C(n, k)
```

四阶矩阵的三阶子式：C(4,3) × C(4,3) = 4 × 4 = 16 个。

四阶矩阵的二阶子式：C(4,2) × C(4,2) = 6 × 6 = 36 个。

所以定义适合证明，不适合计算。

**一个长方形矩阵的例子**

```text
A = | 1  2  3 |
    | 2  4  6 |
```

这是 2×3 矩阵，最高只能取二阶子式。

第 1、2 行与第 1、2 列：

```text
| 1  2 |
| 2  4 | = 4 − 4 = 0
```

第 1、2 行与第 1、3 列：

```text
| 1  3 |
| 2  6 | = 6 − 6 = 0
```

第 1、2 行与第 2、3 列：

```text
| 2  3 |
| 4  6 | = 12 − 12 = 0
```

三个二阶子式全为零，说明秩小于 2。

但一阶子式里有 1，不为零，所以 r(A) = 1。

这也符合直观：两行成比例，只有一条独立信息。

所以实际计算用下一节的办法。

## 4. 算一遍：化阶梯形求秩

没有这个方法，求秩就只能一个个试子式。

**结论**

```text
把矩阵用初等行变换化成阶梯形，
非零行的行数，就是秩。
```

**为什么**

阶梯形的每个非零行都有一个"主元"（该行第一个非零数），主元所在的列逐行往右移。

这些主元所在的行、列交叉出来的子式，是一个上三角行列式，对角线上全是主元，不为零。

所以秩至少等于非零行数。

而阶梯形里其他行全是零行，凑不出更高阶的非零子式，所以秩正好等于非零行数。

**手算一个四阶**

```text
      | 1   2   3   4 |
A =   | 2   3   5   7 |
      | 1   3   4   6 |
      | 3   5   8  11 |
```

第 1 步，用第 1 行消掉下面三行的首元。

```text
r₂ − 2r₁:  (2−2, 3−4, 5−6, 7−8)   = (0, −1, −1, −1)
r₃ − r₁:   (1−1, 3−2, 4−3, 6−4)   = (0,  1,  1,  2)
r₄ − 3r₁:  (3−3, 5−6, 8−9, 11−12) = (0, −1, −1, −1)
```

现在：

```text
| 1   2   3   4 |
| 0  −1  −1  −1 |
| 0   1   1   2 |
| 0  −1  −1  −1 |
```

第 2 步，用第 2 行消掉下面两行的第二个数。

```text
r₃ + r₂:  (0, 0, 0, 1)
r₄ − r₂:  (0, 0, 0, 0)
```

得到：

```text
| 1   2   3   4 |
| 0  −1  −1  −1 |
| 0   0   0   1 |
| 0   0   0   0 |
```

非零行有 3 行。

所以 **r(A) = 3**。

**回头验一下定义**

找一个三阶非零子式。

取第 1、2、3 行，第 1、2、4 列：

```text
| 1   2   4 |
| 2   3   7 |
| 1   3   6 |

= 1×(18 − 21) − 2×(12 − 7) + 4×(6 − 3)
= −3 − 10 + 12
= −1
```

不为零，所以 r(A) ≥ 3。

再算四阶行列式，因为秩是 3，它必然是 0。

两条路一致。

**阶梯形不是唯一的，但非零行数唯一**

不同的消元顺序会得到不同的阶梯形，但非零行的个数总是一样。

这就是秩是矩阵本身的属性，不随算法改变。

**化阶梯形的规范动作**

从上往下，一列一列地清。

第一列找一个非零元当主元（没有就跳到下一列），用这一行把下面所有行的第一个数清成零。

然后不管第一列，对剩下的部分重复同一件事。

每一步只用"某行加另一行的 k 倍"，不用乘系数，就不会引入分数。

遇到主元位置是零，就交换一行上来。

这个流程和求逆时的消元完全一样，区别只在停手的位置：

```text
求逆：要继续往上清，直到左边变成 E
求秩：往下清成阶梯形就够，数非零行
```

**再看一个三行四列的**

```text
A = | 1  2  3  4 |
    | 2  4  7  9 |
    | 0  0  1  1 |
```

第 2 行减第 1 行的 2 倍：

```text
(0, 0, 1, 1)
```

现在第 2 行和第 3 行一模一样，第 3 行减第 2 行得零行。

阶梯形是两行非零，所以 r(A) = 2。

注意第 1 列和第 2 列是 2 倍关系，这一对重复就是秩不够 3 的原因。

数一下独立的列：第 1 列、第 3 列独立，第 2 列是第 1 列的 2 倍，第 4 列由前三列凑出。

所以列秩也是 2。

## 5. 行秩、列秩与"三秩相等"

不弄清行秩和列秩的关系，就会以为"求列向量组的秩"要另起一套方法。

**行秩与列秩**

```text
行秩：行向量组里独立向量的个数
列秩：列向量组里独立向量的个数
```

对长方形矩阵，行数和列数不同，行秩和列秩看起来没有理由相等。

**但它们总是相等。**

这就是"三秩相等"：

```text
行秩 = 列秩 = r(A)
```

所以"矩阵的秩"这个说法是有底气的：不管从行看还是从列看，数出来都一样。

**为什么相等**

阶梯形化完之后，主元的个数既是"非零行数"（行秩），也等于"主元所在列的个数"（列秩）。

因为每一列最多有一个主元，而主元总数固定。

**一个直接推论**

```text
r(A) = r(Aᵀ)
```

Aᵀ 读作"A 的转置"，把行和列对调。

转置把行变成列，行秩变列秩，而两者相等，所以秩不变。

这条在证明题里很好用：想对"列"下手时，可以先转置成"行"。

**例子**

```text
A = | 1  2  3 |
    | 2  4  6 |
    | 1  0  1 |
```

行看：第 2 行 = 2×第 1 行，独立行 2 条。

列看：(1,2,1)、(2,4,0)、(3,6,1)。

第三列 = 第一列 + 第二列？(1+2, 2+4, 1+0) = (3, 6, 1)，正好等于第三列。

所以独立列也是 2 条。

两边一致。

**为什么这件事"不该成立"却总成立**

直觉上，行数和列数是两个独立的量，行秩和列秩看起来可以不一样。

比如一个 3×100 的矩阵，最多 3 个独立行，但可能有 100 个独立的列吗？

不可能。

因为每一列都是三维空间里的一个向量，三维空间里最多有 3 个互相独立的向量。

所以列秩也超不过 3。

这个"空间维数"的论证，是行秩等于列秩的本质：两者都不能超过 min(m, n)，而且都被同一个"像空间"卡住。

**一个附带结论**

矩阵的秩，等于它的行空间维数，也等于列空间维数，还等于非零子式的最高阶数。

四种说法，同一个数。

数一的选择题就爱在这四种说法之间来回换词。

## 6. 秩的十条性质

不记这些性质，每道题都要从定义重新推一遍，考场上没有这个时间。

**第一条：范围**

```text
0 ≤ r(A) ≤ min(m, n)
```

m×n 矩阵，秩最多到行数和列数里小的那个。

全是零的矩阵秩为 0。

**第二条：转置不变**

```text
r(Aᵀ) = r(A)
```

**第三条：乘可逆矩阵不变**

```text
P、Q 可逆时，r(PA) = r(A)，r(AQ) = r(A)，r(PAQ) = r(A)
```

初等变换就是乘初等矩阵，而初等矩阵可逆，所以初等变换不改变秩。

这条是"化阶梯形求秩"的合法性依据。

**第四条：加法不等式**

```text
r(A + B) ≤ r(A) + r(B)
```

两个秩 1 的矩阵加起来，秩最多 2。

例子：

```text
A = | 1  0 |      B = | 0  0 |      A + B = | 1  0 | = E
    | 0  0 |          | 0  1 |              | 0  1 |

r(A) = 1，r(B) = 1，r(A+B) = 2 = 1 + 1
```

取到等号了。

**第五条：乘法不等式**

```text
r(AB) ≤ min{r(A), r(B)}
```

乘法只会让秩变小或不变，不会变大。

为什么？因为 AB 的列是 A 的列的线性组合，组合出来的东西不可能比原料更"独立"。

例子：

```text
A = | 1  0 |      B = | 0  0 |      AB = O
    | 0  0 |          | 0  1 |

r(AB) = 0 ≤ min{1, 1} = 1
```

**第六条：数乘不变**

```text
k ≠ 0 时，r(kA) = r(A)
```

整个矩阵乘一个非零数，独立信息条数不变。

**第七条：可逆因子可以拿掉**

```text
A 可逆时，r(AB) = r(B)，r(BA) = r(B)
```

**第八条：满秩与行列式**

对 n 阶方阵：

```text
r(A) = n ⟺ |A| ≠ 0 ⟺ A 可逆
r(A) < n ⟺ |A| = 0 ⟺ A 不可逆
```

**第九条：幂等矩阵**

```text
A² = A 时，r(A) + r(A − E) = n
```

证明用两个不等式夹：

```text
r(A) + r(A − E) ≥ r(A − (A − E)) = r(E) = n
r(A) + r(A − E) ≤ r(A(A − E)) + n = r(O) + n = n
```

所以两边都等于 n。

这个结论在数一的选择题里出现过。

**第十条：Sylvester 不等式**

```text
AB = O 时，r(A) + r(B) ≤ n    （n 是 A 的列数）
```

因为 B 的每一列都是 Ax = 0 的解，解空间的维数是 n − r(A)；

而 B 的列秩不超过解空间维数，所以 r(B) ≤ n − r(A)。

移项就得到结论。

**这十条怎么用**

先分清"等式"和"不等式"：

```text
等式：r(Aᵀ) = r(A)，r(PA) = r(A)，r(kA) = r(A)，r(AB) = r(B)（A 可逆）
不等式：r(A + B) ≤ r(A) + r(B)，r(AB) ≤ min{r(A), r(B)}
```

等式用来"化简"，不等式用来"卡范围"。

证明题里最常见的动作是"卡范围 + 取到等号"。

比如要证 r(A) + r(A − E) = n，就是一头用加法不等式卡上界，一头用减法卡下界，两边一夹。

**一个容易忽略的点**

r(A + B) ≤ r(A) + r(B) 里的等号不总是成立。

A = E，B = −E 时，左边 r(O) = 0，右边 2n，差得很远。

所以看到"r(A+B)"，默认只能写不等式，不能写等号。

**同一个矩阵，秩的三种算法**

```text
算法一：化阶梯形，数非零行（最快，适合具体矩阵）
算法二：找最高阶非零子式（适合证明和小矩阵）
算法三：数独立列（适合和向量组打交道）
```

三条路答案一样，选顺手的用。

**十条并排**

```text
0 ≤ r(A) ≤ min(m, n)
r(Aᵀ) = r(A)
r(PA) = r(A)（P 可逆）
r(A + B) ≤ r(A) + r(B)
r(AB) ≤ min{r(A), r(B)}
r(kA) = r(A)（k ≠ 0）
A 可逆时 r(AB) = r(B)
r(A) = n ⟺ |A| ≠ 0
A² = A 时 r(A) + r(A − E) = n
AB = O 时 r(A) + r(B) ≤ n
```

## 7. 秩与方程组：一张判定表

没有这张表，解方程组就只能靠试。

**先约定记号**

```text
A：系数矩阵（m×n）
(A|b)：增广矩阵，把等号右边的 b 添成一列
n：未知数的个数
```

**判定表**

```text
r(A) ≠ r(A|b)                 → 无解
r(A) = r(A|b) = n             → 唯一解
r(A) = r(A|b) = r < n         → 无穷多解，有 n − r 个自由变量
```

读法：

```text
先比两个秩，决定"有没有解"
再看秩和 n 的关系，决定"解有几个"
```

**为什么**

r(A) 和 r(A|b) 的关系，说的是"b 能不能由 A 的列凑出来"。

凑不出来，就无解。

凑得出来时，解的自由度等于"没被主元占住的列数"，也就是 n − r。

**三个小例子**

第一个，唯一解：

```text
x + y = 3
x − y = 1
```

A 是 2×2，|A| = −2 ≠ 0，r(A) = 2 = n，唯一解。

第二个，无穷多解：

```text
x + y + z = 1
2x + 2y + 2z = 2
```

第二个方程是第一个的 2 倍，两行成比例。

r(A) = 1，r(A|b) = 1，n = 3。

r = 1 < 3，无穷多解，自由变量有 3 − 1 = 2 个。

第三个，无解：

```text
x + y = 1
x + y = 2
```

r(A) = 1，但增广矩阵 |1 1 1; 1 1 2| 的秩是 2（两行不成比例）。

两个秩不等，无解。

**r(A) 和 r(A|b) 的几何含义**

r(A) 是"系数矩阵能张出几维"。

r(A|b) 是把 b 添进去之后，能张出几维。

```text
两者相等   → b 落在 A 的列空间里 → 有解
r(A|b) 大 1 → b 跑到空间外面去了 → 无解
```

而且 r(A|b) 最多比 r(A) 大 1，因为只添了一列。

所以两个秩的差只有两种可能：0 或 1。

差 1 就是无解，这是数一选择题里最爱设的陷阱。

**这张表要背到什么程度**

看到方程组，第一反应应该是"算两个秩"，而不是"开始消元"。

第 06 篇会把这张表用到底：解的结构、基础解系、通解，全都从它出发。

**齐次方程组：一个特殊但重要的情形**

等号右边全是零的方程组 Ax = 0 叫齐次方程组。

它有一个天然的解：x 全取零，叫零解。

所以齐次方程组永远有解，问题只剩"有没有非零解"。

```text
只有零解      ⟺ r(A) = n
有非零解      ⟺ r(A) < n
```

理由来自判定表：r(A) = n 时唯一解，那个唯一的解只能是零；r(A) < n 时有无穷多解，除零之外还有别的。

自由变量的个数是 n − r(A)。

这也解释了"基础解系里有几个向量"这个问题的答案：就是 n − r。

**一个具体的齐次例子**

```text
x₁ + x₂ + x₃ = 0
2x₁ + 2x₂ + 2x₃ = 0
```

系数矩阵秩为 1，n = 3，所以有 3 − 1 = 2 个自由变量。

令 x₂ = 1、x₃ = 0，得 x₁ = −1，解向量 (−1, 1, 0)。

令 x₂ = 0、x₃ = 1，得 x₁ = −1，解向量 (−1, 0, 1)。

两个向量就是基础解系，通解是它们的任意组合。

这件事第 06 篇会正式做，这里先建立"自由变量个数 = n − r"的直觉。

## 8. 秩与行列式、逆

不把这几件事串起来，就会把"满秩""可逆""行列式不为零"当成三个独立结论去背。

**方阵的三句话合成一句**

```text
r(A) = n ⟺ |A| ≠ 0 ⟺ A 可逆 ⟺ 行（列）向量组线性无关
```

四个说法，同一件事。

**秩亏多少叫"亏秩"**

```text
r(A) = n     → 满秩
r(A) < n     → 降秩（亏秩）
n − r(A)     → 零空间的维数
```

**伴随矩阵的秩（三段式）**

设 A 是 n 阶方阵（n ≥ 2）：

```text
r(A) = n      →  r(A*) = n
r(A) = n − 1  →  r(A*) = 1
r(A) ≤ n − 2  →  r(A*) = 0
```

A* 读作"A 的伴随矩阵"，元素是代数余子式排好再转置，满足 A·A* = |A|E。

这里 |A| 读作"A 的行列式"。

为什么：

第一段，A 可逆，|A| ≠ 0，由 A* = |A|A⁻¹ 知 A* 也可逆。

第二段，r(A) = n−1 说明所有 n−1 阶子式里至少有一个非零，所以 A* 不是零矩阵，r(A*) ≥ 1。

又因为 AA* = |A|E = O，由 Sylvester 不等式 r(A) + r(A*) ≤ n，得 r(A*) ≤ 1。

两头一夹，r(A*) = 1。

第三段，r(A) ≤ n−2 说明所有 n−1 阶子式全为零，A* 的每个元素都是零，所以 A* = O。

**一个具体例子**

```text
A = | 1  2  3 |
    | 2  4  6 |
    | 1  1  1 |
```

r(A) = 2 = 3 − 1，属于第二段，所以 r(A*) = 1。

这个结论在数一的选择题里很爱考，因为它一次考了秩、行列式、伴随三个概念。

## 9. 秩与向量组

不把向量组的秩翻译成矩阵的秩，就只能在向量堆里硬凑。

**向量组的秩**

一组向量里，极大无关组所含向量的个数，叫这组向量的秩。

**和矩阵的关系**

把向量按列摆成矩阵，向量组的秩就等于矩阵的秩。

```text
向量组的秩 = 列向量组的秩 = r(A)
```

**例子**

三个三维向量：

```text
α₁ = (1, 2, 3)
α₂ = (2, 4, 6)
α₃ = (1, 0, 1)
```

按列摆：

```text
A = | 1  2  1 |
    | 2  4  0 |
    | 3  6  1 |
```

第 2 列 = 2×第 1 列，多余。

第 1 列和第 3 列不成比例，独立。

所以 r(A) = 2，向量组的秩是 2。

极大无关组可以取 {α₁, α₃}。

**"秩 = 独立条数"在三种语言里**

```text
矩阵语言：非零子式的最高阶数
向量语言：极大无关组里向量的个数
方程组语言：有效方程的个数
```

第 05 篇会把第二种语言讲透，你会发现三种说法一直在互相翻译。

**极大无关组怎么找**

标准动作只有三步：

```text
第一步：把向量按列摆成矩阵
第二步：化阶梯形，记住哪些列出现了主元
第三步：主元所在的那几列，就是极大无关组
```

注意第三步选的是"原矩阵的列"，不是阶梯形里的列。

因为行变换会改变列的数值，但"哪几列独立"这个信息被保留了下来。

**一个例子**

```text
α₁ = (1, 2, 1)
α₂ = (2, 4, 2)
α₃ = (1, 0, 1)
```

按列摆：

```text
A = | 1  2  1 |
    | 2  4  0 |
    | 1  2  1 |
```

化阶梯形：

```text
r₂ − 2r₁:  (0, 0, −2)
r₃ − r₁:   (0, 0, 0)
```

主元出现在第 1 列和第 3 列。

所以极大无关组是 {α₁, α₃}，秩是 2。

α₂ 是 α₁ 的 2 倍，多余。

**这件事和秩的关系**

极大无关组里向量的个数，就是向量组的秩。

换一个极大无关组，个数不变，但具体是哪几个向量可能不同。

所以"秩"是唯一的，"极大无关组"不唯一。

考试里如果问"写出一个极大无关组"，答案可能不止一种，写对一个就行。

## 10. 分块矩阵的秩

不分块，四阶以上的秩也要整体消元，又慢又容易错。

**分块对角**

```text
r(| A  O |) = r(A) + r(B)
  | O  B |
```

两块各自贡献自己的秩，互不干扰。

**分块三角**

```text
r(| A  C |) ≥ r(A) + r(B)
  | O  B |
```

至少是两块之和，也可能更大，因为 C 会带来额外的独立信息。

**分块"一行一列"**

```text
r(| A |) ≥ r(A)，  r([A  B]) ≥ max{r(A), r(B)}
  | B |
```

拼接只会让秩变大或不变。

**一个具体例子**

```text
M = | 1  2 | 0  0 |
    | 3  4 | 0  0 |
    | 0  0 | 5  0 |
    | 0  0 | 0  6 |
```

左上块 A = |1 2; 3 4|，r(A) = 2。

右下块 B = diag(5, 6)，r(B) = 2。

这是分块对角，所以 r(M) = 2 + 2 = 4。

四阶矩阵满秩，说明 M 可逆。

**一个用法**

看到大矩阵里有一大块零，先分块。

四阶的分块对角，秩直接是两块之和，不用整体消元。

如果题目问"这个矩阵可不可逆"，分块之后看每块可不可逆就行。

**注意前提**

分块对角的秩公式要求"非对角块是零块"。

如果右上块或左下块不为零，公式变成不等式，只能给下界。

这是最容易记错的地方：看到分块就以为是加法，其实只有对角情形才是加法。

## 11. 含参数求秩：完整一道

不掌握这个流程，含参数的秩题就只能一个个试值，试到考试结束也试不完。

这是数一最典型的考法。

**题目**

```text
A = | 1  1  1 |
    | 1  2  3 |
    | 1  4  a |
```

问 a 取何值时 r(A) = 2，取何值时 r(A) = 3。

**思路**

三阶方阵，秩只可能是 3 或小于 3。

而"秩小于 3"等价于 |A| = 0。

所以先算行列式。

**算行列式**

按第一行展开：

```text
A₁₁ = +|2 3; 4 a| = 2a − 12
A₁₂ = −|1 3; 1 a| = −(a − 3) = 3 − a
A₁₃ = +|1 2; 1 4| = 4 − 2 = 2

|A| = 1×(2a − 12) + 1×(3 − a) + 1×2
    = 2a − 12 + 3 − a + 2
    = a − 7
```

**分情况**

```text
a ≠ 7 时，|A| ≠ 0，r(A) = 3
a = 7 时，|A| = 0，r(A) ≤ 2
```

再看 a = 7 时的秩到底是不是 2。

把 a = 7 代进去消元：

```text
| 1  1  1 |
| 1  2  3 |
| 1  4  7 |

r₂ − r₁:  (0, 1, 2)
r₃ − r₁:  (0, 3, 6)
```

第 3 行是第 2 行的 3 倍，消掉：

```text
| 1  1  1 |
| 0  1  2 |
| 0  0  0 |
```

非零行 2 行，r(A) = 2。

**答案**

```text
a = 7 时，r(A) = 2
a ≠ 7 时，r(A) = 3
```

**这类题的固定流程**

```text
第一步：判断能不能用行列式（方阵才行）
第二步：|A| = 0 解出临界参数
第三步：把临界值代回，实际消元确认秩
第四步：写成分段结论
```

第三步不能省，因为 |A| = 0 只说明"不满秩"，具体降到几要另算。

**如果矩阵不是方阵**

比如 3×4 的系数矩阵，没有行列式可用。

这时只能直接消元，把参数当成普通数字往下算，再看非零行数怎么随参数变化。

常见情况是：消到某一步，某个数变成含参数的分式，分母为零时秩掉一档。

所以非方阵的参数题要做除法之前，先记下"分母不能为零"这个条件。

**含参数 + 方程组的混合题**

这是数一的大题常见形态：

```text
给一个带参数的方程组，问参数取何值时无解、有唯一解、有无穷多解
```

流程和第 11 节一样，只是最后一步要把"秩"翻译成"解的个数"：

```text
r(A) ≠ r(A|b)          → 无解
r(A) = r(A|b) = n      → 唯一解
r(A) = r(A|b) < n      → 无穷多解
```

三步走：算行列式找临界值、代回算两个秩、套判定表。

## 12. 常见错误

**错误一：把秩当成非零元素的个数**

```text
| 1  0  0 |
| 0  1  0 |  非零元素 3 个，但秩是 2
| 1  1  0 |
```

第三行等于前两行相加，所以秩是 2。

**错误二：以为行变换会改变秩**

初等变换不改变秩，这是第三条性质。

所以化阶梯形随便怎么做，最后数非零行就行。

**错误三：把"阶梯形的非零行数"当成"原矩阵的非零行数"**

原矩阵可能一行零都没有，秩却小于行数。

必须化完之后再数。

**错误四：r(A + B) = r(A) + r(B)**

正确是不等式 r(A+B) ≤ r(A) + r(B)。

反例：A = E，B = −E，左边 r(O) = 0，右边 2n。

**错误五：r(AB) = r(A)·r(B)**

两个秩 1 的矩阵相乘，秩不一定是 1，可能是 0。

正确是 r(AB) ≤ min{r(A), r(B)}。

**错误六：解方程组时用列变换**

求秩可以用行变换，也可以用列变换（它们都不改变秩）。

但解方程组只能用行变换，因为列变换会改变未知量的对应关系。

这是"求秩"和"解方程"的分界线。

**错误七：以为 r(A) = r 就有 r 行非零**

原矩阵可能每行都有非零元素，但真正独立的只有 r 行。

**错误八：含参数题只算 |A| = 0 就下结论**

|A| = 0 只说明秩小于 n，具体是 n−1 还是更小，必须代回消元确认。

**错误九：把"秩"和"迹"搞混**

秩是独立信息的条数，迹是对角线元素之和。

两者都是矩阵的一个数，但含义和用途完全不同。

一个反例：单位阵 E 的秩是 n，迹也是 n，看着一样；但 2E 的秩还是 n，迹变成 2n。

**错误十：以为秩相同的两个矩阵可以互相乘**

秩相同只说明"独立信息条数一样"，形状可能完全不同。

乘法能不能做，只看形状，不看秩。

**错误十一：把 r(A) = 1 直接当成"只有一个非零元素"**

秩 1 的矩阵可能每个元素都非零。

例子：

```text
| 1  2  3 |
| 2  4  6 |
| 3  6  9 |
```

九个元素全非零，秩却是 1，因为每一行都是第一行的倍数。

## 13. 数一怎么考

**题型一：求具体矩阵的秩**

化阶梯形，数非零行。

四阶以内通常三步到位。

一个快速判断：

```text
先扫一遍有没有两行（列）成比例 → 有，秩必然小于 n
再看有没有整行全零 → 有，那一行不贡献秩
最后才动手消元
```

这三眼能挡掉一半的计算量。

**题型二：含参数，问秩**

按第 11 节的流程走：行列式找临界值，代回确认。

**题型三：证明秩为 1 的矩阵形如 αβᵀ**

结论：

```text
r(A) = 1 ⟺ A = αβᵀ（α、β 是非零列向量）
```

正向：秩 1 说明所有列都是某一列的倍数，于是 A 的每一列 = 该列 × 系数，写成矩阵就是 αβᵀ。

反向：αβᵀ 的每一列都是 α 的倍数，秩不超过 1；又因为 α、β 非零，秩正好是 1。

例子：

```text
| 1  2 |
| 2  4 | = | 1 | · (1, 2)
            | 2 |
```

**题型四：伴随矩阵的秩**

三段式，见第 8 节。

考题常给"r(A) = n−1，求 r(A*)"，答案 1。

**题型五：解的判定（大题）**

给带参数的方程组，问"何时无解、何时唯一解、何时无穷多解"。

标准流程：

```text
第一步：算 |A|（如果是方阵）
第二步：|A| ≠ 0 时唯一解
第三步：|A| = 0 时，代回算 r(A) 与 r(A|b)
第四步：两个秩不等则无解，相等则无穷多解
```

**题型六：Sylvester 不等式的应用**

题目给 AB = O，问 r(A) + r(B) 的上界。

答案：不超过 n（A 的列数）。

如果还给了 r(A)，就能直接算出 r(B) 的上界。

**题型七：证明秩的不等式**

常见目标：r(A + B) ≤ r(A) + r(B)。

证明思路是把 A + B 的列拆成两部分：

```text
A + B 的第 j 列 = A 的第 j 列 + B 的第 j 列
```

所以 A + B 的列空间包含在"A 的列空间与 B 的列空间的并"所张成的空间里。

那个空间的维数不超过两个空间维数之和，于是结论成立。

这类证明不需要算具体元素，全靠"列空间包含关系"。

**题型八：由 r(A) 推 r(A*)**

三段式背下来就能直接答。

但要会写理由，因为大题要求过程：

```text
r(A) = n：A 可逆，A* = |A|A⁻¹ 可逆
r(A) = n−1：一头非零子式给出 r(A*) ≥ 1，一头 AA* = O 给出 r(A*) ≤ 1
r(A) ≤ n−2：所有 n−1 阶子式为零，A* 是零矩阵
```

三段都写全，才拿满分。

**题型九：秩为 1 的矩阵求和**

如果 A = αβᵀ，那么：

```text
A² = (βᵀα)A
Aⁿ = (βᵀα)ⁿ⁻¹A
```

而 βᵀα 是一个数，等于 A 的迹，也等于 A 的唯一非零特征值。

这条把秩、特征值、矩阵幂三件事串在了一起，是数一里少见的"一题多考"。

## 14. 和其他章节怎么连

**连行列式**

方阵满秩 ⟺ 行列式不为零。

|A| = 0 就是"秩不够"的另一种说法。

**连逆矩阵**

可逆 ⟺ 满秩。

求逆过程中如果左边化不出 E，就说明秩不够，矩阵不可逆。

**连向量组**

秩 = 极大无关组的大小 = 独立向量的个数。

第 05 篇整篇都在解释这句话。

**连方程组**

两个秩决定有没有解，n − r 决定有几个自由变量。

第 06 篇的通解公式里，n − r 就是基础解系里向量的个数。

**连特征值**

特征值的几何重数（特征向量的个数）不超过代数重数。

而几何重数 = n − r(A − λE)。

所以秩直接卡住了"能不能对角化"。

**连二次型**

二次型化成标准形后，非零项的个数等于矩阵的秩。

正平方项的个数叫正惯性指数，负的叫负惯性指数，两者之和就是秩。

一句话：

```text
秩是"这个矩阵有几个自由度"的度量，凡是问"有几个"的地方，答案都是秩。
```

**再补一个"零空间"的说法**

把 Ax = 0 的所有解收集起来，构成一个集合，叫 A 的零空间。

它的维数等于 n − r(A)。

```text
r(A) 大  → 零空间小  → 独立性强  → 方程组解少
r(A) 小  → 零空间大  → 冗余多    → 方程组解多
```

"秩"和"零空间维数"是一对互补的量，加起来正好是列数。

第 06 篇写通解时，那个 n − r 就是这里来的。

**最后一句**

秩是整本书里出现频率最高的一个数。

行列式问它"是不是 n"，逆矩阵问它"是不是 n"，方程组问它"两个秩等不等"，特征值问它"n 减秩够不够"。

所有的判断，最后都落到这个数上。

**如果只记住一句话**

```text
秩 = 有效信息的条数，其它一切都是它的推论。
```

拿到任何一个线代题，先问自己：这道题在问"有几条独立信息"吗？

如果是，答案就是秩；如果不是，先把条件翻译成秩再说。

### 自检三问

**第一问：为什么初等变换不改变秩？**

答：因为每种初等变换都等于左乘或右乘一个初等矩阵，而初等矩阵可逆。

乘可逆矩阵相当于换一组基来描述同一个空间，空间的维数不变。

从子式的角度看：初等变换把非零子式变成非零子式，阶数不变，所以最高阶数不变。

**第二问：为什么 r(AB) ≤ min{r(A), r(B)}？**

答：AB 的每一列都是 A 的各列的线性组合，所以 AB 的列空间包含在 A 的列空间里，维数不会更大，得 r(AB) ≤ r(A)。

同理，AB 的每一行都是 B 的各行的组合，得 r(AB) ≤ r(B)。

两个上界取小的，就是 min。

**第三问：为什么 r(A) = n−1 时 r(A*) = 1？**

答：两个方向夹出来的。

一方面，r(A) = n−1 说明存在非零的 n−1 阶子式，所以 A* 里至少有一个非零元素，r(A*) ≥ 1。

另一方面，AA* = |A|E = O（因为 |A| = 0），由 Sylvester 不等式得 r(A) + r(A*) ≤ n。

代入 r(A) = n−1，得 r(A*) ≤ 1。

上下界都是 1，所以等于 1。
