> **读这篇之前，你只需要知道**：方程是"含未知数的等式"，解方程就是找出让等式成立的数；方阵是"数排成的正方形表格"，行数和列数一样多；消元是"把一个方程乘一个数，加到另一个方程上，消掉一个未知数"。
> **这篇讲什么**：给每个方阵算出一个数，这个数不为零就说明方阵里的几行各自独立、方程组有唯一解、矩阵能求逆；这一篇讲这个数怎么定义、怎么手算、有什么脾气。
> **一个类比**：一队人报数，如果每个人报的都是自己的数，队伍就是"独立"的；如果有人偷偷跟着前一个人报，队伍里就有冗余。行列式就是给这支队伍打的一个总分：非零代表没人重复，零代表有人重复。


二元一次方程组：

```text
a₁₁x + a₁₂y = b₁
a₂₁x + a₂₂y = b₂
```

用消元法解它。

第一式乘 a₂₂，第二式乘 a₁₂，相减，y 被消掉，解出 x。

分母是同一个东西：

```text
a₁₁a₂₂ − a₁₂a₂₁
```

换一组等号右边的 b，这个分母不变。

也就是说，它只跟方程组的系数有关，跟 b 无关。

它决定这个方程组"能不能解出唯一一组 x、y"。

给它一个名字和一种写法：

```text
| a₁₁  a₁₂ |
| a₂₁  a₂₂ | = a₁₁a₂₂ − a₁₂a₂₁
```

这就是二阶行列式。

**反直觉的点在这里：**

```text
行列式不是"一种新的运算"，
而是"把一个方阵压缩成一个数"。
```

压缩出来的这个数，专门回答"独立不独立"。

这一篇就讲这个数：怎么读、怎么算、有什么脾气、考试怎么考。

## 1. 为什么需要它（不给会怎样）

先假设没有行列式这个东西。

拿到一个 n 元一次方程组，想知道"有没有唯一解"，只有一条路：动手消元，消到底，看剩下什么。

三元、四元还能忍，十个未知数就变成一叠草稿纸。

更麻烦的是三件事。

第一，消元过程中一旦出现 0 = 0 或者 0 = 5，你得停下来判断，而判断的规则每次都一样，却每次都要从头再推一遍。

第二，你想写一个公式直接给出解，写不出来，因为分母那一坨东西没有名字，没法在式子里引用。

第三，到了矩阵那一章，你要问"这个矩阵能不能求逆"，没有行列式，这个问题就没有一句话的判据。

行列式补的就是这三个洞。

它把"这个方阵里的几行是不是各自独立"压成一个数：

```text
不为 0 → 独立，方程组有唯一解，矩阵可逆
等于 0 → 有冗余，方程组没有唯一解，矩阵不可逆
```

一个数，顶掉一整套消元过程。

这就是它存在的理由。

在数一里，行列式一身三职：

```text
判据：判断方阵可逆不可逆、方程组有没有唯一解
公式的分母：克拉默法则、伴随矩阵求逆
特征多项式的常数项：|λE − A| 展开后的那个常数
```

所以它不是"一个要背的公式"，而是三处地方共用的同一个数。

## 2. 最小模型：二阶行列式

没有这个二阶版本，后面的三阶、n 阶都没有起点。

定义先写清楚。

两个数排成两行两列，两边各画一条竖线，这个记号读作"这个二阶行列式的值"。

计算规则只有一句：

```text
主对角线两个数相乘，减去副对角线两个数相乘。
```

主对角线是从左上到右下，副对角线是从右上到左下。

算一个：

```text
| 2   3 |
| 1  −1 | = 2×(−1) − 3×1 = −2 − 3 = −5
```

再算一个，这次结果为零：

```text
| 1   2 |
| 2   4 | = 1×4 − 2×2 = 0
```

第二行是第一行的 2 倍，两行说的是同一件事，所以这个数等于 0。

**符号怎么读**：

`|A|` 读作"矩阵 A 的行列式"。

注意这里的竖线不是绝对值，虽然样子一样。

对数字取绝对值是"去掉负号"，对方阵取行列式是"算一个值"，两者没有关系。

为什么二阶是这个式子？

把它看成平面上的两个向量：(a₁₁, a₂₁) 和 (a₁₂, a₂₂)，按列摆。

这两个向量张成一个平行四边形。

它的有向面积正好是 a₁₁a₂₂ − a₁₂a₂₁。

验证：向量 (2, 1) 和 (3, −1)，有向面积 = 2×(−1) − 3×1 = −5，取绝对值是 5。

**带符号**这个词很重要。

交换两个向量的位置，面积大小不变，符号反过来。

这就是后面"交换两行，行列式变号"的来源。

面积为零，说明两个向量共线，压成一条线段，平行四边形塌了。

对应到方程组：两条直线平行或重合，没有唯一交点。

**用它判断两条直线的位置关系**

三个方程组，看分母就知道命运。

第一个：

```text
 x + 2y = 3
2x + y  = 4
```

D = 1×1 − 2×2 = 1 − 4 = −3，不为零，两条直线相交，唯一解。

解出来是 x = 5/3，y = 2/3，代回去两个等式都成立。

第二个：

```text
x + 2y = 3
2x + 4y = 6
```

D = 1×4 − 2×2 = 0，两条直线重合，无穷多解。

注意第二个方程就是第一个方程乘 2，两行成比例，行列式必然是 0。

第三个：

```text
x + 2y = 3
2x + 4y = 7
```

D = 0，但两条直线平行且不重合，无解。

第二个和第三个的行列式都是 0，一个有解一个没解。

这说明：**行列式只能回答"有没有唯一解"，回答不了"到底有没有解"。**

"有没有解"要靠秩，那是第 04 篇的事。

## 3. 符号怎么读：从 aᵢⱼ 到 Aᵢⱼ

往后每个符号第一次出现，都要能读出来，不然看公式像看天书。

**aᵢⱼ**

读作"a 下标 i j"，表示第 i 行第 j 列那个数。

行号在前，列号在后，这个顺序不能反。

**|A|**

读作"A 的行列式"，它是一个数。

n 阶方阵的行列式也写作 det A，两种记号都通行。

**E**

读作"单位矩阵"，主对角线全是 1、其余全是 0 的方阵。

它相当于数字里的 1：AE = EA = A。

|E| = 1，这个值在后面的公式里会反复出现。

**Σ**

读作"西格玛"，希腊字母的大写 sigma，意思是"求和"。

```text
Σ aᵢⱼAᵢⱼ   （对 j 从 1 到 n 求和）
```

读作"把 aᵢⱼ 乘 Aᵢⱼ，对 j 从 1 到 n 加起来"。

**Mᵢⱼ**

读作"aᵢⱼ 的余子式"。

做法：把第 i 行、第 j 列整条划掉，剩下的小方阵求行列式，得到的就是 Mᵢⱼ。

**Aᵢⱼ**

读作"aᵢⱼ 的代数余子式"。

它在余子式上多一个符号：

```text
Aᵢⱼ = (−1)^(i+j) Mᵢⱼ
```

(−1) 的指数是 i + j，行号加列号为偶数取正，为奇数取负。

三阶的时候，这些符号排成一张棋盘：

```text
+  −  +
−  +  −
+  −  +
```

左上角是 +，往右走一步变号，往下走一步也变号。

记住这张棋盘，比每次现算 i+j 快。

**三阶行列式的完整定义**

```text
| a₁₁  a₁₂  a₁₃ |
| a₂₁  a₂₂  a₂₃ |
| a₃₁  a₃₂  a₃₃ |

= Σ (−1)^τ a₁ₚ₁ a₂ₚ₂ a₃ₚ₃
```

读作：列标 (p₁, p₂, p₃) 取遍 1、2、3 的全部排列，每一项三个数相乘，符号由排列的逆序数 τ 决定。

一共有 3! = 6 项，三正三负。

**逆序数**：一个排列里，前面的数比后面的数大的"数对"有几个，τ 就是几。

比如 (2, 3, 1)：2 比 1 大，3 比 1 大，共 2 对，τ = 2，符号为正。

这个定义数一不要求你手算逆序数，但你要知道它解释了"六项、三正三负"从哪来。

实际计算用后面两条路，比数排列快得多。

为什么定义非要写成"行标固定、列标取排列"？

因为行列式要保证：**每一行出一个数，每一列出一个数，一个不重复。**

三阶有 3 行，每行挑一个，挑出来的列号不能重样，所以列号正好是 1、2、3 的一个排列。

三行三列各取一个，一共 3! = 6 种挑法，对应定义里的 6 项。

乘法可以交换顺序，所以每项里三个数谁先谁后无所谓，真正决定这项长什么样的，是"挑了哪三个位置"。

逆序数管的是符号。

从几何上看，交换两个列标，等于把平行四边形的两条边换位置，定向翻转，有向面积变号。

逆序数就是"交换了多少次才能排回 1、2、3"，交换奇数次取负，偶数次取正。

这就是为什么定义里要拖一个 (−1)^τ 的尾巴。

## 4. 三阶的两条路

只会死记一个展开式，遇到零多的行列式就会绕远路，遇到四阶更是无从下手。

三阶行列式有两条正规算法。

一条是照定义按行展开。

一条是化成三角形。

还有一条捷径只对二阶和三阶有效，先说它，因为考场上快。

**对角线法则（萨吕斯法则）**

把前两列抄到右边，形成几条斜向的乘积：

```text
| a₁₁  a₁₂  a₁₃ | a₁₁  a₁₂
| a₂₁  a₂₂  a₂₃ | a₂₁  a₂₂
| a₃₁  a₃₂  a₃₃ | a₃₁  a₃₂
```

三条"左上到右下"的斜线上三个数相乘，取正：

```text
a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂
```

三条"右上到左下"的斜线上三个数相乘，取负：

```text
a₁₃a₂₂a₃₁ + a₁₁a₂₃a₃₂ + a₁₂a₂₁a₃₃
```

两者相减，就是三阶行列式。

**这条法则只对二阶和三阶成立。**

四阶照这个画法会得到 8 项，而正确答案是 24 项，直接错。

所以它是个考场加速器，不是定义。

数一考到四阶以上时，你必须会展开或者化三角。

顺便记住项数的规律：

```text
二阶 2! = 2 项
三阶 3! = 6 项
四阶 4! = 24 项
n 阶 n! 项
```

阶数每加一，项数乘一个越来越大的数。

所以四阶开始，"照定义硬算"就没人干了，必须降阶或者化三角。

## 5. 算一遍：按第一行展开

不听一遍完整的手算，展开定理就只是六个字。

先给一个三阶行列式，全程手算：

```text
      | 1   2   3 |
D =   | 4   5   6 |
      | 7   8  10 |
```

第一步，写出第一行三个数的代数余子式。

a₁₁ = 1，划掉第 1 行第 1 列，剩下：

```text
| 5   6 |
| 8  10 | = 5×10 − 6×8 = 50 − 48 = 2
```

位置 (1,1)，1+1 = 2 是偶数，符号为正，所以 A₁₁ = +2。

a₁₂ = 2，划掉第 1 行第 2 列，剩下：

```text
| 4   6 |
| 7  10 | = 4×10 − 6×7 = 40 − 42 = −2
```

位置 (1,2)，1+2 = 3 是奇数，符号为负，所以 A₁₂ = −(−2) = +2。

a₁₃ = 3，划掉第 1 行第 3 列，剩下：

```text
| 4   5 |
| 7   8 | = 4×8 − 5×7 = 32 − 35 = −3
```

位置 (1,3)，1+3 = 4 是偶数，符号为正，所以 A₁₃ = −3。

第二步，按第一行展开：

```text
D = a₁₁A₁₁ + a₁₂A₁₂ + a₁₃A₁₃
  = 1×2 + 2×2 + 3×(−3)
  = 2 + 4 − 9
  = −3
```

答案：**D = −3**。

第三步，换一条路验算，这次按第二列展开。

第二列是 2、5、8。

先把三个代数余子式补齐。

A₁₂ 上面算过，等于 +2。

a₂₂ = 5，划掉第 2 行第 2 列，剩下 |1 3; 7 10|，值 = 1×10 − 3×7 = 10 − 21 = −11。

位置 (2,2)，2+2 = 4 是偶数，符号为正，A₂₂ = −11。

a₃₂ = 8，划掉第 3 行第 2 列，剩下 |1 3; 4 6|，值 = 1×6 − 3×4 = 6 − 12 = −6。

位置 (3,2)，3+2 = 5 是奇数，符号为负，A₃₂ = +6。

按第二列展开：

```text
D = 2×(2) + 5×(−11) + 8×(6)
  = 4 − 55 + 48
  = −3
```

两条路同一个答案。

**这就是展开定理**：按任意一行、任意一列展开，结果都一样。

```text
|A| = Σ aᵢⱼAᵢⱼ   （固定 i，对 j 求和，叫按第 i 行展开）
|A| = Σ aᵢⱼAᵢⱼ   （固定 j，对 i 求和，叫按第 j 列展开）
```

考场上的用法：挑 0 最多的那一行或那一列展开。

如果某行只有一个非零数，展开后只剩一项，计算量从三项直接掉到一项。

**换成第三行再验一遍**

第三行是 7、8、10。

A₃₁ 对应位置 (3,1)，3+1 = 4 为偶，符号为正，划掉第 3 行第 1 列：

```text
| 2  3 |
| 5  6 | = 12 − 15 = −3
```

所以 A₃₁ = −3。

A₃₂ 对应位置 (3,2)，3+2 = 5 为奇，符号为负，划掉第 3 行第 2 列：

```text
| 1  3 |
| 4  6 | = 6 − 12 = −6
```

所以 A₃₂ = −(−6) = +6。

A₃₃ 对应位置 (3,3)，3+3 = 6 为偶，符号为正，划掉第 3 行第 3 列：

```text
| 1  2 |
| 4  5 | = 5 − 8 = −3
```

所以 A₃₃ = −3。

按第三行展开：

```text
D = 7×(−3) + 8×(6) + 10×(−3)
  = −21 + 48 − 30
  = −3
```

三个方向，三个 −3。

**展开之前先造 0**

更省力的做法是：先把某一行（或某一列）清成只剩一个非零数，再展开。

用第 2 行减第 1 行的 4 倍，第 3 行减第 1 行的 7 倍：

```text
| 1   2    3 |
| 0  −3   −6 |
| 0  −6  −11 |
```

第一列只剩左上角一个 1，按第一列展开只有一项，符号为正：

```text
D = 1 × | −3   −6 |
        | −6  −11 |
  = (−3)×(−11) − (−6)×(−6)
  = 33 − 36
  = −3
```

一次清列，三阶变二阶。

注意这一步和下一节"化三角"的开头完全一样，区别只在停手的位置。

展开法停在"能降一阶"，化三角法一路做到上三角。

## 6. 再算一遍：化三角形

只会展开不会化三角，四阶以上基本算不完。

第二个办法：用行变换把行列式变成上三角，再把对角线上三个数相乘。

为什么可以这样？

因为上三角行列式按第一列展开时只有 a₁₁ 一项，剩下的部分还是上三角，一路展开下去就是对角线乘积。

先记住三种行变换对行列式值的影响，这是全部关键：

```text
交换两行              → 行列式变号（乘 −1）
某一行乘 k            → 行列式的值乘 k
某一行加上另一行的 k 倍 → 行列式的值不变
```

第三条是主力，因为它不改值，随便用。

第一条和第二条要记账，最后补回来。

用同一个行列式完整走一遍，前三步和上一节开头相同：

```text
      | 1   2   3 |
D =   | 4   5   6 |
      | 7   8  10 |
```

第 1 步，用第 1 行消掉第 2 行的首元：第 2 行减去第 1 行的 4 倍。

```text
r₂ − 4r₁:  (4−4, 5−8, 6−12) = (0, −3, −6)
```

第 2 步，用第 1 行消掉第 3 行的首元：第 3 行减去第 1 行的 7 倍。

```text
r₃ − 7r₁:  (7−7, 8−14, 10−21) = (0, −6, −11)
```

现在形状是：

```text
| 1    2    3 |
| 0   −3   −6 |
| 0   −6  −11 |
```

第 3 步，用第 2 行消掉第 3 行的第二个数：第 3 行减去第 2 行的 2 倍。

```text
r₃ − 2r₂:  (0−0, −6−(−6), −11−(−12)) = (0, 0, 1)
```

得到上三角：

```text
| 1    2    3 |
| 0   −3   −6 |
| 0    0    1 |
```

对角线相乘：

```text
D = 1 × (−3) × 1 = −3
```

和展开的结果一致。

**如果中途交换过两行**，最后要乘一个 −1。

**如果中途把某一行乘了 k**（比如为了消掉分数，把第 2 行乘 3），最后要除回去。

这两种记账是化三角法最常见的失分点。

两条路怎么选：

```text
元素里 0 多，或者某行某列很整齐 → 展开
阶数高（四阶以上）、数字没规律   → 化三角
```

**四阶也走一遍**

```text
      | 1   2   0   1 |
      | 2   5   3   2 |
M =   | 0   3  11   2 |
      | 1   2   4   6 |
```

第 1 步，用第 1 行消掉第 2 行、第 4 行的首元。

```text
r₂ − 2r₁:  (2−2, 5−4, 3−0, 2−2)   = (0, 1, 3, 0)
r₄ − r₁:   (1−1, 2−2, 4−0, 6−1)   = (0, 0, 4, 5)
```

第 2 步，用新的第 2 行消掉第 3 行的第二个数。

```text
r₃ − 3r₂:  (0−0, 3−3, 11−9, 2−0)  = (0, 0, 2, 2)
```

第 3 步，用新的第 3 行消掉第 4 行的第三个数。

```text
r₄ − 2r₃:  (0−0, 0−0, 4−4, 5−4)   = (0, 0, 0, 1)
```

现在形状是：

```text
| 1   2   0   1 |
| 0   1   3   0 |
| 0   0   2   2 |
| 0   0   0   1 |
```

对角线相乘：

```text
|M| = 1 × 1 × 2 × 1 = 2
```

全程只用了倍加，没有交换行，没有乘系数，所以不用记账。

四阶 24 项，化三角只花了三步。

这就是化三角法在考场上的价值：**阶数越高，优势越大。**

## 7. 七条性质

不会用性质，就只能每次硬展开，也看不出"这个行列式本来就等于零"。

这些性质不是背下来装样子，每一条都能少算一半。

**第一条：转置不变**

```text
|Aᵀ| = |A|
```

Aᵀ 读作"A 的转置"，把行和列对调。

例子：

```text
| 1  2 |
| 3  4 | = 1×4 − 2×3 = −2

把它转置，行变列：

| 1  3 |
| 2  4 | = 1×4 − 3×2 = −2
```

行列式对行和列一视同仁，所以按行展开和按列展开结果一样。

考场上这意味着：哪一列 0 多，就按列展开，不必先把列换成行。

**第二条：交换两行，变号**

```text
| 1  2 |
| 3  4 | = 1×4 − 2×3 = −2

交换两行：

| 3  4 |
| 1  2 | = 3×2 − 4×1 = 6 − 4 = 2
```

2 正好是 −2 的相反数。

**第三条：某行乘 k，值乘 k**

```text
| 1  2 |
| 3  4 | = −2

把第 2 行乘 2：

| 1   2 |
| 6   8 | = 1×8 − 2×6 = 8 − 12 = −4
```

−4 正好是 −2 的 2 倍。

推论，这条最容易错：

```text
|kA| = kⁿ|A|   （n 是阶数，k 提到外面要取 n 次方）
```

验证：A = |1 2; 3 4|，|A| = −2，k = 3，n = 2。

3A = |3 6; 9 12|，行列式 = 3×12 − 6×9 = 36 − 54 = −18。

而 9×(−2) = −18，一致。

如果写成 |kA| = k|A|，会得到 −6，错。

**第四条：两行相同或成比例，值为 0**

```text
| 1  2 |
| 2  4 | = 4 − 4 = 0
```

这两行说的是同一件事，方阵里少了一条独立信息。

这条是判断"行列式为零"最快的路。

**第五条：某行加另一行的 k 倍，值不变**

这就是化三角法的主力，前面已经用过。

```text
| 1  2 |
| 3  4 | = −2

把第 1 行乘 2 加到第 2 行：

| 1  2 |
| 5  8 | = 1×8 − 2×5 = 8 − 10 = −2
```

第二行正是"第一行乘 2 加到第二行"得到的。

**第六条：可拆**

如果某一行是两组数相加，行列式可以拆成两个行列式相加：

```text
| 1   2 |
| 8  10 | = 1×10 − 2×8 = 10 − 16 = −6

第 2 行拆成 (3+5, 4+6)，于是：

| 1  2 |   | 1  2 |
| 3  4 | + | 5  6 | = (−2) + (6 − 10) = −6
```

左边 = 1×10 − 2×8 = −6，右边 = −2 + (−4) = −6。

注意：只能拆一行，其余行必须原样不动。

**第七条：乘法**

```text
|AB| = |A|·|B|
```

例子：A = |1 2; 3 4|，B = |2 0; 1 3|。

先算 AB：

```text
AB = | 1×2+2×1   1×0+2×3 | = | 4   6 |
     | 3×2+4×1   3×0+4×3 |   | 10  12 |
```

|AB| = 4×12 − 6×10 = 48 − 60 = −12。

|A|·|B| = (−2)×6 = −12。

由此推出三条常用的：

```text
|A⁻¹| = 1/|A|
|A*|  = |A|^(n−1)     （A* 读作"伴随矩阵"，下一篇细讲）
|Aᵏ|  = |A|ᵏ
```

**注意 |A + B| 没有公式。**

它既不等于 |A| + |B|，也没有别的简单写法。

反例：A = |1 0; 0 0|，B = |0 0; 0 1|。

|A| = 0，|B| = 0，而 A + B = E，|A+B| = 1。

0 + 0 不等于 1，直接推翻。

**用性质秒算一个四阶**

```text
| 2  3  4  5 |
| 3  4  5  6 |
| 4  5  6  7 |
| 5  6  7  8 |
```

每行都是等差数列，且公差都是 1。

第 2 行减第 1 行：

```text
(3−2, 4−3, 5−4, 6−5) = (1, 1, 1, 1)
```

第 3 行减第 2 行：

```text
(4−3, 5−4, 6−5, 7−6) = (1, 1, 1, 1)
```

两行变成一模一样，由第五条性质，值不变；由第四条性质，两行相同，值为 0。

所以这个四阶行列式等于 0。

一行没展开，一个余子式没算。

**这才是性质真正的用法：先用性质把结构看清，再决定要不要算。**

**性质的组合用法**

单条性质好记，组合起来才是真本事。

下面这个四阶，看着没规律：

```text
| 1  2  3  4 |
| 2  3  4  1 |
| 3  4  1  2 |
| 4  1  2  3 |
```

把第 2、3、4 行都加到第 1 行上（用第五条性质，值不变）：

```text
第 1 行变成 (1+2+3+4, 2+3+4+1, 3+4+1+2, 4+1+2+3) = (10, 10, 10, 10)
```

第 1 行四个数全相等。

提出公因子 10（用第三条性质）：

```text
原式 = 10 × | 1  1  1  1 |
             | 2  3  4  1 |
             | 3  4  1  2 |
             | 4  1  2  3 |
```

再用第 1 行去消下面三行：

```text
r₂ − 2r₁ = (0, 1, 2, −1)
r₃ − 3r₁ = (0, 1, −2, −1)
r₄ − 4r₁ = (0, −3, −2, −1)
```

接着 r₃ − r₂ = (0, 0, −4, 0)，阶数一路往下掉。

这个"先把各行加到某一行，凑出全相等"的动作，是数字对称型行列式的标准开局。

看到"每行数字一样，只是顺序不同"，第一反应就该是它。

## 8. 五类必背的特殊行列式

不背这几类，考场上每一个都要从头展开，时间根本不够。

**第一类：三角形行列式**

上三角、下三角、对角，值都等于对角线乘积。

```text
| 1  2  3 |
| 0  4  5 | = 1×4×6 = 24
| 0  0  6 |
```

副对角线的情形要加符号：

```text
| 0  0  1 |
| 0  2  0 | = −2
| 3  0  0 |
```

符号是 (−1)^(n(n−1)/2)，三阶时指数为 3，取负。

**第二类：范德蒙德行列式**

形状是"每一行都是某个数的 0 次、1 次、2 次方幂"：

```text
| 1   1   1  |
| a   b   c  | = (b−a)(c−a)(c−b)
| a²  b²  c² |
```

口诀：后面每个数减前面每个数，全部乘起来。

算一个具体的，取 a = 1，b = 2，c = 3：

```text
| 1  1  1 |
| 1  2  3 |
| 1  4  9 |
```

按公式：(2−1)(3−1)(3−2) = 1×2×1 = 2。

按第一行展开验证：

```text
1×(2×9 − 3×4) − 1×(1×9 − 3×1) + 1×(1×4 − 2×1)
= (18 − 12) − (9 − 3) + (4 − 2)
= 6 − 6 + 2
= 2
```

一致。

范德蒙德在数一里的用法：三个数互不相同时行列式不为零，于是对应方程组有唯一解，这就是插值问题有唯一解的原因。

**第三类：爪型**

只有第一行、第一列和对角线上有非零元素，形状像一只爪。

处理办法：用第一行（或第一列）把爪子一根一根消掉，化成三角。

例子：

```text
| 1  1  1 |
| 1  2  0 |
| 1  0  3 |
```

第 2 行减第 1 行，第 3 行减第 1 行：

```text
| 1   1   1 |
| 0   1  −1 |
| 0  −1   2 |
```

第 3 行加第 2 行：

```text
| 1   1   1 |
| 0   1  −1 |
| 0   0   1 |
```

值 = 1×1×1 = 1。

直接按第一行展开也是 1：1×(6−0) − 1×(3−0) + 1×(0−2) = 6 − 3 − 2 = 1。

**第四类：三对角递推**

主对角线和上下两条副对角线有数，其余为零。

```text
| a  b  0 |
| c  a  b |
| 0  c  a |
```

记 Dₙ 为 n 阶的这种行列式，按第一行展开：

```text
Dₙ = a·Dₙ₋₁ − bc·Dₙ₋₂
```

这是二阶递推，配上 D₁ = a、D₂ = a² − bc 就能一路往下推。

三阶验算，取 a = 2，b = 1，c = 1：

```text
D₁ = 2
D₂ = 4 − 1 = 3
D₃ = 2×3 − 1×1×2 = 4
```

直接算：

```text
| 2  1  0 |
| 1  2  1 | = 2×(4−1) − 1×(2−0) + 0 = 6 − 2 = 4
| 0  1  2 |
```

一致。

数一考递推一般只到三阶或四阶，写出递推式就能拿分。

**第五类：分块三角形**

```text
| A  O |
| C  B | = |A|·|B|
```

A、B 是方阵，O 是零矩阵，C 是任意块。

读法：左上块的行列式乘右下块的行列式。

四阶例子：

```text
| 1  2 | 0  0 |
| 3  4 | 0  0 |
| 0  0 | 2  1 |
| 0  0 | 5  3 |
```

左上块 |1 2; 3 4| = −2，右下块 |2 1; 5 3| = 6 − 5 = 1。

整体行列式 = (−2)×1 = −2。

如果非零块长在副对角线上，符号要多一层：

```text
| O  A |
| B  O | = (−1)^(mn)|A|·|B|
```

m、n 是两个块的阶数。

**n 阶范德蒙德**

```text
| 1     1     …   1    |
| x₁    x₂    …   xₙ   |
| x₁²   x₂²   …   xₙ²  |
|  ⋮     ⋮    ⋱    ⋮   |
| x₁ⁿ⁻¹ x₂ⁿ⁻¹ …  xₙⁿ⁻¹ |
= ∏ (xⱼ − xᵢ)   （对所有 i < j 乘一遍）
```

∏ 读作"派"，希腊字母 pi，意思是连乘。

不考你写这个符号，但考你看到"方幂排成行"就知道答案长什么样。

## 9. 算一遍：克拉默法则解一个三元方程组

没有它，方程组的解只能一个数一个数消出来，写不成一条公式。

行列式最早的工作，就是给方程组的解写公式。

先把方程组摆好：

```text
 x +  y +  z = 6
2x −  y +  z = 3
 x + 2y −  z = 2
```

第一步，算系数行列式 D。

```text
      | 1   1   1 |
D =   | 2  −1   1 |
      | 1   2  −1 |
```

按第一行展开：

```text
A₁₁ = +|−1  1; 2  −1| = 1 − 2 = −1
A₁₂ = −| 2  1; 1  −1| = −(−2 − 1) = 3
A₁₃ = +| 2 −1; 1   2| = 4 + 1 = 5

D = 1×(−1) + 1×3 + 1×5 = 7
```

D = 7，不为零，可以用克拉默法则，而且解唯一。

第二步，算 D₁：把第 1 列换成等号右边的 (6, 3, 2)。

```text
       | 6   1   1 |
D₁ =   | 3  −1   1 |
       | 2   2  −1 |
```

按第一行展开：

```text
6×(1 − 2) − 1×(−3 − 2) + 1×(6 + 2)
= −6 + 5 + 8
= 7
```

第三步，算 D₂：把第 2 列换成 (6, 3, 2)。

```text
       | 1   6   1 |
D₂ =   | 2   3   1 |
       | 1   2  −1 |
```

```text
1×(−3 − 2) − 6×(−2 − 1) + 1×(4 − 3)
= −5 + 18 + 1
= 14
```

第四步，算 D₃：把第 3 列换成 (6, 3, 2)。

```text
       | 1   1   6 |
D₃ =   | 2  −1   3 |
       | 1   2   2 |
```

```text
1×(−2 − 6) − 1×(4 − 3) + 6×(4 + 1)
= −8 − 1 + 30
= 21
```

第五步，相除：

```text
x = D₁/D = 7/7 = 1
y = D₂/D = 14/7 = 2
z = D₃/D = 21/7 = 3
```

代回原方程组验算：

```text
1 + 2 + 3 = 6      ✓
2 − 2 + 3 = 3      ✓
1 + 4 − 3 = 2      ✓
```

答案：**x = 1，y = 2，z = 3**。

**这个法则的三个使用条件**

```text
方程个数等于未知数个数（系数矩阵是方阵）
系数行列式 D ≠ 0
D ≠ 0 时，解唯一，公式才成立
```

第一条不满足（方程比未知数多或少），根本没有 D，法则直接失效。

第二条不满足，D = 0，公式分母是零，法则失效，此时要改用秩来判断。

所以克拉默法则不是"万能解法"，它只负责"唯一解"这一种情况。

它的价值在于给出解的表达式，而不在于算得快：四个三阶行列式，比消元慢多了。

## 10. 行列式的几何意义：面积与体积

不看几何意义，行列式的性质就只能死背，记不住也推不出。

二阶行列式是有向面积，三阶是有向体积。

三阶这一句，值得展开。

三个三维向量按列摆成一个 3×3 方阵，它们张成一个平行六面体。

这个六面体的体积，等于行列式的绝对值。

例子：

```text
      | 2  0  0 |
A =   | 0  3  0 |
      | 0  0  4 |
```

三个向量是 (2,0,0)、(0,3,0)、(0,0,4)，沿着三条坐标轴，张成一个长方体。

体积 = 2×3×4 = 24。

而 |A| = 2×3×4 = 24，一致。

再看一个行列式为零的例子：

```text
      | 1  2  3 |
B =   | 2  4  6 |
      | 1  1  1 |
```

第 2 行是第 1 行的 2 倍，|B| = 0。

几何上，两个向量共线，三个向量全挤在同一张平面里。

平行六面体被压成一张纸片，体积为零。

**这就是"行列式等于零"的几何图像：降维。**

平面图形被压成一条线段，立体图形被压成一个平面，体积都归零。

**为什么 |AB| = |A||B|**

把矩阵看成"对空间的挤压动作"。

B 把单位立方体挤成体积 |B| 倍的东西，A 再把这个东西挤成 |A| 倍。

两步合起来，体积放大 |A|×|B| 倍。

而两步合起来正是 AB，所以 |AB| = |A||B|。

**负号是什么意思**

体积没有负数，但行列式可能是负的。

负号表示"定向反了"：原来右手系的三个向量，变换后变成左手系。

就像二阶里交换两个向量，面积一样大，方向反过来。

数一不考几何论证，但这一层图像能帮你记住三条性质：

```text
|A| = 0     → 空间被压扁
|AB| = |A||B| → 缩放因子相乘
交换两行变号 → 定向翻转
```

## 11. 常见错误

**错误一：把 |A + B| 当成 |A| + |B|**

前面给过反例，两个含大量零的矩阵加起来是单位阵，行列式从 0 变成 1。

**错误二：|kA| = k|A|**

正确写法是 kⁿ|A|。

只有当 n = 1（矩阵退化成一个数）时两者才一样。

**错误三：交换两行忘记变号**

化三角时为了把主元换成非零的数，经常要交换行。

交换一次记一个负号，交换两次负号抵消。

**错误四：某行乘了 k 忘记除回去**

为了消掉分数把某行乘 2，最后结果必须除以 2。

更稳的做法是宁可不乘，带着分数往下算。

**错误五：代数余子式的符号漏掉**

Mᵢⱼ 是余子式，Aᵢⱼ 是代数余子式，差一个 (−1)^(i+j)。

按第一行展开符号是 + − +，按第二行展开符号是 − + −。

**错误六：拆分行列式时动了别的行**

第六条性质只允许拆一行，其余行必须一模一样。

**错误七：以为对角线法则能用到四阶**

四阶有 24 项，画斜线只能画出 8 项。

**错误八：把 |−A| 当成 |A|**

竖线不是绝对值符号。

|−A| = (−1)ⁿ|A|，n 是阶数。

三阶时 |−A| = −|A|，二阶时 |−A| = |A|。

**错误九：以为 |A| = 0 就一定有零行**

零行只是"值为零"的一种原因。

两行成比例、三阶中三行共面、四阶中某行是另外三行的线性组合，都会让值等于零，但矩阵里一个零行都没有。

例子：

```text
| 1  2  3 |
| 4  5  6 | = 0
| 5  7  9 |
```

第三行等于第一行加第二行，没有零行，值却是 0。

**错误十：展开时只算余子式，忘了乘 aᵢⱼ**

```text
|A| = Σ aᵢⱼAᵢⱼ
```

前面的 aᵢⱼ 是"那个位置的数"，后面的 Aᵢⱼ 是"代数余子式"。

两项都要，少一个就错。

比如第一行是 (2, 0, 0) 时，展开结果只有 2×A₁₁，那个 2 不能丢。

**错误十一：把行列式当成矩阵的函数，却按元素算**

行列式不是"对每个元素做点什么"，它是对整个方阵做一件事。

所以 |A| 里没有"逐元素绝对值"这种操作，|−A| 也不是把每个数变号那么简单。

## 12. 数一怎么考

**题型一：给具体数字，算四阶或五阶行列式**

做法：找 0 多的行或列展开降阶，或者化三角。

五阶以上基本只能化三角，因为展开的项数增长太快。

**题型二：抽象行列式**

这类题不给你具体数字，只给一个 |A|，让你算别的。

例题：A 是 3 阶矩阵，|A| = 2，求 |2A|、|A*|、|A⁻¹|、|A⁻¹ − 2A*|。

```text
|2A|  = 2³|A| = 8×2 = 16
|A*|  = |A|^(n−1) = 2² = 4
|A⁻¹| = 1/|A| = 1/2
```

第四个要先化简。

由 A* = |A|·A⁻¹ = 2A⁻¹，得：

```text
A⁻¹ − 2A* = A⁻¹ − 4A⁻¹ = −3A⁻¹
|−3A⁻¹| = (−3)³ × (1/2) = −27/2
```

这类题的套路固定：先把每个因子化成 A 或 A⁻¹ 的倍数，再提公因子，最后用 kⁿ 那条。

**题型三：特征多项式**

|λE − A| 是一个关于 λ 的多项式，求它的根就是求特征值。

三阶时展开成 λ³ − (tr A)λ² + … − |A|。

两条常用结论：

```text
λ₁ + λ₂ + … + λₙ = a₁₁ + a₂₂ + … + aₙₙ  （对角线之和，叫迹）
λ₁λ₂…λₙ = |A|
```

**题型四：证明 |A| = 0**

三条路：

```text
A 有两行（列）成比例
r(A) < n
A 有特征值 0
```

**题型五：克拉默法则**

方程组 Ax = b，当 |A| ≠ 0 时：

```text
xⱼ = |Aⱼ| / |A|
```

Aⱼ 是把 A 的第 j 列换成 b 得到的矩阵。

数一考它一般是二阶或三阶，四阶以上计算量不划算。

**题型六：递推与归纳**

给一个 n 阶、形状有规律的行列式，让你求通项。

标准动作：按第一行（列）展开，得到 Dₙ 与 Dₙ₋₁、Dₙ₋₂ 的关系，再算两个初值。

三对角那类题就是这么做的。

**题型七：证明题**

常见形式：已知 AB = O，且 A 不是零矩阵，证明 |B| = 0。

一行推理：

```text
若 |B| ≠ 0，则 B 可逆，两边右乘 B⁻¹ 得 A = O，与 A 非零矛盾。
```

所以 |B| = 0。

这类题的关键是"反证 + 用可逆性两边乘"，不涉及具体计算。

**考场上的时间分配**

选择题里的行列式，一般三十秒内要有答案。

判断顺序建议是：

```text
第一步：有没有成比例的行（列）→ 有，就是 0
第二步：能不能提取公因子凑出相同的行 → 能，化简后再看
第三步：是不是三角、对角、范德蒙德 → 套公式
第四步：前三步都不成，才动笔展开或化三角
```

填空题里的抽象行列式，先把每个因子化成 A 或 A⁻¹ 的倍数，再统一提 kⁿ。

最后提醒一句：算出结果后，代回一个具体数字检验几乎不可能，所以只能靠过程不跳步。

每一步写的行变换，都是你事后唯一的验算依据。

## 13. 和其他章节怎么连

行列式在整本书里的位置是"一个判据"，不是"一个工具"。

**连矩阵的秩**

|A| = 0 说明 A 的 n 行里有冗余，秩小于 n。

|A| ≠ 0 说明 n 行各自独立，秩等于 n，叫满秩。

**连逆矩阵**

A 可逆的充要条件是 |A| ≠ 0。

求逆的伴随矩阵公式 A⁻¹ = A*/|A|，分母就是行列式。

**连线性方程组**

|A| ≠ 0 时唯一解，公式由克拉默法则给出。

|A| = 0 时无解或无穷多解，此时要去看秩。

**连特征值**

|λE − A| = 0 是特征方程，解出来是特征值。

特征值之积等于 |A|，这个结论在抽象题里很常用。

**连二次型**

判断正定要看顺序主子式，那也是一串行列式。

一句话：

```text
行列式是"这个方阵退化没退化"的一票否决器。
```

再补两句"它管不到哪里"。

行列式只管方阵，长方形矩阵没有行列式，长方形矩阵的同类问题是秩。

行列式等于零，只能说明"不独立"，不能说明"无解"。

要分清"无解"和"无穷多解"，还得靠第 04 篇的秩。

**连向量组**

n 个 n 维向量组成的方阵，行列式不为零，这 n 个向量就线性无关。

行列式为零，它们就线性相关，其中至少有一个能被其余的表示出来。

"行列式"和"线性相关"说的其实是同一件事的两种语言：

```text
行列式语言：这个方阵的值是不是零
向量语言：这组向量里有没有多余的
```

第 05 篇会把第二种语言讲透，到时候你会发现判断方法还是同一个。

### 自检三问

**第一问：为什么交换两行，行列式要变号？**

答：二阶时 |a b; c d| = ad − bc，交换后 |c d; a b| = cb − da = −(ad − bc)。

几何上两个向量换了位置，平行四边形的定向反了，有向面积取负。

三阶及以上由定义里排列的逆序数保证：交换一次，每一项的符号统一翻转。

**第二问：化三角法里，哪一步会改变行列式的值？**

答：交换两行会变号，某行乘 k 会让值乘 k，这两种要记账。

"某行加另一行的 k 倍"不改值，可以放心用。

所以化三角的标准动作是：能用倍加就用倍加，非交换不可时记一个负号。

**第三问：一个四阶行列式，某一行是 (1, 0, 0, 0)，按这一行展开等于什么？**

答：等于那个 1 所在位置的代数余子式，符号为正，剩下是一个三阶行列式。

这就是"挑 0 多的行展开"的极端情形：一行只有一个 1，展开后阶数直接掉一阶。

## 14. 一张计算流程清单

没有固定顺序，考场上就会在"要不要展开""要不要换行"之间反复犹豫。

拿到任何一个行列式，按这个顺序想，基本不会卡住。

**第 0 步：确认它是方阵**

行列式只对方阵有定义。

看到长方形矩阵还在算行列式，说明第 0 步就错了。

**第 1 步：看结构，不急着算**

先扫三样东西：

```text
有没有两行（列）成比例、相同 → 直接写 0
有没有一行（列）全是 0        → 直接写 0
是不是三角、对角、范德蒙德     → 套结论
```

这三条能在十秒内解决的，不要动笔。

**第 2 步：能造 0 就造 0**

用"某行加另一行的 k 倍"把某一行清成只剩一个非零数。

这是唯一不影响值的操作，可以放心连用。

**第 3 步：选方向展开**

挑 0 最多的那一行或那一列，按它展开，阶数减一。

展开时默念三件事：位置、符号、余子式。

**第 4 步：重复，直到二阶**

三阶以上，每展开一次降一阶，降到二阶用 ad − bc 收尾。

**第 5 步：记账**

如果中途交换过行，最后乘 (−1) 的交换次数次方。

如果中途把某行乘过 k，最后除以 k。

**第 6 步：换条路抽查**

时间允许时，用另一种方法算同一个行列式。

两个方法给出同一个数，才算真的算对。

**四个"看到就想到"**

```text
看到每行和相同      → 各行加到第一行，提公因子
看到爪型            → 用第一行（列）消爪子
看到三对角          → 按第一行展开写递推
看到方幂排成行      → 范德蒙德，后面减前面连乘
```

行列式这一篇，压成三句：

```text
它是把一个 n 阶方阵压成一个数的运算。
这个数不为零，方阵的行就独立，方程就有唯一解，矩阵就可逆。
算它有两条路：按行（列）展开降阶，或者化三角取对角线乘积。
```

必须能默写的：

```text
|a b; c d| = ad − bc
|Aᵀ| = |A|，|kA| = kⁿ|A|，|AB| = |A||B|
|A*| = |A|^(n−1)，|A⁻¹| = 1/|A|
范德蒙德 = 后面的减前面的，全部连乘
```
