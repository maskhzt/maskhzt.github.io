> **读这篇之前，你只需要知道**：矩阵乘法是"行乘列"，两个矩阵相乘得到一个新矩阵；行列式是把方阵压成的一个数，不为零表示这个方阵没有冗余；单位阵 E 相当于数字里的 1，任何矩阵乘它都不变。
> **这篇讲什么**：数字里解 2x = 8 靠除以 2，矩阵里没有除法，只有"乘一个能抵消它的矩阵"，这个矩阵叫逆矩阵；这一篇讲逆矩阵怎么判定、怎么手算、为什么对 (A|E) 做行变换就能把它揪出来。
> **一个类比**：一段路走 3 公里向东，想回到原点就得走 3 公里向西；逆矩阵就是那个"原路返回"的动作。有的路走不回来——比如所有点都被压到同一条直线上——那就没有逆。


数字里解方程：

```text
2x = 8
```

两边除以 2，得 x = 4。

换成矩阵：

```text
Ax = b
```

能不能也"两边除以 A"？

不能。

矩阵没有除法这个运算。

能做的只有一件事：找一个矩阵，乘上去之后把 A 抵消掉。

```text
如果存在 B，使 AB = BA = E
那么两边左乘 B：BAx = Bb，即 x = Bb
```

这个 B 就叫 A 的逆矩阵。

**反直觉的点在这里：**

```text
矩阵的"除法"不是除，是"乘一个反向的动作"。
```

而且这个反向动作不是每个矩阵都有。

有的变换会把整个平面压成一条直线，压完就丢了信息，再也回不去。

这一篇讲三件事：

```text
什么时候能"回去"（判定）
回去的那个动作长什么样（伴随矩阵）
怎么最快把它算出来（初等变换）
```

## 1. 为什么需要它（不给会怎样）

假设没有逆矩阵。

第一个后果：解方程组只能一个一个消元。

一百个未知数、一百个方程，即使等号右边换了一批数，也得从头再消一遍。

有了 A⁻¹，换 b 只是做一次矩阵乘法。

第二个后果：很多"反过来算"的问题没法写。

给一个加密变换，想知道原文怎么恢复；给一个坐标变换，想从结果倒推输入。

这些都要靠逆。

第三个后果：后面很多东西的定义要用到它。

```text
相似：A = P⁻¹BP
二次型化标准形：x = Cy
特征值：Aα = λα → α = λA⁻¹α
```

没有逆，这些概念连定义都写不出来。

所以逆矩阵要解决的是：

```text
给一个变换，找回它的"反动作"。
```

**三类问题都靠它**

```text
反推型：知道结果，求输入
换基型：把问题换到一个更好算的坐标系里（相似、合同）
化简型：把矩阵乘成对角、乘成单位阵
```

第一类最简单的例子就是解方程组 x = A⁻¹b。

第二类的代表是相似对角化 A = P⁻¹BP。

第三类的代表是初等变换本身：每一步都在左乘一个初等矩阵，本质上就是在乘逆。

**现实里的"不可逆"长什么样**

手机把一张照片压成 JPEG，这个过程丢掉了人眼不敏感的高频细节，压完就回不到原始像素。

求逆矩阵时遇到的"不可逆"，是同一类事情：变换丢掉了某些方向上的信息。

平面被压成直线，直线上每一点都对应原来平面上无数个点，你说该返回哪一个？

所以可逆的本质不是"算得出来"，而是"信息没丢"。

## 2. 最小模型：逆的定义

没有定义，就只能凭感觉猜一个"反向矩阵"，对错全看运气。

**定义**

A 是 n 阶方阵，如果存在 n 阶方阵 B，使得：

```text
AB = BA = E
```

就称 A 可逆，B 是 A 的逆矩阵，记作 A⁻¹。

`A⁻¹` 读作"A 的逆"。

`E` 读作"单位矩阵"，主对角线全是 1、其余全是 0 的方阵，相当于数字里的 1，|E| = 1。

**三条必须注意的**

第一条，只有方阵才谈可逆。

长方形矩阵连"同阶"都谈不上，AB = E 和 BA = E 不可能同时成立。

第二条，定义要求两边都等于 E。

只满足 AB = E 还不够严格，必须 BA = E 也成立。

对方阵来说，其实只要一边成立就能推出另一边，但定义按两边的写法来。

第三条，如果逆存在，它唯一。

证明只有两行：

```text
设 B、C 都是 A 的逆
则 B = BE = B(AC) = (BA)C = EC = C
```

所以不可能有两个不同的逆。

**算一个二阶的**

```text
A = | 2  1 |
    | 1  1 |
```

|A| = 2×1 − 1×1 = 1，不为零，可逆。

猜一个 B：

```text
B = |  1  −1 |
    | −1   2 |
```

验证 AB：

```text
第 1 行 (2, 1) 乘两列 → (2×1 + 1×(−1), 2×(−1) + 1×2) = (1, 0)
第 2 行 (1, 1) 乘两列 → (1×1 + 1×(−1), 1×(−1) + 1×2) = (0, 1)
```

```text
AB = | 1  0 | = E
     | 0  1 |
```

所以 A⁻¹ = B。

**另一边也验一次**

定义要求 AB = BA = E，刚才只验了 AB。

算 BA：

```text
第 1 行 (1, −1) 乘 A 的两列 → (2 − 1, 1 − 1) = (1, 0)
第 2 行 (−1, 2) 乘 A 的两列 → (−2 + 2, −1 + 2) = (0, 1)
```

```text
BA = | 1  0 | = E
     | 0  1 |
```

两边都成立。

平时做题只验一边就够，因为方阵一边成立就能推出另一边；但定义上两边都要，理解这一点才不会把长方形矩阵也当成可逆。

**为什么定义要求两边都等于 E**

因为长方形矩阵可能只满足一边。

比如 A 是 1×2 矩阵 (1, 0)，B 是 2×1 矩阵 (1, 0)ᵀ。

```text
AB = |1 0|·|1| = [1]        （1×1 的单位阵）
           |0|

BA = |1|·|1 0| = |1 0|      （2×2，不是单位阵）
     |0|          |0 0|
```

单边成立、另一边不成立。

所以定义必须写两条，才能保证"来回都不变"。

对方阵来说，可以证明只要一边成立，另一边自动成立——因为 |A||B| = 1 会逼出两边都可逆。

但考试时不必纠结：题目给 A·B = E 且都是方阵，就可以直接写 B = A⁻¹。

**这个 B 是怎么猜出来的**

不是猜的。

二阶有现成公式，下一节给。

## 3. 判定：|A| ≠ 0 才可逆

没有判定，你只能"试出一个逆"，试不出来也不能断定它不存在。

**结论**

```text
A 可逆 ⟺ |A| ≠ 0
```

三个等价说法，考试里随便用哪个：

```text
A 可逆
|A| ≠ 0
r(A) = n（满秩）
```

这里 |A| 读作"A 的行列式"，r(A) 读作"矩阵 A 的秩"。

**为什么**

如果 |A| = 0，说明 A 的行（或列）之间有冗余。

几何上，变换把 n 维空间压到了更低维的地方。

信息丢掉了，回不去，所以没有逆。

反过来，|A| ≠ 0 说明各行独立，变换没有压缩维度，可以原路返回。

严格的证明用伴随矩阵，下一节就有。

**一个不可逆的例子**

```text
A = | 1  2 |
    | 2  4 |
```

|A| = 1×4 − 2×2 = 0。

第 2 行是第 1 行的 2 倍，两个行向量共线。

这个变换把整个平面压到一条直线上，直线上的不同点都可能来自平面上不同的点，无法区分。

所以 A 没有逆。

**不可逆的矩阵有个名字**

叫奇异矩阵。

对应的，|A| ≠ 0 的叫非奇异矩阵。

这两个词在题目里出现，就是在说"可逆不可逆"。

**再看一个三阶的**

```text
A = | 1  2  3 |
    | 2  4  6 |
    | 1  1  1 |
```

第 2 行是第 1 行的 2 倍，成比例。

由行列式性质，|A| = 0。

这支"队伍"里有一行是报重复的，三条信息实际只有两条。

变换把三维空间压到一个平面里，压在平面上的点回不到原来的空间位置，所以不可逆。

反过来，如果三行各自独立，|A| ≠ 0，变换是"一对一"的，就能回去。

**这条判定的用法**

拿到一个含参数的矩阵，问"a 取何值时不可逆"，就是在解 |A| = 0。

拿到一个抽象矩阵，问"能否可逆"，就找 |A| 的表达式。

**从"伸缩率"理解 |A| ≠ 0**

|A| 的绝对值，是这个变换对面积（二阶）或体积（三阶）的放大倍数。

```text
|A| = 2  → 面积放大两倍，能回去
|A| = 1  → 面积不变，能回去
|A| = 0  → 面积压成零，回不去
```

压成零之后再想恢复原来的形状，没有任何线索，所以不可逆。

这也是为什么"可逆"和"行列式不为零"是同一件事的几何解释。

## 4. 伴随矩阵：A* 是什么

没有伴随矩阵，求逆就没有公式，只能靠初等变换一条路。

而初等变换算三阶以上还行，遇到含参数的抽象题就完全使不上劲。

**定义**

A = (aᵢⱼ) 是 n 阶方阵，Aᵢⱼ 是代数余子式。

把所有 Aᵢⱼ 按原位置排成一个矩阵，再转置，得到的就是伴随矩阵 A*。

```text
A* 读作"A 的伴随矩阵"
A* = (Aᵢⱼ)ᵀ
```

**两个容易错的地方**

第一，A* 的元素是代数余子式，不是余子式，符号不能丢。

第二，排完之后要转置。

不转置的那个东西叫"余子式矩阵"，它没用。

**核心公式**

```text
A·A* = A*·A = |A|·E
```

注意右边是 |A| 乘 E，不是 E。

这是伴随矩阵最重要的一条，几乎所有伴随的题都从它出发。

**二阶验一遍**

```text
A = | a  b |      A* = |  d  −b |
    | c  d |           | −c   a |
```

先看 A* 怎么来的：

```text
A₁₁ = +d，A₁₂ = −c，A₂₁ = −b，A₂₂ = +a
余子式矩阵 = |  d  −c |
             | −b   a |
转置得 A* = |  d  −b |
            | −c   a |
```

再算 A·A*：

```text
第 1 行 (a, b) 乘第 1 列 (d, −c) → ad − bc = |A|
第 1 行 (a, b) 乘第 2 列 (−b, a) → −ab + ab = 0
第 2 行 (c, d) 乘第 1 列 (d, −c) → cd − cd = 0
第 2 行 (c, d) 乘第 2 列 (−b, a) → −bc + ad = |A|
```

```text
A·A* = | ad−bc    0    | = |A|·| 1  0 | = |A|E
       |   0    ad−bc  |      | 0  1 |
```

成立。

**于是求逆公式就出来了**

因为 A·A* = |A|E，两边除以 |A|（只要它不为零）：

```text
A⁻¹ = A* / |A|
```

二阶时展开就是那个著名公式：

```text
| a  b |⁻¹        1      |  d  −b |
| c  d |    =  ─────── · | −c   a |
                  ad − bc
```

口诀：主对角线交换，副对角线变号，再除以行列式。

**这个口诀为什么对**

看二阶公式里的四个位置：

```text
A⁻¹ 的 (1,1) 位置放 d = A₁₁
A⁻¹ 的 (1,2) 位置放 −b = A₂₁
A⁻¹ 的 (2,1) 位置放 −c = A₁₂
A⁻¹ 的 (2,2) 位置放 a = A₂₂
```

注意 (1,2) 位置放的是 A₂₁，(2,1) 位置放的是 A₁₂。

这就是"转置"在起作用：代数余子式按原位置排好之后，整体翻个面。

所以口诀里的"主对角线交换"不是巧合，是转置的结果。

三阶也一样，只是九个余子式算起来累。

**为什么 |A| = 0 时一定不可逆**

如果 |A| = 0，那么 A·A* = O。

假设 A 可逆，两边左乘 A⁻¹ 得 A* = O。

而 A* = O 时，A·A* = O = |A|E 依然成立，说明不了矛盾，但可以换个角度：

由 A·A* = O 且 A 可逆，得 A* = O；再代回 A⁻¹ = A*/|A| 就变成了除以零，公式本身失效。

更直接的证明要用秩，第 04 篇补。

## 5. 算一遍：伴随矩阵法求三阶的逆

不听一遍完整过程，伴随矩阵公式里的"转置"永远会漏。

给一个三阶矩阵，全程手算。

```text
A = | 1  2  3 |
    | 2  2  1 |
    | 3  4  3 |
```

**第一步：算 |A|**

按第一行展开：

```text
A₁₁ = +|2 1; 4 3| = 6 − 4 = 2
A₁₂ = −|2 1; 3 3| = −(6 − 3) = −3
A₁₃ = +|2 2; 3 4| = 8 − 6 = 2

|A| = 1×2 + 2×(−3) + 3×2 = 2 − 6 + 6 = 2
```

|A| = 2，不为零，可逆。

**第二步：把九个代数余子式都算出来**

```text
A₁₁ = +|2 1; 4 3| = 2      A₁₂ = −|2 1; 3 3| = −3     A₁₃ = +|2 2; 3 4| = 2
A₂₁ = −|2 3; 4 3| = 6      A₂₂ = +|1 3; 3 3| = −6     A₂₃ = −|1 2; 3 4| = 2
A₃₁ = +|2 3; 2 1| = −4     A₃₂ = −|1 3; 2 1| = 5      A₃₃ = +|1 2; 2 2| = −2
```

逐个核一遍中间那行，因为最容易错。

```text
A₂₁：划掉第 2 行第 1 列，剩下 |2 3; 4 3| = 6 − 12 = −6，位置 (2,1) 为奇，符号负
     所以 A₂₁ = −(−6) = 6
A₂₂：划掉第 2 行第 2 列，剩下 |1 3; 3 3| = 3 − 9 = −6，位置为偶，符号正
     所以 A₂₂ = −6
A₂₃：划掉第 2 行第 3 列，剩下 |1 2; 3 4| = 4 − 6 = −2，位置 (2,3) 为奇，符号负
     所以 A₂₃ = −(−2) = 2
```

**第三步：排成矩阵再转置**

```text
余子式按位置排：

|  2   −3    2 |
|  6   −6    2 |
| −4    5   −2 |
```

转置：

```text
A* = |  2    6   −4 |
     | −3   −6    5 |
     |  2    2   −2 |
```

**第四步：除以 |A|**

```text
A⁻¹ = (1/2)·A*

     |  1     3    −2  |
   = | −3/2  −3    5/2 |
     |  1     1    −1  |
```

**第五步：验算一行**

用 A 的第 1 行乘 A* 的第 1 列：

```text
(1, 2, 3)·(2, −3, 2) = 2 − 6 + 6 = 2 = |A|  ✓
```

乘第 2 列：

```text
(1, 2, 3)·(6, −6, 2) = 6 − 12 + 6 = 0  ✓
```

乘第 3 列：

```text
(1, 2, 3)·(−4, 5, −2) = −4 + 10 − 6 = 0  ✓
```

第一行验完，等于 (2, 0, 0)，正是 |A|E 的第一行。

**再用 |A*| 验一次**

行列式性质说 |A*| = |A|ⁿ⁻¹，n = 3、|A| = 2，所以 |A*| 应该等于 4。

直接算 A* 的行列式：

```text
|A*| = |  2    6   −4 |
       | −3   −6    5 |
       |  2    2   −2 |
```

按第一行展开：

```text
2×((−6)(−2) − 5×2) − 6×((−3)(−2) − 5×2) + (−4)×((−3)×2 − (−6)×2)
= 2×(12 − 10) − 6×(6 − 10) + (−4)×(−6 + 12)
= 4 + 24 − 24
= 4
```

等于 |A|² = 4，一致。

两条独立的检验都对上，答案基本可以确定。

**这个方法什么时候用**

```text
二阶：直接用公式，最快
三阶：伴随法可行，但要算九个余子式，慢
四阶以上：伴随法不现实，必须用初等变换
抽象题（含参数、只给关系式）：只能用伴随矩阵
```

**两种方法怎么选**

```text
题目给了具体数字，阶数 ≤ 2  → 二阶公式
题目给了具体数字，阶数 ≥ 3  → 初等变换
题目给的是关系式、含参数    → 伴随矩阵或凑 E 的恒等变形
```

判据是"能不能直接看到所有元素"。

看得到元素，就用算法；看不到元素，就用恒等式。

## 6. 初等变换与初等矩阵

没有初等变换，求逆就只能靠伴随矩阵硬算，四阶就要算十六个三阶行列式。

**三种初等变换**

对矩阵的行做三件事：

```text
1. 交换两行
2. 某一行乘一个非零常数 k
3. 某一行加上另一行的 k 倍
```

对列做同样三件事，叫初等列变换。

统称初等变换。

**这三种动作在方程组里意味着什么**

把矩阵看成方程组的系数，三种行变换正好对应三种合法的方程操作：

```text
交换两行        → 交换两个方程的位置（解不变）
某行乘非零 k    → 方程两边同乘 k（解不变）
某行加另一行的 k 倍 → 两个方程相加减（解不变）
```

初中解方程组用的就是这三招。

所以初等变换是"不改变解集"的操作，这也是它能用来化简、求逆、求秩的根本原因。

**为什么"乘非零常数"强调非零**

如果乘 0，整行变成零，信息彻底丢了，这个过程不可逆。

初等变换必须是"能倒回去"的操作，所以乘的数不能是 0。

**初等矩阵**

对单位阵 E 做一次初等变换，得到的矩阵叫初等矩阵。

三种，记法如下：

```text
E(i, j)      交换第 i 行和第 j 行
E(i(k))      第 i 行乘 k
E(i, j(k))   第 j 行的 k 倍加到第 i 行
```

**最关键的一条性质：左行右列**

```text
左乘一个初等矩阵 = 对原矩阵做一次同种的行变换
右乘一个初等矩阵 = 对原矩阵做一次同种的列变换
```

例子，A = |1 2; 3 4|，交换两行：

```text
E(1,2) = | 0  1 |      E(1,2)·A = | 3  4 |
         | 1  0 |                 | 1  2 |
```

再试"第 1 行乘 3 加到第 2 行"：

```text
E(2,1(3)) = | 1  0 |   E(2,1(3))·A = | 1  2 |
            | 3  1 |                | 6  10 |
```

第 2 行变成 (3+3, 6+4) = (6, 10)。

再用右乘看列变换，还是那个 A：

```text
A·E(1,2) = | 1  2 | | 0  1 | = | 2  1 |
           | 3  4 | | 1  0 |   | 4  3 |
```

两列被交换了，行没动。

左右各乘一次，就能看出"左行右列"不是记法，是事实。

**初等矩阵都可逆，逆还是初等矩阵**

```text
E(i, j)⁻¹ = E(i, j)              交换两次回到原样
E(i(k))⁻¹ = E(i(1/k))            乘 k 再乘 1/k
E(i, j(k))⁻¹ = E(i, j(−k))       加 k 倍再减 k 倍
```

三条都好理解：每个动作都有对应的"反动作"，而且反动作还是同一类动作。

**初等矩阵的行列式**

```text
|E(i, j)| = −1
|E(i(k))| = k
|E(i, j(k))| = 1
```

这三条和行列式的性质一一对应。

**初等变换能做到什么程度**

对一个矩阵做行变换，可以把它化成阶梯形：

```text
每行的第一个非零数（主元）往右下走，主元下方全是零
```

继续做，可以化成简化阶梯形：主元全是 1，且主元所在列其余位置全是零。

如果这个矩阵恰好可逆，简化阶梯形就是 E，于是 (A|E) 变成 (E|A⁻¹)。

如果不可逆，左边会出现零行，那时左边最多化成

```text
| E   * |
| O   O |
```

的形状，右边的零行说明"信息不够"，这就是第 04 篇要用秩来描述的东西。

同一个动作，可逆时得到逆，不可逆时得到秩的线索。

## 7. 算一遍：初等变换法求逆

不会这个方法，三阶以上求逆就只能硬算九个余子式，四阶更是算不动。

这是考场上真正会用的方法。

**原理先说一句**

如果对 A 做若干次行变换能把它变成 E，那么这些行变换对应的初等矩阵乘起来，就是 A⁻¹。

所以对 A 做的每一步，同时对 E 也做一遍，E 最后就变成了 A⁻¹。

**写法**

把 A 和 E 并排写成一个大矩阵：

```text
( A | E )
```

只做行变换，目标是让左边变成 E，右边自然就是 A⁻¹。

**开始，还是那个三阶矩阵**

```text
 1   2   3 | 1  0  0
 2   2   1 | 0  1  0
 3   4   3 | 0  0  1
```

第 1 步，消掉第 2 行、第 3 行的首元。

```text
r₂ − 2r₁:  (0, −2, −5 | −2,  1, 0)
r₃ − 3r₁:  (0, −2, −6 | −3,  0, 1)
```

现在是：

```text
 1    2    3 |  1   0   0
 0   −2   −5 | −2   1   0
 0   −2   −6 | −3   0   1
```

第 2 步，用第 2 行消掉第 3 行的第二个数。

```text
r₃ − r₂:  (0, 0, −1 | −1, −1, 1)
```

```text
 1    2    3 |  1    0   0
 0   −2   −5 | −2    1   0
 0    0   −1 | −1   −1   1
```

第 3 步，把第 3 行乘 −1，让主元变成 1。

```text
r₃ × (−1):  (0, 0, 1 | 1, 1, −1)
```

第 4 步，向上消元：用第 3 行消掉上面两行的第三个数。

```text
r₁ − 3r₃:  (1, 2, 0 | 1−3, 0−3, 0+3) = (1, 2, 0 | −2, −3, 3)
r₂ + 5r₃:  (0, −2, 0 | −2+5, 1+5, 0−5) = (0, −2, 0 | 3, 6, −5)
```

第 5 步，把第 2 行乘 −1/2，让主元变成 1。

```text
r₂ × (−1/2):  (0, 1, 0 | −3/2, −3, 5/2)
```

第 6 步，用第 2 行消掉第 1 行的第二个数。

```text
r₁ − 2r₂:  (1, 0, 0 | −2+3, −3+6, 3−5) = (1, 0, 0 | 1, 3, −2)
```

左边已经是 E：

```text
 1   0   0 |   1     3   −2
 0   1   0 | −3/2   −3   5/2
 0   0   1 |   1     1   −1
```

所以：

```text
A⁻¹ = |   1     3   −2 |
      | −3/2   −3   5/2 |
      |   1     1   −1  |
```

和伴随法的结果一字不差。

**过程中的三个技巧**

第一个，优先把主元变成 1。

如果某行首元是 2，先乘 1/2，后面的消元就全变成整数运算。

第二个，主元是 0 就交换行。

比如第 1 行首元是 0，找一个首元非零的行换上来，记一个负号（这里只是行变换，不影响"是否可逆"的判断）。

第三个，出现整列全零就是不可逆的信号。

如果消到某一步，某一列在未处理的部分全是 0，说明这一列能被前面的列表示，矩阵不满秩，不可能化成 E。

**同步是最容易忘的地方**

每一步都要对左右两块做同样的动作。

做到一半发现右边某一列忘了加，整道题就废了，而且很难查出来。

一个习惯：每做完一步，立刻念一遍这一步做了什么，然后确认左右两块都动了。

最后一定检查左边是不是真的变成了 E。

如果左边还剩非零的非对角元素，说明还有一步没做完，右边自然也不是 A⁻¹。

**顺手多做一件事**

如果把右边的 E 换成一个矩阵 B，写成 (A|B)，做同样的行变换：

```text
(A | B) → (E | A⁻¹B)
```

一次就能解出 AX = B。

这个技巧在数一里出现频率很高，比先求 A⁻¹ 再乘 B 快得多。

**为什么它比"先求逆再乘"快**

先求逆再乘，要做两次完整的矩阵运算；写成 (A|B) 只做一次消元。

更实际的好处是：如果 B 有很多列（比如要解好几个方程组），(A|B) 一次全部搞定。

数一的大题经常是"求一个矩阵 X 满足 AX = B"，用这个写法最省时间。

**考场上的时间账**

三阶求逆，伴随法要算 9 个二阶行列式，大约 5 到 8 分钟。

初等变换大约 3 分钟，而且不容易错。

四阶伴随法要算 16 个三阶行列式，基本不可行。

所以只有二阶和抽象题才用伴随法。

## 8. 为什么 (A|E) 会变成 (E|A⁻¹)

这一节回答原理，考试不直接考，但懂了就不会记混"为什么只能做行变换"。

**第一步：把行变换写成矩阵乘法**

每一次行变换，等于左乘一个初等矩阵。

设这一串初等矩阵依次是 P₁, P₂, …, Pₖ。

那么"把 A 变成 E"这件事，就是：

```text
Pₖ … P₂ P₁ A = E
```

**第二步：两边同时右乘 A⁻¹**

由 Pₖ…P₁A = E，两边右乘 A⁻¹：

```text
Pₖ … P₁ = A⁻¹
```

这一步说明：那一串初等矩阵的乘积，正好就是 A⁻¹。

**第三步：看 E 发生了什么**

同样的乘积作用在 E 上：

```text
Pₖ … P₁ E = A⁻¹ E = A⁻¹
```

**合起来**

```text
A 被这一串初等矩阵变成了 E
E 被同一串初等矩阵变成了 A⁻¹
```

所以并排写、同步做，右边自然出现答案。

**三个推论**

第一条，求逆只能用行变换。

因为推导里用的是"左乘"，左乘对应行变换。

用列变换会把 E 变成别的东西，等式不成立。

第二条，A 可逆是前提。

如果 A 不可逆，左边的消元过程中必然出现全零行，永远变不成 E。

这时候 (A|E) 化到最后左边会出现零行，看到这个就说明"不可逆"，不用再算。

第三条，初等变换不改变秩。

因为初等矩阵都可逆，乘可逆矩阵相当于换一组基来描述同一个空间，维度不变。

第 04 篇会反复用这一条。

**如果偏要用列变换会怎样**

有人会想：既然 A 可逆，那做列变换让 A 变 E，右边不就出答案了吗？

不行。

原因是"同步"这两个字。

对 (A|E) 做一次行变换，等于左边整体乘一个初等矩阵 P。

这一乘，A 和 E 都被同一个 P 作用，所以 A 变成 PA、E 变成 P。

而做一次列变换，只作用于某两列，A 的列动了、E 的列未必动。

两块不再被同一个矩阵同时作用，右边出来的是个残缺的中间产物，不是 A⁻¹。

所以规则不是"列变换没意义"，而是"并排写法下，只有行变换能同步"。

## 9. 逆的八条性质

不记这几条，遇到 (AB)⁻¹ 就会顺手写成 A⁻¹B⁻¹。

这些性质不是背，是用，每条都可能出现在填空里。

**第一条：(A⁻¹)⁻¹ = A**

逆的逆回到自己。

路走回来，再走回去，就回到出发点。

**第二条：(AB)⁻¹ = B⁻¹A⁻¹**

顺序要反过来。

验证：

```text
(AB)(B⁻¹A⁻¹) = A(BB⁻¹)A⁻¹ = AEA⁻¹ = AA⁻¹ = E
```

和转置一样，凡是"复合"，逆和转置都要反序。

一句话记忆：

```text
穿的时候是袜子再鞋，脱的时候是鞋再袜子。
```

**第三条：(Aᵀ)⁻¹ = (A⁻¹)ᵀ**

Aᵀ 读作"A 的转置"，把行和列对调。

转置和求逆可以交换顺序。

常用的写法是 A⁻ᵀ。

**第四条：|A⁻¹| = 1/|A|**

由 |AB| = |A||B| 取 B = A⁻¹：

```text
|A|·|A⁻¹| = |E| = 1
```

所以 |A⁻¹| = 1/|A|。

**第五条：(kA)⁻¹ = (1/k)·A⁻¹（k ≠ 0）**

验证：

```text
(kA)·((1/k)A⁻¹) = (k·(1/k))·(AA⁻¹) = E
```

**第六条：(A*)⁻¹ = A/|A|**

由 A·A* = |A|E，两边除以 |A|：

```text
A·(A*/|A|) = E
```

所以 (A*)⁻¹ = A/|A|。

顺带得到 |A*| = |A|ⁿ⁻¹：两边取行列式，|A|·|A*| = ||A|E| = |A|ⁿ。

**第七条：(A*)* = |A|ⁿ⁻²·A**

这一条用得少，知道有就行。

**第八条：A² = A 且 A 可逆，则 A = E**

因为 A(A − E) = O，两边左乘 A⁻¹，得 A − E = O。

这条结论在证明题里很常见：幂等 + 可逆，只能是单位阵。

**性质怎么串起来用**

单条性质谁都会背，能把它们串起来才算会。

例子：设 A³ = E，求 A⁻¹。

不需要算任何元素，直接由 A³ = A²·A = E 得：

```text
A⁻¹ = A²
```

再具体一点，取循环置换矩阵：

```text
P = | 0  1  0 |
    | 0  0  1 |
    | 1  0  0 |
```

它把 (x, y, z) 变成 (y, z, x)。

做三次回到原样，所以 P³ = E，于是 P⁻¹ = P²。

验证 P²：

```text
P² = | 0  0  1 |
     | 1  0  0 |
     | 0  1  0 |
```

P²·P 的第一行 (0,0,1) 乘 P 的三列，得到 (1, 0, 0)，正是 E 的第一行。

这就是"用幂关系直接写逆"的典型。

**另一类常见组合**

如果题目给出 A² + 3A − E = O，要你求 A⁻¹：

```text
A² + 3A = E
A(A + 3E) = E
A⁻¹ = A + 3E
```

套路永远一样：把式子凑成 A·(某矩阵) = E。

**把八条并排看**

```text
(A⁻¹)⁻¹ = A
(AB)⁻¹ = B⁻¹A⁻¹
(Aᵀ)⁻¹ = (A⁻¹)ᵀ
|A⁻¹| = 1/|A|
(kA)⁻¹ = (1/k)A⁻¹
(A*)⁻¹ = A/|A|
|A*| = |A|ⁿ⁻¹
A² = A 且可逆 → A = E
```

## 10. 矩阵方程：怎么把 X 解出来

没有这一节，就算会求逆也不知道该往哪边乘。

**型一：AX = B**

A 在左，X 在右。

两边左乘 A⁻¹：

```text
A⁻¹AX = A⁻¹B  →  X = A⁻¹B
```

**型二：XA = B**

A 在右，X 在左。

两边右乘 A⁻¹：

```text
XAA⁻¹ = BA⁻¹  →  X = BA⁻¹
```

**型三：AXB = C**

两边先左乘 A⁻¹，再右乘 B⁻¹：

```text
X = A⁻¹CB⁻¹
```

**注意顺序**

型一的答案是 A⁻¹B，不是 BA⁻¹。

型二的答案是 BA⁻¹，不是 A⁻¹B。

记法：**逆矩阵永远贴在原来 A 的那一侧。**

A 在左边，逆就从左边乘；A 在右边，逆就从右边乘。

**手算一个型一**

```text
A = | 1  2 |      B = | 3  1 |
    | 1  3 |          | 4  2 |
```

先求 A⁻¹。|A| = 3 − 2 = 1。

二阶公式：主对角交换，副对角变号，除以 1：

```text
A⁻¹ = |  3  −2 |
      | −1   1 |
```

于是：

```text
X = A⁻¹B = |  3  −2 | | 3  1 |
           | −1   1 | | 4  2 |

第 1 行 (3, −2)：(3×3 − 2×4, 3×1 − 2×2) = (1, −1)
第 2 行 (−1, 1)：(−3 + 4, −1 + 2) = (1, 1)
```

```text
X = |  1  −1 |
    |  1   1 |
```

验算 AX：

```text
第 1 行 (1, 2)：(1+2, −1+2) = (3, 1)  ✓
第 2 行 (1, 3)：(1+3, −1+3) = (4, 2)  ✓
```

正好等于 B。

**型四：X 出现在两项里**

比如 XA + XB = C。

先提公因式，注意 X 在左边：

```text
X(A + B) = C
X = C(A + B)⁻¹
```

这里要求 A + B 可逆。

如果写成 (A + B)⁻¹C 就错了，因为 X 在左边，逆必须贴在右边。

**型五：含 A⁻¹ 的方程**

比如 AX = B 里 B 也带 A⁻¹，先把 A⁻¹ 当成一个整体挪走。

原则只有一条：**逆要贴在原来那个矩阵的那一侧。**

**一个必须记住的坑**

```text
(A + B)⁻¹ ≠ A⁻¹ + B⁻¹
```

反例：A = E，B = E。

左边 = (2E)⁻¹ = (1/2)E，右边 = E + E = 2E，不相等。

加法的逆没有简单公式，只能先算 A + B，再求逆。

## 11. 分块矩阵求逆

没有这一节，遇到四阶分块题就得整体求逆，计算量翻几倍。

**分块对角**

```text
| A  O |⁻¹     | A⁻¹   O   |
| O  B |    =  |  O    B⁻¹ |
```

前提是 A、B 都可逆。

验证：两个矩阵相乘，对角线上是 AA⁻¹ 和 BB⁻¹，其余块全零。

**副对角**

```text
| O  A |⁻¹     | O   B⁻¹ |
| B  O |    =  | A⁻¹   O  |
```

注意位置反了：A⁻¹ 跑到了右下，B⁻¹ 跑到了左上。

验证一下右上块：

```text
(O, A)·(B⁻¹, O)ᵀ 方向 → O·B⁻¹ + A·O = O  ✓
```

**分块三角**

```text
| A  C |⁻¹     | A⁻¹   −A⁻¹CB⁻¹ |
| O  B |    =  |  O       B⁻¹    |
```

这个公式数一考得少，但推导思路值得看：

先把对角块的逆填上，再修正右上块，让乘积变成 E。

验算一下右上块为什么是 −A⁻¹CB⁻¹：

```text
[A C]·[A⁻¹  −A⁻¹CB⁻¹] 的第 1 行第 2 列
= A·(−A⁻¹CB⁻¹) + C·B⁻¹
= −CB⁻¹ + CB⁻¹
= O   ✓
```

两项正好抵消，所以那一块必须带负号。

**手算一个分块对角**

```text
M = | 1  2 | 0  0 |
    | 3  4 | 0  0 |
    | 0  0 | 2  1 |
    | 0  0 | 5  3 |
```

左上块 A = |1 2; 3 4|，|A| = −2，A⁻¹ = (−1/2)|4 −2; −3 1|。

右下块 B = |2 1; 5 3|，|B| = 1，B⁻¹ = |3 −1; −5 2|。

所以：

```text
M⁻¹ = | −2    1  | 0   0 |
      | 3/2  −1/2| 0   0 |
      | 0    0   | 3  −1 |
      | 0    0   | −5  2 |
```

一个四阶求逆，变成了两个二阶求逆。

**用之前先确认前提**

分块求逆的公式都有前提：每一块都要可逆。

如果某一块的行列式是零，整个矩阵就不可逆，公式不成立。

检查方法：把结果乘回去，看是不是 E。

分块对角乘回去，对角线上是 AA⁻¹ 和 BB⁻¹，其余块是零乘零，结果是 E，说明没错。

副对角的情形要额外注意位置：乘回去时会出现 AB⁻¹ 这种交叉项，位置错了就消不掉。

## 12. 常见错误

**错误一：把 A⁻¹ 写成 1/A**

矩阵没有"分子分母"。

1/A 这个记号在矩阵里没有定义。

**错误二：(A + B)⁻¹ = A⁻¹ + B⁻¹**

前面给过反例，两个 E 加起来就露馅。

**错误三：伴随矩阵忘记转置**

A* 是代数余子式矩阵的转置。

不转置的话，AA* 算出来不是 |A|E，而是一个乱七八糟的矩阵。

**错误四：求逆时混用列变换**

(A|E) 化 (E|A⁻¹) 只允许行变换。

对列动手，右边出来的东西没有意义。

**错误五：|A| = 0 还硬求逆**

先算行列式，等于零就直接写"不可逆"，不要往下算。

**错误六：(AB)⁻¹ 写成 A⁻¹B⁻¹**

顺序必须反：B⁻¹A⁻¹。

**错误七：分块副对角求逆时位置不换**

|O A; B O|⁻¹ 的左上块是 O，右下块也是 O，A⁻¹ 和 B⁻¹ 要互换位置。

不换的话，乘出来对不上。

**错误八：AX = B 解成 BA⁻¹**

A 在左边，逆就从左边乘，答案是 A⁻¹B。

写成 BA⁻¹ 相当于把 A 当成了右因子。

**错误九：把 A* 和 A⁻¹ 当成一回事**

A* 的元素是代数余子式，可以直接由 A 的元素算出来，不需要 A 可逆。

A⁻¹ 只在 A 可逆时才存在，而且等于 A*/|A|。

两者只差一个系数 |A|，但含义完全不同：

```text
A* 一定存在（哪怕 |A| = 0）
A⁻¹ 只在 |A| ≠ 0 时存在
```

所以看到"伴随矩阵"三个字，先别急着写 A⁻¹。

**错误十：分块三角求逆时漏了负号**

右上块是 −A⁻¹CB⁻¹，不是 A⁻¹CB⁻¹。

漏了负号，乘出来右上角会变成 2CB⁻¹，不是零。

**错误十一：(kA)⁻¹ = kA⁻¹**

正确是 (1/k)A⁻¹。

验证：kA 乘 (1/k)A⁻¹ 才等于 E；乘 kA⁻¹ 会得到 k²E。

这个错误在填空题里很致命，因为结果只差一个系数，不容易察觉。

## 13. 数一怎么考

**题型一：给具体矩阵求逆**

二阶用公式，三阶用初等变换。

四阶以上一律初等变换。

**题型二：抽象矩阵求逆**

不给你具体数字，只给一个关系式。

例题：设 A 满足 A² − 3A + 2E = O，证明 A 可逆，并求 A⁻¹。

思路：把式子凑成 A·(某个矩阵) = E 的形状。

```text
A² − 3A = −2E
A(A − 3E) = −2E
A·[−(1/2)(A − 3E)] = E
```

所以：

```text
A⁻¹ = −(1/2)(A − 3E) = (3E − A)/2
```

验算 A·(3E − A)/2：

```text
(3A − A²)/2 = (3A − (3A − 2E))/2 = 2E/2 = E  ✓
```

这类题的通用套路：

```text
第一步：把含 A 的项都挪到一边，常数项挪到另一边
第二步：提取公因式 A
第三步：两边除以那个常数
```

**同一套路的另一个形状**

例题：设 A² = A，证明 A + E 可逆，并求 (A + E)⁻¹。

这次要凑的是 (A + E)·(某个矩阵) = E。

设那个矩阵是 aA + bE，乘开：

```text
(A + E)(aA + bE) = aA² + bA + aA + bE
                 = aA + (a + b)A + bE
                 = (2a + b)A + bE
```

要让结果等于 E，A 的系数必须是 0，常数必须是 1：

```text
2a + b = 0
b = 1
```

解得 b = 1，a = −1/2。

所以：

```text
(A + E)⁻¹ = −(1/2)A + E = (2E − A)/2
```

验算：

```text
(A + E)(2E − A) = 2A − A² + 2E − A = 2A − A + 2E − A = 2E
```

两边除以 2 得 E，成立。

注意验算时 A² 要换成 A，这一步不能忘。

**这两个例子说明什么**

"待定系数 + 凑 E"是抽象矩阵求逆的通用手法。

先猜答案的形状（A 的一次式通常够），再乘开对比系数。

**题型：判断某个矩阵可逆**

题目给"设 A 满足某关系式，问 A + 2E 是否可逆"。

标准做法：把 A + 2E 当成一个整体 B，凑 B·C = E。

如果凑不出来，就反过来算 |A + 2E|，看它是否可能为零。

两条路都走不通时，用反证：假设不可逆，引出矛盾。

**题型：用初等矩阵表示变换**

给"先把第 1 行加到第 2 行，再交换第 1、3 行"，让你写成矩阵乘积。

按执行顺序从右往左写：

```text
先做的在右边，后做的在左边
```

因为 P₂(P₁A) = (P₂P₁)A。

**题型三：伴随矩阵的题**

常用三条：

```text
A·A* = |A|E
A* = |A|A⁻¹
|A*| = |A|ⁿ⁻¹
```

例题：A 是三阶可逆矩阵，|A| = 2，求 |(A*)⁻¹ − 2A|。

先把 (A*)⁻¹ 化简：

```text
(A*)⁻¹ = A/|A| = A/2
```

于是：

```text
(A*)⁻¹ − 2A = A/2 − 2A = −(3/2)A
```

取行列式：

```text
|−(3/2)A| = (−3/2)³·|A| = (−27/8)×2 = −27/4
```

**题型四：初等矩阵的题**

常见问法：

```text
用初等矩阵表示某个变换
判断某个初等矩阵的逆
问"左乘还是右乘"
```

记住两条就够：

```text
左乘 = 行变换
右乘 = 列变换
```

**题型五：(A|B) 一次解多个方程**

要求 AX = B，直接写 (A|B)，化到 (E|A⁻¹B)。

比先求逆再乘快一半，而且少一次抄写错误。

**手算一个小例子**

```text
A = | 1  1 |      B = | 2  1 |
    | 1  2 |          | 3  2 |
```

写成 (A|B)：

```text
 1   1 | 2  1
 1   2 | 3  2
```

第 1 步，第 2 行减第 1 行：

```text
 1   1 | 2  1
 0   1 | 1  1
```

第 2 步，第 1 行减第 2 行：

```text
 1   0 | 1  0
 0   1 | 1  1
```

左边是 E，右边就是 X：

```text
X = | 1  0 |
    | 1  1 |
```

验算 AX：

```text
第 1 行 (1, 1)：(1+1, 0+1) = (2, 1)  ✓
第 2 行 (1, 2)：(1+2, 0+2) = (3, 2)  ✓
```

全程只用了两次倍加，比求逆再乘快得多。

## 14. 和其他章节怎么连

**连行列式**

|A| ≠ 0 是可逆的充要条件。

A⁻¹ = A*/|A|，逆的定义里就带着行列式。

**连秩**

可逆 ⟺ 满秩 ⟺ 行（列）向量组线性无关。

第 04 篇会把这三句话合成一句。

**连方程组**

Ax = b，当 A 可逆时 x = A⁻¹b，解唯一。

当 A 不可逆时，逆这个方法失效，要改用秩来判断解的结构。

**连特征值**

Aα = λα，两边左乘 A⁻¹ 得 α = λA⁻¹α，也就是 A⁻¹α = (1/λ)α。

所以 A 的特征值是 λ 时，A⁻¹ 的特征值是 1/λ，特征向量不变。

**连相似对角化**

A = P⁻¹BP 里的 P⁻¹，就是这一篇的东西。

求 P⁻¹ 是相似对角化计算量最大的一步。

一个实用技巧：如果 P 的列是 A 的特征向量，那么 P⁻¹AP = Λ 是对角阵，而 P⁻¹ 往往可以用 (P|E) 一次算出。

所以第 08 篇的对角化题，前半段考的就是这一篇。

**连二次型**

x = Cy 里的 C 必须可逆，否则变换前后不是同一个二次型。

可逆这个条件保证了 x 和 y 一一对应，二次型的"形状"信息不会丢。

一句话：

```text
逆矩阵是"回到原样"的工具，凡是要反推、要换基、要化简的地方，都有它。
```

### 自检三问

**第一问：为什么 A·A* 等于 |A|E，而不是 E？**

答：因为 A* 的每个元素都是代数余子式，是按"展开定理"配出来的。

展开定理说 Σ aᵢⱼAᵢⱼ = |A|，而错位相乘（第 i 行乘第 j 列的代数余子式，i ≠ j）等于 0，因为那相当于把一个有两行相同的行列式展开。

所以乘积是对角线上全是 |A|、其余全零的矩阵，也就是 |A|E。

想让右边变成 E，必须再除以 |A|，这就是 A⁻¹ = A*/|A| 的来历。

**第二问：为什么求逆只能做行变换，不能做列变换？**

答：因为推导用的是"左乘初等矩阵"。

Pₖ…P₁A = E 推出 Pₖ…P₁ = A⁻¹，同一个乘积作用在 E 上得到 A⁻¹。

左乘对应行变换，所以只能动行。

如果对列动手，相当于右乘初等矩阵，得到的是 A 的另一种分解，和 A⁻¹ 无关。

**第三问：(AB)⁻¹ 为什么是 B⁻¹A⁻¹，不能是 A⁻¹B⁻¹？**

答：因为"先 B 后 A"的反动作，必须是"先撤 A 再撤 B"。

验证一下：A⁻¹B⁻¹ 乘 AB 得到 A⁻¹B⁻¹AB，中间是 B⁻¹A，一般不等于 E，没法消。

而 B⁻¹A⁻¹ 乘 AB 得到 B⁻¹(A⁻¹A)B = B⁻¹B = E，一路消干净。

顺序反了，消不掉，这就是必须反序的原因。
