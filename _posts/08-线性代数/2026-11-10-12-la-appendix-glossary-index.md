## 2. 术语表（一）：行列式与矩阵

这一组是"工具层"，全部是矩阵本身的性质。

```text
01 行列式 |A|      方阵压成的一个数；不为零代表各行独立。
02 余子式 Mᵢⱼ      划掉第 i 行第 j 列后剩下的 n−1 阶行列式。
03 代数余子式 Aᵢⱼ  (−1)^(i+j) 乘余子式，带符号的余子式。
04 伴随矩阵 A*     把各元素的代数余子式按转置位置排成的新矩阵；
                   满足 AA* = A*A = |A|E。
05 对角矩阵        非对角元全为 0 的方阵。
06 单位矩阵 E      对角元全为 1 的对角矩阵，乘法里的"1"。
07 数量矩阵 kE     对角元全为 k 的对角矩阵，与任何同阶矩阵可交换。
08 转置 Aᵀ         行和列对调。
09 对称矩阵        Aᵀ = A 的方阵；Aᵀ = −A 的叫反对称矩阵。
10 逆矩阵 A⁻¹      满足 AA⁻¹ = E 的矩阵；存在当且仅当 |A| ≠ 0。
11 正交矩阵 Q      QᵀQ = E 的方阵；列向量是标准正交组；Q⁻¹ = Qᵀ。
12 初等变换        交换两行、某行乘非零数、某行的 k 倍加到另一行。
13 初等矩阵        对 E 做一次初等变换得到的矩阵；左乘它等于做行变换。
14 分块矩阵        把矩阵切成小块，当作元素来运算。
15 秩 r(A)         化成阶梯形后非零行的个数；"独立信息有几条"。
16 满秩            r(A) = n，等价于 |A| ≠ 0，等价于可逆。
17 迹 tr(A)        主对角线元素之和；等于全部特征值之和。
18 范德蒙德行列式  各行是 1, xᵢ, xᵢ², … 的行列式；
                   值等于所有 (xⱼ − xᵢ)（j > i）的连乘。
```

**三条要连起来记的**

```text
A 可逆  ⇔  |A| ≠ 0  ⇔  r(A) = n  ⇔  Ax = 0 只有零解  ⇔  0 不是特征值
```

这五个说法是一件事的五种说法，考试时看到任何一个，都要能瞬间换成另外四个。

**这一组的关键动作**

```text
看到"可逆"两个字，第一反应是算行列式。
看到行列式，第一反应是问"能不能化三角"。
看到伴随，第一反应是写 AA* = |A|E。
```

三个反应，覆盖了这一组 90% 的题。

## 3. 术语表（二）：向量与方程组

这一组是"结构层"，回答的是"有没有解、解有多少、怎么表示"。

```text
19 向量            一组有序的数；可以看成点，也可以看成箭头。
20 线性组合        若干向量各乘一个数再相加。
21 线性表示        β 能写成 α₁, …, αₛ 的线性组合。
22 向量组等价      两组向量能互相线性表示；等价则秩相等。
23 线性相关        存在不全为零的系数，使组合等于零向量。
24 线性无关        只有全零系数，才能使组合等于零向量。
25 极大线性无关组  组内线性无关、且能表示组内其余向量的那一部分。
26 向量组的秩      极大无关组里向量的个数。
27 基与维数        向量空间的一组极大无关组叫基；基的个数叫维数。
28 坐标            向量在给定基下的线性组合系数。
29 增广矩阵 (A|b)  系数矩阵右边添上常数列。
30 齐次方程组      Ax = 0；一定有零解，一定有解空间。
31 非齐次方程组    Ax = b（b ≠ 0）；可能无解。
32 基础解系        齐次方程组解空间的一组基；含 n − r(A) 个向量。
33 通解            全部解的表达式；非齐次 = 特解 + 齐次通解。
34 克拉默法则      |A| ≠ 0 时，xⱼ = |Aⱼ| / |A|。
```

**解的结构一句话**

```text
齐次：x = k₁η₁ + … + kₙ₋ᵣηₙ₋ᵣ
非齐次：x = ξ + k₁η₁ + … + kₙ₋ᵣηₙ₋ᵣ
```

**这一组的关键动作**

```text
看到方程组，第一反应是写增广矩阵，不是解方程。
看到"有几个解"，第一反应是比两个秩。
看到"求通解"，第一反应是先写 n − r(A)，知道要几个自由向量。
```

这里最容易被跳过的一步是"先算 n − r(A)"。

先知道基础解系要有几个向量，做的时候就有数：算出来多一个少一个，立刻能发现。

## 4. 术语表（三）：特征值与二次型

这一组是"形状层"，回答的是"这个矩阵内在长什么样"。

```text
35 特征值 λ        使 Aα = λα 有非零解的 λ。
36 特征向量 α      被 A 作用后方向不变的非零向量。
37 特征多项式      |λE − A|，关于 λ 的 n 次多项式，根即特征值。
38 重数            代数重数 = 根的重数；几何重数 = n − r(λE − A)。
39 相似            存在可逆 P 使 P⁻¹AP = B；相似保持特征值、迹、行列式、秩。
40 相似对角化      A 相似于对角矩阵；等价于有 n 个线性无关的特征向量。
41 实对称矩阵      元素为实数且 Aᵀ = A；一定可以正交对角化。
42 正交对角化      用正交矩阵 Q 使 QᵀAQ = Λ；只有实对称矩阵做得到。
43 二次型          只含二次项的齐次多项式；写成 f = xᵀAx。
44 二次型的矩阵    对称矩阵；平方项系数放对角，交叉项系数折半放两侧。
45 合同            存在可逆 C 使 CᵀAC = B；保持秩与惯性指数，不保持特征值。
46 标准形          只含平方项；规范形是系数只取 ±1、0 的标准形。
47 惯性指数        正系数个数 p、负系数个数 q；p + q = r(A)。
48 惯性定理        无论用哪个可逆替换，p 与 q 都不变。
49 正定            对一切非零 x，xᵀAx > 0；等价于 p = n。
50 半正定          对一切 x，xᵀAx ≥ 0；允许某些非零方向取到 0。
```

**四个数连起来**

```text
r(A) = 标准形里非零项的个数
p    = 标准形里正号的个数 = 正特征值的个数
q    = 标准形里负号的个数 = 负特征值的个数
n−r  = 标准形里零的个数 = 零特征值的个数（计重数）
```

**这一组的关键动作**

```text
看到"二次型"，第一反应是折半写矩阵。
看到"化简"，第一反应是问"要不要 Q"。
看到"正定"，第一反应是算顺序主子式。
```

三个反应对应三种题，混了就白算。

尤其第一个：写完矩阵先回读一遍，把 aᵢⱼ 乘 2 看能不能还原成原式。

能还原，矩阵就对了；不能还原，后面全错。

## 5. 公式速查（一）：行列式

**二阶与三阶**

```text
| a  b | = ad − bc
| c  d |

| a₁₁ a₁₂ a₁₃ |
| a₂₁ a₂₂ a₂₃ | = a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂
| a₃₁ a₃₂ a₃₃ |   − a₁₃a₂₂a₃₁ − a₁₁a₂₃a₃₂ − a₁₂a₂₁a₃₃
```

**展开**

```text
按第 i 行展开：|A| = Σⱼ aᵢⱼ Aᵢⱼ ，Aᵢⱼ = (−1)^(i+j) Mᵢⱼ
```

**六条性质**

```text
|Aᵀ| = |A|
|kA| = kⁿ|A|
|AB| = |A||B|
|A⁻¹| = 1/|A|
|A*| = |A|^(n−1)
交换两行变号；某行乘 k 值乘 k；某行加另一行的 k 倍值不变
```

**两条特殊**

```text
上（下）三角、对角：值 = 对角线乘积
范德蒙德：∏ (xⱼ − xᵢ)，j > i（后面的减前面的）
```

**拿到一个行列式，按这个顺序挑方法**

```text
第一步：有零行或零列吗？有，值为 0。
第二步：有两行成比例吗？有，值为 0。
第三步：各行之和相同吗？相同，全加到第一列，提公因子。
第四步：有某行只有一个非零元吗？有，按它展开降阶。
第五步：都不满足，化三角。能用倍加就用倍加，非交换不可时记负号。
```

## 6. 公式速查（二）：矩阵与秩

**逆与伴随**

```text
AA* = A*A = |A|E
A⁻¹ = A*/|A|        （|A| ≠ 0）
(A*)⁻¹ = (A⁻¹)* = A/|A|
```

**转置与逆的四条**

```text
(A + B)ᵀ = Aᵀ + Bᵀ          (A + B)⁻¹ 一般不存在简单公式
(AB)ᵀ = BᵀAᵀ               (AB)⁻¹ = B⁻¹A⁻¹
(kA)ᵀ = kAᵀ                 (kA)⁻¹ = (1/k)A⁻¹
(Aᵀ)ᵀ = A                   (A⁻¹)⁻¹ = A
```

**伴随的两条**

```text
(AB)* = B*A*
(A*)ᵀ = (Aᵀ)*
```

**秩的不等式**

```text
r(A) = r(Aᵀ) = r(AᵀA) = r(AAᵀ)
r(A + B) ≤ r(A) + r(B)
r(AB) ≤ min{r(A), r(B)}
r(A) + r(B) − n ≤ r(AB)    （A 是 m×n，B 是 n×s，西尔维斯特不等式）
A 可逆 ⇒ r(AB) = r(B)，r(BA) = r(B)
```

**初等变换**

```text
初等变换不改变秩，也不改变列向量之间的线性关系。
左乘初等矩阵 = 行变换；右乘初等矩阵 = 列变换。
```

## 7. 公式速查（三）：方程组与特征值

**解的判定**

```text
r(A) ≠ r(A|b)          →  无解
r(A) = r(A|b) = n      →  唯一解
r(A) = r(A|b) < n      →  无穷多解，自由变量 n − r(A) 个
```

**解的结构**

```text
Ax = 0：基础解系含 n − r(A) 个向量，通解是它们的线性组合
Ax = b：通解 = 一个特解 + 对应齐次方程组的通解
```

**特征值**

```text
Aα = λα，α ≠ 0
|λE − A| = 0 解出 λ
Σλᵢ = tr(A)
∏λᵢ = |A|
```

**变换表**

```text
A          λ
kA         kλ
A + kE     λ + k
Aᵏ         λᵏ
f(A)       f(λ)
A⁻¹        1/λ
A*         |A|/λ
Aᵀ         λ
P⁻¹AP      λ
```

**对角化**

```text
A 可对角化 ⇔ 有 n 个线性无关的特征向量
          ⇔ 每个重特征值的几何重数 = 代数重数
          ⇔ n − r(λᵢE − A) = λᵢ 的重数，对所有 i
A = PΛP⁻¹  ⇒  Aᵏ = PΛᵏP⁻¹
```

**实对称矩阵**

```text
特征值全为实数
不同特征值的特征向量自动正交
一定存在正交矩阵 Q 使 QᵀAQ = Q⁻¹AQ = Λ
```

## 8. 公式速查（四）：二次型与正定

**写矩阵**

```text
平方项系数 → 对角元
交叉项系数 → 除以 2，填在 (i, j) 和 (j, i)
```

**合同与标准形**

```text
x = Cy（C 可逆）  ⇒  A 变成 CᵀAC
C 正交            ⇒  CᵀAC = C⁻¹AC = Λ，系数即特征值
标准形：d₁y₁² + … + dₙyₙ²
规范形：diag(1, …, 1, −1, …, −1, 0, …, 0)
```

**惯性**

```text
p + q = r(A)
p = 正特征值个数，q = 负特征值个数
A ≃ B  ⇔  r(A) = r(B) 且 p(A) = p(B)
```

**正定五判据**

```text
∀x ≠ 0, xᵀAx > 0
特征值全 > 0
顺序主子式 Δ₁, …, Δₙ 全 > 0
A ≃ E（存在可逆 C 使 CᵀAC = E）
p = n
```

**负定与半正定**

```text
负定：Δₖ 与 (−1)^k 同号；等价于 −A 正定
半正定：特征值全 ≥ 0；全体主子式 ≥ 0；p = r
A = BᵀB 半正定；正定 ⇔ B 列满秩
```

## 9. 20 组易混（上：1–10）

**第 1 组：行列式与矩阵**

```text
行列式是一个数，用竖线；矩阵是一张表，用方括号。
|A| 能比较大小，A 不能。
```

**第 2 组：|kA| 与 k|A|**

```text
|kA| = kⁿ|A|，n 是阶数。
k|A| 是"数乘行列式"，跟 |kA| 不是一回事。
```

**第 3 组：(A+B)⁻¹ 与 A⁻¹+B⁻¹**

```text
(A + B)⁻¹ 一般没有简单公式，绝不等于 A⁻¹ + B⁻¹。
A⁻¹ + B⁻¹ = A⁻¹(A + B)B⁻¹ 才是对的（前提是都可逆）。
```

**第 4 组：(AB)ᵀ 与 AᵀBᵀ**

```text
(AB)ᵀ = BᵀAᵀ，顺序要反过来。
AᵀBᵀ 一般不等于 (AB)ᵀ。
```

**第 5 组：(AB)⁻¹ 与 A⁻¹B⁻¹**

```text
(AB)⁻¹ = B⁻¹A⁻¹，同样要反序。
```

**第 6 组：(AB)* 与 A*B***

```text
(AB)* = B*A*，还是反序。
```

**第 7 组：等价、相似、合同**

```text
等价：存在可逆 P、Q 使 PAQ = B；只保持秩。
相似：存在可逆 P 使 P⁻¹AP = B；保持特征值、迹、行列式、秩。
合同：存在可逆 C 使 CᵀAC = B；保持秩、惯性指数。
关系：相似且对称 ⇒ 合同；合同 ⇏ 相似。
```

**第 8 组：秩与维数**

```text
r(A) 是矩阵的秩，等于列空间的维数。
解空间的维数是 n − r(A)，不是 r(A)。
```

**第 9 组：线性相关与线性无关**

```text
相关：有不全为零的系数使组合为零。
无关：只有全零系数才行。
含零向量的组一定相关；单个非零向量一定无关。
```

**第 10 组：基础解系与通解**

```text
基础解系是一组向量（解空间的基）。
通解是这些向量的所有线性组合，是一个集合。
```

**这十组里最容易错的两处**

```text
一、(AB)ᵀ、(AB)⁻¹、(AB)* 三条都要反序，放在一起背比分开背牢。
二、"等价 / 相似 / 合同"三个词，只有相似保持特征值，另外两个都不保持。
```

## 10. 20 组易混（下：11–20）

**第 11 组：特征值与特征向量**

```text
特征值是一个数，特征向量是一个非零向量。
同一个特征值可以对应无穷多个特征向量，它们张成一个特征子空间。
```

**第 12 组：相似与正交相似**

```text
相似用任意可逆 P；正交相似要求 P 是正交矩阵。
正交相似一定相似，反之不然。
只有实对称矩阵一定能找到正交相似的 P。
```

**第 13 组：对角化与正交对角化**

```text
对角化：P⁻¹AP = Λ，P 只要可逆。
正交对角化：QᵀAQ = Λ，Q 必须正交。
前者要求 n 个线性无关的特征向量，后者还要求它们两两正交。
```

**第 14 组：|A| = 0、有特征值 0、不可逆**

```text
这三件事是同一件事。
再加上"r(A) < n"和"Ax = 0 有非零解"，一共五种说法。
```

**第 15 组：正定与半正定**

```text
正定：一切非零 x 都严格大于 0。
半正定：允许某些非零 x 取到 0。
正定一定半正定，反之不然。
```

**第 16 组：顺序主子式与全体主子式**

```text
判正定：只看顺序主子式。
判半正定：必须看全体主子式。
反例 diag(0, −1)：顺序主子式全是 0，但 a₂₂ = −1 < 0。
```

**第 17 组：标准形与规范形**

```text
标准形：只含平方项，系数任意。
规范形：系数只能取 1、−1、0。
标准形不唯一，规范形唯一。
```

**第 18 组：惯性指数与特征值**

```text
惯性指数 (p, q) 只有两个整数，合同就看它。
特征值是 n 个数，相似才看它。
正交变换时，标准形系数就是特征值，两件事才重合。
```

**第 19 组：矩阵里的 aᵢⱼ 与交叉项系数**

```text
矩阵里的 aᵢⱼ 是交叉项系数的一半。
反过来写二次型时，要把 aᵢⱼ 乘 2。
```

**第 20 组：合同于 E 与相似于 E**

```text
合同于 E 的矩阵很多：所有正定矩阵。
相似于 E 的矩阵只有一个：E 自己。
```

**这十组里最容易错的两处**

```text
一、判半正定用了顺序主子式。必须是全体主子式，diag(0, −1) 就是反例。
二、把"标准形"和"规范形"混着写。题目要规范形时写 3y₁²，直接扣分。
```

这两处的共同点是：都没有算错，是"用错了判据"。

算错的题，重算一遍常常能救；用错判据的题，重算十遍还是错。

所以这两条要背到条件反射。

**体检表的正确用法**

打勾的时候要诚实。

"大概知道"不算打上，"能不看书写出来"才算。

判断标准很简单：

```text
合上文章，拿一张白纸，把这条对应的公式或者结论默写出来。
写得出，打勾；写不出，或者写得犹豫，就是没打通。
```

第二个要点是记录错误的原因，而不是只记"没打上"。

```text
是压根不知道有这条？        → 回到对应篇目读定义
是知道但记混了？            → 看第 9、10 节的易混表
是知道但算不对？            → 回到 11 篇对应的题型，练三道
```

三种原因的处方完全不同。

不区分原因，一律"再看一遍书"，是最低效的复习方式。

### 自检三问

**第一问：行列式和矩阵，最根本的区别是什么？**

```text
提示：行列式是一个数，矩阵是一张表。
行列式为 0 说明"这张表对应的变换把空间压扁了"，
矩阵本身只是把线性关系排整齐。
```

**第二问：等价、相似、合同，三者谁包含谁？**

```text
提示：等价最宽（同秩即可）。
相似要求存在可逆 P 使 P⁻¹AP = B，特征值相同。
合同要求存在可逆 C 使 CᵀAC = B，正负惯性指数相同。
实对称矩阵在正交变换下，相似与合同合一。
```

**第三问：给一个 3×3 实对称矩阵，你能走完整条链吗？**

```text
提示：求特征值 → 求特征向量 → 正交化单位化 →
写出 Q 与 Λ → 用 Q 把二次型化成标准形 → 判断正定。
这条链是数一线代大题的固定骨架。
```

## 13. 全系列收官

十三篇，写完了。

回头看，整套线性代数其实就是三件事。

```text
第一件：把关系写成矩阵。
    一个方程组、一组向量、一个二次型，都能写成一个矩阵。

第二件：用秩看结构。
    有没有解、独不独立、能不能对角化，本质上都在问秩。

第三件：用特征值看形状。
    方向不变的那些线，决定了这个矩阵到底在做什么。
```

如果只能记三句话，就记这三句：

```text
矩阵是关系的表格。
秩是独立信息的条数。
特征值是方向不变的伸缩倍数。
```

**这一路走过的顺序**

```text
00  先看地图，知道有哪几块。
01  行列式：一个方阵压成一个数。
02  矩阵运算：关系怎么组合。
03  逆与初等变换：怎么把矩阵拆开。
04  秩：独立信息有几条。
05  向量组：谁多余，谁不可少。
06  方程组：有没有解，解长什么样。
07  特征值：哪个方向不变。
08  对角化：能不能换成最简单的样子。
09  二次型：形状怎么认。
10  正定：什么情况下恒为正。
11  题型：看到什么活，拿哪把工具。
12  附录：回头查的地方。
```

**最后三句提醒**

第一句，线性代数的计算量大，但每一步都是机械的。

```text
会做而算错，比不会做更可惜。
```

所以第 11 篇里那三个校验数（迹、行列式、秩）要养成习惯。

第二句，概念之间的等价关系比单个定义更重要。

```text
"可逆""满秩""行列式非零""零不是特征值""齐次方程只有零解"，
这五句话是同一件事。
```

考试不会直接问你定义，它会在五个说法之间来回换。

第三句，线代没有真正的难题，只有没认出来的题型。

```text
认出来了，就是执行动作；认不出来，就是原地打转。
```

第 11 篇那八类，认全了，线代这一块就稳了。

**写给三种情况不同的读者**

如果你是从零开始读的：不必因为第一遍看不懂而回头重读。

线代的特点是"后面的内容会反过来解释前面的内容"。

读完二次型再回头看行列式，很多当时不明白的地方会自己通。

所以第一遍的目标是"知道有这个东西"，不是"全部弄懂"。

如果你是被线代折磨过的：你的问题很可能不在计算，在概念。

```text
算得对但不知道为什么，一换题型就不会——这是概念没通。
知道为什么但总算错——这是熟练度不够。
```

前一种要读定义和反例，后一种要限时练。

如果你是来查漏的：直接看第 11 节的索引和第 12 节的清单，不要从头读。

这篇附录存在的意义，就是让"从头读"变成"按需查"。
