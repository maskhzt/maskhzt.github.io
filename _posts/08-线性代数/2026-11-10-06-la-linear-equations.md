> **读这篇之前，你只需要知道**：矩阵是"把系数排成一张表"，一行对应一个方程；初等行变换是"把某一行乘一个数加到另一行"，它不改变方程组的解；矩阵的秩是"化成阶梯形以后非零行的个数"，也就是这张表里有几条真正独立的约束。
> **这篇讲什么**：一个方程组到底有没有解、有几个解，怎么判断，无穷多个解又怎么用一个式子全部写出来。
> **一个类比**：三个人报同一件事的证词。如果三份证词其实是一份重复了三遍，那你能确定的只有一份信息，剩下的细节全是自由的；如果三份证词互相打架，那这件事根本不存在。

中学有一条经验：三个方程、三个未知数，就能解出来。

看这个：

```text
 x₁ + 2x₂ + 3x₃ = 6
2x₁ + 4x₂ + 6x₃ = 12
 x₁ −  x₂       = 1
```

三个方程，三个未知数。

按中学的经验，应该有唯一解。

可是第二个方程是第一个乘 2，它一个字的新信息都没有。

真正管用的只有两条：

```text
 x₁ + 2x₂ + 3x₃ = 6
 x₁ −  x₂       = 1
```

两条约束管不住三个未知数，所以解有无穷多个。

**反直觉的点在这里：**

```text
"有几个方程"不重要，
"有几个真正独立的方程"才重要。
```

判断"真正独立"，靠的是秩。

这一篇就是把这句话变成一套能算的流程。

## 1. 为什么需要它（不给会怎样）

先说这一节要回答的问题：没有"解的结构"这套理论，我们会在哪里卡住？

卡在四个地方。

**第一，判断不了"有没有解"。**

拿到一个方程组，硬着头皮消元，消到最后出现

```text
0 = 5
```

才知道无解。

如果一开始就能判断，就不必白算一遍。

**第二，说不清"有多少解"。**

无穷多解的时候，答案是写成"x₁ = 1 + t，x₂ = 2 − t，x₃ = t"这样一串吗？

t 是什么？还有没有别的写法？

不同的写法是不是同一个答案？

这些说不清，答题就是碰运气。

**第三，参数题会漏情形。**

带参数的方程组，参数取某些值时无解，取另一些值时无穷多解。

漏一种情形，整题的分就没了。

**第四，后面所有章节都要用它。**

求特征向量，本质是解 (A − λE)x = 0。

求二次型的标准形，要解一堆方程组。

判断两个矩阵是否相似，要用到解空间。

**所以这一篇是整条链子的计算场。**

前面几篇讲的对象，最后都落在这里算。

## 2. 最小模型：三种写法与两个矩阵

先说为什么要把同一个方程组写成三种样子。

因为三种写法各自方便做不同的事。

只认一种，就会在需要另一种的时候卡住。

**写法一：方程组。**

```text
 a₁₁x₁ + a₁₂x₂ + … + a₁ₙxₙ = b₁
 a₂₁x₁ + a₂₂x₂ + … + a₂ₙxₙ = b₂
              …
 aₘ₁x₁ + aₘ₂x₂ + … + aₘₙxₙ = bₘ
```

a 后面的两个下标，前一个表示第几个方程，后一个表示第几个未知数。

这个写法最直观，但写起来最长。

**写法二：矩阵方程。**

把系数按原位排成矩阵 A（叫系数矩阵）：

```text
     ┌                      ┐
     │ a₁₁  a₁₂  …  a₁ₙ     │
A =  │ a₂₁  a₂₂  …  a₂ₙ     │
     │  …    …   …   …      │
     │ aₘ₁  aₘ₂  …  aₘₙ     │
     └                      ┘
```

未知数和右端各排成一列：

```text
     ┌   ┐         ┌   ┐
     │ x₁│         │ b₁│
x =  │ x₂│    b =  │ b₂│
     │ … │         │ … │
     │ xₙ│         │ bₘ│
     └   ┘         └   ┘
```

方程组就写成了

```text
Ax = b
```

这个写法最省事，一行搞定。

**写法三：向量方程。**

把 A 的每一列看成一个向量 αⱼ：

```text
x₁α₁ + x₂α₂ + … + xₙαₙ = b
```

这个写法最能看出结构。

它说的是：**解方程组，就是找一组系数，把 b 用 A 的列向量凑出来。**

所以：

```text
方程组有解  ⟺  b 能由 A 的列向量组线性表示
```

这句话把第 05 篇和这一篇焊在了一起。

**两个矩阵。**

**系数矩阵 A**：只有系数，没有右端。

**增广矩阵 (A|b)**：把 b 添在 A 的右边，读作"A 杠 b"。

```text
        ┌                            ┐
        │ a₁₁  a₁₂  …  a₁ₙ  │  b₁   │
(A|b) = │ a₂₁  a₂₂  …  a₂ₙ  │  b₂   │
        │  …    …   …   …   │  …    │
        │ aₘ₁  aₘ₂  …  aₘₙ  │  bₘ   │
        └                            ┘
```

竖线只是分隔，不参与计算。

**为什么非要有增广矩阵？**

因为做行变换的时候，右端也会跟着变。

只用系数矩阵，就会把右端的信息丢掉，最后判不出有没有解。

**行变换为什么不改变解？**

对方程组做三件事，解集不变：

```text
交换两个方程的位置
把一个方程乘一个非零的数
把一个方程的 k 倍加到另一个方程上
```

这三件事正好对应矩阵的三种初等行变换。

所以可以放心地在增广矩阵上做行变换，一路化到阶梯形。

**先把"解"这个东西说清楚。**

一个 n 元方程组的解，是一组有序的数 (c₁, c₂, …, cₙ)，把它代进去，每个方程都成立。

排成列向量，就叫解向量。

所以"解方程组"求的不是一个数，而是一个向量。

"解集"就是所有解向量组成的集合。

**两个方程组同解，是什么意思。**

如果两个方程组的解集完全一样，就说它们同解。

上面那三个动作，每一个都保持解集不变，所以变换前后的方程组同解。

**这一点决定了整篇的方法论：**

```text
不必硬解原方程组，
只要把它变成"一眼能读出解"的等价方程组。
```

最简阶梯形就是那个"一眼能读出"的形状。

所以整篇的算法只有一句话：往最简阶梯形上化。

## 3. 有解判定：比较两个秩

先说没有这个判据会怎样。

"有解没解"只能靠消元消到最后一行才知道。

而考试里，一道题的第一问常常就是"a 取何值时方程组有解"，你不可能对每个 a 都消一遍。

判据只有一句话：

```text
r(A) = r(A|b)   →  有解
r(A) ≠ r(A|b)   →  无解
```

r(A) 是系数矩阵的秩，r(A|b) 是增广矩阵的秩。

**为什么"秩相等就有解"？**

回头看写法三：方程组有解，就是 b 能由 A 的列向量表示。

把 b 添进去当新的一列，向量组从 {α₁, …, αₙ} 变成 {α₁, …, αₙ, b}。

如果 b 能由原来的列表示，添进去不会增加秩，所以 r(A|b) = r(A)。

如果 b 表示不出来，它就是一条新信息，秩加 1，所以 r(A|b) = r(A) + 1。

**秩只能相等或者加 1，绝不会加 2 或更多。**

因为只添了一列。

所以判据还可以写成更直白的样子：

```text
r(A|b) = r(A) + 1  →  无解，差的那 1 就是"矛盾"
r(A|b) = r(A)      →  有解
```

**"秩只能差 0 或 1"这件事，可以严格说清。**

把 A 的列记作 α₁、…、αₙ。

r(A) 就是这组列向量的秩。

r(A|b) 是 {α₁, …, αₙ, b} 这一组的秩。

后者是在前者基础上添了一个向量，而添一个向量，秩最多加 1。

所以只有两种可能：b 能被列组表示，秩不变；b 表示不出来，秩加 1。

没有第三种。

这也顺带说明：无解的时候，矛盾的"程度"只有 1。

哪怕写一百个方程，只要无解，多出来的那一条信息就是一行"0 = 非零"。

**有解之后，解有多少个？**

看 r(A) 和未知数个数 n 的关系。

```text
r(A) = n   →  唯一解
r(A) < n   →  无穷多解
```

**为什么 r < n 就一定无穷多？**

因为秩是"独立约束的条数"，n 是"未知数的个数"。

约束比未知数少，说明至少有一个未知数没被卡住，它可以自由取值。

取一个值，得到一组解；取另一个值，得到另一组解。

所以有无穷多组。

**把三种命运合起来，就是数一必背的那张表：**

```text
r(A) ≠ r(A|b)              →  无解
r(A) = r(A|b) = n          →  唯一解
r(A) = r(A|b) < n          →  无穷多解
```

**注意 r(A) 永远不可能大于 r(A|b)。**

因为 A 的列是 (A|b) 的列的一部分，列多了秩只会不减。

所以只有"相等"和"差 1"两种可能，判据不会有第三种情况。

**一个常见的侥幸心理要提前打掉。**

有人看到方程个数等于未知数个数，就认为一定有唯一解。

前面那个三方程三未知数的例子已经推翻了这个想法。

方阵情形下，唯一解的充要条件是 |A| ≠ 0，而不是"行数等于列数"。

**方程个数和结论之间，没有直接关系。**

四个方程三个未知数，可能唯一解（只要有一个方程是废话），也可能无解（只要有两个方程打架）。

两个方程三个未知数，只要有解，就一定是无穷多解，因为约束不够。

所以判断永远看秩，不看方程个数。

数一的选择题很喜欢在这里设陷阱：题干给"三个方程三个未知数"，选项里就有一个"必有唯一解"。

## 4. 算一遍：三种命运各算一例

先说为什么三种都要算。

因为考试不会只考一种。

而且三种情形的判别动作完全一样，只有最后一步的结论不同，放在一起对比，才记得住。

**例 1（唯一解）**

```text
 x₁ +  x₂ + x₃ = 6
2x₁ −  x₂ + x₃ = 3
 x₁ + 2x₂ − x₃ = 2
```

写出增广矩阵：

```text
┌                   ┐
│ 1   1   1  │  6   │
│ 2  −1   1  │  3   │
│ 1   2  −1  │  2   │
└                   ┘
```

第二行减第一行的 2 倍，第三行减第一行：

```text
┌                   ┐
│ 1   1   1  │  6   │
│ 0  −3  −1  │ −9   │
│ 0   1  −2  │ −4   │
└                   ┘
```

交换第二、三行（方便计算）：

```text
┌                   ┐
│ 1   1   1  │  6   │
│ 0   1  −2  │ −4   │
│ 0  −3  −1  │ −9   │
└                   ┘
```

第三行加第二行的 3 倍：

```text
┌                   ┐
│ 1   1   1  │  6   │
│ 0   1  −2  │ −4   │
│ 0   0  −7  │ −21  │
└                   ┘
```

现在回代。

第三行：−7x₃ = −21，所以 x₃ = 3。

第二行：x₂ − 2x₃ = −4，即 x₂ − 6 = −4，所以 x₂ = 2。

第一行：x₁ + x₂ + x₃ = 6，即 x₁ + 2 + 3 = 6，所以 x₁ = 1。

解是 (1, 2, 3)ᵀ。

验算原方程组第三个：

```text
1·1 + 2·2 − 1·3 = 1 + 4 − 3 = 2   ✓
```

秩的情况：r(A) = 3，r(A|b) = 3，n = 3，三个数相等，唯一解。

**例 2（无解）**

```text
x₁ + x₂ = 1
2x₁ + 2x₂ = 3
```

增广矩阵：

```text
┌             ┐
│ 1   1  │ 1  │
│ 2   2  │ 3  │
└             ┘
```

第二行减第一行的 2 倍：

```text
┌             ┐
│ 1   1  │ 1  │
│ 0   0  │ 1  │
└             ┘
```

最后一行翻译回方程是 0 = 1，矛盾。

所以无解。

秩的情况：r(A) = 1，r(A|b) = 2，两个秩不相等，无解。

**这个例子说明了一件事：**

增广矩阵比系数矩阵多出来的那个"1"，就是矛盾。

它一旦出现，方程组的解集就是空的。

**从阶梯形直接读出结论，是这一篇要养成的习惯。**

化成阶梯形以后，只看最后几行的形状：

```text
出现 (0 0 … 0 | 非零数)  →  无解
出现 (0 0 … 0 | 0)       →  这一行是废话，划掉
非零行数 = 未知数个数     →  唯一解
非零行数 < 未知数个数     →  无穷多解
```

这四条判据，把"解方程"变成了"看形状"。

**例 3（无穷多解）**

```text
 x₁ + 2x₂ + 3x₃ = 6
2x₁ + 4x₂ + 6x₃ = 12
 x₁ −  x₂       = 1
```

增广矩阵：

```text
┌                   ┐
│ 1   2   3  │  6   │
│ 2   4   6  │ 12   │
│ 1  −1   0  │  1   │
└                   ┘
```

第二行减第一行的 2 倍：

```text
│ 0   0   0  │  0   │
```

第三行减第一行：

```text
│ 0  −3  −3  │ −5   │
```

整理成：

```text
┌                   ┐
│ 1   2   3  │  6   │
│ 0  −3  −3  │ −5   │
│ 0   0   0  │  0   │
└                   ┘
```

第二行乘 −1/3：

```text
│ 0   1   1  │ 5/3  │
```

所以方程组的全部信息是

```text
x₁ + 2x₂ + 3x₃ = 6
      x₂ +  x₃ = 5/3
```

两个独立约束，三个未知数，有一个自由。

秩的情况：r(A) = 2，r(A|b) = 2，相等；n = 3，r < n，无穷多解。

**把解写出来。**

由第二式：x₂ = 5/3 − x₃。

代回第一式：

```text
x₁ = 6 − 2x₂ − 3x₃
   = 6 − 2(5/3 − x₃) − 3x₃
   = 6 − 10/3 + 2x₃ − 3x₃
   = 8/3 − x₃
```

令 x₃ = t，解就是

```text
x₁ = 8/3 − t
x₂ = 5/3 − t
x₃ = t
```

写成向量形式：

```text
     ┌      ┐       ┌       ┐
     │  8/3 │       │  −1   │
x =  │  5/3 │  + t  │  −1   │
     │   0  │       │   1   │
     └      ┘       └       ┘
```

**验算一组：取 t = 1。**

```text
x = (5/3, 2/3, 1)
第一式：5/3 + 4/3 + 3 = 3 + 3 = 6   ✓
第三式：5/3 − 2/3 = 1              ✓
```

对上了。

**三例对比，只差在秩上：**

```text
例 1：r(A) = r(A|b) = 3 = n   →  唯一解
例 2：r(A) = 1 ≠ 2 = r(A|b)   →  无解
例 3：r(A) = r(A|b) = 2 < 3   →  无穷多解
```

## 5. 拆开看：齐次方程组与基础解系

先说清楚什么叫齐次。

右端全为 0 的方程组 Ax = 0，叫齐次线性方程组。

右端不全为 0 的，叫非齐次线性方程组，Ax = b。

**齐次方程组有一个白送的解：x = 0。**

叫零解。

所以齐次方程组永远不会"无解"。

它只有两种命运：

```text
只有零解      （r(A) = n）
有非零解      （r(A) < n）
```

**为什么 r < n 就有非零解？**

约束比未知数少，就有自由未知量。

让自由未知量取一个非零值，得到的就是非零解。

**基础解系是什么。**

没有它，无穷多个解没法一次性写完。

有了它，无穷多个解可以用有限个解的组合表示出来。

**定义**：齐次方程组 Ax = 0 的一组解 ξ₁、ξ₂、…、ξₛ，如果满足

```text
（1）它们线性无关
（2）方程组的任何一个解都能由它们线性表示
```

就叫这个齐次方程组的一个基础解系。

ξ 读作"克西"。

**这个定义的形状和第 05 篇的"极大无关组"一模一样。**

确实是一回事：基础解系就是"解空间这个向量组"的极大无关组。

也正因为如此，它才叫"基础"：所有解都是它们的组合。

**基础解系里到底有几个向量？**

```text
s = n − r
```

n 是未知数的个数，r 是系数矩阵的秩。

这个数字是本篇最重要的一个结论，理由要讲清。

**为什么是 n − r。**

把增广矩阵化成最简阶梯形以后，主元所在的列叫主元列，其余的列叫自由列。

```text
主元列的个数 = r
自由列的个数 = n − r
```

每一个自由列对应一个自由未知量。

让其中一个自由未知量取 1、其余自由未知量取 0，就能解出一组解。

这样一共能造出 n − r 组解。

它们线性无关（因为每个自由未知量在其中一个向量里是 1，在其余向量里是 0）。

而且任意一个解都能由它们组合出来（因为解完全由自由未知量的取值决定）。

所以它们就是基础解系。

**写基础解系的三步模板。**

```text
1. 化最简阶梯形，标出主元列
2. 把主元变量用自由变量表示出来
3. 每次让一个自由变量取 1、其余自由变量取 0，得到一个向量
```

第三步是关键。

这样造出来的向量一定线性无关，不需要另外验证，因为每个向量都带着一个"只有它是 1"的位置。

**但有一种情形，基础解系根本不存在。**

就是 r(A) = n 的时候。

这时 n − r = 0，解空间里只有零向量，维数是 0。

**例** 判断下面这个齐次方程组有没有非零解。

```text
x₁ + 2x₂ + 3x₃ = 0
2x₁ + 5x₂ + 3x₃ = 0
x₁        + 8x₃ = 0
```

算系数行列式，按第一行展开：

```text
|A| = 1·| 5  3 | − 2·| 2  3 | + 3·| 2  5 |
        | 0  8 |      | 1  8 |      | 1  0 |
```

三个二阶行列式：

```text
| 5  3 |
| 0  8 | = 40 − 0 = 40

| 2  3 |
| 1  8 | = 16 − 3 = 13

| 2  5 |
| 1  0 | = 0 − 5 = −5
```

代回去：

```text
|A| = 40 − 2(13) + 3(−5) = 40 − 26 − 15 = −1
```

行列式是 −1，不为 0。

所以 r(A) = 3 = n，只有零解。

基础解系不存在，解空间维数是 0。

**这个例子的意义在于提醒：**

"基础解系"这个词，不是任何齐次方程组都有。

只有 r < n 时才有。

答题时如果算出 r = n，就该写"只有零解"，而不是硬凑一个基础解系出来。

**通解怎么写成一句话。**

```text
齐次方程组的通解 = k₁ξ₁ + k₂ξ₂ + … + kₛξₛ
```

k 是任意常数。

**这句话的含义是：所有的解，一个不漏。**

## 6. 算一遍：求基础解系与通解

先说这类题的答案长什么样。

答案必须包含三样：

```text
基础解系是哪几个向量
每个向量都要写成列向量的形式
通解要写成组合的形式，并注明 k 是任意常数
```

只写"x₁ = −2x₂ − x₄"这样的式子是不够的，那是方程，不是答案。

**例 4** 求下面齐次方程组的基础解系和通解。

```text
x₁ + 2x₂ +  x₃ + 3x₄ = 0
x₁ + 2x₂ + 2x₃ + 5x₄ = 0
```

写出系数矩阵并做行变换：

```text
┌                   ┐
│ 1   2   1   3     │
│ 1   2   2   5     │
└                   ┘
```

第二行减第一行：

```text
┌                   ┐
│ 1   2   1   3     │
│ 0   0   1   2     │
└                   ┘
```

再把上面的行减去下面的行（消掉第 3 列）：

```text
┌                   ┐
│ 1   2   0   1     │
│ 0   0   1   2     │
└                   ┘
```

已经是最简阶梯形。

秩 r = 2（两个主元），未知数 n = 4。

主元在第 1、3 列，所以 x₂ 和 x₄ 是自由未知量。

基础解系里应该有

```text
s = n − r = 4 − 2 = 2
```

两个向量。

**把方程写出来。**

第一行：x₁ + 2x₂ + x₄ = 0。

第二行：x₃ + 2x₄ = 0。

解出主元变量：

```text
x₁ = −2x₂ − x₄
x₃ = −2x₄
```

**造第一个向量**：令 x₂ = 1，x₄ = 0。

```text
x₁ = −2(1) − 0 = −2
x₃ = −2(0) = 0
```

```text
     ┌    ┐
     │ −2 │
ξ₁ = │  1 │
     │  0 │
     │  0 │
     └    ┘
```

**造第二个向量**：令 x₂ = 0，x₄ = 1。

```text
x₁ = −2(0) − 1 = −1
x₃ = −2(1) = −2
```

```text
     ┌    ┐
     │ −1 │
ξ₂ = │  0 │
     │ −2 │
     │  1 │
     └    ┘
```

**验算 ξ₂ 回原方程组。**

第一式：

```text
−1 + 0 + (−2) + 3 = 0   ✓
```

第二式：

```text
−1 + 0 + (−4) + 5 = 0   ✓
```

**验算 ξ₁。**

第一式：−2 + 2 + 0 + 0 = 0 ✓。

第二式：−2 + 2 + 0 + 0 = 0 ✓。

**通解。**

```text
x = k₁ξ₁ + k₂ξ₂
```

也就是

```text
     ┌    ┐      ┌    ┐      ┌    ┐
     │ −2 │      │ −1 │      │ −2 │
x =  │  1 │  k₁ +│  0 │  k₂  = ...
     │  0 │      │ −2 │
     │  0 │      │  1 │
```

写成一行更省地方：

```text
x = (−2k₁ − k₂, k₁, −2k₂, k₂)ᵀ
```

k₁、k₂ 是任意常数。

**这个答案怎么检验？**

三个动作：

```text
1. 把 ξ₁、ξ₂ 代回原方程组，两个都应该成立
2. 数一数个数，应该等于 n − r = 2
3. 看 ξ₁、ξ₂ 是不是线性无关（不成比例就无关）
```

三步都对，答案基本没错。

**一个容易忽略的细节：自由未知量的取法不唯一。**

如果改令 x₄ = 1、x₂ = 0 得到的是同一个 ξ₂。

但如果用别的组合，比如 ξ₁ + ξ₂ 也当基础解系的成员，得到的是另一组基础解系。

基础解系不唯一，但它含的向量个数一定相同，张成的解空间一定相同。

## 7. 拆开看：非齐次通解的结构

先说没有这个结构会怎样。

非齐次方程组有无穷多解的时候，解集不是一个"过原点的空间"，而是一个"平移过的空间"。

它没有零解（除非 b = 0），所以不能说"通解是基础解系的组合"。

那怎么说？

**结论一句话：**

```text
非齐次通解 = 一个特解 + 导出组的通解
```

导出组，就是把右端换成 0 得到的齐次方程组 Ax = 0。

**写成式子：**

```text
x = η + k₁ξ₁ + k₂ξ₂ + … + kₛξₛ
```

η 读作"伊塔"，是 Ax = b 的某一个具体的解，叫特解。

ξ 是导出组 Ax = 0 的基础解系。

**为什么是这个结构？**

两个方向都要证。

方向一：η + 任意组合，一定是解。

代进 Ax = b：

```text
A(η + k₁ξ₁ + … + kₛξₛ)
= Aη + k₁Aξ₁ + … + kₛAξₛ
= b + 0 + … + 0
= b
```

成立。

方向二：任何一个解，都能写成这个形状。

设 x 是任意一个解，令

```text
δ = x − η
```

那么

```text
Aδ = Ax − Aη = b − b = 0
```

所以 δ 是导出组的解，可以写成 ξ 的组合。

于是 x = η + δ，就是那个形状。

**几何上是什么样。**

齐次方程组的解集是"过原点的平面（或直线）"。

非齐次方程组的解集是"不过原点、但和它平行的一个平面（或直线）"。

```text
        ╱ 非齐次解集（平移过）
       ╱
      ╱──── 齐次解集（过原点）
     ╱
    ● 原点
```

特解 η 就是那个"平移量"。

**特解不是唯一的，但结论一样。**

例 3 的通解里，如果取 t = 3，得到

```text
(8/3 − 3, 5/3 − 3, 3)ᵀ = (−1/3, −4/3, 3)ᵀ
```

它也是一个特解。

用它写通解：

```text
x = (−1/3, −4/3, 3)ᵀ + s(−1, −1, 1)ᵀ
```

这和前面那个写法是同一个集合：只要令 s = t − 3，两个式子就互相转化。

所以特解可以任取，只要它确实是解。

答案的写法不唯一，但解集唯一。

**出题人关心的是解集，不是某一种写法。**

所以答通解时，只要"一个特解 + 基础解系的组合"这个形状对，具体取哪个特解都能得分。

**用例 3 验一遍这个结构。**

例 3 的通解是

```text
x = (8/3, 5/3, 0)ᵀ + t(−1, −1, 1)ᵀ
```

前面的 (8/3, 5/3, 0) 就是特解 η。

后面的 t(−1,−1,1) 就是导出组的通解。

导出组是

```text
 x₁ + 2x₂ + 3x₃ = 0
2x₁ + 4x₂ + 6x₃ = 0
 x₁ −  x₂       = 0
```

它的系数矩阵秩是 2，n = 3，所以基础解系有 3 − 2 = 1 个向量。

取 x₃ = 1，由 x₁ = x₂ 和 x₁ + 2x₂ + 3 = 0 得 3x₁ = −3，x₁ = x₂ = −1。

所以基础解系是 (−1, −1, 1)ᵀ。

和上面写的一模一样。

**所以例 3 的通解可以写成标准形状：**

```text
     ┌      ┐       ┌    ┐
     │  8/3 │       │ −1 │
x =  │  5/3 │  + t  │ −1 │
     │   0  │       │  1 │
     └      ┘       └    ┘
```

**这解释了为什么非齐次方程组不能"随便加减"。**

两个非齐次解加起来，右端变成 2b，不再是 b。

两个非齐次解相减，右端变成 0，变成齐次解。

这就是下一节要讲的性质。

## 8. 拆开看：解的四条性质

先说为什么要单独列性质。

因为考试常出"已知某几个解，求通解"这种抽象题。

不会用性质，就只能干看着。

**性质一：齐次解的任意线性组合仍是齐次解。**

若 Aξ₁ = 0，Aξ₂ = 0，则 A(k₁ξ₁ + k₂ξ₂) = 0。

理由就是分配律。

这条性质说明：齐次方程组的解集对加法、数乘封闭，是一个向量空间。

所以它才有"基"和"维数"。

**性质二：非齐次的两个解之差，是导出组的解。**

若 Ax₁ = b，Ax₂ = b，则 A(x₁ − x₂) = 0。

这条是第 7 节结构定理的另一半。

**性质三：非齐次解加上齐次解，还是非齐次解。**

若 Aη = b，Aξ = 0，则 A(η + ξ) = b。

**性质四：非齐次解的线性组合还是解，当且仅当系数之和为 1。**

设 x₁、…、xₘ 都是 Ax = b 的解。

```text
A(k₁x₁ + … + kₘxₘ) = (k₁ + … + kₘ)b
```

要它等于 b，必须 k₁ + … + kₘ = 1。

**这一条最容易记错。**

两个解相加（系数和是 2）不是解。

两个解相减（系数和是 0）是齐次解。

各取一半相加（系数和是 1）是解。

**性质五：解空间的维数关系。**

齐次解集的维数是 n − r。

非齐次解集不是向量空间（不含零向量），但它是"一个 n − r 维空间平移"，习惯上也说它的自由度是 n − r。

**用几何再说一遍这五条。**

一个三元一次方程是一个平面。

两个方程是两个平面的交，一般是一条直线。

三个方程是三个平面的交，可能是：

```text
一个点         →  唯一解
一条直线       →  无穷多解，基础解系 1 个
一张平面       →  无穷多解，基础解系 2 个
空集           →  无解
```

"三个平面交成一张平面"听起来别扭，但它确实会发生。

三个方程如果是同一个平面方程乘上不同的倍数，交出来就是那张平面自己。

这时 r(A) = r(A|b) = 1，n = 3，基础解系有 2 个，正好对应"平面是二维的"。

**这张对照表还有一个用处：判断几何题的答案该写什么。**

题目问"三个平面是否交于一点"，翻译过来就是"r(A) = r(A|b) = 3 是否成立"。

题目问"是否有公共点"，翻译过来就是"r(A) 与 r(A|b) 是否相等"。

几何语言和秩语言之间，来回翻译就靠这张表。

**这五条性质，考试里最常用的是后三条。**

因为它们能直接从"某几个解"推出"通解"。

**举一个抽象题的典型形状：**

```text
已知四元非齐次方程组 Ax = b 的秩 r(A) = 3，
η₁、η₂、η₃ 是它的三个解，且
η₁ + η₂ = (1, 2, 3, 4)ᵀ，η₂ + η₃ = (0, 1, 2, 3)ᵀ，
求 Ax = b 的通解。
```

这种题的解法：先凑出一个特解（系数和为 1 的组合），再凑出齐次解（系数和为 0 的组合）。

n = 4，r = 3，所以齐次解空间维数是 1，只需要一个非零齐次解。

细节放到第 11 篇的套路里展开，这里先知道"该往性质上想"。

## 9. 算一遍：含参数方程组的讨论

先说为什么参数题必须专门练。

因为它的答案是"分情况"的，而分情况的分界点，要靠行列式或秩算出来。

不算，就不知道该分几种情况。

**例 5** 讨论 a、b 取何值时，下面的方程组有唯一解、无穷多解、无解。

```text
 x₁ +  x₂ +  x₃ = 1
 x₁ + 2x₂ + 3x₃ = 2
 x₁ + 4x₂ + ax₃ = b
```

**第一步，算系数行列式。**

```text
     ┌             ┐
     │ 1   1   1   │
A =  │ 1   2   3   │
     │ 1   4   a   │
     └             ┘
```

按第一行展开：

```text
|A| = 1·| 2  3 | − 1·| 1  3 | + 1·| 1  2 |
        | 4  a |      | 1  a |      | 1  4 |
```

三个二阶行列式：

```text
| 2  3 |
| 4  a | = 2a − 12

| 1  3 |
| 1  a | = a − 3

| 1  2 |
| 1  4 | = 4 − 2 = 2
```

代回去：

```text
|A| = (2a − 12) − (a − 3) + 2
    = 2a − 12 − a + 3 + 2
    = a − 7
```

**第二步，分情况。**

**情形一：a ≠ 7。**

此时 |A| ≠ 0，r(A) = 3 = n，唯一解。

具体解不必求，题目只问"何时有唯一解"。

**情形二：a = 7。**

此时 |A| = 0，r(A) < 3，要看增广矩阵。

把 a = 7 代进去，对增广矩阵做行变换：

```text
┌                   ┐
│ 1   1   1  │  1   │
│ 1   2   3  │  2   │
│ 1   4   7  │  b   │
└                   ┘
```

第二行减第一行，第三行减第一行：

```text
┌                   ┐
│ 1   1   1  │  1     │
│ 0   1   2  │  1     │
│ 0   3   6  │  b−1   │
└                   ┘
```

第三行减第二行的 3 倍：

```text
┌                   ┐
│ 1   1   1  │  1         │
│ 0   1   2  │  1         │
│ 0   0   0  │  b−1−3     │
└                   ┘
```

最后一行右端是 b − 4。

**情形二之一：a = 7 且 b ≠ 4。**

最后一行是 0 = b − 4 ≠ 0，矛盾。

r(A) = 2，r(A|b) = 3，两个秩不等，无解。

**情形二之二：a = 7 且 b = 4。**

最后一行是 0 = 0，没有矛盾。

r(A) = r(A|b) = 2 < 3，无穷多解。

**把通解写出来。**

此时方程组等价于

```text
x₁ + x₂ + x₃ = 1
     x₂ + 2x₃ = 1
```

由第二式：x₂ = 1 − 2x₃。

代回第一式：

```text
x₁ = 1 − x₂ − x₃ = 1 − (1 − 2x₃) − x₃ = x₃
```

令 x₃ = t：

```text
x₁ = t
x₂ = 1 − 2t
x₃ = t
```

向量形式：

```text
     ┌   ┐       ┌    ┐
     │ 0 │       │  1 │
x =  │ 1 │  + t  │ −2 │
     │ 0 │       │  1 │
     └   ┘       └    ┘
```

**验算 t = 0 的特解 (0,1,0)：**

```text
第一式：0 + 1 + 0 = 1        ✓
第二式：0 + 2 + 0 = 2        ✓
第三式：0 + 4 + 0 = 4 = b    ✓
```

**验算 t = 1 的解 (1,−1,1)：**

```text
第一式：1 − 1 + 1 = 1        ✓
第二式：1 − 2 + 3 = 2        ✓
第三式：1 − 4 + 7 = 4 = b    ✓
```

**第三步，把结论整理成一句话。**

```text
a ≠ 7            →  唯一解
a = 7, b ≠ 4     →  无解
a = 7, b = 4     →  无穷多解，x = (0,1,0)ᵀ + t(1,−2,1)ᵀ
```

**这类题的完整流程，四步：**

```text
1. 算系数行列式，令其为 0，解出临界参数值
2. 参数不取临界值 → 唯一解
3. 参数取临界值 → 化增广矩阵，看两个秩
4. 两个秩相等 → 无穷多解，写出基础解系；不等 → 无解
```

## 10. 常见错误

先说这些错误为什么值得单列。因为它们的共同点是"步骤没错、判断错了"，回头检查也查不出来。

**错误一：只算 r(A)，不算 r(A|b)。**

判断有没有解，必须两个都算。

只看 r(A)，永远判不出"无解"。

**错误二：基础解系的个数写成 n。**

应该是 n − r。

多于 n − r 个，必然线性相关，不是基础解系。

少于 n − r 个，表示不全，也不是基础解系。

**错误三：把特解当通解。**

写出一个 (0,1,0)ᵀ 就交卷，这只说明了"有一个解"。

通解必须带上 k 乘基础解系的部分。

**错误四：说"齐次方程组无解"。**

齐次方程组一定有零解，不可能无解。

它只可能"只有零解"。

**错误五：行变换时只对系数矩阵做，忘了右端那列。**

增广矩阵是一整块，右端要跟着一起变。

**错误六：参数讨论漏情形。**

比如只讨论 a = 7 时的无解，忘了 b = 4 还有无穷多解。

分情况要分到底，每种组合都要交代。

**错误七：认为非齐次解的组合还是解。**

只有系数之和为 1 时才是。

**错误八：求基础解系时不检验线性无关。**

随机取几组自由未知量的值，取出来的解可能线性相关。

标准做法是"一个自由变量取 1、其余取 0"，这样构造出来的必定无关。

**错误九：以为基础解系是唯一的。**

不唯一。

但它含的向量个数唯一，张成的空间唯一。

所以答"一个基础解系"比答"基础解系"更准确。

**错误十：把"化到阶梯形"当成"可以停手了"。**

阶梯形能读出秩，用回代也能解出未知数。

但想直接"读"出基础解系的系数，必须化到最简阶梯形。

两类目的要求的形状不同，别混。

## 11. 数一怎么考

先说这一节为什么值得单独看。因为同样的解法，写成不同的顺序，得分多少会不一样。

**题型一：求通解（必考，解答题）。**

给定具体的方程组，要求写出通解。

评分点是三段：秩的判断、基础解系、通解的写法。

**题型二：含参数讨论（高频）。**

给 a 或 λ，问何时无解、何时唯一、何时无穷多。

按第 9 节的四步走。

**题型三：抽象题（较难）。**

不给具体数字，只给秩和几个解，求通解。

解法固定：先凑特解（系数和 1），再凑齐次解（系数和 0），齐次解需要几个就凑几个。

**例 6** 已知四元方程组 Ax = b 中 r(A) = 3，η₁、η₂、η₃ 是它的三个解，且

```text
η₁ + η₂ = (1, 2, 3, 4)ᵀ
η₂ + η₃ = (0, 1, 2, 3)ᵀ
```

求通解。

**第一步，凑一个特解。**

系数之和要为 1。

(η₁ + η₂)/2 的系数和是 1，所以

```text
η = (1/2)(1, 2, 3, 4)ᵀ = (1/2, 1, 3/2, 2)ᵀ
```

是 Ax = b 的一个解。

**第二步，凑齐次解。**

系数之和要为 0。

用 (η₁ + η₂) − (η₂ + η₃) 不行，因为 η₃ 的符号对不上，那个组合是 η₁ − η₃，系数和是 1 − 1 = 0。

所以

```text
ξ = (1, 2, 3, 4)ᵀ − (0, 1, 2, 3)ᵀ = (1, 1, 1, 1)ᵀ
```

是 Ax = 0 的解。

**第三步，数一下够不够。**

n = 4，r = 3，齐次解空间维数是 4 − 3 = 1。

所以一个非零齐次解就够了。

**第四步，写通解。**

```text
x = (1/2, 1, 3/2, 2)ᵀ + k(1, 1, 1, 1)ᵀ
```

k 是任意常数。

**验算思路：**

把 k = 0 代回，得到特解，它应该满足 Ax = b（题目已保证）。

把 k 取 1，得到另一个解，它也应该满足。

而两个解之差是 (1,1,1,1)ᵀ，应该满足 Ax = 0。

**题型四：解的结构的证明。**

证明"若 η₁、η₂ 是解，则 2η₁ − η₂ 也是解"这类。

用性质四，看系数和：2 − 1 = 1，是解。

**题型五：与几何结合。**

三个平面交于一点、交于一条线、没有公共点，分别对应唯一解、无穷多解、无解。

这种题只要把几何语言翻译成秩的语言就行。

**分值分布：**

```text
选择填空：1 题（4–5 分），考判定与基础解系个数
解答题：几乎年年有，10–12 分
与特征值、二次型合并：常见于大题的第二问
```

## 12. 和其他章节怎么连

先说为什么要把章节之间的接口列出来。因为数一的大题常常横跨两三章，节点不清楚就接不上。

**和 01 行列式。**

方阵情形下，唯一解的充要条件是 |A| ≠ 0。

克莱姆法则给的是"用行列式写出的公式解"：

```text
xⱼ = |Aⱼ| / |A|
```

其中 Aⱼ 是把 A 的第 j 列换成 b 得到的矩阵。

这个公式理论价值大于计算价值，考试里只在"证明"或"n 很小"时用。

**和 03 逆矩阵。**

若 A 可逆，Ax = b 的解可以直接写出来：

```text
x = A⁻¹b
```

这是"矩阵方程"视角下最省事的写法。

**和 04 矩阵的秩。**

整篇的判定都建立在秩上。

```text
r(A) ≠ r(A|b)  →  无解
r(A) = r(A|b)  →  有解
```

没有秩，"有没有解"就只能靠消元碰运气。

**和 05 向量组。**

```text
Ax = b 有解       ⟺  b 可由 A 的列向量组线性表示
基础解系          ⟺  解空间的极大无关组
基础解系个数 n−r  ⟺  解空间的维数
```

第 05 篇的每一个概念，在这里都有一个对应的计算对象。

**和 07、08 特征值与对角化。**

求特征向量，就是解

```text
(A − λE)x = 0
```

这是一个齐次方程组。

它的基础解系，就是 λ 对应的全部特征向量（再加上零向量）。

几何重数，就是 n − r(A − λE)。

所以"求特征向量"这件事，本篇已经给了完整方法。

**和 09、10 二次型与正定。**

二次型化标准形，要做可逆线性变换 x = Cy。

变换以后新矩阵是 CᵀAC。

这一步的合法性，建立在"解方程组得到的变换矩阵可逆"之上。

**和 11 数一线代套路。**

第 11 篇会把"求通解"拆成固定的五步，并且给出阅卷的给分点。

这一篇要保证的是每一步都会算，那一篇要保证的是答题的顺序不乱。

**一句话总结这一篇在网里的位置：**

```text
前面几篇给出对象，
这一篇给出"解方程"这个通用动作，
后面几篇全部回到这个动作上算。
```

### 自检三问

**第一问**：一个四元方程组，r(A) = r(A|b) = 2，它有多少个解？基础解系含几个向量？

答案：有无穷多解。

因为 r(A) = r(A|b)，有解；r = 2 < 4 = n，所以无穷多。

基础解系含 n − r = 4 − 2 = 2 个向量。

通解的形状是"一个特解 + 两个任意常数的组合"。

**第二问**：为什么齐次方程组不可能无解？

答案：因为 x = 0 一定是解。

把零向量代进去，A·0 = 0 恒成立。

所以齐次方程组至少有一个解，它只有"只有零解"和"有非零解"两种命运。

前者对应 r(A) = n，后者对应 r(A) < n。

**第三问**：非齐次方程组的两个解相加，还是不是解？

答案：一般不是。

设 Ax₁ = b，Ax₂ = b。

则 A(x₁ + x₂) = 2b。

只有当 b = 0（也就是齐次）时，2b 才等于 b。

一般的判断标准是系数之和：

```text
系数和 = 1  →  是解
系数和 = 0  →  是齐次解
其他         →  什么都不是
```

## 13. 小结 + 下一篇

这一篇的主线是一条判定链：

```text
算两个秩  →  判有没有解  →  算 n − r  →  写基础解系  →  加特解得通解
```

每一步都只用前一步的结果。

**五个必记的结论。**

```text
1. r(A) ≠ r(A|b)          →  无解
2. r(A) = r(A|b) = n      →  唯一解
3. r(A) = r(A|b) < n      →  无穷多解
4. 齐次解空间维数 = n − r，基础解系含 n − r 个向量
5. 非齐次通解 = 特解 + 导出组通解
```

**一个必会的算法。**

```text
增广矩阵 → 行变换化最简阶梯形 → 定主元列与自由列 → 造基础解系 → 加特解
```

**一个必防的坑。**

基础解系的个数是 n − r，不是 n，也不是 r。
