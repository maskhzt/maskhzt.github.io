> **读这篇之前，你只需要知道**：矩阵乘向量是"把向量按矩阵的规则变换一下"，得到一个同维的新向量；齐次方程组 Ax = 0 只有零解还是有非零解，看系数矩阵的秩是不是小于未知数个数；行列式是把方阵压成一个数，它等于 0 就说明这个方阵"不够独立"。
> **这篇讲什么**：一个矩阵作用在向量上，绝大多数方向都被扭走了，但有少数几个方向纹丝不动，只改长度；这几个方向和它们的伸缩倍数，就是矩阵的内在线索。
> **一个类比**：把一张橡皮膜向四周拉伸。膜上大部分点都被拉得偏离了原来的方向，但总有那么几条射线，拉完还在自己那条射线上，只是离原点更远了；这几条射线的方向和拉伸倍数，就是这张膜的"性格"。

先看一个具体的矩阵：

```text
     ┌         ┐
A =  │ 1   2   │
     │ 2   1   │
     └         ┘
```

让它连续乘一个向量一百次，也就是算 A¹⁰⁰。

手工乘是乘不动的：一次矩阵乘向量要 4 次乘法，一百次就是 400 次，中间的数还会越滚越大。

但换两个特别的向量试试。

取 α = (1, 1)：

```text
     ┌         ┐ ┌   ┐     ┌   ┐
Aα = │ 1   2   │ │ 1 │  =  │ 3 │  = 3α
     │ 2   1   │ │ 1 │     │ 3 │
     └         ┘ └   ┘     └   ┘
```

方向没变，长度变成 3 倍。

再取 β = (1, −1)：

```text
     ┌         ┐ ┌    ┐     ┌    ┐
Aβ = │ 1   2   │ │  1 │  =  │ −1 │  = −1·β
     │ 2   1   │ │ −1 │     │  1 │
     └         ┘ └    ┘     └    ┘
```

方向也没变，长度不变，只是掉了个头。

**反直觉的点在这里：**

```text
一个矩阵把大多数向量都扭走了，
却总有那么几个方向，它动不了。
```

这几个"动不了的方向"，就是矩阵的骨架。

有了它们，A¹⁰⁰ 不用乘一百次，一步就能写出来：

```text
A¹⁰⁰α = 3¹⁰⁰α
```

这一篇要做的，就是把"找方向"和"算倍数"变成一套能算的流程。

## 1. 为什么需要它（不给会怎样）

先说这一节要回答的问题：没有特征值这套工具，我们会在哪里卡住？

卡在五个地方。

**第一，矩阵的方幂算不动。**

A²、A³ 还能硬乘，A¹⁰⁰ 就没法看了。

而实际问题里，方幂出现的频率极高：一年的转移矩阵、一步的状态更新、一次迭代的递推。

没有特征值，这些只能一个一个乘。

有了特征值，Aⁿα = λⁿα，指数运算代替了矩阵乘法。

**第二，看不出矩阵的"性格"。**

两个矩阵，看上去都是九个数字，但一个把空间拉长，一个把空间压扁，一个把空间旋转。

光看数字看不出来。

看特征值就一目了然：

```text
特征值全为正        →  各方向都在拉长
有正有负            →  有的方向拉长，有的反向
有 0                →  某个方向被压成了 0，矩阵不可逆
```

**第三，二次型的形状说不清。**

xᵀAx 这个式子在三维里表示一个曲面：椭球面、双曲面、抛物柱面。

到底是哪一种？

答案藏在 A 的特征值的正负号里。

这一条会在第 09、10 篇展开，但根在这里。

**第四，判断"两个矩阵是不是同一个东西换了外衣"没有工具。**

同一个线性变换，换一组基去描述，会得到不同的矩阵。

它们是不是"其实一样"？

特征值是回答这个问题的最强不变量。

**第五，递推数列的通项求不出来。**

斐波那契数列

```text
1, 1, 2, 3, 5, 8, 13, …
```

的通项公式里出现了 √5。

那个 √5 从哪来的？

就从矩阵

```text
┌         ┐
│ 1   1   │
│ 1   0   │
└         ┘
```

的特征值里来。

这是特征值最漂亮的应用之一，本篇第 8 节会把它完整算一遍。

## 2. 最小模型：Aα = λα

先说为什么"方向不变"这件事值得单独定义。

因为矩阵的一般作用是"既转方向又改长度"，两件事混在一起，没法分析。

如果能找到一些向量，方向不变、只有长度变，那么矩阵在这些方向上的作用就退化成了一个数。

一个数，比一个矩阵好处理一万倍。

**定义**：设 A 是 n 阶方阵。

如果存在一个数 λ（读作"拉姆达"）和一个非零向量 α，使得

```text
Aα = λα
```

就说 λ 是 A 的一个特征值，α 是 A 的属于（或对应于）λ 的一个特征向量。

**三句话把定义读透。**

第一句：Aα 是一个向量，λα 也是一个向量，这两个向量相等。

第二句：所以 A 作用在 α 上，效果等于"把 α 乘一个数"。

方向没变（λ > 0 时同向，λ < 0 时反向，λ = 0 时变成零向量），长度乘了 |λ| 倍。

第三句：α 必须非零。

**为什么 α 必须非零？**

因为 A·0 = 0 = λ·0 对任何 λ 都成立。

如果允许零向量，那任何数都是特征值，这个定义就废了。

所以规定 α ≠ 0，把零向量排除在外。

**注意 λ 可以是 0。**

λ = 0 时 Aα = 0，说明 α 被压成了零向量。

这时 A 不可逆（|A| = 0），因为存在非零向量被压没了。

**几何图像。**

```text
       ╱  Aα 还在同一条线上
      ╱
     ╱
    ●──── 原来的 α
   ╱
  ╱
 ╱  原点
```

A 把 α 拉到了同一条直线上，只是位置更远或更近。

这条直线叫"特征方向"。

**λ 的符号和大小，都有几何含义。**

```text
λ > 1      →  同向，拉长
0 < λ < 1  →  同向，压短
λ = 1      →  这个方向上完全不动
λ = 0      →  这个方向被压成零向量
λ < 0      →  反向
```

所以一个矩阵如果所有特征值都是正的，它在每个特征方向上只是"伸缩"。

只要出现负特征值，就一定有"翻转"发生。

**验证一个具体的例子。**

```text
     ┌         ┐        ┌   ┐
A =  │ 1   2   │   α =  │ 1 │
     │ 2   1   │        │ 1 │
     └         ┘        └   ┘
```

按矩阵乘向量的规则算：

```text
     ┌                        ┐   ┌          ┐   ┌   ┐
Aα = │ 1·1 + 2·1   1·1 + 2·1 │ = │ 1 + 2    │ = │ 3 │
     │ 2·1 + 1·1   2·1 + 1·1 │   │ 2 + 1    │   │ 3 │
     └                        ┘   └          ┘   └   ┘
```

结果是 (3,3)，正好等于 3·(1,1)。

所以 λ = 3 是特征值，(1,1) 是对应的特征向量。

**再验证 β = (2,2)。**

它是 (1,1) 的两倍，Aβ = 2Aα = (6,6) = 3β。

所以 (2,2) 也是 λ = 3 的特征向量。

**这说明特征向量从来不唯一。**

一个特征向量乘任何非零数，还是特征向量。

它们全体（再加上零向量）构成一个子空间，叫特征子空间。

**这个子空间有两条现成的性质。**

若 α₁、α₂ 都是属于 λ 的特征向量，则

```text
A(α₁ + α₂) = Aα₁ + Aα₂ = λα₁ + λα₂ = λ(α₁ + α₂)
```

所以 α₁ + α₂ 也是属于 λ 的特征向量。

同理，kα₁ 也是。

**但属于不同特征值的特征向量，加起来什么都不是。**

因为

```text
A(α₁ + α₂) = λ₁α₁ + λ₂α₂
```

右边提不出一个公共的 λ，所以它既不属于 λ₁，也不属于 λ₂。

这也从侧面说明：特征子空间是按特征值分开的，各管各的一块。

**把定义改写成方程组。**

Aα = λα 两边减去 λα：

```text
Aα − λα = 0
```

λα 里的 λ 是数，可以写成 λEα（E 是单位矩阵，Eα = α）：

```text
(A − λE)α = 0
```

**这一步是全篇的枢纽。**

因为 α 是非零向量，所以这个齐次方程组有非零解。

按第 06 篇的判据，齐次方程组有非零解，等价于系数矩阵的行列式为 0：

```text
|A − λE| = 0
```

这一步把"找特征值"变成了"解一个方程"。

## 3. 特征多项式：|A − λE| = 0

先说没有这个方程会怎样。

定义式 Aα = λα 里有两个未知的东西：λ 和 α。

两个未知量、一个向量方程，看起来没法解。

上面那一步把 α 消掉了（只留下"α 非零"这个条件），剩下一个只含 λ 的方程。

方程的次数是 n，所以最多有 n 个根。

**|A − λE| 怎么读。**

读作"A 减 λE 的行列式"。

E 是 n 阶单位矩阵，λE 就是对角线上全是 λ、其余全是 0 的矩阵。

A − λE 就是把 A 的主对角线元素各减去 λ，其余不动。

它的行列式展开以后，是一个关于 λ 的 n 次多项式。

这个多项式叫 A 的特征多项式，通常记作 f(λ)。

**求特征值的三步。**

```text
第一步：写出 A − λE（对角线减 λ）
第二步：算它的行列式，整理成关于 λ 的多项式
第三步：令多项式为 0，解出全部根，这些根就是特征值
```

**二阶的情形，有现成公式。**

```text
     ┌         ┐
A =  │ a   b   │
     │ c   d   │
     └         ┘
```

```text
|A − λE| = (a − λ)(d − λ) − bc
         = λ² − (a + d)λ + (ad − bc)
```

注意两个系数：

```text
一次项系数 = −(a + d) = −tr(A)     （tr 是迹，主对角线之和）
常数项     = ad − bc = |A|
```

所以二阶的特征方程可以背成：

```text
λ² − tr(A)·λ + |A| = 0
```

**例 1** 求 A = [[3,1],[1,3]] 的特征值。

tr(A) = 3 + 3 = 6。

|A| = 9 − 1 = 8。

方程：

```text
λ² − 6λ + 8 = 0
```

因式分解：

```text
(λ − 2)(λ − 4) = 0
```

所以 λ₁ = 2，λ₂ = 4。

**验算一下和与积：**

```text
λ₁ + λ₂ = 6 = tr(A)   ✓
λ₁ · λ₂ = 8 = |A|     ✓
```

这个验算只要两秒，能挡掉大量计算错误。

**一个符号上的坑，先说清楚。**

有人用 |λE − A| 来算，得到的多项式是 |A − λE| 的 (−1)ⁿ 倍。

n 是奇数时，两个多项式差一个负号。

但根是一样的，因为乘一个非零常数不改变根。

所以用哪个都行，**但同一道题里必须始终用同一个**，否则中间验算会对不上。

**还有一件事要提前说明。**

特征值可能是复数。

比如

```text
     ┌          ┐
A =  │ 0   −1   │
     │ 1    0   │
     └          ┘
```

特征方程是 λ² + 1 = 0，根是 ±i。

实矩阵也可以有复特征值。

但第 08、09 篇会用到的一类矩阵是实对称矩阵，它的特征值全是实数，这一点后面会单独讲。

**二阶情形可以用判别式看出根的类型。**

```text
λ² − tr(A)·λ + |A| = 0
```

它的判别式是

```text
Δ = tr(A)² − 4|A|
```

```text
Δ > 0  →  两个不同的实根
Δ = 0  →  一个实根（二重根）
Δ < 0  →  一对共轭复根
```

Δ < 0 时，这个变换不是"沿某个方向拉伸"，而是"旋转加缩放"。

上面那个矩阵 tr = 0，|A| = 1，Δ = −4，两个复根 ±i，正好对应"转 90 度"。

所以特征值的虚实，本身就带着几何信息。

## 4. 算一遍：3×3 矩阵的特征值与特征向量

先说为什么 3×3 必须单独练。

因为 3×3 的特征多项式是三次的，没法像二次那样套公式。

必须真的会展开，也必须会"提取公因子"这个技巧。

**例 2** 求下面矩阵的全部特征值和对应的特征向量。

```text
     ┌             ┐
     │ 3   2   4   │
A =  │ 2   0   2   │
     │ 4   2   3   │
     └             ┘
```

**第一步，写出 A − λE。**

```text
          ┌                      ┐
          │ 3−λ    2      4      │
A − λE =  │  2    −λ      2      │
          │  4     2     3−λ     │
          └                      ┘
```

**第二步，算行列式。**

按第一行展开：

```text
|A − λE| = (3−λ)·| −λ   2 |  −  2·| 2   2 |  +  4·| 2  −λ |
                 | 2  3−λ |       | 4  3−λ|       | 4   2 |
```

三个二阶行列式分别算：

```text
第一个：(−λ)(3−λ) − 2·2 = −3λ + λ² − 4

第二个：2(3−λ) − 2·4 = 6 − 2λ − 8 = −2λ − 2

第三个：2·2 − (−λ)·4 = 4 + 4λ
```

代回去：

```text
|A − λE| = (3−λ)(λ² − 3λ − 4) − 2(−2λ − 2) + 4(4 + 4λ)
```

先把后面两项展开：

```text
−2(−2λ − 2) = 4λ + 4
4(4 + 4λ) = 16 + 16λ
```

合起来是

```text
(3−λ)(λ² − 3λ − 4) + 20λ + 20
```

**这里有个关键动作：先分解，别硬乘。**

```text
λ² − 3λ − 4 = (λ − 4)(λ + 1)
```

所以第一项是

```text
(3−λ)(λ − 4)(λ + 1)
```

而后面两项提出公因子 (λ + 1)：

```text
20λ + 20 = 20(λ + 1)
```

两项都含 (λ + 1)，提出：

```text
|A − λE| = (λ + 1)[(3−λ)(λ − 4) + 20]
```

中括号里展开：

```text
(3−λ)(λ − 4) = 3λ − 12 − λ² + 4λ = −λ² + 7λ − 12
```

加 20：

```text
−λ² + 7λ + 8
```

再分解：

```text
−λ² + 7λ + 8 = −(λ² − 7λ − 8) = −(λ − 8)(λ + 1)
```

代回去：

```text
|A − λE| = (λ + 1)·[−(λ − 8)(λ + 1)]
         = −(λ + 1)²(λ − 8)
```

所以特征方程是

```text
−(λ + 1)²(λ − 8) = 0
```

根是

```text
λ₁ = 8,   λ₂ = λ₃ = −1
```

**验算和与积：**

```text
λ₁ + λ₂ + λ₃ = 8 − 1 − 1 = 6
tr(A) = 3 + 0 + 3 = 6              ✓
```

```text
λ₁λ₂λ₃ = 8·(−1)·(−1) = 8

|A| = 3·| 0  2 | − 2·| 2  2 | + 4·| 2  0 |
         | 2  3 |      | 4  3 |      | 4  2 |
    = 3(0 − 4) − 2(6 − 8) + 4(4 − 0)
    = −12 + 4 + 16
    = 8                             ✓
```

两个验算都对上了，说明特征值算对了。

**第三步，求每个特征值对应的特征向量。**

**先求 λ = 8。**

写 A − 8E，就是主对角线各减 8：

```text
          ┌                ┐
          │ −5    2     4  │
A − 8E =  │  2   −8     2  │
          │  4    2    −5  │
          └                ┘
```

要解 (A − 8E)x = 0。

看第二行：

```text
2x₁ − 8x₂ + 2x₃ = 0
```

两边除以 2：

```text
x₁ − 4x₂ + x₃ = 0
```

所以

```text
x₁ = 4x₂ − x₃
```

代入第一行：

```text
−5x₁ + 2x₂ + 4x₃ = 0
−5(4x₂ − x₃) + 2x₂ + 4x₃ = 0
−20x₂ + 5x₃ + 2x₂ + 4x₃ = 0
−18x₂ + 9x₃ = 0
x₃ = 2x₂
```

回代：

```text
x₁ = 4x₂ − 2x₂ = 2x₂
```

令 x₂ = 1，得到 (2, 1, 2)。

**验算第三行：**

```text
4·2 + 2·1 + (−5)·2 = 8 + 2 − 10 = 0   ✓
```

所以 λ = 8 的特征向量是

```text
ξ₁ = (2, 1, 2)ᵀ，全体为 k(2, 1, 2)ᵀ，k ≠ 0
```

**再求 λ = −1。**

写 A + E（因为减去 −1 就是加上 1）：

```text
         ┌             ┐
         │ 4   2   4   │
A + E =  │ 2   1   2   │
         │ 4   2   4   │
         └             ┘
```

三行成比例：第一行是第二行的 2 倍，第三行和第一行一样。

所以只有一条独立的方程：

```text
2x₁ + x₂ + 2x₃ = 0
```

即

```text
x₂ = −2x₁ − 2x₃
```

有两个自由未知量 x₁、x₃，所以基础解系里有两个向量。

取 x₁ = 1、x₃ = 0：

```text
x₂ = −2
ξ₂ = (1, −2, 0)ᵀ
```

取 x₁ = 0、x₃ = 1：

```text
x₂ = −2
ξ₃ = (0, −2, 1)ᵀ
```

**验算 ξ₃：**

```text
A(0, −2, 1)ᵀ

第一分量：3·0 + 2·(−2) + 4·1 = −4 + 4 = 0
第二分量：2·0 + 0·(−2) + 2·1 = 2
第三分量：4·0 + 2·(−2) + 3·1 = −4 + 3 = −1
```

结果是 (0, 2, −1)，正好等于 −1·(0, −2, 1)。✓

**把答案整理成一句话：**

```text
λ = 8   对应特征向量 k₁(2, 1, 2)ᵀ
λ = −1  对应特征向量 k₂(1, −2, 0)ᵀ + k₃(0, −2, 1)ᵀ
k₁, k₂, k₃ 不全为零
```

**注意 λ = −1 对应的不是一个向量，而是一整张平面。**

因为 2x₁ + x₂ + 2x₃ = 0 是一个过原点的平面方程。

这张平面上每个非零向量都是 λ = −1 的特征向量。

## 5. 拆开看：五个必须记住的性质

先说为什么性质必须背。

因为考试里有一半的特征值题，根本不让你求特征值，而是"已知特征值，求某个式子的值"。

不会用性质，就只能从头算，还算不出来。

**性质一：特征值之和等于迹。**

```text
λ₁ + λ₂ + … + λₙ = a₁₁ + a₂₂ + … + aₙₙ = tr(A)
```

在例 2 里验过：8 + (−1) + (−1) = 6 = 3 + 0 + 3。

**性质二：特征值之积等于行列式。**

```text
λ₁λ₂…λₙ = |A|
```

在例 2 里也验过：8 = 8。

**这两条性质的用处极大。**

它们提供了两个免费的验算，还提供了两个反推的入口：

```text
知道 n−1 个特征值，最后一个用和或积反推
知道 |A| 和 tr(A)，可以验证求出的特征值
```

**性质三：不同特征值对应的特征向量线性无关。**

也就是说：λ₁ ≠ λ₂ 时，属于 λ₁ 的特征向量和属于 λ₂ 的特征向量不成比例。

**证明的思路值得看一眼。**

设 Aα₁ = λ₁α₁，Aα₂ = λ₂α₂，λ₁ ≠ λ₂，且 α₁、α₂ 都非零。

假设它们相关，那么 α₂ = kα₁。

两边乘 A：

```text
Aα₂ = kAα₁ = kλ₁α₁
```

但 Aα₂ = λ₂α₂ = λ₂kα₁。

所以

```text
λ₂kα₁ = kλ₁α₁
```

因为 α₁ ≠ 0 且 k ≠ 0（否则 α₂ = 0），得到 λ₁ = λ₂，与假设矛盾。

所以 α₁、α₂ 无关。

**这个结论可以推广到多个特征值：**

属于不同特征值的特征向量放在一起，整组仍然线性无关。

这是第 08 篇能对角化的理论基础。

**性质四：矩阵变形，特征值跟着变。**

设 λ 是 A 的特征值，α 是对应的特征向量。

```text
A² 的特征值是 λ²          （A²α = A(λα) = λ²α）
kA 的特征值是 kλ
A + aE 的特征值是 λ + a   （(A+aE)α = λα + aα = (λ+a)α）
A⁻¹ 的特征值是 1/λ        （λ ≠ 0 时才有 A⁻¹）
A* 的特征值是 |A|/λ       （A* 是伴随矩阵）
f(A) 的特征值是 f(λ)      （f 是任意多项式）
```

**这几条的记忆方法只有一句：**

```text
特征向量不变，特征值跟着做同样的运算。
```

**注意 A* 那一条的前提。**

A* 的特征值是 |A|/λ，要求 λ ≠ 0，也就是 A 可逆。

如果 λ = 0，A 不可逆，A* 要另外讨论。

**性质五：特征值相同，不代表矩阵相同。**

A 和 Aᵀ 的特征值相同（因为 |A − λE| = |(A − λE)ᵀ| = |Aᵀ − λE|）。

但它们的特征向量一般不同。

更一般地，两个矩阵特征值完全一样，也可能完全不像。

第 08 篇会给出"像"的准确标准：相似。

**这五条性质，值得抄在一张纸上。**

```text
1. Σλ = tr(A)
2. Πλ = |A|
3. 不同特征值的特征向量无关
4. f(A) 的特征值是 f(λ)
5. 特征值相同 ≠ 矩阵相同
```

## 6. 算一遍：用性质反推

先说这类题的形状。

题干给"A 的特征值是 1, 2, 3"，然后问 |A + 2E| 等于多少。

从头算是算不出来的：A 具体是什么根本不知道。

只能靠性质四。

**例 3** 设三阶矩阵 A 的特征值为 1、2、3，求下面六个量。

```text
（1）|A|
（2）tr(A)
（3）|A + 2E|
（4）A⁻¹ 的特征值
（5）A* 的特征值
（6）tr(A²)
```

**（1）|A|。**

按性质二：

```text
|A| = 1·2·3 = 6
```

**（2）tr(A)。**

按性质一：

```text
tr(A) = 1 + 2 + 3 = 6
```

**（3）|A + 2E|。**

A + 2E 的特征值是 λ + 2，也就是

```text
1 + 2 = 3
2 + 2 = 4
3 + 2 = 5
```

三个特征值的积就是 |A + 2E|：

```text
|A + 2E| = 3·4·5 = 60
```

**（4）A⁻¹ 的特征值。**

按 1/λ：

```text
1, 1/2, 1/3
```

验算：它们的积应该等于 |A⁻¹| = 1/|A| = 1/6。

```text
1 · 1/2 · 1/3 = 1/6   ✓
```

它们的和应该等于 tr(A⁻¹)：

```text
1 + 1/2 + 1/3 = 11/6
```

这个数没法用原矩阵直接验，但可以留作后面题目的已知条件。

**（5）A* 的特征值。**

按 |A|/λ：

```text
|A|/1 = 6/1 = 6
|A|/2 = 6/2 = 3
|A|/3 = 6/3 = 2
```

所以 A* 的特征值是 6、3、2。

验算：它们的积应该等于 |A*| = |A|ⁿ⁻¹ = 6² = 36。

```text
6·3·2 = 36   ✓
```

它们的和是 11，所以 tr(A*) = 11。

**（6）tr(A²)。**

A² 的特征值是 λ²：

```text
1, 4, 9
```

所以

```text
tr(A²) = 1 + 4 + 9 = 14
```

**这道题的六个小问，没有一个需要知道 A 长什么样。**

全靠性质四。

**再看一个"由行列式反推特征值"的例子。**

设三阶矩阵 A 满足 |A| = 0。

由性质二，λ₁λ₂λ₃ = |A| = 0。

所以三个特征值里至少有一个是 0。

反过来也成立：如果题目给出"0 是 A 的特征值"，立刻可以断定 A 不可逆。

**这条推理链值得背下来：**

```text
0 是特征值  ⟺  |A| = 0  ⟺  r(A) < n  ⟺  A 不可逆
```

四个说法，说的是同一件事。

题目只要出现其中任何一个，另外三个都可以随手拿来用。

**再看一个带伴随矩阵的题。**

**例 4** 设三阶矩阵 A 的特征值为 1、−2、3，求 |A* + E|。

先算 A* 的特征值。

|A| = 1·(−2)·3 = −6。

```text
A* 的特征值 = |A|/λ，即 −6/1 = −6，−6/(−2) = 3，−6/3 = −2
```

所以 A* 的特征值是 −6、3、−2。

A* + E 的特征值是

```text
−6 + 1 = −5
3 + 1 = 4
−2 + 1 = −1
```

行列式是它们的积：

```text
|A* + E| = (−5)·4·(−1) = 20
```

**这里有一个高频错误要提醒。**

有人会写成

```text
|A* + E| = |A*| + |E| = 36 + 1 = 37
```

这是错的。

行列式对加法没有分配律，只有对乘法有：|AB| = |A||B|。

所以"把 A* 换成它的行列式、把 E 换成 1"这种做法，在任何式子里都不成立。

**正确的通道永远只有一条：**

```text
先求特征值，再对特征值做那个运算，最后把结果乘起来。
```

**例 5** 设三阶矩阵 A 满足 A² = A，且 tr(A) = 2，求 |A + 2E|。

先由 A² = A 定特征值的范围。

设 λ 是特征值，α 是对应特征向量。

```text
A²α = A(Aα) = A(λα) = λ²α
```

另一方面 A² = A，所以 A²α = Aα = λα。

两式相减：

```text
(λ² − λ)α = 0
```

α ≠ 0，所以

```text
λ² − λ = 0
λ(λ − 1) = 0
```

λ 只能是 0 或 1。

**再用迹定个数。**

三个特征值，每个是 0 或 1，和是 2。

所以是 1、1、0。

于是 A + 2E 的特征值是

```text
3, 3, 2
```

行列式：

```text
|A + 2E| = 3·3·2 = 18
```

**这道题的关键动作：把矩阵方程翻译成特征值的方程。**

```text
A² = A        →  λ² = λ
A² = E        →  λ² = 1，λ = ±1
A² = 0        →  λ² = 0，λ = 0
Aᵏ = 0        →  λ = 0
```

这个转换用到的就是性质四：f(A) 的特征值是 f(λ)。

## 7. 拆开看：重数与特征向量的个数

先说为什么"重数"必须区分。

例 2 里 λ = −1 出现了两次。

有的矩阵，这个重根能给两个线性无关的特征向量；有的只能给一个。

给得出两个和给不出两个，决定了矩阵能不能对角化（第 08 篇的核心）。

所以要把"根出现几次"和"能拿到几个向量"分成两个概念。

**代数重数**：λ₀ 作为特征多项式的根，出现几次。

例 2 里 λ = −1 的代数重数是 2。

**几何重数**：属于 λ₀ 的特征子空间的维数。

也就是齐次方程组 (A − λ₀E)x = 0 的解空间维数，等于

```text
n − r(A − λ₀E)
```

例 2 里 λ = −1 时，A + E 的三行成比例，秩是 1。

所以几何重数是

```text
3 − 1 = 2
```

**两者的关系，是一个不等式：**

```text
1 ≤ 几何重数 ≤ 代数重数
```

**为什么几何重数至少是 1？**

因为 λ₀ 是特征值，按定义就存在非零的 α 使 Aα = λ₀α。

所以特征子空间至少有一维。

**为什么几何重数不超过代数重数？**

这个证明稍长，可以这样理解：特征子空间里能取到 k 个线性无关的特征向量，把这 k 个向量扩充成一组基，在这组基下矩阵的形状会逼出 (λ − λ₀) 至少出现 k 次。

严格证明在第 11 篇的证明套路里给，这里先记住这个不等式。

**"几何重数 < 代数重数"会发生什么？**

看一个具体例子。

```text
     ┌                ┐
     │ −1    1    0   │
B =  │ −4    3    0   │
     │  1    0    2   │
     └                ┘
```

算特征多项式，按第三列展开（第三列只有两个非零元，展开最省事）：

```text
|B − λE| = (2 − λ)·| −1−λ   1 |
                    |  −4   3−λ|
```

二阶行列式：

```text
(−1−λ)(3−λ) − 1·(−4) = (−3 + λ − 3λ + λ²) + 4 = λ² − 2λ + 1 = (λ − 1)²
```

所以

```text
|B − λE| = (2 − λ)(λ − 1)²
```

特征值是 1（代数重数 2）和 2。

**看 λ = 1 的几何重数。**

写 B − E：主对角线各减 1。

```text
          ┌                ┐
          │ −2    1    0   │
B − E =   │ −4    2    0   │
          │  1    0    1   │
          └                ┘
```

三行分别是 (−2,1,0)、(−4,2,0)、(1,0,1)。

第二行是第一行的 2 倍，所以只有两行独立。

```text
r(B − E) = 2
```

几何重数：

```text
3 − 2 = 1
```

**1 < 2，几何重数小于代数重数。**

这时属于 λ = 1 的特征向量只能取到 1 个（差一个非零常数）。

具体算一下：解 (B − E)x = 0。

第三行：x₁ + x₃ = 0，即 x₃ = −x₁。

第一行：−2x₁ + x₂ = 0，即 x₂ = 2x₁。

令 x₁ = 1，得到 (1, 2, −1)。

验算：

```text
B(1, 2, −1)ᵀ

第一分量：−1·1 + 1·2 + 0·(−1) = 1
第二分量：−4·1 + 3·2 + 0 = 2
第三分量：1·1 + 0 + 2·(−1) = −1
```

结果是 (1, 2, −1)，等于 1·(1,2,−1)。✓

只有这一个方向。

再找不到第二个和它无关的解。

**顺便把这个矩阵 λ = 2 的情形也算一下。**

写 B − 2E：

```text
          ┌                ┐
          │ −3    1    0   │
B − 2E =  │ −4    1    0   │
          │  1    0    0   │
          └                ┘
```

第三行给出 x₁ = 0。

第一行：−3x₁ + x₂ = 0，即 x₂ = 3x₁ = 0。

第二行：−4x₁ + x₂ = 0，即 x₂ = 4x₁ = 0，同样是 0。

所以前两个分量都是 0，只有 x₃ 自由。

特征向量是 (0, 0, 1)ᵀ。

验算：

```text
B(0, 0, 1)ᵀ = (0, 0, 2)ᵀ = 2·(0, 0, 1)ᵀ   ✓
```

代数重数是 1，几何重数也是 1。

**把两边合起来数一数：**

```text
λ = 1 贡献 1 个线性无关的特征向量
λ = 2 贡献 1 个线性无关的特征向量
合计 2 个，而矩阵是 3 阶
```

凑不到 3 个。

这就是它不能对角化的直接原因，下一篇会用这个结论。

这个矩阵就是第 08 篇"不能对角化"的标准例子，先在这里埋个伏笔。

**把三种情形列成表：**

```text
几何重数 = 代数重数    →  特征向量够用，可对角化
几何重数 < 代数重数    →  特征向量不够，不可对角化
代数重数 = 1           →  几何重数必为 1，一定没问题
```

## 8. 拆开看：特征值能干什么

先说这一节为什么不能省。

前面七节都在讲"怎么算"。

不知道"算了有什么用"，公式就记不牢，题也只知道硬算。

而且数一的大题，常常把特征值当成中间工具，不是最终答案。

**用途一：算矩阵的方幂。**

若 Aα = λα，那么

```text
A²α = A(λα) = λ²α
A³α = A(λ²α) = λ³α
Aⁿα = λⁿα
```

每一步只是把前一步的 λ 提出来一次。

所以一个向量在 A 的反复作用下怎么变，只看 λⁿ。

这正是本篇开头那个 3¹⁰⁰ 的来历。

**如果 A 有 n 个线性无关的特征向量**，把这件事对每个方向各做一遍，就能得到整块矩阵的方幂公式：

```text
Aⁿ = P Λⁿ P⁻¹
```

Λ 读作"大写拉姆达"，是对角线上排着特征值的对角矩阵。

P 的每一列是对应的特征向量。

这个公式是下一篇的主题，这里先记住它的形状。

**用途二：求递推数列的通项。**

斐波那契数列：

```text
F₁ = 1,  F₂ = 1,  F₃ = 2,  F₄ = 3,  F₅ = 5,  F₆ = 8, …
```

递推式是

```text
Fₙ₊₂ = Fₙ₊₁ + Fₙ
```

把它写成矩阵形式。取

```text
     ┌         ┐
M =  │ 1   1   │
     │ 1   0   │
     └         ┘
```

验证一下它作用在 (Fₙ₊₁, Fₙ)ᵀ 上的效果：

```text
第一分量：1·Fₙ₊₁ + 1·Fₙ = Fₙ₊₂    ← 正好是递推式
第二分量：1·Fₙ₊₁ + 0·Fₙ = Fₙ₊₁
```

所以

```text
     ┌        ┐          ┌        ┐
     │ Fₙ₊₁  │          │  F₂    │
     │       │  =  Mⁿ⁻¹ │        │
     │  Fₙ   │          │  F₁    │
     └        ┘          └        ┘
```

而 (F₂, F₁)ᵀ = (1, 1)ᵀ，是个定值。

于是求通项变成了"算 M 的方幂"。

**求 M 的特征值。**

tr(M) = 1 + 0 = 1。

|M| = 1·0 − 1·1 = −1。

特征方程：

```text
λ² − λ − 1 = 0
```

求根公式：

```text
λ = (1 ± √(1 + 4)) / 2 = (1 ± √5)/2
```

两个根是

```text
λ₁ = (1 + √5)/2 ≈ 1.618
λ₂ = (1 − √5)/2 ≈ −0.618
```

**黄金比和那个 √5 就是从这一步来的。**

它们不是硬凑的，是特征方程的根。

**求特征向量。**

对 λ，解 (M − λE)x = 0，第一行是

```text
(1 − λ)x₁ + x₂ = 0
```

即

```text
x₂ = (λ − 1)x₁
```

取 x₁ = 1，得到特征向量

```text
α = (1, λ − 1)ᵀ
```

两个特征值给出两个方向，它们不成比例（因为 λ₁ ≠ λ₂），所以线性无关。

把初始向量 (1,1)ᵀ 按这两个方向拆开，各自乘 λⁿ，就得到通项：

```text
Fₙ = (λ₁ⁿ − λ₂ⁿ) / √5
```

**验算前三项：**

```text
n = 1：λ₁ − λ₂ = √5，除以 √5 得 1        ✓
n = 2：λ₁² − λ₂² = (λ₁+λ₂)(λ₁−λ₂) = 1·√5，除以 √5 得 1   ✓
n = 3：λ₁³ − λ₂³ = 2√5，除以 √5 得 2      ✓
```

第二行用到 λ₁ + λ₂ = 1，也就是"特征值之和等于迹"。

**这个公式还顺带解释了一个现象。**

|λ₂| = 0.618 < 1，所以 λ₂ⁿ 很快趋于 0。

于是

```text
Fₙ ≈ λ₁ⁿ / √5
```

斐波那契数列的增长速度，就是黄金比的 n 次方。

**这就是特征值的分量：**

它把一个"只能一项一项往下推"的递推，变成了一个闭式公式。

**用途三：判断一个方阵可不可逆。**

```text
A 可逆  ⟺  |A| ≠ 0  ⟺  所有特征值都不为 0
```

所以"0 是特征值"和"矩阵不可逆"是同一件事。

这一条在判断参数时很好用。

题目问"a 取何值时 A 不可逆"，可以翻译成"a 取何值时 0 是特征值"，也就是"a 取何值时 |A| = 0"。

两条路都行，哪条好算走哪条。

**把三个用途压成一句话：**

```text
特征值把"反复作用"变成了"乘方"，
而乘方是可以算的。
```

## 9. 常见错误

先说这些错误的共同点。它们大多不是算错，而是定义没读准，所以检查也查不出来。

**错误一：把零向量当成特征向量。**

零向量对任何 λ 都满足 Aα = λα，放进答案就是错的。

答案里必须写"k ≠ 0"或"k 不全为零"。

**错误二：以为一个特征值只对应一个特征向量。**

例 2 里 λ = −1 对应整张平面上的所有非零向量。

正确答案要写成"全部 k₂ξ₂ + k₃ξ₃"的形式，不是一个向量。

**错误三：用 |λE − A| 算到一半换成 |A − λE|。**

两者差 (−1)ⁿ，n 为奇数时符号相反。

同一道题里混用，中间验算就会对不上，白白浪费检查的机会。

**错误四：忘记 λ 可以等于 0。**

λ = 0 是完全合法的特征值。

它的含义是"存在非零向量被压成零"，等价于 |A| = 0。

**错误五：把 tr(A) 和 Σ|λ| 搞混。**

是和，不是绝对值的和。

例 2 里 8 + (−1) + (−1) = 6，如果写成 8 + 1 + 1 = 10，就对不上 tr(A) 了。

**错误六：重根只算一次。**

λ = −1 出现两次，求 Σλ 时要算两个 −1。

漏一个，验算就通不过。

**错误七：认为 A 和 Aᵀ 的特征向量相同。**

它们的特征值相同，因为特征多项式一样。

但特征向量一般不同，因为 A 和 Aᵀ 不是同一个变换。

**错误八：解 (A − λE)x = 0 时忘了 λ 已经代进去。**

写完 A − λE 就去做行变换，λ 还挂在矩阵里。

必须先代入具体的 λ 值，得到一个数字矩阵，再做行变换。

**错误九：算完不验算。**

特征值有两个免费的验算（和、积），特征向量有一个免费的验算（Aα = λα）。

三个验算都用上，错误率会降很多。

**错误十：算几何重数时用了 r(A)，而不是 r(A − λE)。**

几何重数是 n − r(A − λE)，用的是"减完 λ 以后"的那个矩阵。

拿 r(A) 去算，例 2 会得到 3 − 3 = 0，明显不合理。

**错误十一：以为复特征值说明算错了。**

实矩阵完全可能有复特征值。

只有实对称矩阵才保证全是实根。

题目没说对称，就不要因为出现复数就推翻重算。

## 10. 数一怎么考

先说这一节为什么值得单独看。因为这一篇的题，一半的分丢在"没认出考的是哪条性质"。

**题型一：求特征值与特征向量（基础题）。**

给一个具体的 2×2 或 3×3 矩阵，要求全部算出来。

按第 4 节的流程走，最后必须验算。

**答题格式要写全，否则会丢步骤分。**

```text
求特征值：写出 A − λE，写出特征多项式，写出它的根
求特征向量：写出 (A − λE)x = 0，写出基础解系，注明 k ≠ 0
```

只写最后那几行答案，解答题的过程分就没了。

**题型二：用性质求值（选择、填空高频）。**

给特征值，求 |A + kE|、tr(A*)、|A⁻¹ + E| 这类式子。

全部靠性质四和"特征值之积等于行列式"。

**题型三：已知特征向量反求参数。**

给一个矩阵含参数，又给一个特征向量，求参数。

做法：把 Aα = λα 按分量写开，得到方程组，解出参数和 λ。

**例 6** 设

```text
     ┌             ┐
     │ 2   1    1  │
A =  │ 1   2    a  │
     │ 1   a    2  │
     └             ┘
```

已知 α = (1, 1, 1)ᵀ 是 A 的特征向量，求 a 和对应的 λ。

按分量算 Aα。

第一分量：

```text
2·1 + 1·1 + 1·1 = 4
```

第二分量：

```text
1·1 + 2·1 + a·1 = 3 + a
```

第三分量：

```text
1·1 + a·1 + 2·1 = 3 + a
```

另一方面 λα 的三个分量都是 λ。

于是得到三个方程：

```text
λ = 4
3 + a = λ
3 + a = λ
```

后两个是同一式，所以条件只有两条。

由 λ = 4 代入：3 + a = 4，得

```text
a = 1
```

**验算一遍。**

a = 1 时，A 的第二、三行变成 (1, 2, 1) 和 (1, 1, 2)。

```text
第一分量：2 + 1 + 1 = 4
第二分量：1 + 2 + 1 = 4
第三分量：1 + 1 + 2 = 4
```

结果 (4,4,4) = 4·(1,1,1)。✓

所以 a = 1，λ = 4。

**这一类题的做法，只有一句话：**

```text
把 Aα = λα 按分量写开，
左边算出一个含参数的向量，右边是 λ 乘 α 的各个分量，
对应分量相等，得到方程组。
```

**注意三个分量必须同时满足。**

只对上前两个就下结论，一旦第三个对不上，说明前面的数抄错了，或者这个 α 根本不是特征向量。

题目的条件如果是"α 是特征向量"，那么三个方程一定相容；如果解出来自相矛盾，就该回头检查算得对不对。

**题型四：抽象矩阵求特征值。**

给一个矩阵方程（A² = A、A² = E、A² + A − 2E = 0 等），求特征值。

做法：把方程里的 A 换成 λ，解出 λ 的可能值，再用 tr 或 |A| 定个数。

**例 7** 设三阶矩阵 A 满足 A² + A − 2E = 0，且 |A| = 4，求 tr(A)。

把 A 换成 λ：

```text
λ² + λ − 2 = 0
(λ + 2)(λ − 1) = 0
```

λ 只能是 1 或 −2。

设三个特征值里有 k 个是 −2，3 − k 个是 1。

由 |A| = 4：

```text
(−2)ᵏ · 1³⁻ᵏ = 4
```

k = 2 时左边是 4，成立。

所以特征值是 −2、−2、1。

```text
tr(A) = −2 − 2 + 1 = −3
```

**题型五：与方程组、二次型合并。**

大题的第二问常常是"求可逆矩阵 P 使 P⁻¹AP 为对角阵"，第一问就是求特征值和特征向量。

第一问错了，第二问全错。

**复习顺序建议。**

```text
第一步：2×2 练到 30 秒出答案，靠和与积自查
第二步：3×3 练展开，重点是"先分解再展开"
第三步：练性质题，看到 |f(A)| 就直接写特征值
```

三步都熟了，这一篇的选择填空题基本不会错。

**分值分布：**

```text
选择填空：1–2 题（4–10 分）
解答题：常作为大题第一问出现
与二次型合并：10–12 分中的前半部分
```

## 11. 和其他章节怎么连

先说为什么要把接口列出来。因为特征值在这一门课里到处都是，认不出它就会重复造轮子。

**和 01 行列式。**

特征多项式就是一个行列式 |A − λE|。

三阶展开要用到按行展开，这一步在第 01 篇练过。

另外，|A| = Πλ，这条把行列式和特征值绑在一起。

**和 02、03 矩阵运算与逆。**

A⁻¹、A*、A² 的特征值，全部靠"特征向量不变"这一条推。

逆矩阵的特征值是 1/λ，前提是 λ ≠ 0。

**和 04 矩阵的秩。**

λ = 0 是特征值，等价于 |A| = 0，等价于 r(A) < n。

几何重数等于 n − r(A − λE)，这里直接用了秩。

**和 05 向量组。**

"不同特征值的特征向量线性无关"，用的是第 05 篇的定义法。

"几何重数"就是特征子空间的维数，也就是它的极大无关组的大小。

**和 06 线性方程组。**

求特征向量的动作，就是解齐次方程组

```text
(A − λE)x = 0
```

基础解系就是特征向量组的极大无关组。

所以第 06 篇的方法必须熟，否则这一篇只能停在"求特征值"。

**和 08 相似对角化。**

这是最直接的一篇。

对角化要求"n 个线性无关的特征向量"，等价于每个特征值的几何重数都等于代数重数。

本篇第 7 节那个几何重数不足的例子，就是下一篇的反面教材。

**和 09、10 二次型与正定。**

二次型 xᵀAx 化标准形，系数的正负由 A 的特征值决定。

正定等价于所有特征值都大于 0。

**一句话总结这一篇的位置：**

```text
前面几篇给出矩阵的"外形"，
这一篇给出矩阵的"内在线索"，
后面几篇用这条线索把矩阵化简成对角形。
```

### 自检三问

**第一问**：A = [[2,1],[1,2]] 的特征值是多少？对应的特征向量是什么？

答案：先算 tr(A) = 4，|A| = 4 − 1 = 3。

特征方程 λ² − 4λ + 3 = 0，即 (λ − 1)(λ − 3) = 0。

所以 λ₁ = 1，λ₂ = 3。

λ = 3 时解 (A − 3E)x = 0：

```text
│ −1   1 │
│  1  −1 │
```

即 −x₁ + x₂ = 0，x₂ = x₁。

特征向量是 k(1, 1)ᵀ，k ≠ 0。

λ = 1 时解 (A − E)x = 0：

```text
│ 1   1 │
│ 1   1 │
```

即 x₁ + x₂ = 0，x₂ = −x₁。

特征向量是 k(1, −1)ᵀ，k ≠ 0。

验算：λ₁ + λ₂ = 4 = tr(A) ✓，λ₁λ₂ = 3 = |A| ✓。

**第二问**：为什么特征向量不能是零向量？

答案：因为 A·0 = 0 = λ·0 对任何 λ 都成立。

如果允许零向量，那么每个数都会成为特征值，定义就失去了区分能力。

规定 α ≠ 0 之后，"存在非零向量使 Aα = λα"才成为一个有内容的条件。

**第三问**：已知三阶矩阵 A 的特征值是 1、2、3，|A + E| 等于多少？

答案：A + E 的特征值是 1 + 1 = 2、2 + 1 = 3、3 + 1 = 4。

三个特征值的积等于行列式：

```text
|A + E| = 2·3·4 = 24
```

注意不能用 |A| + 1 = 7 这样的算法，那是不成立的。

## 12. 小结 + 下一篇

这一篇的主线只有两个人：

```text
一个方向 α，一个倍数 λ。
```

Aα = λα 说的就是"这个方向上，矩阵退化成一个数"。

把这句定义式改写成 (A − λE)α = 0，就把"找 λ"变成了"解行列式方程"。

整个流程是一条链：

```text
Aα = λα  →  (A − λE)α = 0  →  |A − λE| = 0  →  解出 λ  →  回代求 α
```

**五个必记的结论。**

```text
1. Σλ = tr(A)
2. Πλ = |A|
3. 不同特征值的特征向量线性无关
4. f(A) 的特征值是 f(λ)
5. 1 ≤ 几何重数 ≤ 代数重数
```

**一个必会的算法。**

```text
写 A − λE → 算行列式（先分解再展开）→ 求根 → 对每个根解齐次方程组
```

**一个必防的坑。**

求特征向量时先代入 λ，再用行变换，别让 λ 留在矩阵里。
