先看一个中学就见过的东西：

```text
2x + 3y = 8
 x −  y = −1
```

怎么解？

第一个式子乘 1、第二个式子乘 2，相减消掉 x……

或者代入消元。

两行式子，两支笔，能算出来：x = 1，y = 2。

但如果有一百个未知数、一百个方程呢？

还能这样"消"吗？

能，但要换一种写法。

把所有系数排成一个方阵：

```text
┌         ┐
│ 2   3   │
│ 1  −1   │
└         ┘
```

**反直觉的点在这里：**

```text
线性代数不是"更难的计算"，
而是"换一种方式看同一件事"。
```

同一个方程组，看成矩阵以后，"消元"变成"矩阵变换"，"有没有解"变成"秩"，"解有多少个"变成"零空间维数"。

这一篇，就是把这张地图画出来。

## 1. 线性代数到底在研究什么

三个词：

```text
线性关系：变量之间只出现一次方，不出现平方、乘积、三角函数。
表示：怎么把这种关系写成一个整齐的对象（矩阵）。
结构：这些对象之间有什么规律（秩、特征值、相似）。
```

一句话：

```text
把"一堆一次方程"的事，变成"矩阵的事"。
```

## 2. 在往下读之前：六个常识

**1. 向量**

一组有序的数。

比如 (1, 2) 可以看成平面上的一个点，也可以看成一个箭头。

**2. 矩阵**

一堆数排成矩形。

```text
┌         ┐
│ 1   2   │
│ 3   4   │
└         ┘
```

**3. 转置**

把行和列对调，记作 Aᵀ。

**4. 单位矩阵**

对角线上全是 1、其余是 0 的方阵，记作 E 或 I。

它相当于数字里的 1：A·E = A。

**5. 线性组合**

把几个向量分别乘一个数，再加起来。

比如 2(1,0) + 3(0,1) = (2,3)。

**6. 秩**

一个矩阵里"真正独立的信息有几条"。

全是重复的行，秩就低。

这六个词就是整套讲解的地基。

```text
┌────────────────────────────────────────┐
│ 行列式：一个方阵"压缩成一个数"            │
├────────────────────────────────────────┤
│ 矩阵：运算、逆、初等变换、秩              │
├────────────────────────────────────────┤
│ 向量组：线性相关、极大无关组、基           │
├────────────────────────────────────────┤
│ 方程组：有没有解、有多少解、怎么表示        │

│ 特征值与二次型：矩阵的"内在方向"与"形状"    │
└────────────────────────────────────────┘
```

## 4. 第 1 块：行列式

行列式是把一个方阵"压成一个数"。

二元方程组的系数行列式：

```text
| 2   3 |
| 1  −1 | = 2×(−1) − 3×1 = −5
```

这个数不为 0，方程组就有唯一解。

所以行列式回答的是：**这个方程组"独不独立"。**

## 5. 第 2 块：矩阵

矩阵是"关系的表格"。

它有三种最重要的操作：

```text
加法：对应位置相加
乘法：行乘列（这一条最容易懵）
求逆：找一个矩阵，乘回去等于单位阵
```

矩阵乘法为什么这么怪？

因为它表示"先做一个变换，再做另一个变换"。

**两个变换接起来，就是矩阵相乘。**

## 6. 第 3 块：向量组

几个向量放在一起，要问：

```text
其中有没有"多余的"？
能不能用其他的表示出来？
```

如果有向量能被其他表示，就叫**线性相关**。

去掉多余的那些，剩下的叫**极大无关组**。

极大无关组里向量的个数，就是**秩**。

## 7. 第 4 块：方程组

一个方程组，只有三种命运：

```text
无解
唯一解
无穷多解
```

判断只看两个秩：

```text
系数矩阵的秩 r(A)
增广矩阵的秩 r(A|b)
```

```text
r(A) ≠ r(A|b) → 无解
r(A) = r(A|b) = n → 唯一解
r(A) = r(A|b) < n → 无穷多解
```

## 8. 第 5 块：特征值与二次型

有些向量，被矩阵变换之后，方向不变，只变长度：

```text
Aα = λα
```

α 是特征向量，λ 是特征值。

这个"方向不变"的性质，能用来：

```text
判断矩阵能不能对角化
把二次型化成标准形
判断正定性
```

## 9. 三张必须能画的图

### 9.1 矩阵 = 变换

```text
原始图形        变换后
  □      →     ▱
```

### 9.2 向量空间

```text
      y
      │   ● (2,3)
      │  ╱
      │ ╱
──────┼────── x
```

### 9.3 特征向量：方向不变

```text
       ╱ 变换后仍在同一条线上
      ╱
     ●─── 原来
```

## 10. 三个必算的量

### 10.1 行列式

```text
| a  b |
| c  d | = ad − bc
```

### 10.2 秩

把矩阵化成阶梯形，非零行的个数就是秩。

### 10.3 特征值

解 |A − λE| = 0。

## 11. 数一怎么考

```text
选择题、填空题：行列式计算、秩、逆、特征值性质
解答题：解方程组、相似对角化、二次型化标准形、正定判定
```

一个实用判断：

```text
线代的题，几乎都能用"秩"和"特征值"两条线串起来。
```
