> **读这篇之前，你只需要知道**：二重积分 ∬_D f dx dy 是在一块平面区域上累加；曲面可以用方程 z = z(x, y) 表示，把它投影到 xOy 平面上会得到一块平面区域；法向量是垂直于曲面的箭头，曲面上每一点都有两个相反的朝向可选。
> **这篇讲什么**：把"平面区域"换成"一张曲面"，于是有了两类曲面积分──一类只管面积，一类还要管"朝哪边"；高斯公式和斯托克斯公式再把曲面上的积分换成立体或曲线上的积分。
> **一个类比**：河边张一张渔网，问"每秒有多少水穿过网"，这时候网的方向很关键：正对着水流，穿过的水最多；平行于水流，一滴也穿不过。这就是第二类曲面积分要定向的原因。

先看一个场景。

一条河的横截面上，张了一张网。

要算：每秒有多少水穿过这张网。

```text
水流速度：v
网的面积：S
```

如果网正对着水流，一秒穿过的水量是 v·S。

如果网歪了一点呢？

穿过的水变少。

如果网和水流平行呢？

一滴也穿不过。

```text
所以"穿过多少"取决于两件事：
水的速度大小，以及网面与水流方向的夹角。
```

数学上把这个夹角写成"法向量与速度向量的内积"。

再看第二个场景。

一张弯曲的铁皮，厚度均匀，但每平方厘米的重量随位置变化。

```text
总重量 = 每一点的"面密度" × 该点附近的小块面积，全部加起来。
```

这里不需要方向，只要面积。

两个场景，两种积分：

```text
只管面积、不管方向 → 第一类曲面积分（对面积）
连着方向一起算 → 第二类曲面积分（对坐标、通量）
```

**这一篇要回答四件事：**

```text
∬_Σ 和 dS 怎么读？面积元 dS 怎么算？
第二类曲面积分的"正负"到底由什么决定？
高斯公式为什么必须"闭合 + 外侧"？
斯托克斯公式和格林公式是什么关系？
```

## 1. 为什么需要它（不给会怎样）

先说没有它会怎样。

具体卡在四个地方。

**第一处，二重积分只认"平的"区域。**

二重积分 ∬_D f(x,y) dx dy 的 D 是平面上一块区域。

```text
它算的是"平地上的累积"。
```

但现实里的东西是弯的：

```text
球面、锥面、柱面、抛物面。
```

弯面上的面积不是投影面积。

```text
一块斜放的平板，投影到地面上的面积比它本身小。
```

所以不能拿投影面积直接乘。

必须补一个"面积放大因子"。

**第二处，很多物理量必须带方向。**

```text
电通量、磁通量、热流量、流体通量。
```

这四个量的共同点：

```text
它们都是"穿过某个面"的量，而"穿过"必须区分从哪边穿到哪边。
```

没有定向，通量就没有意义。

**第三处，硬算通量要做三次投影。**

```text
∬_Σ P dy dz + Q dz dx + R dx dy
```

三个项，每一项都要单独投影到三个坐标平面上。

一张曲面要投三次，算三次，再相加。

高斯公式把这三项一次换成三重积分。

**第四处，曲线积分和曲面积分之间缺一座桥。**

第 14 篇算的是"沿边界的环量"。

如果想知道"曲面内部转得多厉害"，需要一个把两者连起来的公式。

```text
斯托克斯公式：沿边界的环量 = 曲面上旋度的通量。
```

**所以这一章的骨架是：**

```text
第一类：对面积，不管方向
第二类：对坐标，必须定向
高斯：闭合曲面 → 立体（通量 = 散度的积分）
斯托克斯：闭合曲线 → 曲面（环量 = 旋度的通量）
格林：斯托克斯在平面上的特例
```

## 2. 最小模型：第一类曲面积分 ∬_Σ f dS

没有这一节，∬_Σ 和 dS 就是念不出来的符号。

你会以为"曲面上的积分"和"平面上的积分"一样，直接 ∬ f dx dy 就行，于是在面积元上错掉一整题。

先读符号。

```text
∬_Σ    读作"在曲面 Σ（读 sigma）上的曲面积分"
f(x,y,z) 被积函数，可以是面密度、可以是 1、可以是 z
dS      读作"面积元"，是曲面上一小块的面积
```

合起来：

```text
∬_Σ f(x,y,z) dS
```

意思：

```text
把曲面 Σ 切成许多小块，每块面积 ΔS
在每块上挑一点，算出 f
相乘：f × ΔS
全部加起来，取极限
```

定义写出来：

```text
∬_Σ f dS = lim_{λ→0} Σ f(ξᵢ, ηᵢ, ζᵢ) ΔSᵢ
```

λ 是所有小块里"直径最大"的那块的直径。

**这个积分也没有方向。**

```text
曲面翻个面，取上侧还是下侧，∬_Σ f dS 不变。
```

因为 dS 是面积，面积是正的。

**它算的是什么？**

```text
f = 1 时，∬_Σ 1 dS = 曲面的面积。
f = 面密度时，∬_Σ ρ dS = 曲面薄片的质量。
f = z 时，∬_Σ z dS = 曲面关于 xOy 平面的"静矩"。
```

**怎么算？一招：投影 + 面积元。**

设曲面写成显式方程：

```text
Σ：z = z(x, y)，(x, y) ∈ D
```

那么：

```text
dS = √(1 + z_x² + z_y²) dx dy
```

其中 z_x、z_y 是 z 对 x、y 的偏导。

**为什么多这个因子？**

看一小块。

```text
在 xOy 平面上取一小块 dx dy。
它对应的曲面小块，是"斜着"的一小块。
斜着放的小块，面积总比投影大。
```

斜多少？由曲面在这个点的"倾斜程度"决定。

```text
z_x、z_y 是曲面在两个方向上的坡度。
坡度越大，同样的投影对应的真实面积越大。
```

一个特例可以验证：

```text
平面 z = ax + by + c
z_x = a，z_y = b
dS = √(1 + a² + b²) dx dy
```

a = b = 0（水平面）时 dS = dx dy，投影等于本身，对上了。

**公式四步：第一类曲面积分。**

**第一步，算什么。**

```text
在一张曲面上，把"函数值 × 小块面积"加起来。
```

**第二步，逐符号。**

```text
Σ              曲面，用方程 z = z(x,y) 给出
D              它在 xOy 平面上的投影区域
√(1+z_x²+z_y²) 面积放大因子，把 dxdy 换成 dS
f(x,y,z)       把 z 换成 z(x,y)，变成 x、y 的函数
```

写成：

```text
∬_Σ f dS = ∬_D f(x, y, z(x,y)) √(1 + z_x² + z_y²) dx dy
```

**第三步，代数字。**

Σ 是平面 x + y + z = 1 在第一卦限的部分，求 ∬_Σ (x + y + z) dS。

**第一步：曲面方程。**

```text
z = 1 - x - y
z_x = -1，z_y = -1
√(1 + 1 + 1) = √3
```

**第二步：投影区域。**

在第一卦限，x ≥ 0，y ≥ 0，x + y ≤ 1。

```text
D 是直角边长为 1 的等腰直角三角形，面积 1/2。
```

**第三步：代被积函数。**

在 Σ 上，x + y + z = 1（这就是平面方程）。

所以被积函数是常数 1。

```text
∬_Σ (x+y+z) dS = ∬_Σ 1 dS = √3 ∬_D 1 dx dy = √3 × 1/2 = √3/2
```

答案 √3/2。

**第四步：验算。**

√3/2 应该等于三角形 Σ 的面积。

三角形三个顶点是 (1,0,0)、(0,1,0)、(0,0,1)，边长都是 √2。

```text
等边三角形，边长 √2，面积 = (√3/4) × (√2)² = (√3/4) × 2 = √3/2
```

对上了。

**第四步：适用条件。**

```text
第一，曲面要能写成 z = z(x,y) 的单值显式，且在 D 上偏导连续。
第二，投影必须"一对一"：竖线穿过曲面只有一点。
第三，f 里的 z 必须换成 z(x,y)。
```

第二条是坑：球面、闭合曲面不能整体投影。

```text
上半球可以投（z 有单值表达式）。
整个球面不行，必须分成上下两半。
```

## 3. 算一遍：第一类曲面积分

不算两个曲面，面积元的因子永远只是"抄来的"。

算完你会发现，球面上那个根号往往和曲面的根号互相约掉，题目一下就轻了。

**例：上半球面。**

Σ 是上半球面 z = √(a² - x² - y²)，求 ∬_Σ z dS。

**第一步：算面积元。**

```text
z = √(a² - x² - y²)
z_x = -x / √(a² - x² - y²)
z_y = -y / √(a² - x² - y²)
```

```text
1 + z_x² + z_y² = 1 + (x² + y²)/(a² - x² - y²)
= a² / (a² - x² - y²)
```

开根号：

```text
√(1 + z_x² + z_y²) = a / √(a² - x² - y²)
```

**第二步：投影。**

上半球投到 xOy 平面，是圆 x² + y² ≤ a²。

**第三步：代入。**

在 Σ 上，z = √(a² - x² - y²)。

```text
z · dS = √(a² - x² - y²) · a/√(a² - x² - y²) dx dy = a dx dy
```

两个根号正好约掉！

```text
∬_Σ z dS = ∬_D a dx dy = a × (πa²) = πa³
```

答案 πa³。

**第四步：验算。**

上半球面积是 2πa²。

z 在半球上的平均值应该是：

```text
πa³ / (2πa²) = a/2
```

半球上 z 的平均值是 a/2，这个结论和第 13 篇"半球质心 3a/8"配套：

```text
z 的平均值 = a/2（面积平均）
质心的 z = 3a/8（体积平均）
```

两者不同，因为一个是"面上平均"，一个是"体内平均"，权重不一样。

**这个例子最值得记的一点：**

```text
球面的面积元里那个根号，和 z = √(a²-x²-y²) 的根号，正好互相约掉。
所以球面上算第一类积分，常常出奇地简单。
```

这就是"曲面和坐标匹配"的好处。

**再补一个常考的：柱面上的第一类积分。**

Σ 是圆柱面 x² + y² = a²（0 ≤ z ≤ h），求 ∬_Σ (x² + y²) dS。

柱面不能写成 z = z(x,y)，要用参数方程：

```text
x = a cosθ，y = a sinθ，z = z
θ ∈ [0, 2π]，z ∈ [0, h]
```

柱面的面积元：

```text
dS = a dθ dz
```

（理由：θ 方向走 a dθ，z 方向走 dz，两者垂直。）

被积函数在柱面上是常数：

```text
x² + y² = a²
```

所以：

```text
∬_Σ (x²+y²) dS = a² × 面积 = a² × 2πah = 2πa³h
```

**三条常用面积元，整理成一张表：**

```text
z = z(x,y)：        dS = √(1 + z_x² + z_y²) dx dy
圆柱 x²+y²=a²：      dS = a dθ dz
球面 r = a：         dS = a² sinφ dφ dθ
```

第三行来自第 13 篇的球坐标体积元，去掉 dr 就是面积元。

## 4. 第二类曲面积分：∬_Σ P dy dz + Q dz dx + R dx dy

没有这一节，通量这个概念就落不到纸面上。

你会把 dy dz 当成两个微分相乘，算出的结果差一个方向余弦，自己还不知道错在哪。

先说它和第一类的区别。

```text
第一类：∬ f dS  —— 乘"面积"
第二类：∬ P dy dz + Q dz dx + R dx dy —— 乘"投影面积"
```

读法：

```text
∬_Σ P dy dz + Q dz dx + R dx dy
读作"P 对 yOz 平面投影的积分，加 Q 对 zOx 投影的积分，加 R 对 xOy 投影的积分"。
```

**关键：dy dz 不是两个微分相乘，是"投影到 yOz 平面上的面积元"。**

这句话必须记牢。

```text
dy dz = 曲面小块在 yOz 平面上的投影面积（带符号）
dz dx = 曲面小块在 zOx 平面上的投影面积（带符号）
dx dy = 曲面小块在 xOy 平面上的投影面积（带符号）
```

用方向余弦可以统一写：

```text
dy dz = cosα dS
dz dx = cosβ dS
dx dy = cosγ dS
```

其中 (cosα, cosβ, cosγ) 是曲面在这一点**选定**的单位法向量。

**"选定"这两个字，就是第二类曲面积分的方向。**

```text
曲面有两面：上侧和下侧，外侧和内侧。
选哪一面，法向量就朝哪边，三个余弦的符号就定下来。
```

**常见定向的记法：**

```text
z = z(x,y) 的曲面：
  上侧：法向量朝上，cosγ > 0，dx dy 取正号
  下侧：法向量朝下，cosγ < 0，dx dy 取负号
```

```text
闭合曲面：
  外侧：法向量朝外（离开立体）
  内侧：法向量朝里
```

**它算的是什么？**

```text
向量场 F = (P, Q, R) 穿过曲面 Σ 的通量。
```

理由：

```text
一小块面积 dS，法向量 n。
通过它的"流量"是 F · n dS（只有法向分量穿得过去）。
而 F · n dS = P dy dz + Q dz dx + R dx dy。
```

这正是开头那个"渔网"的例子。

**怎么算？合一投影法。**

对 dx dy 这一项：

```text
∬_Σ R dx dy = ± ∬_D R(x, y, z(x,y)) dx dy
```

符号由"上侧取正、下侧取负"决定。

对 dy dz、dz dx 两项，要么投影到另外两个平面，要么用"合一投影"：

```text
∬_Σ P dy dz + Q dz dx + R dx dy
= ± ∬_D [ -P z_x - Q z_y + R ] dx dy
```

（上侧取正，下侧取负。）

这个式子把三项合成一次投影，考试里最省时间。

**公式四步：第二类曲面积分。**

**第一步，算什么。**

```text
向量场穿过一张有向曲面的通量。
```

**第二步，逐符号。**

```text
P、Q、R     三个分量
dy dz 等    投影面积元，不是微分乘积
±           曲面的定向，上侧正、下侧负
z_x、z_y    曲面方程的偏导（用合一投影时出现）
```

**第三步，代数字。**

Σ 是上半球面 z = √(a²-x²-y²)，取上侧，求 ∬_Σ z dx dy。

用合一投影，只有 R = z 这一项：

```text
∬_Σ z dx dy = + ∬_D z(x,y) dx dy
```

在 Σ 上 z = √(a²-x²-y²)，投影 D 是圆 x²+y² ≤ a²。

用极坐标：

```text
∬_D √(a²-ρ²) ρ dρ dθ = 2π ∫₀^a √(a²-ρ²) ρ dρ
```

令 u = a² - ρ²，du = -2ρ dρ：

```text
∫₀^a √(a²-ρ²) ρ dρ = (1/2) ∫₀^{a²} √u du = (1/2) · (2/3) a³ = a³/3
```

所以：

```text
∬_Σ z dx dy = 2π · a³/3 = 2πa³/3
```

答案 2πa³/3。

**第四步：验算。**

如果取**下侧**，答案就是 -2πa³/3。

```text
定向往返一次，符号必翻。
```

**第四步：适用条件。**

```text
第一，曲面必须有明确的定向（题目会说"上侧""外侧"）。
第二，用合一投影时，曲面要能写成 z = z(x,y)。
第三，投影要一对一；闭合曲面必须拆成几片分别算。
```

## 5. 两类曲面积分怎么换算

不弄懂换算，两类积分会变成两套互不相干的公式。

而考试里最常见的一步，正是"用方向余弦把第二类变成第一类"。

和曲线积分类似，换算靠方向余弦。

```text
∬_Σ P dy dz + Q dz dx + R dx dy = ∬_Σ (P cosα + Q cosβ + R cosγ) dS
```

读法：

```text
右边是"向量场在法向量方向上的投影"乘面积元，
也就是法向分量在曲面上的第一类积分。
```

**这个式子的意思是：**

```text
第二类积分 = 先投影到法方向，再按面积累加。
```

和曲线积分的换算完全同构：

```text
曲线：P dx + Q dy = (P cosα + Q cosβ) ds
曲面：P dy dz + … = (P cosα + Q cosβ + R cosγ) dS
```

曲线用切向量，曲面用法向量。

**一个具体例子。**

Σ 是平面 x + y + z = 1 的第一卦限部分，取上侧。

求 ∬_Σ x dy dz + y dz dx + z dx dy。

**用换算：**

平面的法向量是 (1,1,1)，单位化后：

```text
(cosα, cosβ, cosγ) = (1/√3, 1/√3, 1/√3)
```

所以：

```text
被积函数 = (x + y + z)/√3 = 1/√3（在 Σ 上 x+y+z=1）
```

而 dS 的积分就是曲面面积：

```text
∬_Σ dS = √3/2（第 2 节算过）
```

答案：

```text
∬_Σ = (1/√3) × (√3/2) = 1/2
```

**用合一投影验算：**

z = 1 - x - y，z_x = z_y = -1。

```text
被积式子 = -P z_x - Q z_y + R = -x(-1) - y(-1) + z = x + y + z = 1
```

```text
∬ = ∬_D 1 dx dy = 1/2
```

一致。

**这个例子说明：**

```text
当被积表达式在曲面上刚好是常数时，两种方法都很快。
选哪种，看你更熟悉哪个公式。
```

## 6. 高斯公式：闭合曲面换成三重积分

先说没有它会怎样。

```text
要算 ∬_Σ x³ dy dz + y³ dz dx + z³ dx dy，Σ 是整个球面。
```

直接算要投三次，每次都是一个带根号的二重积分。

高斯公式一行解决。

**公式：**

```text
∬_Σ P dy dz + Q dz dx + R dx dy = ∭_Ω ( ∂P/∂x + ∂Q/∂y + ∂R/∂z ) dV
```

读法：

```text
"穿过闭合曲面的通量，等于曲面内部每一点的散度之和。"
```

**逐符号：**

```text
Σ        闭合曲面（围成一个立体的外表面）
Ω        Σ 围成的立体
外侧      Σ 的定向，法向量指向立体外部
∂P/∂x + ∂Q/∂y + ∂R/∂z   散度，衡量"这一点是源还是汇"
```

**四步：**

**第一步，算什么。**

```text
把"穿过边界的总流量"换成"内部每一点的发散程度之和"。
```

**第二步，逐符号。**

```text
散度 > 0：这一点往外冒（源）
散度 < 0：这一点往里吸（汇）
散度 = 0：不冒不吸，进出平衡
```

**第三步，代数字。**

Σ 是球面 x² + y² + z² = a²，取外侧。

求 ∬_Σ x³ dy dz + y³ dz dx + z³ dx dy。

算散度：

```text
P = x³ → ∂P/∂x = 3x²
Q = y³ → ∂Q/∂y = 3y²
R = z³ → ∂R/∂z = 3z²
散度 = 3(x² + y² + z²)
```

所以：

```text
∬_Σ = ∭_Ω 3(x²+y²+z²) dV
```

用球坐标：

```text
= 3 ∫₀^{2π} dθ ∫₀^{π} sinφ dφ ∫₀^a r² · r² dr
= 3 × 2π × 2 × a⁵/5
= 12πa⁵/5
```

答案 12πa⁵/5。

**第四步：适用条件（三条）。**

```text
第一，Σ 必须是闭合曲面。
第二，Σ 必须取外侧。
第三，P、Q、R 在 Ω 上有一阶连续偏导（Ω 内不能有奇点）。
```

**为什么必须"外侧"？**

因为散度定理的"源"是从里面往外冒的。

法向量朝外，通量为正，才对应"冒出来"。

```text
如果取内侧，通量全部反号，公式右端要加负号。
```

**为什么必须"闭合"？**

因为公式说的是"边界的通量 = 内部的散度"。

不闭合的曲面没有"内部"，等式无从谈起。

```text
补救办法：补面。这是下一节的内容。
```

**再看一个"散度为 0"的例子。**

Σ 是任意闭合曲面，F = (x, y, z) 换成 F = (-y, x, 0)。

```text
P = -y → ∂P/∂x = 0
Q = x  → ∂Q/∂y = 0
R = 0  → ∂R/∂z = 0
散度 = 0
```

所以：

```text
∬_Σ (-y) dy dz + x dz dx = ∭ 0 dV = 0
```

**这个结果值得琢磨：**

```text
场 (-y, x, 0) 是"绕 z 轴旋转"的场，它只在转，不往外冒。
所以穿过任何闭合曲面的净通量都是 0。
```

它有旋度，没有散度。

**再看一个"散度是常数"的例子，可以拿来验算。**

Σ 是球面 x² + y² + z² = a²，外侧，求 ∬_Σ x dy dz + y dz dx + z dx dy。

散度：

```text
∂x/∂x + ∂y/∂y + ∂z/∂z = 1 + 1 + 1 = 3
```

```text
∬_Σ = ∭_Ω 3 dV = 3 × (4πa³/3) = 4πa³
```

**直接验算：**

在球面上，单位外法向量正好是 (x, y, z)/a。

```text
F · n = (x, y, z) · (x, y, z)/a = (x² + y² + z²)/a = a
```

所以通量 = a × 球面积 = a × 4πa² = 4πa³。

一致。

**这个验算值得记住，因为它只用了几何：**

```text
球面上，径向场的法向分量恒等于 a。
所以"穿过整个球面的通量"就是一个常数乘面积。
```

## 7. 补面法：不闭合怎么补

不学补面，高斯公式就只能在"题目刚好给闭合曲面"时用一次。

而真题里给的大多是不闭合的曲面。

这是数一最爱考的技巧。

**思路：**

```text
题目给的曲面不闭合，直接算很难。
补一块简单的面，凑成一个闭合曲面。
对闭合曲面用高斯公式，算出总数。
再减掉补的那一块。
```

公式化：

```text
∬_{Σ} = ∬_{Σ + Σ₁} - ∬_{Σ₁} = ∭_Ω 散度 dV - ∬_{Σ₁}
```

**关键两点：**

```text
补的面要简单：平面片最好，因为它的法向量是常数。
补完之后，Σ 和 Σ₁ 的定向要一起构成"外侧"。
```

**例：上半球面的通量。**

Σ 是上半球面 z = √(a²-x²-y²)，取上侧。

求 ∬_Σ x dy dz + y dz dx + z dx dy。

**第一步，判断。**

Σ 是开口的（只有上半球），不闭合。

补上底面：圆盘 D：x² + y² ≤ a²，z = 0，取下侧。

为什么取下侧？

```text
因为这个圆盘是"立体的底"，外侧方向朝下。
```

**第二步，用高斯。**

Σ + Σ₁ 围成上半球体 Ω，取外侧。

```text
散度 = 1 + 1 + 1 = 3
∬_{Σ+Σ₁} = ∭_Ω 3 dV = 3 × (2πa³/3) = 2πa³
```

**第三步，算补的那一块。**

在圆盘上，z = 0，法向量朝下，所以：

```text
∬_{Σ₁} x dy dz + y dz dx + z dx dy
```

圆盘是水平面，法向量是 (0,0,-1)，所以只有 dx dy 项非零：

```text
= ∬_D z dx dy = ∬_D 0 dx dy = 0
```

（圆盘上 z 恒为 0。）

**第四步，相减。**

```text
∬_Σ = 2πa³ - 0 = 2πa³
```

答案 2πa³。

**这个例子里，补的那块贡献是 0。**

不是每次都是 0。

看下一个。

**例：锥面的通量（补的块不为 0）。**

Σ 是锥面 z = √(x²+y²) 被 z = 1 截下的部分，取**下侧**（法向量指向 z 轴）。

求 ∬_Σ z dx dy。

**第一步，补面。**

补圆盘 D₁：x² + y² ≤ 1，z = 1，取上侧。

这样 Σ（下侧）+ D₁（上侧）围成"锥体"：√(x²+y²) ≤ z ≤ 1，取外侧。

**第二步，用高斯。**

只有 R = z 这一项，散度 = 1。

锥体体积：

```text
V = ∫₀^{2π} dθ ∫₀¹ ρ dρ ∫_ρ¹ dz = 2π ∫₀¹ ρ(1-ρ) dρ = 2π(1/2 - 1/3) = π/3
```

```text
∬_{Σ+D₁} z dx dy = ∭ 1 dV = π/3
```

**第三步，算补的圆盘。**

D₁ 上 z = 1，法向朝上，dx dy 取正号：

```text
∬_{D₁} z dx dy = ∬_{D₁} 1 dx dy = π × 1² = π
```

**第四步，相减。**

```text
∬_Σ = π/3 - π = -2π/3
```

答案 -2π/3。

**负号对不对？**

对。

```text
Σ 取的是下侧，法向量朝下，而 z 在锥面上是正的。
被积函数 R = z > 0，法向的 z 分量 < 0，所以通量是负的。
```

**直接验算：**

锥面 z = ρ，投影 D：ρ ≤ 1。

合一投影，下侧取负号：

```text
∬_Σ z dx dy = - ∬_D ρ dx dy = - 2π ∫₀¹ ρ · ρ dρ = -2π/3
```

一致。

**这个对比说明补面法的两个要点：**

```text
第一，补的块往往不为 0，必须老实算。
第二，符号由"外侧"决定，补的面必须和原曲面共同构成外侧。
```

**常见的补面选择：**

```text
上半球面 → 补底面圆盘 z = 0
锥面 → 补顶面圆盘 z = h
柱面 → 补上下两个圆盘
不闭合的立方体表面 → 补缺的那几个面
```

**还有一个高阶技巧：挖洞。**

如果被积函数在立体内部有奇点（比如分母带 r²），不能直接用高斯。

```text
做法：在奇点周围挖一个小球，在大立体和小球之间的区域用高斯公式。
```

例：

```text
∬_Σ (x dy dz + y dz dx + z dx dy)/r³，Σ 是包围原点任意闭合曲面，取外侧。
```

散度在原点以外处处为 0。

挖一个小球面 Σ_ε，得到：

```text
∬_Σ = ∬_{Σ_ε} = 4π（在小球上直接算，r = ε）
```

**这个 4π 是"高斯定律"的数学原型，和 ε 无关。**

（第 14 篇的 2π 是它的二维版本。）

## 8. 斯托克斯公式：闭合曲线换成曲面积分

先说没有它会怎样。

```text
要算 ∮_Γ z dx + x dy + y dz，Γ 是空间中的一条闭合曲线。
```

直接参数化 Γ，可能要分段，而且 z 也得写成参数形式。

斯托克斯公式把它换成"以 Γ 为边界的一张曲面上的积分"。

**公式：**

```text
∮_Γ P dx + Q dy + R dz = ∬_Σ ( ∂R/∂y - ∂Q/∂z ) dy dz
                        + ( ∂P/∂z - ∂R/∂x ) dz dx
                        + ( ∂Q/∂x - ∂P/∂y ) dx dy
```

读法：

```text
"沿闭合曲线 Γ 的环量，等于以 Γ 为边界的一张曲面 Σ 上旋度的通量。"
```

**逐符号：**

```text
Γ        空间闭合曲线（分段光滑）
Σ        以 Γ 为边界的曲面（可以任选，越简单越好）
旋度     括号里那三个组合，合起来是一个向量
方向      Γ 的方向与 Σ 的法向量要满足"右手法则"
```

**右手法则：**

```text
右手四指沿 Γ 的方向弯曲，拇指指向就是 Σ 的法向量方向。
```

或者换个说法：

```text
沿着 Σ 的法向量看下去，Γ 是逆时针的。
```

**四步：**

**第一步，算什么。**

```text
把"沿边界的环量"换成"曲面上旋度的通量"。
```

**第二步，逐符号。**

```text
∂R/∂y - ∂Q/∂z  旋度的 x 分量
∂P/∂z - ∂R/∂x  旋度的 y 分量
∂Q/∂x - ∂P/∂y  旋度的 z 分量
```

**第三步，代数字。**

Γ 是圆 x² + y² = a²，z = 0，从 z 轴正向看是逆时针。

求 ∮_Γ z dx + x dy + y dz。

**选曲面。**

取 Γ 围成的平面圆盘：z = 0，x² + y² ≤ a²，法向量朝上 (0,0,1)。

右手法则验证：从 +z 往下看，Γ 逆时针，拇指朝上，一致。

**算旋度。**

```text
P = z，Q = x，R = y
∂R/∂y - ∂Q/∂z = 1 - 0 = 1
∂P/∂z - ∂R/∂x = 1 - 0 = 1
∂Q/∂x - ∂P/∂y = 1 - 0 = 1
旋度 = (1, 1, 1)
```

**算通量。**

圆盘法向量 (0,0,1)，所以：

```text
∬_Σ (1,1,1)·(0,0,1) dS = ∬_Σ 1 dS = 圆盘面积 = πa²
```

答案 πa²。

**第四步：直接验算。**

```text
x = a cosθ，y = a sinθ，z = 0
dx = -a sinθ dθ，dy = a cosθ dθ，dz = 0
```

```text
z dx + x dy + y dz = 0 + a cosθ · a cosθ dθ + 0 = a² cos²θ dθ
```

```text
∮ = ∫₀^{2π} a² cos²θ dθ = a² · π = πa²
```

一致。

**第四步：适用条件。**

```text
第一，Γ 必须闭合。
第二，Σ 以 Γ 为边界，且 Γ 的方向与 Σ 的法向量满足右手法则。
第三，P、Q、R 在包含 Σ 的空间区域上有一阶连续偏导。
```

**换一张曲面，结果一样吗？**

一样。

```text
只要这些曲面都以同一条 Γ 为边界，且定向都满足右手法则，
通量就相同。
```

原因：

```text
两张曲面拼成一个闭合曲面，
旋度的通量在闭合曲面上是 0（因为"边界无边界"）。
所以两张曲面的通量相等。
```

**这条性质很实用：**

```text
选曲面时，挑最好算的。
圆盘、三角形、平面片，哪个投影简单选哪个。
```

## 9. 三大公式的统一：边界与内部

不把三个公式摆到一起看，你会背三套互相干扰的符号。

摆到一起才发现，它们说的是同一句话。

到现在为止，出现了三个公式。

```text
格林：    ∮_L P dx + Q dy = ∬_D (∂Q/∂x - ∂P/∂y) dx dy
高斯：    ∬_Σ P dy dz + Q dz dx + R dx dy = ∭_Ω (散度) dV
斯托克斯：∮_Γ P dx + Q dy + R dz = ∬_Σ (旋度)·n dS
```

**共同结构只有一句话：**

```text
边界上的积分 = 内部的导数之和。
```

```text
格林：边界是一维的曲线，内部是二维的区域。
高斯：边界是二维的曲面，内部是三维的立体。
斯托克斯：边界是一维的空间曲线，内部是二维的曲面。
```

**它们的关系：**

```text
格林公式 = 斯托克斯公式的平面特例（Σ 取成平面区域，R = 0）。
```

验证：

斯托克斯里取 R = 0，Σ 是平面区域 D，法向量 (0,0,1)：

```text
∮_L P dx + Q dy = ∬_D (∂Q/∂x - ∂P/∂y) dx dy
```

正是格林公式。

```text
高斯公式 = 格林公式的三维推广（把"降一维"从 3→2 变成 2→1 的思路搬到 3→2）。
```

**三个公式的"物理读法"：**

```text
格林：绕一圈的环量 = 圈里每一点的旋转加起来。
高斯：穿出去的总流量 = 里头每一点冒出多少加起来。
斯托克斯：绕一圈的环量 = 圈住的面上旋转加起来。
```

**一个漂亮的推论：**

```text
任何闭合曲面上，旋度场的通量都是 0。
```

因为：

```text
闭合曲面没有边界，
所以 ∬_Σ (旋度)·n dS = ∮_{∂Σ} = ∮_∅ = 0。
```

同理：

```text
任何闭合曲线上，梯度场的环量都是 0。
```

因为梯度是"有势"的，势函数绕一圈回到原点，差值是 0。

```text
∮_Γ ∇u · τ ds = u(终点) - u(起点) = 0（闭合时终点 = 起点）
```

这两条"边界无边界"的结论，是三大公式的灵魂。

**一个帮助记忆的图像：旋度和散度分别长什么样。**

散度，想的是一口泉眼。

```text
泉眼往外冒水：散度 > 0。
下水口往里吸：散度 < 0。
水只是流过、不冒不吸：散度 = 0。
```

```text
所以散度问的是"这一点是源还是汇"，对应"闭合曲面上的净通量"。
```

旋度，想的是放进水里的一架小风车。

```text
风车被水推着转 → 这一点的旋度不为 0，转得越快旋度越大。
风车不转 → 旋度为 0。
```

```text
所以旋度问的是"水在这一点绕着转得多厉害"，对应"闭合曲线上的环量"。
```

两个图像合起来，就是三大公式的物理意义：

```text
格林 / 斯托克斯：环量 = 圈住的曲面内"小风车转速"之和。
高斯：净流量 = 围住的立体里"泉眼和下水口"之和。
```

考场上记不住公式的符号时，回到这两个图像：

```text
问的是"转"还是"冒"？转 → 环量 → 曲线或旋度；冒 → 通量 → 曲面或散度。
```

## 10. 常见错误

不列一份清单，这一章会有四处反复失分：面积元、定向、闭合、奇点。

**错误一：把 dy dz 当成 dy 乘 dz。**

```text
它是"投影面积元"，不是两个微分的乘积。
```

后果：

```text
如果按乘积理解，会漏掉投影因子，结果差一个方向余弦。
```

**错误二：第一类忘了面积元因子。**

```text
错：∬_Σ f dS = ∬_D f dx dy
对：∬_Σ f dS = ∬_D f √(1+z_x²+z_y²) dx dy
```

检查方法：用 f = 1 算曲面面积，和几何公式对。

**错误三：第二类忘了定向的符号。**

```text
上侧取正、下侧取负；外侧取正、内侧取负。
```

题目说"下侧"，答案就要带负号。

**错误四：用高斯公式却忘了闭合。**

```text
Σ 是开口的，直接写 ∬_Σ = ∭_Ω。
```

必须先补面，再减掉补的部分。

**错误五：补面后忘记相减。**

```text
算出 ∭ 就当成答案，忘了减 ∬_{补的面}。
```

**错误六：补的面取向错了。**

```text
补的面必须和原曲面共同构成"外侧"。
```

上半球的底面，外侧朝下，不是朝上。

**错误七：有奇点还用高斯。**

```text
被积函数在 Ω 里有分母为零的点（比如 r³ 在原点），
散度公式用不了。
```

处理：挖小球。

**错误八：斯托克斯的方向搞错。**

```text
Γ 的方向与 Σ 的法向量必须满足右手法则。
```

搞反了，答案差一个负号。

**错误九：把闭合曲面当成"不能投影"。**

```text
闭合曲面确实不能整体投影，但可以拆成上下两片分别算。
```

球面 = 上半球 + 下半球，这是最常用的拆法。

**错误十：第一类用对称性，第二类也照搬。**

```text
第一类没有方向，可以放心用奇偶性。
第二类有方向，法向量一变，符号就变，不能照搬。
```

## 11. 数一怎么考

不知道考法，你会把时间花在推导公式上。

而这一章的分数，几乎全落在"补面 + 高斯"这一条链上。

**题型一：第一类曲面积分。**

投影 + 面积元 + 二重积分。

难点在面积元的根号能不能化简，所以要认熟三种曲面：

```text
平面、球面、柱面。
```

**题型二：第二类曲面积分（合一投影）。**

```text
∬_Σ P dy dz + Q dz dx + R dx dy = ± ∬_D (-P z_x - Q z_y + R) dx dy
```

一步到位，适合曲面有显式方程时。

**题型三：高斯公式（主力）。**

大多数年份都有。

判断流程：

```text
一、Σ 闭合吗？不闭合 → 补面。
二、定向对吗？外侧。
三、有奇点吗？有 → 挖球。
四、算散度，算三重积分。
五、减掉补的部分。
```

**题型四：斯托克斯公式。**

题目给空间闭曲线，要求环量。

```text
选一张好算的曲面，算旋度，投影。
```

**题型五：用高斯公式求"散度为 0"的结论。**

```text
证明某个通量与曲面形状无关。
```

这类题考的是理解，不是计算。

**题型六：与三重积分结合。**

高斯公式把曲面积分变成三重积分，于是第 13 篇的所有技巧都能用：

```text
球坐标、柱坐标、对称性、截面法。
```

**一道数一风格的完整题。**

```text
Σ 是上半球面 z = √(a²-x²-y²) 与平面 z = 0 围成的闭合曲面的外侧，
求 ∬_Σ (x³ dy dz + y³ dz dx + z³ dx dy)。
```

注意：这里的 Σ 是**闭合**曲面（上半球 + 底面），不是只有球面。

**第一步，判断。**

闭合、外侧、无奇点。

可以直接用高斯。

**第二步，算散度。**

```text
散度 = 3x² + 3y² + 3z² = 3r²
```

**第三步，算三重积分。**

Ω 是上半球体，用球坐标：

```text
∭ 3r² dV = 3 ∫₀^{2π} dθ ∫₀^{π/2} sinφ dφ ∫₀^a r² · r² dr
= 3 × 2π × 1 × a⁵/5
= 6πa⁵/5
```

（中间 ∫₀^{π/2} sinφ dφ = 1。）

**答案 6πa⁵/5。**

**如果题目只给上半球面（不闭合）呢？**

那就补底面，用高斯算出 6πa⁵/5，再减掉底面的贡献。

底面上 z = 0，法向朝下，只有 z³ 项相关：

```text
∬_{底面} z³ dx dy = ∬ 0 dx dy = 0
```

所以：

```text
上半球面的通量 = 6πa⁵/5 - 0 = 6πa⁵/5
```

和闭合曲面一样。

**为什么？**

```text
因为底面的贡献是 0。
所以"闭合"与"只算球面"，在这道题里答案相同。
```

这种情况要能看出来，不然会白补一次面。

**判断方法：**

```text
看补的面上，被积表达式是不是恒为 0。
是 → 补面只是为了合法用高斯，答案不变。
不是 → 必须老实相减。
```

## 12. 和其他章节怎么连

不接回其他章节，高斯公式就只是一个"要用三重积分"的黑箱。

其实右端就是第 13 篇练过的三种坐标，左端就是第 14 篇的曲线积分推广。

**往回连：12 二重积分。**

第一类曲面积分投影之后，就是一个二重积分。

```text
∬_Σ f dS = ∬_D f √(1+z_x²+z_y²) dx dy
```

所以二重积分不熟，这一章一定卡。

**往回连：13 三重积分。**

高斯公式的右端是三重积分。

```text
球坐标、柱坐标、截面法，全部会用上。
```

第 13 篇练的那三套坐标，就是为这一刻准备的。

**往回连：14 曲线积分。**

格林公式是斯托克斯的平面版。

```text
∮_L P dx + Q dy = ∬_D (∂Q/∂x - ∂P/∂y) dx dy
```

把这一篇的斯托克斯公式取 R = 0，就退回格林。

**往前连：16 数项级数。**

看起来没关系，其实有两条线。

第一条：通量的级数展开（物理里常见，数一不考）。

第二条：更实际的——曲面积分算出来的结果常常带 π，而级数里 Σ1/n² = π²/6 这类结论也来自"积分与求和互换"。

```text
两者的共同工具是"先算有限和，再取极限"。
```

**横向连：11 全微分与多元微分。**

散度和旋度都是偏导的组合。

```text
散度 = P_x + Q_y + R_z（一个数）
旋度 = (R_y - Q_z, P_z - R_x, Q_x - P_y)（一个向量）
```

记不住旋度的三个分量时，用行列式：

```text
        | i   j   k  |
旋度 =  | ∂/∂x ∂/∂y ∂/∂z |
        | P   Q   R  |
```

按第一行展开，就是那三个组合。

**横向连：21 空间解析几何。**

曲面的方程决定了用哪种面积元：

```text
z = z(x,y) → √(1+z_x²+z_y²)
柱面 → a dθ dz
球面 → a² sinφ dφ dθ
```

认不出曲面，就选不出面积元。

### 自检三问

**第一问：第一类和第二类曲面积分的本质区别是什么？**

区别在"乘的是什么"。

第一类乘 dS，是真实面积，永远为正，所以没有方向。

第二类乘 dy dz、dz dx、dx dy，是投影面积，带正负，所以必须定向。

```text
第二类 = 第一类 × 法向量的方向余弦。
```

一句话：

```text
第一类问"这张面有多大、上面有多少东西"，
第二类问"有多少东西穿过了这张面、朝哪边穿"。
```

**第二问：高斯公式为什么要求"闭合 + 外侧"？**

两个条件各管一件事。

"闭合"保证有"内部"，散度才有地方积。

```text
不闭合就没有 Ω，公式右端写不出来。
```

"外侧"保证符号约定一致。

```text
散度衡量"往外冒"，
法向量朝外，通量为正，才和"冒出来"对应。
取内侧，所有通量反号。
```

两个条件缺一，公式要么用不了，要么符号错。

**第三问：三大公式能不能统一成一句话？**

能。

```text
边界上的积分 = 内部的导数之和。
```

具体三句：

```text
格林：一圈的环量 = 圈里的旋转。
高斯：一层的流量 = 层里的发散。
斯托克斯：一圈的环量 = 圈住的曲面上的旋转。
```

它们的共同来源是一个更抽象的事实：

```text
边界的边界是空的。
```

所以"对边界再取一次边界"得到 0，这就解释了为什么"旋度的通量在闭曲面上是 0"、"梯度的环量在闭曲线上是 0"。

## 13. 小结 + 下一篇

没有小结，三个公式会在脑子里打架，符号互相污染。

压成一张卡片：

```text
第一类：∬_Σ f dS，无方向，dS = √(1+z_x²+z_y²) dx dy
第二类：∬_Σ P dy dz + Q dz dx + R dx dy，有方向
换算：  = ∬_Σ (P cosα + Q cosβ + R cosγ) dS
高斯：  ∬_Σ (闭合、外侧) = ∭_Ω (P_x + Q_y + R_z) dV
补面：  ∬_Σ = ∭_Ω 散度 - ∬_{补的面}
斯托克斯：∮_Γ = ∬_Σ (旋度)·n dS
统一：  边界上的积分 = 内部的导数之和
```

四步公式的统一形态：

```text
算什么 → 在一张曲面上做累积（带不带方向）
逐符号 → ∬_Σ、dS 或 dy dz、法向量、定向
代数字 → 投影，或补面用高斯
适用条件 → 显式方程、闭合、外侧、无奇点
```

考场上的判断顺序：

```text
一、看微元：dS 还是 dy dz？
二、看闭合：闭合 → 高斯；开口 → 补面或直接投影
三、看定向：上侧/下侧、外侧/内侧，先定符号
四、看奇点：分母含 r³ 且区域含原点 → 挖球
五、看曲线：空间闭曲线 → 斯托克斯
```

三句提醒。

```text
第一句：dS 的根号、定向的符号，这两处错了整题白做。
第二句：补面之后一定要减，剪掉的那块常常不是 0。
第三句：高斯算完用体积或量级验一下，通量不该大得离谱。
```

下一篇换一个完全不同的方向。

```text
前面十二篇都在"算积分"，区域是区间、平面、立体、曲线、曲面。
下一篇开始"无限相加"，区域变成了一列数。
```

问题变成：

```text
高等数学系统讲解 16：数项级数
```

那一篇会回答：

```text
无限个数加起来，凭什么会有有限的结果？
Σuₙ 收敛还是发散，怎么一眼判断？
比较、比值、根值，三个判别法该怎么选？
交错级数为什么只要"越来越小、趋于 0"就收敛？
```
