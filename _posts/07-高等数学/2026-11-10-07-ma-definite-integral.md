> **读这篇之前，你只需要知道**：不定积分是"已知导数求原函数"，结果带一个任意常数 C；极限是"让某个量趋近于某个值，看另一个量趋向哪里"；求和符号 Σ 表示"很多项相加"。
> **这篇讲什么**：把曲线下的面积切成无数个细条再全部加起来，这个和的极限叫定积分，而它居然能用一个原函数在两端点相减算出来。
> **一个类比**：想知道一片不规则地的面积，把它切成很多窄条，每条近似当长方形算，条越窄总和越准；定积分就是这个"切到无穷细再相加"的极限。

先看一个算不出来的面积。

```text
求曲线 y = x²、横轴、直线 x = 0、直线 x = 1 围成的面积。
```

这是个曲边三角形。

它没有现成的面积公式。

矩形有，三角形有，圆有，抛物线围出来的这块没有。

两千多年前，阿基米德用一种笨办法逼近它：往里面塞三角形，塞得越多越接近。

这个方法的思想，就是这一篇的全部内容。

```text
把不会算的东西，切成很多"会算的小块"，加起来，再让块数趋于无穷。
```

## 1. 为什么需要它（不给会怎样）

没有定积分，你会卡在四个地方。

**第一，面积、体积、弧长全部无从下手。**

圆的面积 πR² 是怎么来的？

中学是直接给的公式，到了大学要能推。

推的办法就是定积分：把圆切成无数个扇形或细条，加起来。

**第二，物理里的"累积量"算不出来。**

```text
变力做功：力在变，W = ∫ F(x) dx
变速运动的位移：速度在变，s = ∫ v(t) dt
不均匀细杆的质量：密度在变，m = ∫ ρ(x) dx
水压力：深度在变，P = ∫ ρg·h·w dh
```

这些量的共同点是：每一小段上的"变化率"不同，只能靠累加。

**第三，概率论要用。**

连续型随机变量的概率是密度函数的积分。

数一虽然不考概率的积分技巧，但正态分布的式子处处是积分。

**第四，它是不定积分的"用途"。**

上一篇学了怎么找原函数，这一篇回答"找来干什么用"。

答案是：

```text
原函数在两端点的差，就是曲线下的面积。
```

这个结论叫牛顿-莱布尼茨公式，是整门课最重要的一个公式。

顺带说清它在数一里的位置。

```text
定积分是"计算题的中转站"：
一元积分学（07、08、09）靠它，
二重积分（12）化成累次积分靠它，
曲线曲面积分（14、15）也靠它，
甚至级数（16）的判敛都拿它当尺子。
```

所以这一篇如果只学一个公式，就学 N-L；只学一个技巧，就学变上限求导。

这两个东西在后面每一章都会再出现一次。

## 2. 最小模型：四步定义

定积分不是"算面积"的同义词，它是一个**极限**。

先把它定义清楚。

**第一步，分割。**

把区间 [a, b] 插进 n - 1 个分点：

```text
a = x₀ < x₁ < x₂ < … < xₙ = b
```

每一小段的长度记作 Δxᵢ = xᵢ - xᵢ₋₁。

**第二步，近似。**

在每一小段 [xᵢ₋₁, xᵢ] 上任取一点 ξᵢ（读"xi"，希腊字母），用矩形代替那一条曲边：

```text
第 i 条的面积 ≈ f(ξᵢ) · Δxᵢ
```

**第三步，求和。**

n 条加起来：

```text
Sₙ = Σ(i=1 到 n) f(ξᵢ) Δxᵢ
```

这个和叫黎曼和（Riemann sum）。

**第四步，取极限。**

令 λ 是所有小段里最长的那一段长度：

```text
λ = max{Δx₁, Δx₂, …, Δxₙ}
```

让 λ → 0（等价于 n → ∞ 且每段都变短），如果 Sₙ 的极限存在且与分法、与 ξᵢ 的取法都无关，就称 f 在 [a, b] 上可积，把这个极限记作：

```text
∫ₐᵇ f(x) dx
```

**逐符号读一遍：**

**∫**：积分号，拉长的 S，提醒你这是"求和"。

**a**：积分下限，区间的左端点。

**b**：积分上限，区间的右端点。

**f(x)**：被积函数。

**dx**：读"d x"，表示积分变量是 x，同时是"无穷小的宽度"。

在极限过程里，Δxᵢ 变成了 dx，Σ 变成了 ∫，这就是记号的全部含义。

```text
Σ f(ξᵢ) Δxᵢ   ──(取极限)──→   ∫ₐᵇ f(x) dx
```

记号上的一个区别要看清：

```text
∫ f(x) dx        不定积分，结果是一族函数，带 +C
∫ₐᵇ f(x) dx      定积分，结果是一个数，不带 C
```

多出来的上下限，不只是装饰，它把"一族函数"定格成了"一个数值"。

**定积分是一个数。**

不是函数，不是一族函数，是一个确定的实数。

这一点和不定积分区别最大：不定积分的结果带 C，定积分的结果不带。

**几何意义：带符号的面积。**

```text
f(x) ≥ 0 的部分，积分算正面积
f(x) < 0 的部分，积分算负面积
∫ₐᵇ f(x) dx = 上方面积 - 下方面积
```

所以"定积分等于面积"这句话不严谨，正确说法是"定积分等于代数和面积"。

**用定义算一个。**

算 ∫₀¹ x² dx。

等分区间，取 ξᵢ 为每段右端点：

```text
Δxᵢ = 1/n，ξᵢ = i/n
Sₙ = Σ(i=1 到 n) (i/n)² · (1/n) = (1/n³) Σ(i=1 到 n) i²
```

用平方和公式 Σi² = n(n+1)(2n+1)/6：

```text
Sₙ = n(n+1)(2n+1) / (6n³)
   = (2n³ + 3n² + n) / (6n³)
   = 1/3 + 1/(2n) + 1/(6n²)
```

让 n → ∞：

```text
lim Sₙ = 1/3
```

所以：

```text
∫₀¹ x² dx = 1/3
```

这个结果和"曲边三角形的面积是三分之一"对得上。

用定义算一次，目的是理解 ∫ 和 Σ 的关系。

真正做题时不会这么算，因为有下一节的公式。

**什么样的函数可积？**

两个充分条件够用：

```text
f 在 [a,b] 上连续                        ⇒ 可积
f 在 [a,b] 上有界，且只有有限个间断点    ⇒ 可积
```

反例是 Dirichlet 函数：有理点取 1，无理点取 0。

它在任何区间上都不连续，黎曼和的极限不存在，所以不可积。

数一不考这种反例的细节，但要知道"可积"不是自动成立的。

**为什么极限用 λ → 0 而不是 n → ∞？**

因为分段越多数不一定越细。

如果分点集中在左边，右边留一个巨大的段，n 再大，那个大段也没被切细。

λ 是所有段里最长的那一段，它趋于 0，才能保证"每段都变细"。

这个细节是定义严谨性的关键，理解了就不会把"可积"和"分得够多"混为一谈。

## 3. 定积分的性质：八条够用

没有这一节，你会在"比较两个积分大小""拆区间""用对称性"这些地方反复出错。

**第一条，线性。**

```text
∫ₐᵇ [k f(x) + m g(x)] dx = k∫ₐᵇ f(x) dx + m∫ₐᵇ g(x) dx
```

常数可以提到积分号外，加减可以分开。

**第二条，区间可加。**

```text
∫ₐᵇ f dx = ∫ₐᶜ f dx + ∫_cᵇ f dx
```

c 可以在 [a,b] 内，也可以在外。

这条性质是"分段函数积分"的依据。

**第三条，上下限交换变号。**

```text
∫ₐᵇ f dx = -∫_bᵃ f dx
```

所以 ∫ₐᵃ f dx = 0。

**第四条，保号性。**

```text
f(x) ≥ 0 在 [a,b] 上  ⇒  ∫ₐᵇ f dx ≥ 0
f(x) ≤ g(x)           ⇒  ∫ₐᵇ f dx ≤ ∫ₐᵇ g dx
```

这条是"比较积分大小"题的依据。

**第五条，估值定理。**

设 m 和 M 分别是 f 在 [a,b] 上的最小值和最大值：

```text
m(b - a) ≤ ∫ₐᵇ f dx ≤ M(b - a)
```

几何上就是"面积夹在小矩形和大矩形之间"。

**第六条，绝对值不等式。**

```text
|∫ₐᵇ f dx| ≤ ∫ₐᵇ |f| dx
```

左边是"先积分再取绝对值"，右边是"先取绝对值再积分"。

两者一般不等，右边总是不小于左边。

**第七条，积分中值定理。**

f 在 [a,b] 上连续，则存在 ξ ∈ [a,b]，使：

```text
∫ₐᵇ f(x) dx = f(ξ)(b - a)
```

它的意思是：曲边梯形的面积，等于某个高度的矩形面积。

```text
        ┌──────────┐
        │          │  ← 高 f(ξ) 的矩形
   ┌────┤  曲线    │
   │    └──────────┘
   └────────────────
     a            b
```

f(ξ) 叫 f 在 [a,b] 上的平均值：

```text
f(ξ) = (1/(b-a)) ∫ₐᵇ f(x) dx
```

这条在证明题里出现频率很高。

用中值定理算一个极限：

例：算 lim(n→∞) (1/n) Σ(k=1 到 n) sin(kπ/n)。

把和式认成某个函数在 [0,1] 上的黎曼和。取 n 等分，ξ_k = k/n，Δx = 1/n：

```text
(1/n) Σ sin(kπ/n) = Σ sin(π·ξ_k)·Δx  →  ∫₀¹ sin(πx) dx
```

算这个积分：

```text
∫₀¹ sin(πx) dx = [-cos(πx)/π]₀¹ = (1/π) - (-1/π) = 2/π
```

所以极限是 2/π。

这类"数列和的极限"题，套路是把它认成某个函数的黎曼和，再转成定积分。

判断的方法：看能不能写成 (1/n)Σ f(k/n) 的形状。

**第八条，变上限积分可导。**

f 连续时，Φ(x) = ∫ₐˣ f(t) dt 是可导的，且 Φ'(x) = f(x)。

这条单独放在第 6 节讲，它是整章的技术核心。

**用一条性质算一个分段积分。**

算 ∫₀² |x - 1| dx。

绝对值在 x = 1 处改号，用区间可加性拆开：

```text
∫₀² |x-1| dx = ∫₀¹ (1 - x) dx + ∫₁² (x - 1) dx
```

分别算：

```text
∫₀¹ (1-x) dx = [x - x²/2]₀¹ = 1 - 1/2 = 1/2
∫₁² (x-1) dx = [x²/2 - x]₁² = (2-2) - (1/2-1) = 1/2
```

相加：

```text
= 1/2 + 1/2 = 1
```

几何上，两个三角形的底都是 1、高都是 1，各占 1/2。

遇到绝对值、max、min、分段定义的被积函数，第一步永远是"找改号点，拆区间"。

## 4. 牛顿-莱布尼茨公式

没有它，每个积分都得用定义算，一道题要写半小时。

公式长这样：

```text
∫ₐᵇ f(x) dx = F(b) - F(a)
```

其中 F 是 f 的任意一个原函数。

**逐符号：**

**F(b) - F(a)**：原函数在上限的值减去在下限的值。

常用记号：

```text
F(x)|ₐᵇ = F(b) - F(a)
```

竖线右下写 a，右上写 b，读"F(x) 从 a 到 b"。

**它在算什么？**

它在说：曲线下的面积，等于"原函数这个量的总增量"。

一个直观解释：记 Φ(x) 为"从 a 到 x 累积的积分"：

```text
Φ(x) = ∫ₐˣ f(t) dt
```

那么 Φ 的增量 Φ(b) - Φ(a)，正好是从 a 到 b 累积的全部面积。

而第 6 节会证明 Φ'(x) = f(x)，所以 Φ 就是 f 的一个原函数，把 F 取成 Φ 就得到了公式。

**公式四步：用 N-L 算定积分**

第一步，算什么：先找 f 的一个原函数 F，再在两端点求差。

第二步，逐符号：∫ₐᵇ 是定积分号，a 是下限、b 是上限，dx 说明变量是 x；F(b) - F(a) 是一个数，不带 C。

第三步，代数字：算 ∫₁² x² dx。

```text
F(x) = x³/3
F(2) = 8/3
F(1) = 1/3
∫₁² x² dx = 8/3 - 1/3 = 7/3
```

第四步，适用条件：f 在 [a,b] 上连续（或至多有限个第一类间断点且可积）；F 必须是 f 在这个区间上的原函数；被积函数在区间内部不能有瑕点，有瑕点时这个公式不能直接用，要走反常积分。

最后一条是最大的坑，第 9 节会专门说。

**为什么原函数可以随便取哪个？**

因为不同的原函数只差一个常数：

```text
F₁(x) = F(x) + C₁
F₁(b) - F₁(a) = [F(b) + C₁] - [F(a) + C₁] = F(b) - F(a)
```

常数在相减时自动抵消。

这就是为什么定积分不带 C：

```text
C 在两端相减时消失了。
```

**把 N-L 想成"面积函数的增量"。**

定义一个面积函数：

```text
A(x) = ∫ₐˣ f(t) dt
```

它是"从 a 到 x 曲线下的面积"，是这个抽象动作的实物版本。

x 增加一点点 Δx，A 增加的部分是一条窄条，面积约等于 f(x)·Δx：

```text
A(x + Δx) - A(x) ≈ f(x)·Δx
```

两边除以 Δx 再让 Δx → 0：

```text
A'(x) = f(x)
```

所以 A 是 f 的原函数。

而 A(a) = 0，A(b) 正好是从 a 到 b 的全部面积。

把这段推理写成式子：

```text
∫ₐᵇ f(x) dx = A(b) - A(a) = F(b) - F(a)
```

一句话总结：

```text
面积函数就是原函数，所以面积等于原函数的增量。
```

这句话是整章的核心，比公式本身更值得记。

## 5. 算一遍：六个积分

没有这一节，公式永远停在纸上。

**例一，三角函数的积分。**

算 ∫₀^(π/2) cos x dx。

```text
原函数 F(x) = sin x
F(π/2) = sin(π/2) = 1
F(0) = sin 0 = 0
∫₀^(π/2) cos x dx = 1 - 0 = 1
```

几何上，cos x 在 [0, π/2] 下的面积正好是 1，可以验证。

**例二，对数型积分。**

算 ∫₁^e (1/x) dx。

```text
原函数 F(x) = ln|x| = ln x （区间在正半轴）
F(e) = ln e = 1
F(1) = ln 1 = 0
∫₁^e dx/x = 1
```

这个结果是自然对数定义的来源：

```text
ln x = ∫₁ˣ dt/t
```

**例三，跨过零点的积分。**

算 ∫₀^π sin x dx。

```text
原函数 F(x) = -cos x
F(π) = -cos π = 1
F(0) = -cos 0 = -1
∫₀^π sin x dx = 1 - (-1) = 2
```

sin x 在 [0, π] 上非负，面积是 2，符合直觉。

再看 ∫₀^(2π) sin x dx：

```text
F(2π) - F(0) = -cos(2π) - (-cos 0) = -1 + 1 = 0
```

后半段在横轴下方，负面积把正面积抵消了。

**例四，反三角型积分。**

算 ∫₀¹ dx/(1 + x²)。

```text
原函数 F(x) = arctan x
F(1) = π/4
F(0) = 0
∫₀¹ dx/(1+x²) = π/4
```

这个式子给出了 π 的一个计算方法，虽然收敛很慢。

**例五，需要分部的积分。**

算 ∫₀¹ x e^x dx。

先算不定积分（06 篇例五）：

```text
∫ x e^x dx = (x - 1)e^x
```

代上下限：

```text
F(1) = (1 - 1)e¹ = 0
F(0) = (0 - 1)e⁰ = -1
∫₀¹ x e^x dx = 0 - (-1) = 1
```

**例六，需要降次的积分。**

算 ∫₀^(π/2) sin²x dx。

先降次：

```text
sin²x = (1 - cos 2x)/2
∫ sin²x dx = x/2 - sin(2x)/4
```

代上下限：

```text
F(π/2) = π/4 - sin(π)/4 = π/4 - 0 = π/4
F(0) = 0 - 0 = 0
∫₀^(π/2) sin²x dx = π/4
```

同理可以算出 ∫₀^(π/2) cos²x dx = π/4，两者相加正好是 π/2，也就是矩形面积。

**例七，正切函数的积分。**

算 ∫₀^(π/4) tan x dx。

原函数（06 篇推导过）：

```text
∫ tan x dx = -ln|cos x|
```

代上下限：

```text
F(π/4) = -ln(cos(π/4)) = -ln(√2/2) = ln√2 = (1/2)ln 2
F(0) = -ln 1 = 0
∫₀^(π/4) tan x dx = (1/2)ln 2 ≈ 0.347
```

**例八，凑成 ln 型。**

算 ∫₀¹ dx/(1 + x)。

分母的导数就是分子（差一个系数），所以原函数是 ln(1 + x)：

```text
[ln(1+x)]₀¹ = ln 2 - ln 1 = ln 2
```

这类"分子是分母导数"的积分，在 06 篇推 ∫tan x dx 时见过，是同一个套路。

**例九，对数函数乘一次式。**

算 ∫₀¹ ln(1 + x) dx。

先求原函数（06 篇分部法）：

```text
∫ ln(1+x) dx = (1+x)ln(1+x) - (1+x)
```

代上下限：

```text
F(1) = 2ln 2 - 2
F(0) = 0 - 1 = -1
∫₀¹ ln(1+x) dx = (2ln 2 - 2) - (-1) = 2ln 2 - 1 ≈ 0.386
```

检验一下符号：ln(1+x) 在 [0,1] 上从 0 增到 ln 2 ≈ 0.693，平均值约 0.386，和结果吻合。

九个例子的共同结构：

```text
先求原函数（用 06 篇的方法），再代两个端点，做减法。
```

所以定积分的难点从来不在"定积分"本身，而在"求原函数"。

06 篇练得越熟，这一篇越快。

把流程写成四步，考试时照着走：

```text
第一步：看被积函数，判断要不要先化简（拆项、降次、去绝对值）
第二步：求原函数，用 06 篇的基本表、换元、分部
第三步：代上下限，做减法，注意符号
第四步：检验量级（正负号、大小是否合理）
```

第四步最容易被跳过，但它是唯一能在考场上抓住错误的环节。

比如算出面积为负数，说明上下限代反了；算出概率大于 1，说明某步漏了系数。

## 6. 变上限积分：Φ(x) 与它的导数

没有这一节，你会看不懂"两边求导"这类题，也做不出与极限结合的题。

**先看一个新函数。**

固定下限 a，让上限动起来：

```text
Φ(x) = ∫ₐˣ f(t) dt
```

**Φ**：读"fai"，希腊字母的大写 Phi，这里表示一个函数。

**为什么里面写 t 不写 x？**

因为 x 已经用来表示"上限"了。

积分里面的变量只是"跑一遍积分区间"的临时变量，叫哑变量，用 t 表示可以避免混淆：

```text
Φ(x) = ∫ₐˣ f(t) dt   ← 正确
Φ(x) = ∫ₐˣ f(x) dx   ← 错误，x 一名两用
```

**Φ 是什么？**

是"从 a 到 x 累积的面积"。

x 变大，累积的面积变大，所以 Φ 是 x 的函数。

**核心定理：**

```text
f 在 [a,b] 上连续  ⇒  Φ'(x) = f(x)
```

也就是说：变上限积分对上限求导，直接得到被积函数。

**这个定理为什么成立？**

看 Φ 的增量：

```text
Φ(x + Δx) - Φ(x) = ∫ₓ^(x+Δx) f(t) dt
```

这一小段积分，由积分中值定理等于 f(ξ)·Δx，其中 ξ 在 x 和 x + Δx 之间。

两边除以 Δx：

```text
[Φ(x+Δx) - Φ(x)]/Δx = f(ξ)
```

让 Δx → 0，ξ 被挤向 x，f 连续，所以 f(ξ) → f(x)。

于是 Φ'(x) = f(x)。

**这就是牛顿-莱布尼茨公式的证明核心：**

它说明"变上限积分"本身就是 f 的一个原函数。

原函数存在性也因此得到保证：连续函数一定有原函数，那个原函数就是 Φ。

**求导的三种变形。**

**变形一，上限是 x 的函数。**

```text
d/dx ∫ₐ^(φ(x)) f(t) dt = f(φ(x)) · φ'(x)
```

例：Φ(x) = ∫₀^(x²) sin t dt。

```text
Φ'(x) = sin(x²) · (x²)' = 2x sin(x²)
```

多出来的 2x 是链式法则，不能漏。

**变形二，上下限都是 x 的函数。**

```text
d/dx ∫_(ψ(x))^(φ(x)) f(t) dt = f(φ(x))φ'(x) - f(ψ(x))ψ'(x)
```

例：F(x) = ∫ₓ^(x²) e^(t²) dt。

```text
F'(x) = e^((x²)²)·(x²)' - e^(x²)·(x)'
      = 2x e^(x⁴) - e^(x²)
```

上限那项是正的，下限那项是负的，符号不能弄反。

**变形三，被积函数里含 x。**

```text
Φ(x) = ∫₀ˣ x f(t) dt = x ∫₀ˣ f(t) dt
```

x 对 t 来说是常数，可以提到积分号外，然后用乘积求导：

```text
Φ'(x) = ∫₀ˣ f(t) dt + x f(x)
```

如果 x 和 t 纠缠在一起（比如 ∫₀ˣ f(x - t) dt），要先换元把 x 挪出去。

**变形四，x 藏在被积函数里。**

例：Φ(x) = ∫₀ˣ (x - t)f(t) dt，求 Φ'(x)。

先把积分拆开：

```text
Φ(x) = ∫₀ˣ x f(t) dt - ∫₀ˣ t f(t) dt
     = x ∫₀ˣ f(t) dt - ∫₀ˣ t f(t) dt
```

第一项是两个函数相乘（x 和变上限积分），用乘积求导：

```text
[x ∫₀ˣ f(t) dt]' = ∫₀ˣ f(t) dt + x f(x)
```

第二项直接用变上限公式：

```text
[∫₀ˣ t f(t) dt]' = x f(x)
```

相减：

```text
Φ'(x) = ∫₀ˣ f(t) dt + x f(x) - x f(x) = ∫₀ˣ f(t) dt
```

结果是 ∫₀ˣ f(t) dt，比原来的样子简单。

这个变形经常出现在数一的综合题里。

处理原则只有一句：

```text
先把 x 从积分号里彻底挪出来（提出来或者换元），再求导。
```

x 留在积分号里直接求导，几乎必错。

**和 05 篇结合：用变上限积分求极值。**

例：设 Φ(x) = ∫₀ˣ (t - 1)e^t dt，求 Φ 的极值点。

第一步，求导：

```text
Φ'(x) = (x - 1)e^x
```

第二步，解驻点：

```text
(x - 1)e^x = 0  ⇒  x = 1
```

第三步，判号：

```text
x < 1 时 Φ' < 0，递减
x > 1 时 Φ' > 0，递增
```

所以 x = 1 是极小值点。

极小值：

```text
Φ(1) = ∫₀¹ (t-1)e^t dt
```

分部算一下，∫ (t-1)e^t dt = (t-2)e^t：

```text
Φ(1) = [(t-2)e^t]₀¹ = (-1)e - (-2) = 2 - e
```

这类题把两章接在一起：

```text
变上限求导 → 得到 Φ' → 用 05 篇的办法判极值。
```

**与极限结合，是数一的高频题。**

例：算 lim(x→0) [∫₀ˣ sin t dt] / x²。

x → 0 时分子分母都趋于 0，是 0/0 型，用洛必达。

分子求导用变上限公式：

```text
d/dx ∫₀ˣ sin t dt = sin x
分母求导：(x²)' = 2x
```

于是：

```text
原式 = lim(x→0) sin x/(2x) = (1/2)·lim sin x/x = 1/2
```

这里用了重要极限 lim(sin x/x) = 1。

这类题的固定结构：

```text
分子是变上限积分，分母是幂函数，用洛必达把积分号去掉。
```

## 7. 换元与分部在定积分里的两个坑

没有这一节，你会把不定积分的手法直接搬过来，然后在上下限上翻车。

**坑一：换元必须换限。**

不定积分换元后要回代，定积分换元后不回代，而是把上下限一起换掉。

算 ∫₀^a √(a² - x²) dx，a > 0。

令 x = a sin t，t ∈ [0, π/2]。

先换限：

```text
x = 0  ⇒  sin t = 0  ⇒  t = 0
x = a  ⇒  sin t = 1  ⇒  t = π/2
```

再换微分：

```text
dx = a cos t dt
√(a² - x²) = a cos t
```

代入：

```text
∫₀^a √(a²-x²) dx = ∫₀^(π/2) a cos t · a cos t dt
                 = a² ∫₀^(π/2) cos²t dt
                 = a² · π/4
                 = πa²/4
```

这个结果是四分之一圆的面积，和几何直觉一致。

**注意上限变成了 π/2，不是 a。**

如果换元后忘了换限，还在用 0 和 a，会算出：

```text
∫₀^a a²cos²t dt   ← 上限 a 代进 t 的位置，毫无意义
```

这是定积分换元最常见的错误。

正确做法只有两条：

```text
要么换元同时换限（推荐）
要么换元后回代成 x，再用原来的上下限
```

两条不能混着用。

**坑二：分部积分要带上下限。**

公式是：

```text
∫ₐᵇ u dv = [u v]ₐᵇ - ∫ₐᵇ v du
```

注意第一项要写成方括号加下标，表示"代入上下限相减"。

算 ∫₁^e ln x dx。

令 u = ln x，dv = dx：

```text
du = dx/x，v = x
```

套公式：

```text
∫₁^e ln x dx = [x ln x]₁^e - ∫₁^e x·(1/x) dx
             = [x ln x]₁^e - ∫₁^e 1 dx
```

先算第一项：

```text
[x ln x]₁^e = e·ln e - 1·ln 1 = e - 0 = e
```

再算第二项：

```text
∫₁^e 1 dx = e - 1
```

合并：

```text
= e - (e - 1) = 1
```

答案很干净，但不能漏掉方括号那一步。

如果按不定积分的写法先算出 x ln x - x，再代上下限，结果一样：

```text
[x ln x - x]₁^e = (e - e) - (0 - 1) = 1
```

两种写法都对，但混着写（比如先算不定积分却忘了代限）必定出错。

**一个常用的换元技巧。**

算 I = ∫₀^π x sin x dx。

直接分部能做，但有一个更快的办法。

令 x = π - t，则 dx = -dt，上下限跟着换：

```text
x = 0  ⇒  t = π
x = π  ⇒  t = 0
```

代入：

```text
I = ∫_π^0 (π - t) sin(π - t)(-dt) = ∫₀^π (π - t) sin t dt
```

利用 sin(π - t) = sin t，展开成两项：

```text
I = π∫₀^π sin t dt - ∫₀^π t sin t dt
```

第一项是 π·2 = 2π，第二项就是 I 本身：

```text
I = 2π - I
2I = 2π
I = π
```

这个技巧的通用形式是：

```text
∫₀^π x f(sin x) dx = (π/2)∫₀^π f(sin x) dx
```

它的作用是把带 x 因子的积分，变成不带 x 的积分，省掉一次分部。

推导的关键只有一步：sin(π - t) = sin t，所以换元后函数形状不变，x 却变成了 π - t。

**为什么定积分换元不用回代？**

因为定积分的值只依赖区间和函数，和变量的名字无关。

换元把 x 的区间 [0, a] 一一映射成 t 的区间 [0, π/2]，在新的区间上算出的积分值，就是原来的值。

回代是"把答案翻译回 x 的语言"，而定积分要的是一个数，不需要翻译。

## 8. 对称性、周期性与几何意义

没有这一节，你会把本该为零的积分硬算一遍，浪费十分钟还可能算错。

**奇偶性，在对称区间上最有用。**

```text
f 是奇函数（f(-x) = -f(x)）：∫_{-a}^{a} f(x) dx = 0
f 是偶函数（f(-x) = f(x)） ：∫_{-a}^{a} f(x) dx = 2∫₀^a f(x) dx
```

几何解释：奇函数的图像关于原点对称，右边正面积和左边负面积正好抵消。

例：算 ∫_{-π/2}^{π/2} (x³cos x + sin²x) dx。

先拆成两个积分：

```text
∫_{-π/2}^{π/2} x³cos x dx + ∫_{-π/2}^{π/2} sin²x dx
```

第一项，x³ 是奇函数、cos x 是偶函数，乘积是奇函数，区间对称：

```text
∫_{-π/2}^{π/2} x³cos x dx = 0
```

第二项，sin²x 是偶函数：

```text
∫_{-π/2}^{π/2} sin²x dx = 2∫₀^(π/2) sin²x dx = 2·(π/4) = π/2
```

结果：

```text
原式 = 0 + π/2 = π/2
```

一个看起来需要算很久的积分，对称性一用，三行结束。

再练一个带绝对值的。

算 ∫_{-2}^{2} (x³ + |x|) dx。

拆成两项：

```text
∫_{-2}^{2} x³ dx + ∫_{-2}^{2} |x| dx
```

第一项，x³ 是奇函数，区间对称：

```text
∫_{-2}^{2} x³ dx = 0
```

第二项，|x| 是偶函数：

```text
∫_{-2}^{2} |x| dx = 2∫₀² x dx = 2·[x²/2]₀² = 2·2 = 4
```

结果：

```text
原式 = 0 + 4 = 4
```

两个动作要分清：

```text
奇函数在对称区间上，积分直接是 0
偶函数在对称区间上，积分折半到 [0,a] 再乘 2
```

**周期性。**

f 以 T 为周期，则：

```text
∫ₐ^(a+T) f(x) dx = ∫₀^T f(x) dx      与起点无关
∫₀^(nT) f(x) dx = n∫₀^T f(x) dx      整周期可叠加
```

例：算 ∫₀^(2π) |sin x| dx。

|sin x| 以 π 为周期，所以：

```text
∫₀^(2π) |sin x| dx = 2∫₀^π |sin x| dx = 2∫₀^π sin x dx = 2·2 = 4
```

**华里士公式，考过多次。**

```text
∫₀^(π/2) sinⁿx dx = ∫₀^(π/2) cosⁿx dx
```

```text
n 为偶数：(n-1)!!/n!! · π/2
n 为奇数：(n-1)!!/n!!
```

其中双阶乘 n!! 表示"隔一个乘一个"：

```text
4!! = 4·2 = 8
5!! = 5·3·1 = 15
```

举例：

```text
∫₀^(π/2) sin²x dx = (1/2)·(π/2) = π/4
∫₀^(π/2) sin³x dx = (2/3)·1 = 2/3
∫₀^(π/2) sin⁴x dx = (3/4)·(1/2)·(π/2) = 3π/16
```

这个公式在算旋转体体积、曲线弧长时会反复用到。

**几何意义：圆的面积。**

算半径为 R 的圆的面积。

上半圆的方程是 y = √(R² - x²)，所以面积是：

```text
S = 2∫_{-R}^{R} √(R²-x²) dx
```

由偶函数性：

```text
= 4∫₀^R √(R²-x²) dx
```

用第 7 节的换元结果（a = R）：

```text
= 4 · πR²/4 = πR²
```

圆面积公式到这里才算真正推出来。

同样可以推出椭圆 x²/a² + y²/b² = 1 的面积是 πab。

**用定积分算一块具体的面积。**

算 y = x² 与 y = x 围成的面积。

先找交点，解 x² = x：

```text
x = 0 或 x = 1
```

在 (0, 1) 上，x > x²，所以上曲线是 y = x，下曲线是 y = x²。

面积就是"上减下"的积分：

```text
S = ∫₀¹ (x - x²) dx = [x²/2 - x³/3]₀¹ = 1/2 - 1/3 = 1/6
```

画出来是这样：

```text
   y
   │        ╱  y = x
   │      ╱░░░
   │    ╱░░░░░  ← 这块面积 1/6
   │  ╱░░░░░░░
   │╱░░░░░░░░░  y = x²
   └──────────── x
   0            1
```

这块面积只有整个正方形面积的六分之一，和直觉相符。

下一篇会把"上减下"这个动作发展成完整的面积公式，并推广到极坐标。

## 9. 常见错误

没有这一节，前面所有正确做法都会在考场上变形成错误版本。

**错误一：换元不换限。**

第 7 节已详述，这是最高频的错。

**错误二：给定积分加 C。**

定积分是一个数，C 在两端相减时已经抵消。

写"∫₀¹ x dx = 1/2 + C"是概念错误，直接扣分。

**错误三：有瑕点还用牛顿-莱布尼茨。**

例：算 ∫₀¹ dx/x²。

如果硬套公式：

```text
F(x) = -1/x
F(1) - F(0) = -1 - (-∞)   ← 无意义
```

有人写成 -1，这是错的。

真实情况是这个积分发散（趋于无穷）。

有瑕点时要用反常积分（09 篇）的办法，先算 ∫_ε¹ 再让 ε → 0⁺。

**错误四：上下限写反。**

∫ₐᵇ 和 ∫_bᵃ 差一个负号。

抄题时看错上下限，整题白做。

**错误五：被积函数含绝对值不拆区间。**

∫₀^(2π) sin x dx 和 ∫₀^(2π) |sin x| dx 是两个不同的值（0 和 4）。

绝对值必须先去符号，按正负分段。

**错误六：变上限求导漏链式法则。**

上限是 x² 时，导数要乘 2x。

只写 sin(x²) 是漏了内层导数。

**错误七：把积分变量和上限变量混用。**

Φ(x) = ∫ₐˣ f(x) dx 这种写法，同一个 x 有两个身份，必然出错。

正确写法是把积分变量换成 t。

**错误八：忽略"可积"的条件。**

f 在 [a,b] 上有无穷型间断点时，定积分可能不存在。

用 N-L 之前先扫一眼：区间内有没有让 f 跑向无穷的点。

**错误九：把定积分和面积当成完全等价。**

定积分是"代数和面积"。

```text
∫₀^(2π) sin x dx = 0，但曲线与横轴围出的实际面积是 4
```

题目问"面积"时，要把负的部分翻上来，分段积分再取绝对值。

**错误十：在积分号里对 x 和上限 x 混用。**

写出 Φ(x) = ∫₀ˣ f(x) dx 这种式子，等于让同一个字母同时扮演两个角色。

改写成 Φ(x) = ∫₀ˣ f(t) dt，再往下做。

**错误十一：把原函数写成被积函数。**

套 N-L 时，先写的是 F(x)（原函数），不是 f(x)。

```text
正确：∫₁² x² dx = [x³/3]₁² = 7/3
错误：∫₁² x² dx = [x²]₁² = 3
```

方括号里必须已经是原函数。

养成一个习惯：写方括号的同时，把求导检验在草稿纸上做一次。

**错误十二：算出负数就以为错了。**

定积分为负是正常现象，说明曲线在横轴下方占主导。

只有"面积"才必须非负，而面积要另设积分（上下曲线相减或取绝对值）。

## 10. 数一怎么考

没有这一节，你不知道这些知识会以什么形式出现。

**题型一：填空题，直接计算。**

```text
∫₀¹ (2x + 1) dx = ?
∫₁² dx/x = ?
∫₀^(π/4) sec²x dx = ?
```

答案分别是 2、ln 2、1。

这类题只考"原函数 + 代限"，两分钟一道。

**题型二：比较积分大小。**

例：比较 ∫₀¹ x dx、∫₀¹ x² dx、∫₀¹ √x dx 的大小。

在 (0,1) 上，x² < x < √x，所以由保号性：

```text
∫₀¹ x² dx = 1/3 < ∫₀¹ x dx = 1/2 < ∫₀¹ √x dx = 2/3
```

比较大小的题目，先比较被积函数，再套保号性，不要真去算。

**题型三：变上限积分 + 洛必达求极限。**

第 6 节的例子是标准形式。

还有一种变形：分母也是变上限积分。

```text
lim(x→0) [∫₀ˣ sin t dt] / [∫₀ˣ t dt]
```

洛必达一次：

```text
= lim(x→0) sin x/x = 1
```

**题型四：由积分等式求 f。**

例：已知 ∫₀ˣ f(t) dt = x² e^x，求 f(x)。

两边对 x 求导，左边用变上限公式：

```text
f(x) = (x² e^x)' = 2x e^x + x² e^x = (x² + 2x)e^x
```

如果条件是 ∫₀ˣ f(t) dt = x² e^x + 1，先代 x = 0 检验：

```text
左边 = 0，右边 = 1，矛盾
```

这说明这类等式必须"在 x = 0 处自洽"，出题人通常会让常数项为 0。

**题型五：积分中值定理证明。**

例：设 f 在 [0,1] 上连续，证明存在 ξ ∈ [0,1]，使 ∫₀¹ f(x) dx = f(ξ)。

直接套中值定理：b - a = 1，所以 ∫₀¹ f = f(ξ)·1。

这类题在证明题里属于送分，把定理写全就有分。

**题型六：用估值法证不等式。**

例：证明 ∫₀¹ e^(-x²) dx ≤ 1。

在 [0,1] 上，-x² ≤ 0，所以 e^(-x²) ≤ e⁰ = 1。

由保号性：

```text
∫₀¹ e^(-x²) dx ≤ ∫₀¹ 1 dx = 1
```

估值题的套路：

```text
先找被积函数在区间上的界，再用 m(b-a) ≤ ∫ ≤ M(b-a)。
```

**题型七：用积分的性质证"恒为零"。**

例：设 f 在 [0,1] 上连续且 f(x) ≥ 0，若 ∫₀¹ f(x) dx = 0，证明 f(x) ≡ 0。

思路：连续加非负，如果某点 f(x₀) > 0，由连续性会在 x₀ 附近一个小区间上都有 f > f(x₀)/2，那块面积就是正的，与总积分为 0 矛盾。

写成标准步骤：

```text
假设存在 x₀ 使 f(x₀) > 0
由连续性和保号性，存在 δ > 0，在 [x₀-δ, x₀+δ] ∩ [0,1] 上 f(x) ≥ f(x₀)/2
于是 ∫ 在这小段上 ≥ (f(x₀)/2)·长度 > 0
又 f ≥ 0，其余部分积分为非负
故总积分 > 0，与已知矛盾
所以 f ≡ 0
```

这类题的核心不是计算，是把"积分为零"翻译成"函数处处为零"。

**题型八：已知积分值求参数。**

例：已知 ∫₀^a (2x + 1) dx = 6，求正数 a。

先算左边：

```text
∫₀^a (2x+1) dx = [x² + x]₀^a = a² + a
```

列方程：

```text
a² + a = 6
a² + a - 6 = 0
(a + 3)(a - 2) = 0
```

a = 2 或 a = -3，由 a > 0 取 a = 2。

这类题的得分点有两个：

```text
一是把积分算成一个关于 a 的表达式
二是舍掉不符合条件的根
```

第二点经常被忘，尤其是题目限定了 a > 0 或有几何意义时。

**分值与时间。**

定积分在数一里是"必经之路"，单独出题和作为中间步骤各占一部分：

```text
填空选择：1 到 2 道，4 到 8 分
解答题：作为一步或一道小题，8 到 10 分
```

时间上，一道标准的定积分计算应该在四分钟内完成。

超过六分钟，说明原函数找错了方向，应该换方法而不是继续硬算。

## 11. 和其他章节怎么连

没有这一节，定积分会变成一个孤立公式，看不出它是枢纽。

**往回连：06 不定积分。**

定积分的计算完全依赖原函数。

06 篇的换元、分部、有理函数，在这一篇原样出现，只多了一步"代限"。

**往回连：02 连续与间断。**

"连续函数一定可积"、"连续函数一定有原函数"，这两条保证了 N-L 公式能用。

遇到不连续的函数，要先检查间断点的类型。

**往回连：04 微分中值定理。**

积分中值定理是微分中值定理的"积分版"。

```text
微分版：f(b) - f(a) = f'(ξ)(b - a)
积分版：∫ₐᵇ f dx = f(ξ)(b - a)
```

两者的形状几乎一样，都在说"某个中间值取到了平均值"。

中值定理那一篇练熟，这一篇的证明题就有把握了。

**往前连：08 定积分的应用。**

面积、体积、弧长、做功，全部是"先写出微元，再积分"。

这一篇提供工具，下一篇提供场景。

**往前连：09 反常积分。**

无穷限、瑕点，都是把定积分的区间或函数推到极限。

N-L 公式照样用，只是代入时要取极限。

**横向连：12 二重积分。**

二重积分是"先对一个变量积，再对另一个变量积"。

把二重积分化成累次积分后，每一次都是一个定积分。

所以定积分算不快，二重积分一定慢。

**横向连：16 数项级数。**

级数的部分和，本质上是"离散版的定积分"。

比较判别法里的 ∫₁^∞ f(x) dx，就是拿积分当"连续的尺子"去量级数。

**一个整体视角。**

定积分把三件事连在一起：

```text
几何：曲线下的面积
分析：黎曼和的极限
代数：原函数在两端相减
```

三者等价，这就是微积分基本定理的力量。

### 自检三问

**第一问：定积分和不定积分差在哪？为什么定积分不带 C？**

不定积分是一族函数，结果是 F(x) + C；定积分是一个数，结果是 F(b) - F(a)。

不带 C 的原因是：不同的原函数只差一个常数，而在两端相减时，这个常数被减掉了。

```text
[F(b) + C] - [F(a) + C] = F(b) - F(a)
```

**第二问：变上限积分求导，上限是 x² 时为什么要多乘 2x？**

因为 Φ(x) = ∫ₐ^(x²) f(t) dt 是复合函数：外层是"变上限积分"，内层是 x²。

由链式法则，导数等于"外层对上限求导"乘"内层导数"：

```text
f(x²) · 2x
```

只写 f(x²) 是漏了内层。

**第三问：换元时为什么必须同时换上下限？**

因为换元把 x 的区间一一映射成了 t 的区间。

原来的上下限是 x 的取值，代进 t 的式子里没有意义。

```text
x 从 0 到 a  ⇔  t 从 0 到 π/2 （在 x = a sin t 下）
```

如果坚持不换限，就必须把结果回代成 x 的表达式，两条路选一条，不能混。

## 12. 小结

没有小结，这一章的三个层次会混在一起。

把这一篇压成一张卡片：

```text
定义：分割 → 近似 → 求和 → 取极限
记号：∫ₐᵇ f(x)dx，a 下限、b 上限、dx 变量
性质：线性、区间可加、保号、估值、中值
计算：∫ₐᵇ f dx = F(b) - F(a)
变上限：Φ(x) = ∫ₐˣ f(t)dt，Φ'(x) = f(x)
换元：换元必换限
```

四步公式在这一篇出现三次，形式一致：

```text
算什么 → 逐符号 → 代数字 → 适用条件
```

N-L 公式的"适用条件"是连续性，变上限求导的"适用条件"是 f 连续，换元的"适用条件"是代换单调可导。

三个条件都不能省。

考场上遇到定积分题，按这个顺序想：

```text
1. 区间内有没有瑕点？有就转反常积分
2. 被积函数有没有奇偶性、周期性？有就先化简
3. 能不能直接查原函数？能就套 N-L
4. 不能就换元或分部，换元记得换限
5. 结果是一个数，不带 C
```

五个常见数值，背下来能省时间：

```text
∫₀^(π/2) sin²x dx = π/4        ∫₀^(π/2) sin x dx = 1
∫₀^π sin x dx = 2              ∫₀¹ dx/(1+x²) = π/4
∫₁^e dx/x = 1                   ∫₀¹ x e^x dx = 1
```

这六个结果在后面的应用题里会反复出现。

如果这一篇只记三句话：

```text
定积分是一个数：黎曼和的极限，也是原函数的增量。
变上限积分就是原函数，所以 Φ'(x) = f(x)。
换元必换限，结果不带 C。
```

三句话对应三个必考动作：算值、求导、变形。

下一篇讲应用。

这一篇算的是"一个数"，下一篇要问：

```text
这个数能用来算什么？
```
