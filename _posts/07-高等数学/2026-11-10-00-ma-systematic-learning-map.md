先看一个式子：

```text
1/2 + 1/4 + 1/8 + 1/16 + … = ?
```

一直加下去，项数无限多。

加起来会是无穷大吗？

不会。

**结果是 1。**

为什么？

因为每加一项，剩下的空间就少一半：

```text
1/2          剩下 1/2
1/2+1/4=3/4  剩下 1/4
1/2+…+1/8=7/8 剩下 1/8
```

剩下的部分越来越小，趋近于 0。

所以总和趋近于 1。

**反直觉的点在这里：**

```text
"无限多"不一定等于"无限大"。
关键是：每一项是不是越来越小，小得够快。
```

这一句话，就是整门高等数学的起点。

## 1. 高等数学到底在研究什么

两个词：

```text
变化率：某个量变多快（导数）。
累积量：把无数个小块加起来（积分）。
```

而这两件事，都要靠一个工具才说得清：

```text
极限：当某个量越来越接近某个值时，另一个量趋向哪里。
```

所以整门课的结构是：

```text
极限（地基）
  ├─ 微分：研究"变多快"
  ├─ 积分：研究"攒多少"
  ├─ 级数：研究"无限相加"
  └─ 微分方程：研究"变化率和量本身的关系"
```

## 2. 在往下读之前：六个常识

**1. 函数**

一个"输入 → 输出"的规则。

比如 f(x) = x²，输入 3，输出 9。

**2. 图像**

把函数画在坐标系里，横轴是输入，纵轴是输出。

**3. 斜率**

一条线"陡不陡"。

直线 y = 2x 的斜率是 2：x 每加 1，y 加 2。

**4. 面积**

曲线和横轴围出来的那块。

**5. 无穷**

不是一个数，是一个"越来越大/越来越接近"的过程。

**6. Σ 与 ∫**

Σ（读 sigma）表示"很多项相加"。

∫（读积分号）表示"把连续的东西累加"。

这六个词就是整套讲解的地基。

## 4. 第 1 块：极限与连续

极限要解决的问题：

```text
x 越来越接近 2 时，x² 越来越接近几？
```

答案是 4。

但有些情况不那么直观：

```text
sin x / x，当 x → 0 时是多少？
```

x = 0 时是 0/0，没定义。

但 x 越接近 0，这个比值越接近 **1**。

这就是极限：**不看那一点，看它附近怎么走。**

连续则是：

```text
函数图像能不能一笔画过去，中间不断。
```

## 5. 第 2 块：一元微分

导数就是"瞬时变化率"。

```text
平均速度 = 走过的距离 / 花的时间
瞬时速度 = 时间间隔趋近于 0 时的平均速度
```

几何上，导数是**切线斜率**。

有了导数，就能回答：

```text
函数在哪里上升、哪里下降？
最高点、最低点在哪？
曲线是"凹"还是"凸"？
```

中值定理是这一块的枢纽：

```text
一段路平均速度 60，
那么至少有一瞬间，速度正好是 60。
```

## 6. 第 3 块：一元积分

积分是"把无数小块加起来"。

```text
把曲线下的区域切成无数个细长条，
每条面积 = 高 × 宽，
全部加起来，就是定积分。
```

积分和导数是一对反操作：

```text
先积分再求导，回到原函数。
```

这就是牛顿-莱布尼茨公式，也是定积分能算出来的原因。

## 7. 第 4 块：级数

级数就是"无限相加"。

要判断两件事：

```text
加下去会不会收敛到一个有限值？
如果收敛，值是多少？
```

幂级数更厉害：

```text
很多函数都能写成一串 x 的幂相加，
比如 e^x = 1 + x + x²/2! + x³/3! + …
```

## 8. 第 5 块：微分方程

方程里带导数，就是微分方程。

```text
y' = 2x
```

意思是"变化率等于 2x"，解出来：

```text
y = x² + C
```

C 是任意常数，因为"变化率"不决定起点在哪。

## 10. 三个必算的量

### 10.1 极限

```text
lim(x→2) x² = 4
```

### 10.2 导数

```text
(x²)' = 2x
```

### 10.3 定积分

```text
∫₀¹ x² dx = 1/3
```

## 11. 数一怎么考

```text
选择题、填空题：极限、导数、积分、级数敛散、曲面方程
解答题：求极限、求导、积分计算、中值定理证明、
        二重/三重积分、曲线曲面积分、级数展开、微分方程
```

一个实用判断：

```text
计算题占大头，先把"算得对"练熟。
证明题只有几道，但套路固定（中值定理 + 构造辅助函数）。
```
