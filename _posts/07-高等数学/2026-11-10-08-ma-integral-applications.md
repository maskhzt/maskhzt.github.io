> **读这篇之前，你只需要知道**：定积分是"把无数个细条的面积加起来"的极限，记作 ∫ₐᵇ f(x)dx；导数是切线斜率，弧长、体积这些公式里会用到 y'；极坐标用 (r, θ) 描述点，r 是到原点的距离，θ 是转过的角。
> **这篇讲什么**：定积分只是个工具，真正要学的是"怎么把一块面积、一个体积、一段弧长写成一个积分"——这个写法叫微元法，四步之内能套到几乎所有几何量和物理量上。
> **一个类比**：要用秤称一张不规则纸的重量，先剪下一小条量一量，知道每条的重量规律，再把所有小条加起来；微元法就是"先管一小条，再管全部"。

有一片地，边界是弯的。

要量它的面积。

没有公式可用，因为边界不是直线，也不是圆。

办法只有一个：

```text
把它切成很多窄条。
每一条窄到可以当成矩形。
把矩形面积加起来。
```

这就是这一篇的全部内容。

微积分厉害的地方，不是"能算积分"，而是"能把现实问题翻译成积分"。

翻译对了，剩下的只是算。

翻译错了，算得再快也是零分。

## 1. 为什么需要它（不给会怎样）

没有这一节，你会算 ∫ 但不会用 ∫。

**第一，几何量算不出来。**

```text
曲线围成的面积：没有公式，只能积分
旋转体的体积：一个杯子、一个碗的容积
曲线的弧长：一根弯铁丝有多长
旋转曲面的面积：一个喇叭口的表面积
```

这些量在中学都有特殊公式（圆、球、圆锥），但一旦形状变了，公式就没了。

积分是唯一的通用办法。

**第二，物理量算不出来。**

```text
变力做功：力随位置变化
水压力：压强随深度变化
抽水做功：每一层水要提升的高度不同
质心位置：密度不均匀的板
```

它们的共同点是"每一小段的情况都不一样"，只能靠累加。

**第三，数一的应用题就靠它。**

数一每年必有一道"定积分应用"的题，形式通常是：

```text
求面积 / 求体积 / 求弧长 / 求做功
```

分值 10 分左右，而且设式对了，计算通常很快。

设式错了，一分不给。

所以这一篇真正要练的是"设式"，不是"算积分"。

**第四，它是后面所有积分的模板。**

二重积分算体积、三重积分算质量、第一类曲线积分算弧长、第一类曲面积分算曲面面积，全部是"微元法"的推广。

一元这一篇学透，多元那几篇只是把"一条"换成"一片"。

**第五，它是"总量 = 积分"这个思想的第一次落地。**

经济学里的总收益、总成本，物理里的总功、总电量，生物里的总增长量，全都写成积分。

共同结构是：

```text
总量 = ∫ (变化率) d(自变量)
```

这句话在后续每一门课里都会再出现。

这一篇只是把"变化率"换成了"高""半径""力""密度"。

再补一句区别：导数研究"某一点的瞬时变化"，积分研究"一整段的累积结果"。

```text
导数：把整体切到一点，看那一点的斜率
积分：把整体切成小块，把所有小块加起来
```

两者是同一个动作的两个方向，所以微积分能互相验证。

## 2. 最小模型：微元法四步

微元法是这一篇的唯一方法。

它把"求一个总量"变成"求一个积分"。

**第一步，选变量和区间。**

确定用哪个量做积分变量（通常是 x 或 θ），以及它的变化范围 [a, b]。

**第二步，取微元。**

在区间里取一小段 [x, x + dx]，看这一小段对应的小块。

**第三步，写微元。**

把这一小块近似成一个规则形状，写出它的"量"：

```text
面积微元：dA = 高 × dx
体积微元：dV = 底面积 × dx
弧长微元：ds = 斜边 = √(dx² + dy²)
功微元：  dW = 力 × 位移 = F(x) dx
```

**第四步，积分。**

```text
总量 = ∫ₐᵇ (微元)
```

**为什么可以近似？**

因为微元里的误差是 dx 的高阶无穷小。

具体说：把窄条当成矩形，误差是一个"小三角形"，它的面积是 dx·dy 级别，比 dx 还小一个量级。

积分是"求和再取极限"，这些高阶小量的和在极限下趋于 0，不影响结果。

这句话是微元法合法的依据，答题时不必写出来，但要知道它为什么成立。

**微元法的关键判断：**

```text
微元必须是"一阶"的：dA 里只能出现 dx 的一次方。
如果写出 dA = (某量)·dx²，那这个微元就取错了。
```

**四个常用微元，先记住形状：**

```text
面积：一条竖窄条，宽 dx，高 = 上曲线 - 下曲线
体积：一片薄圆盘，厚 dx，半径 = 曲线的高度
弧长：一小段斜线，横 dx、竖 dy，长度 = √(dx²+dy²)
做功：一层薄水/一小段弹簧，位移 dx，力 = F(x)
```

后面每一节，都是把这四个形状套到具体问题上。

**一个检验办法：**

```text
量纲检验。
面积微元 dA 的量纲是"长度²"，体积微元 dV 是"长度³"。
如果算出来的量纲不对，微元一定写错了。
```

比如算面积时写出 dA = f(x)·dx²，量纲是长度³，立刻能发现错。

**一个"取错微元"的例子。**

想算曲线下的面积，写成：

```text
错误：dA = f(x) · (Δx)²
```

为什么错？因为把"高"也乘了两遍。

正确的微元只乘一个 dx：

```text
正确：dA = f(x) · dx
```

同理，算旋转体体积时写成 dV = πy²(dx)² 也错，体积微元是"底面积乘厚度"，厚度只出现一次。

一句话记：

```text
微元里，微变量只出现一次（一阶）。
```

**一个检验微元的笨办法。**

把 [x, x + dx] 这一小段"放大"看。

如果放大之后它像一个矩形（或圆盘、或斜线），说明微元取得对。

如果放大之后还是一条弯曲的边，说明你取的不是"一小段"，而是一大块。

积分的合法性来自"dx 足够小"，解题时只写形式，不再真的取极限。

## 3. 平面面积：直角坐标

没有这一节，你连最简单的"两曲线围成的面积"都设不对。

**基本公式：**

```text
A = ∫ₐᵇ [f(x) - g(x)] dx
```

其中 f 是上曲线，g 是下曲线，a、b 是两条曲线的交点横坐标（或者题目给定的边界）。

**四步公式：算面积**

第一步，算什么：两条曲线之间夹的那块面积。

第二步，逐符号：f(x) 是上方的曲线，g(x) 是下方的曲线，相减保证被积函数非负；a、b 是积分区间，由交点或题目条件确定；dx 表示沿 x 方向切条。

第三步，代数字：算 y = x² 与 y = x 围成的面积。

```text
交点：x² = x  ⇒  x = 0 或 x = 1
在 (0,1) 上 x > x²，所以上曲线是 y = x
A = ∫₀¹ (x - x²) dx = [x²/2 - x³/3]₀¹ = 1/2 - 1/3 = 1/6
```

第四步，适用条件：上下曲线在区间内不能交叉；如果交叉，要在交点处拆区间，每段分别判断谁在上；被积函数必须非负，算出负数说明上下写反了。

**例一，一条曲线与坐标轴。**

算 y = ln x、x 轴、直线 x = e 围成的面积。

```text
在 [1, e] 上 ln x ≥ 0，上曲线是 y = ln x，下曲线是 y = 0
A = ∫₁^e ln x dx
```

原函数（06 篇例七）：

```text
∫ ln x dx = x ln x - x
```

代上下限：

```text
A = [x ln x - x]₁^e = (e·1 - e) - (0 - 1) = 0 + 1 = 1
```

答案正好是 1，这是 ln 的一个漂亮性质。

**例二，曲线穿过横轴，要拆区间。**

算 y = x² - 2x 与 x 轴围成的面积。

先找零点：

```text
x² - 2x = x(x - 2) = 0  ⇒  x = 0, 2
```

在 (0, 2) 上，x² - 2x < 0，曲线在横轴下方。

如果直接积分：

```text
∫₀² (x² - 2x) dx = [x³/3 - x²]₀² = 8/3 - 4 = -4/3
```

得到负数，说明是"带符号面积"。

面积要取绝对值：

```text
A = |−4/3| = 4/3
```

也可以先翻转被积函数：

```text
A = ∫₀² (2x - x²) dx = [x² - x³/3]₀² = 4 - 8/3 = 4/3
```

**例三，两条曲线在区间内交叉。**

算 y = x 与 y = x³ 围成的全部面积。

先求交点：

```text
x = x³  ⇒  x(x² - 1) = 0  ⇒  x = -1, 0, 1
```

两个交点把区间分成两段，上下关系互换：

```text
(-1, 0)：x³ > x，上曲线是 y = x³
(0, 1) ：x > x³，上曲线是 y = x
```

分段积分：

```text
A₁ = ∫_{-1}^{0} (x³ - x) dx = [x⁴/4 - x²/2]_{-1}^{0} = 0 - (1/4 - 1/2) = 1/4
A₂ = ∫₀¹ (x - x³) dx = [x²/2 - x⁴/4]₀¹ = 1/2 - 1/4 = 1/4
A = 1/4 + 1/4 = 1/2
```

还有一个更快的办法：两块面积关于原点对称，算一块乘 2。

```text
A = 2∫₀¹ (x - x³) dx = 2·(1/4) = 1/2
```

**判断"要不要拆"的方法：**

```text
解 f(x) = g(x)，把所有交点求出来。
交点都是分界点，每段内部上下关系不变。
漏掉一个交点，就漏掉一次拆分。
```

**例四，上下曲线都是抛物线。**

算 y = x² 与 y = 2 - x² 围成的面积。

求交点：

```text
x² = 2 - x²  ⇒  2x² = 2  ⇒  x = ±1
```

在 (-1, 1) 上，2 - x² > x²（代 x = 0 验证：2 > 0）。

所以上曲线是 y = 2 - x²：

```text
A = ∫_{-1}^{1} [(2 - x²) - x²] dx = ∫_{-1}^{1} (2 - 2x²) dx
```

被积函数是偶函数：

```text
= 2∫₀¹ (2 - 2x²) dx = 2[2x - 2x³/3]₀¹ = 2(2 - 2/3) = 8/3
```

检验：整个区域夹在 y = 0 到 y = 2 之间，宽是 2，所以面积不超过 4。

8/3 ≈ 2.67，落在合理范围。

这种"量级检验"能快速发现严重错误。

**例五，需要把 y 当成自变量的情形。**

算 y = x² 与 x = y² 围成的面积。

两条曲线交于 (0,0) 和 (1,1)。

如果沿 x 切，上曲线要分段判断，麻烦。

如果沿 y 切，右边界是 x = √y，左边界是 x = y²，关系很清楚：

```text
A = ∫₀¹ (√y - y²) dy = [(2/3)y^(3/2) - y³/3]₀¹ = 2/3 - 1/3 = 1/3
```

这个例子说明了选变量方向的重要性：

```text
沿着"边界更好表示"的方向切条。
```

## 4. 极坐标面积

没有这一节，遇到 r = a(1 + cos θ) 这种曲线，直角坐标根本设不出积分。

**基本公式：**

```text
A = (1/2)∫_α^β r²(θ) dθ
```

**逐符号：**

**r(θ)**：极坐标下的曲线，表示"角度为 θ 时，点到原点的距离"。

**(1/2)r² dθ**：这是一个小扇形的面积。

**为什么是扇形？**

在极坐标里，区间不是"一小段横坐标"，而是"一小段角度"。

角度从 θ 变到 θ + dθ，半径 r 几乎不变，扫出的形状是一个细扇形：

```text
面积 = (1/2)·r²·dθ
```

这就是扇形面积公式 (1/2)r²θ 的微分版本。

**四步公式：算极坐标面积**

第一步，算什么：曲线 r(θ) 与两条射线 θ = α、θ = β 围成的扇形区域面积。

第二步，逐符号：r 是极径，θ 是极角，dθ 是角度的微小增量，(1/2) 来自扇形面积公式。

第三步，代数字：算心形线 r = a(1 + cos θ) 在 [0, 2π] 上的面积。

```text
A = (1/2)∫₀^(2π) a²(1 + cos θ)² dθ
```

先把平方展开：

```text
(1 + cos θ)² = 1 + 2cos θ + cos²θ
```

逐项积分，用 cos²θ = (1 + cos 2θ)/2：

```text
∫₀^(2π) 1 dθ = 2π
∫₀^(2π) 2cos θ dθ = 0
∫₀^(2π) cos²θ dθ = (1/2)·2π + 0 = π
```

合并：

```text
A = (1/2)a²(2π + 0 + π) = (3/2)πa²
```

第四步，适用条件：曲线在 [α, β] 上必须"每个角度只对应一个 r"；如果曲线绕原点多圈，要按实际扫过的角度分段；r 必须非负，出现负值时那一段的点在反方向，要单独处理。

**例二，圆方程用极坐标表示。**

算 r = 2a cos θ 围成的面积。

先确定 θ 的范围。r ≥ 0 要求 cos θ ≥ 0，所以 θ ∈ [-π/2, π/2]。

```text
A = (1/2)∫_{-π/2}^{π/2} 4a²cos²θ dθ
  = 2a²∫_{-π/2}^{π/2} cos²θ dθ
```

cos²θ 是偶函数，区间对称：

```text
= 2a²·2∫₀^(π/2) cos²θ dθ = 4a²·(π/4) = πa²
```

结果是 πa²，正好是半径为 a 的圆。

这个例子说明：r = 2a cos θ 是圆心在 (a, 0)、半径为 a 的圆。

**极坐标与直角坐标的互化：**

```text
x = r cos θ
y = r sin θ
r² = x² + y²
```

遇到 r = 2a cos θ，两边乘 r：

```text
r² = 2ar cos θ  ⇒  x² + y² = 2ax  ⇒  (x - a)² + y² = a²
```

确实是圆。

**什么时候用极坐标？**

```text
曲线方程里有 x² + y²、圆、心形线、双纽线、玫瑰线  → 用极坐标
曲线是 y = f(x) 的形式                        → 用直角坐标
区域是"扇形、圆环、过原点的射线围成"           → 用极坐标
```

判断依据是"边界形状"，不是"题目怎么说"。

**例三，用极坐标算扇形区域。**

算圆 r = 2a cos θ 在第一象限的那一块（θ ∈ [0, π/4]）。

```text
A = (1/2)∫₀^(π/4) 4a²cos²θ dθ = 2a²∫₀^(π/4) cos²θ dθ
```

用降次：

```text
∫ cos²θ dθ = θ/2 + sin(2θ)/4
```

代上下限：

```text
∫₀^(π/4) cos²θ dθ = π/8 + (1/4)sin(π/2) = π/8 + 1/4
```

所以：

```text
A = 2a²(π/8 + 1/4) = a²(π/4 + 1/2)
```

这个例子说明极坐标积分也会遇到"降次"这一步，和直角坐标一样。

**例四，双纽线的面积。**

双纽线 r² = a²cos 2θ，求全长围出的面积。

r² 必须非负，所以 cos 2θ ≥ 0：

```text
θ ∈ [-π/4, π/4] 或 θ ∈ [3π/4, 5π/4]
```

两叶，关于原点对称，算一叶乘 2：

```text
A = 2·(1/2)∫_{-π/4}^{π/4} a²cos 2θ dθ = a²·[sin 2θ/2]_{-π/4}^{π/4}
```

```text
= a²·(1/2)[sin(π/2) - sin(-π/2)] = a²·(1/2)(1 + 1) = a²
```

双纽线的总面积是 a²。

注意这里的技巧：被积函数是 r² 而不是 r，题目直接给 r² 时省去开方。

## 5. 旋转体体积

没有这一节，你算不出一个碗能装多少水。

体积有三种设法，对应三种几何情形。

**方法一，圆盘法（绕 x 轴，实心）。**

```text
V = π∫ₐᵇ [f(x)]² dx
```

**微元长什么样？**

把曲线下的区域绕 x 轴转一圈，每一条竖窄条扫出一个薄圆盘：

```text
半径 = f(x)，厚度 = dx
体积 = π·半径²·厚度 = π[f(x)]² dx
```

**例一，抛物面。**

算 y = √x 在 [0, 1] 上绕 x 轴旋转得到的体积。

```text
V = π∫₀¹ (√x)² dx = π∫₀¹ x dx = π·(1/2) = π/2
```

**例二，球的体积。**

上半圆 y = √(R² - x²)，x ∈ [-R, R]，绕 x 轴旋转得到球。

```text
V = π∫_{-R}^{R} (R² - x²) dx
```

被积函数是偶函数：

```text
= 2π∫₀^R (R² - x²) dx = 2π[R²x - x³/3]₀^R
= 2π(R³ - R³/3)
= 4πR³/3
```

球体积公式到这里才被推出来。

**方法二，垫圈法（绕 x 轴，空心）。**

两条曲线之间夹的区域绕 x 轴转，中间是空的。

```text
V = π∫ₐᵇ ([f(x)]² - [g(x)]²) dx
```

其中 f 是外曲线（离轴远），g 是内曲线（离轴近）。

**例三，两曲线之间。**

算 y = x 与 y = x² 之间绕 x 轴旋转的体积。

在 [0, 1] 上，x > x²，所以外半径是 x，内半径是 x²：

```text
V = π∫₀¹ (x² - x⁴) dx = π[1/3 - 1/5] = 2π/15
```

**方法三，柱壳法（绕 y 轴）。**

区域绕 y 轴转，用"薄圆柱壳"更省事。

```text
V = 2π∫ₐᵇ x·f(x) dx
```

**微元长什么样？**

在位置 x 处取一条竖条，绕 y 轴转一圈，扫出一个薄壳：

```text
半径 = x，高 = f(x)，厚度 = dx
体积 = 2π·半径·高·厚度 = 2πx f(x) dx
```

**例四，柱壳法。**

算 y = x² 在 [0, 1] 上绕 y 轴旋转的体积。

```text
V = 2π∫₀¹ x·x² dx = 2π∫₀¹ x³ dx = 2π·(1/4) = π/2
```

**例五，同一块区域，两种方法对照。**

算 y = x²、y = 0、x = 1 围成的区域绕 y 轴旋转的体积。

用柱壳法：

```text
V = 2π∫₀¹ x·x² dx = π/2
```

用圆盘法（沿 y 方向切）：

```text
y 从 0 到 1，半径 = x = √y，厚度 = dy
V = π∫₀¹ (√y)² dy = π∫₀¹ y dy = π/2
```

两种方法结果相同。

**怎么选方法？**

```text
绕 x 轴 → 圆盘法（沿 x 切），V = π∫ y² dx
绕 y 轴 → 柱壳法（沿 x 切），V = 2π∫ x y dx
绕 y 轴 → 圆盘法（沿 y 切），V = π∫ x² dy
```

绕哪个轴转，就优先"沿那个轴的反方向切"，公式最简单。

如果反过来切，往往会遇到"半径要写成两个函数的差"，容易错。

**例六，垫圈法再来一次。**

算 y = √x 与 y = x 之间绕 x 轴旋转的体积。

交点：√x = x ⇒ x = 0 或 1。

在 (0,1) 上 √x > x，外半径是 √x：

```text
V = π∫₀¹ [(√x)² - x²] dx = π∫₀¹ (x - x²) dx = π(1/2 - 1/3) = π/6
```

这个体积小于 π/2（例一），因为中间被挖掉了。

**例七，绕 y 轴用圆盘法。**

算 y = x²、y = 1、x = 0 围成的区域绕 y 轴旋转的体积。

沿 y 方向切，y ∈ [0, 1]，半径 x = √y：

```text
V = π∫₀¹ (√y)² dy = π∫₀¹ y dy = π/2
```

和用柱壳法算出来的结果一致。

两种方法都对，选计算量小的那个。

**为什么圆盘法要求"绕坐标轴"？**

因为圆盘的半径必须是"点到轴的距离"。

绕 x 轴时，点 (x, y) 到轴的距离就是 |y|，所以半径写成 y。

绕 x = 1 时，距离变成 |x - 1|，公式就要改：

```text
V = π∫ [(x-1) 的函数]² dy  或者  V = 2π∫ |x-1|·f(x) dx
```

具体用哪个，看哪个方向切条后半径好写。

**一个检验体积的办法。**

算出体积后，和"外接圆柱"比一比。

比如 y = √x 在 [0,1] 上绕 x 轴，外接圆柱半径 1、高 1，体积 π。

算出来 π/2，正好是一半，合理。

如果算出来比外接圆柱还大，肯定错了。

**一个常见的绕轴问题。**

区域绕 x = 1 旋转，怎么办？

半径不再是 x，而是 |x - 1|。

```text
V = 2π∫ₐᵇ |x - 1|·f(x) dx  （柱壳法）
```

原则只有一句：

```text
半径 = 点 到 旋转轴 的距离。
```

轴不是坐标轴时，这个距离要老老实实写出来。

## 6. 弧长

没有这一节，一根弯铁丝的长度只能靠估。

**直角坐标下的弧长公式：**

```text
s = ∫ₐᵇ √(1 + [y']²) dx
```

**这个根号从哪来？**

取一小段曲线，横向走 dx，纵向走 dy。

这一小段近似成直线，长度是勾股定理：

```text
ds = √(dx² + dy²) = √(1 + (dy/dx)²) dx = √(1 + y'²) dx
```

所以：

```text
s = ∫ ds = ∫ₐᵇ √(1 + y'²) dx
```

**四步公式：算弧长**

第一步，算什么：曲线在 [a,b] 上的长度。

第二步，逐符号：y' 是导数（切线斜率），1 + y'² 保证根号里大于 1，dx 是横向的微元。

第三步，代数字：算 y = (2/3)x^(3/2) 在 [0, 1] 上的弧长。

```text
y' = x^(1/2)
1 + y'² = 1 + x
s = ∫₀¹ √(1 + x) dx = [(2/3)(1+x)^(3/2)]₀¹
  = (2/3)(2^(3/2) - 1)
  = (2/3)(2√2 - 1)
```

第四步，适用条件：y 在 [a,b] 上必须有连续导数；如果导数在某点无穷（比如曲线竖直），要改用以 x 为 y 的函数，或者用参数方程。

**例二，参数方程。**

摆线：

```text
x = a(t - sin t)
y = a(1 - cos t)
```

求 t ∈ [0, 2π] 一拱的弧长。

参数方程的弧长公式：

```text
s = ∫_α^β √(x'² + y'²) dt
```

先算两个导数：

```text
x' = a(1 - cos t)
y' = a sin t
```

再算平方和：

```text
x'² + y'² = a²[(1 - cos t)² + sin²t]
          = a²[1 - 2cos t + cos²t + sin²t]
          = a²[2 - 2cos t]
          = 2a²(1 - cos t)
```

用半角公式 1 - cos t = 2sin²(t/2)：

```text
= 4a²sin²(t/2)
```

开根号（t ∈ [0, 2π] 时 sin(t/2) ≥ 0）：

```text
√(x'² + y'²) = 2a sin(t/2)
```

积分：

```text
s = ∫₀^(2π) 2a sin(t/2) dt = 2a·[-2cos(t/2)]₀^(2π)
  = 2a·(-2·(-1) + 2·1)
  = 2a·4 = 8a
```

摆线一拱的长度是 8a。

这个结果很干净：一拱的长度正好等于"生成圆"半径的 8 倍。

**例三，极坐标。**

极坐标的弧长公式：

```text
s = ∫_α^β √(r² + r'²) dθ
```

这个公式可以从参数方程推出来：把 x = r cos θ、y = r sin θ 代进去，化简后正好是这个形状。

算心形线 r = a(1 + cos θ) 的全长。

```text
r' = -a sin θ
r² + r'² = a²[(1+cos θ)² + sin²θ]
         = a²[1 + 2cos θ + cos²θ + sin²θ]
         = a²[2 + 2cos θ]
         = 4a²cos²(θ/2)
```

开根号要小心符号：θ ∈ [0, 2π] 时 cos(θ/2) 在 [0, π] 上非负、在 [π, 2π] 上非正。

所以：

```text
√(r² + r'²) = 2a|cos(θ/2)|
```

积分时按符号拆开，或者用对称性算一半乘 2：

```text
s = 2∫₀^π 2a cos(θ/2) dθ = 2·2a·[2sin(θ/2)]₀^π = 2·2a·2 = 8a
```

心形线的全长也是 8a，和摆线一拱一样长。

**三个公式的统一理解：**

```text
直角坐标：ds = √(1 + y'²) dx     横着切
参数方程：ds = √(x'² + y'²) dt   顺着参数走
极坐标：  ds = √(r² + r'²) dθ    按角度扫
```

三个都是勾股定理，只是"横"和"竖"的写法不同。

三个都是勾股定理，只是"横"和"竖"的写法不同。

**为什么弧长积分常常"算不出来"？**

因为根号 √(1 + y'²) 里含平方，很多情况下它不能化简成初等函数。

```text
y = x² 的弧长：∫√(1 + 4x²) dx，只能用双曲函数表示
椭圆周长：没有初等表达式
```

所以数一考的弧长，都是"能化简"的曲线：

```text
y = (2/3)x^(3/2)  →  根号里配成 1 + x
摆线             →  根号里配成平方
心形线           →  根号里配成 cos²(θ/2)
```

遇到算不出来的，先检查曲线选得对不对，而不是怀疑自己算错。

**例四，极坐标下最简单的弧长。**

算圆 r = 2a cos θ（θ ∈ [-π/2, π/2]）的周长。

```text
r' = -2a sin θ
r² + r'² = 4a²cos²θ + 4a²sin²θ = 4a²
√(r² + r'²) = 2a
```

被积函数是常数：

```text
s = ∫_{-π/2}^{π/2} 2a dθ = 2a·π = 2πa
```

半径 a 的圆，周长 2πa，对上了。

这个例子说明：极坐标弧长公式在圆上会退化成一个常数积分。

## 7. 旋转曲面面积

没有这一节，你算不出一个喇叭口要多少铁皮。

**公式：**

```text
S = 2π∫ₐᵇ |y|·√(1 + y'²) dx
```

**这个公式和体积公式的区别在哪？**

体积用的是"薄圆盘"，面积用的是"薄圆环带"。

```text
体积微元：dV = π y² dx      厚度是 dx，平的
面积微元：dS = 2π y ds      沿弧长展开，斜的
```

关键差别是：曲面是"斜着"的，所以厚度要用弧长微元 ds，不能用 dx。

**一个必须避免的错误：**

```text
错误：S = 2π∫ y dx
```

这个式子算的是"侧面积投影"，不是真实面积。

因为曲线是斜的，同样一段 dx，实际展开的长度是 ds > dx。

**四步公式：算旋转曲面面积**

第一步，算什么：曲线 y = f(x) 在 [a,b] 上绕 x 轴旋转扫出的曲面面积。

第二步，逐符号：y 是旋转半径，ds = √(1 + y'²) dx 是弧长微元，2π 是"转一圈的周长"。

第三步，代数字：算 y = √x 在 [0, 1] 上绕 x 轴旋转的面积。

先算导数：

```text
y' = 1/(2√x)
1 + y'² = 1 + 1/(4x)
```

代入：

```text
S = 2π∫₀¹ √x·√(1 + 1/(4x)) dx
```

把 √x 乘进根号：

```text
√x·√(1 + 1/(4x)) = √(x·(1 + 1/(4x))) = √(x + 1/4)
```

所以：

```text
S = 2π∫₀¹ √(x + 1/4) dx
  = 2π·(2/3)(x + 1/4)^(3/2)|₀¹
  = (4π/3)[(5/4)^(3/2) - (1/4)^(3/2)]
```

算两个幂：

```text
(5/4)^(3/2) = 5√5/8
(1/4)^(3/2) = 1/8
```

合并：

```text
S = (4π/3)·(5√5 - 1)/8 = (π/6)(5√5 - 1) ≈ 4.6
```

第四步，适用条件：y 在 [a,b] 上非负且导数连续；绕 x 轴时半径是 |y|，绕 y 轴时半径是 |x|；如果曲线跨过旋转轴，要分段。

**例二，球面面积。**

上半圆 y = √(R² - x²)，x ∈ [-R, R]，绕 x 轴转得到球面。

导数：

```text
y' = -x/√(R² - x²)
```

算根号里的量：

```text
1 + y'² = 1 + x²/(R² - x²) = R²/(R² - x²)
```

开根号：

```text
√(1 + y'²) = R/√(R² - x²)
```

被积函数是"半径乘弧长系数"：

```text
y·√(1 + y'²) = √(R² - x²) · R/√(R² - x²) = R
```

约掉了！于是：

```text
S = 2π∫_{-R}^{R} R dx = 2π·R·2R = 4πR²
```

球面积公式 4πR² 到这里才被推出来。

这个"约掉"不是巧合：球面上每一小块的法向都指向球心，展开后正好是"半径 R 的窄条"，面积自然与位置无关。

**绕 y 轴的情形。**

公式对偶地写成：

```text
S = 2π∫ |x| ds
```

半径换成"点到 y 轴的距离"，也就是 |x|。

例：y = x² 在 [0,1] 上绕 y 轴旋转，求曲面面积。

```text
y' = 2x，ds = √(1 + 4x²) dx
S = 2π∫₀¹ x√(1 + 4x²) dx
```

令 u = 1 + 4x²，du = 8x dx：

```text
S = 2π·(1/8)∫₁⁵ √u du = (π/4)·(2/3)u^(3/2)|₁⁵
  = (π/6)(5√5 - 1)
```

和例一的结果一样，因为例一是把 y = √x 绕 x 轴转，两者互为 x 与 y 互换，曲面形状相同，面积自然相同。

## 8. 物理应用

没有这一节，数一物理应用那几分只能放弃。

物理题的套路和几何题完全一样，只换一个"微元"的解释。

**类型一，变力做功。**

```text
W = ∫ₐᵇ F(x) dx
```

意思是：把路径切成很多小段，每段上力近似不变，功 = F(x)·dx，加起来就是积分。

**例一，弹簧。**

弹簧的力满足 F = kx（k 是劲度系数，x 是伸长量）。

从自然长度拉到 a，做功：

```text
W = ∫₀^a kx dx = kx²/2 |₀^a = ka²/2
```

这个结果说明：拉伸量翻倍，做功变成四倍。

**例二，抽水做功。**

一个圆柱形水池，底面半径 R，深 H，装满水，把水全部抽到池口，求做功。

设水面高度为 x，取一层厚 dx 的水。

这一层的水要提升的高度是 (H - x)（离池口的距离），它的重量是：

```text
ρg·πR²·dx
```

功微元：

```text
dW = ρgπR²(H - x) dx
```

积分：

```text
W = ρgπR²∫₀^H (H - x) dx = ρgπR²·H²/2
```

量纲检验：ρg 是"力/体积"，乘以体积 πR²H 是力，再乘高度 H 是"功"，正确。

**类型二，水压力。**

```text
P = ρg∫ h·w(h) dh
```

其中 h 是深度，w(h) 是该深度处闸门的宽度。

**例三，半圆形闸门。**

半径 R 的半圆闸门，直边与水面齐平，垂直放置，求一侧所受的水压力。

设深度为 y，该处闸门的宽度是 2√(R² - y²)（半圆在该高度的弦长）。

压强是 ρgy，所以压力微元：

```text
dP = ρgy·2√(R² - y²) dy
```

积分：

```text
P = 2ρg∫₀^R y√(R² - y²) dy
```

令 u = R² - y²，du = -2y dy：

```text
∫ y√(R²-y²) dy = -(1/3)(R² - y²)^(3/2)
```

代上下限：

```text
P = 2ρg·[-(1/3)(R²-y²)^(3/2)]₀^R = 2ρg·(R³/3) = (2/3)ρgR³
```

结果和 R³ 成正比，符合量纲。

**类型三，质心（形心）。**

均匀薄板的形心坐标：

```text
x̄ = (∫ x·dA) / A
ȳ = (∫ y·dA) / A
```

分母是面积，分子是"面积矩"。

**例四，半圆板的形心。**

半径 R 的半圆板，直边在 x 轴上。

由对称性 x̄ = 0。

ȳ 用水平窄条算，深度 y 处条宽 2√(R² - y²)：

```text
∫ y·dA = ∫₀^R y·2√(R²-y²) dy = 2R³/3
A = πR²/2
ȳ = (2R³/3)/(πR²/2) = 4R/(3π)
```

所以形心在 (0, 4R/(3π))，比 R/2 稍高一点，因为在圆心附近"材料更多"。

**类型四，转动惯量（了解即可）。**

```text
I = ∫ x² dm
```

意思是"每一小块的质量乘上它到轴距离的平方"，再加起来。

数一不常考，但二重积分那一篇会给它的二维版本。

**类型五，平均值。**

```text
ȳ = (1/(b-a))∫ₐᵇ f(x) dx
```

这是积分中值定理的直接应用。

例：算 f(x) = x² 在 [0, 1] 上的平均值。

```text
ȳ = ∫₀¹ x² dx = 1/3
```

函数在 [0,1] 上从 0 增到 1，平均值 1/3 落在中间，符合直觉。

物理里的"平均速度""平均功率"，用的都是这个式子。

**一个通用提醒：**

做物理应用题，先写三件事：

```text
1. 微元是什么（一层水？一小段弹簧？一条窄条？）
2. 微元的量怎么算（重量？压力？面积？）
3. 积分变量和范围
```

三件事写清，积分就是机械动作。

## 9. 常见错误

没有这一节，设式环节会反复翻车。

**错误一：上下曲线搞反。**

算出负面积就是信号。

先画个草图，或者代一个中间点比较大小。

**错误二：交点没求全。**

y = x 与 y = x³ 有三个交点，只求出一个，面积就少算一半。

**错误三：旋转体半径写错。**

绕 x = 1 旋转，半径是 |x - 1|，不是 x。

半径的定义永远是"点到旋转轴的距离"。

**错误四：旋转曲面面积用 dx 代替 ds。**

```text
错误：S = 2π∫ y dx
正确：S = 2π∫ y ds
```

曲面是斜的，展开长度比 dx 长。

**错误五：弧长公式漏掉 1。**

```text
错误：s = ∫ y' dx
正确：s = ∫ √(1 + y'²) dx
```

s = ∫ y' dx 只在 y' 恒为常数时才对，那是直线。

**错误六：极坐标面积漏掉 1/2 或漏掉平方。**

```text
错误：A = ∫ r dθ
错误：A = ∫ r² dθ
正确：A = (1/2)∫ r² dθ
```

**错误七：水压力题把深度和宽度混成一个变量。**

深度是积分变量，宽度是深度的函数 w(h)。

两个都要写出来，代进去才不会乱。

**错误八：只写公式，不写区间和微元。**

解答题的评分点里，"设 dV = πy²dx，积分区间 [0,1]"这样的句子本身就有分。

直接写一个结果，即使对了也拿不满。

**错误九：把"体积"和"容积"混用。**

体积是几何量，容积是"能装多少"。

一个开口容器的容积，等于内表面围出的体积，边界判断不一样。

题目说"容器能装多少水"，要看清水面在哪。

**错误十：量纲不检验。**

面积算出来是"长度³"，体积算出来是"长度²"，说明微元写错。

十秒钟的量纲检查，比重新算一遍便宜。

## 10. 数一怎么考

没有这一节，你不知道该练哪几种图形。

**题型一：直角坐标面积。**

最常见的形式是"求由曲线 y = ... 与直线 ... 围成的面积"。

步骤固定：求交点 → 判上下 → 分段 → 积分。

**题型二：极坐标面积。**

曲线通常是心形线、双纽线、圆。

关键是先定 θ 的范围（由 r ≥ 0 决定），再套 (1/2)∫r²dθ。

**题型三：旋转体体积。**

这是必考内容，且经常和"参数"结合。

例：设曲线 y = x² 与 y = ax 围成的区域绕 x 轴旋转，求 a 使体积最大。

先求交点：x² = ax ⇒ x = 0 或 x = a（设 a > 0）。

体积：

```text
V(a) = π∫₀^a [(ax)² - (x²)²] dx
     = π∫₀^a (a²x² - x⁴) dx
     = π[a²·a³/3 - a⁵/5]
     = πa⁵(1/3 - 1/5)
     = 2πa⁵/15
```

V 随 a 单调增加，没有最大值（a 可以无限大）。

如果题目加约束（比如 a ≤ 1），则 a = 1 时最大。

这类题的陷阱是"忘了约束条件"，导致结论是"无最大值"。

**题型四：弧长。**

常以填空形式出现，或者作为参数方程题的一问。

注意根号下的化简，很多时候能配成完全平方。

**题型五：物理应用。**

做功和水压力各考一种，通常在选择填空里。

记住三个微元：

```text
抽水：dW = ρg·(截面积)·(提升高度) dx
水压力：dP = ρg·(深度)·(宽度) dy
弹簧：dW = kx dx
```

**题型六：与微分方程结合。**

例：已知曲线上任一点 (x, y) 处的切线、该点与 y 轴的垂线、x 轴围成的三角形面积等于 2，求曲线方程。

这类题先用几何条件列方程，再解微分方程。

它同时考"设式"和"解方程"，是数一压轴题的常见结构。

**题型七：由已知面积反求参数或曲线。**

例：曲线 y = a√x（a > 0）与 y = x 围成的面积是 1/6，求 a。

先求交点：a√x = x ⇒ x = 0 或 x = a²（两边平方得 a²x = x²）。

在 (0, a²) 上比较大小，代 x = a²/4：

```text
a√(a²/4) = a²/2，而 x = a²/4
所以 a√x 在上面
```

面积：

```text
∫₀^(a²) (a√x - x) dx = [a·(2/3)x^(3/2) - x²/2]₀^(a²)
= (2a/3)(a²)^(3/2) - a⁴/2
= (2a/3)a³ - a⁴/2
= (2/3)a⁴ - (1/2)a⁴
= a⁴/6
```

令 a⁴/6 = 1/6，得 a⁴ = 1，a = 1。

这类题的思路是"正向设式，反向解方程"。

设式部分的分值占大头，解方程只是收尾。

## 11. 和其他章节怎么连

没有这一节，这些公式会变成孤立的一堆。

**往回连：07 定积分。**

这一篇的每一个公式，都是"定积分 + 一个微元"。

07 篇的换元、分部、对称性，在这里全部用得上。

**往回连：05 导数的应用。**

几何题里求"体积最大""面积最小"，最后一步是求导找极值。

05 篇的单调性与极值判定，在这里负责收尾。

**往回连：03 导数与微分。**

弧长、曲面面积公式里的 y' 和 ds，都来自微分。

理解 ds = √(dx² + dy²)，比背公式重要。

**往前连：09 反常积分。**

"无穷长的曲线""无界的区域"面积，要用反常积分。

这一篇的公式照用，只是区间变成无穷。

**横向连：12 二重积分。**

二重积分算面积和体积，和这一篇是同一个思想：

```text
二重积分：把区域切成小方块，dA = dx dy
这一篇：把区域切成细条，dA = (高) dx
```

细条法是二重积分在特殊区域上的简化版。

**横向连：13 三重积分。**

质量、质心、转动惯量的三重积分版本，和这一篇的物理应用完全对应。

**一个整体视角。**

这一篇真正教的只有一件事：

```text
把"总量"切成"微元"，把"微元"写成"函数 × 微变量"，再积分。
```

四个几何量、三个物理量，都是这一句话的实例。

考场上遇到没见过的应用题，也还是这一句话。

### 自检三问

**第一问：微元法里的"微元"为什么可以近似成规则形状？**

因为误差是 dx 的高阶无穷小。

把窄条当成矩形，差出来的是一个小三角形，面积与 dx² 同阶。

积分是"求和再取极限"，这些高阶小量的和在 dx → 0 时趋于 0，所以不影响结果。

**第二问：绕 y 轴旋转，用圆盘法和柱壳法分别怎么设？**

圆盘法是"沿 y 方向切"：

```text
V = π∫ x² dy
```

柱壳法是"沿 x 方向切"：

```text
V = 2π∫ x·f(x) dx
```

两者结果相同，选哪个取决于"哪个方向的边界更好表示"。

如果曲线是 y = f(x) 且能解出 x，两种都行；如果解不出 x，用柱壳法。

**第三问：极坐标面积公式里的 1/2 和 r² 从哪来？**

来自小扇形的面积。

角度从 θ 增到 θ + dθ，半径 r 扫出一块细扇形，面积是 (1/2)r²dθ。

这是扇形面积公式 (1/2)r²θ 的微分版本。

## 12. 小结

没有小结，这一堆公式会变成需要硬背的清单。

把这一篇压成一张卡片：

```text
面积：A = ∫ [上 - 下] dx
极坐标：A = (1/2)∫ r² dθ
体积：V = π∫ y² dx（圆盘）、π∫(外² - 内²)dx（垫圈）、2π∫ xy dx（柱壳）
弧长：s = ∫ √(1 + y'²) dx（直角）、∫√(x'²+y'²)dt（参数）、∫√(r²+r'²)dθ（极坐标）
曲面：S = 2π∫ y ds
物理：W = ∫F dx、P = ρg∫ h w dh
```

公式虽多，来源只有一个：

```text
切一小条 → 把这一条当成规则形状 → 写出微元 → 积分。
```

四步公式在这一篇的用法：

```text
算什么 → 逐符号 → 代数字 → 适用条件
```

"适用条件"这一步在应用题里格外重要：

```text
上下曲线不能交叉、半径必须是非负距离、被积函数要能积分出来。
```

三个条件任一不满足，设式就得改。

考场上遇到应用题，按这个顺序走：

```text
1. 画草图，标出交点和边界
2. 选积分变量（沿哪个方向切最省事）
3. 写微元（面积/体积/弧长/功）
4. 定区间（交点或题目条件）
5. 积分并检验量级与符号
```

五步走完，一般不会错。

时间分配上，一道 10 分的应用题建议这样用：

```text
画图与设式：3 分钟
算积分：    4 分钟
检验与写答：2 分钟
留 1 分钟复查符号和量纲
```

设式花的时间比算积分多，这是正常的。

因为设式决定对错，计算只决定快慢。

最后一句：

```text
这一篇的所有公式都会忘，但"切一小条再积分"这个动作要留下。
```

公式忘了可以现场推，动作忘了就无从下手。

这一篇的所有公式都假设"区间有限、函数有界"。

如果区间无限长，或者函数在某点附近趋向无穷，公式还成立吗？

```text
高等数学系统讲解 09：反常积分
```

那一篇会回答：

```text
无穷长的曲线下的面积，可能是有限的吗？
函数在一点附近爆掉，积分还能算吗？
怎么判断一个反常积分收敛还是发散？
```
