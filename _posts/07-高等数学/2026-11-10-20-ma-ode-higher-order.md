> **读这篇之前，你只需要知道**：一阶方程里只出现 y'，解出来带一个任意常数；二阶方程里会出现 y''（二阶导数），它描述的是"变化率本身的变化率"，也就是加速度；一元二次方程 ax² + bx + c = 0 的根由判别式 Δ = b² − 4ac 决定，Δ 有三种情况。
> **这篇讲什么**：二阶常系数线性方程的解，可以完全由一条一元二次方程（特征方程）定下来；这一篇讲清三种根对应三种解的形状，再讲右端不为零时怎么补一个特解，最后处理可降阶和欧拉方程两类变形。
> **一个类比**：弹簧振子。拉一下松手，它来回摆；摆的快慢和衰减快慢由两个旋钮（劲度、阻尼）决定，特征方程的根就是这两个旋钮算出来的两个数字。

先看一个东西。

一根弹簧，挂一个小球。

拉离平衡位置，松手。

它会来回振动，而且幅度慢慢变小。

写成方程：

```text
x'' + 2x' + 5x = 0
```

x 是小球离开平衡位置的距离，x' 是速度，x'' 是加速度。

三项各有一个物理含义：

```text
x''：加速度，对应"惯性"
2x'：阻力，正比于速度，越大越难动
5x：回复力，正比于位移，拉得越远拉回来越猛
```

这个方程怎么解？

猜不出来，因为里面既有 x、又有 x'、又有 x''，三者还互相牵制。

但答案其实很规整：

```text
x = e^{−t}(C₁ cos 2t + C₂ sin 2t)
```

代 t = 0，取 C₁ = 1、C₂ = 0：

```text
x = e^{−t} cos 2t
```

图像是一条"边振边衰"的曲线：

```text
 1 ┤╮
   │ ╰╮
 0 ┼───╰─╮──╮──╮─
   │     ╰╯  ╰╯
−1 ┤
```

振动频率是 2，衰减速度是 e^{−t}。

**这两个数字，来自一个一元二次方程。**

```text
r² + 2r + 5 = 0
```

它的根是：

```text
r = −1 ± 2i
```

实部 −1 决定衰减，虚部 2 决定振动。

**整章的核心就是这句话：二阶常系数方程的解，由一条一元二次方程的根决定。**

那条方程叫特征方程。

## 1. 为什么需要它（不给会怎样）

**第一处，一阶方程描述不了"惯性"。**

一阶方程 y' = f(x, y) 里，变化率直接由当前状态决定。

没有"上一刻还在往那边走，所以这一刻还要往那边走"这种效应。

弹簧、单摆、电路里的电感，全都有这种效应。

描述它必须有二阶导数。

**第二处，物理定律大多是二阶的。**

```text
牛顿第二定律：m x'' = F
单摆：θ'' + (g/L) sin θ = 0
RLC 串联电路：L q'' + R q' + q/C = E(t)
梁的弯曲：EI y'''' = q(x)
```

牛顿第二定律里，力对应加速度，加速度是位移的二阶导数。

所以只要涉及"力 → 运动"，方程就是二阶的。

**第三处，考试必考，而且分值重。**

数一每年一道二阶常系数非齐次方程的题，10 分。

有时是纯计算，有时套一个物理背景。

套路固定，是整张卷子里最容易拿满分的解答题之一。

**第四处，它是"线性方程"这套理论的样板。**

高阶线性方程的解的结构，和二阶完全一样。

学会了二阶，三阶、四阶只是多几个根。

所以这一章表面讲二阶，实际讲的是"线性方程怎么组织它的解"。

**不给它会怎样，一句话。**

```text
所有带惯性、带回弹、带振荡的现象，都没法用数学描述。
```

## 2. 最小模型：二阶线性方程的解怎么组织

没有这一节，你会以为"解"就是一个函数，不明白为什么它一定带两个常数，也不知道特解该往哪放。

**标准形。**

```text
y'' + p y' + q y = f(x)
```

逐符号读：

```text
y''      y 的二阶导数，读"y 两撇"
p, q     常数（这一章只讨论常系数）
f(x)     右端项，叫自由项
```

p、q 是常数，这叫"常系数"。

f(x) = 0 时，叫齐次方程。

f(x) ≠ 0 时，叫非齐次方程。

**注意"齐次"这个词第三次出现。**

19 篇有两种用法：y/x 型、右端为零。

这一章只有一种：右端为零。

**解的结构，一条定理。**

非齐次方程的通解，等于：

```text
齐次方程的通解 + 非齐次方程的一个特解
```

写成式子：

```text
y = C₁y₁ + C₂y₂ + y*
```

其中 y₁、y₂ 是齐次方程的两个线性无关解，y* 是非齐次的某一个特解。

**为什么是这样。**

两条理由。

第一条，齐次部分的任意组合还是齐次解。

把 C₁y₁ + C₂y₂ 代进左边，每一项都单独为 0，加起来还是 0。

第二条，非齐次的两个解之差是齐次解。

设 y_a、y_b 都满足非齐次方程。

相减：

```text
(y_a − y_b)'' + p(y_a − y_b)' + q(y_a − y_b) = f − f = 0
```

所以它们的差满足齐次方程。

**两条合起来说明：非齐次的所有解，都可以由一个特解加上齐次通解得到。**

这就是"通解 = 齐次通解 + 一个特解"的来历。

**什么叫线性无关。**

两个函数 y₁、y₂ 线性无关，意思是：

```text
不存在常数 k，使 y₁ = k y₂
```

也就是它们的比值不是常数。

```text
e^x 和 e^{2x}     比值 e^{−x}，不是常数 → 无关
e^x 和 3e^x       比值 1/3，是常数 → 相关
sin x 和 cos x    比值 tan x，不是常数 → 无关
```

**为什么要两个无关的解。**

因为二阶方程的通解要含两个任意常数。

如果 y₁ 和 y₂ 相关，那 C₁y₁ + C₂y₂ 其实只有一个自由度，凑不出全部解。

**一条更硬的判据。**

把两个解摆成行列式：

```text
W = | y₁  y₂  |
    | y₁' y₂' |
```

这个行列式叫朗斯基行列式（Wronskian）。

W ≠ 0 就线性无关，W = 0 就线性相关。

对常系数方程来说，两个不同的特征根给出的 e^{r₁x} 和 e^{r₂x}，W 恒不为 0。

所以"两根不同"这一条，已经保证了无关性。

数一不要求算 W，只要知道"不同根就无关"即可。

**初值条件也是两条。**

```text
y(x₀) = y₀
y'(x₀) = y₀'
```

二阶方程需要两个条件：一个定位置，一个定速度。

这和物理直觉一致：知道小球现在在哪、现在多快，就能定出它之后的全部运动。

**四步公式，结构版本。**

```text
算什么：把二阶方程拆成"齐次通解"和"一个特解"两块，分别求
逐符号：C₁、C₂ 是任意常数，y₁、y₂ 是齐次的两个无关解，y* 是特解
代数字：y''−3y'+2y = e^{3x} → 齐次 C₁e^x + C₂e^{2x}，特解 e^{3x}/2
适用条件：方程必须是线性的、常系数的；变系数要另想办法
```

**这张结构图记住，后面全是填空。**

```text
                     ┌─ 齐次通解：C₁y₁ + C₂y₂（两个常数）
y（非齐次通解）──────┤
                     └─ 一个特解：y*（不含常数）
```

## 3. 可降阶的三种类型

没有这一节，缺 y 或缺 x 的方程会被当成常系数方程硬套，套到一半就卡住。

有些二阶方程不含 y 或 y'，可以直接降成一阶。

这一类题不难，但必须先认出类型。

**类型一：y'' = f(x)。**

右边只有 x，没有 y，也没有 y'。

解法：连积两次。

```text
y' = ∫ f(x) dx + C₁
y  = ∫ [∫ f(x) dx] dx + C₁x + C₂
```

**例：y'' = 6x。**

```text
y' = 3x² + C₁
y  = x³ + C₁x + C₂
```

**类型二：缺 y。**

方程形如：

```text
y'' = f(x, y')
```

右边有 x 和 y'，但没有 y。

解法：令 p = y'，则 p' = y''。

方程变成一阶：

```text
p' = f(x, p)
```

解出 p，再积分一次得 y。

**例：x y'' = y'（x > 0）。**

令 p = y'：

```text
x p' = p
dp/p = dx/x
ln|p| = ln x + C
p = C₁ x
```

再积分：

```text
y = C₁x²/2 + C₂
```

**类型三：缺 x。**

方程形如：

```text
y'' = f(y, y')
```

右边有 y 和 y'，但没有 x。

解法：令 p = y'，但这次要把 y'' 换成对 y 的导数。

因为 p 是 x 的函数，而 y 也是 x 的函数，用链式法则：

```text
y'' = dp/dx = (dp/dy)(dy/dx) = p · dp/dy
```

方程变成：

```text
p dp/dy = f(y, p)
```

这是关于 p 和 y 的一阶方程，解出 p 后再用 dy/dx = p 积分。

**例：y y'' + (y')² = 0。**

令 p = y'，y'' = p dp/dy：

```text
y p dp/dy + p² = 0
```

除以 p（p ≠ 0）：

```text
y dp/dy = −p
dp/p = −dy/y
ln|p| = −ln|y| + C
p = C₁/y
```

回代 p = dy/dx：

```text
dy/dx = C₁/y
y dy = C₁ dx
y²/2 = C₁x + C₂
y² = C₃x + C₄
```

**三种类型的判别表。**

```text
y'' = f(x)        缺 y 也缺 y'   → 连积两次
y'' = f(x, y')    缺 y           → p = y'，对 x 求导
y'' = f(y, y')    缺 x           → p = y'，y'' = p dp/dy
```

**判断的关键是"缺谁"。**

```text
看方程里有没有 y：没有 → 类型二
看方程里有没有 x：没有 → 类型三
两个都没有 → 类型一
```

**四步公式，降阶版本。**

```text
算什么：把二阶降成一阶，用 19 篇的方法解掉，再积回去
逐符号：p = y' 是新未知函数；缺 x 时 y'' = p dp/dy
代数字：x y'' = y' → p = C₁x → y = C₁x²/2 + C₂
适用条件：必须真的缺某一个变量；降阶后常数个数仍是两个
```

**一个容易错的点。**

缺 x 时，y'' = p dp/dy 这个换元是必须的。

如果直接写 y'' = p'，那 p' 是对 x 求导，方程里还留着 x，降不下去。

## 4. 特征方程：r² + pr + q = 0

没有这一节，三种根对应三种解就只是三条要背的结论，用一次错一次。

这一节是整章的心脏。

**先猜一个解的形状。**

对于：

```text
y'' + p y' + q y = 0
```

什么样的函数，求两次导之后还能和原函数凑成 0？

指数函数符合要求。

因为 e^{rx} 求导只是乘一个 r：

```text
(e^{rx})' = r e^{rx}
(e^{rx})'' = r² e^{rx}
```

**代进去试试。**

设 y = e^{rx}：

```text
r² e^{rx} + p r e^{rx} + q e^{rx} = 0
```

提出公因子 e^{rx}：

```text
(r² + p r + q) e^{rx} = 0
```

e^{rx} 永远不为 0。

所以只能：

```text
r² + p r + q = 0
```

**这条一元二次方程就叫特征方程。**

读作"r 平方 加 p 乘 r 加 q 等于零"。

r 叫特征根。

**为什么它这么重要。**

因为它把一个"微分方程"的问题，换成了一个"解一元二次方程"的问题。

微分方程不好解，一元二次方程谁都会解。

**三种根，三种解。**

判别式 Δ = p² − 4q。

```text
Δ > 0：两个不同的实根 r₁, r₂
Δ = 0：一个二重实根 r
Δ < 0：一对共轭复根 α ± βi
```

**情形一：两个不同实根。**

```text
y = C₁ e^{r₁x} + C₂ e^{r₂x}
```

理由：e^{r₁x} 和 e^{r₂x} 都是解，比值 e^{(r₁−r₂)x} 不是常数，所以线性无关。

两个无关解凑齐，通解就是它们的组合。

**情形二：二重根 r。**

```text
y = (C₁ + C₂ x) e^{rx}
```

**为什么多乘一个 x。**

因为只有一个根，只能给出一个解 e^{rx}。

需要第二个无关解，猜它形如 u(x)e^{rx}。

代进方程，会得到 u'' = 0。

所以 u = C₁ + C₂x。

**这个"乘 x"的动作，后面还会出现两次。**

一次是非齐次特解遇到共振。

一次是欧拉方程遇到重根。

三处的理由相同：原来的形状已经被占用，得乘一个 x 才能造出新的无关解。

**情形三：共轭复根 α ± βi。**

```text
y = e^{αx} ( C₁ cos βx + C₂ sin βx )
```

**为什么复根会变成三角函数。**

因为 e^{(α+βi)x} 可以用欧拉公式拆开：

```text
e^{(α+βi)x} = e^{αx} · e^{iβx} = e^{αx}(cos βx + i sin βx)
```

实部和虚部分别是解（因为方程是实系数的）。

于是得到两个实值解：

```text
e^{αx} cos βx
e^{αx} sin βx
```

它们的组合就是通解。

**三种情形合起来看。**

```text
Δ > 0   r₁ ≠ r₂ 实根    y = C₁e^{r₁x} + C₂e^{r₂x}
Δ = 0   r 重根          y = (C₁ + C₂x)e^{rx}
Δ < 0   α ± βi          y = e^{αx}(C₁cos βx + C₂sin βx)
```

**怎么记。**

只看三个东西：

```text
根是实的还是复的 → 决定有没有三角函数
根重不重         → 决定要不要乘 x
根的实部         → 决定整体的增减（e^{αx}）
根的虚部         → 决定振动的快慢（cos βx、sin βx）
```

**四步公式，齐次版本。**

```text
算什么：把微分方程换成一条一元二次方程，用它的根拼出通解
逐符号：r 是特征根；p 是 y' 的系数，q 是 y 的系数
代数字：y''+2y'+5y=0 → r²+2r+5=0 → r=−1±2i → e^{−t}(C₁cos2t+C₂sin2t)
适用条件：只对常系数线性齐次方程有效；变系数不适用
```

**判别式还有一种更快的算法。**

对标准形 y'' + py' + qy = 0：

```text
p² − 4q 的正负，决定振荡与否
```

因为判别式就是 p² − 4q，不用真的去解方程就能判断类型。

比如 y'' + 3y' + 1 = 0：

```text
p = 3，q = 1
p² − 4q = 9 − 4 = 5 > 0
```

所以是两个实根，解不振荡。

再如 y'' + y' + 1 = 0：

```text
p² − 4q = 1 − 4 = −3 < 0
```

所以是复根，解振荡。

**这个判断在物理上有直接含义。**

```text
p² > 4q：阻尼太大，回不到平衡就慢慢爬回去（过阻尼）
p² = 4q：临界，最快回到平衡且不过冲（临界阻尼）
p² < 4q：阻尼太小，来回振荡着衰减（欠阻尼）
```

汽车减震器设计就卡在第二种情形上：既要快，又不能来回颠。

**一个必须提醒的坑。**

特征方程里，y'' 的系数要当成 1。

如果题目给的是：

```text
2y'' + 3y' + y = 0
```

要先除以 2，化成标准形：

```text
y'' + 1.5y' + 0.5y = 0
```

然后特征方程是 r² + 1.5r + 0.5 = 0。

不做除法直接写 r² + 3r + 1 = 0 是错的（除非只关心根的相对关系，但通解里的系数会全错）。

## 5. 手算：三种根各一例

**例 1：解 y'' − 3y' + 2y = 0，且 y(0) = 0，y'(0) = 1。**

第一步，写特征方程。

y'' 系数是 1，y' 系数是 −3，y 系数是 2。

```text
r² − 3r + 2 = 0
```

第二步，解。

因式分解：

```text
(r − 1)(r − 2) = 0
r₁ = 1，r₂ = 2
```

两个不同实根，属于情形一。

第三步，写通解。

```text
y = C₁ e^x + C₂ e^{2x}
```

第四步，代第一个初值。

```text
y(0) = C₁ + C₂ = 0
```

所以 C₁ = −C₂。

第五步，先求导，再代第二个初值。

```text
y' = C₁ e^x + 2C₂ e^{2x}
y'(0) = C₁ + 2C₂ = 1
```

把 C₁ = −C₂ 代入：

```text
−C₂ + 2C₂ = 1
C₂ = 1
C₁ = −1
```

第六步，写答案。

```text
y = e^{2x} − e^x
```

**验算。**

```text
y(0) = 1 − 1 = 0
y' = 2e^{2x} − e^x，y'(0) = 2 − 1 = 1
y'' = 4e^{2x} − e^x
y'' − 3y' + 2y = (4e^{2x} − e^x) − 3(2e^{2x} − e^x) + 2(e^{2x} − e^x)
              = 4e^{2x} − e^x − 6e^{2x} + 3e^x + 2e^{2x} − 2e^x
              = 0
```

对上。

**这个解的形状值得看一眼。**

x 很大时，e^{2x} 压过 e^x，所以 y 最终按 e^{2x} 增长。

初值那一瞬间 y 是 0，但增长速度是 1，所以先下探再上升（因为 e^{2x} − e^x 在 x < 0 时是负的？实际上 x>0 时 e^{2x} > e^x，所以一直为正，且从 0 开始上升）。

**例 2：解 y'' − 4y' + 4y = 0，且 y(0) = 1，y'(0) = 0。**

第一步，特征方程。

```text
r² − 4r + 4 = 0
```

第二步，解。

```text
(r − 2)² = 0
r = 2（二重根）
```

属于情形二。

第三步，写通解。

```text
y = (C₁ + C₂x) e^{2x}
```

**注意括号里的 C₂x，不能漏。**

第四步，代 y(0) = 1。

```text
y(0) = C₁ · 1 = 1
C₁ = 1
```

第五步，求导。

```text
y = (1 + C₂x) e^{2x}
y' = C₂ e^{2x} + 2(1 + C₂x) e^{2x}
   = [C₂ + 2 + 2C₂x] e^{2x}
```

代 y'(0) = 0：

```text
C₂ + 2 = 0
C₂ = −2
```

第六步，写答案。

```text
y = (1 − 2x) e^{2x}
```

**验算 x = 0。**

```text
y(0) = 1
y' = [−2 + 2 − 4x]e^{2x} = −4x e^{2x}
y'(0) = 0
```

对上。

**顺便验证方程。**

```text
y = (1−2x)e^{2x}
y' = −4x e^{2x}
y'' = −4e^{2x} − 8x e^{2x}
y'' − 4y' + 4y = (−4 − 8x)e^{2x} + 16x e^{2x} + (4 − 8x)e^{2x}
              = (−4 − 8x + 16x + 4 − 8x)e^{2x} = 0
```

对上。

**例 3：解 y'' + 2y' + 5y = 0。**

第一步，特征方程。

```text
r² + 2r + 5 = 0
```

第二步，用求根公式。

```text
r = [−2 ± √(4 − 20)]/2 = [−2 ± √(−16)]/2 = −1 ± 2i
```

所以 α = −1，β = 2。

第三步，写通解。

```text
y = e^{−x}(C₁ cos 2x + C₂ sin 2x)
```

**答案：y = e^{−x}(C₁ cos 2x + C₂ sin 2x)。**

第四步，验算。

取 C₁ = 1，C₂ = 0：

```text
y = e^{−x} cos 2x
y' = −e^{−x}cos 2x − 2e^{−x} sin 2x
y'' = e^{−x}cos 2x + 2e^{−x}sin 2x + 2e^{−x}sin 2x − 4e^{−x}cos 2x
    = −3e^{−x}cos 2x + 4e^{−x} sin 2x
```

代入：

```text
y'' + 2y' + 5y = (−3cos2x + 4sin2x)e^{−x}
               + 2(−cos2x − 2sin2x)e^{−x}
               + 5cos2x e^{−x}
             = e^{−x}[−3 − 2 + 5]cos2x + e^{−x}[4 − 4]sin2x
             = 0
```

对上。

**三道题的类型对照。**

```text
例 1：Δ > 0，两个实根      → 两条指数相加
例 2：Δ = 0，二重根        → 指数乘一个一次多项式
例 3：Δ < 0，共轭复根      → 指数乘三角函数
```

**一个几何直觉。**

```text
实根：单调地增或减，没有振荡
重根：先增后减或先减后增，临界状态，也不会振荡
复根：一定有振荡，因为 cos 和 sin 在来回
```

所以判断"解会不会振荡"，只看判别式的符号。

## 6. 非齐次方程：特解怎么设

没有这一节，非齐次方程只能停在"齐次通解"，答案永远不完整。

齐次部分解决了，剩下 y'' + py' + qy = f(x)。

按第 2 节的结构，只需要再找一个特解 y*。

**问题在于：特解不能乱猜。**

猜错了，代进去系数全部矛盾，白算。

但右端 f(x) 只有有限的几种形状，特解的形状可以照着它设。

这叫待定系数法。

**类型一：f(x) = P_m(x) e^{λx}。**

P_m 是一个 m 次多项式，λ 是一个常数。

设：

```text
y* = x^k Q_m(x) e^{λx}
```

逐符号：

```text
Q_m(x)   一个 m 次的待定多项式，系数待定
e^{λx}   照抄右端的指数部分
x^k      k 是修正因子，只取 0、1、2 三种值
```

**k 怎么定。**

看 λ 是不是特征根。

```text
λ 不是特征根           → k = 0
λ 是特征方程的单根      → k = 1
λ 是特征方程的重根      → k = 2
```

**为什么会有 x^k 这一项。**

因为如果不乘，设出来的 y* 会落进齐次解的空间里。

那时候左边算出来是 0，永远等于不了右端。

这个现象叫共振。

**举一个最小的例子看清共振。**

方程：

```text
y' − y = e^x
```

右端 λ = 1，而齐次方程 y' − y = 0 的解是 Ce^x。

如果设 y* = Ae^x，代入：

```text
Ae^x − Ae^x = 0 ≠ e^x
```

左边恒为 0，定不出 A。

改设 y* = Axe^x：

```text
y*' = Ae^x + Axe^x
y*' − y* = Ae^x
```

要求等于 e^x，得 A = 1。

所以 y* = xe^x。

**乘一个 x，正好躲开齐次解。**

**类型二：f(x) = e^{αx}[P_l(x) cos βx + P_n(x) sin βx]。**

这里出现了三角函数，处理方式类似。

设：

```text
y* = x^k e^{αx}[ R_m(x) cos βx + S_m(x) sin βx ]
```

其中：

```text
m = max(l, n)，取两个多项式次数的较大者
R_m、S_m 是两个 m 次待定多项式
k 的取法：α ± βi 是特征根则 k = 1，否则 k = 0
```

**两个细节必须注意。**

第一，cos 和 sin 必须同时出现。

即使右端只有 cos，也要在解里同时设 cos 和 sin。

因为求导会把 cos 变成 sin，只设一个凑不齐。

第二，R_m 和 S_m 的次数要取两者较大者。

右端是 x cos x 时，m = 1，两个多项式都要设成一次。

**k 的判定，换成复数说法更清楚。**

把右端的"频率"写成复数：

```text
α + βi
```

看它是不是特征根。

```text
不是特征根 → k = 0
是特征根   → k = 1
```

对二阶方程，α + βi 只可能是单根（重根只能是实数），所以 k 最多取 1。

**四步公式，特解版本。**

```text
算什么：照着右端的形状设一个带未知系数的特解，代进去定系数
逐符号：P_m 是多项式，λ 或 α±βi 是"频率"，x^k 是修正因子
代数字：y''−3y'+2y = e^{3x}，λ=3 不是根，k=0，设 y*=Ae^{3x}，得 A=1/2
适用条件：只适用于常系数、右端为"多项式乘指数"或"指数乘三角"
```

**右端是几项相加怎么办。**

用叠加原理，拆开分别设。

```text
f = f₁ + f₂
y* = y₁* + y₂*
```

其中 y₁* 对应 f₁，y₂* 对应 f₂。

分别定系数，最后相加。

**这一步很容易漏。**

比如右端是 e^x + cos x。

有人只设一个 e^x(A cos x + B sin x)，那是错的。

正确做法是设两个：

```text
y* = Ae^x + (B cos x + C sin x)
```

**再补一个"多项式乘指数"的例子。**

右端是 x e^x。

这是 1 次多项式乘 e^x，λ = 1。

假设特征根里没有 1，设：

```text
y* = (Ax + B) e^x
```

注意括号里必须是完整的一次式，不能只写 Ax。

如果只写 Ax，代进去会得到"缺一个常数项"的矛盾方程，定不出解。

**这个细节考过很多次。**

判断的方法很简单：右端多项式的次数是几，特解里的多项式就必须是几次，且要写全所有低次项。

## 7. 手算：非齐次三例

**例 4：解 y'' − 3y' + 2y = e^{3x}。**

第一步，先解齐次。

第 5 节例 1 已经算过：

```text
齐次通解 Y = C₁e^x + C₂e^{2x}
```

第二步，看右端。

```text
f(x) = e^{3x}
```

这是 P_0(x)e^{λx} 的形状：多项式是常数 1，λ = 3。

第三步，定 k。

λ = 3，特征根是 1 和 2。

3 不是根，所以 k = 0。

设：

```text
y* = A e^{3x}
```

第四步，求导。

```text
y*' = 3A e^{3x}
y*'' = 9A e^{3x}
```

第五步，代入左边。

```text
9A e^{3x} − 3·3A e^{3x} + 2A e^{3x}
= (9 − 9 + 2)A e^{3x}
= 2A e^{3x}
```

要求等于 e^{3x}：

```text
2A = 1
A = 1/2
```

第六步，写通解。

```text
y = C₁e^x + C₂e^{2x} + (1/2)e^{3x}
```

**答案：y = C₁e^x + C₂e^{2x} + e^{3x}/2。**

第七步，看一眼结构。

```text
C₁e^x + C₂e^{2x}   ← 齐次通解，两个常数
e^{3x}/2           ← 特解，没有常数
```

这个结构就是第 2 节那条定理的样子。

**例 5：解 y'' − 2y' + y = e^x。**

第一步，齐次。

```text
r² − 2r + 1 = 0
(r − 1)² = 0
r = 1（二重根）
Y = (C₁ + C₂x)e^x
```

第二步，看右端。

```text
f = e^x，λ = 1
```

第三步，定 k。

λ = 1 是特征方程的重根，所以 k = 2。

设：

```text
y* = A x² e^x
```

**这里是最容易错的地方。**

很多人只乘一个 x，设成 A x e^x。

但重根要乘两个 x。

第四步，求导。

```text
y*  = A x² e^x
y*' = A(2x + x²)e^x
y*''= A(2 + 4x + x²)e^x
```

第五步，代入。

```text
y*'' − 2y*' + y*
= A e^x[(2 + 4x + x²) − 2(2x + x²) + x²]
= A e^x[2 + 4x + x² − 4x − 2x² + x²]
= 2A e^x
```

要求等于 e^x：

```text
2A = 1
A = 1/2
```

第六步，写通解。

```text
y = (C₁ + C₂x)e^x + (1/2)x²e^x
```

**答案：y = (C₁ + C₂x + x²/2)e^x。**

第七步，注意一个现象。

解里出现了 x²e^x。

而齐次解里已经有 e^x 和 xe^x。

所以这个特解"比齐次解高一阶"。

这不是巧合，是共振的必然结果。

**例 6：解 y'' + y = cos x。**

第一步，齐次。

```text
r² + 1 = 0
r = ±i
Y = C₁cos x + C₂ sin x
```

第二步，看右端。

```text
f = cos x
```

写成 e^{αx}[P cos βx + Q sin βx] 的形状：

```text
α = 0，β = 1
```

第三步，定 k。

α ± βi = 0 ± i = ±i。

这正是特征根。

所以 k = 1。

设：

```text
y* = x(a cos x + b sin x)
```

**注意 cos 和 sin 都要设，前面已经强调过。**

第四步，求导。

```text
y*  = ax cos x + bx sin x
y*' = a cos x − ax sin x + b sin x + bx cos x
y*''= −2a sin x − ax cos x + 2b cos x − bx sin x
```

第五步，算 y*'' + y*。

x 的项全部抵消：

```text
y*'' + y* = −2a sin x + 2b cos x
```

要求等于 cos x：

```text
−2a = 0  →  a = 0
 2b = 1  →  b = 1/2
```

第六步，写通解。

```text
y = C₁cos x + C₂ sin x + (x/2) sin x
```

**答案：y = C₁cos x + C₂ sin x + (x/2)sin x。**

第七步，看解的行为。

x 很大时，(x/2)sin x 越来越大。

这说明外力频率和系统固有频率相同时，振幅会无限增大。

这就是共振。

物理上，士兵齐步过桥如果步频和桥的固有频率一致，桥会越振越厉害。

**三道题的对照。**

```text
例 4：λ 不是根，k = 0，设 Ae^{3x}
例 5：λ 是重根，k = 2，设 Ax²e^x
例 6：α±βi 是根，k = 1，设 x(a cos x + b sin x)
```

**一个统一的记忆法。**

```text
右端的"频率"撞上了特征根几次，就乘几个 x。
```

撞 0 次乘 1（即不乘），撞 1 次乘 x，撞 2 次乘 x²。

## 8. 欧拉方程

没有这一节，x²y'' 这类变系数方程完全没有入口，套常系数公式会得到错误的根。

**形状。**

```text
x² y'' + p x y' + q y = f(x)
```

注意 x 的幂次和导数的阶数对齐：y'' 配 x²，y' 配 x。

这叫欧拉方程（Euler equation），也叫等维方程。

**它和常系数方程的关系。**

做一个换元就能变过去。

令：

```text
x = e^t，  即 t = ln x（x > 0）
```

**这个换元会把 x 的幂消掉。**

先算一阶导：

```text
dy/dt = (dy/dx)(dx/dt) = y' · e^t
```

所以：

```text
x y' = dy/dt
```

再算二阶导：

```text
d²y/dt² = d/dt (x y') = (dx/dt)y' + x(dy'/dt) = e^t y' + x · y'' · e^t
        = x y' + x² y''
```

所以：

```text
x² y'' = d²y/dt² − dy/dt
```

**结果。**

代入原方程：

```text
(d²y/dt² − dy/dt) + p (dy/dt) + q y = f(e^t)
```

整理：

```text
d²y/dt² + (p − 1) dy/dt + q y = f(e^t)
```

**这已经是一个常系数方程了。**

它的特征方程是：

```text
r² + (p − 1) r + q = 0
```

**另一种写法，更常用。**

直接把 y = x^r 代进欧拉方程：

```text
y = x^r
y' = r x^{r−1}
y'' = r(r−1) x^{r−2}
```

代入：

```text
x² · r(r−1)x^{r−2} + p x · r x^{r−1} + q x^r
= [r(r−1) + pr + q] x^r
```

所以特征方程是：

```text
r(r − 1) + p r + q = 0
```

**和上面那个一致。**

展开展开验证：

```text
r² − r + pr + q = r² + (p−1)r + q
```

一样。

**四步公式，欧拉版本。**

```text
算什么：把变系数的欧拉方程，换成常系数方程
逐符号：p 是 xy' 的系数，q 是 y 的系数；r 是待定的幂次
代数字：x²y'' − 2xy' + 2y = 0 → r(r−1) − 2r + 2 = 0 → r=1,2 → y = C₁x + C₂x²
适用条件：x > 0；系数必须按"x² 配 y''"的规律对齐
```

**为什么默认 x > 0。**

因为换元用了 ln x。

x < 0 时可以改用 t = ln(−x)，得到对称的一套结论。

考试里题目基本都会写 x > 0，照着做即可。

**例 7：解 x²y'' − 2xy' + 2y = 0（x > 0）。**

第一步，对照标准形。

```text
p = −2，q = 2
```

第二步，写特征方程。

```text
r(r−1) + (−2)r + 2 = 0
r² − r − 2r + 2 = 0
r² − 3r + 2 = 0
(r−1)(r−2) = 0
r₁ = 1，r₂ = 2
```

第三步，写通解。

```text
y = C₁ x + C₂ x²
```

**答案：y = C₁x + C₂x²。**

第四步，验算。

取 y = x：

```text
y' = 1，y'' = 0
x²·0 − 2x·1 + 2x = 0
```

对上。

取 y = x²：

```text
y' = 2x，y'' = 2
x²·2 − 2x·2x + 2x² = 2x² − 4x² + 2x² = 0
```

对上。

**欧拉方程的三种根，对应三种解。**

```text
两个不同实根：y = C₁x^{r₁} + C₂x^{r₂}
二重根：      y = (C₁ + C₂ ln x) x^r
共轭复根：    y = x^α[C₁cos(β ln x) + C₂sin(β ln x)]
```

**为什么不写成 e^{rx}。**

因为 x = e^t，所以 x^r = e^{rt}。

换回 x 之后，指数函数就变成了幂函数。

同理，e^{αt} 变成 x^α，cos βt 变成 cos(β ln x)。

**记法。**

```text
常系数方程里，t 是指数上的变量；
欧拉方程里，x 是底数，ln x 才是那个"指数上的变量"。
```

只需把常系数的每个 e^{kt} 换成 x^k，就得到欧拉的结果。

三角项也照换：cos βt 换成 cos(β ln x)。

这一步换了，欧拉方程就完全退化成常系数那一套。

## 9. 常见错误

**错误一：特征方程系数抄错。**

```text
y'' + py' + qy = 0  →  r² + pr + q = 0
```

对应关系是"阶数当次数"。

y'' 的系数变成 r² 的系数，y' 的系数变成 r 的系数，y 的系数变成常数项。

抄错一个符号，整题报废。

**错误二：y'' 前有系数时忘了先除以它。**

```text
2y'' + 3y' + y = 0
```

必须先化成 y'' + 1.5y' + 0.5y = 0，再写 r² + 1.5r + 0.5 = 0。

**错误三：重根只写一个指数。**

```text
错：y = C₁e^{2x}
对：y = (C₁ + C₂x)e^{2x}
```

漏了 x，通解的自由度就不够，代初值会解不出。

**错误四：复根的 β 漏掉。**

```text
r = −1 ± 2i
错：y = e^{−x}(C₁ + C₂x)
对：y = e^{−x}(C₁cos 2x + C₂ sin 2x)
```

虚部 β 决定频率，漏了就完全变形。

**错误五：非齐次通解只写特解。**

```text
错：y = e^{3x}/2
对：y = C₁e^x + C₂e^{2x} + e^{3x}/2
```

"通解"必须含两个任意常数。

只写特解，那叫一个特解，不叫通解。

**错误六：共振时忘了乘 x。**

```text
y'' − 2y' + y = e^x
```

如果设 y* = Ae^x，代入得 0 = e^x，矛盾。

必须设 Ax²e^x。

**错误七：类型二只设 cos 不设 sin。**

```text
错：y* = Ax cos x
对：y* = x(a cos x + b sin x)
```

求导会互换 cos 和 sin，只设一个必定凑不齐。

**错误八：右端多项式的次数设低。**

```text
f = x e^x
```

这是 1 次多项式乘指数，特解要设 (Ax + B)e^x。

只设 Ae^x 差一个常数项，定不出解。

**错误九：可降阶时缺 x 却写 y'' = p'。**

缺 x 时，p 必须看成 y 的函数，y'' = p dp/dy。

写成 p' 就还是对 x 求导，方程没降下来。

**错误十：欧拉方程漏掉那个 −dy/dt。**

```text
x²y'' = d²y/dt² − dy/dt
```

那个减号来自乘积法则，漏了就全错。

**错误十一：初值条件用了两个 y 值。**

```text
y(0) = 1，y(0) = 2
```

这是矛盾的。

二阶方程需要的是 y(x₀) 和 y'(x₀)，一个位置一个速度。

## 10. 数一怎么考

**题型一：求二阶常系数齐次方程的通解。**

最基础，必须满分。

动作固定：写特征方程 → 解根 → 按三种情形写解。

**题型二：带初值求特解。**

比题型一多一步代入。

注意求导之后再代 y'(x₀)，别把两个条件都代到 y 上。

**题型三：二阶常系数非齐次。**

分值最高的一类。

固定五步：

```text
1. 解齐次，得 C₁y₁ + C₂y₂
2. 看右端形状，定 λ 或 α±βi
3. 判 k（撞了几次特征根）
4. 设特解，代进去定系数
5. 相加，写通解
```

**题型四：应用题。**

常见是弹簧振子或 RLC 电路。

例：质量为 1 的物体挂在劲度系数为 4 的弹簧上，无阻尼。

初始位移 1，初始速度 0。求运动方程。

第一步，列方程。

```text
m x'' + k x = 0
x'' + 4x = 0
```

第二步，特征方程。

```text
r² + 4 = 0
r = ±2i
```

第三步，通解。

```text
x = C₁cos 2t + C₂ sin 2t
```

第四步，代初值。

```text
x(0) = C₁ = 1
x' = −2C₁sin 2t + 2C₂cos 2t
x'(0) = 2C₂ = 0，C₂ = 0
```

**答案：x = cos 2t。**

第五步，读一下这个结果。

振幅 1，角频率 2，周期 π。

没有衰减，因为题目说无阻尼。

如果加上阻尼项 2x'，就变成第 5 节例 3 那种"边振边衰"的形状。

**题型五：可降阶方程。**

认出缺谁，按第 3 节的三条路走。

**题型六：欧拉方程。**

换成 r(r−1) + pr + q = 0，解完把 e^{rt} 换成 x^r。

**题型七：已知通解反求方程。**

给一个含两个常数的解族，问它满足哪个方程。

做法：求两次导，消掉两个常数。

比如 y = C₁e^x + C₂e^{2x}。

求导：

```text
y' = C₁e^x + 2C₂e^{2x}
y'' = C₁e^x + 4C₂e^{2x}
```

消 C₁、C₂，会得到 y'' − 3y' + 2y = 0。

更快的办法是看指数上的数：1 和 2 是特征根，所以特征方程是 (r−1)(r−2) = 0。

**题型八：三阶及以上。**

数一偶尔出三阶，方法完全一样。

```text
y''' − y' = 0
```

特征方程：

```text
r³ − r = 0
r(r−1)(r+1) = 0
r = 0，1，−1
```

通解：

```text
y = C₁ + C₂e^x + C₃e^{−x}
```

三个根，三个常数，结构不变。

**一个提醒。**

三阶方程里 r = 0 是一个根，对应的是常数解 1。

不要因为"根的乘积为 0"就以为算错了。

**时间分配建议。**

```text
齐次通解：3 分钟
非齐次定特解：6 到 8 分钟
代初值 + 验算：2 分钟
```

## 11. 和其他章节怎么连

**和 19 篇（一阶方程）。**

这一章的两个工具都来自一阶。

可降阶：把二阶降成一阶，用 19 篇的四类解法。

非齐次特解：设好形状后，定系数经常要解一个简单方程。

所以 19 篇不熟，这一章会卡在第一步。

**和 03 篇（导数）。**

y'' 是二阶导数，几何上是"曲线的弯曲方向"。

y'' > 0 是凹，y'' < 0 是凸。

方程 y'' + qy = 0 在说："弯曲方向和当前高度相反"。

这正是"往回拉"的数学表达，也就是回复力。

**和 04 篇（中值定理）。**

二阶导数的符号决定凹凸，中值定理把"二阶导"和"函数值"联系起来。

这一章的很多定性结论（解会不会振荡、会不会衰减）本质上是二阶导的符号分析。

**和线性代数（数一不考但思想相通）。**

二阶常系数方程对应一个 2×2 矩阵的特征值问题。

特征方程就是那个矩阵的特征方程。

三个根的情形，对应矩阵有三种 Jordan 形。

这条联系在工程数学里很重要，数一只需要知道有这回事。

**和 17 篇（幂级数）。**

变系数方程一般解不出初等函数。

这时候用幂级数设解，比较系数。

比如贝塞尔方程、勒让德方程，解都是幂级数。

**和物理。**

```text
无阻尼振动：x'' + ω²x = 0
阻尼振动：  x'' + 2μx' + ω²x = 0
受迫振动：  x'' + 2μx' + ω²x = F cos γt
```

三种情形分别对应判别式大于 0、等于 0、小于 0（对无阻尼情形则是纯虚根）。

阻尼大小的临界值，就是判别式等于 0 的那一点。

### 自检三问

**第一问：为什么二阶方程的通解必须含两个任意常数，而且这两个解要线性无关？**

因为每积分两次才回到 y，每次积分产生一个常数。

从几何上看，二阶方程的解是一族曲线，需要"过哪一点"和"以什么斜率过"两个条件才能定下一条。

两个条件对应两个常数。

至于线性无关：如果 y₂ = k y₁，那么 C₁y₁ + C₂y₂ = (C₁ + kC₂)y₁，只剩一个自由参数。

一个参数凑不出所有解，代两个初值时会出现方程矛盾或解不唯一。

所以必须取两个比值不是常数的解。

**第二问：二重根时为什么要在 e^{rx} 前面乘一个 x？**

因为只有一个根，只能给出一个解 e^{rx}。

二阶方程要两个无关解，第二个必须另找。

找法是设 y = u(x)e^{rx}，代进方程。

计算后会发现 u'' = 0，所以 u 是一次函数 C₁ + C₂x。

于是第二个解是 xe^{rx}。

从"共振"的角度看，e^{rx} 已经被占用，乘以 x 才能挤进一个新的方向。

这个动作在后来的非齐次特解里又出现一次，理由完全一样。

**第三问：非齐次特解什么时候要乘 x，乘几个？**

看右端的"频率"撞了特征根几次。

类型一：右端是 P_m(x)e^{λx}，看 λ 是特征方程的几重根。

```text
0 重（不是根）→ 不乘
1 重（单根）  → 乘 x
2 重（重根）  → 乘 x²
```

类型二：右端含 e^{αx}cos βx 或 sin，看 α ± βi 是不是特征根。

```text
不是根 → 不乘
是根   → 乘 x（对二阶，只可能是单根）
```

为什么必须乘：不乘的话，设出来的特解会落在齐次解空间里，代入左边恒为 0，永远等于不了非零的右端。

## 12. 小结

压成一张卡片。

```text
标准形：y'' + py' + qy = f(x)
特征方程：r² + pr + q = 0
两不同实根：y = C₁e^{r₁x} + C₂e^{r₂x}
二重根：    y = (C₁ + C₂x)e^{rx}
共轭复根：  y = e^{αx}(C₁cos βx + C₂ sin βx)
非齐次通解：齐次通解 + 一个特解
类型一：f = P_m(x)e^{λx} → 设 x^k Q_m(x)e^{λx}
类型二：f = e^{αx}(P cos βx + Q sin βx) → 设 x^k e^{αx}(R cos βx + S sin βx)
降阶：缺 y 令 p = y'；缺 x 令 p = y' 且 y'' = p dp/dy
欧拉：x²y'' + pxy' + qy = 0 → r(r−1) + pr + q = 0
```

四步公式在这一章的统一形态。

```text
算什么 → 先解齐次拿两个常数，再补一个特解
逐符号 → p 是 y' 系数，q 是 y 系数，λ 或 α±βi 是右端的频率
代数字 → 每道题都代回原方程验算，尤其非齐次
适用条件 → 常系数、线性；变系数只处理可降阶和欧拉两类
```

三个必须记住的判别。

```text
Δ > 0：两条指数，不振荡
Δ = 0：一条指数乘一次式，临界
Δ < 0：指数乘三角，振荡
```

三个"乘 x"的场合。

```text
特征方程重根         → 通解乘 x
非齐次 λ 撞单根      → 特解乘 x
非齐次 λ 撞重根      → 特解乘 x²
```

三处理由相同：

```text
原来的形状已经被齐次解占用，必须乘 x 才能造出新的无关方向。
```

**一个捷径：先看右端的"频率"，再看根。**

拿到非齐次题，先不急着算齐次通解。

先把右端的 λ 或 α±βi 写出来，和特征根对比。

对比完，特解的形状就定了。

然后回头解齐次。

这个顺序比"先解齐次再想特解"省时间，因为定 k 的时候正好用上根。

**一个自查习惯。**

```text
算出通解，先数常数：二阶必须恰好两个。
多一个或少一个，说明中间某步错了。
```

**两个提醒。**

第一个，特解定系数时，如果出现"0 = 非零"的矛盾，不要以为题错了。

那说明 k 取小了，回去乘一个 x 再试。

第二个，初值条件代进去之后，两个方程要联立解 C₁、C₂。

如果解不出唯一的一组，说明两个解线性相关，通解写错了。

到这里，级数（16 到 18）和微分方程（19 到 20）两块都结束了。

这两块有一个共同点：

```text
都不是"算一个数"，而是"处理一类对象"。
级数处理无限和，方程处理未知函数。
```

两种"处理"的终点都一样：把一个陌生的对象，换成已知的、可算的形状。
