> **读这篇之前，你只需要知道**：导数表示"变化率"，比如路程对时间求导得到速度；求导有固定公式表，幂函数、指数函数、三角函数的导数都能查；复合函数求导要用链式法则，即外层导数乘内层导数。
> **这篇讲什么**：把求导反过来做——已知变化率，找出原来的函数，这个反向动作叫不定积分，它比求导难，因为要"猜"。
> **一个类比**：求导像把一整块面团擀开，有固定几刀；积分像看着一张摊开的饼，要复原出原来的面团，得靠手感、靠试、靠几张常用配方。

已知速度，求路程。

这句话听起来简单，做起来不容易。

速度是 v(t) = 2t，路程是多少？

你可能会说 s(t) = t²。

也可能说 s(t) = t² + 5。

还可能说 s(t) = t² - 100。

三个都对。

因为"速度一样"只规定了怎么变，没规定从哪里出发。

**这就是积分和求导最大的区别：**

```text
求导：给一个函数，答案唯一。
积分：给一个导数，答案是一族函数，差一个常数。
```

这一篇讲的就是怎么把这族函数找出来。

## 1. 为什么需要它（不给会怎样）

没有积分，你会遇到三类过不去的坎。

**第一类，反问题无法回答。**

物理、几何、经济里大量的问题是"已知变化率，求总量"。

```text
已知加速度求速度，已知速度求位移
已知边际成本求总成本，已知人口增长率求人口
已知曲线斜率求曲线方程
```

这些问题在数学上都是同一个：求 f(x)，使 f'(x) 等于已知函数。

**第二类，定积分算不出来。**

下一篇要讲的牛顿-莱布尼茨公式，形如：

```text
∫ₐᵇ f(x) dx = F(b) - F(a)
```

其中 F 是 f 的原函数。

没有这一篇练出的找原函数能力，那个公式就是一句空话。

**第三类，微分方程解不下去。**

y' = 2x 这样的方程，解出来是 y = x² + C。

解这个方程的动作，就是积分。

数一的微分方程大题，第一步几乎都是积分。

所以不定积分不是"积分学的第一半"，它是整个积分学的地基。

地基不牢，后面全部塌。

**第四类，求曲线方程。**

已知曲线上每一点的切线斜率是 2x，且曲线过点 (0, 1)，求这条曲线。

翻译成数学语言：

```text
f'(x) = 2x，且 f(0) = 1
```

积分一次得到形状：

```text
f(x) = x² + C
```

代入条件定常数：

```text
1 = 0 + C  ⇒  C = 1
f(x) = x² + 1
```

这个过程叫"积分一次，定一次常数"。

它是所有"由导数求原函数"题目的标准结构。

## 2. 最小模型：一个符号、三个零件

先把这个式子的每个部分读出来：

```text
∫ f(x) dx = F(x) + C
```

**∫**：读"积分号"。

它原本是一个拉长的字母 S，取自拉丁文 summa（求和）的首字母。

写成这个形状，是提醒你：积分和"把很多小块加起来"是同一件事。

**f(x)**：叫被积函数。

**dx**：读"d x"，两个字母分开读。

d 表示"一点点"，x 是变量名，合起来是"x 的一点点增量"。

它有两个作用：

```text
1. 说明对哪个变量积分（dx 表示变量是 x，不是 t）
2. 和前面的 f(x) 一起构成"微元"，是求和时的那个小块
```

不要把 dx 当成装饰。

∫ f(x) 后面不带 dx，这个式子就没有意义，因为不知道对谁积分。

**F(x)**：f 的一个原函数，满足 F'(x) = f(x)。

**C**：读"常数 C"，全称是任意常数。

它是"积分常数"，代表那一族函数之间唯一的差别。

**为什么必须有 C？**

因为常数的导数是 0。

```text
(x²)' = 2x
(x² + 7)' = 2x
(x² - 3)' = 2x
```

这三个函数的导数完全一样。

反过来说，知道导数是 2x，无法确定原函数是哪一个，只能确定"x² 加某个常数"。

所以答案必须写成 x² + C。

**几何上，C 是什么？**

是图像上下平移的距离。

```text
y = x² + 3      ── 往上挪 3
y = x²          ── 中间那条
y = x² - 2      ── 往下挪 2
```

这三条抛物线形状完全一样，只是位置不同。

在任意一个 x 处，三条曲线的切线斜率都相等，都是 2x。

积分给出的是"一整族平行曲线"，要确定具体哪一条，还需要一个额外条件（比如曲线过某点），这叫"初始条件"。

**一个反直觉的地方：**

积分号里的 f(x) 是"导数"，等号右边的 F(x) 是"原函数"。

```text
∫ 后面写的东西，是结果求导之后能得到的那个东西。
```

所以看一个积分对不对，最可靠的检验是：

```text
把结果求导，看是否等于被积函数。
```

这个检验在考场上只要十秒，能救回大量粗心错误。

**每个函数都有原函数吗？**

不是。

结论有两条：

```text
f 在区间上连续              ⇒  原函数一定存在
f 在区间上有第一类间断点    ⇒  原函数一定不存在
```

第一条的证明要用变上限积分，下一篇会讲。

第二条的理由是：原函数求导能得到 f，而导数有一个性质叫介值性——导数取到的值不会跳过中间值。

如果 f 在一点有跳跃，它跳过的那些值就永远取不到，与介值性矛盾。

这两条解释了为什么教材在讲积分之前，总要先把连续性说清楚。

**积分与微分是一对互逆操作，写成两条恒等式：**

```text
d[∫ f(x) dx] = f(x) dx       先积后微，回到原式
∫ F'(x) dx = F(x) + C        先微后积，差一个常数
```

第一条说"积分再微分"完全抵消。

第二条说"微分再积分"会多出一个 C，因为积分把"起点信息"丢了。

这两条是整章的理论依据。

换元法、分部法的所有公式，都是从"求导法则反过来"得到的。

**为什么叫"不定"积分？**

因为结果不唯一，被常数 C 放着不管，位置"不定"。

下一篇的定积分，算出来是一个确定的数，所以叫"定"。

两个名字的对比，就是这个区别。

**积分变量是哑变量。**

```text
∫ f(x) dx 和 ∫ f(t) dt 是同一个积分
```

变量换成什么字母，结果一样。

这条认识在下一篇很有用：牛顿-莱布尼茨公式里要区分"积分变量"和"上限变量"，这时候必须换字母。

## 3. 基本积分表：把求导表倒着读

没有这张表，你连最简单的积分都做不了，因为积分没有"乘法公式"可套。

积分表不需要背，它本来就是求导表的反向抄写。

下面是最常用的十六条。

```text
∫ k dx = kx + C                       （k 是常数）
∫ x^a dx = x^(a+1)/(a+1) + C          （a ≠ -1）
∫ 1/x dx = ln|x| + C
∫ e^x dx = e^x + C
∫ a^x dx = a^x/ln a + C               （a > 0, a ≠ 1）
∫ sin x dx = -cos x + C
∫ cos x dx = sin x + C
∫ sec²x dx = tan x + C
∫ csc²x dx = -cot x + C
∫ sec x tan x dx = sec x + C
∫ csc x cot x dx = -csc x + C
∫ 1/(1+x²) dx = arctan x + C
∫ 1/√(1-x²) dx = arcsin x + C
∫ tan x dx = -ln|cos x| + C
∫ cot x dx = ln|sin x| + C
∫ sec x dx = ln|sec x + tan x| + C
```

前十三条是直接倒抄，后三条要稍微推一下，但也能用换元得到。

**逐条对照的思路：**

```text
(sin x)' = cos x        ⇒  ∫ cos x dx = sin x + C
(tan x)' = sec²x        ⇒  ∫ sec²x dx = tan x + C
(arctan x)' = 1/(1+x²)  ⇒  ∫ 1/(1+x²) dx = arctan x + C
```

倒着读的时候，符号变化要特别小心。

cos 的导数是 -sin，所以 ∫ sin x dx 的结果带负号：

```text
∫ sin x dx = -cos x + C
```

幂函数那一条要练熟，因为它的形式变化最多。

```text
∫ x² dx = x³/3 + C           指数加一，再除以新指数
∫ x^(-2) dx = -x^(-1) + C    负指数同样规律
∫ √x dx = (2/3)x^(3/2) + C   √x 就是 x^(1/2)
∫ dx/√x = 2√x + C            x^(-1/2) 积分
```

规律只有一句：

```text
指数加一，然后除以加一后的指数。
```

唯一的例外是 a = -1，加一之后是 0，不能做除数。

那一条正好被 ln|x| 补上，这不是巧合，而是 ln 的定义决定的。

表里后三条不常用，但推导方法很典型，值得各看一遍。

**推 ∫ tan x dx。**

把 tan 拆成 sin 除以 cos：

```text
∫ tan x dx = ∫ (sin x/cos x) dx
```

令 u = cos x，则 du = -sin x dx，所以 sin x dx = -du：

```text
= ∫ (-du/u) = -ln|u| + C = -ln|cos x| + C
```

**推 ∫ sec x dx。**

这个技巧叫"分子分母同乘"：

```text
∫ sec x dx = ∫ [sec x(sec x + tan x)]/(sec x + tan x) dx
```

观察分母的导数：

```text
(sec x + tan x)' = sec x tan x + sec²x = sec x(sec x + tan x)
```

正好等于分子。

所以：

```text
∫ sec x dx = ln|sec x + tan x| + C
```

这两条推导展示了一个思路：

```text
当分子正好是分母的导数时，积分就是 ln|分母|。
```

后面第 5 节换元法里，所有形如 ∫ f'(x)/f(x) dx 的积分都靠这条。

**公式四步：用基本表直接算**

第一步，算什么：找出被积函数能拆成哪几个"表里有"的基本函数之和。

第二步，逐符号：∫ 是积分号，f(x) 是被积函数，dx 说明变量是 x，右边的 +C 不能丢。

第三步，代数字：算 ∫ (3x² + 2) dx。

```text
∫ 3x² dx = 3 · x³/3 = x³
∫ 2 dx = 2x
合起来：x³ + 2x + C
```

第四步，适用条件：被积函数必须是基本表里的形式，或者能拆成有限个基本形式之和；x^a 的公式要求 a ≠ -1，a = -1 时改用 ln|x|；积分对加减法可以逐项进行，对乘除法不行。

最后一条是这一章最重要的提醒：

```text
∫ [f(x) + g(x)] dx = ∫f(x) dx + ∫g(x) dx     ← 成立
∫ [f(x) · g(x)] dx = ∫f(x) dx · ∫g(x) dx     ← 不成立
```

## 4. 算一遍：逐项积分与拆项

没有这一节，你会以为所有积分都能一眼看穿。

**例一，逐项积分。**

算 ∫ (3x² - 2/x + 5e^x - 4/(1+x²)) dx。

逐项对照基本表：

```text
∫ 3x² dx      = x³
∫ (-2/x) dx   = -2 ln|x|
∫ 5e^x dx     = 5e^x
∫ -4/(1+x²) dx = -4 arctan x
```

合并：

```text
= x³ - 2ln|x| + 5e^x - 4arctan x + C
```

需要注意这个函数的定义域被 x = 0 切成两段，所以严格说，两段上的 C 可以不同。

考试一般默认在同一个区间上讨论，写一个 C 就够。

**例二，先化简再积分。**

算 ∫ (x³ + 1)/(x + 1) dx。

分子可以因式分解：

```text
x³ + 1 = (x + 1)(x² - x + 1)
```

约掉公因子：

```text
(x³ + 1)/(x + 1) = x² - x + 1
```

于是：

```text
∫ (x² - x + 1) dx = x³/3 - x²/2 + x + C
```

**例三，用三角恒等式降次。**

算 ∫ sin²x dx。

sin²x 不在基本表里，但可以用倍角公式降次：

```text
sin²x = (1 - cos 2x)/2
```

于是：

```text
∫ sin²x dx = (1/2)∫ (1 - cos 2x) dx
           = (1/2)[x - (sin 2x)/2] + C
           = x/2 - sin(2x)/4 + C
```

这里用到 ∫ cos 2x dx = (sin 2x)/2，因为内层 2x 的导数是 2，要除以 2 补偿。

这个"除以系数"的动作，就是下一节第一类换元的雏形。

**例四，用恒等式变形。**

算 ∫ tan²x dx。

tan²x 也不在表里，但 tan²x = sec²x - 1：

```text
∫ tan²x dx = ∫ (sec²x - 1) dx = tan x - x + C
```

四个例子的共同点：

```text
先想办法把被积函数变成"表里有"的样子，再逐项积分。
```

这就是不定积分的全部策略。

后面的换元法、分部法，都只是变形的两种高级手段。

再补一个"先除后积"的例子。

算 ∫ (2x² + 1)/x² dx，x ≠ 0。

先做除法：

```text
(2x² + 1)/x² = 2 + 1/x²
```

逐项积分：

```text
∫ (2 + x^(-2)) dx = 2x - x^(-1) + C = 2x - 1/x + C
```

检验：

```text
(2x - 1/x)' = 2 + 1/x²
```

对上了，注意 (-1/x)' = 1/x² 是正的，因为 x^(-2) 的积分是 -x^(-1)。

## 5. 第一类换元：凑微分

没有这一节，遇到 ∫ 2x·e^(x²) dx 这种式子，基本表一条都对不上。

先看一个观察：

```text
d(x²) = 2x dx
```

也就是说，被积式里的 2x dx，正好可以整体换成 d(x²)。

于是：

```text
∫ e^(x²) · 2x dx = ∫ e^(x²) d(x²)
```

把 x² 看成一个整体 u：

```text
= ∫ e^u du = e^u + C = e^(x²) + C
```

这个动作叫"凑微分"：把被积式里的一部分硬凑成某个函数的微分。

**例一，凑成 u = x²。**

算 ∫ 2x e^(x²) dx。

```text
令 u = x²，则 du = 2x dx
原式 = ∫ e^u du = e^u + C
回代：= e^(x²) + C
```

**例二，凑成 u = ln x。**

算 ∫ dx/(x ln x)，其中 x > 1。

先看关键的一步：

```text
d(ln x) = (1/x) dx
```

所以被积式里的 dx/x 就是 d(ln x)：

```text
∫ dx/(x ln x) = ∫ d(ln x)/ln x
```

令 u = ln x：

```text
= ∫ du/u = ln|u| + C = ln|ln x| + C
```

代入验证一下，对结果求导：

```text
[ln(ln x)]' = (1/ln x)·(1/x) = 1/(x ln x)
```

和被积函数完全一致。

这就是积分的标准检验法：把答案求导一次，看是否回到被积函数。

答案对不上，说明中间某一步漏了系数或者漏了负号。

**常用的凑微分清单：**

```text
2x dx        = d(x²)
dx/x         = d(ln|x|)
e^x dx       = d(e^x)
cos x dx     = d(sin x)
sin x dx     = d(-cos x)
sec²x dx     = d(tan x)
dx/√(1-x²)   = d(arcsin x)
dx/(1+x²)    = d(arctan x)
dx/√x        = d(2√x)
```

这张表要背到条件反射。

考场上看到被积式里有"某个函数的导数乘着 dx"，就该想到凑微分。

**四步口诀：**

```text
第一步：找出被积式里"谁是谁的导数"
第二步：把那一对整体写成 du
第三步：对 u 积分，用基本表
第四步：把 u 换回 x
```

第一步是最难的，因为它靠观察，没有固定算法。

经验是：先看有没有 ln x、arctan x、sin x 这类"复合内层"，再看它旁边有没有内层的导数。

再练两个，把"缺个系数就补一个"的动作做熟。

**补系数：算 ∫ x√(1 + x²) dx。**

被积式里有 x dx，而 d(1 + x²) = 2x dx，差一个 2。

```text
x dx = (1/2) d(1 + x²)
```

于是：

```text
∫ x√(1+x²) dx = (1/2)∫ √(1+x²) d(1+x²)
令 u = 1 + x²：
= (1/2)∫ u^(1/2) du
= (1/2)·(2/3)u^(3/2) + C
= (1/3)(1+x²)^(3/2) + C
```

检验：[(1/3)(1+x²)^(3/2)]' = (1/3)·(3/2)(1+x²)^(1/2)·2x = x√(1+x²)，对上了。

**拆奇次幂：算 ∫ cos³x dx。**

cos 的奇次幂留一个 cos x 出来，剩下的用 1 - sin²x 换掉：

```text
cos³x = cos²x · cos x = (1 - sin²x)cos x
```

令 u = sin x，du = cos x dx：

```text
∫ (1 - u²) du = u - u³/3 + C = sin x - (sin³x)/3 + C
```

这个套路对 sin 的奇次幂同样有效，留一个 sin x 出来当 du。

## 6. 第二类换元：换掉自变量

没有这一节，遇到 ∫ √(1 - x²) dx 这种带根号的式子，凑微分凑不出来。

第一类换元是把"一部分"换成 u，变量还是 x 的表达式。

第二类换元是直接把 x 换成另一个变量的函数，通常是三角函数。

**例三，三角代换处理 √(1 - x²)。**

算 ∫ √(1 - x²) dx。

看到 √(1 - x²)，想到 sin²t + cos²t = 1。

令 x = sin t，t ∈ (-π/2, π/2)，于是：

```text
dx = cos t dt
√(1 - x²) = √(1 - sin²t) = √(cos²t) = cos t （因为 t 在 (-π/2,π/2)，cos t > 0）
```

代进去：

```text
∫ √(1-x²) dx = ∫ cos t · cos t dt = ∫ cos²t dt
```

降次：

```text
= ∫ (1 + cos 2t)/2 dt = t/2 + sin(2t)/4 + C
```

回代。t = arcsin x，而：

```text
sin 2t = 2 sin t cos t = 2x√(1-x²)
```

所以：

```text
sin(2t)/4 = (2x√(1-x²))/4 = x√(1-x²)/2
```

最终结果：

```text
∫ √(1-x²) dx = (1/2)arcsin x + (1/2)x√(1-x²) + C
```

这个结果有一个几何解释：它算的是单位圆上的一块面积。

下一篇讲定积分时会回到这个式子。

**例四，三角代换处理 √(x² + a²)。**

算 ∫ dx/√(x² + a²)，a > 0。

看到 x² + a²，想到 1 + tan²t = sec²t。

令 x = a tan t，t ∈ (-π/2, π/2)：

```text
dx = a sec²t dt
√(x² + a²) = √(a²tan²t + a²) = a sec t
```

代入：

```text
∫ a sec²t/(a sec t) dt = ∫ sec t dt
```

sec t 的积分在基本表里：

```text
= ln|sec t + tan t| + C
```

回代。tan t = x/a，sec t = √(x²+a²)/a：

```text
= ln|√(x²+a²)/a + x/a| + C
= ln(x + √(x²+a²)) - ln a + C
```

把 -ln a 这个常数吸收进 C，最终写成：

```text
∫ dx/√(x²+a²) = ln(x + √(x²+a²)) + C
```

因为 x + √(x²+a²) > 0 恒成立，绝对值可以去掉，这一步要说明。

**还有一个常用类型：根式代换。**

算 ∫ dx/(1 + √x)。

令 t = √x，则 x = t²，dx = 2t dt：

```text
∫ 2t/(1+t) dt = 2∫ (1 - 1/(1+t)) dt
              = 2[t - ln|1+t|] + C
```

回代 t = √x：

```text
= 2√x - 2ln(1 + √x) + C
```

这里用了多项式除法：2t/(1+t) = 2 - 2/(1+t)。

**选代换的判断表：**

```text
√(a² - x²)  →  x = a sin t
√(a² + x²)  →  x = a tan t
√(x² - a²)  →  x = a sec t
√x 或 √(ax+b) →  t = 整个根式
```

三种三角代换的共同点是：代换之后根号消失，变成三角函数的有理式。

**第二类换元的关键约束：**

代换必须在一个区间上单调、可导，否则回代时会出现符号错误。

比如 x = sin t 限定 t ∈ (-π/2, π/2)，就是为了保证 arcsin 能唯一回代，同时 cos t > 0，开根号不用带绝对值。

这一点在解答题里写一句"令 x = sin t，t ∈ (-π/2, π/2)"，是标准的得分动作。

带参数的版本要会推。

算 ∫ √(a² - x²) dx，a > 0。

令 x = a sin t，t ∈ (-π/2, π/2)：

```text
dx = a cos t dt
√(a² - x²) = a cos t
```

代入：

```text
∫ a²cos²t dt = a²∫ (1 + cos 2t)/2 dt = a²[t/2 + sin(2t)/4] + C
```

回代，sin t = x/a，cos t = √(a²-x²)/a：

```text
sin(2t) = 2 sin t cos t = 2x√(a²-x²)/a²
```

所以：

```text
∫ √(a²-x²) dx = (a²/2)arcsin(x/a) + (x/2)√(a²-x²) + C
```

这个式子的几何意义是半径为 a 的圆上一块扇形加一块三角形的面积，下一篇用定积分算面积时会对上。

还有一条要记的：

```text
∫ dx/(x² + a²) = (1/a)arctan(x/a) + C
```

它的来源也是 x = a tan t，但结果太常用，建议直接当公式背下来。

**回代时画个直角三角形最省事。**

以 x = a tan t 为例，画一个直角三角形：

```text
对边 = x，邻边 = a，斜边 = √(x² + a²)
```

三个三角函数值一眼读出来：

```text
sin t = x/√(x²+a²)
cos t = a/√(x²+a²)
tan t = x/a
sec t = √(x²+a²)/a
```

不用解方程，也不用三角恒等式。

这个技巧在处理参数较多的题时能省两三分钟。

## 7. 分部积分：把乘积拆开

没有这一节，遇到 ∫ x e^x dx 这种"两种不同类型函数相乘"的积分，换元也救不了。

分部积分来自乘积求导公式：

```text
(uv)' = u'v + uv'
```

移项：

```text
uv' = (uv)' - u'v
```

两边积分：

```text
∫ u v' dx = uv - ∫ u' v dx
```

写成微分形式就是那个要记的公式：

```text
∫ u dv = u v - ∫ v du
```

**这个公式在做什么？**

它把"对 u dv 积分"换成"对 v du 积分"。

如果新的积分比原来的简单，这一步就赚了。

**例五，幂函数乘指数函数。**

算 ∫ x e^x dx。

选择 u = x，dv = e^x dx。

```text
u = x        ⇒ du = dx
dv = e^x dx  ⇒ v = e^x
```

套公式：

```text
∫ x e^x dx = x e^x - ∫ e^x dx = x e^x - e^x + C
```

整理：

```text
= (x - 1)e^x + C
```

检验：[(x-1)e^x]' = e^x + (x-1)e^x = x e^x，对上了。

**为什么不能反过来选？**

如果令 u = e^x，dv = x dx：

```text
v = x²/2
∫ x e^x dx = (x²/2)e^x - ∫ (x²/2)e^x dx
```

新的积分里 x 的次数从 1 升到了 2，越换越难。

所以选 u 的原则是：**让求导之后变简单的那个当 u。**

**例六，指数乘三角，要算两次。**

算 I = ∫ e^x sin x dx。

第一次，令 u = sin x，dv = e^x dx：

```text
du = cos x dx，v = e^x
I = e^x sin x - ∫ e^x cos x dx
```

记 J = ∫ e^x cos x dx，对 J 再分部一次，令 u = cos x，dv = e^x dx：

```text
du = -sin x dx，v = e^x
J = e^x cos x - ∫ e^x(-sin x) dx = e^x cos x + I
```

把 J 代回 I 的式子：

```text
I = e^x sin x - (e^x cos x + I)
I = e^x sin x - e^x cos x - I
2I = e^x(sin x - cos x)
I = e^x(sin x - cos x)/2 + C
```

这种"算两次回到原式"的题型叫循环型，数一考过多次。

它的标志是：指数函数乘三角函数。

关键是两次分部要选同一类的 u（都选三角，或都选指数），不能一次选三角一次选指数，否则会转回原点。

**例七，只有对数函数。**

算 ∫ ln x dx。

被积式里只有一个 ln x，看起来没法分部。

但可以把它看成 ln x 乘 1：

```text
u = ln x，dv = dx
du = (1/x) dx，v = x
```

套公式：

```text
∫ ln x dx = x ln x - ∫ x·(1/x) dx = x ln x - ∫ 1 dx = x ln x - x + C
```

这个技巧叫"凑 dv = dx"，在只有反三角函数或对数函数时特别有用。

同理可以算出：

```text
∫ arctan x dx = x arctan x - (1/2)ln(1+x²) + C
```

**选 u 的口诀：**

```text
反、对、幂、指、三
```

顺序是：反三角函数 → 对数函数 → 幂函数 → 指数函数 → 三角函数。

排在前面的优先当 u。

理由是：反三角和对数求导后变成代数式（变简单），幂函数求导后降次（变简单），指数和三角求导后形态不变（换不出简化）。

用这个口诀检查例五：幂（x）在对数之后、指数之前，所以 u = x，正确。

检查例六：指数和三角都在末尾，两者差不多，选谁都行，但两次要一致。

**例八，幂函数要分部两次。**

算 ∫ x² e^x dx。

第一次，令 u = x²，dv = e^x dx：

```text
du = 2x dx，v = e^x
∫ x² e^x dx = x² e^x - 2∫ x e^x dx
```

后面那个积分在例五算过：

```text
∫ x e^x dx = (x - 1)e^x
```

代回：

```text
∫ x² e^x dx = x² e^x - 2(x - 1)e^x + C
            = (x² - 2x + 2)e^x + C
```

检验：

```text
[(x² - 2x + 2)e^x]' = (2x - 2)e^x + (x² - 2x + 2)e^x = x² e^x
```

对上了。

这个例子说明了分部的"降次"效果：

```text
x² 求导变 2x，再求导变 2，次数降到底，积分自然结束。
```

一般规律：∫ xⁿ e^x dx 需要分部 n 次。

分部次数多了容易符号错乱，可以改用表格法。

以 ∫ x² e^x dx 为例，画两列，交替求导和积分：

```text
符号    求导列      积分列
 +      x²          e^x
 -      2x          e^x
 +      2           e^x
 -      0           e^x
```

然后把"斜着乘"的结果加起来：

```text
+ x²·e^x  - 2x·e^x  + 2·e^x
```

```text
∫ x² e^x dx = (x² - 2x + 2)e^x + C
```

和分部两次的结果一致。

表格法的适用条件是：

```text
一边是多项式、求导若干次后变 0
另一边是指数或三角、积分后形态不变
```

多项式不是几次都行，只要最终能求导到 0，表格就能收尾。

如果另一边是 ln x 或 arctan x，表格法失效，因为它们的积分会变复杂。

## 8. 三类特殊形式：有理函数、三角有理式、递推

没有这一节，遇到分母是二次式的积分，你会停在"表里没有"这一步。

**第一类，有理函数。**

形如 P(x)/Q(x)，P、Q 都是多项式。

处理流程是固定的三步：

```text
1. 如果是假分式（分子次数 ≥ 分母次数），先做多项式除法，拆出整式部分
2. 分母因式分解
3. 拆成部分分式，逐项积分
```

一个典型例子：

算 ∫ dx/(x² - a²)，a > 0。

分母分解：

```text
x² - a² = (x - a)(x + a)
```

设：

```text
1/[(x-a)(x+a)] = A/(x-a) + B/(x+a)
```

通分比较分子：

```text
1 = A(x+a) + B(x-a)
```

代 x = a：1 = 2aA，A = 1/(2a)。

代 x = -a：1 = -2aB，B = -1/(2a)。

所以：

```text
∫ dx/(x²-a²) = (1/(2a))∫ [1/(x-a) - 1/(x+a)] dx
             = (1/(2a))[ln|x-a| - ln|x+a|] + C
             = (1/(2a))ln|(x-a)/(x+a)| + C
```

这个结果建议直接记住，考场上能省三分钟。

另一种常见形式：

算 ∫ (2x + 3)/(x² + 3x + 5) dx。

分母的导数是 2x + 3，正好等于分子。

```text
∫ (2x+3)/(x²+3x+5) dx = ln(x² + 3x + 5) + C
```

如果分子是 2x + 1，就要先拆：

```text
2x + 1 = (2x + 3) - 2
```

前一半凑成 ln，后一半配方成 arctan。

配方：

```text
x² + 3x + 5 = (x + 3/2)² + 11/4
```

于是后一半是：

```text
-2∫ dx/[(x+3/2)² + 11/4] = -2·(2/√11)arctan((2x+3)/√11) + C
```

这一套"凑分母导数 + 配方"的流程，是有理函数题的通用打法。

再补一个配方题，把流程走全。

算 ∫ dx/(x² + 2x + 5)。

分母配方：

```text
x² + 2x + 5 = (x + 1)² + 4
```

于是：

```text
∫ dx/[(x+1)² + 2²] = (1/2)arctan((x+1)/2) + C
```

用的是公式 ∫ du/(u² + a²) = (1/a)arctan(u/a) + C，这里 u = x + 1，a = 2。

如果分子是一次式，比如：

算 ∫ (3x + 1)/(x² + 2x + 5) dx。

先把分子凑成分母的导数（2x + 2）：

```text
3x + 1 = (3/2)(2x + 2) - 2
```

拆成两项：

```text
(3/2)∫ (2x+2)/(x²+2x+5) dx - 2∫ dx/(x²+2x+5)
```

第一项是 ln：

```text
= (3/2)ln(x² + 2x + 5)
```

第二项按上面配方算：

```text
= -2·(1/2)arctan((x+1)/2) = -arctan((x+1)/2)
```

合并：

```text
∫ (3x+1)/(x²+2x+5) dx = (3/2)ln(x²+2x+5) - arctan((x+1)/2) + C
```

这套"一分为二"的拆法，可以处理所有分母为二次、分子为一次的有理函数。

**第二类，三角有理式。**

形如只含 sin x、cos x 的有理式。

通用办法是万能代换：

```text
令 t = tan(x/2)
sin x = 2t/(1+t²)
cos x = (1-t²)/(1+t²)
dx = 2dt/(1+t²)
```

代换之后，三角有理式变成 t 的有理函数，可以用第一类的方法处理。

万能代换一定能做出来，但计算量大。

实际做题时优先试更简单的：

```text
只含 sin²x、cos²x → 用倍角公式降次
只含 sin x 的奇次幂 → 令 u = cos x
只含 cos x 的奇次幂 → 令 u = sin x
```

**万能代换的完整示范。**

算 ∫ dx/(2 + cos x)。

令 t = tan(x/2)，三个替换式一起代：

```text
cos x = (1 - t²)/(1 + t²)
dx = 2dt/(1 + t²)
```

先化简分母：

```text
2 + cos x = 2 + (1 - t²)/(1 + t²)
          = (2 + 2t² + 1 - t²)/(1 + t²)
          = (3 + t²)/(1 + t²)
```

代进去，两个 (1 + t²) 正好约掉：

```text
∫ dx/(2+cos x) = ∫ [2dt/(1+t²)] · [(1+t²)/(3+t²)]
               = ∫ 2dt/(3 + t²)
```

这是基本表里的 arctan 形式：

```text
= (2/√3)arctan(t/√3) + C
```

回代 t = tan(x/2)：

```text
= (2/√3)arctan(tan(x/2)/√3) + C
```

万能代换的价值在于"一定能做出来"：任何三角有理式，经过它都变成有理函数。

代价是计算量大，所以它排在最后一位。

这个例子里有一个值得学的动作：

```text
先化简分母，再和 dx 约分，能省掉一大段计算。
```

直接硬代不化简，会得到四层分式，容易算错。

**第三类，递推积分。**

形如 Iₙ = ∫ sinⁿx dx，直接算不出来，但可以建立递推关系。

分部积分一次，可以得到：

```text
Iₙ = -(1/n)sin^(n-1)x·cos x + ((n-1)/n)Iₙ₋₂
```

这个式子的意思是：n 次幂的积分，可以换成 n-2 次幂的积分。

一路降下去，最后落到 I₀ = x + C 或 I₁ = -cos x + C。

数一考过这个递推公式的推导，要求写清分部积分的过程。

## 9. 常见错误

没有这一节，上面所有正确方法都会在考场上退化成各种漏项版本。

**错误一：漏掉 + C。**

不定积分的结果是一族函数，不是一个函数。

考试时漏 C，通常扣 1 分，但年年有人漏。

**错误二：∫ (1/x) dx 写成 ln x + C。**

正确是 ln|x| + C。

因为 x < 0 时 ln x 没有定义，但 1/x 在 x < 0 时照样有原函数 ln(-x)。

绝对值不是可选项。

**错误三：换元后忘了换 dx。**

把 ∫ e^(x²) dx 直接写成 e^(x²) + C，是典型错误。

dx 不是装饰，代换 x = φ(t) 时，dx 必须换成 φ'(t) dt。

**错误四：换元后忘了回代。**

结果写成 e^u + C 或者 (1/2)arcsin t + C，都不算完成。

不定积分的答案必须用原来的变量 x 表示。

**错误五：三角代换忘了限定范围。**

令 x = sin t 却不写 t ∈ (-π/2, π/2)，开根号时 cos t 的符号就说不清。

**错误六：分部积分选错 u。**

∫ x e^x dx 里若令 u = e^x，会得到次数更高的积分。

口诀"反对幂指三"能避免大部分错误。

**错误七：把乘积的积分拆成积分的乘积。**

```text
∫ f(x)g(x) dx ≠ ∫ f(x) dx · ∫ g(x) dx
```

积分对乘法没有分配律。

**错误八：不检验。**

每个积分答案都能用求导验证，十秒钟的事。

不验证，错了也不知道错在哪一步。

**错误九：把 arctan 类的结果写成对数。**

∫ dx/(1 + x²) = arctan x + C，不是 ln(1 + x²) + C。

ln(1+x²) 的导数是 2x/(1+x²)，分子带 x，对不上。

**错误十：拆项时符号漏掉。**

∫ (1 - cos 2x)/2 dx 里，-cos 2x 积分得 -sin(2x)/2，两个负号不能丢一个。

结果是 x/2 - sin(2x)/4 + C，不是 x/2 + sin(2x)/4 + C。

检验一次就能发现：后者求导得 1/2 + cos(2x)/2，与 (1 - cos 2x)/2 差一个负号。

**错误十一：以为答案的形式必须和标准答案一样。**

同一个积分，用不同方法会得到看起来完全不同的结果。

算 ∫ sin x cos x dx，三种做法：

```text
法一，令 u = sin x：      ∫ u du = sin²x/2 + C
法二，令 u = cos x：      -∫ u du = -cos²x/2 + C
法三，用倍角：            (1/2)∫ sin 2x dx = -cos(2x)/4 + C
```

三个答案外形不同，但它们只差一个常数：

```text
sin²x/2 = -cos²x/2 + 1/2
-cos(2x)/4 = sin²x/2 - 1/4
```

差的那部分被吸收进了 C，所以三个都对。

结论：

```text
判断积分对不对，只看求导能不能回去，不看形式是否一样。
```

考场上如果答案和记忆中的"标准形式"不同，先求导验证，别急着改。

## 10. 数一怎么考

没有这一节，你练的题会和考卷上的题对不上。

**题型一：填空题，直接积分。**

形式是给一个不太复杂的式子，四个空之一。

```text
∫ (x² + 1)² dx = ?
∫ e^(2x) dx = ?
∫ sin 3x dx = ?
```

这类题只考基本表加一点点凑系数。

比如 ∫ e^(2x) dx = (1/2)e^(2x) + C，系数 1/2 是补偿内层 2x 的导数。

**题型二：解答题，换元加分部组合。**

一个积分里既要换元又要分部，是 10 分题的常见结构。

例：算 ∫ x arctan x dx。

分部，令 u = arctan x，dv = x dx：

```text
du = dx/(1+x²)，v = x²/2
∫ x arctan x dx = (x²/2)arctan x - (1/2)∫ x²/(1+x²) dx
```

后一个积分用拆项：

```text
x²/(1+x²) = 1 - 1/(1+x²)
∫ [1 - 1/(1+x²)] dx = x - arctan x
```

合并：

```text
= (x²/2)arctan x - (1/2)(x - arctan x) + C
= (x²/2)arctan x - x/2 + (1/2)arctan x + C
= ((x²+1)/2)arctan x - x/2 + C
```

**题型三：抽象函数，已知原函数求积分。**

例：设 f(x) 的一个原函数是 e^(-x)，求 ∫ x f'(x) dx。

第一步，从"原函数"还原 f：

```text
f(x) = (e^(-x))' = -e^(-x)
f'(x) = e^(-x)
```

第二步，代入并分部：

```text
∫ x f'(x) dx = ∫ x e^(-x) dx
```

令 u = x，dv = e^(-x) dx：

```text
v = -e^(-x)
= -x e^(-x) + ∫ e^(-x) dx
= -x e^(-x) - e^(-x) + C
= -(x + 1)e^(-x) + C
```

这类题的坑在于"原函数"和"导数"的方向。

题目说"f 的原函数是 e^(-x)"，意思是 (e^(-x))' = f，不是 f' = e^(-x)。

方向搞反，整题全错。

换元加分部的组合，还有一个典型结构：

例：算 ∫ e^(√x) dx。

第一步换元，令 t = √x，则 x = t²，dx = 2t dt：

```text
∫ e^(√x) dx = ∫ e^t · 2t dt = 2∫ t e^t dt
```

第二步分部：

```text
∫ t e^t dt = (t - 1)e^t
```

合并并回代：

```text
= 2(t - 1)e^t + C = 2(√x - 1)e^(√x) + C
```

这个例子的结构值得记住：

```text
被积函数里出现 √x、ln x、arcsin x 这类"不好积"的整体，
先换元把它变成普通变量，再考虑分部。
```

顺序不能反，直接对 e^(√x) 分部会卡住，因为找不到简单的 v。

**题型四：三角有理式。**

例：算 ∫ dx/(1 + sin x)。

分子分母同乘 1 - sin x：

```text
∫ (1 - sin x)/[(1+sin x)(1-sin x)] dx = ∫ (1 - sin x)/cos²x dx
```

拆开：

```text
= ∫ sec²x dx - ∫ sin x/cos²x dx
= tan x - (1/cos x) + C
= tan x - sec x + C
```

第二项用了 ∫ sin x/cos²x dx = sec x + C，可以用 u = cos x 验证。

**题型五：递推公式的推导。**

要求写出 Iₙ 与 Iₙ₋₂ 的关系式，并说明用了哪一步分部。

这类题的分值不高，但过程分好拿，把分部过程写全就行。

**题型六：由积分结果反求被积函数。**

例：已知 ∫ f(x) dx = x e^x + C，求 f(x)。

方法：两边求导。

```text
f(x) = (x e^x)' = e^x + x e^x = (x + 1)e^x
```

这类题的核心认识是：

```text
不定积分和求导互逆，所以"积分结果求导"能还原被积函数。
```

反过来也常考：已知 f'(x) = ... 且 f(0) = ...，求 f(x)。

这时先积分得 f(x) = 原函数 + C，再用初始条件定 C。

**题型七：分段函数的积分。**

例：求 ∫ |x| dx。

分段去掉绝对值：

```text
x ≥ 0 时，|x| = x，积分得 x²/2 + C₁
x < 0 时，|x| = -x，积分得 -x²/2 + C₂
```

这里有一个关键约束：原函数必须连续。

在 x = 0 处，左侧极限是 C₂，右侧极限是 C₁，让它们相等：

```text
C₁ = C₂
```

所以两个常数其实是同一个，结果写成：

```text
∫ |x| dx = x|x|/2 + C
```

检验：x > 0 时导数为 x，x < 0 时导数为 -x，x = 0 处左右导数都是 0，与 |x| 一致。

这个题型考的是"原函数连续"这条容易被忽略的要求。

两个 C 不是各管一段，它们被连续性绑在一起。

**分值与时间。**

数一高数部分，不定积分很少单独出大题，它通常作为定积分、微分方程的前半段出现。

```text
填空选择：约 1 道，4 分
解答题：作为其中一步，5 到 8 分
```

所以练的目标不是"攻下最难的积分"，而是"常见形式一次做对"。

一个能算完的积分，比一个算错一半的巧解更值钱。

## 11. 和其他章节怎么连

没有这一节，积分会变成一个孤立的技巧库，看不出它在整门课里的位置。

**往回连：03 导数与微分。**

整张基本积分表都是求导表的反写。

求导越熟，积分表背得越快。

反过来，积分结果用求导检验，也是在用 03 篇的知识。

**往回连：05 导数的应用。**

导数告诉你曲线怎么走，积分把它还原回去。

给了 f' 的图像，积分能算出 f 的增量，这一点在下一篇会展开。

**往回连：05 导数的应用。**

05 篇从 f' 的符号画出 f 的形状，这一篇从 f' 的表达式算出 f。

两章合起来，一条曲线就被完全确定了：表达式由积分得到，形状由符号判断。

做题时的顺序通常是：

```text
先积分得到 f(x) + C，再用 05 篇的办法判单调、极值、凹凸，画出图像。
```

**往前连：07 定积分。**

牛顿-莱布尼茨公式需要"一个原函数"，不定积分正是找原函数的工具。

可以说：不定积分是手段，定积分是目的。

**往前连：09 反常积分。**

反常积分的计算，最后也落到"求原函数再代上下限"。

区别只在端点处要取极限。

**横向连：19 微分方程。**

一阶可分离变量方程，解到最后一步就是两边积分。

```text
dy/dx = f(x)g(y)  ⇒  ∫ dy/g(y) = ∫ f(x) dx
```

不定积分不熟，微分方程就只能列式不能求解。

**一个整体视角。**

微积分基本定理把两块连成一个环：

```text
求导 → 得到变化率
积分 → 从变化率还原函数（差一个常数）
再求导 → 回到变化率
```

这个环是整门课的主轴。

### 自检三问

**第一问：为什么不定积分的结果必须带 C？去掉 C 会在哪里出错？**

因为常数的导数为零，所以原函数永远是一族，不是单个。

去掉 C 在纯计算题里只是丢一分，但在"已知曲线过某点求曲线方程"这类题里会直接导致答案错误。

比如已知 y' = 2x 且曲线过 (1, 3)，正确解法是 y = x² + C，代点得 3 = 1 + C，C = 2，所以 y = x² + 2。

没有 C，就写不出这个 2。

**第二问：第一类换元与第二类换元的差别在哪，各自什么时候用？**

第一类换元是"把被积式里的一部分凑成 du"，变量仍然是 x 的表达式，适合被积式里明显含有"内层函数 × 内层导数"的情形。

第二类换元是"把 x 整体换成 φ(t)"，适合被积式里有根号、需要靠三角恒等式消去根号的情形。

判断方法：如果能一眼看出"某函数的导数就在旁边"，用第一类；如果看到 √(a²-x²)、√(x²+a²) 这类结构，用第二类。

**第三问：分部积分选 u 的口诀是什么？为什么反过来会越算越复杂？**

口诀是"反、对、幂、指、三"，排在前面的优先当 u。

反过来的问题在于：分部积分的效果取决于"u 求导后是否变简单"。

幂函数求导降次，越算越简单；指数和三角函数求导后形态不变，如果让它们当 u，被求导的变成了幂函数，幂次反而升高。

## 12. 小结

没有小结，这一章的六个方法会混成一团。

把这一篇压成一张卡片：

```text
∫ f(x) dx = F(x) + C，F' = f
基本表：十六条，从求导表倒着抄
拆项：加减可以分开积，乘除不行
第一类换元：凑微分，du = φ'(x)dx
第二类换元：x = φ(t)，三角代换消根号
分部：∫u dv = uv - ∫v du，口诀"反对幂指三"
```

四步公式在这六种方法里是同一套：

```text
算什么 → 逐符号 → 代数字 → 适用条件
```

差别只在"算什么"这一步：直接积分是查表，换元是变形，分部是转移。

考场上遇到一个新积分，判断顺序是：

```text
1. 能不能直接查表或拆成表里的项
2. 能不能凑微分
3. 有没有根号，要不要三角代换
4. 是不是两类函数相乘，要不要分部
5. 是不是有理函数或三角有理式，要不要拆部分分式
```

按这个顺序试，五步之内一般能出结果。

再看三个"信号词"，听到它们就该想到对应方法：

```text
"凑微分"   → 看到内层函数和它的导数同时出现
"消根号"   → 看到 √(a²-x²)、√(x²+a²)、√(x²-a²)
"降次"     → 看到 xⁿ 乘 e^x 或 sin x，看到 sin²x、cos²x
```

三个信号词对应三套动作，考场上先认信号，再动手。

最后是两句提醒。

```text
第一句：每个答案都求导验一次，十秒钟，能救回大量错。
第二句：形式不同不等于错，只差常数就都是对的。
```
