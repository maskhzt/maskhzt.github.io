> **读这篇之前，你只需要知道**：偏导数 ∂z/∂x 是"按住 y、只让 x 变"时的变化率；二元函数的图像是一张曲面；一元函数求极值要先找导数为零的点，再看二阶导数的正负。
> **这篇讲什么**：把两个偏导合成一个整体，用来做近似计算；再把"导数为零"推广到曲面，找出山顶和谷底，包括被一条曲线限制住时的极值。
> **一个类比**：站在山坡上，想知道往东北走一步会升高多少——把"往东的坡度"乘上东移的距离，加上"往北的坡度"乘上北移的距离，就是这一步的高度变化。

一块矩形薄板。

长 x，宽 y，面积是

```text
S = xy
```

现在长增加 0.01，宽增加 0.02。

面积增加多少？

精确值是：

```text
(x + 0.01)(y + 0.02) - xy = 0.02x + 0.01y + 0.0002
```

最后那个 0.0002 是两个小量相乘，非常小。

如果只保留"主要部分"：

```text
ΔS ≈ y·Δx + x·Δy = 0.01y + 0.02x
```

这个"主要部分"，就是**全微分**。

它把两个偏导各乘上对应的微小改变量，再加起来。

```text
dz = (∂z/∂x)·dx + (∂z/∂y)·dy
```

这一篇先讲清 dz 是什么，再用它来求极值。

## 1. 为什么需要它（不给会怎样）

没有这一节，偏导数就只是两个孤立的数，用不起来。

具体会缺三种能力。

**第一种，估不出总变化。**

只知道 ∂z/∂x = 4、∂z/∂y = 13，问"x 增加 0.01、y 增加 0.02，z 大约变多少"，你答不出来。

把两个偏导按各自的改变量加权相加，才能回答。

工程里的误差分析、灵敏度分析，全靠这一步。

**第二种，判断不了"可微"。**

偏导存在，函数却可能连连续都不满足，更谈不上"用一个平面去逼近曲面"。

没有全微分，你分不清"两个方向都有切线"和"整个曲面有一个切平面"。

这两件事在多元里是两回事，数一专门设选择题考它。

**第三种，找不到极值。**

一元求极值：令 f'(x) = 0。

多元求极值：令两个偏导同时为零。

但"两个偏导为零"只是必要条件，还得判断这个点是山顶、谷底还是马鞍。

判断要用二阶偏导组成的判别式。

**第四种，处理不了约束。**

现实里的最优化几乎都带约束：

```text
周长固定，求面积最大
表面积固定，求体积最大
预算固定，求产量最高
```

这叫条件极值。

工具是拉格朗日乘数法，里面有一个新符号 λ。

**这四件事合起来，就是这一篇的全部内容。**

**先看一个具体的误差例子。**

量一块矩形地面，长 5 米，误差 ±0.01 米；宽 3 米，误差 ±0.02 米。

面积 S = xy = 15 平方米，误差是多少？

用全微分：

```text
dS = y dx + x dy = 3(0.01) + 5(0.02) = 0.03 + 0.10 = 0.13
```

所以面积误差约 ±0.13 平方米，相对误差约 0.87%。

**这个算法比"算两个极端"多给了什么？**

多给了"谁贡献大"。

```text
宽的误差贡献 0.10，长的误差贡献 0.03。
```

宽是主要误差源，想提高精度，先换量宽的尺子。

这个信息，只算最大值和最小值是得不到的。

所以全微分不是考试用的花架子，工程里管它叫误差传播公式。

哪一项偏导大，哪一项就是误差的主渠道，这个判断直接决定该换哪台仪器。

## 2. 最小模型：全微分 dz

没有这一步，后面的近似和极值都没有落脚点。

先读符号。

```text
dz = (∂z/∂x) dx + (∂z/∂y) dy
```

**dz**：读"d z"，叫 z 的全微分。

**∂z/∂x**：z 对 x 的偏导，一个数（在给定点处）。

**dx**：x 的微分，就是 x 的一个微小改变量，可以理解成 Δx。

**dy**：y 的微小改变量。

整个式子的意思：

```text
x 动一点点、y 也动一点点，z 跟着动的那部分"主要变化"。
```

**和偏导的区别，一句话。**

```text
∂z/∂x：只让 x 动。
dz：让 x 和 y 一起动。
```

**几何意义。**

曲面 z = f(x, y) 在点 P 处有一张切平面。

全微分 dz 就是"切平面上升的高度"。

真实曲面上升的高度记作 Δz。

两者的差，是一个比 √(dx² + dy²) 高阶的无穷小。

写成：

```text
Δz = dz + o(ρ)，ρ = √(dx² + dy²)
```

**什么叫"可微"。**

如果 Δz 能写成

```text
Δz = A·Δx + B·Δy + o(ρ)
```

其中 A、B 只与点 P 有关、与 Δx、Δy 无关，就说 f 在 P 点可微。

而且这时 A = ∂z/∂x，B = ∂z/∂y。

所以可微的定义里，"线性主部"就是全微分。

**四个步骤过一遍。**

**算什么**：用一个线性式子近似函数值的改变量。

**逐符号**：A、B 是两个偏导；Δx、Δy 是自变量的改变；o(ρ) 是比距离更高阶的小量。

**代数字**：z = x²y，在 (1, 2) 处，z_x = 4，z_y = 1，所以 dz = 4dx + dy。

**适用条件**：函数在该点可微。偏导存在还不够。

**切平面长什么样。**

```text
        z
        │       ╱
        │     ╱   ← 曲面
        │   ╱
        │ ╱
        └──────── y
       ╱
      x
```

在 P 点附近，曲面和切平面几乎贴在一起；离 P 越远，两者分开越快。

dz 就是"切平面上升的高度"，Δz 是"曲面上升的高度"。

两者之差，就是那个 o(ρ)。

**一个必须记住的反例。**

```text
f(x, y) = xy/√(x² + y²)，(x,y) ≠ (0,0)；f(0,0) = 0
```

在原点，两个偏导都等于 0。

但如果可微，就该有

```text
f(Δx, Δy) - f(0,0) = 0·Δx + 0·Δy + o(ρ)
```

也就是 f(Δx, Δy)/ρ → 0。

实际算一下，取 Δx = Δy = t：

```text
f(t, t)/ρ = (t²/(t√2))/(t√2) = 1/2
```

不趋于 0。

所以这个函数在原点不可微，尽管两个偏导都存在。

**结论：偏导存在 ⇏ 可微。**

**结论：偏导存在 ⇏ 可微。**

**微分形式不变性。**

设 z = f(u, v)，而 u、v 又是 x、y 的函数。

不管 u、v 是自变量还是中间变量，都有

```text
dz = f_u du + f_v dv
```

形式完全一样。

这条性质叫一阶微分形式不变性。

它的用处是：复合求导时可以先写 dz，再换 du、dv，最后整理出偏导。

对一元函数，它就是"dy = f'(u) du"在多元的翻版。

**"线性主部"这四个字，值得多解释两句。**

把 Δx、Δy 想得很小，比如 0.01。

那么 Δz 里，一次项大约按 0.01 缩小，二次项按 0.0001 缩小。

一次项占绝对大头，二次及以上的项加起来还不到它的百分之一。

所谓"主部"，就是这段占大头的线性部分。

而"线性"的意思是：它对 Δx、Δy 都是一次的，没有平方、没有乘积。

所以它能写成两个系数乘上两个增量再相加。

这两个系数，就是两个偏导。

**为什么偏导恰好是这两个系数？**

让 Δy = 0，只让 x 变。

这时 Δz = A Δx + o(|Δx|)，两边除以 Δx，再令 Δx → 0：

```text
A = lim Δz/Δx = ∂z/∂x
```

所以线性主部里 x 的系数，只能是 ∂z/∂x。

y 的系数同理。

**这就是全微分公式的来历：不是规定，是推出来的。**

## 3. 拆开看：可微怎么判

没有这一节，你会在"这个函数可不可微"上卡住，而这是选择题的高频点。

判可微有三条路，按顺序用。

**第一条，必要条件，用来否定。**

```text
可微 ⇒ 连续
可微 ⇒ 偏导存在
```

逆否命题：

```text
不连续 ⇒ 不可微
偏导不存在 ⇒ 不可微
```

所以拿到一个函数，先看它连不连续、偏导在不在。

有一个不满足，直接判不可微，不用再算。

**第二条，充分条件，用来肯定。**

```text
偏导连续 ⇒ 可微
```

这是最常用的一条。

因为初等函数的偏导在定义域内通常连续，所以：

```text
由初等函数构成的二元函数，在定义域内可微。
```

考试里九成的函数，用它一句话就判完了。

**第三条，回到定义，用于分段点。**

分界点上的偏导连续与否不好看，只能算极限：

```text
lim_{ρ→0} [Δz - (A Δx + B Δy)]/ρ = 0
```

等于 0 才可微。

**把关系图画出来，贴在桌上。**

```text
偏导连续  ⇒  可微  ⇒  连续
                 ⇒  偏导存在
```

箭头都是单向的。

反过来：

```text
连续 ⇏ 偏导存在（锥面顶点）
偏导存在 ⇏ 连续（xy/(x²+y²)）
偏导存在 ⇏ 可微（xy/√(x²+y²)）
```

**一张对照表，记住三种反例。**

```text
反例                    连续  偏导  可微
√(x²+y²) 在原点          是    否    否
xy/(x²+y²) 在原点        否    是    否
xy/√(x²+y²) 在原点       是    是    否
```

第三行是最反直觉的：连续、偏导都有，就是不可微。

这正是"切平面立不起来"的样子。

**例题：用定义判一个"振荡型"的函数。**

```text
f(x,y) = (x²+y²)sin(1/(x²+y²))，(x,y) ≠ (0,0)
f(0,0) = 0
```

先看偏导。

```text
[f(Δx,0) - f(0,0)]/Δx = Δx² sin(1/Δx²)/Δx = Δx sin(1/Δx²)
```

sin 有界，Δx → 0，所以极限是 0。

同理 f_y(0,0) = 0。

再看可微。

```text
Δz = (Δx²+Δy²) sin(1/(Δx²+Δy²)) = ρ² sin(1/ρ²)
```

除以 ρ：

```text
Δz/ρ = ρ sin(1/ρ²) → 0
```

所以可微，全微分 dz = 0。

**这个例子说明：即使函数在原点附近疯狂振荡，只要振荡的幅度被 ρ² 压住，仍然可微。**

判可微，看的是"除以 ρ 之后还剩多少"，不是"函数看起来乱不乱"。

## 4. 算一遍：全微分与近似计算

没有这道手算，dz 就只是一个公式。

题目：

```text
z = x²y + y³，求在 (1, 2) 处的全微分；
并估计 x 增加 0.01、y 增加 0.02 时 z 的改变量。
```

**第一步，求两个偏导。**

```text
z_x = 2xy，z_y = x² + 3y²
```

**第二步，代点。**

```text
z_x(1,2) = 2·1·2 = 4
z_y(1,2) = 1 + 3·4 = 13
```

**第三步，写全微分。**

```text
dz = 4 dx + 13 dy
```

**第四步，代入改变量。**

dx = 0.01，dy = 0.02：

```text
dz = 4(0.01) + 13(0.02) = 0.04 + 0.26 = 0.30
```

所以 z 大约增加 0.30。

**验算精确值。**

```text
z(1,2) = 1·2 + 8 = 10
z(1.01, 2.02) = (1.01)²(2.02) + (2.02)³
```

算出来：

```text
1.0201 × 2.02 = 2.060602
2.02³ = 8.242408
合计 10.30301
```

真实增量是 0.30301，近似值是 0.30，误差 0.003。

误差来自二阶小量，量级是 (0.01)² 这个级别。

**再练一道"开根号"的近似。**

```text
估算 √(1.02² + 1.97²)
```

设 f(x, y) = √(x² + y²)，取 (x₀, y₀) = (1, 2)，Δx = 0.02，Δy = -0.03。

偏导：

```text
f_x = x/√(x²+y²)，f_y = y/√(x²+y²)
```

在 (1,2) 处，√5 ≈ 2.236：

```text
f_x = 1/√5 ≈ 0.447，f_y = 2/√5 ≈ 0.894
```

全微分：

```text
dz ≈ 0.447(0.02) + 0.894(-0.03) ≈ 0.00894 - 0.02683 ≈ -0.0179
```

原来 f(1,2) = √5 ≈ 2.2361，所以

```text
√(1.02² + 1.97²) ≈ 2.2361 - 0.0179 = 2.2182
```

直接算：1.0404 + 3.8809 = 4.9213，开方得 2.2184。

近似值和真值差 0.0002。

**近似计算的三步模板。**

```text
第一步：选一个附近的、函数值好算的点 (x₀, y₀)
第二步：算两个偏导，写 dz
第三步：f ≈ f(x₀,y₀) + dz
```

关键在第一步：整点选得好，手算量减半。

## 5. 拆开看：梯度与方向导数

没有这一节，"沿任意方向的变化率"就答不出来，而它正是梯度的来源。

偏导只管两个方向：x 方向和 y 方向。

如果问"沿东北方向走，z 变化多快"，偏导不够用。

**方向导数。**

设方向 l 的单位向量是

```text
e = (cosα, cosβ)
```

其中 α、β 是 l 与 x 轴、y 轴的夹角。

沿 l 的方向导数：

```text
∂f/∂l = f_x cosα + f_y cosβ
```

**梯度。**

```text
grad f = (f_x, f_y)
```

**grad**：读"gradient"的前四个字母，中文叫梯度。

符号也可以写成 ∇f，∇ 读"纳布拉"。

梯度是一个向量，两个分量分别是两个偏导。

于是方向导数可以写成内积：

```text
∂f/∂l = grad f · e
```

**内积的几何意义给出两个结论。**

```text
当 e 与梯度同向时，方向导数最大，最大值 = |grad f|
当 e 与梯度垂直时，方向导数为 0
```

翻译成人话：

```text
梯度指向"上升最快"的方向。
梯度的长度，就是那个最快的上升速度。
```

**算一道。**

```text
f(x, y) = x² + y²，在 (1, 2) 处
```

```text
grad f = (2x, 2y) = (2, 4)
|grad f| = √(4 + 16) = 2√5
```

沿方向 (1, 1) 的单位向量 e = (1/√2, 1/√2)：

```text
∂f/∂l = (2, 4)·(1/√2, 1/√2) = 6/√2 = 3√2
```

沿梯度方向 (1, 2)/√5：

```text
∂f/∂l = (2,4)·(1,2)/√5 = (2 + 8)/√5 = 10/√5 = 2√5
```

正好等于 |grad f|。

**几何直观：等高线。**

z = x² + y² 的等高线是同心圆。

梯度垂直于等高线，指向"从一圈到更高一圈"的方向。

等高线越密，梯度越长，坡越陡。

**为什么梯度垂直于等高线。**

沿着等高线走，f 的值不变，所以 df = 0。

而

```text
df = grad f · (dx, dy)
```

内积为零，说明位移方向与梯度垂直。

所以梯度垂直于等高线的切线，也就垂直于等高线本身。

**一个容易混的说法：梯度是法向量。**

二维时，梯度是等高线的法向量。

三维时，梯度是等值面的法向量。

求曲面切平面时用的法向量 (F_x, F_y, F_z)，就是 F 的梯度。

一句话：**梯度指方向，也当法线用。**

**和全微分的关系。**

```text
dz = f_x dx + f_y dy = grad f · (dx, dy)
```

所以全微分就是"梯度与位移的内积"。

位移方向和梯度同向时，dz 最大。

这句话在优化算法里叫"沿梯度方向走，函数值上升最快"。

这句话在优化算法里叫"沿梯度方向走，函数值上升最快"。

## 6. 拆开看：无条件极值

没有这一节，"求最大值"就只能靠观察。

极值分两种：极大值和极小值。

它们的定义是"局部"的：

```text
在 P₀ 附近的一个小圈里，f(P₀) 比所有其他点都大（小）。
```

注意"附近"三个字。

极值只管局部，不管整体；最值才管整个区域。

**必要条件。**

```text
f 在 P₀ 可微且取极值  ⇒  f_x(P₀) = 0 且 f_y(P₀) = 0
```

满足两个偏导都为零的点，叫驻点。

**定理里为什么要写"可微"？**

因为不可微的点，也可能靠一个尖点取到极值。

锥面 z = √(x²+y²) 在原点是极小值点，但两个偏导都不存在，根本谈不上"偏导为零"。

所以"偏导为零"只是可微函数才有的必要条件。

条件写全，才不会漏掉尖点这种极值点。

**为什么？**

固定 y = y₀，得到一条一元曲线。

P₀ 是二元极值点，那在这条曲线上也是极值点。

一元函数取极值，导数必为零，所以 f_x = 0。

同理 f_y = 0。

**注意两件事。**

第一，驻点不一定是极值点。

```text
f = x² - y² 在原点，两个偏导都是 0，但沿 x 轴是谷，沿 y 轴是峰。
```

这叫鞍点。

```text
        z
        │  ╲    ╱
        │   ╲  ╱
        │    ╲╱
        └────── y
       ╱
      x
```

沿 x 方向看是谷底，沿 y 方向看是峰顶，合起来是马鞍。

第二，极值点也可能不是驻点。

```text
z = √(x² + y²) 在原点取极小值，但偏导不存在。
```

所以找极值要查两类点：驻点，和偏导不存在的点。

**充分条件：二阶判别。**

设 P₀ 是驻点，记

```text
A = f_xx(P₀)，B = f_xy(P₀)，C = f_yy(P₀)
```

算判别式：

```text
Δ = AC - B²
```

三种情况：

```text
Δ > 0 且 A > 0  →  极小值
Δ > 0 且 A < 0  →  极大值
Δ < 0           →  不是极值（鞍点）
Δ = 0           →  失效，要另想办法
```

**这个判别式从哪来？**

把 f 在 P₀ 处做二阶泰勒展开：

```text
f ≈ f(P₀) + (1/2)(A Δx² + 2B Δx Δy + C Δy²)
```

一次项已经为零（驻点）。

二次型

```text
A Δx² + 2B Δx Δy + C Δy²
```

正定时，不管往哪个方向走都变大，所以是极小。

负定时，都变小，是极大。

不定时，有的方向变大有的变小，是鞍点。

二次型正定的判据，正好是 A > 0 且 AC - B² > 0。

**所以判别式的本质是：看二次型定不定号。**

**找极值的四步。**

```text
第一步：求 f_x、f_y，令它们为 0，解出驻点
第二步：求二阶偏导 A、B、C
第三步：在每个驻点算 AC - B²
第四步：按判别表下结论，并算出极值
```

## 7. 算一遍：f = x³ + y³ - 3xy

没有这道题，判别式就记不住。

**第一步，求驻点。**

```text
f_x = 3x² - 3y = 0  ⇒  y = x²
f_y = 3y² - 3x = 0  ⇒  x = y²
```

把第一个代入第二个：

```text
x = (x²)² = x⁴
x⁴ - x = 0
x(x³ - 1) = 0
```

实数解只有 x = 0 和 x = 1。

对应 y：

```text
x = 0  ⇒  y = 0
x = 1  ⇒  y = 1
```

两个驻点：(0, 0) 和 (1, 1)。

**第二步，求二阶偏导。**

```text
f_xx = 6x
f_xy = -3
f_yy = 6y
```

**第三步，在 (0, 0) 处判别。**

```text
A = 0，B = -3，C = 0
AC - B² = 0 - 9 = -9 < 0
```

不是极值，是鞍点。

**第四步，在 (1, 1) 处判别。**

```text
A = 6，B = -3，C = 6
AC - B² = 36 - 9 = 27 > 0
```

且 A = 6 > 0，所以是极小值。

```text
f(1, 1) = 1 + 1 - 3 = -1
```

**结论。**

```text
(0, 0) 是鞍点，不是极值点。
(1, 1) 是极小值点，极小值 -1。
```

**验算：沿几条直线切一刀。**

沿 y = x：

```text
f = 2x³ - 3x²
```

在 x = 1 处，一阶导 6x² - 6x = 0，二阶导 12x - 6 = 6 > 0，是极小。

沿 x = 1：

```text
f = 1 + y³ - 3y
```

在 y = 1 处，一阶导 3y² - 3 = 0，二阶导 6y = 6 > 0，也是极小。

沿 y = 2 - x（另一条过 (1,1) 的直线）：

```text
f = x³ + (2-x)³ - 3x(2-x)
```

在 x = 1 处二阶导为 18 > 0，仍是极小。

三个方向都显示极小，再加上 AC - B² > 0，才能确定是极小。

只看一个方向不够，这就是判别式存在的理由。

**为什么 (0, 0) 是鞍点，值得看一眼。**

沿 y = 0：

```text
f = x³
```

x 从负变正，函数从负变正，原点两侧一升一降。

沿 x = 0：

```text
f = y³
```

同样一升一降。

所以原点附近，有的方向函数变大，有的方向变小。

判别式 AC - B² = -9 < 0，说的就是这件"二次型不定号"的事。

**极值不等于最值，这一点必须分清。**

极值只看"附近一圈"，是局部概念。

最值看"整个区域"，是整体概念。

一个函数可以有很多个极大值，但最多只有一个最大值。

有界闭区域上的连续函数一定有最大值和最小值，这条定理保证最值存在。

但定理不告诉你最值在哪里。

它可能在内部驻点，可能在边界上，也可能在偏导不存在的尖点上。

所以求最值的标准流程是"三处都查"：

```text
第一处：内部驻点
第二处：内部偏导不存在的点
第三处：边界上的点（通常化成一元函数或条件极值）
```

把这三处的候选值全部算出来，比大小，最大的就是最大值。

这个过程没有技巧，只有遗漏。

考试失分，十有八九是漏了边界。

**为什么边界要单独处理？**

因为在边界上，x 和 y 不再自由，它们被约束方程绑住了。

约束一绑，问题就从"二元无约束"变成"一元"或者"条件极值"。

比如圆盘边界 x² + y² = 9，用一个参数 θ 就能把 x、y 都表示出来。

代进去，二元函数变成一元函数，直接求导即可。

这就是边界处理的核心动作：**降维**。

## 8. 拆开看：条件极值与拉格朗日乘数

没有这一节，带约束的最优化题就只能硬代，代完还要处理根号和定义域。

条件极值的问题是：

```text
在约束 g(x, y) = 0 下，求 f(x, y) 的极值。
```

**几何上先看明白。**

画出 f 的等高线，再画出约束曲线 g = 0。

沿着约束曲线走，f 的值在变。

当走到某一点，约束曲线的切线与某条等高线相切时，f 暂时不再增大或减小。

那一刻，两条曲线的法向量平行。

而 f 的等高线的法向量是 grad f，g = 0 的法向量是 grad g。

所以：

```text
grad f = λ · grad g
```

λ 是一个比例系数。

**为什么"相切"就是极值？**

沿约束曲线走，f 的值一直在变。

如果某点处，约束曲线是"穿过"等高线的，那么往前走一点进入更高的等高线，往后退一点进入更低的等高线。

两边都不取极值。

只有相切时，约束曲线与等高线擦肩而过，往前走和往后走都进入同一边的等高线，f 才在这里取到局部最大或最小。

相切的意思是两条曲线的切线方向相同，也就是法向量平行。

所以极值点必须满足

```text
grad f = λ grad g
```

**这就是乘数法的几何来源。**

**这个 λ 就是拉格朗日乘数。**

**λ**：读"兰姆达"，希腊字母，表示两个梯度之间的比例。

**构造拉格朗日函数。**

```text
L(x, y, λ) = f(x, y) + λ g(x, y)
```

然后令三个偏导为零：

```text
L_x = f_x + λ g_x = 0
L_y = f_y + λ g_y = 0
L_λ = g(x, y) = 0
```

前两个给出"梯度平行"，第三个就是约束本身。

**四步公式。**

**算什么**：在一条约束曲线上找 f 的最值。

**逐符号**：L 是辅助函数；λ 是乘数；g 是约束，写成 g = 0 的形式。

**代数字**：见下一节两道题。

**适用条件**：f 与 g 有连续偏导，且 grad g ≠ 0（约束曲线光滑），极值点存在。

**三个变量、一个约束，同理。**

```text
L = f(x, y, z) + λ g(x, y, z)
```

四个方程：L_x = L_y = L_z = L_λ = 0。

**两个约束呢？**

```text
L = f + λ g + μ h
```

引入两个乘数，五个方程。

数一一般只考一个约束，两个约束偶尔出现在小题里。

**λ 有什么实际意义？**

它是"约束放松一点，最优值能提高多少"的比率。

经济学里叫影子价格。

考试一般不要求解释，但知道这层意思，就不容易把 λ 当成一个凑数的符号。

## 9. 算一遍：三道条件极值

没有这两道题，乘数法就落不了地。

**第一道，两变量。**

```text
求 z = xy 在 x + y = 1 下的最大值。
```

第一步，写成标准形式：

```text
f = xy，g = x + y - 1 = 0
```

第二步，造 L：

```text
L = xy + λ(x + y - 1)
```

第三步，求偏导并令零：

```text
L_x = y + λ = 0
L_y = x + λ = 0
L_λ = x + y - 1 = 0
```

第四步，解方程组。

前两式相减：

```text
y - x = 0  ⇒  x = y
```

代入第三式：

```text
2x = 1  ⇒  x = y = 1/2
```

最大值：

```text
z = (1/2)(1/2) = 1/4
```

**验算：直接代。**

y = 1 - x，z = x(1 - x) = x - x²。

这是一元二次函数，顶点在 x = 1/2，最大值 1/4。

两条路一致。

**第二道，三变量。**

```text
表面积固定为 S，求长方体体积的最大值。
```

设长宽高为 x、y、z。

```text
体积 V = xyz
约束 2(xy + yz + zx) = S
```

把约束除以 2，写成 g = xy + yz + zx - S/2 = 0。

造 L：

```text
L = xyz + λ(xy + yz + zx - S/2)
```

求偏导：

```text
L_x = yz + λ(y + z) = 0
L_y = xz + λ(x + z) = 0
L_z = xy + λ(x + y) = 0
```

三个式子分别乘 x、y、z：

```text
xyz + λ(xy + xz) = 0
xyz + λ(xy + yz) = 0
xyz + λ(xz + yz) = 0
```

第一式减第二式：

```text
λ(xz - yz) = λz(x - y) = 0
```

x、y、z 都是正数，λ 不为零（否则 xyz = 0，矛盾），所以 x = y。

同理 y = z。

代回约束：

```text
3x² = S/2  ⇒  x = √(S/6)
```

三个边长相等，是正方体。

最大体积：

```text
V = (S/6)^(3/2)
```

**这个结论要记住：表面积固定时，正方体体积最大。**

它是一大类"等周问题"的原型。

**解题时的两个细节。**

第一，约束要写成"等于 0"的形式，常数项放进 g。

第二，解出 λ 后通常要消掉它，消不掉就回代约束。

第二，解出 λ 后通常要消掉它，消不掉就回代约束。

**第三道，约束是圆。**

```text
求 z = x + y 在 x² + y² = 1 下的最大值和最小值。
```

造 L：

```text
L = x + y + λ(x² + y² - 1)
```

求偏导：

```text
L_x = 1 + 2λx = 0
L_y = 1 + 2λy = 0
L_λ = x² + y² - 1 = 0
```

前两式给出：

```text
x = y = -1/(2λ)
```

代入第三式：

```text
2x² = 1  ⇒  x = ±1/√2
```

两个候选点：

```text
(1/√2, 1/√2)：z = √2
(-1/√2, -1/√2)：z = -√2
```

最大值 √2，最小值 -√2。

**几何解释。**

z = x + y 的等高线是一族平行直线 x + y = c。

约束是单位圆。

让直线平移，与圆相切时 c 取到极值，切点正是 (1/√2, 1/√2) 和它的对点。

切的时候，直线的法向量 (1, 1) 与圆的法向量 (2x, 2y) 平行。

这就是"两个梯度平行"的几何来源。

## 10. 常见错误

没有这一节，会做的题也会丢分。

**错误一：把 dz 和 Δz 当成一回事。**

dz 是线性主部，Δz 是真实增量。

两者差一个高阶无穷小。

在 (1, 2) 那道题里，dz = 0.30，Δz = 0.30301。

题目问"约等于"，写 dz；问"实际增加"，写 Δz。

**错误二：以为偏导存在就可微。**

反例第 2 节已经给过：xy/√(x²+y²)。

判断可微，最稳的是看偏导是否连续。

**错误三：把驻点直接当极值点。**

驻点只是"两个偏导为零"，可能是鞍点。

必须用 AC - B² 判别。

比如 f = x² - y²，原点两个偏导为零，但不是极值。

**错误四：AC - B² = 0 时直接下结论。**

判别式失效，不等于"不是极值"。

这时要回到定义，或者用其他方法（比如配方法、泰勒展开的高阶项）。

数一考到这种情况很少，但概念题会问"判别式为零时能否判定"，答案是不能。

**错误五：条件极值忘了约束方程。**

只解 L_x = 0、L_y = 0，得到的是"无约束的驻点"，不是条件极值点。

第三个方程 L_λ = 0 必须写。

**错误六：解出 λ 就停手，不回代求点。**

题目问的是极值点坐标和极值，不是 λ 的值。

λ 只是中间量。

**错误七：求最值时只算内部驻点，忘了边界。**

有界闭区域上的最值，可能在边界上取到。

标准做法：

```text
第一步：算区域内部的驻点，求函数值
第二步：把边界代入（通常变成一元函数或条件极值），求边界上的最值
第三步：所有候选值比较大小
```

漏掉第二步，答案可能完全错。

**错误八：把"极大值"说成"最大值"。**

极大值是局部的，最值是整体的。

一个函数可以有多个极大值，只有一个最大值。

答题时用词要准。

## 11. 数一怎么考

没有这一节，复习会没有重点。

数一在这一章有四种题型。

**第一种，全微分与近似。**

```text
设 z = e^(xy)，求 dz。
```

```text
z_x = y e^(xy)，z_y = x e^(xy)
dz = e^(xy)(y dx + x dy)
```

填空，4 分。

**第二种，无条件极值。**

常考"求 f 的极值"，10 分。

步骤就是第 7 节那四步，关键是解方程组要全。

**第三种，条件极值。**

这是重中之重，几乎年年有。

```text
求原点到平面 x + 2y + 3z = 6 的距离。
```

转化成条件极值：求 x² + y² + z² 在约束下的最小值。

造 L：

```text
L = x² + y² + z² + λ(x + 2y + 3z - 6)
```

求偏导：

```text
2x + λ = 0
2y + 2λ = 0
2z + 3λ = 0
```

解出：

```text
x = -λ/2，y = -λ，z = -3λ/2
```

代入约束：

```text
-λ/2 - 2λ - 9λ/2 = -7λ = 6  ⇒  λ = -6/7
```

所以：

```text
x = 3/7，y = 6/7，z = 9/7
```

距离：

```text
d = √(x² + y² + z²) = √(9 + 36 + 81)/7 = √126/7 = 3√14/7
```

用点到平面距离公式验算：6/√14 = 3√14/7，一致。

**第四种，几何应用。**

求曲面在某点的切平面、法线。

切平面的法向量是 (F_x, F_y, F_z)，三个分量都是偏导。

**分值与时间。**

```text
全微分：选择或填空，4 分
无条件极值：解答题，10 分
条件极值：解答题，10 到 12 分
几何应用：填空或大题的一问，4 到 8 分
```

条件极值建议留 15 分钟：列式 3 分钟，解方程 7 分钟，回代验算 3 分钟。

**条件极值的答题模板。**

```text
第一行：写出目标函数 f 与约束 g = 0
第二行：造 L = f + λg，列出 L_x = L_y = L_λ = 0
第三行：解方程组，得到候选点
第四行：回代 f，比较大小，写结论
```

第四行经常被省略，但题目问的是"最大值是多少"，不是"λ 等于多少"。

少写一行，少一半分。

**一个检查办法。**

把候选点代回约束方程，看是否满足。

不满足，说明解方程时哪一步代数错了。

这一步只花二十秒，能拦住大部分计算失误。

**一道综合题，把内部和边界都走一遍。**

```text
求 f = x² + y² - 2x - 2y 在圆盘 x² + y² ≤ 9 上的最大值和最小值。
```

第一步，内部驻点。

```text
f_x = 2x - 2 = 0  ⇒  x = 1
f_y = 2y - 2 = 0  ⇒  y = 1
```

(1, 1) 在圆盘内，函数值：

```text
f(1,1) = 1 + 1 - 2 - 2 = -2
```

第二步，边界。

在圆 x² + y² = 9 上，用参数：

```text
x = 3cosθ，y = 3sinθ
```

代入：

```text
f = 9 - 6(cosθ + sinθ) = 9 - 6√2 sin(θ + π/4)
```

最大值 9 + 6√2，最小值 9 - 6√2。

第三步，比较。

```text
-2 比 9 - 6√2 ≈ 0.515 小，所以最小值是 -2。
最大值是 9 + 6√2。
```

**关键点：最值不一定在边界，也不一定在内部。**

两边都要算，再比大小。

如果只算内部，会漏掉 9 + 6√2；如果只算边界，会漏掉 -2。

## 12. 和其他章节怎么连

没有这一节，这一章会显得像一套孤立的判别规则。

**往回连：10 偏导数。**

全微分的两个系数、极值的两个必要条件、乘数法的三个方程，全是偏导。

偏导不熟，这一章寸步难行。

**往回连：05 导数的应用。**

一元极值的判别用 f''，多元用 AC - B²。

一元的最值比较端点，多元的比较边界。

结构完全平行。

**往前连：12 二重积分。**

二重积分的被积函数在区域上积分，区域的边界常常就是条件极值里的约束曲线。

求区域面积、质心，有时要先确定边界的最值点。

**横向连：21 空间解析几何。**

切平面、法线、距离公式，都要用偏导和梯度。

**往前连：13 三重积分。**

三重积分的计算里，常常要先确定积分区域的最值点，用来定积分限。

条件极值求出的切点，往往就是积分限的边界。

**一个容易忽略的联系：泰勒公式。**

一元有泰勒展开，多元也有。

这一章用到的二阶泰勒展开，只取到二次项，就足以判极值。

到了级数那一章，一元泰勒展开会展开得更细。

两者的思想是同一个：用多项式逼近函数。

**一个整体视角。**

```text
偏导 → 全微分 → 切平面 → 梯度 → 极值 → 条件极值
```

这条链上，每一步都是前一步的"整体化"：

偏导是一个方向，全微分是所有方向，梯度是"最陡的方向"，极值是"梯度为零"，条件极值是"梯度与约束法向量平行"。

看懂了这条链，这一章就不用背。

### 自检三问

**第一问：dz 和 Δz 有什么区别？近似计算时用哪个？**

dz 是切平面上升的高度，是一个线性表达式。

Δz 是曲面真实上升的高度。

两者相差一个比距离更高阶的无穷小，所以距离很小时 dz ≈ Δz。

题目说"近似""约等于""估计"，用 dz；说"精确增量""实际改变"，用 Δz。

**第二问：为什么驻点不一定是极值点？AC - B² 在判什么？**

驻点只保证两个坐标方向的斜率为零。

但曲面在这一点可能是马鞍形：一个方向向上弯，另一个方向向下弯。

AC - B² 判的是二阶泰勒展开里那个二次型定不定号。

正定（A > 0 且 AC - B² > 0）是碗形，极小；负定是倒扣的碗，极大；不定是马鞍。

**第三问：拉格朗日乘数法为什么要求两个梯度平行？λ 是什么？**

在约束曲线上走，f 的值变化。

当走到极值点时，沿约束曲线再走一小步，f 的一阶变化为零。

而 f 的一阶变化是 grad f 与位移的内积。

位移又必须与 grad g 垂直（因为要贴着约束曲线走）。

所以 grad f 必须与 grad g 平行，比例系数就是 λ。

λ 的绝对值表示"约束放松一个单位，最优值能变多少"。

## 13. 小结

没有小结，这一章的公式会混成一团。

压成一张卡片：

```text
全微分：dz = f_x dx + f_y dy
可微：Δz = f_x Δx + f_y Δy + o(ρ)
可微的充分条件：偏导连续
梯度：grad f = (f_x, f_y)，方向导数 = grad·e
极值必要条件：f_x = f_y = 0（驻点）
极值充分条件：A = f_xx，B = f_xy，C = f_yy
              AC - B² > 0 且 A > 0 → 极小
              AC - B² > 0 且 A < 0 → 极大
              AC - B² < 0 → 鞍点
条件极值：L = f + λg，L_x = L_y = L_λ = 0
```

四步公式的统一形态：

```text
算什么 → 整体变化量 / 曲面上的最高最低点
逐符号 → dz 是全微分，λ 是乘数，A、B、C 是二阶偏导
代数字 → 代点算偏导，解方程组
适用条件 → 可微；约束光滑；极值点存在
```

三句提醒。

```text
第一句：偏导存在只是必要条件，可微要看偏导连续。
第二句：驻点必须判 AC - B²，别直接写"极值"。
第三句：条件极值一定带约束方程，λ 不是答案。
```

最后补两句。

乘数法不是新公式，它就是"两个梯度平行"的代数写法。

复习时只看两样东西：AC - B² 判别表，和 L 的三个方程。其余内容都是这两样的展开。

这两样东西，一个管"内部"，一个管"边界"，合起来才是一道完整的极值题。
