> **读这篇之前，你只需要知道**：定积分 ∫ₐᵇ f(x) dx 是"把曲线下的面积切成细条加起来"；二元函数的图像是一张曲面；平面区域可以用不等式描述，比如 x² + y² ≤ 1 是一个圆盘。
> **这篇讲什么**：把"切细条"升级成"切小方块"，在一块平面区域上把每一点的高度累加起来，得到一块立体的体积；难点全在"怎么把区域写成两次积分"。
> **一个类比**：要给一块形状不规则的地面铺瓷砖，先沿一个方向把地面切成一条条，再把每条切成小块，一块一块算面积乘高度，最后全加起来。

先看一个几何问题。

平面上有一块区域 D，是四分之一圆：

```text
x² + y² ≤ 1，x ≥ 0，y ≥ 0
```

在 D 的上方，立着一个曲面：

```text
z = x² + y²
```

曲面、区域 D、以及过 D 边界的竖直柱面，围出一块立体。

问：这块立体的体积是多少？

一元积分解决不了。

因为切一刀，截面是一个随位置变化的曲线，不是一个固定形状。

必须把地面切成小块，每块上方近似看成一根柱子：

```text
柱子的体积 ≈ 底面积 × 该点的高度
```

把所有柱子加起来，再让每块底面积趋于零。

这个"加起来取极限"的动作，就是**二重积分**。

写成：

```text
∬_D (x² + y²) dσ
```

这一篇就讲清楚这个符号的每一部分，以及怎么把它算成一个数。

## 1. 为什么需要它（不给会怎样）

没有这一节，你会以为积分只是"一元的事情"，遇到体积、质量、平均值就无从下手。

具体缺四种能力。

**第一种，算不了曲顶柱体的体积。**

一元定积分算的是"曲线下的面积"，底边是一条线段。

二重积分算的是"曲面下的体积"，底面是一块区域。

区域可以是圆、三角形、环形、被两条抛物线夹住的月牙形。

形状一复杂，一元就无能为力。

**第二种，算不了薄板的质量。**

一块密度不均匀的薄板，密度是 ρ(x, y)。

总质量不是"密度乘面积"，因为密度逐点不同。

要把板切成小块，每块的质量 ≈ ρ × 小块面积，再全部加起来。

这正是二重积分。

**第三种，算不了平均值。**

一块区域上温度的平均值，是"总热量除以面积"。

总热量就是温度在区域上的二重积分。

```text
平均温度 = (1/面积) ∬_D T(x, y) dσ
```

概率论里二维随机变量的联合密度、期望，全是这个结构。

**第四种，后面几章都要用。**

三重积分要先把二重积分算出来。

曲面积分会把问题投影到平面上，化成二重积分。

格林公式把曲线积分和二重积分连起来。

所以这一章不是"多元积分的入门"，它是整个多元积分的地基。

地基不牢，后面全塌。

**再补两个场景，说明它为什么绕不开。**

场景一，转动惯量。

一块薄板绕一根轴旋转，板上每一点到轴的距离不同，对转动的贡献也不同。

离轴越远的点，贡献越大，而且是按距离的平方增长。

所以不能只算总质量，必须逐点算，再累加：

```text
I = ∬_D ρ(x, y)·(到轴距离)² dσ
```

场景二，质心。

一块密度不均匀的板，重心不在几何中心。

求重心坐标，分子是"每点的位置乘密度"的累加，分母是总质量：

```text
x̄ = ∬_D x·ρ(x, y) dσ / ∬_D ρ(x, y) dσ
```

**这两个式子的共同点：被积的不是 1，而是"每一点自己的某个量"。**

二重积分做的事，就是把这些逐点不同、没法用乘法解决的量，一块一块累加起来。

一元积分只能沿一条线累加，遇到"铺满一块面"的量，就不够用了。

这就是二重积分必须存在的理由。

## 2. 最小模型：∬ 与 dσ

没有这一步，符号就是一堆看不懂的笔画。

先读符号。

```text
∬_D f(x, y) dσ
```

**∬**：读"二重积分号"。

它由两个 ∫ 叠在一起，意思是"两个方向各积一次"。

**D**：积分区域，平面上的一个点集。

**f(x, y)**：被积函数，可以理解为每一点的"高度"或"密度"。

**dσ**：读"d sigma"，叫面积元素，表示"一小块面积"。

**∬_D**：整体读作"在区域 D 上的二重积分"。

**这个式子的意思。**

把 D 切成 n 个小块，第 i 块的面积记作 Δσᵢ。

在每块里随便取一点 (ξᵢ, ηᵢ)，算出高度 f(ξᵢ, ηᵢ)。

做和：

```text
Σ f(ξᵢ, ηᵢ) Δσᵢ
```

让所有小块的最大直径趋于零，如果这个和趋于一个确定的数，就把它定义为二重积分。

**几何意义，分三种情况。**

```text
f ≥ 0：曲顶柱体的体积
f = 1：区域 D 的面积
f 有正有负：体积的代数和（正的算正，负的算负）
```

第二条很实用：算面积时，被积函数取 1 就行。

```text
∬_D 1 dσ = D 的面积
```

**四个步骤过一遍。**

**算什么**：一块区域上"高度"的累加，几何上是曲顶柱体的体积。

**逐符号**：∬ 是两次积分；D 是积分区域；dσ 是面积元素；f 是每一点的高度。

**代数字**：f = x² + y²，D 是单位圆盘，用极坐标算得 π/2。

**适用条件**：f 在 D 上有界且可积（连续就够），D 是有界、可求面积的区域。

**二重积分的五条性质。**

```text
线性：∬(af + bg) = a∬f + b∬g
可加：D 分成 D₁、D₂，则 ∬_D = ∬_D₁ + ∬_D₂
比较：f ≤ g 则 ∬f ≤ ∬g
估值：m·S ≤ ∬f ≤ M·S（m、M 是 f 的最值，S 是面积）
中值：存在一点，使 ∬f = f(该点)·S
```

中值定理在证明题里偶尔出现，其余四条是计算时的基本操作。

**中值定理在说什么。**

把 ∬f 想成"总量"，S 是区域面积。

总量等于"某个平均高度"乘面积。

中值定理说：这个平均高度，一定能在区域里找到一点真正取到。

物理上就是"平均温度一定在板上某一点出现"。

严密一点说，连续函数在连通闭区域上的值域是一个区间，平均值落在区间内，所以能取到。

**可积的条件。**

和一元一样，连续函数一定可积。

有界、且不连续点只落在有限条曲线上的函数，也可积。

考试里遇到的函数几乎都满足，不用专门验证。

真正要花时间的是"把区域写对"，不是"验证可积"。

**一个容易忽略的细节：积分与变量的名字无关。**

```text
∬_D f(x, y) dxdy = ∬_D f(u, v) dudv
```

x、y 只是占位符，换成 u、v 结果不变。

这一点在换元时很重要：换元之后，积分变量变了，但积分值不变。

**一个必须先建立的习惯：画图。**

不画图，积分限一定写错。

图不用漂亮，能看出边界是谁、谁在上谁在下、区域偏向哪一边，就够。

```text
      y
      │   ╱ 上边界 y = φ₂(x)
      │ ╱
      │╱   区域 D
      ├──── 下边界 y = φ₁(x)
      └──────── x
     a         b
```

这张图决定了后面所有的上下限。

这张图决定了后面所有的上下限。

## 3. 拆开看：直角坐标下的累次积分

没有这一节，二重积分就只是一个定义，永远算不出数。

二重积分要算成两个一元积分，一前一后。

这叫**累次积分**。

**X 型区域。**

如果区域能写成

```text
a ≤ x ≤ b，φ₁(x) ≤ y ≤ φ₂(x)
```

也就是"竖着切，每一条竖线的上下端都由 x 决定"，就叫 X 型区域。

这时：

```text
∬_D f(x, y) dσ = ∫ₐ^b dx ∫_{φ₁(x)}^{φ₂(x)} f(x, y) dy
```

**怎么读这个式子。**

先算方括号里的内层积分：

```text
∫_{φ₁(x)}^{φ₂(x)} f(x, y) dy
```

这一步把 y 积掉，x 当常数，结果是一个只含 x 的函数。

再把这个结果对 x 从 a 积到 b。

**Y 型区域。**

如果区域能写成

```text
c ≤ y ≤ d，ψ₁(y) ≤ x ≤ ψ₂(y)
```

就叫 Y 型区域。

```text
∬_D f(x, y) dσ = ∫_c^d dy ∫_{ψ₁(y)}^{ψ₂(y)} f(x, y) dx
```

**定限的三条规则。**

```text
第一条：外层积分限一定是常数
第二条：内层积分限可以是外层变量的函数
第三条：内层先积，外层后积，顺序不能乱
```

第一条是检查的法宝。

写完积分限，看一眼最外面那两个数。

如果它们含变量，一定错了。

**为什么外层必须是常数？**

因为外层积分积完之后，结果必须是一个数。

如果外层限含变量，积出来还是一个函数，那就不是二重积分的值了。

**dσ 在直角坐标下就是 dxdy。**

```text
dσ = dxdy
```

读作"d x d y"。

它表示"x 方向的一小段乘上 y 方向的一小段"，也就是一个小矩形的面积。

所以直角坐标下，二重积分常写成：

```text
∬_D f(x, y) dxdy
```

两种写法完全等价。

**选 X 型还是 Y 型？**

看哪个方向切下去，边界更好表示。

```text
如果区域的上下边界是 y = … 的形式，选 X 型
如果区域的左右边界是 x = … 的形式，选 Y 型
如果两个方向都不好表示，就分块
```

选对了，积分好算；选错了，可能积不出来。

**"穿线法"：定限的通用动作。**

以 X 型为例。

拿一根竖直的线，从左往右移。

线第一次碰到区域的地方，是外层下限 a。

线最后离开区域的地方，是外层上限 b。

对某个固定的 x，线在区域里穿过的那一段，下端是内层下限 φ₁(x)，上端是内层上限 φ₂(x)。

把"下端""上端"写成关于 x 的表达式，内层限就有了。

**为什么要先画图再做这个动作？**

因为"第一次碰到"和"穿出"的位置，看图能一眼确认。

直接用代数解不等式也能做，但很容易把上下写反。

图是保险，不是装饰。

**Y 型就把竖线换成横线。**

动作完全一样，只是变量对调。

## 4. 算一遍：直角坐标基础题

没有这道题，定限规则就只是文字。

题目：

```text
计算 ∬_D (x + y) dσ，其中 D 是由 y = 0、x = 1、y = x 围成的三角形。
```

**第一步，画图定限。**

三条边：y = 0（下），x = 1（右），y = x（斜边）。

区域是：

```text
0 ≤ x ≤ 1，0 ≤ y ≤ x
```

这是一个 X 型区域。

**第二步，写成累次积分。**

```text
I = ∫₀¹ dx ∫₀^x (x + y) dy
```

**第三步，算内层。**

x 当常数，对 y 积分：

```text
∫₀^x (x + y) dy = [xy + y²/2]₀^x = x² + x²/2 = 3x²/2
```

**第四步，算外层。**

```text
I = ∫₀¹ (3x²/2) dx = (3/2)(1/3) = 1/2
```

答案是 1/2。

**换一个次序验算。**

区域也可以写成 Y 型：

```text
0 ≤ y ≤ 1，y ≤ x ≤ 1
```

```text
I = ∫₀¹ dy ∫_y^1 (x + y) dx
```

内层：

```text
[x²/2 + xy]_y^1 = (1/2 + y) - (y²/2 + y²) = 1/2 + y - 3y²/2
```

外层：

```text
∫₀¹ (1/2 + y - 3y²/2) dy = 1/2 + 1/2 - 1/2 = 1/2
```

两种次序结果一样。

**这个"两种次序都算一遍"的习惯，是检查答案最可靠的办法。**

代价是多花三分钟，收益是确定对错。

**再看一个被积函数更简单的。**

```text
计算 ∬_D xy dσ，D：0 ≤ x ≤ 1，0 ≤ y ≤ 1
```

矩形区域，两个方向都是常数限：

```text
I = ∫₀¹ dx ∫₀¹ xy dy = ∫₀¹ x·(1/2) dx = 1/4
```

也可以拆成两个一元积分相乘：

```text
∫₀¹ x dx · ∫₀¹ y dy = (1/2)(1/2) = 1/4
```

**矩形区域且被积函数能分离变量时，二重积分可以拆成两个定积分相乘。**

这是唯一能拆的情况。

区域不是矩形，或者被积函数分不开，就不能拆。

**第二道，区域要分块。**

```text
计算 ∬_D |x| dσ，D：|x| + |y| ≤ 1
```

D 是一个菱形，四个顶点是 (1,0)、(0,1)、(-1,0)、(0,-1)。

**第一步，看对称。**

区域关于 y 轴对称，|x| 也关于 y 轴对称。

所以可以只算右半，再乘 2：

```text
∬_D |x| dσ = 2 ∬_{D右半} |x| dσ
```

右半是：

```text
0 ≤ x ≤ 1，-1 + x ≤ y ≤ 1 - x
```

**第二步，写累次积分。**

在右半，x ≥ 0，所以 |x| = x。

```text
I = 2∫₀¹ dx ∫_{-1+x}^{1-x} x dy
```

**第三步，算内层。**

x 对 y 是常数，内层就是对常数积分，等于"常数乘区间长度"。

区间长度是：

```text
(1 - x) - (-1 + x) = 2 - 2x
```

所以内层是 x(2 - 2x)。

**第四步，算外层。**

```text
I = 2∫₀¹ (2x - 2x²) dx = 2(1 - 2/3) = 2/3
```

答案是 2/3。

**如果不用对称性会怎样？**

要写 -1 ≤ x ≤ 1，内层是 -1+|x| 到 1-|x|，绝对值还在。

分成 x ≥ 0 和 x < 0 两段，本质还是分块，只是分得更碎。

**所以对称性不是"可选的技巧"，它是把分块减半的工具。**

先看对称，再定限，顺序别反。

## 5. 拆开看：交换积分次序

没有这一节，遇到 e^{-y²} 这种"积不出来"的函数，整道题就死在这里。

先看一个死局。

```text
I = ∫₀¹ dx ∫_x^1 e^{-y²} dy
```

内层是对 y 积分 e^{-y²}。

这个原函数不是初等函数，积不出来。

但整道题是有答案的。

办法是：换一个次序。

**交换次序的三步。**

```text
第一步：由原积分限写出区域的不等式
第二步：画出这个区域
第三步：换一个方向重新写限
```

**按三步走一遍。**

第一步，原积分说：

```text
0 ≤ x ≤ 1，x ≤ y ≤ 1
```

第二步，画图。

这是一条直线 y = x 上方的三角形，顶点是 (0,0)、(0,1)、(1,1)。

第三步，换成先积 x、后积 y。

看这个三角形：

```text
y 从 0 到 1，对每个 y，x 从 0 到 y
```

所以：

```text
I = ∫₀¹ dy ∫₀^y e^{-y²} dx
```

**现在能算了。**

内层对 x 积分，e^{-y²} 是常数：

```text
∫₀^y e^{-y²} dx = y e^{-y²}
```

外层：

```text
I = ∫₀¹ y e^{-y²} dy
```

令 u = y²，du = 2y dy：

```text
I = (1/2)∫₀¹ e^{-u} du = (1/2)(1 - e^{-1})
```

算出来了。

**这就是交换次序的价值：把一个积不出的内层，换成一个能积的外层。**

**再练一个稍微复杂的。**

```text
I = ∫₀¹ dy ∫_{√y}^1 f(x, y) dx
```

第一步，写不等式：

```text
0 ≤ y ≤ 1，√y ≤ x ≤ 1
```

第二步，画图。

x 从 √y 到 1，也就是 y ≤ x²，且 y ≥ 0，x ≤ 1。

第三步，换成先积 y：

```text
0 ≤ x ≤ 1，0 ≤ y ≤ x²
```

所以：

```text
I = ∫₀¹ dx ∫₀^{x²} f(x, y) dy
```

**交换次序最容易错的地方：边界曲线认错。**

√y ≤ x 等价于 y ≤ x²，但前提是 x ≥ 0。

如果 x 可能为负，平方会引入多余的解。

所以换限时，先确认变量的正负范围。

所以换限时，先确认变量的正负范围。

## 6. 拆开看：极坐标与 dσ = r dr dθ

没有这一节，遇到圆域就只能写出一堆根号，算到崩溃。

圆、圆环、扇形、被圆切出来的区域，用直角坐标写限会很难看。

换成极坐标，边界往往变成常数。

**变换公式。**

```text
x = r cosθ
y = r sinθ
```

**r**：读"r"，极径，点到原点的距离，r ≥ 0。

**θ**：读"theta"，极角，从 x 轴正方向逆时针量的角。

**面积元素要换，这是最关键的一步。**

```text
dσ = r dr dθ
```

**为什么多一个 r？**

直角坐标的小块是一个矩形，面积是 dx·dy。

极坐标的小块是一个"小扇环"。

```text
        ╱
       ╱
      ╱  ← r dθ 是弧长
     ╱
    ●─────
      dr
```

它的面积约等于"弧长 × 径向宽度"：

```text
(r dθ) · dr = r dr dθ
```

严格推一遍：

```text
大扇形面积 = (1/2)(r + dr)² dθ
小扇形面积 = (1/2) r² dθ
差 = (1/2)(2r dr + dr²) dθ ≈ r dr dθ
```

dr² 是高阶小量，丢掉。

**所以那个 r 不是凑出来的，是扇形面积公式里带出来的。**

漏掉 r，答案会差一个量级。

**极坐标下的累次积分。**

```text
∬_D f(x, y) dσ = ∫_α^β dθ ∫_{r₁(θ)}^{r₂(θ)} f(r cosθ, r sinθ) · r dr
```

三条规则和直角坐标一样：

```text
外层 θ 的限是常数
内层 r 的限可以是 θ 的函数
先积 r，后积 θ
```

**常见边界的极坐标写法，必须熟。**

```text
x² + y² = R²      →  r = R
x² + y² = 2ax     →  r = 2a cosθ
x² + y² = 2ay     →  r = 2a sinθ
y = x             →  θ = π/4
y = 0             →  θ = 0
x = 0             →  θ = π/2
```

**θ 的范围怎么定？**

看区域从哪条射线开始，到哪条射线结束。

整圆：0 到 2π。

上半圆：0 到 π。

右半平面：-π/2 到 π/2。

被 x² + y² = 2x 围出的圆（圆心在 (1,0)，半径 1）：-π/2 到 π/2。

因为这个圆整个在右半平面，θ 跨过 0。

**一个判断技巧：从原点出发射一条线，看它什么时候能穿过区域。**

能穿过的那些 θ，就是积分范围。

穿不进的 θ，对应的 r 范围是空的。

**每加一条边界，就切掉一段 θ。**

以 x² + y² = 2x 为例。

这个圆过原点，在原点处的切线是竖直的，对应 θ = ±π/2。

所以圆本身覆盖的 θ 是 -π/2 到 π/2。

再加 y ≥ 0，只留 0 到 π/2。

再加 y = x，只剩 π/4 到 π/2。

一条边界一条边界地切，剩下的就是区域的 θ 范围。

切线方向怎么定？看边界在原点附近往哪边走。

竖直走，对应 θ = π/2；水平走，对应 θ = 0。

**这个办法比解不等式快，也比背公式可靠。**

## 7. 算一遍：极坐标例题

没有这两道题，r 这个因子就记不牢。

**第一道。**

```text
计算 ∬_D √(x² + y²) dσ，D：x² + y² ≤ 2x
```

**第一步，把边界换成极坐标。**

```text
x² + y² ≤ 2x  ⇒  r² ≤ 2r cosθ  ⇒  r ≤ 2cosθ
```

**第二步，定 θ 的范围。**

r ≥ 0 要求 cosθ ≥ 0，所以

```text
-π/2 ≤ θ ≤ π/2
```

**第三步，写累次积分。**

被积函数 √(x²+y²) = r，面积元素是 r dr dθ，所以被积式是 r·r = r²。

```text
I = ∫_{-π/2}^{π/2} dθ ∫₀^{2cosθ} r² dr
```

**第四步，算内层。**

```text
∫₀^{2cosθ} r² dr = (2cosθ)³/3 = 8cos³θ/3
```

**第五步，算外层。**

```text
I = (8/3) ∫_{-π/2}^{π/2} cos³θ dθ
```

cos³θ 的积分，用换元：

```text
cos³θ = (1 - sin²θ) cosθ
```

令 u = sinθ，du = cosθ dθ，θ 从 -π/2 到 π/2 对应 u 从 -1 到 1：

```text
∫_{-1}^{1} (1 - u²) du = [u - u³/3]_{-1}^{1} = (1 - 1/3) - (-1 + 1/3) = 4/3
```

所以：

```text
I = (8/3)(4/3) = 32/9
```

**验算量级。**

区域是一个直径 2 的圆，面积 π。

被积函数 r 在 0 到 2 之间，平均值大约 1 左右。

所以结果应该在 π 附近。

32/9 ≈ 3.56，π ≈ 3.14，量级吻合。

**第二道，指数型。**

```text
计算 ∬_D e^{-(x²+y²)} dσ，D：x² + y² ≤ 1，x ≥ 0，y ≥ 0
```

D 是第一象限的四分之一圆盘。

极坐标下：

```text
0 ≤ θ ≤ π/2，0 ≤ r ≤ 1
```

被积函数：

```text
e^{-(x²+y²)} = e^{-r²}
```

积分：

```text
I = ∫₀^{π/2} dθ ∫₀¹ e^{-r²} r dr
```

内层对 r，令 u = r²，du = 2r dr：

```text
∫₀¹ e^{-r²} r dr = (1/2)∫₀¹ e^{-u} du = (1/2)(1 - e^{-1})
```

外层只是一个常数乘 π/2：

```text
I = (π/2)·(1/2)(1 - e^{-1}) = (π/4)(1 - 1/e)
```

**这道题说明极坐标最大的好处：**

直角坐标下 e^{-(x²+y²)} 没法积，极坐标下变成 e^{-r²}·r，一个换元就出来了。

那个多出来的 r，在这里正好凑成了 du。

**所以看到 x² + y² 出现在指数上，立刻想极坐标。**

**第三道，圆环区域。**

```text
计算 ∬_D (x² + y²) dσ，D：1 ≤ x² + y² ≤ 4
```

极坐标下，边界直接变成 r 的两个常数：

```text
1 ≤ r ≤ 2，0 ≤ θ ≤ 2π
```

积分：

```text
I = ∫₀^{2π} dθ ∫₁² r² · r dr
```

内层：

```text
∫₁² r³ dr = (16 - 1)/4 = 15/4
```

外层：

```text
I = 2π · 15/4 = 15π/2
```

**这道题简单到不像话，原因有两个。**

第一，区域是圆环，极坐标下两个限都是常数，没有函数。

第二，被积函数只含 r，不含 θ，内外层彻底分离。

**极坐标的最大价值就在这里：把二维拆成两个一维。**

只要区域是"圆类"、被积函数是"r 的函数"，积分就变成两个独立的定积分相乘。

直角坐标下这个区域要写成

```text
-2 ≤ x ≤ 2，√(1-x²) ≤ |y| ≤ √(4-x²)
```

还要分正负、分上下半圆，至少四块。

对比一下，就知道为什么看到圆域要立刻换极坐标。

## 8. 拆开看：对称性与奇偶性

没有这一节，明明答案是 0 的积分，你会硬算十分钟。

二重积分里，对称性是最省力的工具。

**第一种，关于 x 轴对称。**

如果 D 关于 x 轴对称，也就是 (x, y) 在 D 里时 (x, -y) 也在 D 里。

```text
f(x, -y) = -f(x, y)  ⇒  ∬_D f dσ = 0
f(x, -y) =  f(x, y)  ⇒  ∬_D f dσ = 2 ∬_{D上半} f dσ
```

**第二种，关于 y 轴对称。**

```text
f(-x, y) = -f(x, y)  ⇒  ∬_D f dσ = 0
f(-x, y) =  f(x, y)  ⇒  ∬_D f dσ = 2 ∬_{D右半} f dσ
```

**第三种，轮换对称。**

如果 D 关于直线 y = x 对称，那么把 x 和 y 互换，区域不变。

于是：

```text
∬_D f(x, y) dσ = ∬_D f(y, x) dσ
```

这条性质最常用的形式是：

```text
∬_D x² dσ = ∬_D y² dσ = (1/2) ∬_D (x² + y²) dσ
```

**算一道，体会威力。**

```text
计算 ∬_D x² dσ，D：x² + y² ≤ R²
```

直接算要用 √(R² - x²) 做限，很麻烦。

用轮换对称：

```text
∬ x² = (1/2) ∬ (x² + y²)
```

右边用极坐标：

```text
(1/2) ∫₀^{2π} dθ ∫₀^R r²·r dr = (1/2)(2π)(R⁴/4) = πR⁴/4
```

**三步就完了。**

如果硬算，要先写 ∫_{-R}^{R} x²·2√(R²-x²) dx，再三角换元。

**用对称性之前，必须先确认区域真的对称。**

区域不对称，性质全部失效。

比如 D 是第一象限的四分之一圆，关于 x 轴、y 轴都不对称，只能用轮换对称。

**一个常见错误：只看被积函数，不看区域。**

f = xy 是奇函数，但只有在区域关于坐标轴对称时，积分才是 0。

区域偏在一边，xy 的积分就不是 0。

**对称性为什么成立？**

因为二重积分是"求和取极限"，而求和可以按任意方式配对。

区域关于 x 轴对称时，把上半的点 (x, y) 和下半的点 (x, -y) 配成一对。

两块面积一样，函数值正好相反，加起来就是 0。

每一对都抵消，总和自然是 0。

如果函数值相同而不是相反，每一对加起来是两倍，所以等于上半部分的两倍。

**这个"配对"的想法，是理解对称性的钥匙。**

它不依赖任何公式，只依赖"区域能配对"。

所以判断能不能用，只问一句：区域能不能按某条轴配对？

能，就用；不能，就别用。

**轮换对称也是配对。**

区域关于 y = x 对称时，(x, y) 和 (y, x) 配成一对。

把 f(x, y) 换成 f(y, x)，配对之后总和不变。

所以 ∬f(x,y) = ∬f(y,x)。

取 f = x²，就得到 ∬x² = ∬y²。

**一个常见的误用：把轮换对称当成"任何区域都能用"。**

只有区域关于 y = x 对称时才行。

比如 D 是 0 ≤ x ≤ 1、0 ≤ y ≤ 2 的矩形，关于 y = x 不对称。

这时 ∬x² 和 ∬y² 不相等。

算一下就知道：一个得 2/3，一个得 8/3。

这两个数怎么来的？

第一个是 ∫₀¹ dx ∫₀² x² dy = 2·(1/3) = 2/3。

第二个是 ∫₀¹ dx ∫₀² y² dy = 1·(8/3) = 8/3。

同样是被积函数平方，换个变量差了四倍，原因在于区域在两个方向的长度不同。

所以"轮换"两个字，前提是区域真的能轮换。

## 9. 常见错误

没有这一节，会算的题也会错。

**错误一：积分限上小下大。**

```text
错：∫₁⁰ dx …
```

除非是故意用"交换上下限变号"，一般都应该小的在下、大的在上。

写完检查一眼。

**错误二：外层积分限含变量。**

```text
错：∫₀^x dx ∫₀¹ f dy
```

外层是 x 的积分，限必须是常数。

含变量，说明定限时搞反了内外层。

**错误三：不画图就写限。**

区域是"由 y = x² 和 y = x 围成"，到底是中间那块还是外面那块？

不画图，永远说不清。

**错误四：极坐标忘了乘 r。**

```text
错：∫∫ e^{-r²} dr dθ
对：∫∫ e^{-r²} r dr dθ
```

漏 r 是最常见的失分点，因为它不影响形式，只影响数值。

**检查办法：量纲。**

直角坐标下 dσ 是长度平方。

r dr dθ 里，dr 是长度，r dθ 是弧长，乘起来也是长度平方。

dr dθ 缺了一个长度，量纲就不对。

**错误五：θ 的范围写错。**

整圆是 0 到 2π，不是 0 到 π。

上半圆是 0 到 π。

圆 x² + y² = 2x 是 -π/2 到 π/2。

范围错，结果可能差一半甚至差一个符号。

**错误六：区域不对称却用对称性。**

用之前，先看图，再用一句话说出对称轴。

说不出来，就不要用。

**错误七：交换次序时把边界曲线认错。**

最常见的是把 y = x² 和 x = √y 混着用，忘了正负号。

换限前先把不等式写清楚，再平方或开方。

**错误八：把 ∬ f·g 当成 ∬f · ∬g。**

这个等式只在"矩形区域 + 被积函数能分离变量"时成立。

其余情况一律不成立。

**错误九：忘了"积不出来"时要交换次序。**

拿到题先看内层能不能积。

如果内层是 e^{-x²}、sin(x²)、1/ln x 这类没有初等原函数的，先别急着算。

停下来想：交换次序之后，它会不会变成外层？

这类题的信号很明显：函数"积不出来"，题目却要求一个数。

**错误十：把定积分的换元直接套到二重积分。**

二重积分换元，除了换 x、y，还要乘一个雅可比行列式。

极坐标的 r 就是这个行列式的值。

换一般的 u = u(x,y)、v = v(x,y)，面积元素要乘 |∂(x,y)/∂(u,v)|。

数一不考一般换元，但极坐标的 r 必须理解成"雅可比的特殊情况"。

这样就不会觉得它是凭空冒出来的。

**错误十一：区域分块之后漏掉一块。**

D 被一条曲线切成两块，只算了一块。

检查办法：分块后的面积加起来，应该等于原区域面积。

面积对不上，肯定漏了。

## 10. 数一怎么考

没有这一节，复习会没有靶子。

数一在这一章有三种题型。

**第一种，直接计算。**

最常见的是"计算 ∬_D f dσ"，10 分。

```text
计算 ∬_D (x² + y²) dσ，D：x² + y² ≤ 1
```

极坐标：

```text
∫₀^{2π} dθ ∫₀¹ r²·r dr = 2π·(1/4) = π/2
```

**第二种，交换积分次序。**

题目给一个积不出来的累次积分，要求交换。

就是第 5 节那道 e^{-y²} 的变体。

也有可能问"交换后等于哪个选项"，选择题。

**第三种，利用对称性化简。**

题目故意给一个对称区域，被积函数有一半是奇函数。

看出对称性，一行出答案；看不出，算十分钟。

**还有一种，比较大小。**

```text
比较 ∬_D ln(x + y) dσ 与 ∬_D (x + y)² dσ，D：1 ≤ x ≤ 2，1 ≤ y ≤ 2
```

在 D 上，x + y 在 2 到 4 之间。

ln(x+y) 在 ln2 到 ln4 之间，大约 0.69 到 1.39。

(x+y)² 在 4 到 16 之间。

所以后者大。

比较大小的依据是比较性质：f ≤ g 则积分也 ≤。

**分值与时间。**

```text
选择或填空：1 道，4 分
计算大题：1 道，10 分
交换次序：常作为计算题的第一步
```

二重积分是数一积分题的必考项，几乎每年一道大题。

## 11. 和其他章节怎么连

没有这一节，二重积分会变成一个孤立的计算技巧。

**往回连：10 偏导数与 11 全微分。**

被积函数是二元函数，积分区域由二元不等式给出。

区域的边界常常要用偏导求切线、求最值点。

**往前连：13 三重积分。**

三重积分先用二重积分的思想降维，再积一次。

"先一后二"和"先二后一"两种算法，都建立在二重积分之上。

**往前连：14 曲线积分与 15 曲面积分。**

格林公式把第二类曲线积分化成二重积分：

```text
∮_L P dx + Q dy = ∬_D (Q_x - P_y) dxdy
```

曲面积分则要投影到坐标平面上，化成二重积分。

所以这一章算不快，后面两章都会拖慢。

**横向连：概率论。**

二维随机变量的联合密度 f(x, y) 满足

```text
∬ f(x, y) dxdy = 1
```

求概率就是在一个区域上做二重积分。

数一不考概率，但思想的来源是同一个。

**一个整体视角。**

```text
定积分：一维区域上累加
二重积分：二维区域上累加
三重积分：三维区域上累加
```

三者的定义完全平行：分割、取点、求和、取极限。

差别只在"小块"的形状和"面积元素"的写法。

**一条练习路线，按这个顺序走。**

第一步，只练矩形区域。

把被积函数换成 x、y、xy、x²+y²，各算一遍。

目的是把"先内后外"的顺序刻进手里。

第二步，练三角形和抛物线与直线围成的区域。

这一步练的是"画图定限"。

每个区域都先用 X 型算一遍，再用 Y 型算一遍，对比答案。

第三步，练圆域和圆环。

重点练"把边界换成极坐标方程"。

圆、圆环、偏心的圆，各算两道。

第四步，练交换次序。

专门找内层积不出来的题，比如 e^{-y²}、sin(y²)、1/(1+y³)。

第五步，练对称性。

拿到题先看区域，再看被积函数的奇偶性。

能一行出答案的，不要算第二行。

**这五步走完，二重积分的大题基本不会失分。**

每一步花的时间不一样，第三步和第四步最费时间，也最值钱。

因为考试最爱考的，正是极坐标和交换次序。

**一个预测考点的办法。**

看题目给的被积函数：

```text
出现 x² + y²  →  极坐标的概率很大
出现 e^{-y²} 之类  →  交换次序的概率很大
区域是圆  →  极坐标
区域是三角形  →  直角坐标
```

按这个表先猜方法，再验证，比盲目试快得多。

**最后一条：二重积分是"体力活"，也是"眼力活"。**

体力活指算内层积分，一步不能错。

眼力活指定限和选方法，选错了要多算三倍。

所以拿到题，先花三十秒看图、看函数，再动笔。

这三十秒，往往决定这道题是五分钟还是十五分钟。

**一个自查清单，交卷前用。**

```text
外层限是不是常数？
内层的上下限是不是写反了？
极坐标有没有乘 r？
区域的边界有没有全部用上？
结果是不是正数（被积函数为正时）？
```

五条全过，这道题基本稳了。

### 自检三问

**第一问：为什么累次积分的外层限必须是常数？**

因为二重积分的结果是一个数。

内层积掉一个变量后，剩下一个只含外层变量的函数。

外层再积，如果限是常数，结果就是数；如果限含变量，结果还是函数，那就不对了。

所以"外层常数、内层函数"是硬规则。

**第二问：极坐标下为什么 dσ = r dr dθ，而不是 dr dθ？**

因为极坐标的小块不是矩形，是小扇环。

扇环的面积等于"弧长乘径向宽度"，弧长是 r dθ，宽度是 dr。

乘起来就是 r dr dθ。

从扇形面积公式推，也会得到同一个结果。

漏掉 r，等于把每个小块的面积都算小了 r 倍。

**第三问：交换积分次序，怎么保证不出错？**

三步：写不等式、画图、重写限。

画图是关键，图能把"谁在谁上面"看得很清楚。

还有一个自检办法：交换前后，区域的形状必须一样，只是描述方式变了。

如果交换后画出来的区域和原来不同，一定错了。

## 12. 小结

没有小结，这一章的公式会记混。

压成一张卡片：

```text
定义：∬_D f dσ = lim Σ f(ξ, η) Δσ
直角坐标：dσ = dxdy
X 型：∫ₐ^b dx ∫_{φ₁(x)}^{φ₂(x)} f dy
Y 型：∫_c^d dy ∫_{ψ₁(y)}^{ψ₂(y)} f dx
极坐标：x = r cosθ，y = r sinθ，dσ = r dr dθ
对称性：奇函数在对称区域上积分为 0
轮换：∬x² = ∬y² = (1/2)∬(x²+y²)
```

四步公式的统一形态：

```text
算什么 → 曲面下的体积（或区域上的累加）
逐符号 → ∬ 是两次积分，dσ 是面积元素
代数字 → 画图定限，先内后外
适用条件 → 区域可写、函数可积；极坐标要求区域是圆类
```

**三张必须能画的图。**

图一，X 型区域怎么定限：

```text
      y
      │  ╱ 上边界 y = φ₂(x)
      │╱
      │╲ 下边界 y = φ₁(x)
      └────── x
      a      b
```

竖线从上边界穿到下边界，外层从 a 扫到 b。

图二，极坐标的小扇环：

```text
       ╱
      ╱  r dθ
     ╱
    ●── dr
```

面积约等于 r dr dθ。

图三，交换次序前后是同一个区域：

```text
      y
      │╲
      │ ╲
      │  ╲
      └──── x
```

形状不变，只是"先积谁"变了。

三句提醒。

```text
第一句：不画图，不写限。
第二句：极坐标别忘 r，量纲能救你。
第三句：对称性先看区域，再看函数。
```
