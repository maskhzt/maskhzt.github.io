> **读这篇之前，你只需要知道**：极限是 x 靠近 a 时 f(x) 靠近谁，它绕开那一点看附近；连续是极限值正好等于函数值，图像接得上；斜率是一条线"y 涨得比 x 快多少"，直线 y = 2x 的斜率是 2。
> **这篇讲什么**：把"曲线在某一点的陡峭程度"定义出来，再把它变成一套照着走就能算对的规则；顺带说明为什么"局部放大后的曲线像一条直线"这件事，能拿来估算平方根。
> **一个类比**：开车时仪表盘上的速度是"此刻"的速度，不是"全程平均 60 公里每小时"；它由很短一段路程除以很短一段时间得到，段越短越接近"此刻"，而这段趋近的动作就是导数。


拿一条曲线来问一个问题。

```text
y = x² 在点 (1, 1) 处的切线，斜率是多少？
```

切线是"贴着曲线"的那条直线。

可"贴着"是什么意思？

初中办法是取两个点连一条线：

```text
取 x = 1 和 x = 1 + h，两点连线，叫割线。
```

斜率：

```text
k = [(1 + h)² − 1] / [(1 + h) − 1]
  = (1 + 2h + h² − 1) / h
  = 2 + h
```

h = 1 时 k = 3。

h = 0.1 时 k = 2.1。

h = 0.01 时 k = 2.01。

h = 0.001 时 k = 2.001。

```text
   h 越小，割线越贴近曲线，斜率越靠近 2。
```

那么 h = 0 呢？

h = 0 时两点重合，割线退化成一个点，斜率公式分母为 0，算不出来。

**切线就在这个位置上：它想等于 2，但它永远只能是"趋近 2"。**

所以切线的斜率不是"两点斜率"，而是"两点斜率当 h → 0 时的极限"。

```text
k = lim(h→0) (2 + h) = 2
```

这就是导数。

另外还有一个视角，更直观，也更能说明导数为什么有用。

把 (1, 1) 附近那一小段曲线，放在放大镜下面看：

```text
放大 10 倍： 还是有点弯
放大 100 倍：看起来挺直
放大 1000 倍：基本就是一条直线
```

**任何光滑曲线，局部放大到足够倍数，都像一条直线。**

这条"假装是直线"的斜率，就是导数。

而"用直线代替曲线"这个动作，就是微分。

导数和微分是同一件事的两个说法：

```text
导数回答：这条替代直线的斜率是多少。
微分回答：用这条直线代替曲线，误差有多大。
```

## 1. 为什么需要导数（不给会怎样）

**第一，速度只有平均值。**

一辆车 5 秒内从静止加到 100 km/h，平均加速度是 20 km/h 每秒。

但第 3 秒那一瞬间，加速度是多少？

平均加速度回答不了。

要回答，就得让时间间隔趋于 0，这正是导数。

**第二，最优化无从下手。**

一根 20 厘米的铁丝折成一个矩形，长宽各多少时面积最大？

面积 = x(10 − x)，是一个开口向下的抛物线。

不用导数也能配方求顶点，但如果形状换成"圆柱形罐头，表面积固定，体积最大"呢？

配方法彻底失效。

导数给出一套通用办法：极值点处导数必为 0（费马引理，04 篇）。

**第三，曲线的形状说不清。**

哪里在上升、哪里在下降、哪里弯向上、哪里弯向下、拐点在哪。

这些问题全部由一阶导数和二阶导数的符号回答（05 篇）。

**第四，近似估算没有工具。**

√1.02 等于多少？

没有微分，只能硬算或查表。

有微分，一行就够：

```text
√(1 + 0.02) ≈ 1 + (1/2)(0.02) = 1.01
```

真实值是 1.00995，误差 0.00005。

**第五，积分反过来要用它。**

牛顿-莱布尼茨公式说"积分是求导的逆运算"。

不认识导数，定积分就只能靠定义硬算，一道题写两页。

所以导数是整门课里"性价比最高"的一章：投入一天，后面每一章都在回本。

## 2. 最小模型：导数定义

定义只有一行，但它是所有求导公式的来源。

```text
f'(a) = lim(Δx→0) [f(a + Δx) − f(a)] / Δx
```

读法：f 撇 a 等于，当德尔塔 x 趋于 0 时，f 括号 a 加德尔塔 x 减去 f a，再除以德尔塔 x 的极限。

符号逐个念：

```text
f'       读"f 撇"，表示 f 的导函数。f'(a) 是它在 a 点的值。
Δx       读"德尔塔 x"，希腊字母 Δ 表示"增量"，即 x 的一小段改变量。
         它也常写成 h、t、Δh。
[f(a+Δx) − f(a)] / Δx   是"函数增量 ÷ 自变量增量"，即割线斜率，也叫差商。
lim(Δx→0)  让那段增量缩到 0。
```

同一件事有三种等价写法，考试里都会出现：

```text
f'(a) = lim(Δx→0) [f(a + Δx) − f(a)] / Δx
f'(a) = lim(x→a) [f(x) − f(a)] / (x − a)
f'(a) = lim(h→0) [f(a + h) − f(a)] / h
```

第二种形式在判断分段点、绝对值、含 |x − a| 的题里最好用，因为它把"增量"换成了"两点距离"。

### 2.1 三个记号，各有各的用处

```text
f'(x)     拉格朗日记号，读"f 撇 x"。最简洁，写复合函数时最省地方。
y'        同上，用于 y = f(x) 的场合。
dy/dx     莱布尼茨记号，读"dy 比 dx"或"y 对 x 的导数"。
d/dx      算子记号，读"d 比 dx"，表示"对 x 求导这个动作"。
```

**dy/dx 要特别说清楚。**

它是一个**整体记号**，不是 dy 除以 dx，分子分母不是两个独立的数。

但它在两种场合可以"当分数用"：

```text
第一，链式法则：dy/dx = (dy/du) · (du/dx)，看起来像约掉 du。
第二，微分公式：dy = f'(x) dx，这是真的等式，dy 和 dx 都是微分。
```

所以在导数阶段把它当记号，在微分阶段它才真的能拆。

这个区分不搞清楚，学到隐函数和参数方程时会一直含糊。

### 2.2 四步拆开

```text
① 它在算什么：
   算"这一点的瞬时变化率"，几何上是切线斜率。
   做法是把"两点之间的平均变化率"取极限。

② 符号逐个念：
   Δx 是横向的一小段，f(a+Δx) − f(a) 是纵向的对应变化，
   两者相除是"每单位 x 引起多少 y"，取极限就是"当下"的比值。

③ 代一组数：
   f(x) = x²，a = 1。
   差商 = [(1 + Δx)² − 1]/Δx = (2Δx + Δx²)/Δx = 2 + Δx。
   Δx = 0.1 → 2.1；Δx = 0.01 → 2.01；Δx = 0.001 → 2.001。
   极限 = 2，即 f'(1) = 2。

④ 什么时候能用/不能用：
   用来求导、证明可导性、处理分段点。
   不能直接代入 Δx = 0（分母为 0），必须先约分或化简。
   极限不存在时，导数不存在，不能说"导数是无穷大"（那只是记号上的写法）。
```

### 2.3 导函数

把 a 换成任意的 x，得到的是**导函数**：

```text
f'(x) = lim(Δx→0) [f(x + Δx) − f(x)] / Δx
```

f'(a) 是一个数，f'(x) 是一个函数。

求 f'(a) 有两条路：

```text
路一：先求 f'(x)，再把 x = a 代进去。（快，但要求导函数在 a 附近都对）
路二：直接用定义算 f'(a)。（慢，但在分段点、绝对值点、抽象函数题里必须用）
```

数一的规矩：**分段函数的分界点，一律用定义。**

因为分界点两侧的表达式不同，先求导函数再代入，等于偷偷假设了两侧公式都适用。

### 2.4 单侧导数

分段点只有一侧的式子，所以要把导数也拆成左右：

```text
左导数 f'₋(a) = lim(h→0⁻) [f(a + h) − f(a)]/h
右导数 f'₊(a) = lim(h→0⁺) [f(a + h) − f(a)]/h
```

三条关系：

```text
f 在 a 处可导  ⇔  左导数与右导数都存在且相等。
可导必连续，但"左导数存在"只推出"左连续"。
```

所以判分段点的标准流程是：

```text
第一步：分别算 f'₋(a) 和 f'₊(a)（用定义，不用公式）。
第二步：两者相等 → 可导，导数值就是那个公共值。
       两者不等 → 不可导。
       有一个不存在 → 不可导。
```

用 |x| 在 0 处验一遍：

```text
f'₋(0) = lim(h→0⁻) [|h| − 0]/h = lim (−h)/h = −1
f'₊(0) = lim(h→0⁺) [|h| − 0]/h = lim h/h = 1
−1 ≠ 1，不可导。
```

这和 02 篇判间断点用的是同一套思路：**遇到分界，一律分左右。**

## 3. 几何意义：切线、法线、可导的三种失败

### 3.1 切线方程

```text
曲线 y = f(x) 在点 (a, f(a)) 处的切线：
y − f(a) = f'(a) (x − a)
```

四步：

```text
① 它在算什么：
   用一条直线去贴合曲线，直线上每一点的"倾斜程度"都等于曲线在 a 处的导数。

② 符号逐个念：
   (a, f(a)) 是切点，f'(a) 是斜率，x、y 是直线上的流动坐标。

③ 代一组数：
   y = x² 在 (1, 1) 处，f'(1) = 2。
   切线：y − 1 = 2(x − 1)，即 y = 2x − 1。
   验算：把 x = 1 代入得 y = 1，过切点；x = 1.1 时直线给 1.2，
   曲线给 1.21，差 0.01，说明在近处贴得不错。

④ 什么时候能用/不能用：
   只要 f'(a) 存在就能写。
   f'(a) 不存在时切线可能仍然存在（竖直切线），但方程不能写成这个形式。
```

法线是过切点且与切线垂直的直线，斜率取负倒数：

```text
y − f(a) = −1/f'(a) · (x − a)      （要求 f'(a) ≠ 0）
```

例：y = x² 在 (1, 1) 处，切线斜率 2，法线斜率 −1/2。

法线方程：y − 1 = −(1/2)(x − 1)，即 y = −x/2 + 3/2。

两斜率相乘 (2)(−1/2) = −1，确实垂直。

### 3.2 可导的三种失败方式

导数不存在，图像上只有三种样子。

```text
第一种：尖角。
例：y = |x| 在 x = 0。
左导数 −1，右导数 1，两侧斜率对不上，切线定不下来。

第二种：竖直切线。
例：y = ∛x 在 x = 0。
差商 = [∛h − 0]/h = h^(−2/3) → +∞。
切线是 y 轴（竖直），斜率不存在，但切线确实存在。

第三种：振荡。
例：y = x sin(1/x)（补 f(0) = 0），在 x = 0。
差商 = sin(1/h)，来回跳，连"无穷"都不是。
```

```text
      尖角            竖直切线          振荡
       ╱               │                ～～～
   ───●───             │              ～     ～
     ╱                 │                ～～～
```

这三种在选择题里各有一个标准例子，记住就能秒判。

### 3.3 可导与连续

02 篇已经证过，这里只留结论和一个使用要点：

```text
可导 ⇒ 连续
连续 ⇏ 可导
```

**使用要点：判断分段点可导性，先验连续。**

```text
第一步：算左极限、右极限、函数值，三者相等才连续。
第二步：连续不过关，直接判不可导，收工。
第三步：连续过关，再用定义算左右导数，看是否相等。
```

这个顺序能省掉大量无用的导数计算。

很多考卷上写"讨论 f 在 x = 1 处的可导性"，正确答案就是"不连续，故不可导"，两行结束。

## 4. 求导法则：把极限变成算术

定义了导数之后，如果每道题都用定义算，考试做不完。

所以需要一套"合法偷懒"的规则。

这一节的所有公式，都是把定义里的极限算出来之后得到的结果，可以直接用。

### 4.1 基本导数表

```text
(C)' = 0                    C 是常数
(x^α)' = α x^(α−1)          α 是任意实数
(sin x)' = cos x
(cos x)' = −sin x
(tan x)' = sec²x = 1/cos²x
(cot x)' = −csc²x
(sec x)' = sec x tan x
(csc x)' = −csc x cot x
(e^x)' = e^x
(a^x)' = a^x ln a
(ln x)' = 1/x
(log_a x)' = 1/(x ln a)
(arcsin x)' = 1/√(1 − x²)
(arccos x)' = −1/√(1 − x²)
(arctan x)' = 1/(1 + x²)
(arccot x)' = −1/(1 + x²)
```

这张表必须背到条件反射，因为它是所有求导的地基。

背的时候抓两条线索：

```text
线索一：三角与反三角成对出现，反三角的导数分母带根号或 1 + x²。
线索二：e^x 的导数还是 e^x，这是它最特殊的性质；
       ln x 的导数是 1/x，两者互为反函数（下面 4.4 会解释这个对应）。
```

### 4.2 四则运算法则

```text
(u ± v)' = u' ± v'
(u · v)' = u' v + u v'
(u / v)' = (u' v − u v') / v²        （v ≠ 0）
(C · u)' = C · u'
```

**没有它会怎样？**

乘积求导只能回到定义，展开 (u+Δu)(v+Δv) 再算极限，每题五分钟。

四步（以乘积法则为例）：

```text
① 它在算什么：
   两个函数相乘，变化率不等于两个变化率相乘，
   而是"u 变带来的部分"加"v 变带来的部分"。

② 符号逐个念：
   u' v 是"u 的变化乘上 v 的当前值"，
   u v' 是"u 的当前值乘上 v 的变化"。

③ 代一组数：
   y = x² sin x。
   y' = 2x · sin x + x² · cos x。
   取 x = π/2：(2 · π/2 · 1) + (π²/4 · 0) = π。

④ 什么时候能用/不能用：
   u、v 都必须在该点可导。
   三项以上相乘要反复用，或者用对数求导（4.5）。
   (uv)' = u'v' 是错的，这是最高频的公式错误。
```

### 4.3 链式法则

```text
若 y = f(u)，u = g(x)，则 dy/dx = f'(u) · g'(x)
```

读法：dy 比 dx 等于 f 撇 u 乘上 g 撇 x。

大白话：**外层导数 × 内层导数，一层层剥。**

四步：

```text
① 它在算什么：
   复合函数的变化率，等于"外层相对于内层的敏感度"乘"内层相对于 x 的敏感度"。

② 符号逐个念：
   f'(u) 是把 u 当整体求导，g'(x) 是内层自己的导数。

③ 代一组数：
   y = sin(x²)。外层 sin，内层 x²。
   外层导数 cos(u)，内层导数 2x。
   y' = cos(x²) · 2x = 2x cos(x²)。
   取 x = 1：y' = 2 cos 1 ≈ 1.0806。

④ 什么时候能用/不能用：
   任何复合结构都能用，层数多就多乘几次。
   最容易漏的是最内层的导数（比如 sin 2x 漏掉 2）。
```

三个必须练熟的形态：

```text
y = sin(2x)          y' = 2 cos(2x)              漏 2 是最常见错误
y = e^(x²)           y' = 2x e^(x²)
y = ln(cos x)        y' = (1/cos x) · (−sin x) = −tan x
y = √(1 + x²)        y' = x/√(1 + x²)
y = arctan(3x)       y' = 3/(1 + 9x²)
```

再来一个三层的，看清"剥洋葱"的顺序：

```text
y = ln(cos(e^x))
最外层 ln：导数是 1/cos(e^x)
中间层 cos：导数是 −sin(e^x)
最内层 e^x：导数是 e^x
三层相乘：y' = [1/cos(e^x)] · [−sin(e^x)] · e^x = −e^x tan(e^x)
```

顺序无关紧要（乘法可交换），关键是**每一层都不能漏**。

练习时可自问：这个式子是由几个函数套起来的？套了几层就乘几个因子。

### 4.4 反函数求导

```text
若 y = f(x) 的反函数是 x = f⁻¹(y)，则
[f⁻¹(y)]' = 1 / f'(x)
```

大白话：反函数的斜率，是原函数斜率的倒数。

几何上很直观：把图像沿 y = x 翻折，横纵互换，斜率自然取倒数。

例：y = e^x 的导数是 e^x，所以 y = ln x 的导数是 1/e^y = 1/x。

例：y = sin x 在 (−π/2, π/2) 上，导数是 cos x，所以 arcsin 的导数是：

```text
1/cos y = 1/√(1 − sin²y) = 1/√(1 − x²)
```

**这一步的思路从哪来？**

要算 arcsin 的导数，但 arcsin 不好直接求。

那就绕一圈：先算它的反函数 sin 的导数，再取倒数。

"反函数不好求，就求原函数再取倒数"，这是这一招的全部内容。

### 4.5 对数求导法

遇到"幂指函数"（底和指数都含 x）或"一堆因子连乘"，先取对数再求导。

```text
y = u(x)^(v(x))        →        ln y = v ln u        →        两边求导
```

例：y = x^x（x > 0）。

```text
两边取对数：ln y = x ln x。
两边对 x 求导（左边用链式法则，y 是 x 的函数）：
  (1/y) · y' = ln x + x · (1/x) = ln x + 1。
所以 y' = y (ln x + 1) = x^x (ln x + 1)。
```

**为什么左边会多出一个 y'？**

因为 y 是 x 的函数，对 ln y 求导要用链式法则：外层 ln 的导数是 1/y，内层 y 的导数是 y'。

这一步是隐函数求导的核心动作，下一节专门讲。

## 5. 高阶导数

一阶导数是"变化率"，二阶导数是"变化率的变化率"。

记号：

```text
f''(x)     读"f 两撇"，二阶导数。
f'''(x)    三阶。
f⁽ⁿ⁾(x)    读"f 的 n 阶导"，n ≥ 4 时用括号上标。
d²y/dx²    莱布尼茨记号的二阶形式，读"d 平方 y 比 d x 平方"。
```

例：y = x³。

```text
y' = 3x²
y'' = 6x
y''' = 6
y⁽⁴⁾ = 0
```

物理上的对应值得记一下：

```text
s(t)  位移
s'(t) 速度       一阶导
s''(t) 加速度     二阶导
```

例：s = t³ − 3t²。

```text
v = s' = 3t² − 6t
a = s'' = 6t − 6
t = 1 时 v = −3（往回走），a = 0（加速度瞬间为 0）
t = 2 时 v = 0（瞬时停下），a = 6（正在被往前推）
```

注意 t = 2 时速度是 0 但加速度不是 0，这正是"瞬时静止"和"一直静止"的区别。

**没有高阶导数会怎样？**

05 篇判断凹凸性和拐点，靠的就是 f'' 的符号。

04 篇的泰勒公式，靠的是各阶导数。

物理上，位移的一阶导是速度，二阶导是加速度，三阶导是急动度。

几个必须记住的高阶导数公式：

```text
(x^n)⁽ⁿ⁾ = n!                     n 次导之后变成常数 n!
(e^x)⁽ⁿ⁾ = e^x                    每一阶都是自己
(sin x)⁽ⁿ⁾ = sin(x + nπ/2)        每求一次导，相位前进 π/2
(cos x)⁽ⁿ⁾ = cos(x + nπ/2)
(1/x)⁽ⁿ⁾ = (−1)ⁿ n! / x^(n+1)
(ln x)⁽ⁿ⁾ = (−1)^(n−1) (n−1)! / xⁿ
```

sin 的那条为什么是加 nπ/2？

因为求导一次，sin 变 cos，而 cos x = sin(x + π/2)。

每求一次导，相当于在相位上加 π/2，求 n 次就加 nπ/2。

**这个"把 cos 改写成 sin(x + π/2)"的动作，是这类题的通用技巧。**

看到三角的高阶导数，第一反应就是把所有东西统一成 sin 或 cos，然后只看相位。

### 5.1 乘积的高阶导数：莱布尼茨公式

两个函数相乘，求 n 阶导时不能只算各自的 n 阶导，要按二项式那样展开：

```text
(uv)⁽ⁿ⁾ = Σ(k=0 到 n) C(n,k) u⁽ᵏ⁾ v⁽ⁿ⁻ᵏ⁾
```

符号读音与含义：

```text
Σ     读"西格玛"，求和号。
C(n,k) 读"C n k"，组合数，等于 n!/[k!(n−k)!]。
u⁽ᵏ⁾   u 的 k 阶导数，k = 0 时就是 u 本身。
```

它长得和二项式定理 (a + b)^n 一模一样，只是把"乘方"换成了"求导"。

例：y = x² e^x，求 y⁽¹⁰⁾。

```text
取 u = x²，v = e^x。
u 的导数很快就没了：u' = 2x，u'' = 2，u''' 及以后全是 0。
v 的任意阶导数都是 e^x。
所以求和只剩三项：
y⁽¹⁰⁾ = C(10,0) x² e^x + C(10,1) · 2x · e^x + C(10,2) · 2 · e^x
      = e^x [x² + 20x + 90]
```

**这道题为什么能这么短？**

因为 x² 求三次导就变成 0，后面的项全部自动消失。

所以莱布尼茨公式用在"一个因子是多项式"的场合最划算。

## 6. 隐函数与参数方程求导

前面所有例子都是 y = 某某，y 明明白白解出来了。

但很多曲线不是这个形状。

### 6.1 隐函数求导

```text
x² + y² = 1
```

这是一个圆，y 没有被解出来（解出来要分 ± 两支，很麻烦）。

这种"y 藏在方程里"的函数，叫隐函数。

求导的办法只有一句话：

```text
两边同时对 x 求导，把 y 看成 x 的函数，遇到 y 就用链式法则补一个 y'。
```

完整示例：

```text
x² + y² = 1
两边对 x 求导：
  (x²)' = 2x
  (y²)' = 2y · y'        ← 这里用的就是链式法则，外层 2y，内层 y'
所以 2x + 2y y' = 0
解出 y' = −x/y。
```

**那个 y' 是怎么冒出来的？**

因为 y 不是常数，它随 x 变。

对 y² 求导，等于"外层 2y 乘内层 y'"。

漏掉这个 y'，是隐函数求导第一大错。

代一组数验证：圆上取点 (3/5, 4/5)。

```text
y' = −(3/5)/(4/5) = −3/4。
```

几何上，这一点在圆的第一象限，切线朝右下，斜率确实是负的，而且比 −1 平缓一点，−3/4 合理。

再看一个三次的：

```text
x³ + y³ − 3xy = 0
两边求导：3x² + 3y² y' − 3y − 3x y' = 0
整理：y'(3y² − 3x) = 3y − 3x²
所以 y' = (y − x²)/(y² − x)
```

**注意结果里允许留着 y。**

不要求把所有 y 都换成 x，因为隐函数本来就没解出来。

求某一点的导数值时，把该点的 x、y 一起代进去即可。

隐函数的二阶导数，就是把一阶结果再对 x 求一次导，遇到 y 继续补 y'。

```text
接 x² + y² = 1，已知 y' = −x/y。
再对 x 求导：
  1 · y + x · y' 的那个形式要小心，直接算：
  y'' = −[1 · y − x · y'] / y²
      = −[y − x(−x/y)] / y²
      = −[y + x²/y] / y²
      = −(y² + x²)/y³
      = −1/y³            ← 因为 x² + y² = 1
```

最后一步用上了原方程，这是隐函数二阶导的常用收尾技巧：**能化简就回到原方程。**

### 6.2 参数方程求导

有些曲线用 t 当中介最方便：

```text
x = φ(t)
y = ψ(t)
```

比如圆 x = cos t，y = sin t；摆线 x = a(t − sin t)，y = a(1 − cos t)。

求 dy/dx：

```text
dy/dx = ψ'(t) / φ'(t)
```

大白话：y 对 x 的变化率，等于"y 对 t 的变化率"除以"x 对 t 的变化率"。

四步：

```text
① 它在算什么：
   曲线是 t 画出来的，我们想知道"横向走一点，纵向涨多少"，
   于是把两者都换算成"对 t 的速率"，再相除。

② 符号逐个念：
   ψ'(t) 是纵向速度，φ'(t) 是横向速度，比值就是轨迹的斜率。

③ 代一组数：
   x = t²，y = t³。
   dy/dx = (3t²)/(2t) = 3t/2（t ≠ 0）。
   取 t = 1：dy/dx = 3/2。

④ 什么时候能用/不能用：
   要求 φ'(t) ≠ 0（横向不能停，停了切线变竖直）。
   二阶导不能直接对 t 再求一次，必须除以 φ'(t)，见下。
```

**二阶导数的正确算法**

这是数一最容易错的一个点。

```text
d²y/dx² = [d/dt (dy/dx)] / φ'(t)
```

为什么？

因为 dy/dx 仍然是 t 的函数，要把它对 x 求导，就得再用一次"参数方程求导"：分子是对 t 的导数，分母补一个 dx/dt。

完整示例：

```text
x = t²，y = t³。
一阶：dy/dx = 3t/2。
二阶：先对 t 求导得 3/2，再除以 dx/dt = 2t，
      d²y/dx² = (3/2)/(2t) = 3/(4t)。
```

如果偷懒直接写 3/2，就错了。这个错误在考卷上出现频率极高。

再看摆线：

```text
x = a(t − sin t)，y = a(1 − cos t)。
dx/dt = a(1 − cos t)
dy/dt = a sin t
dy/dx = sin t / (1 − cos t)
```

取 t = π/2：

```text
sin(π/2) = 1，cos(π/2) = 0，
dy/dx = 1/(1 − 0) = 1。
```

摆线在最高点处切线斜率为 0（t = π 时 sin π = 0），在起点处斜率为无穷（t = 0 时分母为 0）。

这些结论用参数方程一算就出来，比消去 t 快得多。

## 7. 微分：用直线代替曲线

### 7.1 从增量到微分

给 x 一个增量 Δx，函数值也跟着变，增量是：

```text
Δy = f(x + Δx) − f(x)
```

这个 Δy 一般不等于 f'(x)Δx，两者差一点点。

微分就是把"最主要的那个线性部分"单独拎出来：

```text
dy = f'(x) dx        其中 dx = Δx
```

读法：dy 等于 f 撇 x 乘以 dx。

逐符号：

```text
dy    函数的微分，读"d y"，是"用切线算出来的纵向增量"。
dx    自变量的微分，等于 Δx，可以任意取。
f'(x) 切线的斜率。
```

四步：

```text
① 它在算什么：
   把曲线换成它的切线，算"如果沿着切线走 Δx，纵向会涨多少"。
   这个值是 Δy 的线性主部，误差是比 Δx 更高阶的无穷小。

② 符号逐个念：
   dy = 切线上的纵向增量；Δy = 曲线上的真实纵向增量；
   两者之差 Δy − dy 是 o(Δx)，即"比 Δx 更快归零"。

③ 代一组数：
   y = x²，x = 1，Δx = 0.01。
   真实增量 Δy = 1.01² − 1 = 0.0201。
   微分 dy = 2 · 0.01 = 0.02。
   误差 0.0001，是 Δx² 的量级，确实比 Δx 小一个数量级。

④ 什么时候能用/不能用：
   只要 f 在该点可导，微分就存在。
   用 dy 近似 Δy 时，|Δx| 必须很小；Δx 大了误差会失控（见 7.3）。
```

**一元函数里，"可微"和"可导"是同一件事。**

这一点和多元函数不同（10 篇会看到：偏导存在推不出可微）。

所以数一里看到"可微"两个字，直接当"可导"处理。

### 7.2 微分形式不变性

```text
无论 u 是自变量还是中间变量，都有 dy = f'(u) du。
```

这条性质听起来抽象，其实就一句话：

```text
链式法则在微分记号下，就是"约分"。
```

验证：

```text
y = f(u)，u = g(x)。
dy = f'(u) du          （把 u 当自变量）
   = f'(u) · g'(x) dx  （把 du 展开）
   = [f(g(x))]' dx     （复合函数的导数）
```

两种算法的结果一致，所以 du 可以自由替换。

微分的四则运算法则也照抄导数那套，只是把撇换成 d：

```text
d(u ± v) = du ± dv
d(uv) = v du + u dv
d(u/v) = (v du − u dv)/v²
```

例：d(x² sin x) = sin x · d(x²) + x² · d(sin x) = 2x sin x dx + x² cos x dx。

把 dx 提出来，括号里就是导数，所以"求微分"和"求导数"实际上只差一步乘法。

**这就是为什么莱布尼茨记号好用：它把链式法则写成了一步约分。**

### 7.3 近似计算

把 dy 顶替 Δy，就得到近似公式：

```text
f(x₀ + Δx) ≈ f(x₀) + f'(x₀) Δx
```

四步：

```text
① 它在算什么：
   在已知点上加一个"切线修正量"，估算邻近点的函数值。

② 符号逐个念：
   x₀ 是熟悉的起点（比如 1、0、4），Δx 是那一点点偏移；
   f'(x₀) 是修正的倍率。

③ 代一组数：
   估 √1.02。取 f(x) = √x，x₀ = 1，Δx = 0.02。
   f(1) = 1，f'(x) = 1/(2√x)，f'(1) = 1/2。
   √1.02 ≈ 1 + (1/2)(0.02) = 1.01。
   真值 1.0099505，误差 0.00005。

④ 什么时候能用/不能用：
   只在小 Δx 时可靠。Δx = 1 时估 √2 ≈ 1.5，真值 1.414，误差 6%。
   起点 x₀ 必须好算（1、4、9、0、π/2 之类）。
```

常用的三个估算，考试直接套：

```text
√(1 + x) ≈ 1 + x/2
ln(1 + x) ≈ x
e^x ≈ 1 + x
sin x ≈ x
(1 + x)^α ≈ 1 + αx
```

这五个其实就是 01 篇的等价无穷小表，换了个说法：

```text
等价无穷小说的是"f(x) ~ 它的一次项"，
微分近似说的是"f(x) ≈ 它的一次项"，两者是同一件事的极限版与近似版。
```

### 7.4 误差估计

微分还能反过来用：知道自变量的测量误差，估计结果的误差。

```text
题：测得球半径 r = 5 cm，测量误差不超过 0.01 cm。
    求体积 V = (4/3)πr³ 的绝对误差限。
```

```text
第一步：求微分。dV = V'(r) dr = 4πr² dr。
第二步：代入。r = 5，dr = 0.01。
        dV = 4π · 25 · 0.01 = π ≈ 3.14 cm³。
第三步：结论。体积误差约 3.14 cm³。
```

**这里的思路从哪来？**

误差就是"自变量动一点点，函数动多少"，本质是 Δy。

用 dV 顶替 ΔV，就把误差估计变成了求导加乘法。

相对误差则是 dV/V = 3 dr/r，说明体积的相对误差是半径相对误差的 3 倍。

这个"几次方就放大几倍"的规律，在物理和工程里常用来判断该优先提高哪个量的精度。

### 7.5 挑起点也是一门手艺

估算的关键是选一个"函数值好算、离目标近"的 x₀。

```text
题：估算 √4.1。
```

如果取 x₀ = 4（因为 √4 = 2 好算），Δx = 0.1：

```text
f'(x) = 1/(2√x)，f'(4) = 1/4。
√4.1 ≈ 2 + (1/4)(0.1) = 2.025。
真值 2.02484…，误差 0.00016。
```

如果硬取 x₀ = 1，Δx = 3.1，误差会大到没法看：

```text
√4.1 ≈ 1 + (1/2)(3.1) = 2.55，错了 26%。
```

**所以起点的选取标准是：离得近，且 f(x₀)、f'(x₀) 都心算得出来。**

常用的好起点：1、4、9、16（开方），0（三角与指数），1（对数），π/2（三角）。

## 8. 算一遍：用定义求导

用定义求导是数一的基本功，尤其是分段点、绝对值点、抽象函数题。

四道题，四种情形。

### 8.1 多项式

```text
题：用定义求 f(x) = x² 在 x = 2 处的导数。
```

```text
f'(2) = lim(h→0) [f(2 + h) − f(2)]/h
      = lim(h→0) [(2 + h)² − 4]/h
      = lim(h→0) (4 + 4h + h² − 4)/h
      = lim(h→0) (4h + h²)/h
      = lim(h→0) (4 + h)
      = 4
答案：f'(2) = 4。
```

### 8.2 根式

```text
题：用定义求 f(x) = √x 在 x = 1 处的导数。
```

```text
f'(1) = lim(h→0) [√(1 + h) − 1]/h
```

这是 0/0 型，用有理化（01 篇第 8 节的方法）：

```text
分子分母同乘 (√(1 + h) + 1)：
= lim(h→0) [(1 + h) − 1] / [h(√(1 + h) + 1)]
= lim(h→0) h / [h(√(1 + h) + 1)]
= lim(h→0) 1/(√(1 + h) + 1)
= 1/2
答案：f'(1) = 1/2。
```

### 8.3 分式

```text
题：用定义求 f(x) = 1/x 在 x = 2 处的导数。
```

```text
f'(2) = lim(h→0) [1/(2 + h) − 1/2]/h
通分：= lim(h→0) [(2 − (2 + h))/(2(2 + h))]/h
      = lim(h→0) [−h/(2(2 + h))]/h
      = lim(h→0) −1/[2(2 + h)]
      = −1/4
答案：f'(2) = −1/4。
```

### 8.4 振荡型：只能用定义

```text
题：设 f(x) = x² sin(1/x)（x ≠ 0），f(0) = 0。
    求 f'(0)。
```

**这道题不能用求导公式算。**

因为 x = 0 两侧的表达式和 0 点的值不是同一个式子，公式法在这里没有依据。

必须回到定义：

```text
f'(0) = lim(h→0) [f(0 + h) − f(0)]/h
      = lim(h→0) [h² sin(1/h) − 0]/h
      = lim(h→0) h sin(1/h)
```

现在用 01 篇的工具：sin(1/h) 有界（|sin| ≤ 1），h → 0 是无穷小。

```text
有界 × 无穷小 = 无穷小，所以极限 = 0。
答案：f'(0) = 0。
```

**这道题说明一件重要的事：**

f 在 0 处可导，导数为 0。

但 f'(x) 在 x ≠ 0 时是 2x sin(1/x) − cos(1/x)，当 x → 0 时它振荡，没有极限。

所以"f 处处可导"不等于"f' 连续"。

数一有一类题专门考这个反例。

### 8.5 抽象函数：凑定义

```text
题：设 f(0) = 0，f'(0) = 2，求 lim(x→0) f(3x)/x。
```

思路：把式子凑成导数的定义形状。

```text
f(3x)/x = 3 · [f(3x) − f(0)]/(3x)
```

令 t = 3x，x → 0 时 t → 0：

```text
原式 = 3 · lim(t→0) [f(t) − f(0)]/t = 3 f'(0) = 6。
答案：6。
```

**这个凑法的要点是"缺什么补什么"。**

定义里分母必须是自变量的增量，所以 f(3x) 配的分母必须是 3x，多出来的 3 提到外面。

## 9. 常见错误

**错误一：(uv)' = u'v'。**

```text
错：(x · sin x)' = 1 · cos x = cos x
对：(x sin x)' = sin x + x cos x
```

**错误二：链式法则漏内层导数。**

```text
错：(sin 2x)' = cos 2x
对：(sin 2x)' = 2 cos 2x
```

**错误三：商法则分子顺序写反。**

```text
正确：(u/v)' = (u'v − uv')/v²
写反成 (uv' − u'v)/v² 会整体差一个负号。
```

**错误四：隐函数求导漏 y'。**

```text
错：x² + y² = 1 求导得 2x + 2y = 0
对：2x + 2y y' = 0
```

**错误五：参数方程二阶导直接对 t 求导。**

```text
错：x = t²，y = t³，d²y/dx² = (3t/2)' = 3/2
对：d²y/dx² = (3/2)/(2t) = 3/(4t)
```

**错误六：把 dy/dx 当分数随便约。**

```text
dy/dx 是整体记号。
只有在链式法则和微分等式里，才表现得像分数。
随意写 dy = (dy/dx) · dx 在微分意义下是对的，
但写 d²y/dx² = d²y/dt² ÷ d²x/dt² 是错的。
```

**错误七：在不可导点硬套公式。**

```text
错：f(x) = |x|，f'(x) = 1（x > 0），−1（x < 0），所以 f'(0) = 0
对：0 处两侧导数不等，f'(0) 不存在
```

分段点、绝对值点、根号顶点，一律用定义验。

**错误八：把 Δy 和 dy 当成一个东西。**

Δy 是曲线上真实的增量，dy 是切线上算出来的增量。

两者只差一个 o(Δx)，但 Δx 一大，差别就会很显眼：y = x² 在 x = 1 处，Δx = 1 时 Δy = 3，dy = 2，差了三分之一。

所以"用微分近似"永远要附一句"当 Δx 很小时"。

## 10. 数一怎么考

```text
选择/填空：
  1. 求导数值、微分值、切线方程。
  2. 隐函数 / 参数方程求一阶、二阶导。
  3. n 阶导数（三角、有理式）。
  4. 判断某点可导性（绝对值、分段、抽象）。
解答题：
  5. 求导作为大题第一步，后面接单调性、极值、中值定理。
  6. 证明可导性、证明导函数满足某等式。
```

### 10.1 例题：幂指函数

```text
题：设 y = x^x（x > 0），求 y'。
```

```text
两边取对数：ln y = x ln x。
两边对 x 求导：(1/y) y' = ln x + 1。
所以 y' = x^x (ln x + 1)。
```

### 10.2 例题：带根号的对数

```text
题：设 y = ln(x + √(x² + 1))，求 y'。
```

```text
外层 ln，内层 x + √(x² + 1)。
y' = 1/(x + √(x² + 1)) · [1 + x/√(x² + 1)]
   = 1/(x + √(x² + 1)) · [√(x² + 1) + x]/√(x² + 1)
   = 1/√(x² + 1)
```

这个结果值得记：**ln(x + √(x²+1)) 的导数就是 1/√(x²+1)。**

它是双曲正弦的反函数，后面 06 篇凑微分时会反复出现。

### 10.3 例题：切线方程

```text
题：求曲线 y = x ln x 在 x = 1 处的切线方程。
```

```text
第一步：算切点。x = 1 时 y = 1 · ln 1 = 0，切点 (1, 0)。
第二步：算斜率。y' = ln x + 1（乘积法则），y'(1) = 0 + 1 = 1。
第三步：写方程。y − 0 = 1 · (x − 1)，即 y = x − 1。
```

### 10.4 例题：分段点的可导性

```text
题：设 f(x) = x²（x ≤ 0），f(x) = ax + b（x > 0）。
    若 f 在 x = 0 处可导，求 a、b。
```

```text
第一步（连续，可导的必要条件）：
  f(0) = 0，左极限 0，右极限 b，所以 b = 0。
第二步（可导）：
  左导数用定义：lim(h→0⁻)[h² − 0]/h = lim h = 0。
  右导数用定义：lim(h→0⁺)[ah + b − 0]/h = a（因为 b = 0）。
  可导要求左右相等，所以 a = 0。
答案：a = 0，b = 0。
```

**这道题的关键是"先连续、再可导"的顺序，以及分界点必须用定义。**

如果对两侧表达式分别求导再代入，会得到左导数 0、右导数 a，结论一样，但逻辑上有漏洞：那个做法默认了导函数在 0 点连续。

考试时写定义，最稳。

### 10.5 例题：凑导数的定义

```text
题：设 f 在 x₀ 处可导，求 lim(h→0) [f(x₀ + 2h) − f(x₀ − h)]/h。
```

思路：一个分子里出现两个不同的偏移，先拆成两个标准差商，再各配各的分母。

```text
拆：[f(x₀ + 2h) − f(x₀ − h)]/h
  = [f(x₀ + 2h) − f(x₀)]/h + [f(x₀) − f(x₀ − h)]/h
```

第一块配 2h，第二块配 −h：

```text
= 2 · [f(x₀ + 2h) − f(x₀)]/(2h) + 1 · [f(x₀ − h) − f(x₀)]/(−h)
```

两个方括号里的式子，当 h → 0 时都趋于 f'(x₀)：

```text
原式 → 2 f'(x₀) + 1 · f'(x₀) = 3 f'(x₀)。
```

答案：3f'(x₀)。

**这类题的通用套路是"一分为二，各配各的增量"。**

不要把整个式子硬凑成一个差商，那样配不出来。

## 11. 和其他章节怎么连

```text
← 01 极限：导数是 0/0 型极限，差商的极限。
← 02 连续：可导必连续，连续不一定可导。

→ 04 中值定理：罗尔、拉格朗日、柯西全部建立在"可导"上；
             洛必达法则是柯西中值定理的推论。

→ 05 导数应用：f' 的符号定单调，f'' 的符号定凹凸，
             极值点要 f' = 0 或不存在。

→ 06 不定积分：求导的逆运算，基本积分表就是导数表倒过来念。
→ 07 定积分：变上限积分求导，靠的正是本篇的链式法则。

→ 09 反常积分：收敛性判别里用洛必达，洛必达要用导数。

→ 19 微分方程：方程里出现的 y'、y''，就是本篇的记号。

→ 21 空间曲线：切向量 (x'(t), y'(t), z'(t)) 就是参数方程求导的推广。
```

一条实用的总结：

```text
极限是"地基层"，
连续是"第一层"，
导数是"第二层"，
中值定理是"第二层的枢纽"。
```

### 自检三问

**第一问：dy/dx 是一个分数吗？**

答：不是，它是一个整体记号，表示"y 对 x 的导数"。

但在两种场合它可以表现得像分数：链式法则 dy/dx = (dy/du)(du/dx)，以及微分等式 dy = f'(x)dx。

这两种"像分数"的性质来自定理，不是因为记号本身是除法。

**第二问：f 在 a 处连续，能推出 f 在 a 处可导吗？**

答：不能。

反例是 f(x) = |x| 在 0 处：连续但左右导数分别是 −1 和 1，不可导。

连续只说"接得上"，可导还要求"接得顺"，即左右两侧的斜率必须对得上。

**第三问：参数方程求二阶导，为什么不能对 dy/dx 直接再对 t 求一次导？**

答：因为 dy/dx 是"对 x"的导数，不是"对 t"的。

要对 x 再求一次导，得用链式法则补上 dx/dt：

```text
d²y/dx² = [d/dt(dy/dx)] / (dx/dt)
```

漏掉这个除法，是数一最常见的计算错误之一。

## 12. 小结与下一篇

这一篇压成六句话：

```text
1. 导数是差商的极限，几何上是切线斜率，物理上是瞬时变化率。
2. 三个记号：f'(x)、y'、dy/dx，其中 dy/dx 是整体记号。
3. 可导必连续，连续不一定可导；不可导只有尖角、竖直切线、振荡三种。
4. 求导靠四件工具：基本表、四则、链式、反函数；
   幂指函数和连乘式用对数求导。
5. 隐函数求导要补 y'，参数方程求导是"纵速比横速"，
   二阶必须再除以 x'(t)。
6. 微分 dy = f'(x)dx 是"用切线代替曲线"，
   它和等价无穷小是同一件事的两种说法。
```

一张必须背下来的表（求导基本式）：
```text
(x^α)' = αx^(α−1)      (sin x)' = cos x       (cos x)' = −sin x
(e^x)' = e^x           (a^x)' = a^x ln a      (ln x)' = 1/x
(arctan x)' = 1/(1+x²) (arcsin x)' = 1/√(1−x²)
```

如果只记一句话：**导数把曲线翻译成斜率，微分把曲线翻译成直线。**

这两件事合起来，就是高等数学处理非线性的全部本钱。
