> **读这篇之前，你只需要知道**：函数是"输入一个数、输出一个数"的规则，比如 f(x) = x² 输入 3 输出 9；图像是把所有输入输出对画在坐标系里；自变量是那个被喂进去的数，通常叫 x。
> **这篇讲什么**：不谈"到了那一点是多少"，只谈"越来越靠近那一点时，结果越来越靠近多少"，这套看法叫极限，它是导数、积分、级数全部的地基。
> **一个类比**：你站在一扇关着的门前，门缝里看不清屋里，但你可以从走廊两头往门口走，看屋里灯光越来越亮到什么程度；从左走和从右走看到的亮度必须一样，才能说"门口那个亮度"是确定的。


先看一个问题：

```text
x 越来越接近 0 时，1/x 等于几？
```

从正数那边过来：x = 0.1、0.01、0.001，1/x = 10、100、1000，越跑越大。

从负数那边过来：x = −0.1、−0.01、−0.001，1/x = −10、−100、−1000，越跑越小。

同一个"接近 0"，得到两个完全相反的方向。

所以"1/x 在 0 附近趋向几"这句话本身是坏的，得先补一句：你从哪边过来？

这就是这一篇要讲清楚的第一件事：**趋近是有方向的，方向不同，答案可以不同。**

第二件事更微妙。

```text
x 越来越接近 2 时，x² 等于几？
```

x = 2.1，x² = 4.41；x = 2.01，x² = 4.0401；x = 2.001，x² = 4.004001。

越来越接近 4。

这里没有任何矛盾，答案是 4。

但请注意我们做了什么：**我们一次也没有让 x 真的等于 2，只让它越来越近。**

这不是矫情，这是必须的。

因为高数里最要命的一类式子，恰恰在"那一点"上没有定义：

```text
(f(1+h) − f(1)) / h，当 h = 0 时
```

分母是 0，整个式子没有意义。

可它偏偏就是"切线斜率"的算法。

不让 h 等于 0，只让 h 趋向 0，式子就有意义了，而且结果越来越稳定。

**极限就是干这件事的工具：绕开那一点，看它附近怎么走。**

## 1. 为什么需要极限（不给会怎样）

先说清楚：如果没有极限这个概念，高等数学会缺哪些东西。

**第一，切线算不出来。**

求 y = x² 在 x = 1 处的切线斜率。

初中办法是取两点算斜率：

```text
k = (f(1+h) − f(1)) / h
  = ((1+h)² − 1) / h
  = (1 + 2h + h² − 1) / h
  = 2 + h
```

h = 1 时 k = 3，h = 0.1 时 k = 2.1，h = 0.01 时 k = 2.01。

h 越小，k 越靠近 2。

但 h 不能等于 0，一等于 0 就变成 0/0。

于是"切线斜率"这个几何上明明白白的东西，算术上却写不出来。

补上极限，它才能写成：

```text
k = lim(h→0) (2 + h) = 2
```

**第二，瞬时速度算不出来。**

平均速度 = 路程差 / 时间差，这个没问题。

瞬时速度要求时间差为 0，又是 0/0。

**第三，面积算不出来。**

曲线下的面积要切成无数个细条再加起来，条数越多越准，"无限多"这一步没有极限就无法收口。

**第四，连"0.999… 等于 1"都说不清。**

它是 0.9、0.99、0.999 这一串数趋向的值，本质是极限。

**第五，e、π 这类数定义不出来。**

e 的定义就是 lim(n→∞)(1+1/n)^n，没有极限，e 只是一个字母。

所以极限不是一章内容，它是**语法**。

后面所有章节都在用这套语法说话。

这一篇的任务只有两个：

```text
1. 把"趋近"讲成一句可以验收的话（ε-δ 语言）。
2. 把"算极限"变成几个可以照着做的动作。
```

## 2. 最小模型之一：函数

极限是"函数在一点附近的走向"，所以先把函数这件事钉住。

函数的定义很朴素：给一个输入，按规则给一个输出，并且**每个允许的输入只对应一个输出**。

记号：

```text
y = f(x)
```

读法：y 等于 f 括号 x。f 是规则的名字，x 是喂进去的数，f(x) 是吐出来的数。

三个词必须分清：

```text
定义域：允许输入的全体。
值域：实际输出的全体。
对应规则：怎么算。
```

例：f(x) = √(x − 1)。

定义域是 x ≥ 1，因为根号里不能是负数。

值域是 y ≥ 0。

**这一步为什么重要？**

因为极限只在"有定义的地方的附近"谈。

求 lim(x→0) √(x−1)，这个式子根本不该出现：x 在 0 附近（比如 x = −0.5）时函数没定义，谈不上走向。

所以看见一个极限，第一件事是扫一眼：**这点附近函数活着吗？**

### 2.1 复合函数与反函数

复合就是"套娃"：

```text
y = sin(x²)
```

先算 u = x²，再算 y = sin u。

记号写成 y = f(g(x))，读作"f 复合 g"。

拆复合函数的本事，在后面求导（03 篇）里是硬需求，因为链式法则就是按这个套娃一层层剥。

反函数是"反过来查"：

```text
y = 2x + 1  →  x = (y − 1)/2
```

原来是"给 x 算 y"，反函数是"给 y 找回 x"。

记作 x = f⁻¹(y)。

注意 f⁻¹ 不是 1/f，那个是倒数，两回事。

反函数存在的条件：原函数必须一对一（不同的 x 给不同的 y）。

y = x² 在整个实数上不是一对一的，但限制在 x ≥ 0 上就是，所以它的反函数是 y = √x。

### 2.2 四个性质

这四个性质在往后每一篇都会冒出来，先记住名字和作用。

```text
有界：图像能被两条水平线夹住。例：sin x 在 [−1, 1] 之间。
单调：一直往上走或一直往下走。例：e^x 一直往上。
奇偶：f(−x) = f(x) 是偶函数（关于 y 轴对称）；
      f(−x) = −f(x) 是奇函数（关于原点对称）。
周期：f(x + T) = f(x)，T 是最小正周期。例：sin x 的周期是 2π。
```

**没有这些性质会怎样？**

后面证明题里经常要"取一个 ξ 让 f(ξ) = 0"，凭什么敢说存在？靠的就是"连续 + 单调"或"连续 + 有界"。

性质不是装饰，是证明时能拿出来的工具。

## 3. 最小模型之二：数列极限

数列就是一串排好队的数：

```text
a₁, a₂, a₃, …, aₙ, …
```

例：aₙ = 1/n，就是 1、1/2、1/3、1/4…

**没有数列极限会怎样？**

级数那一块（16 篇）会整体垮掉。

因为"无穷多项相加等于几"的定义就是"部分和数列的极限"。

所以这一节是后面级数的地基。

先看 1/n 这串数往哪走：
```text
n = 1     1
n = 10    0.1
n = 100   0.01
n = 1000  0.001
```

越来越接近 0。

"越来越接近"这四个字太软，考试不认。

要把它换成一句能验收的话，就需要 ε-N 语言。

```text
lim(n→∞) aₙ = A
```

读法：lim 是 limit 的缩写，读"极限"；n→∞ 读"n 趋于无穷大"；整句读"当 n 趋于无穷大时，aₙ 的极限是 A"。

正式定义：

```text
对任意 ε > 0，存在正整数 N，
当 n > N 时，都有 |aₙ − A| < ε。
```

符号读音与含义：

```text
ε      读"艾普西龙"，希腊字母，代表"你要求的误差上限"，可以要多小有多小。
N      读"恩"，是一个项号，通常依赖 ε。
|aₙ − A|  第 n 项与目标 A 的距离。
```

四步拆开：

```text
① 它在算什么：
   它是一张验收单。你说"我要误差小于 ε"，
   我就交出一个起点 N，保证从第 N 项之后，所有项都落在 A 附近 ε 以内。

② 符号逐个念：
   ε 是允许误差，N 是起跳项号，n > N 表示"从某一项之后"。

③ 代一组数：
   aₙ = 1/n，A = 0，要求 ε = 0.01。
   要 |1/n − 0| < 0.01，即 n > 100，取 N = 100。
   验证：n = 101 时 1/101 ≈ 0.0099 < 0.01，过关。
   若要求 ε = 0.0001，取 N = 10000，同样过关。

④ 什么时候能用/不能用：
   能用来"证明某个数是极限"。
   不能用来"求出极限是多少"，因为 A 必须先猜出来才能写这张验收单。
   实际计算靠后面的运算法则和等价替换，不靠定义。
```

再写一遍这个证明的完整格式，考试就照这个写：

```text
任给 ε > 0，要使 |1/n − 0| = 1/n < ε，
只需 n > 1/ε。
取 N = [1/ε] + 1（[ ] 表示取整数部分），
则当 n > N 时，恒有 |1/n − 0| < ε。
故 lim(n→∞) 1/n = 0。
```

顺便定两个词，后面 16 篇还要用：

```text
数列有极限，叫收敛。
数列没有极限，叫发散。
```

发散不等于"跑到无穷大"，比如 1、−1、1、−1… 一直跳，也属于发散。

**这里的思路从哪来？**

从最后一行倒着推。

先盯着目标 |aₙ − A| < ε，把 aₙ 代进去，解出 n 该多大，这个"多大"就是 N。

所以 ε-N 证明永远是从结论往回算，不是从定义往前凑。

## 4. 函数极限：ε-δ 与左右极限

数列的自变量只能一个格子一个格子跳（n = 1, 2, 3…）。

函数不一样，x 是连续地滑过去的。

所以"趋于"要重新定义，而且比数列多一个麻烦：**可以从左边滑，也可以从右边滑。**

```text
lim(x→a) f(x) = A
```

读法：当 x 趋于 a 时，f(x) 的极限是 A。

正式定义（ε-δ 语言）：

```text
对任意 ε > 0，存在 δ > 0，
当 0 < |x − a| < δ 时，都有 |f(x) − A| < ε。
```

逐符号：

```text
δ      读"德尔塔"，希腊字母，是"x 允许偏离 a 的范围"。
0 < |x − a|  表示 x 靠近 a，但不许等于 a。这一条是关键：
            极限不管 a 点本身发生了什么，只看 a 周围。
|f(x) − A| < ε  表示函数值落在 A 的 ε 邻域里。
```

四步：

```text
① 它在算什么：
   你给一个纵向的宽容度 ε，我总能找到一个横向的窗口 δ，
   只要 x 落进这个窗口（且不站在中心点 a 上），f(x) 就落在你的宽容度里。

② 符号逐个念：
   ε 管纵向误差，δ 管横向范围，δ 一般随 ε 变小而变小。

③ 代一组数：
   证明 lim(x→2)(3x − 1) = 5。
   先算距离：|(3x − 1) − 5| = |3x − 6| = 3|x − 2|。
   要求 3|x − 2| < ε，即 |x − 2| < ε/3。
   取 δ = ε/3。
   若 ε = 0.01，则 δ ≈ 0.0033；x = 2.001 时 |f(x) − 5| = 0.003 < 0.01，过关。

④ 什么时候能用/不能用：
   用来证"极限是 A"，以及做少量简单估计。
   不用来算具体极限（太慢）。
   注意 a 点本身可以没有定义，也可以有定义但值不等于 A，
   这两种情况都不影响极限。
```

### 4.1 左极限与右极限

```text
lim(x→a⁻) f(x)   读"x 从左侧趋于 a"，也写成 f(a−0)，表示 x < a 地靠近。
lim(x→a⁺) f(x)   读"x 从右侧趋于 a"，也写成 f(a+0)，表示 x > a 地靠近。
```

三条命：

```text
极限存在的充要条件：左极限 = 右极限 = A。
```

这句话是数一选择题的高频陷阱，因为它把"看着像有极限"的很多情况一刀切掉。

例 1：f(x) = |x|/x，问 x → 0 的极限。

```text
x > 0 时 |x| = x，f(x) = 1，所以右极限是 1。
x < 0 时 |x| = −x，f(x) = −1，所以左极限是 −1。
1 ≠ −1，极限不存在。
```

画出来是两段平线，在 0 处断开：

```text
        y
   1 ────●
         │
─────────┼───────── x
         │
    −1 ────●
        0
```

例 2：f(x) = e^(1/x)，问 x → 0。

```text
x → 0⁺ 时 1/x → +∞，e^(1/x) → +∞。
x → 0⁻ 时 1/x → −∞，e^(1/x) → 0。
左右不同（一个是无穷大，一个是 0），极限不存在。
```

例 3：f(x) = arctan(1/x)，问 x → 0。

```text
右极限是 π/2，左极限是 −π/2，极限不存在。
```

例 4：分段函数 f(x) = x²（x < 1），f(x) = 2x（x ≥ 1），问 x → 1。

```text
左极限：走 x² 这条路，x → 1⁻ 时 x² → 1。
右极限：走 2x 这条路，x → 1⁺ 时 2x → 2。
1 ≠ 2，所以极限不存在。
但 f(1) = 2 是有定义的，可见"有定义"和"有极限"是两件事。
```

**记住这三个例子。**

数一考"极限不存在"的时候，八成就是这三张脸：绝对值、指数倒挂、反正切倒挂。

### 4.2 x 趋于无穷大

```text
lim(x→∞) f(x) = A
```

读法：当 x 的绝对值无限增大时，f(x) 趋于 A。

定义只需把 δ 换成 X：

```text
对任意 ε > 0，存在 X > 0，
当 |x| > X 时，都有 |f(x) − A| < ε。
```

例：lim(x→∞) 1/x = 0。

给 ε = 0.01，要 1/|x| < 0.01，即 |x| > 100，取 X = 100。

**这里最容易错的一点：**

x → ∞ 在数一里默认指 |x| → ∞（两头都跑）。

如果要只跑正方向，会写成 x → +∞。

所以 lim(x→∞) e^x 不存在，因为 x → −∞ 那一头是 0，x → +∞ 那一头是 +∞。

## 5. 无穷小与无穷大：极限世界的两把尺子

### 5.1 无穷小

定义很短：

```text
以 0 为极限的变量叫无穷小。
```

注意两点：

```text
第一，无穷小是变量，不是数。0 是无穷小里唯一的一个常数。
第二，"很小"不等于"无穷小"。0.000001 是个固定的数，它的极限是它自己，不是 0。
```

**没有无穷小会怎样？**

求极限的最后一步永远是"比较谁更快归零"。

不比阶，就只能一个个套定义，慢到无法做题。

三条常用性质：

```text
有限个无穷小相加，还是无穷小。
有限个无穷小相乘，还是无穷小。
有界函数 × 无穷小 = 无穷小。
```

第三条最有用。

例：lim(x→0) x² sin(1/x)。

sin(1/x) 在 −1 和 1 之间乱跳，没有极限。

但它有界（|sin| ≤ 1），而 x² 是无穷小。

有界 × 无穷小 = 无穷小，所以答案是 0。

这类题的核心就是一句话：**乱跳不要紧，只要跳不出范围，乘上一个归零的因子就压平了。**

### 5.2 无穷大与"无界"的区别

```text
lim(x→a) f(x) = ∞
```

读法：f(x) 趋于无穷大。

它的意思是：**要多大有多大**，不是"等于一个叫 ∞ 的数"。

所以 ∞ 不能参加四则运算，∞ − ∞、∞/∞ 都没有意义。

还有一个高频混淆：

```text
无界 ≠ 无穷大
```

例：f(x) = x sin x，当 x → ∞。

它无界，因为总能取到 x = π/2 + 2kπ 让 f 任意大。

但它不是无穷大，因为取 x = kπ 时 f = 0，函数一再回到 0。

无穷大的要求是"从某一刻起，一直很大"，不许回头。

再记两个对照，考试里常拿它们当烟雾弹：

```text
lim(x→+∞)(x² − x) = +∞     ∞ − ∞ 也可以是无穷大，别急着说"没意义"。
lim(x→0⁺) x ln x = 0       0 · ∞ 也可以收敛到 0。
```

未定式的意思是"要算才知道"，不是"一定不存在"。

### 5.3 无穷小的阶与等价无穷小

两个无穷小都趋于 0，但归零的速度可以差很远。

设 α、β 都是无穷小，看比值 α/β：

```text
α/β → 0      称 α 是 β 的高阶无穷小，记 α = o(β)。
α/β → ∞      称 α 是 β 的低阶无穷小。
α/β → c ≠ 0  称 α 与 β 同阶。
α/β → 1      称 α 与 β 等价，记 α ~ β。
```

符号读音：

```text
o     读"小 o"，o(β) 读"β 的高阶无穷小"。
~     读"等价于"。
```

四步说清"等价"这件事：

```text
① 它在算什么：
   两个无穷小归零的速度几乎一模一样，比值趋于 1，
   所以在乘除法里可以互相顶替，不改变极限值。

② 符号逐个念：
   α ~ β 读"α 等价于 β"，等价于 α/β → 1。

③ 代一组数：
   取 x = 0.01，sin x = 0.0099998333…，
   sin x / x = 0.9999833…，非常接近 1。
   取 x = 0.001，比值 0.99999983…，更接近 1。

④ 什么时候能用/不能用：
   能用在乘除的因子上，整体替换。
   不能随手用在加减法里（下面有反例）。
   替换必须是在 x → 0 的过程中，且替换前后都是无穷小。
```

必背等价表（x → 0）：

```text
sin x      ~ x
tan x      ~ x
arcsin x   ~ x
arctan x   ~ x
1 − cos x  ~ x²/2
ln(1 + x)  ~ x
e^x − 1    ~ x
a^x − 1    ~ x ln a
(1 + x)^α  ~ αx        （α 为任意常数）
x − sin x  ~ x³/6
tan x − x  ~ x³/3
```

这张表不用背证明，但必须背结论，而且要背到"看见 1 − cos x 就想到 x²/2"这种条件反射。

因为数一的极限题，八成靠这张表在三十秒内结束战斗。

**加减法为什么不能乱换？看一个反例。**

求 lim(x→0) (sin x − x) / x³。

如果直接把 sin x 换成 x，分子变成 x − x = 0，答案 0。

实际答案不是 0。

原因：sin x 和 x 的主部互相抵消了，剩下的 x³/6 这个"老二"才是真正的主角，而替换把老二也一起丢了。

正确做法是用泰勒展开（05 篇之后会讲）或用洛必达（04 篇）：

```text
sin x = x − x³/6 + …
sin x − x = −x³/6 + …
(sin x − x)/x³ → −1/6
```

一句话总结：**乘法随便换，加减要看清有没有抵消。**

## 6. 极限的四则运算与夹逼

### 6.1 四则运算法则

```text
若 lim f(x) = A，lim g(x) = B，且 A、B 都是有限数，则
lim [f(x) ± g(x)] = A ± B
lim [f(x) · g(x)] = A · B
lim [f(x) / g(x)] = A / B      （要求 B ≠ 0）
```

**没有它会怎样？**

每道题都得回到 ε-δ，一道题写两页，考试做不完三道。

有了它，极限变成"能拆就拆、能代就代"的算术。

四步：

```text
① 它在算什么：
   把一个大式子拆成几块，分别算完再合并。

② 符号逐个念：
   lim 是极限，A、B 是两块各自的极限值，"有限数"是前提。

③ 代一组数：
   lim(x→2)(x² + 3x) = 4 + 6 = 10。
   先算 x² → 4，再算 3x → 6，相加得 10。

④ 什么时候能用/不能用：
   拆之前必须先确认两块极限都存在且有限。
   分母极限为 0 时除法法则失效，这时是"未定式"，得变形。
```

第④条是最大的坑，看反例：

```text
lim(x→0) (1/x − 1/x)
```

如果拆成 lim 1/x − lim 1/x，两块都是 ∞，∞ − ∞ 没有意义。

可原式恒等于 0，极限就是 0。

**拆开之前先问一句：两块各自收敛吗？**

不收敛就不能拆，这不是技巧问题，是逻辑问题。

### 6.2 未定式是什么

```text
0/0、∞/∞、0·∞、∞ − ∞、1^∞、0⁰、∞⁰
```

这七种叫未定式，读作"未定"，意思是**光看形式判断不了结果**，必须具体算。

它们不是"没有极限"，只是"法则暂时失灵"。

处理顺序也固定：先想办法化成 0/0 或 ∞/∞，再用洛必达（04 篇），化不动的用等价替换或泰勒。

例：0/0 型的两个样本。

```text
lim(x→0) x/x = 1
lim(x→0) x²/x = 0
lim(x→0) x/x² = ∞
```

同样是 0/0，结果可以是 1、0、∞。

所以 0/0 是一个"问号"，不是一个"答案"。

### 6.3 夹逼准则

```text
若 g(x) ≤ f(x) ≤ h(x)，且 lim g(x) = lim h(x) = A，
则 lim f(x) = A。
```

**没有它会怎样？**

有些式子根本算不出来，比如 n 项和、带 n 的根号，只能靠"上下两条绳子一起收"。

四步：

```text
① 它在算什么：
   把要求的式子夹在两个好算的式子中间，两边都奔向同一个数，中间只能跟着去。

② 符号逐个念：
   g 是下界，h 是上界，A 是共同的落点。

③ 代一组数：
   求 lim(n→∞) (1/√(n²+1) + 1/√(n²+2) + … + 1/√(n²+n))。
   一共 n 项，每项最小是 1/√(n²+n)，最大是 1/√(n²+1)。
   所以 n/√(n²+n) ≤ 原式 ≤ n/√(n²+1)。
   左边 = 1/√(1+1/n) → 1，右边 → 1。
   两头都到 1，原式 = 1。

④ 什么时候能用/不能用：
   用于"项数随 n 变"的和式、含 n 的根式、乱跳的三角式。
   关键是两边要收口到同一个值，收不到同一个值就白夹。
```

### 6.4 单调有界准则

```text
单调递增且有上界的数列，必有极限。
单调递减且有下界的数列，必有极限。
```

注意它只说"存在"，不说"等于几"。

所以用它的标准流程是：

```text
第一步：证明单调（作差 a(n+1) − aₙ 看符号，或作商）。
第二步：证明有界（找一条数轴上的墙）。
第三步：既然存在，设为 A，在递推式两边取极限解出 A。
```

例：a₁ = √2，a(n+1) = √(2 + aₙ)，求极限。

```text
第一步（有界）：a₁ = 1.414 < 2。若 aₙ < 2，则 a(n+1) = √(2 + aₙ) < √4 = 2。
              由归纳法，所有项都小于 2，有上界。
第二步（单调）：a(n+1)² − aₙ² = 2 + aₙ − aₙ² = −(aₙ − 2)(aₙ + 1)。
              因为 0 < aₙ < 2，所以 (aₙ − 2) < 0，(aₙ+1) > 0，
              乘积取负号后为正，即 a(n+1)² > aₙ²，故 a(n+1) > aₙ，单调递增。
第三步（求值）：设极限为 A，两边取极限：A = √(2 + A)，
              A² = 2 + A，A² − A − 2 = 0，(A − 2)(A + 1) = 0，
              A = 2 或 A = −1。因为每项都是正的，A ≥ 0，所以 A = 2。
```

这个"先证存在、再解方程"的套路，在数一里出现过很多次，值得背下来。

## 7. 两个重要极限

这两个极限是"从定义推出来的两个标准件"，后面的等价无穷小表、e 的定义、指数函数的导数，全靠它们。

### 7.1 第一个：sin x / x

```text
lim(x→0) sin x / x = 1
```

**没有它会怎样？**

三角函数的导数就推不出来。

(sin x)' = cos x 这一步，中间必须用到 lim(h→0) sin h / h = 1。

推不出来，后面所有跟三角有关的求导、积分、级数展开都断链。

四步：

```text
① 它在算什么：
   0/0 型。分子分母都趋于 0，但两者归零的速度几乎相同，比值稳定在 1。
   几何上是"小角度时，弧长、弦长、正切长三者几乎相等"。

② 符号逐个念：
   sin 是正弦，x 必须用弧度制（这是前提条件，不是可选项）。
   x→0 表示从两侧趋近。

③ 代一组数：
   x = 0.1  弧度，sin 0.1 = 0.0998334，比值 0.998334。
   x = 0.01 弧度，sin 0.01 = 0.00999983，比值 0.999983。
   x = 0.001，比值 0.99999983。
   肉眼可见地贴着 1。

④ 什么时候能用/不能用：
   只适用于 x→0 且用弧度。
   x→π 时不能套，那时 sin x/x → 0/π = 0。
   度数制下公式不成立（sin 0.1° / 0.1 ≈ 0.01745），所以数一默认弧度。
```

怎么来的（思路，不要求背证明）：

在单位圆里，设圆心角 x（很小），比较三块面积：

```text
三角形面积 = (1/2) sin x
扇形面积   = (1/2) x
大三角形   = (1/2) tan x
```

夹逼关系：

```text
(1/2) sin x < (1/2) x < (1/2) tan x
```

同除以 (1/2) sin x：

```text
1 < x / sin x < 1 / cos x
```

两边取倒数翻转：

```text
cos x < sin x / x < 1
```

x → 0 时 cos x → 1，两头都到 1，由夹逼准则得 sin x / x → 1。

**思路从哪来？**

要证一个比值趋于 1，就找两条都趋于 1 的界线把它夹住。

单位圆里现成的三条线（弦、弧、切线）正好给出这个夹逼。

常用变体（都是它穿了件衣服）：

```text
lim(x→0) sin(3x)/x = 3            把 3x 看成整体 u，sin u/u → 1，再补一个 3。
lim(x→0) sin(ax)/sin(bx) = a/b    上下各换一次，再用 ax/bx 收尾。
lim(x→0) tan x/x = 1              因为 tan x = sin x / cos x，cos x → 1。
lim(x→0) arcsin x/x = 1           令 u = arcsin x，则 x = sin u。
```

### 7.2 第二个：e 的定义

```text
lim(x→∞) (1 + 1/x)^x = e
```

四步：

```text
① 它在算什么：
   1^∞ 型。底数趋于 1，指数趋于无穷，两个力互相拉扯，
   结果不是 1 也不是 ∞，而是一个固定的数 e ≈ 2.718281828…。

② 符号逐个念：
   e 读"衣"，自然对数的底，是一个无理数，约等于 2.71828。
   ^ 表示乘方，(1 + 1/x)^x 读"1 加 x 分之一的 x 次方"。

③ 代一组数：
   x = 10      (1.1)^10 = 2.5937…
   x = 100     (1.01)^100 = 2.7048…
   x = 1000    (1.001)^1000 = 2.71692…
   x = 10000   (1.0001)^10000 = 2.71815…
   一路爬到 2.71828 附近。

④ 什么时候能用/不能用：
   必须是"1 的无穷大次方"这种形状。
   底数不趋于 1，或者指数不趋于无穷，都不能套。
```

等价的常用形式（x → 0）：

```text
lim(x→0) (1 + x)^(1/x) = e
```

为什么两种写法是一回事：令 t = 1/x，x → 0⁺ 时 t → +∞，代入即得。

**1^∞ 型的标准处理法**

设 u(x) → 1，v(x) → ∞，求 lim u^v。

取对数，把幂变成乘：

```text
u^v = e^(v ln u)
```

而 ln u = ln(1 + (u − 1)) ~ (u − 1)（因为 ln(1+t) ~ t）。

于是：

```text
lim u^v = e^(lim v(u − 1))
```

这个式子值得单独记，它把 1^∞ 型一步打完：

```text
lim u^v = e^(lim v · (u − 1))
```

把 x 换成整数 n，就得到 e 的数列定义：

```text
e = lim(n→∞) (1 + 1/n)^n
```

这个数还可以写成无穷级数 e = 1 + 1/1! + 1/2! + 1/3! + …（17 篇会展开）。

它无理、超越，值约 2.718281828459045，记住 2.71828 就够用。

四步：

```text
① 它在算什么：
   把"1 的无穷次方"这个问号，换算成"指数上的一次普通极限"。

② 符号逐个念：
   u 是底，v 是指数，u − 1 是底离 1 的距离。

③ 代一组数：
   lim(x→0) (1 + 3x)^(1/x)。这里 u = 1 + 3x，v = 1/x，
   v(u − 1) = (1/x)(3x) = 3，所以结果是 e³。

④ 什么时候能用/不能用：
   只用于 1^∞ 型。别的一律不套，0⁰ 和 ∞⁰ 型也常取对数，但公式不同。
```

三个必须会的例题：

```text
例1  lim(x→∞) (1 + 2/x)^x
     u = 1 + 2/x，v = x，v(u − 1) = x · (2/x) = 2，答案 e²。

例2  lim(x→∞) (1 − 2/x)^x
     这里 u − 1 = −2/x，v(u−1) = −2，答案 e^(−2) = 1/e²。

例3  lim(x→∞) ((x + 1)/(x − 1))^x
     先拆底：(x+1)/(x−1) = 1 + 2/(x−1)，u − 1 = 2/(x−1)，
     v(u−1) = 2x/(x−1) → 2，答案 e²。
```

## 8. 算一遍：极限的三种基本方法

极限题千变万化，但 0/0 型的基本功只有三招。

先把判断顺序写成一张流程图：

```text
第一步：能不能直接代入？
       能代进去且分母不为 0 → 直接出答案，结束。
       代进去分母为 0 → 进入第二步。
第二步：分子分母有没有公因子？
       有 → 因式分解或有理化，约掉，回到第一步。
第三步：是不是乘除结构、有没有标准等价？
       是 → 等价无穷小替换，收工。
       都不是 → 洛必达或泰勒（04、05 篇）。
```

### 8.1 方法一：直接代入

适用于"函数在这一点连续"的情况（连续的定义就是极限等于函数值，见 02 篇）。

```text
例  lim(x→2) (x² + 3x − 1)
     = 4 + 6 − 1 = 9
```

只要分母不为 0，多项式、指数、对数、三角在定义域内都可以直接代。

### 8.2 方法二：约去零因子

这是最重要的一招，因为 0/0 型的病根就是"上下都有 (x − a) 这个因子"。

**因式分解型**

```text
例1  求 lim(x→3) (x² − 9)/(x − 3)。
     代入得 0/0。
     分解：x² − 9 = (x − 3)(x + 3)。
     原式 = lim(x→3) (x + 3) = 6。
     答案：6。
```

**有理化型**

根号相减会产生 0/0，把分子分母同乘共轭式（把减号变加号的那个式子）。

```text
例2  求 lim(x→0) (√(1 + x) − 1)/x。
     代入得 0/0。
     同乘共轭：分子分母都乘 (√(1 + x) + 1)。
     分子 = (1 + x) − 1 = x。
     原式 = lim(x→0) x / [x(√(1 + x) + 1)]
          = lim(x→0) 1/(√(1 + x) + 1)
          = 1/(1 + 1) = 1/2。
     答案：1/2。
```

验算一下：√1.01 = 1.0049876，(1.0049876 − 1)/0.01 = 0.49876，确实贴着 0.5。

```text
例3  求 lim(x→0) (√(1 + x) − √(1 − x))/x。
     同乘共轭 (√(1+x) + √(1−x))：
     分子 = (1 + x) − (1 − x) = 2x。
     原式 = lim 2x / [x(√(1+x) + √(1−x))]
          = 2/(1 + 1) = 1。
     答案：1。
```

**换元型**

含根号又不好有理化时，直接把根号整个换掉。

```text
例4  求 lim(x→0) (∛(1 + x) − 1)/x。
     令 t = ∛(1 + x)，则 x = t³ − 1，x → 0 时 t → 1。
     原式 = lim(t→1) (t − 1)/(t³ − 1)
          = lim(t→1) 1/(t² + t + 1)
          = 1/3。
     答案：1/3。
```

### 8.3 方法三：等价无穷小替换

```text
例5  求 lim(x→0) (1 − cos x)/(x sin x)。
     1 − cos x ~ x²/2，sin x ~ x。
     原式 = lim (x²/2)/(x · x) = 1/2。
     答案：1/2。
```

注意这里能换，是因为分母是**乘积** x · sin x，sin x 是一个独立的因子。

```text
例6  求 lim(x→0) (e^(2x) − 1)/(ln(1 + 3x))。
     e^(2x) − 1 ~ 2x，ln(1 + 3x) ~ 3x。
     原式 = 2x/3x = 2/3。
     答案：2/3。
```

```text
例7  求 lim(x→0) (tan x − sin x)/x³。
     这里分子是差，直接换会得到 0，所以先提公因子把它变成乘积：
     tan x − sin x = tan x (1 − cos x)。
     于是原式 = lim [tan x / x] · [(1 − cos x)/x²]
              = 1 · (1/2) = 1/2。
     答案：1/2。
```

例 7 是这一篇最值钱的一道题。

它演示了"加减不能换"时的救法：**先提公因子，把差变成积，再换。**

比洛必达快得多，而且不容易算错。

### 8.4 一道三招连用的综合题

```text
例8  求 lim(x→0) [√(1 + tan x) − √(1 + sin x)] / x³。
```

拿到手先分类型：代入是 0/0，而且分子是两个根号相减。

```text
第一招（有理化）：分子分母同乘 (√(1 + tan x) + √(1 + sin x))。
  分子 = (1 + tan x) − (1 + sin x) = tan x − sin x。
  分母 = x³ (√(1 + tan x) + √(1 + sin x))。
  当 x → 0 时，括号里那一坨 → 1 + 1 = 2。

第二招（化积）：tan x − sin x = tan x (1 − cos x)。

第三招（等价替换）：
  tan x ~ x，1 − cos x ~ x²/2，
  所以分子 ~ x · x²/2 = x³/2。

合并：
  原式 = lim (x³/2) / (2x³) = 1/4。
  答案：1/4。
```

为什么可以用三次替换而不出错：每一步换掉的都是**乘除因子**。

有理化之后，分子成了一个整体乘法结构，三项各自等价，互不干扰。

这就是"先改结构、再做替换"的完整思路。

## 9. 等价替换的三个操作要点

### 9.1 只换因子，不换加减项

正确：

```text
lim (x · sin x)/x²   → 换 sin x ~ x  →  lim x · x/x² = 1
```

错误：

```text
lim (sin x − x)/x³   → 换 sin x ~ x  →  lim 0/x³ = 0   （答案应为 −1/6）
```

判断标准只有一条：**被换的部分是不是整个分子或整个分母的乘除因子。**

是，就能换；不是（被加减号连着），就不能单独换。

### 9.2 差值型要先化积

这是应对"不能换"的通用手段。

```text
tan x − sin x = tan x(1 − cos x)        → 积
1 − cos x cos 2x = (1 − cos x) + cos x(1 − cos 2x)   → 拆成两个可换的差
x − sin x                                       → 化不了，只能用泰勒
```

最后一行说明：不是所有差都能化积，遇到化不动的，就上泰勒或洛必达。

### 9.3 幂指函数先取对数

u^v 这种形状，先写 u^v = e^(v ln u)，再算指数上的极限。

```text
例  求 lim(x→0⁺) x^x。
    取对数：x^x = e^(x ln x)。
    先算指数：lim(x→0⁺) x ln x。
    这是 0 · (−∞) 型，令 t = 1/x，则 x ln x = −(ln t)/t → 0（t → +∞）。
    所以原式 = e⁰ = 1。
    答案：1。
```

一个反直觉的结论：0 的 0 次方在极限意义下可以是 1，因为底数归零的速度比指数发散的速度更"强势"。

这也是 0⁰ 被列为未定式的原因。

## 10. 常见错误

**错误一：拆极限不看存在性。**

```text
错：lim(x→0)(1/x − 1/x) = lim 1/x − lim 1/x = ∞ − ∞
对：原式 = lim 0 = 0
```

**错误二：加减法里乱用等价无穷小。**

```text
错：sin x − x ~ x − x = 0
对：sin x − x ~ −x³/6
```

**错误三：把 ∞ 当数算。**

∞ − ∞、∞/∞、0 · ∞ 都是未定式，不能按算术处理。

**错误四：忘记左右极限。**

出现 |x|、e^(1/x)、arctan(1/x)、分段函数、根号下的平方时，必须先分左右。

**错误五：以为极限存在就要求那点有定义。**

lim(x→1)(x² − 1)/(x − 1) = 2，而原式在 x = 1 处根本没有定义。

极限只看附近，不看该点。

**错误六：替换时把 x→0 的条件丢了。**

sin x ~ x 只在 x → 0 时成立。

x → 1 时 sin x ~ sin 1，不能写 sin x ~ x。

**错误七：只算一侧就下结论。**

看到 |x − 2| 或 e^(1/(x−1)) 这类式子，只算 x → 2⁺ 就写答案。

数一的选择题经常在选项里同时放左极限、右极限和"不存在"，专门钓这种漏算。

## 11. 数一怎么考

极限在数一里的出题方式很固定，就四类：

```text
选择/填空：
  1. 直接求一个 0/0 或 1^∞ 的极限。
  2. 比较无穷小的阶（问"是 x 的几阶无穷小"）。
  3. 已知极限值，反求参数 a、b。
解答题：
  4. 求极限作为大题的第一小问，后面接导数或积分。
```

一个实用的预判：题干里出现"等价无穷小"三个字的，基本都在考第 5.3 节那张表；出现"参数 a"的，基本都在考"上下同阶"配平；出现"几阶无穷小"的，一律上泰勒。

这三类之外的极限题，大多只是换了个外衣的 0/0。

### 11.1 例题：反求参数

```text
题：已知 lim(x→0) (√(1 + a x²) − 1)/(1 − cos x) = 1，求 a。
```

思路：分子分母都是无穷小，都用等价替换。

```text
第一步，换分子：√(1 + u) − 1 ~ u/2，取 u = a x²，得分子 ~ a x²/2。
第二步，换分母：1 − cos x ~ x²/2。
第三步，相比：(a x²/2)/(x²/2) = a。
第四步，由题意 a = 1。
答案：a = 1。
```

验算：a = 1 时，分子 ~ x²/2，分母 ~ x²/2，比值 → 1，成立。

### 11.2 例题：判断无穷小的阶

```text
题：当 x → 0 时，x − sin x 是 x 的几阶无穷小？
```

思路：用"阶"的定义，看 (x − sin x)/x^k 的极限是不是非零常数。

```text
用泰勒展开：sin x = x − x³/6 + o(x³)。
所以 x − sin x = x³/6 + o(x³)。
(x − sin x)/x³ → 1/6 ≠ 0。
答案：三阶无穷小，主部是 x³/6。
```

这类题的通用做法：把两个函数都展开到"第一次出现差别"的那一项，差别的次数就是阶数。

### 11.3 例题：通分造出 0/0

```text
题：求 lim(x→0) [1/x² − 1/(x tan x)]。
```

思路：∞ − ∞ 型，先通分变成 0/0。

```text
通分：1/x² − 1/(x tan x) = (tan x − x)/(x² tan x)。
分子 tan x − x ~ x³/3（查等价表）。
分母 x² tan x ~ x² · x = x³。
比值 → (1/3)/1 = 1/3。
答案：1/3。
```

### 11.4 例题：乘积型三角

```text
题：求 lim(x→0) (1 − cos x cos 2x)/x²。
```

思路：把乘积拆成"能换的差"。

```text
1 − cos x cos 2x = (1 − cos x) + cos x(1 − cos 2x)。
第一块 ~ x²/2。
第二块：cos x → 1，1 − cos 2x ~ (2x)²/2 = 2x²，所以第二块 ~ 2x²。
相加 ~ x²/2 + 2x² = (5/2)x²。
除以 x² 得 5/2。
答案：5/2。
```

## 12. 和其他章节怎么连

极限不是一个孤立章节，它是整套课的通用货币。

```text
→ 02 连续：连续的定义就是 lim(x→a) f(x) = f(a)。
           极限不会算，连续就没法判，间断点也分不了类。

→ 03 导数：导数是 0/0 型的极限，
           f'(a) = lim(h→0) [f(a+h) − f(a)]/h。
           再用定义求导，本质还是求极限。

→ 04 中值定理：洛必达法则处理 0/0 与 ∞/∞，
              它是柯西中值定理的推论，而柯西中值定理本身是极限过程的产物。

→ 07 定积分：定积分是"分割、求和、取极限"，
             那个极限是 n → ∞ 的数列极限。

→ 09 反常积分：无穷限积分定义为 lim(b→+∞) ∫ₐ^b f，
             本质是函数极限。

→ 16 级数：级数收敛 = 部分和数列有极限。
          比值审敛法里的 ρ = lim |a(n+1)/aₙ| 就是极限。

→ 17 幂级数：收敛半径由 lim |a(n+1)/aₙ| 决定。
```

所以这一篇如果没打牢，后面不是"某章难一点"，而是"每章都断一节"。

反过来说，极限的三招（代入、约因子、等价替换）练到条件反射，后面很多计算题会突然变简单。

### 自检三问

**第一问：lim(x→0) 1/x 存在吗？如果不存在，是哪种"不存在"？**

答：不存在。

左极限 −∞，右极限 +∞，两侧不同。

这类叫"无穷型不存在"，和"左右极限都存在但不相等"（跳跃型）要区分开。

**第二问：为什么 sin x − x 不能直接把 sin x 换成 x，而 (x sin x)/x² 可以？**

答：替换只对乘除因子成立。

在 x sin x 里 sin x 是一个独立因子，换掉不改变主部。

在 sin x − x 里，两项的主部都是 x，一减就抵消了，主部归零，真正决定大小的是三阶项 −x³/6；替换把这一项也丢了，所以答案会错。

**第三问：lim(x→∞) (1 + 1/x)^x 和 lim(x→0)(1 + x)^(1/x) 是同一个极限吗？**

答：是同一个。

令 t = 1/x，两个式子互换，都等于 e。

记住这一点，考试时看到哪种形式都能立刻套 e 的结论。

## 13. 小结与下一篇

这一篇的全部内容压成五句话：

```text
1. 极限不谈"那一点是多少"，只谈"附近趋向多少"。
2. 趋近有方向：左极限 = 右极限，极限才存在。
3. ε-δ 是把"越来越接近"翻译成可验收句子的工具，
   它的用法是从目标倒推 δ，不是从定义正着凑。
4. 算 0/0 型就三招：直接代入、约去零因子（分解 / 有理化 / 换元）、
   等价无穷小替换（只对乘除因子）。
5. 两个标准件：sin x/x → 1，(1 + 1/x)^x → e，
   后者专治 1^∞ 型。
```

一张必须能默写的表：

```text
sin x ~ x        tan x ~ x        arcsin x ~ x     arctan x ~ x
1 − cos x ~ x²/2     ln(1+x) ~ x     e^x − 1 ~ x
(1+x)^α − 1 ~ αx     x − sin x ~ x³/6     tan x − x ~ x³/3
```

下一篇是 02：连续与间断。

它要回答的问题是：

```text
极限存在，和"函数在这点接得上"，差在哪里？
间断点有几种？凭什么分类？
闭区间上连续的函数，为什么一定取到最大值？
```

那一篇会把"极限"从一个计算工具，变成描述函数形状的语言。
