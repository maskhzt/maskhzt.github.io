
**第三件事：术语表怎么算"过关"。**

标准不是"能背出定义"，而是：

```text
看到这个词，能用一句话说出它是什么、用在哪。
```

比如"变上限积分"，过关的回答是：

```text

```

不需要背出 Φ(x) = ∫ₐˣ f(t)dt 这种完整写法，那个在公式表里。

## 2. 术语表（一）：极限与连续

**1. 函数**

一个"输入对应一个输出"的规则，记作 y = f(x)。

**2. 定义域**

让式子有意义的输入全体。

分母不为零、根号内非负、对数内为正，三条是主要限制。

**3. 复合函数**

把一个函数的输出，当成另一个函数的输入，记作 f[g(x)]。

**4. 反函数**

把输入与输出对调得到的函数，记作 f⁻¹。

原函数与反函数的图像关于直线 y = x 对称。

**5. 数列极限**

n 无限增大时，aₙ 无限接近的那个定数，记作 lim aₙ = A。

关键词是"无限接近"，不是"等于"。

**6. 函数极限**

x 无限接近 x₀（但不等于 x₀）时，f(x) 无限接近的定数。

那一点本身有没有定义，不影响极限。

**7. 左极限与右极限**

从左侧逼近记作 x → x₀⁻，从右侧逼近记作 x → x₀⁺。

极限存在的充要条件：左右极限都存在且相等。

**8. 无穷小**

极限为 0 的变量。

它是一个"过程量"，不是"很小的数"。

**9. 等价无穷小**

两个无穷小之比的极限为 1，记作 α ~ β。

乘除里可以互相替换，加减里不行。

**10. 连续**

函数在 x₀ 处的极限值等于函数值，即 lim f(x) = f(x₀)。

三个条件缺一不可：有定义、有极限、两者相等。

**11. 间断点**

不连续的点，分两类。

```text
第一类：左右极限都存在（可去间断、跳跃间断）
第二类：左右极限至少有一个不存在（无穷间断、振荡间断）
```

**12. 闭区间上连续函数的性质**

四条：有界性、最值性、介值性、零点定理。

零点定理最常用：两端异号，中间必有一点取零。

## 3. 术语表（二）：一元微分

**13. 导数**

变化率，几何上是切线斜率，定义是差商的极限。

```text
f'(x₀) = lim [f(x₀ + Δx) − f(x₀)] / Δx
```

**14. 可导与连续的关系**

可导必连续，连续不一定可导。

反例是 y = |x| 在 x = 0 处：连续，但左右导数不相等。

**15. 微分**

函数增量的线性主部，记作 dy = f'(x)dx。

它的意义是"用直线代替曲线"，做近似计算用。

**16. 高阶导数**

导数的导数，记作 f''、f'''、f⁽ⁿ⁾。

二阶导数的符号决定凹凸性。

**17. 隐函数求导**

方程 F(x, y) = 0 没有解出 y 时，两边同时对 x 求导，把 y 看成 x 的函数。

**18. 参数方程求导**

```text
dy/dx = (dy/dt) / (dx/dt) = y'(t)/x'(t)
```

二阶导数要再对 t 求一次，再除以 x'(t)。

**19. 罗尔定理**

闭区间连续、开区间可导、两端函数值相等，则中间必有一点的导数为零。

它是另外两个中值定理的基础。

**20. 拉格朗日中值定理**

```text
f(b) − f(a) = f'(ξ)(b − a)
```

一句话：平均变化率必在某一点被取到。

**21. 柯西中值定理**

两个函数版本的拉格朗日：

```text
[f(b) − f(a)] / [g(b) − g(a)] = f'(ξ)/g'(ξ)
```

要求 g'(x) ≠ 0。

**22. 泰勒公式**

用多项式逼近函数，带拉格朗日余项或皮亚诺余项。

```text
f(x) = f(x₀) + f'(x₀)(x − x₀) + … + f⁽ⁿ⁾(x₀)(x − x₀)ⁿ/n! + Rₙ
```

**23. 洛必达法则**

0/0 或 ∞/∞ 型，可以用"分子分母分别求导"的极限代替原极限。

用之前必须验证是这两种型。

**24. 驻点、极值与拐点**

```text
驻点：f'(x) = 0 的点。
极值点：函数值局部最大或最小的点，可能在驻点，也可能在不可导点。
拐点：凹凸性改变的点，看 f'' 是否变号。
```

三个概念互不包含，考试常拿它们互相设套。

## 4. 术语表（三）：一元积分

**25. 原函数**

若 F'(x) = f(x)，则 F 是 f 的一个原函数。

原函数有无穷多个，彼此只差常数。

**26. 不定积分**

全体原函数的集合，记作 ∫f(x)dx = F(x) + C。

那个 C 不能丢。

**27. 定积分**

把区间切成 n 段，每段"高乘宽"求和，再让 n 趋于无穷取极限。

它是一个数，几何上是曲边梯形的面积（带符号）。

**28. 变上限积分**

上限是变量的定积分，记作 Φ(x) = ∫ₐˣ f(t)dt。

它是 f 的一个原函数，所以 Φ'(x) = f(x)。

**29. 牛顿-莱布尼茨公式**

```text
∫ₐᵇ f(x)dx = F(b) − F(a)
```

它把"求和取极限"变成了"找原函数代两端"。

**30. 换元积分法**

第一类换元（凑微分）：把 ∫f[g(x)]g'(x)dx 变成 ∫f(u)du。

第二类换元：令 x = φ(t)，把难算的根式变成好算的三角式。

**31. 分部积分法**

```text
∫u dv = uv − ∫v du
```

用于两类不同函数相乘，选 u 的顺序是"反对幂指三"。

**32. 反常积分**

积分区间无限，或被积函数在区间内无界。

判敛散靠极限，不是靠"算出来是数"。

**33. 定积分的几何应用**

```text
面积：∫[f(x) − g(x)]dx
体积：π∫[f² − g²]dx（垫圈法）
弧长：∫√(1 + y'²)dx
```

**34. 定积分的物理应用**

功、水压力、质心、转动惯量。

统一写法：微元 = 某个量 × 某个小段，再积分。

**35. 积分中值定理**

```text
∫ₐᵇ f(x)dx = f(ξ)(b − a)，ξ 在 [a, b] 内
```

一句话：存在一点，使"平均高度"正好等于那一点的函数值。

**36. 积分的对称性**

奇函数在对称区间上积分为零，偶函数等于一半区间的两倍。

用之前先确认区间对称、函数奇偶。

## 5. 术语表（四）：多元、向量与曲线曲面

**37. 偏导数**

固定其余变量，只对一个变量求导，记作 ∂z/∂x。

读作"z 对 x 的偏导"。

**38. 全微分**

```text
dz = z_x dx + z_y dy
```

它要求函数"可微"，比"偏导存在"更强。

**39. 方向导数与梯度**

方向导数是沿某个方向的变化率，梯度是方向导数最大的方向。

```text
∂f/∂l = grad f · e_l
```

**40. 多元极值与拉格朗日乘数**

无条件极值用 AC − B² 判别。

条件极值用拉格朗日乘数法：∇f = λ∇g。

**41. 二重积分**

平面区域上的"面积分"，记作 ∬_D f(x, y)dσ。

极坐标下 dσ = r dr dθ。

**42. 三重积分**

空间区域上的"体积分"，记作 ∭_Ω f dV。

柱坐标 dV = r dr dθ dz，球坐标 dV = r² sin φ dr dφ dθ。

**43. 向量与数量积**

向量是有大小有方向的量。

数量积 a·b = |a||b|cos θ，结果是数，管夹角与垂直。

**44. 向量积与混合积**

向量积 a×b 垂直于两者，模是平行四边形面积。

混合积 (a×b)·c 是平行六面体的有向体积，等于零判共面。

**45. 平面与直线方程**

```text
平面：点法式 A(x−x₀) + B(y−y₀) + C(z−z₀) = 0
直线：对称式 (x−x₀)/m = (y−y₀)/n = (z−z₀)/p
```

平面的系数是法向量，直线的分母是方向向量。

**46. 第一类曲线积分**

对弧长的积分，记作 ∫_L f ds，与方向无关。

**47. 第二类曲线积分与格林公式**

对坐标的积分，记作 ∫_L P dx + Q dy，与方向有关。

闭合曲线正向时：∮_L P dx + Q dy = ∬_D (Q_x − P_y)dσ。

**48. 曲面积分与高斯、斯托克斯**

第一类对面积，第二类对坐标。

```text
高斯：闭合曲面 → 三重积分，被积函数是散度
斯托克斯：闭合曲线 → 曲面积分，被积函数是旋度
```

## 6. 术语表（五）：级数与微分方程

**49. 数项级数与收敛**

无穷多个数相加，部分和数列有极限就收敛。

收敛的必要条件是通项趋于零，不充分。

**50. 正项级数判别法**

```text
比值法：lim a_{n+1}/a_n = ρ，ρ < 1 收敛，ρ > 1 发散
根值法：lim ⁿ√aₙ = ρ，判据同上
比较法：与 p 级数、几何级数比
p 级数：∑1/n^p 在 p > 1 时收敛
```

**51. 交错级数与莱布尼茨判别**

形如 ∑(−1)ⁿuₙ。

uₙ 单调递减且趋于零时，级数收敛，且余项不超过下一项。

**52. 绝对收敛与条件收敛**

```text
绝对收敛：∑|aₙ| 收敛
条件收敛：∑aₙ 收敛，但 ∑|aₙ| 发散
```

绝对收敛一定收敛，反之不成立。

**53. 幂级数与收敛半径**

形如 ∑aₙ(x − x₀)ⁿ。

存在 R，使 |x − x₀| < R 时绝对收敛，大于 R 时发散。

**54. 和函数**

幂级数在收敛域内收敛到的那个函数。

求法：逐项求导或逐项积分，凑成几何级数。

**55. 泰勒级数与麦克劳林级数**

把函数展开成幂级数。

x₀ = 0 时叫麦克劳林级数。

**56. 傅里叶级数与狄利克雷条件**

把周期函数展开成三角级数。

狄利克雷条件保证展开收敛；间断点处的和等于左右极限的平均。

**57. 微分方程、阶、通解、特解**

含导数的方程。

最高阶导数的阶数就是方程的阶。

通解含与阶数相同个数的任意常数，特解不含任意常数。

**58. 可分离变量方程与齐次方程**

```text
可分离：y' = f(x)g(y) → 分离后两边积分
齐次：y' = f(y/x) → 令 u = y/x
```

**59. 一阶线性方程与伯努利方程**

```text
线性：y' + P(x)y = Q(x)，套通解公式
伯努利：y' + Py = Qyⁿ，令 z = y^(1−n) 化线性
```

**60. 二阶常系数线性方程与欧拉方程**

先写特征方程 r² + pr + q = 0，按判别式分三种情形。

欧拉方程 x²y'' + pxy' + qy = 0，令 x = eᵗ 化成常系数。

## 7. 公式速查（一）：极限、导数、积分

这一节只列式子和一句话说明，推导在各篇里。

符号读法先统一：

```text
∫（积分号）、∬（二重）、∭（三重）、∮（闭合积分）
∂（偏导）、Σ（求和）、lim（极限）、ln（自然对数）
∞（无穷）、⇒（推出）、⇔（等价于）、~（等价无穷小）
```

**两个重要极限。**

```text
lim (sin x)/x = 1        x → 0
lim (1 + 1/x)^x = e      x → ∞
lim (1 + x)^(1/x) = e    x → 0
```

**等价无穷小（x → 0）。**

```text
sin x ~ x,  tan x ~ x,  arcsin x ~ x,  arctan x ~ x
ln(1 + x) ~ x,  e^x − 1 ~ x
1 − cos x ~ x²/2
(1 + x)^α − 1 ~ αx
x − sin x ~ x³/6,  tan x − x ~ x³/3
```

记法：一次的一起记，二次、三次的各记一个"修正项"。

**泰勒展开（x → 0，写到需要的阶）。**

```text
e^x   = 1 + x + x²/2! + x³/3! + …
sin x = x − x³/3! + x⁵/5! − …
cos x = 1 − x²/2! + x⁴/4! − …
ln(1 + x) = x − x²/2 + x³/3 − …
(1 + x)^α = 1 + αx + α(α−1)x²/2 + …
```

**导数表。**

```text
(x^α)' = αx^(α−1)          (a^x)' = a^x ln a
(e^x)' = e^x                (log_a x)' = 1/(x ln a)
(sin x)' = cos x            (cos x)' = −sin x
(tan x)' = sec²x            (cot x)' = −csc²x
(arcsin x)' = 1/√(1−x²)     (arccos x)' = −1/√(1−x²)
(arctan x)' = 1/(1+x²)
```

**积分表（不定积分，都加 C）。**

```text
∫x^α dx = x^(α+1)/(α+1)      α ≠ −1
∫dx/x = ln|x|
∫e^x dx = e^x                ∫a^x dx = a^x/ln a
∫sin x dx = −cos x           ∫cos x dx = sin x
∫sec²x dx = tan x
∫dx/(1+x²) = arctan x
∫dx/√(1−x²) = arcsin x
∫dx/(a²+x²) = (1/a)arctan(x/a)
∫sec x dx = ln|sec x + tan x|
∫tan x dx = −ln|cos x|
```

**分部与换元的常用配对。**

```text
∫x e^x dx、∫x sin x dx、∫x ln x dx   → 分部
∫√(a²−x²) dx                          → x = a sin t
∫dx/(a²+x²)                           → x = a tan t
∫dx/√(x²±a²)                          → x = a sec t 或双曲
```

**定积分的应用公式。**

```text
面积     A = ∫ₐᵇ |f(x) − g(x)| dx
体积     V = π∫ₐᵇ [f²(x) − g²(x)] dx   （绕 x 轴）
柱壳     V = 2π∫ₐᵇ x f(x) dx          （绕 y 轴）
弧长     s = ∫ₐᵇ √(1 + y'²) dx
参数弧长 s = ∫ √(x'² + y'²) dt
侧面积   S = 2π∫ₐᵇ |f(x)|√(1 + f'²) dx
```

**反常积分的 p 判别。**

```text
∫₁^∞ dx/x^p   收敛 ⇔ p > 1
∫₀¹ dx/x^p    收敛 ⇔ p < 1
```

两个方向相反，别记混：无穷远处要"掉得快"，瑕点附近要"爆得慢"。

**华里士公式（点火公式）。**

```text
∫₀^(π/2) sinⁿx dx = ∫₀^(π/2) cosⁿx dx
n 为偶数：(n−1)!!/n!! · π/2
n 为奇数：(n−1)!!/n!!
```

## 8. 公式速查（二）：多元、向量、级数、方程

**偏导与全微分。**

```text
dz = z_x dx + z_y dy
复合：dz/dt = z_x·x'(t) + z_y·y'(t)
隐函数：F(x, y, z) = 0 → z_x = −F_x/F_z
```

**方向导数与梯度。**

```text
grad f = (f_x, f_y)
∂f/∂l = f_x cos α + f_y sin α = grad f · e_l
```

梯度方向是函数增长最快的方向，模是最大变化率。

**多元极值判别。**

```text
驻点处 A = f_xx, B = f_xy, C = f_yy
AC − B² > 0 且 A > 0  → 极小
AC − B² > 0 且 A < 0  → 极大
AC − B² < 0           → 不是极值（鞍点）
AC − B² = 0           → 判别失效，另想办法
```

**条件极值。**

```text
L = f + λg，解 ∇L = 0
```

**三种坐标的体积元。**

```text
直角：dV = dx dy dz
柱面：dV = r dr dθ dz        （dσ = r dr dθ）
球面：dV = r² sin φ dr dφ dθ
```

**向量三积。**

```text
a·b = a₁b₁ + a₂b₂ + a₃b₃ = |a||b|cos θ
a×b = (a₂b₃ − a₃b₂, a₃b₁ − a₁b₃, a₁b₂ − a₂b₁)
|a×b| = |a||b|sin θ = 平行四边形面积
[a b c] = (a×b)·c = 平行六面体有向体积
```

**平面、直线、距离。**

```text
平面：A(x−x₀) + B(y−y₀) + C(z−z₀) = 0
直线：(x−x₀)/m = (y−y₀)/n = (z−z₀)/p
点面距：|Ax₀+By₀+Cz₀+D| / √(A²+B²+C²)
点线距：|M₀M₁ × s| / |s|
异面距：|[s₁ s₂ M₁M₂]| / |s₁×s₂|
线面夹角：sin φ = |s·n|/(|s||n|)
```

**曲线与曲面积分三大公式。**

```text
格林：∮_L P dx + Q dy = ∬_D (Q_x − P_y) dσ
高斯：∯_Σ P dy dz + Q dz dx + R dx dy = ∭_Ω (P_x + Q_y + R_z) dV
斯托克斯：∮_Γ P dx + Q dy + R dz = ∬_Σ rot F · n dS
```

三者的共同结构：

```text
边界上的积分 = 内部"某种导数"的积分。
```

**幂级数展开（必背六个）。**

```text
1/(1−x) = Σxⁿ,  |x| < 1
e^x = Σxⁿ/n!
sin x = Σ(−1)ⁿx^(2n+1)/(2n+1)!
cos x = Σ(−1)ⁿx^(2n)/(2n)!
ln(1+x) = Σ(−1)^(n−1)xⁿ/n,  −1 < x ≤ 1
arctan x = Σ(−1)ⁿx^(2n+1)/(2n+1),  |x| ≤ 1
```

**收敛半径。**

```text
R = 1/ρ,  ρ = lim |a_{n+1}/a_n|
```

**傅里叶系数（周期 2l）。**

```text
aₙ = (1/l)∫_{−l}^{l} f(x)cos(nπx/l)dx
bₙ = (1/l)∫_{−l}^{l} f(x)sin(nπx/l)dx
f(x) ~ a₀/2 + Σ[aₙcos(nπx/l) + bₙsin(nπx/l)]
```

间断点处，级数的和等于左右极限的平均值。

**微分方程的解公式。**

```text
可分离：∫dy/g(y) = ∫f(x)dx
一阶线性：y = e^(−∫P dx)[∫Q e^(∫P dx)dx + C]
齐次：u = y/x，化成可分离
伯努利：z = y^(1−n)，化成一阶线性
```

**二阶常系数齐次通解。**

```text
r₁ ≠ r₂（实）：y = C₁e^(r₁x) + C₂e^(r₂x)
r₁ = r₂ = r：y = (C₁ + C₂x)e^(rx)
r = α ± βi：y = e^(αx)(C₁cos βx + C₂sin βx)
```

**非齐次特解形式。**

```text
右端 e^(λx)P_m(x)
λ 不是特征根 → Q_m(x)e^(λx)
λ 是单根     → x Q_m(x)e^(λx)
λ 是重根     → x² Q_m(x)e^(λx)
右端含 sin ωx / cos ωx：把 λ 换成 ωi，按同样规则
```

## 9. 易混对照（一）：第 1 到第 10 组

每组都用同一个格式：左边是什么，右边是什么，最后一句判据。

**第一组：极限存在 与 连续。**

```text
极限存在：x → x₀ 时 f(x) 有定值，不看 f(x₀)。
连续：极限值恰好等于 f(x₀)。
```

判据：连续 = 有定义 + 有极限 + 两者相等。

**第二组：可导 与 可微（一元）。**

```text
可导：f'(x₀) 存在。
可微：Δy = AΔx + o(Δx) 中的 A 存在。
```

一元里两者等价，且 A = f'(x₀)。

多元里不等价：偏导存在推不出可微。

**第三组：可导 与 连续。**

```text
可导 ⇒ 连续
连续 ⇏ 可导
```

反例：y = |x| 在 0 处连续，但左右导数一个 −1 一个 1。

**第四组：偏导存在 与 可微（多元）。**

```text
偏导存在：沿 x 轴、y 轴两个方向的差商有极限。
可微：所有方向的增量都能被同一个线性式逼近。
```

判据：偏导连续 ⇒ 可微；可微 ⇒ 偏导存在。两个箭头都不能反。

**第五组：定积分 与 不定积分。**

```text
不定积分：一族函数 F(x) + C。
定积分：一个数 F(b) − F(a)。
```

判据：看结果带不带 C，看有没有上下限。

**第六组：反常积分 与 定积分。**

```text
定积分：区间有限，被积函数有界。
反常积分：区间无限，或被积函数无界。
```

判据：先看区间，再看函数在区间内是否有瑕点。

**第七组：条件收敛 与 绝对收敛。**

```text
绝对收敛：∑|aₙ| 收敛。
条件收敛：∑aₙ 收敛，但 ∑|aₙ| 发散。
```

判据：先加绝对值判一次，不收敛再判原级数。

**第八组：级数收敛 与 级数的和。**

```text
收敛：部分和数列有极限，是一个判断。
和：那个极限的具体数值，是一个计算结果。
```

判据：题目问"是否收敛"只要结论，问"求和"才要算数值。

**第九组：二重积分 与 三重积分。**

```text
二重：区域是平面图形，微元 dσ，结果是"面积上的累加"。
三重：区域是空间立体，微元 dV，结果是"体积上的累加"。
```

判据：看区域是几维的，看微元是一个 d 还是三个 d。

**第十组：第一类曲线积分 与 第二类曲线积分。**

```text
第一类：∫_L f ds，对弧长，与方向无关。
第二类：∫_L P dx + Q dy，对坐标，换方向变号。
```

判据：被积式里有 dx、dy 就是第二类；只有 ds 就是第一类。

## 10. 易混对照（二）：第 11 到第 20 组

**第十一组：第一类曲面积分 与 第二类曲面积分。**

```text
第一类：∬_Σ f dS，对面积，与侧无关。
第二类：∬_Σ P dy dz + Q dz dx + R dx dy，对坐标，换侧变号。
```

判据：出现 dy dz 这类"两个微分的乘积"就是第二类。

**第十二组：格林、高斯、斯托克斯。**

```text
格林：平面闭合曲线 → 平面区域，被积函数是 Q_x − P_y。
高斯：空间闭合曲面 → 空间区域，被积函数是散度。
斯托克斯：空间闭合曲线 → 空间曲面，被积函数是旋度。
```

判据：看边界是曲线还是曲面，看维数升一维。

**第十三组：齐次方程 与 齐次线性方程。**

```text
一阶"齐次方程"：y' = f(y/x)，指右端只含 y/x。
"齐次线性方程"：y' + P(x)y = 0，指右端为零。
```

同一个词，两个意思，看上下文。

**第十四组：通解 与 特解。**

```text
通解：含与阶数相同个数的任意常数。
特解：不含任意常数，满足方程的一组具体解。
```

非齐次方程的通解 = 齐次通解 + 非齐次的一个特解。

**第十五组：极大值 与 最大值。**

```text
极大值：局部最大，只跟附近比。
最大值：整个区间上最大，要跟所有点比。
```

判据：极大值可能有多个，最大值只有一个（或并列）。

**第十六组：驻点 与 极值点。**

```text
驻点：f'(x) = 0 的点。
极值点：函数值局部最大或最小的点。
```

驻点不一定是极值点（如 y = x³ 在 0 处）；极值点也可能是不可导点。

**第十七组：拐点 与 极值点。**

```text
拐点：凹凸性改变的点，看 f'' 变号。
极值点：单调性改变的点，看 f' 变号。
```

判据：拐点看二阶导，极值看一阶导。

**第十八组：收敛半径 与 收敛域。**

```text
收敛半径：一个数 R，只管开区间 |x − x₀| < R。
收敛域：一个集合，要把两个端点单独判完才算完。
```

判据：收敛域 = 开区间 + 端点判断的结果。

**第十九组：ds、dσ、dV。**

```text
ds：弧长微元，用于曲线积分。
dσ：面积微元，用于二重积分与第一类曲面积分。
dV：体积微元，用于三重积分。
```

判据：数一数"被切的对象的维数"。

**第二十组：旋转面 与 柱面。**

```text
旋转面：一条曲线绕轴转出来的曲面，方程里三个变量都有。
柱面：一条直线沿曲线平移出来的曲面，方程里少一个变量。
```

判据：方程里有没有缺席的变量。

### 自检三问

**第一问：术语表要背到什么程度才算够？**

背到"能一句话说出来"就够，不需要背完整定义。

```text
能说"变上限积分求导还原被积函数"，比分毫不差地背出 Φ(x) 的定义有用。
```

因为考场上用的是那句话，不是那段定义。

**第二问：二十组易混里，哪几组最容易在考场丢分？**

按丢分频率排，前三名是：

```text
第一类与第二类曲线积分（方向、符号）
条件收敛与绝对收敛（多判一次的事）
收敛半径与收敛域（端点没判）
```

这三组有一个共同点：

```text
都是"多一步就对了"的题，少一步就错。
```

所以考场上遇到它们，多花三十秒检查那一步。

**第三问：三十条自检，打不上勾的怎么办？**
