> **读这篇之前，你只需要知道**：二重积分 ∬_D f(x,y) dσ 是把一块平面图形切成许多小方块，每块用"高乘面积"估一个数，全加起来再取极限；一元定积分是同样的想法，只是把区间切成小段，每段"高乘长度"。
> **这篇讲什么**：把平面图形换成空间里的一块立体，把"小面积"换成"小体积"，于是有了三重积分，再配三套坐标（直角、柱面、球面）把体积元换成好算的样子。
> **一个类比**：算一整块豆腐有多重，把它切成小方丁，每丁用"体积乘那一处的密度"，全加起来的极限就是总质量。

一块铁块，密度到处一样。

体积 10 立方厘米，每立方厘米 7.8 克，质量 78 克。

乘法一步到位。

现在把条件改掉：

```text
密度不再均匀。
越靠中心越紧，越靠边缘越松。
```

质量怎么算？

不能再用"体积乘密度"，因为没有一个统一的密度可乘。

只能切。

```text
切成许多小方块，
每块足够小，小到块内密度几乎不变，
每块算 "小块体积 × 该处密度"，
全部加起来。
```

块切得越细，总和越接近真值。

取极限，就是三重积分。

**这一篇要回答三件事：**

```text
∭ 这个符号在算什么？
dV 为什么有时变成 ρ dρ dθ dz，有时变成 r² sinφ dr dφ dθ？
给定一块立体，先对谁积分？
```

## 1. 为什么需要它（不给会怎样）

没有这一节，你会以为"积分"只有一种长相：一个 ∫，后面跟一个 dx。

遇到立体就会卡住。

具体卡在四个地方。

**第一处，二重积分处理不了"厚度方向在变"的东西。**

二重积分 ∬_D f(x,y) dσ 的自变量只有两个。

它管得住的场景是：一块平面薄片，密度只在平面内变化。

```text
薄片的厚度必须是个常数，或者已经被吸收进 f 里。
```

一旦物体是实心的、密度沿高度也变，两个人就描述不了三个方向的变化。

**第二处，没有符号写"在体积上累加"。**

把球体切成小块，求和，取极限。

用 Σ 能写，但写出来是：

```text
lim Σ f(ξᵢ, ηᵢ, ζᵢ) ΔVᵢ
```

这个式子在证明里够用，在计算里没法下手。

你需要的是一套像定积分那样能代公式、能换元、能查表的机器。

**第三处，直角坐标硬算球体会出根号。**

要求一个半径 a 的球体的体积。

用直角坐标，内层是：

```text
z 从 -√(a²-x²-y²) 到 +√(a²-x²-y²)
```

两个根号相减，再对 y 积，再对 x 积。

算得出来，但过程又长又容易错。

换成球坐标，三行结束：

```text
V = ∫₀^{2π} dθ ∫₀^{π} sinφ dφ ∫₀^a r² dr = 4πa³/3
```

差别不在技巧，在**坐标系和形状是否匹配**。

**第四处，物理量算不出来。**

转动惯量、质心、引力、电荷量，都要对立体做累加。

```text
质心 z̄ = ∭ z ρ dV / ∭ ρ dV
转动惯量 I_z = ∭ (x² + y²) ρ dV
```

分母就是"总质量"，分子就是"z 坐标的加权和"。

没有 ∭，这些定义写不出来。

所以这一章的定位很清楚：

```text
二重积分是"平面上的累积"，
三重积分是"立体上的累积"，
三套坐标是"把立体切得顺手"的三把刀。
```

## 2. 最小模型：∭ 与 dV 到底是什么

没有这一节，∭ 只是一个吓人的符号。

你知道它表示"在体积上累加"，却写不出定义，也判断不了 dV 什么时候要变形。

先读符号。

```text
∭        读作"三重积分号"，三个积分号叠在一起，表示在三维区域上累加
Ω        读作"欧米伽"，是积分区域，也就是那块立体
f(x,y,z) 被积函数，可以是密度、可以是 1、可以是 z
dV       读作"体积元"，是一小块体积，等于 dx dy dz
```

合起来：

```text
∭_Ω f(x,y,z) dV
```

读作"在区域 Ω 上，对 f 做三重积分"。

它的意思，按定义展开是这样的：

```text
把 Ω 切成 n 个小块 ΔV₁, ΔV₂, …, ΔVₙ
在每块里随便挑一个点，算出 f 在那里的值
乘起来：f(点) × 小块体积
全加起来：Σ f ΔV
让所有小块的最大直径趋于 0，取极限
```

写成式子：

```text
∭_Ω f dV = lim_{λ→0} Σ_{i=1}^{n} f(ξᵢ, ηᵢ, ζᵢ) ΔVᵢ
```

λ 是"所有小块里最胖的那块的直径"。

λ → 0 的意思是：不是块数变多，而是**最胖的块也变薄了**。

这一点和定积分、二重积分完全一致。

**这个定义告诉你三件事：**

```text
第一，∭ 就是"切碎、相乘、相加、取极限"，没有新东西。
第二，f = 1 时，∭_Ω 1 dV 就是 Ω 的体积。
第三，f 是密度时，∭_Ω ρ dV 就是 Ω 的质量。
```

**关于 dV：它不是一个符号，是一个乘积。**

直角坐标下：

```text
dV = dx dy dz
```

三个微分相乘，顺序随便换，因为乘法可交换。

```text
dx dy dz = dz dy dx = dy dx dz
```

但**换坐标系时，dV 会变形**，这是这一章最大的坑。

原因很实在：坐标一变，"一小块"的形状就变了。

在直角坐标里，dx、dy、dz 是三条互相垂直的边，小块是个长方体，体积就是三者相乘。

在柱坐标里，沿 θ 方向走一小步 dθ，实际走过的弧长不是 dθ，而是 ρ dθ。

半径越大，同样转一度，走的路越长。

所以那一小块是个"扇环柱"，体积里必须补上这个 ρ。

```text
柱坐标：dV = ρ dρ dθ dz
球坐标：dV = r² sinφ dr dφ dθ
```

先记住结论，第 4、6 节会分别把这两个因子推出来。

**公式四步：直角坐标下的三重积分。**

**第一步，算什么。**

```text
∭_Ω f(x,y,z) dV
= 把立体 Ω 投影到 xOy 平面上，得到平面区域 D，
  再从 D 里每个点往上穿一根竖线，穿过 Ω 的那一段就是 z 的范围。
```

**第二步，逐符号。**

```text
D           Ω 在 xOy 面上的投影（影子）
z₁(x,y)     竖线进入 Ω 的下表面
z₂(x,y)     竖线离开 Ω 的上表面
∫_{z₁}^{z₂} 内层积分，把 x、y 当常数，只对 z 积
∬_D        外层，在影子上做二重积分
```

写成：

```text
∭_Ω f dV = ∬_D [ ∫_{z₁(x,y)}^{z₂(x,y)} f(x,y,z) dz ] dx dy
```

这个顺序叫**先一后二**：先对 z 积一次，再对 x、y 积两次。

**第三步，代数字。**

取 Ω 为单位立方体 0 ≤ x ≤ 1，0 ≤ y ≤ 1，0 ≤ z ≤ 1，f = xyz。

```text
∭ xyz dV = ∫₀¹ dx ∫₀¹ dy ∫₀¹ xyz dz
内层：∫₀¹ xyz dz = xy · (1/2) = xy/2
中层：∫₀¹ xy/2 dy = x/4
外层：∫₀¹ x/4 dx = 1/8
```

结果是 1/8。

验算一下：三个变量完全对称，所以结果应是 (∫₀¹x dx)³ = (1/2)³ = 1/8。

对上了。

**第四步，适用条件。**

```text
第一，Ω 在 xOy 面上的投影是"能写清上下曲线"的区域。
第二，每条竖线与 Ω 的交集是一段（不能穿出再穿进）。
第三，f 在 Ω 上连续（本题都满足）。
```

第二条最容易被忽略。

如果一个立体像"哑铃"，一根竖线穿进去、出来、再进去，就必须**拆成两块分别积**。

```text
不是积分公式错了，是这根竖线违反了"一段"的要求。
```

**还有第二种切法：先二后一，也叫截面法。**

```text
∭_Ω f dV = ∫_{c}^{d} dz ∬_{D_z} f(x,y,z) dx dy
```

意思是：把立体像切吐司一样横着切片。

固定 z，切出一片 D_z，先在这一片上做二重积分，再沿 z 把所有片加起来。

什么时候用它？

```text
被积函数只含 z（或者对 x、y 好积），而截面积好算时。
```

比如球体、圆锥、旋转体，截面都是圆，面积一眼可得。

## 3. 算一遍：直角坐标下的三重积分

没有手算这一步，公式会停在纸面上。

你会知道"先一后二"这四个字，却不知道投影该写在哪一步、"一段"该怎么检查。

题目：

```text
Ω 是四面体：x + y + z ≤ 1，x ≥ 0，y ≥ 0，z ≥ 0。
求 I = ∭_Ω (x + y + z) dV
```

先画图，确认形状。

```text
        z
        │  (0,0,1)
        │ ╱
        │╱
        ●─────── y  (0,1,0)
       ╱
      ╱
     x (1,0,0)
```

三个坐标轴上的截点都是 1，再加原点，围成一个四面体。

**第一步：写投影。**

投到 xOy 平面上，影子是三角形：

```text
D：x ≥ 0，y ≥ 0，x + y ≤ 1
```

固定 (x, y) 在 D 内，竖线从 z = 0 穿到 z = 1 - x - y。

```text
下表面：z = 0（xOy 平面）
上表面：z = 1 - x - y（斜面）
```

**第二步：写累次积分。**

```text
I = ∫₀¹ dx ∫₀^{1-x} dy ∫₀^{1-x-y} (x + y + z) dz
```

**第三步：一层一层积。**

内层，把 x、y 看成常数：

```text
∫₀^{1-x-y} (x + y + z) dz
= (x+y)z + z²/2 在 z = 1-x-y 处的值
= (x+y)(1-x-y) + (1-x-y)²/2
```

上面这一步能算，但式子会越滚越长。

**换个办法：先看对称性。**

区域 Ω 的方程 x + y + z ≤ 1 对三个变量完全对称。

在 Ω 里把 x 和 y 互换，区域不变。

所以：

```text
∭ x dV = ∭ y dV = ∭ z dV
```

于是：

```text
I = ∭(x+y+z) dV = 3 ∭ x dV
```

只需要算一个。

```text
∭_Ω x dV = ∫₀¹ x dx ∫₀^{1-x} dy ∫₀^{1-x-y} dz
```

最内层最简单，因为它对 z 积的是常数 1：

```text
∫₀^{1-x-y} 1 dz = 1 - x - y
```

中层：

```text
∫₀^{1-x} (1 - x - y) dy
= [(1-x)y - y²/2]₀^{1-x}
= (1-x)² - (1-x)²/2
= (1-x)²/2
```

几何意义：固定 x 时，截面三角形的面积就是 (1-x)²/2。

外层：

```text
∫₀¹ x · (1-x)²/2 dx
= (1/2) ∫₀¹ (x - 2x² + x³) dx
= (1/2)(1/2 - 2/3 + 1/4)
= (1/2)(1/12)
= 1/24
```

所以：

```text
I = 3 × 1/24 = 1/8
```

**第四步：验算。**

用"平均值"估一下。

四面体的体积是：

```text
V = ∫₀¹ (1-x)²/2 dx = (1/2)(1/3) = 1/6
```

f = x + y + z 在 Ω 上的平均值应当是：

```text
I / V = (1/8) / (1/6) = 3/4
```

而 x 的平均值是 (1/24)/(1/6) = 1/4。

三个变量的平均加起来正好 3/4。

对上了。

**这个例子给了一条经验：**

```text
区域对称 + 被积函数是单项式 → 先用对称性，把三项变成一项。
省下的不只是时间，还有出错的机会。
```

**换一种切法，验算一遍。**

这个四面体横着切片很好写。

固定 z（0 ≤ z ≤ 1），截面是：

```text
D_z：x ≥ 0，y ≥ 0，x + y ≤ 1 - z
```

这是个直角边长为 1 - z 的等腰直角三角形，面积：

```text
S(z) = (1 - z)²/2
```

于是体积可以只用一次一元积分算出来：

```text
V = ∫₀¹ S(z) dz = ∫₀¹ (1-z)²/2 dz = (1/2)(1/3) = 1/6
```

和前面一致。

更妙的是，分子也能这样算：

```text
∭ z dV = ∫₀¹ z S(z) dz = ∫₀¹ z(1-z)²/2 dz
= (1/2) ∫₀¹ (z - 2z² + z³) dz
= (1/2)(1/2 - 2/3 + 1/4)
= (1/2)(1/12)
= 1/24
```

由对称性，∭ x dV 和 ∭ y dV 也是 1/24。

三者相加：

```text
∭(x+y+z) dV = 3/24 = 1/8
```

和前面用"先一后二"得到的结果完全一样。

**这个对比说明一件事：**

```text
先一后二和先二后一不是两种数学，是同一块立体切两刀。
截面好算时，先二后一往往少写两行。
```

顺便得到质心高度：

```text
z̄ = (1/24)/(1/6) = 1/4
```

四面体的顶点是 (0,0,0)、(1,0,0)、(0,1,0)、(0,0,1)。

四个顶点坐标的平均是 (1/4, 1/4, 1/4)，正好对上。

三角形、四面体的质心都是顶点坐标的算术平均，这个结论可以当速查表用。

## 4. 拆开看：柱坐标与 dV = ρ dρ dθ dz

先说没有它会怎样。

```text
Ω 是圆柱、圆锥、旋转抛物面围成的体，
被积函数含 x² + y²。
```

用直角坐标，边界写成 z = √(x²+y²)，内层带根号。

投影是圆，外层积分限也要写成 ±√(1-x²)。

两层根号，算到第三行就想放弃。

柱坐标就是为这种形状准备的。

**定义：把平面上的极坐标，直接往 z 方向拉长。**

```text
x = ρ cosθ
y = ρ sinθ
z = z
```

三个新坐标：

```text
ρ  读作"rho"，是点到 z 轴的距离，ρ ≥ 0
θ  读作"theta"，是投影点与 x 轴正向的夹角，0 ≤ θ ≤ 2π
z  不变，就是高度
```

注意 ρ 的含义：它是**到 z 轴的距离**，不是到原点的距离。

这是它和球坐标最大的区别。

**为什么 dV = ρ dρ dθ dz？**

看一小块。

```text
ρ 方向：走 dρ，长度 dρ
θ 方向：转 dθ，走过的弧长是 ρ dθ
z 方向：走 dz，长度 dz
```

三条边互相垂直，所以体积是三边相乘：

```text
dV = dρ × (ρ dθ) × dz = ρ dρ dθ dz
```

那个 ρ 的来源只有一句话：

```text
离轴越远，转同样的角度，走的路越长，弧长 = 半径 × 角。
```

ρ = 0 时弧长为 0，所以轴上的"小块"退化了，这也是 ρ 必须写出来的原因。

漏掉 ρ，算出来的结果永远偏小，而且偏心（近轴的部分被低估得更多）。

**公式四步：柱坐标下的三重积分。**

**第一步，算什么。**

```text
把 Ω 投影到 xOy 平面上，得到极坐标下的区域 D_ρθ，
再从每个 (ρ, θ) 往上穿一根平行于 z 轴的线。
```

**第二步，逐符号。**

```text
ρ 从 ρ₁(θ) 到 ρ₂(θ)     影子的内外边界
θ 从 α 到 β               影子的角度范围
z 从 z₁(ρ,θ) 到 z₂(ρ,θ)   下表面到上表面
```

写成：

```text
∭_Ω f dV = ∫_α^β dθ ∫_{ρ₁(θ)}^{ρ₂(θ)} ρ dρ ∫_{z₁}^{z₂} f(ρcosθ, ρsinθ, z) dz
```

ρ 放在哪个位置都行（乘法可交换），但习惯写在 dρ 旁边，提醒自己别丢。

**第三步，代数字。**

取 Ω 为单位圆柱：x² + y² ≤ 1，0 ≤ z ≤ 1，f = z。

```text
∭ z dV = ∫₀^{2π} dθ ∫₀¹ ρ dρ ∫₀¹ z dz
= 2π × (1/2) × (1/2)
= π/2
```

验算：圆柱体积 π，z 的平均值 1/2，乘积 π/2。

对上了。

**第四步，适用条件。**

```text
第一，Ω 的投影是圆、圆环、扇形这类极坐标好写的区域。
第二，上下表面能写成 z = z(ρ, θ) 的单值函数。
第三，被积函数里出现 x² + y²、√(x²+y²) 这类组合。
```

第三条是判断信号：看到 x² + y²，先想柱坐标。

**常见的柱坐标边界对照：**

```text
x² + y² = a²          圆柱面，ρ = a
z = x² + y²           旋转抛物面，z = ρ²
z = √(x² + y²)        圆锥面，z = ρ
x² + y² = 2z          抛物面，ρ² = 2z，即 z = ρ²/2
```

## 5. 算一遍：柱坐标下的三重积分

没有这一节，ρ 永远是"多出来的一个字母"。

你会在考场上反复问自己：这个 ρ 到底该写还是在 dρ 前面，写了又该放在哪一层。

题目：

```text
Ω 由旋转抛物面 z = x² + y² 与平面 z = 1 围成。
求 ∭_Ω z dV
```

**先看形状。**

抛物面开口朝上，顶点在原点，被 z = 1 这个平面盖住。

所以 Ω 是"碗里装满到碗口"的那块。

```text
        z = 1  ─────────────
              ╲         ╱
               ╲       ╱
                ╲     ╱
                 ╲___╱   ← z = x² + y²
```

**定坐标：用柱坐标。**

两个理由：

```text
边界含 x² + y²，投影是圆。
抛物面在柱坐标下就是 z = ρ²，没有根号。
```

**定积分限。**

投影：抛物面与 z = 1 的交线是 x² + y² = 1，所以影子是单位圆。

```text
0 ≤ θ ≤ 2π
0 ≤ ρ ≤ 1
```

竖线方向：从抛物面进，从平面出。

```text
ρ² ≤ z ≤ 1
```

**写式子。**

```text
∭_Ω z dV = ∫₀^{2π} dθ ∫₀¹ ρ dρ ∫_{ρ²}^{1} z dz
```

**一层一层积。**

内层：

```text
∫_{ρ²}^{1} z dz = [z²/2]_{ρ²}^{1} = (1 - ρ⁴)/2
```

中层：

```text
∫₀¹ ρ · (1 - ρ⁴)/2 dρ
= (1/2) ∫₀¹ (ρ - ρ⁵) dρ
= (1/2)(1/2 - 1/6)
= (1/2)(1/3)
= 1/6
```

外层：

```text
∫₀^{2π} (1/6) dθ = 2π/6 = π/3
```

所以：

```text
∭_Ω z dV = π/3
```

**顺手把体积和质心也算出来。**

体积：

```text
V = ∫₀^{2π} dθ ∫₀¹ ρ dρ ∫_{ρ²}^{1} dz
= 2π ∫₀¹ ρ(1 - ρ²) dρ
= 2π (1/2 - 1/4)
= π/2
```

这就是"碗"的容积。

质心高度：

```text
z̄ = ∭ z dV / ∭ 1 dV = (π/3) / (π/2) = 2/3
```

**这个结果值得停一下。**

碗口的 z 是 1，碗底的 z 是 0。

质心在 2/3 处，比中间（1/2）高。

合理吗？

合理。

```text
碗的上半部分比下半部分"胖"。
越往上，截面圆的半径越大，材料越多，
所以质心被拉高了。
```

如果反过来是"锥形漏斗"（上宽下窄更极端），质心会更高。

**如果这里用直角坐标会怎样？**

内层：

```text
z 从 x² + y² 到 1
```

这一步还好。

中层：

```text
∫_{-√(1-x²)}^{√(1-x²)} ...
```

根号出现了。

外层再套一个根号。

能算，但要花三倍时间，且容易在根号上出错。

**这就是"选坐标"的全部意义：**

```text
不是直角坐标不行，是它和形状不匹配。
匹配的坐标，把根号变没有，把圆变成长方形。
```

## 6. 拆开看：球坐标与 dV = r² sinφ dr dφ dθ

先说没有它会怎样。

```text
Ω 是球体、球壳、球的一部分，
被积函数含 x² + y² + z²。
```

用柱坐标，边界是 z = √(a² - ρ²)，还是根号。

投影是圆，但上下表面都弯，内层要算两次根号。

球坐标是为"球"准备的。

**定义：用"离原点多远"加"两个角度"定位。**

```text
x = r sinφ cosθ
y = r sinφ sinθ
z = r cosφ
```

三个坐标：

```text
r  读作"r"，是点到原点的距离，r ≥ 0
φ  读作"phi"，是向量与 z 轴正向的夹角，0 ≤ φ ≤ π
θ  读作"theta"，是投影点与 x 轴正向的夹角，0 ≤ θ ≤ 2π
```

**φ 和 θ 千万别搞反。**

一个记忆法：

```text
φ 是"从北极往下量"的角度，像纬度但起点在北极。
θ 是"绕 z 轴转圈"的角度，像经度。
```

```text
北极：φ = 0
赤道：φ = π/2
南极：φ = π
```

所以上半球的 φ 范围是 0 到 π/2。

圆锥面 z = √(x²+y²) 的方程是 φ = π/4，因为那条线与 z 轴成 45 度。

**常见曲面的球坐标方程：**

```text
x² + y² + z² = a²    球面，r = a
z = √(x² + y²)       圆锥面，φ = π/4
z = √(3(x²+y²))      圆锥面，φ = π/6（更陡）
z = 0                xOy 平面，φ = π/2
```

**为什么 dV = r² sinφ dr dφ dθ？**

这次三条边不再是直角坐标的三条。

先看三条"弧"：

```text
沿 r 方向：走 dr，长度 dr
沿 φ 方向：转 dφ，走的弧长是 r dφ（半径是 r）
沿 θ 方向：转 dθ，走的弧长是 r sinφ dθ
```

第三条为什么多一个 sinφ？

因为绕 z 轴转圈时，转轴是 z 轴，点到 z 轴的距离是 r sinφ，不是 r。

```text
赤道上 sinφ = 1，走得最远。
靠近极点 sinφ → 0，转一圈几乎不动。
```

三条弧两两垂直，小块近似为长方体，体积相乘：

```text
dV = dr × (r dφ) × (r sinφ dθ) = r² sinφ dr dφ dθ
```

两个因子各管一件事：

```text
r²     管"离原点越远，同样的角度跨得越开"
sinφ   管"越靠近极点，绕轴转的圈子越小"
```

**公式四步：球坐标下的三重积分。**

**第一步，算什么。**

```text
把区域 Ω 用 r、φ、θ 的范围描述，
然后按 r、φ、θ 的顺序做三次一元积分。
```

**第二步，逐符号。**

```text
r 从 r₁(φ,θ) 到 r₂(φ,θ)    沿射线的进出位置
φ 从 φ₁ 到 φ₂               上下张角
θ 从 θ₁ 到 θ₂               绕轴转的范围
体积元 r² sinφ dr dφ dθ     不能漏
```

写成：

```text
∭_Ω f dV = ∫_{θ₁}^{θ₂} dθ ∫_{φ₁}^{φ₂} sinφ dφ ∫_{r₁}^{r₂} f · r² dr
```

（把 sinφ 提到 φ 的积分旁边，是为了少写字，位置可以换。）

**第三步，代数字。**

求半径 a 的球体体积。

```text
r: 0 → a
φ: 0 → π
θ: 0 → 2π

V = ∫₀^{2π} dθ ∫₀^{π} sinφ dφ ∫₀^{a} r² dr
= 2π × 2 × a³/3
= 4πa³/3
```

中间那个 ∫₀^π sinφ dφ = 2，因为 -cosφ 从 0 到 π 是 1 - (-1) = 2。

对上了。

**第四步，适用条件。**

```text
第一，Ω 的边界是球面、锥面，或者它们的组合。
第二，被积函数是 r 的函数，或者含 x²+y²+z²。
第三，射线从原点出发，与 Ω 的交集是一段。
```

第三条要注意：如果 Ω 把原点包在里面，r 的下限是 0；如果 Ω 是一个球壳，下限就是内半径。

如果射线穿过 Ω 后出去又进来（比如两个分离的球），必须拆。

## 7. 算一遍：球坐标下的三重积分

没有这一步，φ 和 θ 永远会混。

定义看懂了，一上手还是把"从北极往下量"写成"绕轴转一圈"。

题目：

```text
Ω 是上半球体：x² + y² + z² ≤ a²，z ≥ 0。
求 ∭_Ω z dV
```

**定坐标：球坐标。**

```text
边界是球面，被积函数只含 z，而 z = r cosφ。
```

**定限。**

```text
r: 0 → a          从原点到球面
φ: 0 → π/2        从北极到赤道（z ≥ 0 就是 φ ≤ π/2）
θ: 0 → 2π         整圈
```

**写式子。**

```text
∭_Ω z dV = ∫₀^{2π} dθ ∫₀^{π/2} sinφ dφ ∫₀^{a} (r cosφ) · r² dr
```

注意三处都写对了才成立：

```text
z 换成 r cosφ
体积元补上 r² sinφ
sinφ 已经在 dφ 前面
```

**一层一层积。**

最内层对 r：

```text
∫₀^a r³ cosφ dr = cosφ · a⁴/4
```

中层对 φ：

```text
∫₀^{π/2} sinφ cosφ dφ = 1/2
```

（因为 sinφcosφ = (1/2)sin2φ，积分得 1/2。）

外层对 θ：

```text
∫₀^{2π} (a⁴/4)(1/2) dθ = 2π · a⁴/8 = πa⁴/4
```

所以：

```text
∭_Ω z dV = πa⁴/4
```

**验算。**

上半球的体积是 2πa³/3。

质心高度 z̄ 满足：

```text
z̄ = (πa⁴/4) / (2πa³/3) = (πa⁴/4) × (3/(2πa³)) = 3a/8
```

3a/8 ≈ 0.375a。

上半球的"重心"在 0.375a 处，比半球的中点 0.5a 低。

合理：

```text
半球是"下宽上窄"的形状：z 越大，截面圆越小。
材料集中在低处，所以质心被压到 0.5a 以下。
```

对比第 5 节的"碗"：

```text
碗：z 越大，截面圆越大（上宽下窄），质心 2/3 > 1/2。
半球：z 越大，截面圆越小（下宽上窄），质心 3a/8 < a/2。
```

两个形状的"宽窄方向"相反，质心偏离中点的方向也相反。

这条规律可以当快速验算用：

```text
先看截面是变大还是变小，再判断质心该偏高还是偏低。
算出来方向不对，就回去查分子分母有没有写反。
```

**再看一个数一常见的例子。**

题目：

```text
求 ∭_Ω e^{(x²+y²+z²)^{3/2}} dV，其中 Ω 是单位球 x² + y² + z² ≤ 1。
```

被积函数里的指数是 (x²+y²+z²)^{3/2}，而 x²+y²+z² = r²。

所以指数就是 r³。

```text
∭ e^{r³} dV = ∫₀^{2π} dθ ∫₀^{π} sinφ dφ ∫₀^{1} e^{r³} r² dr
```

前面的角度部分：

```text
∫₀^{2π} dθ = 2π
∫₀^{π} sinφ dφ = 2
```

合起来 4π。

对 r 的部分，注意 d(r³) = 3r² dr，所以 r² dr = d(r³)/3：

```text
∫₀¹ e^{r³} r² dr = (1/3) ∫₀¹ e^{u} du = (1/3)(e - 1)
```

其中 u = r³。

总数：

```text
4π × (1/3)(e - 1) = 4π(e - 1)/3
```

**这个例子说明一件事：**

```text
球坐标不只用来"化简区域"，也用来"化简被积函数"。
看到 x²+y²+z²，就算区域是立方体，也值得想一想球坐标。
```

当然，如果区域是立方体，球坐标的积分限会很难写。

那时候就该反过来：区域优先，坐标服从区域。

## 8. 对称性：先看奇偶，再动手

这一节讲一个"不算就能得 0"的工具。

没有它，你会把大量时间花在"算出来是 0"的积分上。

**第一条：奇函数在对称区域上积分为 0。**

```text
若 Ω 关于 xOy 平面对称（即 (x,y,z) ∈ Ω 时 (x,y,-z) ∈ Ω），
且 f(x,y,-z) = -f(x,y,z)，
则 ∭_Ω f dV = 0。
```

道理和二重积分完全一样：

```text
上下对称的两个小块，体积相同，函数值一个正一个负，
配对相加正好抵消。
```

用法：

```text
Ω 是球体 x²+y²+z² ≤ a²，求 ∭ z dV。
```

球体关于 xOy 平面对称，z 是奇函数。

```text
答案直接是 0。
```

再比如：

```text
∭ xyz dV 在球体上 = 0（对 x 是奇函数）
∭ z² dV 在球体上 ≠ 0（偶函数，要算）
```

**第二条：轮换对称，把三项并成一项。**

```text
若把 x、y、z 任意互换，区域 Ω 不变，
则 ∭ x dV = ∭ y dV = ∭ z dV。
```

第 3 节的四面体就用了这一条。

再举一个：

```text
Ω：x² + y² + z² ≤ 1，求 ∭ (x + y + z)² dV。
```

展开：

```text
(x+y+z)² = x² + y² + z² + 2xy + 2yz + 2zx
```

交叉项 2xy 关于 x 是奇函数（固定 y、z 时），区域对称，积分为 0。

同理 2yz、2zx 也是 0。

剩下：

```text
∭ (x²+y²+z²) dV = 3 ∭ z² dV
```

而 ∭ z² dV 用球坐标：

```text
∫₀^{2π} dθ ∫₀^{π} sinφ cos²φ dφ ∫₀¹ r⁴ dr
= 2π × (2/3) × (1/5)
= 4π/15
```

所以答案是 3 × 4π/15 = 4π/5。

**第三条：对称性只能用在"区域真的对称"时。**

反例：

```text
Ω：x² + y² + z² ≤ 1，z ≥ 0（上半球），求 ∭ z dV。
```

区域关于 xOy 平面**不**对称（只有上半）。

所以不能用奇偶性得 0，答案就是第 7 节的 πa⁴/4（取 a = 1 得 π/4）。

**这一条错误的后果很严重：**

```text
把 π/4 写成 0，整道题白做。
```

判断方法只有一句：

```text
把区域画出来，问自己：把 z 换成 -z，点还在不在区域里？
```

## 9. 三种坐标怎么选：一张决策表

先说什么都没有会怎样。

```text
拿到题就套直角坐标，算到第三行发现根号套根号，
再回头换坐标，前面写的全废。
```

选坐标应该在动笔之前定。

**决策表：**

```text
看区域边界              看被积函数            选什么
─────────────────────────────────────────────────
长方体、四面体           多项式               直角坐标
圆柱、旋转体、投影是圆    含 x²+y²             柱坐标
球、锥、球壳             含 x²+y²+z²          球坐标
```

三条补充规则：

```text
第一，区域优先。区域用哪种坐标好写，就用哪种，哪怕被积函数不配合。
第二，被积函数次优先。区域两种都行时，看函数。
第三，都不顺时，想想能不能用对称性砍掉一部分。
```

**再补一张"先一后二还是先二后一"的表。**

```text
先一后二（投影法）：
  适合：上下表面都是显式曲面 z = z(x,y)，投影区域好写。
  代价：外层要做二重积分，投影区域复杂时麻烦。

先二后一（截面法）：
  适合：被积函数只含 z，或者截面 D_z 的面积好算（圆、正方形）。
  代价：要能写出"固定 z 时的截面"。
```

截面法的典型例子：

```text
Ω：x² + y² + z² ≤ a²，求 ∭ z² dV。
```

固定 z，截面是圆 x² + y² ≤ a² - z²，面积 π(a² - z²)。

```text
∭ z² dV = ∫_{-a}^{a} z² · π(a² - z²) dz
= π ∫_{-a}^{a} (a²z² - z⁴) dz
= π [a² · (2a³/3) - (2a⁵/5)]
= π (2a⁵/3 - 2a⁵/5)
= π · 2a⁵ · (2/15)
= 4πa⁵/15
```

一行写完，比球坐标还快。

（用球坐标也能算：2π × ∫₀^π sinφcos²φ dφ × a⁵/5 = 2π × (2/3) × a⁵/5 = 4πa⁵/15。两条路殊途同归，可以互相验算。）

**一个实用习惯：**

```text
算完用另一种方法估一下量级。
体积乘被积函数的典型值，应该和答案同阶。
```

## 10. 常见错误

不列一份错误清单，同一个坑会踩三遍：漏因子、写反限、误用对称性。

**错误一：漏掉体积元里的因子。**

```text
错：∭ f dρ dθ dz
对：∭ f ρ dρ dθ dz
```

```text
错：∭ f dr dφ dθ
对：∭ f r² sinφ dr dφ dθ
```

这是这一章最高频的失分点。

检查方法：

```text
用 f = 1 算体积，看结果对不对。
球体积应为 4πa³/3，柱体积应为 πa²h。
```

**错误二：φ 和 θ 用反。**

```text
错：把上半球写成 θ: 0 → π/2
```

θ 是绕 z 轴的角度，一整圈 2π。

φ 才是"从北极往下"的角度。

```text
上半球：φ 从 0 到 π/2，θ 从 0 到 2π。
```

**错误三：把 ρ 当成到原点的距离。**

柱坐标的 ρ 是到 **z 轴**的距离。

球坐标的 r 才是到原点的距离。

```text
柱坐标下 ρ = 1 是一个圆柱面。
球坐标下 r = 1 是一个球面。
```

**错误四：上下限交叉。**

内层的上下限只能含**外层变量**。

```text
对：z 从 z₁(x,y) 到 z₂(x,y)，只含 x、y
错：z 从 z₁(x,y,z) 到 …（自己含自己）
```

对 ρ、φ 也一样：

```text
ρ 的上限可以含 θ，不能含 ρ。
φ 的上限可以含 θ，不能含 r。
```

**错误五：区域不满足"一段"却硬套公式。**

```text
Ω 由 z = x² + y² 与 z = 2 - x² - y² 围成。
```

这两张曲面交于 x² + y² = 1。

立体是"上下两个碗扣在一起"，形状像个橄榄。

竖线从下碗进、上碗出，只有一段，可以直接积。

但如果区域是"甜甜圈"（环面），一根竖线可能穿两段，必须拆。

```text
判断方法：把区域画出来，随便画一根平行于积分方向的线，数交点。
```

**错误六：对称性误用。**

```text
区域不对称，却按对称砍成 0。
区域对称，但函数不是奇函数，却当成 0。
```

两个条件必须同时满足。

**错误七：把 ∭ 写成 ∬。**

```text
三重积分号是三个 ∫ 叠起来，二重是两个。
```

这不是美观问题：写错说明脑子里还在想二维。

**错误八：内层积分上限写成了常数，但它其实是变量。**

```text
错：∫₀¹ dx ∫₀¹ dy ∫₀¹ f dz（区域明明是斜面）
```

内层的上限如果是曲面，就必须写成 z₂(x, y)。

反过来，如果区域真是长方体，写成变量也未必错，但多半说明没看懂区域。

**一张开算前的检查清单：**

```text
□ 区域画了没有？投影是什么形状？
□ 坐标选对了吗（直角 / 柱面 / 球面）？
□ 体积元写对了吗（ρ、r² sinφ 有没有）？
□ 三层限里，内层只含外层变量吗？
□ 对称性能不能用？用了之后区域还对称吗？
□ 算完用体积或质心方向验算了吗？
```

六条全过，基本不会失分。

## 11. 数一怎么考

不知道考法，你会把时间花在大段证明上。

而这一章的分数，九成落在计算和定限上。

**题型一：直接计算。**

给区域、给函数，要求算出数值。

这是主流，占分最多。

**题型二：交换积分次序。**

给一个累次积分，要求换成另一种顺序。

```text
核心动作：把积分限翻译成区域，再把区域按新顺序重新描述。
```

三重积分的交换比二重积分更花时间，但套路一样。

```text
第一步：由现有限写出 Ω 的不等式组。
第二步：画出 Ω（或者画它的投影）。
第三步：按新顺序重新穿线。
```

**题型三：截面法求旋转体。**

```text
Ω 由 y = x² 绕 y 轴旋转而成，与 y = 4 围成。
```

旋转体，截面是圆，半径 √y。

```text
V = ∫₀⁴ π y dy = 8π
```

（这是"先二后一"的直接应用。）

**题型四：质心、转动惯量。**

```text
z̄ = ∭ z dV / ∭ dV
I_z = ∭ (x² + y²) dV（密度为 1 时）
```

**题型五：与曲面积分结合。**

高斯公式把曲面积分变成三重积分：

```text
∬_Σ P dy dz + Q dz dx + R dx dy = ∭_Ω (∂P/∂x + ∂Q/∂y + ∂R/∂z) dV
```

所以三重积分算得快，15 篇才能算得快。

这是 15 篇的主线，这里先记个位置。

**题型六：估值与比较。**

不要求算出精确值，只要证明它落在某个区间内。

工具是积分的保号性：

```text
若在 Ω 上 m ≤ f ≤ M，则 m·V ≤ ∭_Ω f dV ≤ M·V
```

例：

```text
Ω 是单位球（V = 4π/3），f = x² + y² + z² ≤ 1。
```

因为 0 ≤ f ≤ 1，且在球内 f 的平均值是：

```text
∭ r² dV / V = (4π/5)/(4π/3) = 3/5
```

所以：

```text
0 ≤ ∭ (x²+y²+z²) dV = 4π/5 ≤ 4π/3
```

右边等于 M·V = 1 × 4π/3，对上了。

这类题在填空里常以"比较大小"出现：

```text
∭ x dV 与 ∭ x² dV 谁大？
```

在 0 ≤ x ≤ 1 上，x² ≤ x，所以后者不一定大，要看区域。

```text
若 Ω 完全落在 0 ≤ x ≤ 1 内，则 ∭ x² dV ≤ ∭ x dV。
```

判断的依据永远是"逐个点比较被积函数"，而不是"看起来谁大"。

**一道完整的数一风格例题。**

```text
Ω 由 z = x² + y² 与 z = 4 围成，求 Ω 的质心高度 z̄。
```

区域是"抛物面碗"装到 z = 4。

投影：x² + y² = 4，圆，半径 2。

```text
0 ≤ θ ≤ 2π，0 ≤ ρ ≤ 2，ρ² ≤ z ≤ 4
```

体积：

```text
V = ∫₀^{2π} dθ ∫₀² ρ dρ ∫_{ρ²}^{4} dz
= 2π ∫₀² ρ(4 - ρ²) dρ
= 2π (8 - 4)
= 8π
```

分子：

```text
∭ z dV = ∫₀^{2π} dθ ∫₀² ρ dρ ∫_{ρ²}^{4} z dz
= 2π ∫₀² ρ · (16 - ρ⁴)/2 dρ
= π (32 - 32/6)
= π · 80/3
= 80π/3
```

（中间 ∫₀² ρ(16 - ρ⁴) dρ = 16·2 - 32/6 = 32 - 16/3 = 80/3。）

所以：

```text
z̄ = (80π/3) / (8π) = 10/3
```

**答案：10/3。**

**验算思路：**

```text
碗口在 z = 4，碗底在 z = 0。
质心在 3.33，靠近碗口。
因为碗上宽下窄，材料集中在上部。
```

和第 5 节"碗口在 1、质心 2/3"是同一个规律：

```text
上宽下窄的旋转体，质心在总高度的 2/3 以上。
```

## 12. 和其他章节怎么连

不接回其他章节，这一章就是孤立的三个公式。

等到 15 篇讲高斯公式，才发现右端正是三重积分，那时再回头补就晚了。

**往回连：12 二重积分。**

三重积分的"先一后二"，本质是把三重积分拆成"一次定积分 + 一次二重积分"。

```text
∭_Ω f dV = ∬_D [ ∫_{z₁}^{z₂} f dz ] dx dy
```

所以二重积分算不快，三重积分一定算不快。

反过来，三重积分的"先二后一"是二重积分的"截面法"。

两章共用一套"切、穿、投影"的语言。

**往回连：07 定积分。**

内层 ∫_{z₁}^{z₂} f dz 是一个普通的定积分。

上限含 x、y，所以它是"变上限"的，但因为外层还要再积，不需要求导。

```text
三层积分 = 三次一元积分，从里往外算。
```

**往前连：14 曲线积分。**

曲线积分是"沿一条线累加"。

它和三重积分的关系是**降维**：

```text
三重积分 → 曲面积分 → 曲线积分
```

每降一维，就用一次"三大公式"。

**往前连：15 曲面积分与三大公式。**

高斯公式：

```text
∬_Σ (闭曲面) = ∭_Ω (散度)
```

这是三重积分最重要的下游应用。

考题常见的形态是：

```text
给你一个曲面积分，但它不闭合。
补一块面，凑成闭曲面，用高斯公式变成三重积分。
再减掉补的那块。
```

三重积分算得熟，这一步才敢补。

**横向连：08 定积分的应用。**

质心、转动惯量、引力，一元时有公式，三元时公式长得一样，只是 ∫ 变成 ∭。

```text
一元：x̄ = ∫ x ρ dx / ∫ ρ dx
三元：x̄ = ∭ x ρ dV / ∭ ρ dV
```

**横向连：21 空间解析几何。**

球面、锥面、抛物面、柱面的方程，决定了用哪套坐标。

```text
认不出曲面 → 选不出坐标 → 积分限写不出来。
```

所以 21 篇虽然排在后面，实际是这一章的前置。

### 自检三问

**第一问：为什么柱坐标的体积元是 ρ dρ dθ dz，而球坐标是 r² sinφ dr dφ dθ？**

两个因子都来自"角度方向的实际弧长"。

柱坐标里，绕 z 轴转 dθ，走过的弧长是 ρ dθ（半径是 ρ），所以多一个 ρ。

球坐标里，绕 z 轴转 dθ，走过的弧长是 r sinφ dθ（到 z 轴的距离是 r sinφ）；沿 φ 方向走 dφ，弧长是 r dφ（半径是 r）。

三条边相乘：

```text
dr × r dφ × r sinφ dθ = r² sinφ dr dφ dθ
```

多出的两个因子，一个来自 sinφ 那次"绕轴"，一个来自两次"以 r 为半径"。

**第二问：什么情况下必须把积分区域拆开？**

当"穿线"不是一段的时候。

具体三种：

```text
第一种，投影内的某个点，竖线与 Ω 的交集是两段（比如哑铃形、环面）。
第二种，射线从原点出发与 Ω 的交集是两段（比如球壳）。
第三种，上下表面不能用同一个表达式写出（比如分片定义的立体）。
```

拆的原则：按"分界曲面"拆，每块单独满足"一段"。

**第三问：对称性用了半天，怎么确认没算错？**

三个检查：

```text
第一，区域是否真的对称。把区域写出来，做那个变换，看点是否还在区域内。
第二，函数是否真的奇（或偶）。把变量换号，看 f 是否变号。
第三，用 f = 1 检验体积，看结果是不是正的、量级对不对。
```

最实用的是第三条：

```text
体积必须是正数。
如果算出 0 或者负数，一定是某一步的限或符号错了。
```

## 13. 小结 + 下一篇

没有小结，这一章会剩下五六个零散的公式，彼此没有关系。

压成一张卡片：

```text
定义：∭_Ω f dV = lim Σ f ΔV（切碎、相乘、相加、取极限）
直角：dV = dx dy dz，先一后二或先二后一
柱面：dV = ρ dρ dθ dz，用于旋转体、含 x²+y²
球面：dV = r² sinφ dr dφ dθ，用于球、锥、含 x²+y²+z²
选坐标：区域优先，函数次之
对称性：奇函数 + 对称区域 → 0；轮换对称 → 三项并一项
```

四步公式的统一形态：

```text
算什么 → 在一块立体上做累积
逐符号 → ∭、Ω、f、dV，体积元随坐标变
代数字 → 定限，从里往外积三次
适用条件 → 穿线必须"一段"，区域要能写成显式边界
```

考场上的判断顺序：

```text
一、看区域：长方体 / 旋转体 / 球锥
二、看函数：多项式 / x²+y² / x²+y²+z²
三、定坐标：直角 / 柱面 / 球面
四、定顺序：先一后二，还是先二后一
五、用对称性砍一刀，再看要不要拆区域
六、算完用体积或量级验算
```

三句提醒。

```text
第一句：体积元是这一章最贵的三个字符，宁可多检查一遍。
第二句：先画图再写限，图和限不一致时，错的一定是限。
第三句：看到 x²+y²+z²，先想球坐标；看到 x²+y²，先想柱坐标。
```
