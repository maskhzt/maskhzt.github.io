> **读这篇之前，你只需要知道**：极限是"x 靠近 a 时 f(x) 靠近谁"，它不管 a 点本身发生了什么；左极限和右极限是从两侧分别靠近得到的结果；函数在某点有定义，指的是 f(a) 这个数确实存在。
> **这篇讲什么**：连续就是"极限值正好等于函数值"，图像上表现为一笔画得过去；画不过去的地方叫间断点，按左右极限的情况分成四类，每类有自己的名字和判法。
> **一个类比**：坐电梯上楼，楼层显示屏从 3 跳到 4 是"间断"（中间没有 3.5 层），而电梯轿厢的高度从 9 米升到 12 米是"连续"（中间每一厘米都真的到过）；前者只能报整数，后者可以用尺子量出任何一个中间值。


先看一个函数：

```text
f(x) = 1/x
```

它在 x = 0 处彻底断了，图像在 0 附近冲到无穷。

那它是不是"不连续函数"？

不是。

在 x = 1 处，它好得很：f(1) = 1，x 靠近 1 时 f(x) 也靠近 1，图像在那儿是光滑的一条。

在 x = 2 处也一样。

**所以"连续"不是给整个函数贴的标签，是一个点一个点判的。**

这句话是这一篇的地基。

它带来一个直接后果：问"这个函数连不连续"，正确的问法是"在哪些点连续、在哪些点不连续"。

而那些"不连续的点"，就是这一篇的另一半内容：间断点。

间断点为什么值得单独讲？

因为数一的选择题极爱考它，而且四个选项往往长得都很像，只有把分类标准背准了才分得清。

分类标准其实只有一个：

```text
看这个点的左极限、右极限各自是什么情况。
```

左、右都存在 → 第一类。

左、右至少一个不存在 → 第二类。

就这么两句话，能派生出四张图。

## 1. 为什么需要连续（不给会怎样）

先把"没有连续这个概念"的后果列出来，才知道这一篇在补哪个洞。

**第一，求极限不能直接代入。**

lim(x→2)(x² + 3x) = 10，我们是直接把 2 代进去算的。

凭什么可以代？

凭的就是"多项式在 2 处连续"。

没有连续的概念，"能代入"这件事就没有依据。

**第二，最值可能不存在。**

一个函数在一个区间上，一定有最大值吗？

不一定。

f(x) = 1/x 在 (0, 1] 上没有最大值，因为它一路冲到无穷。

f(x) = x 在 (0, 1) 上既没有最大值也没有最小值，因为 0 和 1 都取不到。

加上"闭区间 + 连续"，最值就一定有。这是数一证明题的常用前提。

**第三，方程的根说不清有没有。**

x³ + 4x² − 3x − 1 = 0 有没有根？

凭眼睛看不出来。

但如果知道左边这个函数连续，且 x = 0 时它是 −1（负）、x = 1 时它是 1（正），那么从负走到正，中间必然穿过 0。

这就是零点定理，它的唯一前提是连续。

**第四，中值定理全部失效。**

罗尔、拉格朗日、柯西（04 篇），条件里都写着"在闭区间上连续，在开区间内可导"。

少了连续这一条，定理不成立，证明题一分没有。

所以连续不是一个"描述性"的概念，它是**所有存在性定理的入场券**。

## 2. 最小模型：一点连续

定义只有一行：

```text
f 在 x = a 处连续  ⇔  lim(x→a) f(x) = f(a)
```

读法：当 x 趋于 a 时 f(x) 的极限，等于 f 在 a 点的函数值。

左边是"走向"，右边是"实际值"。连续就是说这两个东西对上了。

把这个等式拆开，它其实在要求三件事同时成立：

```text
① f(a) 有定义            （右边那个数得存在）
② lim(x→a) f(x) 存在      （左边那个数得存在）
③ 两个数相等              （对得上）
```

**三条缺一条就不连续。**

这三条是判断连续的标准流程，考试就按这个顺序查。

### 2.1 写成 ε-δ 的样子

连续的定义也可以写成 ε-δ 语言，它和 01 篇的极限定义只差一个地方：

```text
对任意 ε > 0，存在 δ > 0，
当 |x − a| < δ 时，都有 |f(x) − f(a)| < ε。
```

对比一下 01 篇的极限定义：

```text
极限：0 < |x − a| < δ     （挖掉中心点，不管 a 本身）
连续：    |x − a| < δ     （不挖，a 本身也要算进去）
```

**区别就在这个 0 < 上。**

极限允许 a 点是空洞，连续不允许。

这一个小改动，就是"极限"和"连续"的全部分野。

四步：

```text
① 它在算什么：
   它说"只要你要求输出的误差小于 ε，我就能保证输入的偏差小于 δ"。
   注意这里比较的是 f(x) 和 f(a)，不再是 f(x) 和某个抽象的 A。

② 符号逐个念：
   ε 读"艾普西龙"，纵向误差上限。
   δ 读"德尔塔"，横向允许的偏差。
   f(a) 是这一点的真实值，它必须存在。

③ 代一组数：
   证明 f(x) = 3x + 1 在 x = 2 处连续。
   |f(x) − f(2)| = |3x + 1 − 7| = 3|x − 2|。
   要 3|x − 2| < ε，取 δ = ε/3。
   若 ε = 0.03，取 δ = 0.01：x = 2.005 时 |f − 7| = 0.015 < 0.03，过关。

④ 什么时候能用/不能用：
   用于证明连续性，以及做误差估计。
   不用于判断间断点类型（那要看左右极限）。
```

### 2.2 连续的四则运算

```text
若 f、g 都在 a 处连续，则 f ± g、f · g、f/g（g(a) ≠ 0）都在 a 处连续。
若 u 在 a 处连续，f 在 u(a) 处连续，则复合函数 f(u(x)) 在 a 处连续。
```

由此得到一条极重要的结论：

```text
初等函数在其定义区间内连续。
```

初等函数指的是：幂函数、指数函数、对数函数、三角函数、反三角函数，以及它们经过有限次四则运算和复合得到的函数。

这条结论的价值在于：**它把"求极限"降级成了"代入求值"。**

看到 lim(x→3) ln(x² + 1)，不用任何技巧，直接代：

```text
ln(9 + 1) = ln 10
```

只要 3 在定义区间内，就可以代。

**但要小心"定义区间"四个字。**

ln x 在 x ≤ 0 处没有定义，谈不上连续。

√x 在 x < 0 处没有定义，也谈不上连续。

所以判断连续性之前，先看定义域。

## 3. 左连续、右连续与区间连续

一个点在中间，可以从两边靠近；一个点在区间端点上，就只能从一边靠近。

所以端点要单独定义：

```text
左连续：lim(x→a⁻) f(x) = f(a)，记 f(a−0) = f(a)。
右连续：lim(x→a⁺) f(x) = f(a)，记 f(a+0) = f(a)。
```

三条关系：

```text
f 在 a 处连续  ⇔  既左连续又右连续。
```

这一条和 01 篇"极限存在 ⇔ 左右极限相等"是同一件事的两种说法。

```text
在开区间 (a, b) 内连续：区间内每一点都连续。
在闭区间 [a, b] 上连续：开区间内每点连续，且 a 处右连续、b 处左连续。
```

**为什么闭区间要特意规定端点单侧连续？**

因为后面三条大定理（最值、介值、零点）都写在闭区间上。

如果端点不连续，定理就可能不成立。

例：f(x) = 1/x 在 (0, 1] 上连续，但 0 这一点不连续（也没定义）。

所以它不能算"在 [0, 1] 上连续"，也就享受不到有界性定理的保护：它确实无界。

这不是巧合，是条件在起作用。

## 4. 间断点：断在哪里，怎么断

定义：

```text
若 f 在 a 的去心邻域内有定义，但在 a 处不连续，
则称 a 是 f 的间断点。
```

"去心邻域"的意思是：a 附近一圈，但不含 a 本身。

这个措辞很讲究：**间断点只要求附近有定义，不要求 a 点本身有定义。**

所以 (x² − 1)/(x − 1) 在 x = 1 处有间断点，尽管 f(1) 根本不存在。

### 4.1 分类的唯一标准

拿到一个间断点，只做一件事：

```text
算左极限 f(a−0) 和右极限 f(a+0)。
```

然后查表：

```text
                   ┌─ 都存在 ──→ 第一类 ─┬─ 相等 ──→ 可去间断点
                   │                     └─ 不等 ──→ 跳跃间断点
左右极限情况 ──────┤
                   └─ 至少一个不存在 ──→ 第二类 ─┬─ 有趋于 ∞ 的 ──→ 无穷间断点
                                                  └─ 来回振荡的 ──→ 振荡间断点
```

这张图必须能默画。

它的逻辑非常干净：

```text
第一类 = 两侧都能"看到头"（极限是有限数）。
第二类 = 至少一侧"看不到头"（跑到无穷，或者根本不收敛）。
```

**没有这个分类会怎样？**

数一选择题会直接问"x = 0 是 f(x) = arctan(1/x) 的哪一类间断点"，四个选项就是四个名字。

不算左右极限，纯靠图像印象猜，正确率大概四分之一。

### 4.2 可去间断点

条件：左右极限都存在且相等，但不等于 f(a)（或者 f(a) 压根没定义）。

名字的来历：只要把 f(a) 重新定义成那个极限值，断点就被"补上"了，函数立刻变连续。

所以叫"可去"。

例：

```text
f(x) = (x² − 1)/(x − 1)，在 x = 1 处。
去心邻域有定义。f(1) 不存在。
化简：(x² − 1)/(x − 1) = x + 1（x ≠ 1）。
lim(x→1) f(x) = 2，左右都是 2。
所以 x = 1 是可去间断点。
补上 f(1) = 2，函数就连续了。
```

图像长这样：一条直线 y = x + 1，在 x = 1 处被挖掉一个点。

```text
      y
      │      ╱
    2 │    ○ ← 挖空的点 (1, 2)
      │  ╱
      │╱
──────┼────── x
      0  1
```

### 4.3 跳跃间断点

条件：左右极限都存在，但不相等。

名字的来历：图像在那儿"跳"了一下，高度差就是跳跃度。

例：

```text
f(x) = |x|/x，在 x = 0 处。
f(0) 不存在。
左极限 = −1，右极限 = 1。
两个都存在，但不相等 → 跳跃间断点。
跳跃度 = 1 − (−1) = 2。
```

```text
      y
    1 │      ●────────
      │
──────┼────────────── x
      │
   −1 │────────●
            0
```

### 4.4 无穷间断点

条件：至少一侧的极限是 ∞（或 −∞）。

例：

```text
f(x) = 1/x，在 x = 0 处。
左极限 −∞，右极限 +∞。
两侧都不是有限数 → 第二类，具体叫无穷间断点。
```

```text
f(x) = 1/(x − 1)²，在 x = 1 处。
左、右极限都是 +∞ → 无穷间断点。
```

注意：只要有一侧跑到无穷，就归第二类。

不需要两侧都跑。

### 4.5 振荡间断点

条件：至少一侧的极限不存在，而且不是趋于无穷，是来回跳。

标准例子只有一个，但必须记住：

```text
f(x) = sin(1/x)，在 x = 0 处。
x → 0 时 1/x → ∞，sin 在 −1 和 1 之间无限次来回。
极限不存在，也不是 ∞。
所以是第二类，具体叫振荡间断点。
```

把它乘上一个 x，性质就变了：

```text
g(x) = x sin(1/x)，在 x = 0 处。
|sin(1/x)| ≤ 1（有界），x → 0（无穷小），有界 × 无穷小 = 无穷小。
所以 lim(x→0) g(x) = 0，左右极限都是 0。
x = 0 是可去间断点，补上 g(0) = 0 就连续。
```

**这两个例子要成对记。**

sin(1/x) 振荡到没有极限，乘个 x 就被压平了。

数一很爱把它们放在同一道题的选项里。

### 4.6 四类间断点速查表

```text
函数                     间断点    左极限    右极限    类型
(x²−1)/(x−1)             x=1       2         2         第一类·可去
|x|/x                    x=0       −1        1         第一类·跳跃
arctan(1/x)              x=0       −π/2      π/2       第一类·跳跃
1/x                      x=0       −∞        +∞        第二类·无穷
1/(x−1)²                 x=1       +∞        +∞        第二类·无穷
e^(1/x)                  x=0       0         +∞        第二类·无穷
sin(1/x)                 x=0       振荡      振荡      第二类·振荡
x sin(1/x)               x=0       0         0         第一类·可去
```

这张表是这一篇最该背下来的东西。

特别注意第三行：**arctan(1/x) 是跳跃，不是无穷。**

因为 arctan 的值域被夹在 (−π/2, π/2) 里，无论 1/x 多大，它都不会跑到无穷。

这是最高频的一个坑。

## 5. 算一遍：判断连续性与找间断点

这一节给四道完整的手算题，覆盖考试的主要问法。

### 5.1 题型一：补充定义使函数连续

```text
题：设 f(x) = (e^x − 1)/x（x ≠ 0），f(0) = a。
    问 a 取何值时 f 在 x = 0 处连续。
```

思路：连续要求 lim(x→0) f(x) = f(0) = a，所以先算极限，再让 a 等于它。

```text
第一步：算极限。这是 0/0 型。
        用等价无穷小：e^x − 1 ~ x。
        lim(x→0) (e^x − 1)/x = lim x/x = 1。
第二步：令 a = 1。
答案：a = 1。
```

验算：x = 0.001 时，(e^0.001 − 1)/0.001 = 1.0005，贴着 1。

### 5.2 题型二：求间断点并分类

```text
题：求 f(x) = (x² − x)/(x² − 1) 的间断点，并指出类型。
```

思路：先找"分母为 0 且分子不为 0 或可约"的点，再逐个算左右极限。

```text
第一步：找可疑点。分母 x² − 1 = (x − 1)(x + 1)，可疑 x = 1 和 x = −1。
第二步：化简。分子 x² − x = x(x − 1)。
        f(x) = x(x − 1)/[(x − 1)(x + 1)] = x/(x + 1)（x ≠ 1）。
第三步：判 x = 1。
        lim(x→1) f(x) = 1/2，左右都是 1/2，而 f(1) 不存在（原式 0/0）。
        → 第一类·可去间断点。
第四步：判 x = −1。
        分子 → (−1)/(0)，趋于无穷，左右异号：
        x → −1⁺ 时 x + 1 → 0⁺，f → −∞；
        x → −1⁻ 时 x + 1 → 0⁻，f → +∞。
        → 第二类·无穷间断点。
答案：x = 1 是可去间断点，x = −1 是无穷间断点。
```

**这里的关键动作是"先约分再判"。**

约分能约掉的因子对应可去间断点，约不掉的因子对应无穷间断点。

这条经验能让你在十秒内分出这两类。

### 5.3 题型三：含绝对值和取整的跳跃

```text
题：求 f(x) = |x − 2|/(x − 2) 的间断点并分类。
```

```text
x = 2 处分母为 0，可疑。
x > 2 时 |x − 2| = x − 2，f = 1，右极限 1。
x < 2 时 |x − 2| = −(x − 2)，f = −1，左极限 −1。
两侧都存在但不相等 → 第一类·跳跃间断点，跳跃度 2。
```

### 5.4 题型四：含 e^(1/x) 的第二类

```text
题：求 f(x) = 1/(1 + e^(1/x)) 在 x = 0 处的类型。
```

```text
x → 0⁻：1/x → −∞，e^(1/x) → 0，f → 1/(1 + 0) = 1。
x → 0⁺：1/x → +∞，e^(1/x) → +∞，f → 1/(+∞) = 0。
左极限 1，右极限 0，都存在但不相等 → 第一类·跳跃间断点。
```

注意这道题容易看错：虽然式子里有 e^(1/x)，但整个 f 的两侧极限都是有限数。

所以它是第一类。

**判类型永远看最后算出来的左右极限，不看式子里有没有吓人的东西。**

### 5.5 题型五：分段函数在分界点的连续性

```text
题：设 f(x) = x²（x ≤ 1），f(x) = ax + b（x > 1）。
    已知 f 在 x = 1 处连续，且 f 在 1 处可导，求 a、b。
```

这道题跨到 03 篇了，但思路完全靠这一篇：

```text
连续：左极限 = 右极限 = f(1)。
      f(1) = 1² = 1。
      左极限 = 1。
      右极限 = a + b。
      所以 a + b = 1。        （第一式）

可导：左右导数相等（03 篇会讲）。
      左导数 = (x²)' 在 1 处 = 2。
      右导数 = (ax + b)' = a。
      所以 a = 2。            （第二式）

联立：a = 2，b = 1 − 2 = −1。
答案：a = 2，b = −1。
```

**注意顺序：先连续，再可导。**

因为可导必连续，连续是可导的前提。

如果先算可导，得到的 a、b 还要回头验证连续，多绕一步。

### 5.6 题型六：先看定义域

```text
题：讨论 f(x) = ln(x − 1)/√(2 − x) 的连续区间。
```

```text
定义域：ln 要求 x − 1 > 0，即 x > 1；
      根号在分母上，要求 2 − x > 0，即 x < 2。
      合起来 1 < x < 2。

在 (1, 2) 内，f 是两个初等函数的商，分母不为 0，处处连续。
x = 1 和 x = 2 不在定义域内，不谈连续，也不叫间断点
（间断点要求"去心邻域内有定义"，而这两点的邻域里有一半没定义）。

答案：连续区间是 (1, 2)。
```

**这道题的意义在于提醒一件事：判断连续之前先求定义域。**

定义域之外的点不是间断点，这个区分在选择题里被专门考过。

## 6. 闭区间上连续函数的三条性质

这三条性质是数一证明题的主力工具，必须连条件一起背。

前提统一是：

```text
f 在闭区间 [a, b] 上连续。
```

**两个条件都不能松：闭区间、连续。**

### 6.1 有界性与最值定理

```text
f 在 [a, b] 上连续 ⇒ f 在 [a, b] 上有界，且必能取到最大值 M 和最小值 m。
```

"取到"两个字是关键：存在 ξ₁、ξ₂ 使得 f(ξ₁) = M，f(ξ₂) = m。

不是"无限接近但取不到"。

**没有它会怎样？**

求最值的题（05 篇）就没法说"最大值一定存在"。

你算出一堆候选点，凭什么说其中必有一个是最大的？靠这条定理兜底。

四步：

```text
① 它在算什么：
   一条连续曲线画在有限的闭区间上，一定会有一个最高点和一个最低点。
   不会一路冲天，也不会永远在逼近却够不到。

② 符号逐个念：
   M 是最大值，m 是最小值，ξ 读"克西"，是取到最值的那两个横坐标。

③ 代一组数：
   f(x) = x² 在 [−1, 2] 上连续。
   最小值 m = 0，在 x = 0 处取到。
   最大值 M = 4，在 x = 2 处取到。
   端点 x = −1 的值是 1，不是最值，但也在区间内。

④ 什么时候能用/不能用：
   必须闭区间。f(x) = x 在 (0, 1) 上连续，却没有最大值也没有最小值。
   必须连续。f(x) = 1/x 在 (0, 1] 上连续但无界（0 这一点不连续）。
```

反例都值得记，因为选择题就爱考"去掉哪个条件会失效"。

```text
去掉"闭"：f(x) = x 在 (0, 1) 上，无最值。
去掉"连续"：f(x) = 1/x 在 (0, 1] 上，无界。
去掉"有界区间"：f(x) = x 在 [0, +∞) 上，无最值。
```

### 6.2 介值定理

```text
f 在 [a, b] 上连续，m ≤ μ ≤ M，
则存在 ξ ∈ [a, b]，使 f(ξ) = μ。
```

大白话：连续函数从一个值走到另一个值，中间所有的值都真的到过。

四步：

```text
① 它在算什么：
   它保证"中间值一定被取到"，但不说在哪一点取到，也不说有几个点。

② 符号逐个念：
   μ 读"缪"，是介于最小值与最大值之间的任意一个数。
   ξ 是那个"至少存在一个"的横坐标。

③ 代一组数：
   f(x) = x³ 在 [0, 2] 上连续。
   f(0) = 0，f(2) = 8，所以 m = 0，M = 8。
   取 μ = 3，问有没有 ξ 使 ξ³ = 3？
   有，ξ = ∛3 ≈ 1.442，落在 [0, 2] 里。

④ 什么时候能用/不能用：
   用于证明"存在某点使 f 等于某个值"。
   只保证存在，不保证唯一；要证唯一，得再加单调性。
   必须连续，且有界闭区间。
```

**一个反例说明"连续"不能少：**

```text
f(x) = 0（x < 0），f(x) = 1（x ≥ 0），在 [−1, 1] 上。
f 在 0 处跳跃，不连续。
f(−1) = 0，f(1) = 1，按端点看 0.5 应该"经过"，
但 f 的取值只有 0 和 1 两种，μ = 0.5 在任何点都取不到。
这就是不连续导致介值失效：定理的结论不成立，不是因为区间不好，是因为断了。
```

### 6.3 零点定理

它是介值定理最常用的特例：

```text
f 在 [a, b] 上连续，且 f(a) · f(b) < 0，
则存在 ξ ∈ (a, b)，使 f(ξ) = 0。
```

"f(a) · f(b) < 0"的意思是两端异号：一正一负。

从正走到负，必然穿过 0。

四步：

```text
① 它在算什么：
   它把"方程有没有根"这个问题，变成"算两个端点的符号"。

② 符号逐个念：
   f(a) · f(b) < 0 读"f(a) 乘 f(b) 小于 0"，即两端异号。
   ξ ∈ (a, b) 是开区间内的根，端点不算。

③ 代一组数：
   证明 x³ + 4x² − 3x − 1 = 0 在 (0, 1) 内有根。
   令 f(x) = x³ + 4x² − 3x − 1。
   f(0) = −1 < 0。
   f(1) = 1 + 4 − 3 − 1 = 1 > 0。
   异号，且 f 是多项式（连续）。
   所以存在 ξ ∈ (0, 1)，f(ξ) = 0。

④ 什么时候能用/不能用：
   用于证明根的存在。
   不能证明根的个数，也不能定位根。
   端点值恰好为 0 时定理仍成立，但根可能就在端点，此时要单独说明。
```

**这里最容易丢分的地方：忘了写"f 连续"。**

多项式连续是要交代一句的，尤其是解答题。

写"因为 f(x) 是多项式，在 [0, 1] 上连续"只多花七个字，能保住步骤分。

### 6.4 三条性质是一条链

它们不是三个孤立结论，是一条递进链：

```text
有界性（曲线不会跑飞）
   ↓
最值定理（一定有个最高点 M 和最低点 m）
   ↓
介值定理（m 与 M 之间的每个值都取到）
   ↓
零点定理（取 μ = 0，只要 0 在 m 与 M 之间）
```

背的时候按这条链背，比死记三句话省力。

用的时候也按这条链想：先确认有界闭区间连续，再想"我要的那个值在最小值和最大值之间吗"。

## 7. 零点定理的四个典型套路

零点定理本身只有一行，但它的用法被数一考出了固定套路。

认准套路，证明题就变成填空题。

### 7.1 套路一：证明方程有根

三步走，一步都不能省：

```text
第一步：把方程整理成 f(x) = 0 的形式，令 f 为左边减去右边。
第二步：交代 f 在 [a, b] 上连续（多项式、初等函数都要说一句）。
第三步：算 f(a)、f(b)，指出异号，下结论。
```

完整示例：

```text
题：证明方程 x = cos x 在 (0, π/2) 内至少有一个根。
```

```text
令 f(x) = x − cos x。
f 在 [0, π/2] 上连续（两个初等函数之差）。
f(0) = 0 − 1 = −1 < 0。
f(π/2) = π/2 − 0 = π/2 > 0。
两端异号，由零点定理，存在 ξ ∈ (0, π/2)，使 f(ξ) = 0，
即 ξ = cos ξ。
```

**这类题的唯一难点是"怎么构造函数"。**

通用做法：把方程所有项挪到一边，另一边是 0，挪完的那一坨就是 f。

### 7.2 套路二：再加单调性证明唯一

零点定理只管"有"，不管"几个"。

要证"有且仅有一个"，必须补一刀：单调。

```text
接上题：证明 x = cos x 在 (0, π/2) 内只有一个根。
```

```text
f'(x) = 1 + sin x。
在 (0, π/2) 上 sin x > 0，所以 f'(x) > 1 > 0。
f 在 [0, π/2] 上严格单调递增。
严格单调的函数，每个函数值最多被取到一次，
所以零点最多一个。
结合上题"至少一个"，得"有且仅有一个"。
```

这个"存在性 + 唯一性"的两段式，是数一证明题最常见的骨架。

看到"有且仅有一个"，就条件反射地想到：零点定理 + 导数定号。

### 7.3 套路三：不动点

```text
题：设 f 在 [0, 1] 上连续，且 0 ≤ f(x) ≤ 1。
    证明存在 ξ ∈ [0, 1]，使 f(ξ) = ξ。
```

"f(ξ) = ξ"叫不动点：输入什么，输出还是什么。

思路：把等式挪成"某某 = 0"，构造 g(x) = f(x) − x。

```text
g 在 [0, 1] 上连续（连续函数减多项式）。
g(0) = f(0) − 0 = f(0)。
因为 0 ≤ f(x) ≤ 1，所以 g(0) ≥ 0。
g(1) = f(1) − 1 ≤ 0（因为 f(1) ≤ 1）。

情况一：g(0) = 0，则 ξ = 0 就是要找的点。
情况二：g(1) = 0，则 ξ = 1 就是要找的点。
情况三：g(0) > 0 且 g(1) < 0，两端异号，
        由零点定理，存在 ξ ∈ (0, 1)，g(ξ) = 0，即 f(ξ) = ξ。
```

**为什么要分三种情况？**

因为零点定理要求"严格异号"，而端点恰好为 0 时不算异号。

这一步分情况是阅卷的给分点，不能省。

### 7.4 套路四：证 f(ξ) 等于某个特定值

```text
题：设 f 在 [a, b] 上连续，证明存在 ξ ∈ [a, b]，
    使 f(ξ) = [f(a) + f(b)]/2。
```

思路：不用构造函数，直接用介值定理。

```text
由最值定理，f 在 [a, b] 上有最小值 m 和最大值 M。
而 f(a)、f(b) 都是区间内的函数值，任何一个函数值都不会小于最小值、大于最大值，
所以 m ≤ f(a) ≤ M，m ≤ f(b) ≤ M。
所以 m ≤ [f(a) + f(b)]/2 ≤ M（两个数的平均不会跑出它们的范围）。
令 μ = [f(a) + f(b)]/2，由介值定理，存在 ξ 使 f(ξ) = μ。
```

**这一类题的信号词是"证明存在 ξ 使 f(ξ) = 常数"。**

常数落在最小值和最大值之间，就用介值定理；落在 0 附近，就用零点定理。

两者其实是同一条定理。

### 7.5 一个高频变体：错开半格

```text
题：设 f 在 [0, 2] 上连续，且 f(0) = f(2)。
    证明存在 ξ ∈ [0, 1]，使 f(ξ) = f(ξ + 1)。
```

思路：把"两点函数值相等"改成"某个辅助函数的零点"。构造

```text
g(x) = f(x) − f(x + 1)，x ∈ [0, 1]。
```

然后算两个端点：

```text
g(0) = f(0) − f(1)。
g(1) = f(1) − f(2) = f(1) − f(0) = −g(0)。
```

两个端点互为相反数。

```text
若 g(0) = 0，则 ξ = 0 即可。
若 g(0) ≠ 0，则 g(0) 与 g(1) 严格异号，
由零点定理，存在 ξ ∈ (0, 1)，g(ξ) = 0，即 f(ξ) = f(ξ + 1)。
```

**这个构造是怎么想出来的？**

从结论倒推：要 f(ξ) = f(ξ+1)，就把它挪成 f(ξ) − f(ξ+1) = 0。

左边这一坨当成 x 的函数，就是 g(x)。

"把要证的等式挪成 0 = 0，左边就是辅助函数"——这是所有中值定理证明题的总纲（04 篇会反复用）。

## 8. 连续还不够：从连续到可导

这一节是给 03 篇铺路的，但考点本身就在这一篇。

连续说的是"图像接得上"，可导说的是"图像接得顺"。

**接得上不等于接得顺。**

### 8.1 连续但不可导的标准例子

```text
f(x) = |x|，在 x = 0 处。
```

先验连续：

```text
f(0) = 0。
左极限 = lim(x→0⁻)(−x) = 0。
右极限 = lim(x→0⁺) x = 0。
三者相等，所以连续。
```

再看可导（导数的定义 03 篇细讲，这里先用）：

```text
左导数 = lim(h→0⁻) [|0 + h| − |0|]/h = lim (−h)/h = −1。
右导数 = lim(h→0⁺) [|h| − 0]/h = lim h/h = 1。
−1 ≠ 1，左右导数不等，所以不可导。
```

图像在 0 处有个尖角：

```text
       ╱
      ╱
─────●─────
    ╱
   ╱
```

尖角的地方，"切线"有两个候选方向，定不下来，于是导数不存在。

### 8.2 更狠的例子：抖到没有切线

```text
g(x) = x sin(1/x)（x ≠ 0），g(0) = 0。
```

它在 0 处连续（前面 4.5 节算过，有界 × 无穷小 = 0）。

但导数：

```text
g'(0) = lim(h→0) [g(h) − g(0)]/h = lim(h→0) [h sin(1/h)]/h = lim(h→0) sin(1/h)。
```

sin(1/h) 在 h → 0 时来回振荡，没有极限。

所以 g 在 0 处连续但不可导，而且不是尖角，是"无限密集的抖动"。

把这条曲线放大再放大，它还是在抖，永远画不出切线。

### 8.3 一条必须记住的单向箭头

```text
可导 ⇒ 连续
连续 ⇏ 可导
```

证明"可导 ⇒ 连续"只要三行：

```text
若 f 在 a 处可导，则 lim(x→a) [f(x) − f(a)]/(x − a) = f'(a) 存在。
而 f(x) − f(a) = [f(x) − f(a)]/(x − a) · (x − a)。
两个因子一个趋于 f'(a)（有限），一个趋于 0，
乘积趋于 f'(a) · 0 = 0。
所以 lim(x→a) f(x) = f(a)，即 f 在 a 处连续。
```

**这个证明的思路值得学：把"函数值的差"拆成"斜率的差"乘"自变量的差"。**

一个有限的数乘一个趋于 0 的数，结果趋于 0。

这条链在后面判断"分段函数在分界点可不可导"时天天用：先验连续，再验导数。

连续都不过，直接判不可导，不用算导数。

## 9. 常见错误

**错误一：只验极限存在就判连续。**

```text
错：lim(x→1) (x² − 1)/(x − 1) = 2 存在，所以 x = 1 处连续。
对：f(1) 根本没有定义，缺了"f(a) 存在"这一条，不连续。
```

**错误二：把 arctan(1/x) 的间断点归为第二类。**

```text
错：arctan(1/x) 在 0 处跑到无穷，是无穷间断点。
对：arctan 的值域是 (−π/2, π/2)，永远跑不到无穷。
    左极限 −π/2，右极限 π/2，都存在 → 第一类·跳跃。
```

**错误三：e^(1/x) 只看一侧。**

```text
错：e^(1/x) 在 0 处极限是 +∞，所以是无穷间断点。
对：只看右侧。左极限是 0，右侧才是 +∞。
    两侧不是都跑，但按"至少一侧不存在"的规则，仍归第二类·无穷。
    关键是要把两侧都算出来再下结论。
```

**错误四：用零点定理不写连续。**

```text
错：f(0) < 0，f(1) > 0，所以有根。
对：f(0) < 0，f(1) > 0，且 f 在 [0, 1] 上连续，由零点定理，有根。
```

零点定理的条件是"连续 + 异号"，少写一条就是逻辑缺口。

**错误五：区间不闭也用最值定理。**

```text
错：f(x) = x 在 (0, 1) 上连续，所以有最大值。
对：(0, 1) 不是闭区间，f 没有最大值（也取不到 1）。
```

**错误六：以为"可去间断点"等于"函数连续"。**

可去间断点的名字是说"可以把断点去掉"，前提是你**重新定义** f(a)。

原函数在这一点就是不连续的。

**错误七：分段函数忘记讨论分界点。**

分段函数在每一段内部都连续，但分界点必须单独算左右极限。

考试里 90% 的错都出在分界点上。

## 10. 数一怎么考

连续与间断在数一里的题型非常集中：

```text
选择/填空：
  1. 判断某点是哪一类间断点（最高频）。
  2. 数一数一个函数有几个间断点。
  3. 已知连续，反求参数 a。
解答题：
  4. 讨论分段函数在分界点的连续性、可导性。
  5. 用零点定理证明方程有根 / 有且仅有一个根。
```

### 10.1 例题：反求参数

```text
题：设 f(x) = (1 − cos x)/x²（x ≠ 0），f(0) = a。
    若 f 在 x = 0 处连续，求 a。
```

```text
先算极限：1 − cos x ~ x²/2，所以 (1 − cos x)/x² → 1/2。
连续要求极限等于函数值，故 a = 1/2。
答案：a = 1/2。
```

### 10.2 例题：数间断点并分类

```text
题：求 f(x) = (x² − 1)/(x² − 3x + 2) 的间断点并分类。
```

```text
分母分解：x² − 3x + 2 = (x − 1)(x − 2)，可疑点 x = 1、x = 2。
分子分解：x² − 1 = (x − 1)(x + 1)。

x = 1：约掉公因子 (x − 1)，f = (x + 1)/(x − 2)。
       lim(x→1) f = (1 + 1)/(1 − 2) = −2，左右都是 −2，f(1) 不存在。
       → 第一类·可去间断点。

x = 2：约不掉 (x − 2)，分子在 2 处为 3 ≠ 0，分母为 0。
       → 第二类·无穷间断点。

答案：两个间断点，x = 1 可去，x = 2 无穷。
```

**这道题的十秒解法：**

先把分子分母都分解，看公因子。

有公因子 (x − a) 能约掉 → a 是可去间断点。

约不掉的因子 → a 是无穷间断点。

### 10.3 例题：证明根的存在与唯一

```text
题：证明方程 x · 2^x = 1 在 (0, 1) 内有且仅有一个实根。
```

```text
第一步（存在）：令 f(x) = x · 2^x − 1。
  f 在 [0, 1] 上连续（初等函数）。
  f(0) = 0 − 1 = −1 < 0。
  f(1) = 1 · 2 − 1 = 1 > 0。
  异号，由零点定理，存在 ξ ∈ (0, 1)，f(ξ) = 0。

第二步（唯一）：f'(x) = 2^x + x · 2^x · ln 2 = 2^x (1 + x ln 2)。
  在 (0, 1) 上，2^x > 0，1 + x ln 2 > 1 > 0，
  所以 f'(x) > 0，f 严格单调递增。
  严格单调函数最多有一个零点。

结论：有且仅有一个根。
```

### 10.4 例题：错开半格型

这道题上面 7.5 节已经推过，这里给出考试版的完整写法：

```text
题：f 在 [0, 2] 上连续，f(0) = f(2)。
    证明存在 ξ ∈ [0, 1]，使 f(ξ) = f(ξ + 1)。

证：令 g(x) = f(x) − f(x + 1)，x ∈ [0, 1]。
    g 在 [0, 1] 上连续。
    g(0) = f(0) − f(1)。
    g(1) = f(1) − f(2) = f(1) − f(0) = −g(0)。
    若 g(0) = 0，取 ξ = 0 即可。
    若 g(0) ≠ 0，则 g(0) 与 g(1) 异号，
    由零点定理，存在 ξ ∈ (0, 1)，g(ξ) = 0，
    即 f(ξ) = f(ξ + 1)。证毕。
```

```text
          没有极限，连续无法定义。

→ 03 导数：可导必连续，连续不一定可导。
          分段函数分界点的可导性，必须先过连续这一关。

→ 04 中值定理：罗尔、拉格朗日、柯西的条件里都写着"闭区间上连续"。
              这七个字直接来自本篇第 6 节。

→ 05 导数应用：求最值靠"闭区间连续必有最值"，
              求极值靠"导数变号"，两者都建立在连续之上。

→ 07 定积分：连续函数一定可积，
            这是定积分存在的充分条件里最好用的一个。

→ 10 多元函数：二元函数的连续定义形状一样，
              但"趋近"的方式有无穷多条路径，
              这是多元和一元最大的差别。
```

一个总结性的看法：

```text
极限管"靠近"，
连续管"接上"，
导数管"顺不顺"。
```

三句话，三个层次，一层比一层要求高。

### 自检三问

**第一问：f 在 x = a 处连续，需要几个条件？分别是什么？**

答：三个。

f(a) 有定义；极限 lim(x→a) f(x) 存在；两者相等。

只满足前两个不算连续，那是"可去间断点"。

**第二问：x = 0 是 f(x) = arctan(1/x) 的哪一类间断点？为什么容易判错？**

答：第一类·跳跃间断点。

左极限 −π/2，右极限 π/2，都存在但不相等。

容易判错是因为式子里有 1/x，看着像要跑到无穷；但 arctan 把结果压在 (−π/2, π/2) 里，跑不出去。

**第三问：零点定理能证明"有且仅有一个根"吗？**

答：不能，它只证"至少有一个"。

要证唯一，必须再加一条：f 严格单调（通常用 f'(x) 恒正或恒负证明）。

"存在 + 唯一"才是完整的"有且仅有一个"。

## 12. 小结与下一篇

这一篇压成六句话：

```text
1. 连续是逐点判的：lim(x→a) f(x) = f(a)，三条件缺一不可。
2. 极限与连续只差一个"0 <"：极限挖掉中心点，连续不挖。
3. 初等函数在定义区间内连续，这就是"求极限可以直接代入"的依据。
4. 间断点分类只看左右极限：
   都存在 → 第一类（相等可去，不等跳跃）；
   至少一个不存在 → 第二类（趋于无穷叫无穷，来回跳叫振荡）。
5. 闭区间连续的三条性质：有界最值 → 介值 → 零点，是一条链。
6. 连续只管"接得上"，不管"顺不顺"，所以连续推不出可导。
```

一张随手要能画出来的分类图：

```text
左右极限 ─┬─ 都存在 ─┬─ 相等 → 可去
          │           └─ 不等 → 跳跃
          └─ 有不存在 ─┬─ 跑到 ∞ → 无穷
                        └─ 来回跳 → 振荡
```
