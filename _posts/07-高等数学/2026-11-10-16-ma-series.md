> **读这篇之前，你只需要知道**：数列就是一列数 a₁, a₂, a₃, …，数列的极限是说"n 越大，aₙ 越接近某个固定的数"；Σ（读 sigma）表示"把一串东西加起来"。
> **这篇讲什么**：把"无限多个数相加"定义清楚，判断它到底能不能加出一个有限的数，以及能加出来时用什么办法估这个数。
> **一个类比**：往一个杯子里倒水，第 1 次倒 1/2 杯，第 2 次倒 1/4 杯，第 3 次倒 1/8 杯……杯子永远倒不满，但水位越来越接近满格——水量的"极限"就是级数的和。

先看两个式子。

```text
第一个：1/2 + 1/4 + 1/8 + 1/16 + …
第二个：1 + 1/2 + 1/3 + 1/4 + …
```

两个都是无限多项相加。

第一个的和是 1。

第二个的和是无穷大。

**都是"越加越小"，为什么一个收得住，一个收不住？**

看每一项掉得多快：

```text
第一个：每项是前一项的一半，掉得极快。
第二个：第 100 项还是 1/100，掉得极慢。
```

慢到什么程度？

```text
加到 1000 项，和约 7.49。
加到 100 万项，和约 14.39。
每翻一倍项数，只增加约 0.69。
```

永远在涨，永远不停，所以发散。

**这就引出了这一篇的核心问题：**

```text
一串数加起来，加得完吗？
判断的标准不是"项越来越小"，而是"项小得够不够快"。
```

**这一篇要回答四件事：**

```text
Σuₙ 与 Sₙ 怎么读？收敛到底是什么意思？
哪些级数必须背下来（几何、调和、p 级数）？
比较、比值、根值、莱布尼茨，四个判别法怎么选？
绝对收敛和条件收敛差在哪，为什么这个区别重要？
```

## 1. 为什么需要它（不给会怎样）

先说没有它会怎样。

具体卡在四个地方。

**第一处，"无限相加"这句话本身没有定义。**

有限个数相加，可以一个一个加。

```text
1 + 2 + 3 = 6，这是确定的。
```

无限个数相加，加不完。

```text
1/2 + 1/4 + 1/8 + … 这个"…"到底是什么意思？
```

如果只说"一直加下去"，那就等于什么都没说。

必须有一个定义，把"无限次操作"翻译成"一次极限"。

**这个翻译，就是部分和。**

**第二处，很多数学对象只能用级数表示。**

```text
e^x = 1 + x + x²/2! + x³/3! + …
sin x = x - x³/3! + x⁵/5! - …
π/4 = 1 - 1/3 + 1/5 - 1/7 + …
```

这些等号成立的前提，是右边的级数收敛。

```text
如果级数发散，等号右边就是无穷大，写出来没有意义。
```

所以先要会判断收敛，才敢用这些展开式。

17 篇（幂级数）和 18 篇（傅里叶级数）全部建立在"收敛"这个概念上。

**第三处，概率、物理、数值计算都要用到级数。**

```text
一个随机变量取无穷多个值，概率之和必须是 1。
```

```text
电路里无穷多个电阻串并联，等效电阻是一个级数的和。
```

```text
计算 sin(0.1) 到小数点后十位，用级数的前几项截断。
```

三处都需要回答同一个问题：**截断的误差有多大？**

这个问题又回到"级数收不收敛、收敛得多快"。

**第四处，考试里判断题占比高。**

数一的选择题里，级数敛散性几乎年年出现。

```text
四个选项，四个级数，问哪个收敛。
```

这种题不能靠算，要靠"认模式 + 用判别法"。

```text
看到阶乘、n 次幂 → 比值或根值。
看到 1/n^p 的结构 → 比较。
看到 (-1)ⁿ → 莱布尼茨。
```

**所以这一章的骨架是：**

```text
定义：Σuₙ 收敛 ⟺ 部分和数列 Sₙ 有极限
基准：几何级数、调和级数、p 级数（必须背）
工具：比较、比值、根值（正项）；莱布尼茨（交错）
细分：绝对收敛、条件收敛
```

## 2. 最小模型：Σuₙ、Sₙ 与收敛

没有这一节，"无限相加"这句话没有定义。

你只能凭感觉说"看起来收敛"，而考试要的是一个能验证的判据。

先读符号。

```text
Σ_{n=1}^{∞} uₙ   读作"从 n 等于 1 到无穷，对 uₙ 求和"
uₙ               通项，第 n 项
Sₙ               部分和，前 n 项的和
```

```text
Sₙ = u₁ + u₂ + … + uₙ
```

注意 Sₙ 是一个**数列**，不是一个数。

```text
S₁ = u₁
S₂ = u₁ + u₂
S₃ = u₁ + u₂ + u₃
…
```

每个 n 对应一个有限和。

**收敛的定义：**

```text
若部分和数列 {Sₙ} 有极限 S（S 是有限数），
则称级数 Σuₙ 收敛，并把这个极限叫做级数的和，记作
Σ_{n=1}^{∞} uₙ = S。
若 {Sₙ} 没有极限（趋于无穷或者振荡），则称级数发散。
```

**这个定义做了一件关键的事：**

```text
把"无限次相加"翻译成"一次取极限"。
```

于是所有关于极限的定理，都能搬过来用。

**它算的是什么？**

```text
不是"加到无穷多项"，而是"看前 n 项的和，随 n 增大趋向哪里"。
```

这个区别很重要：

```text
"Sₙ 趋于 S" 不表示"某一项之后就没有了"，
只表示"截断得越晚，剩下的尾巴越小"。
```

尾巴叫什么？

```text
余项 rₙ = S - Sₙ = u_{n+1} + u_{n+2} + …
```

收敛的意思就是 rₙ → 0。

**一个必须能自己推的例子。**

```text
Σ_{n=0}^{∞} qⁿ = 1 + q + q² + …
```

部分和用错位相减：

```text
Sₙ = 1 + q + q² + … + qⁿ
qSₙ = q + q² + … + qⁿ + q^{n+1}
两式相减：(1-q)Sₙ = 1 - q^{n+1}
```

所以：

```text
Sₙ = (1 - q^{n+1}) / (1 - q)   （q ≠ 1）
```

**看极限：**

```text
|q| < 1 时，q^{n+1} → 0，Sₙ → 1/(1-q)，收敛。
|q| > 1 时，q^{n+1} 爆炸，Sₙ → ∞，发散。
q = 1 时，Sₙ = n + 1 → ∞，发散。
q = -1 时，Sₙ 在 1 和 0 之间跳，无极限，发散。
```

**结论：**

```text
Σ qⁿ（从 n=0 开始）：
|q| < 1 收敛，和 = 1/(1-q)
|q| ≥ 1 发散
```

如果从 n = 1 开始：

```text
Σ_{n=1}^{∞} qⁿ = q/(1-q)，|q| < 1
```

**收敛级数能做什么运算？**

三条规则，和极限的运算律平行。

```text
规则一：若 Σuₙ = A，Σvₙ = B 都收敛，
        则 Σ(αuₙ + βvₙ) = αA + βB（α、β 是常数）。
规则二：若 Σuₙ 收敛，Σvₙ 发散，则 Σ(uₙ + vₙ) 一定发散。
规则三：若 Σuₙ 发散，Σvₙ 发散，则 Σ(uₙ + vₙ) 可能收敛也可能发散。
```

规则二值得说明：

```text
若 Σ(uₙ + vₙ) 收敛，而 Σuₙ 收敛，
则 vₙ = (uₙ + vₙ) - uₙ 是两个收敛级数之差，也应收敛，
与 Σvₙ 发散矛盾。
```

规则三的反例：

```text
Σ1/n 发散，Σ(-1/n) 也发散，但 Σ(1/n - 1/n) = 0 收敛。
```

**这三条在化简题目时很有用：**

```text
一个级数拆成两项，一项收敛一项发散 → 整体发散，不必再算。
```

**公式四步：判断级数收敛。**

**第一步，算什么。**

```text
判断"无限相加"能不能得到一个有限数，能的话是多少。
```

**第二步，逐符号。**

```text
uₙ      通项
Sₙ      部分和
S       极限（若存在）
rₙ      余项，S - Sₙ
```

**第三步，代数字。**

```text
Σ_{n=1}^{∞} (2/3)ⁿ
```

这是几何级数，q = 2/3，首项是 2/3。

```text
和 = 首项 / (1 - q) = (2/3) / (1 - 2/3) = (2/3)/(1/3) = 2
```

验算：前几项和

```text
S₁ = 0.667
S₂ = 0.667 + 0.444 = 1.111
S₃ = 1.111 + 0.296 = 1.407
S₄ = 1.407 + 0.198 = 1.605
```

确实在向 2 爬。

**第四步，适用条件。**

```text
第一，级数必须从某项开始"通项形式统一"（几何级数的 q 是常数）。
第二，q 必须与 n 无关。
第三，收敛的必要条件 uₙ → 0 必须满足；不满足直接判发散。
```

## 3. 算一遍：三条基准级数

没有这三条基准，后面的比较判别法就无从"比"。

所有判别法最后都要落回 1/n^p 或者几何级数，这张表不熟，题就判不动。

这三条必须背下来，因为几乎所有判别法最后都要和它们比。

**第一条：几何级数。**

```text
Σ_{n=0}^{∞} qⁿ：|q| < 1 收敛（和 1/(1-q)），|q| ≥ 1 发散。
```

**第二条：调和级数。**

```text
Σ_{n=1}^{∞} 1/n 发散。
```

**这个结论反直觉，必须会证。**

证明用的是"分组"：

```text
S₁ = 1
S₂ = 1 + 1/2
S₄ = 1 + 1/2 + 1/3 + 1/4 > 1 + 1/2 + 1/4 + 1/4 = 1 + 2/2
S₈ > 1 + 1/2 + (1/4+1/4) + (1/8+1/8+1/8+1/8) = 1 + 3/2
```

一般地：

```text
S_{2^m} > 1 + m/2
```

m 越大，右边越大，无界。

```text
所以部分和无界，级数发散。
```

**关键的一步是"把每组的项都放大成组里最小的那项"：**

```text
1/3 + 1/4 > 1/4 + 1/4 = 1/2
1/5 + … + 1/8 > 4 × 1/8 = 1/2
```

每组都超过 1/2，组数无限，所以总和无限。

**第三条：望远镜级数。**

```text
Σ_{n=1}^{∞} 1/(n(n+1))
```

裂项：

```text
1/(n(n+1)) = 1/n - 1/(n+1)
```

部分和：

```text
Sₙ = (1 - 1/2) + (1/2 - 1/3) + … + (1/n - 1/(n+1))
```

中间全部抵消：

```text
Sₙ = 1 - 1/(n+1)
```

取极限：

```text
S = 1
```

**答案 1。**

**这三条基准的分工：**

```text
几何级数：判断"q 的 n 次方"型。
调和级数：判断"1/n 型"，它是发散的分界线。
望远镜：判断"能裂项"型，直接求和。
```

**第四条（其实是调和级数的推广）：p 级数。**

```text
Σ_{n=1}^{∞} 1/n^p：p > 1 收敛，p ≤ 1 发散。
```

```text
p = 1：调和级数，发散（分界点）。
p = 2：收敛，和是 π²/6（这个值不用背证明，记住结论）。
p = 1/2：Σ 1/√n，发散（比调和还大）。
```

**这张表是这一章最重要的东西。**

后面所有"比较判别法"的题，都是拿待判级数去和 1/n^p 比。

**为什么分界线正好在 p = 1？**

看积分的对应物：

```text
∫₁^∞ dx/x^p：p > 1 收敛（结果是 1/(p-1)），p ≤ 1 发散。
```

```text
p = 1 时，∫ dx/x = ln x，对数增长无界。
p = 1.1 时，∫ x^{-1.1} dx = -10 x^{-0.1}，趋于 0，有界。
```

级数也是同样的机制：

```text
1/n 的累积按"对数速度"增长，永远不停。
1/n^{1.1} 的累积有上限。
```

所以 p = 1 不是随便选的整数，它是"累积量刚好从有界变无界"的那一点。

```text
这也是为什么比较法一定要"抓大头、定出 p、再对照"：
p 的相对位置决定了敛散，而不是系数。
```

## 4. 收敛的必要条件与三个陷阱

不知道必要条件，你会漏掉最省时间的一步。

很多题看一眼通项就能定发散，根本不用算。

**必要条件：**

```text
若 Σuₙ 收敛，则 uₙ → 0。
```

逆否命题更有用：

```text
若 uₙ 不趋于 0，则 Σuₙ 一定发散。
```

**为什么必要？**

```text
uₙ = Sₙ - S_{n-1}。
若 Sₙ → S，则 S_{n-1} → S，两者相减趋于 0。
```

**但反过来不成立，这是第一个陷阱。**

```text
uₙ → 0 推不出收敛。
```

反例就是调和级数：

```text
1/n → 0，但 Σ1/n 发散。
```

**所以判断顺序永远是：**

```text
第一步：看 uₙ → 0 吗？不 → 发散，结束。
第二步：趋于 0 了，才需要往下用判别法。
```

**第二个陷阱：把"通项趋于 0"当成"级数收敛"的充分条件。**

考试里最常见的错误选项就是这种：

```text
"因为 1/n → 0，所以 Σ1/n 收敛。" 错。
```

**第三个陷阱：乱用"加括号"和"去括号"。**

规则是这样的：

```text
收敛级数加括号，仍收敛，和不变。
发散级数加括号，可能变成收敛。
```

例：

```text
1 - 1 + 1 - 1 + …（发散，部分和在 1 和 0 之间跳）
加括号：(1-1) + (1-1) + … = 0 + 0 + … = 0（收敛）
```

所以：

```text
"加括号后收敛"推不出"原级数收敛"。
```

**反过来：**

```text
若原级数收敛，则任意加括号后仍收敛，且和相同。
```

这个方向可以用。

**第四个陷阱：把有限和的运算律搬到无限和。**

```text
有限和可以任意交换项的顺序，无限和不一定。
```

例：条件收敛的级数重排后可以变成任何值（黎曼重排定理）。

```text
Σ(-1)^{n-1}/n = ln2 ≈ 0.693
重排成 1 + 1/3 - 1/2 + 1/5 + 1/7 - 1/4 + …
可以变成 (3/2)ln2。
```

**这条在数一里不深考，但要知道"条件收敛的级数不能随意重排"。**

绝对收敛的级数才能随便重排。

```text
这就是第 9 节要讲的"绝对收敛"为什么重要。
```

## 5. 正项级数：比较判别法

先说没有它会怎样。

```text
每个级数都要先求部分和再取极限，几乎都求不出来。
```

比较判别法换了个思路：

```text
不求精确的和，只比大小。
和一个已知敛散的级数比，就能定下自己的敛散。
```

**判别法（不等式形式）：**

```text
设 0 ≤ uₙ ≤ vₙ（从某项起）。
若 Σvₙ 收敛，则 Σuₙ 收敛。
若 Σuₙ 发散，则 Σvₙ 发散。
```

**记忆口诀：**

```text
大的收敛 → 小的必收敛。
小的发散 → 大的必发散。
```

**为什么？**

```text
Σuₙ 的部分和单调递增（因为每项非负），
又有上界（不超过 Σvₙ 的和），
单调有界必有极限。
```

这是 01 篇"单调有界准则"的直接应用。

**注意方向，这是最容易错的地方：**

```text
"大的发散"推不出"小的发散"。
"小的收敛"推不出"大的收敛"。
```

**极限形式（更好用）：**

```text
设 uₙ, vₙ > 0，且 lim (uₙ/vₙ) = l。
0 < l < ∞：两者同敛散。
l = 0：Σvₙ 收敛 → Σuₙ 收敛（uₙ 比 vₙ 小得多）。
l = ∞：Σvₙ 发散 → Σuₙ 发散（uₙ 比 vₙ 大得多）。
```

**实战做法：抓大头。**

```text
看 uₙ 里 n 的最高次幂，把它留下来，其余扔掉。
扔完得到一个 1/n^p 型的式子，用 p 级数判。
```

**例 1：**

```text
Σ 1/(n² + 3n)
```

抓大头：

```text
分母最大项是 n²，所以 uₙ ~ 1/n²。
```

严格写：

```text
0 < 1/(n² + 3n) < 1/n²
```

而 Σ1/n² 收敛（p = 2 > 1）。

```text
所以原级数收敛。
```

**例 2：**

```text
Σ 1/(2n + 1)
```

抓大头：

```text
uₙ ~ 1/(2n)，和调和级数同阶。
```

严格写：

```text
1/(2n+1) > 1/(2n+2) = (1/2) · 1/(n+1)
```

而 Σ1/(n+1) 发散（调和级数去掉首项）。

```text
所以原级数发散。
```

**例 3：**

```text
Σ sin(1/n)
```

当 n 很大时，1/n 很小，sin(1/n) ~ 1/n。

```text
lim [sin(1/n)] / (1/n) = 1（重要极限）
```

由极限形式：

```text
Σ1/n 发散 → Σsin(1/n) 发散。
```

**例 4：**

```text
Σ (2n + 1)/(n³ + 1)
```

抓大头：

```text
分子 ~ 2n，分母 ~ n³，比值 ~ 2/n²。
```

```text
lim [ (2n+1)/(n³+1) ] / (1/n²) = lim (2n³ + n²)/(n³ + 1) = 2
```

0 < 2 < ∞，而 Σ1/n² 收敛。

```text
所以原级数收敛。
```

**比较判别法的三个操作步骤：**

```text
一、找 uₙ 的"主部"：分子分母各留最高次项。
二、用主部构造 vₙ = 1/n^p（或几何级数）。
三、算 lim uₙ/vₙ，看是不是 0 到 ∞ 之间的数。
```

**如果极限是 0 或 ∞ 呢？**

```text
l = 0：说明 uₙ 比 vₙ 还小，vₙ 收敛就能保证 uₙ 收敛。
l = ∞：说明 uₙ 比 vₙ 大得多，vₙ 发散就能保证 uₙ 发散。
```

**一个常用的"放大/缩小"技巧：**

```text
分母变小，分数变大：1/(n² - n) > 1/n²
分母变大，分数变小：1/(n² + n) < 1/n²
```

**例 5：**

```text
Σ 1/(n² - n)，n ≥ 2
```

分母 n² - n < n²，所以：

```text
1/(n² - n) > 1/n²
```

这个方向不能判收敛（大的发散推不出小的发散）。

**换一个方向：**

```text
n² - n = n(n-1) ≥ n²/2（当 n ≥ 2）
```

所以：

```text
1/(n² - n) ≤ 2/n²
```

```text
Σ2/n² 收敛 → 原级数收敛。
```

**这个例子说明：放大缩小要往"能判"的方向做，不是随手做。**

## 6. 正项级数：比值判别法

先说没有它会怎样。

```text
遇到阶乘、n 的 n 次方、2ⁿ 这类项，比较法很难找到合适的 vₙ。
```

比值判别法专治这类。

**判别法：**

```text
设 uₙ > 0，lim_{n→∞} u_{n+1}/uₙ = ρ。
ρ < 1：收敛。
ρ > 1（含 ρ = +∞）：发散。
ρ = 1：失效，另想办法。
```

**为什么 ρ < 1 就收敛？**

直觉：

```text
相邻两项的比值稳定在一个小于 1 的数 ρ 附近，
说明从某一项起，每项都比前一项小一个固定比例。
这就是"几何级数"的行为，而几何级数在公比小于 1 时收敛。
```

严格写：取 ρ 和 1 之间的一个数 q，从某项起 u_{n+1}/uₙ < q。

```text
于是 u_{N+k} < u_N · q^k，和几何级数比较，收敛。
```

**例 1：**

```text
Σ n!/nⁿ
```

算比值：

```text
u_{n+1}/uₙ = [(n+1)!/(n+1)^{n+1}] / [n!/nⁿ]
= (n+1) · nⁿ / (n+1)^{n+1}
= nⁿ/(n+1)ⁿ
= 1/(1 + 1/n)ⁿ
```

求极限：

```text
lim (1 + 1/n)ⁿ = e
```

所以：

```text
ρ = 1/e ≈ 0.368 < 1
```

```text
收敛。
```

**例 2：**

```text
Σ n²/2ⁿ
```

```text
u_{n+1}/uₙ = [(n+1)²/2^{n+1}] / [n²/2ⁿ]
= ((n+1)/n)² · (1/2)
= (1 + 1/n)² / 2
```

```text
ρ = 1/2 < 1
```

```text
收敛。
```

**例 3：**

```text
Σ 1/n!
```

```text
u_{n+1}/uₙ = [1/(n+1)!] / [1/n!] = 1/(n+1) → 0
```

```text
ρ = 0 < 1，收敛。
```

（顺便：这个级数的和是 e。）

**例 4：比值失效的例子。**

```text
Σ 1/n
```

```text
u_{n+1}/uₙ = n/(n+1) → 1
```

ρ = 1，判别法失效。

```text
但 Σ1/n 是发散的。
```

```text
Σ 1/n²
```

```text
u_{n+1}/uₙ = n²/(n+1)² → 1
```

ρ = 1，还是失效。

```text
但 Σ1/n² 是收敛的。
```

**这两条对比说明：**

```text
ρ = 1 时，收敛和发散都可能出现，比值判别法什么也判不了。
```

**遇到 ρ = 1 怎么办？**

```text
回到比较判别法，用 p 级数比。
```

这也是为什么 p 级数必须背：

```text
凡是含 n 的幂、又没有阶乘和指数函数的，比值法多半失效，只能比较。
```

**例 5：带参数的比值。**

```text
Σ 2ⁿ n!/nⁿ
```

算比值：

```text
u_{n+1}/uₙ = [2^{n+1}(n+1)!/(n+1)^{n+1}] / [2ⁿ n!/nⁿ]
= 2 · (n+1) · nⁿ/(n+1)^{n+1}
= 2 · nⁿ/(n+1)ⁿ
= 2/(1 + 1/n)ⁿ
```

```text
ρ = 2/e ≈ 0.736 < 1
```

```text
收敛。
```

把 2 换成 a，就是一道标准的"讨论参数"题：

```text
a < e：收敛。
a > e：发散。
a = e：ρ = 1，比值法失效，需要更细的估计（数一不考这个临界情形）。
```

**这类题的套路：**

```text
先算出 ρ 的表达式，再让 ρ 与 1 比较，反解出参数的范围。
```

## 7. 正项级数：根值判别法

先说没有它会怎样。

```text
遇到 uₙ 是"整个式子的 n 次方"，比值法要算 (n+1) 次方的商，很啰嗦。
```

根值法直接开 n 次方。

**判别法：**

```text
设 uₙ > 0，lim_{n→∞} ⁿ√uₙ = ρ。
ρ < 1：收敛。
ρ > 1：发散。
ρ = 1：失效。
```

**为什么？**

```text
ⁿ√uₙ → ρ < 1 说明从某项起 ⁿ√uₙ < q < 1，
即 uₙ < qⁿ，和几何级数比较，收敛。
```

**例 1：**

```text
Σ (n/(2n+1))ⁿ
```

开 n 次方：

```text
ⁿ√uₙ = n/(2n+1) → 1/2
```

```text
ρ = 1/2 < 1，收敛。
```

**例 2：**

```text
Σ (1 + 1/n)^{-n²}
```

开 n 次方：

```text
ⁿ√uₙ = (1 + 1/n)^{-n} = 1/(1+1/n)ⁿ → 1/e
```

```text
ρ = 1/e < 1，收敛。
```

**这道题用比值法会很痛苦，用根值法两行。**

**例 3：**

```text
Σ (1 - 1/n)^{n²}
```

开 n 次方：

```text
ⁿ√uₙ = (1 - 1/n)ⁿ → 1/e
```

```text
收敛。
```

**例 4：根值失效。**

```text
Σ 1/n²
```

```text
ⁿ√(1/n²) = n^{-2/n} → 1（因为 ln n / n → 0）
```

```text
ρ = 1，失效。
```

**比值和根值什么时候用哪个？**

```text
uₙ 里有阶乘、连乘、n 的 n 次方 → 比值法（阶乘能约掉）。
uₙ 本身是一个整体的 n 次方 → 根值法（开方就化掉）。
两者都能用时，通常根值更快。
```

**一条重要的关系：**

```text
若 lim u_{n+1}/uₙ 存在，则 lim ⁿ√uₙ 也存在且相等。
```

所以根值法适用的范围更广（比值极限不存在时，根值极限可能仍存在）。

```text
但反过来不成立：根值极限存在，比值极限可能不存在。
```

**实战建议：**

```text
先看形式。有阶乘 → 比值。有整体的 n 次幂 → 根值。
两者都不像 → 比较。
```

## 8. 交错级数：莱布尼茨判别法

先说没有它会怎样。

```text
正项级数的判别法全部失效，因为 (-1)ⁿ 让每一项都在变号。
```

交错级数的部分和会在两个值之间摆动，不能直接用"单调有界"。

**判别法（莱布尼茨）：**

```text
设 uₙ > 0，若
（1）uₙ 单调递减：u₁ ≥ u₂ ≥ u₃ ≥ …
（2）lim uₙ = 0，
则交错级数 Σ(-1)^{n-1} uₙ 收敛。
```

**两个条件，缺一不可。**

**为什么收敛？**

看部分和。

```text
考虑偶数项部分和 S_{2n} = (u₁ - u₂) + (u₃ - u₄) + … + (u_{2n-1} - u_{2n})
```

每一对括号都是非负的（因为 u 递减），所以：

```text
S_{2n} 单调递增。
```

再看：

```text
S_{2n} = u₁ - (u₂ - u₃) - (u₄ - u₅) - … - u_{2n} ≤ u₁
```

所以 S_{2n} 有上界 u₁。

```text
单调有界 → S_{2n} 有极限 S。
```

奇数项：

```text
S_{2n+1} = S_{2n} + u_{2n+1} → S + 0 = S。
```

两边极限相同，所以整个数列收敛。

**还有一个好用的副产品：误差估计。**

```text
|S - Sₙ| ≤ u_{n+1}
```

```text
截断误差不超过"被砍掉的第一项"。
```

这是交错级数独有的好处，正项级数没有这么干净的估计。

**例 1：调和交错级数。**

```text
Σ_{n=1}^{∞} (-1)^{n-1}/n = 1 - 1/2 + 1/3 - 1/4 + …
```

验证两条件：

```text
uₙ = 1/n，单调递减（1 > 1/2 > 1/3 > …）。
uₙ → 0。
```

```text
所以收敛。
```

它的和是 ln 2 ≈ 0.693（这个值 17 篇用幂级数算）。

**注意：它本身收敛，但它的绝对值级数 Σ1/n 发散。**

这就是"条件收敛"，第 9 节详细讲。

**例 2：**

```text
Σ (-1)^{n-1}/√n
```

```text
uₙ = 1/√n 递减，趋于 0。
```

```text
收敛。
```

但 Σ1/√n 发散（p = 1/2 ≤ 1），所以是条件收敛。

**例 3：**

```text
Σ (-1)^{n-1} · n/(n² + 1)
```

先看 uₙ = n/(n²+1) 是否递减。

用求导或作差：

```text
设 f(x) = x/(x²+1)，f'(x) = (1 - x²)/(x²+1)²
```

x > 1 时 f' < 0，所以从 n = 2 起递减。

```text
单调递减（从某项起即可），且 uₙ → 0。
```

```text
收敛。
```

**"从某项起递减"就够了，不要求从第一项就递减。**

**例 4：条件不满足会怎样。**

```text
Σ (-1)^{n-1} uₙ，其中 uₙ = 1/n（n 为奇数），uₙ = 1/n²（n 为偶数）
```

这里 uₙ → 0，但**不单调**（奇数项比相邻的偶数项大得多）。

它会收敛吗？

看奇数项部分和：

```text
u₁ + u₃ + u₅ + … = 1 + 1/3 + 1/5 + … 发散
```

偶数项：

```text
u₂ + u₄ + … = 1/4 + 1/16 + … 收敛
```

一正一负，正的部分发散，负的部分收敛，整体发散。

```text
所以"uₙ → 0"不够，必须单调。
```

**莱布尼茨判别法的检查清单：**

```text
□ 是交错级数吗（正负交替）？
□ uₙ > 0 吗？
□ uₙ 单调递减吗（从某项起即可）？
□ uₙ → 0 吗？
```

四条全过，收敛。

## 9. 绝对收敛与条件收敛

先说没有这个区分会怎样。

```text
把所有级数都当正项处理，或者都当交错处理，都会出错。
```

而且这个区分决定了一件大事：**能不能重排、能不能随便加括号。**

**定义：**

```text
若 Σ|uₙ| 收敛，则称 Σuₙ 绝对收敛。
若 Σuₙ 收敛但 Σ|uₙ| 发散，则称 Σuₙ 条件收敛。
```

**定理：绝对收敛 → 收敛。**

```text
Σ|uₙ| 收敛，则 Σuₙ 必收敛。
```

理由：

```text
0 ≤ uₙ + |uₙ| ≤ 2|uₙ|
```

右边收敛，由比较判别法，Σ(uₙ + |uₙ|) 收敛。

```text
而 uₙ = (uₙ + |uₙ|) - |uₙ|，
两个收敛级数相减，仍收敛。
```

**反过来不成立。**

```text
Σ(-1)^{n-1}/n 收敛，但 Σ1/n 发散。
```

**所以判断一个任意项级数，标准流程是：**

```text
第一步：看 Σ|uₙ| 收不收敛（变成正项级数，用比较/比值/根值）。
第二步：若收敛 → 绝对收敛 → 原级数收敛，结束。
第三步：若发散 → 再看原级数（可能用莱布尼茨），
        收敛则是条件收敛，不收敛则发散。
```

**例 1：**

```text
Σ (-1)^{n-1}/n²
```

看绝对值：

```text
Σ 1/n² 收敛（p = 2）。
```

```text
所以绝对收敛。
```

**例 2：**

```text
Σ (-1)^{n-1}/n
```

绝对值是调和级数，发散。

原级数用莱布尼茨，收敛。

```text
所以条件收敛。
```

**例 3：**

```text
Σ (-1)ⁿ (n/(n+1))ⁿ
```

先看绝对值：

```text
|uₙ| = (n/(n+1))ⁿ
```

用根值法：

```text
ⁿ√|uₙ| = n/(n+1) → 1
```

ρ = 1，失效。

**换个办法：**

```text
(n/(n+1))ⁿ = 1/(1 + 1/n)ⁿ → 1/e
```

所以 |uₙ| → 1/e ≠ 0。

```text
通项不趋于 0，级数发散。
```

**这道题的关键：先看通项。**

```text
如果 |uₙ| 不趋于 0，那么无论怎么交错，都发散。
```

**例 4：**

```text
Σ (-1)^{n-1} (n/(n²+1))
```

绝对值：

```text
Σ n/(n²+1)
```

抓大头：

```text
n/(n²+1) ~ 1/n
```

和调和级数同阶，发散。

原级数：例 3 已证收敛（莱布尼茨）。

```text
所以条件收敛。
```

**绝对收敛和条件收敛的差别，为什么重要？**

```text
绝对收敛的级数，可以任意重排、任意加括号，和不变。
条件收敛的级数，重排会改变和（甚至能变成任何指定的数）。
```

所以：

```text
在幂级数里做逐项运算、逐项积分，前提都是绝对收敛。
```

这也是 17 篇为什么那么在意收敛半径：**在收敛区间内部是绝对收敛的，所以可以放心操作。**

**把常见的四类摆在一起，做一个对照：**

```text
Σ (-1)^{n-1}/n²    绝对值收敛（p=2）      绝对收敛
Σ (-1)^{n-1}/n     莱布尼茨收敛，绝对值发散  条件收敛
Σ (-1)^{n-1}/√n    同上                    条件收敛
Σ (-1)^{n-1}·n     通项不趋于 0             发散
```

**判断口诀：**

```text
先问绝对值：收敛 → 绝对收敛，结束。
绝对值发散：再问原级数，收敛 → 条件收敛，不收敛 → 发散。
```

**一个容易忽略的点：**

```text
Σ(-1)^{n-1}/n^p 的敛散完全由 p 决定：
p > 1 绝对收敛；
0 < p ≤ 1 条件收敛；
p ≤ 0 发散（通项不趋于 0）。
```

这张表把 p 级数和交错级数合在一起，考试里能直接用。

## 10. 判别流程：拿到一道题先干什么

先说没有流程会怎样。

```text
拿到题就开始算比值，算出来是 1，卡住，换比较，又不知道和谁比。
```

**一条决策树，按顺序走：**

```text
第一步：通项 uₙ → 0 吗？
  不趋于 0 → 发散，结束（这一步能砍掉很多题）。

第二步：是正项级数吗（uₙ > 0）？
  是 → 走第三步。
  否 → 走第五步。

第三步：形式里有什么？
  有阶乘、n 的 n 次方、连乘 → 比值法。
  整个式子是一个 n 次方 → 根值法。
  只有 n 的幂、根号、对数 → 比较法（和 1/n^p 比）。

第四步：比较法抓大头，定出 p，对照 p 级数。

第五步：是交错级数吗？
  是 → 莱布尼茨（单调 + 趋于 0）。
  否 → 先看绝对值，转成正项级数处理。

第六步：判完之后，回答"绝对收敛还是条件收敛"。
```

**一个总结表：**

```text
判别法        适用形式                  结论
──────────────────────────────────────────────
必要条件     任何级数                  uₙ ↛ 0 → 发散
比较          1/n^p 型、根号、对数      与 p 级数比
比值          阶乘、nⁿ、连乘            ρ<1 收敛，ρ>1 发散
根值          整体的 n 次方             ρ<1 收敛，ρ>1 发散
莱布尼茨      交错、单调、→0            收敛
```

**三个"失效"要记住：**

```text
比值 ρ = 1 → 失效。
根值 ρ = 1 → 失效。
莱布尼茨不单调 → 失效。
```

**失效时的退路：**

```text
比值、根值失效 → 退回比较法，用 p 级数。
莱布尼茨失效 → 看通项是否趋于 0，或者直接分析部分和。
```

**四道速判，练一下流程。**

```text
第一道：Σ n/3ⁿ
```

有指数 3ⁿ，用比值：

```text
ρ = lim [(n+1)/3^{n+1}] / [n/3ⁿ] = lim (n+1)/(3n) = 1/3 < 1
```

```text
收敛。
```

```text
第二道：Σ 1/(n² + n)
```

裂项：

```text
1/(n²+n) = 1/n - 1/(n+1)
```

```text
望远镜，和 = 1，收敛。
```

```text
第三道：Σ (-1)ⁿ/√(n+1)
```

交错，uₙ = 1/√(n+1) 递减、趋于 0。

```text
莱布尼茨 → 收敛。
绝对值 Σ1/√(n+1) 是 p = 1/2 的 p 级数，发散。
所以条件收敛。
```

```text
第四道：Σ (n/(n+1))ⁿ
```

根值算出 ρ = 1，失效。

**这时要回头看通项：**

```text
uₙ = 1/(1 + 1/n)ⁿ → 1/e ≈ 0.368 ≠ 0
```

```text
通项不趋于 0 → 发散。
```

**第四道是典型陷阱：**

```text
根值失效不代表"判不了"，只代表"这个方法判不了"。
再看一眼通项，常常一眼就出结果。
```

## 11. 常见错误

不列一份清单，这一章的错会集中在同一批地方：必要条件当充分、ρ = 1 下结论、比较方向反。

**错误一：通项趋于 0 就判收敛。**

```text
1/n → 0，但 Σ1/n 发散。
```

必要条件不是充分条件。

**错误二：比值算出 1 就下结论。**

```text
ρ = 1 时，收敛和发散都可能。
```

例：Σ1/n（发散）和 Σ1/n²（收敛）的 ρ 都是 1。

**错误三：比较时方向搞反。**

```text
uₙ ≤ vₙ 且 Σvₙ 收敛 → Σuₙ 收敛。（对）
uₙ ≤ vₙ 且 Σvₙ 发散 → Σuₙ 发散。（错）
```

**错误四：交错级数只看 uₙ → 0，忘了单调。**

```text
必须两个条件同时满足。
```

**错误五：把 Σ1/n^p 的判据记反。**

```text
p > 1 收敛，p ≤ 1 发散。
p = 1 是分界，发散。
```

**错误六：绝对收敛和条件收敛搞混。**

```text
先算 Σ|uₙ|，收敛就是绝对收敛。
```

**错误七：随便给级数加括号或去括号。**

```text
收敛级数可以加括号；发散级数加括号可能变收敛。
```

**错误八：把有限和的运算律搬到无限和。**

```text
条件收敛的级数不能重排。
```

**错误九：忘记"从某项起"这个限定。**

```text
判别法里的"单调""0 ≤ uₙ ≤ vₙ"都只要求从某一项开始成立。
```

前面有限项不影响敛散。

**错误十：算错极限。**

```text
(1 + 1/n)ⁿ → e，不是 1。
n^{1/n} → 1，不是 ∞。
```

这两个极限在比值、根值题里反复出现，必须记牢。

**错误十一：以为收敛级数的通项必须单调递减。**

```text
Σuₙ 收敛推不出 uₙ 单调。
```

反例：

```text
uₙ 在 1/n 和 1/n² 之间交替取值，级数仍收敛，
但通项忽大忽小，根本不单调。
```

单调这个条件只在**莱布尼茨判别法**里需要，不是收敛的必要条件。

**错误十二：把"级数收敛"和"部分和有界"混为一谈。**

```text
正项级数：部分和有界 ⟺ 收敛（因为单调）。
一般级数：有界推不出收敛。
```

反例：

```text
1 - 1 + 1 - 1 + … 的部分和在 0 和 1 之间，
有界，但发散。
```

## 12. 数一怎么考

不知道考法，你会把时间花在求级数的和上。

而这一章绝大多数题只问"收敛还是发散"。

**题型一：判断敛散（选择题、填空题）。**

这是最高频的。

```text
给四个级数，问哪个收敛。
```

做法：按第 10 节的决策树，逐个过。

```text
先看通项，再看形式，最后选判别法。
```

**题型二：求级数的和。**

只考能求和的类型：

```text
几何级数、望远镜级数。
```

```text
Σ 1/(n(n+1)) = 1
Σ qⁿ = 1/(1-q)
```

**题型三：证明收敛（解答题）。**

常用工具：

```text
单调有界准则（部分和单调递增有上界）。
比较判别法（放缩）。
```

**题型四：绝对收敛还是条件收敛。**

标准流程，先绝对值再原级数。

**题型五：含参数的敛散讨论。**

```text
Σ 1/(n^p)，讨论 p。
Σ xⁿ/n，讨论 x（这是 17 篇的收敛半径）。
```

**题型六：截断误差估计。**

交错级数有一个现成的估计：

```text
|S - Sₙ| ≤ u_{n+1}
```

例：

```text
用 Σ(-1)^{n-1}/n 的前几项近似 ln2，要求误差小于 0.01，n 取多少？
```

```text
u_{n+1} = 1/(n+1) < 0.01 → n + 1 > 100 → n ≥ 100
```

```text
取前 100 项即可。
```

**这类题只需要一个不等式，不需要求和。**

```text
而且要注意：只有交错级数（满足莱布尼茨条件）才有这个估计。
正项级数的误差要靠别的办法（比如和几何级数比）。
```

**一道数一风格的完整题。**

```text
判断 Σ_{n=1}^{∞} (-1)^{n-1} · n/(n² + 2) 的敛散性，
若收敛，说明是绝对收敛还是条件收敛。
```

**第一步，通项。**

```text
n/(n²+2) → 0，必要条件满足。
```

**第二步，绝对值。**

```text
Σ n/(n²+2)
```

抓大头：n/(n²+2) ~ 1/n。

严格写：

```text
n/(n²+2) ≥ n/(n²+2n²) = 1/(3n)（当 n ≥ 1）
```

（因为 2 ≤ 2n²。）

```text
Σ1/(3n) 发散 → 原绝对值级数发散。
```

**第三步，原级数。**

交错，uₙ = n/(n²+2)。

单调性：

```text
f(x) = x/(x²+2)，f'(x) = (2 - x²)/(x²+2)²
```

x > √2 时递减，所以从 n = 2 起单调递减。

```text
uₙ → 0。
```

由莱布尼茨，收敛。

**结论：条件收敛。**

**再补一道"比较 + 比值都不好用"的题。**

```text
判断 Σ 1/(n ln n)（n ≥ 2）的敛散性。
```

比值法：

```text
u_{n+1}/uₙ = [n ln n]/[(n+1) ln(n+1)] → 1，失效。
```

比较法：

```text
1/(n ln n) 比 1/n 小，比 1/n^1.1 大？
```

不好直接比。

**用积分判别法：**

```text
f(x) = 1/(x ln x) 单调递减、非负。
∫₂^{∞} dx/(x ln x) = [ln ln x]₂^{∞} = ∞
```

```text
积分发散 → 级数发散。
```

**积分判别法是数一考纲里的工具，虽然不常考，但遇到 1/(n ln n) 这类题只有它好使。**

它的依据在 09 篇：

```text
Σf(n) 与 ∫₁^∞ f(x) dx 同敛散（f 非负、单调减少）。
```

## 13. 和其他章节怎么连

不接回其他章节，级数会显得像一门独立的小课。

其实它就是"部分和的极限"，而极限、积分、幂级数全在同一个链条上。

**往回连：01 函数与极限。**

级数收敛的定义就是"部分和数列有极限"。

```text
所以极限的所有性质（四则运算、夹逼、单调有界）都能用。
```

比较判别法的证明用的就是单调有界准则。

**往回连：09 反常积分。**

积分判别法把级数和积分绑在一起：

```text
Σ f(n) 与 ∫₁^∞ f(x) dx 同敛散。
```

所以 p 级数和 p 积分是同一张表：

```text
Σ1/n^p 与 ∫₁^∞ dx/x^p：都是 p > 1 收敛。
```

**往前连：17 幂级数。**

幂级数 Σaₙxⁿ 的收敛性依赖数项级数的判别法：

```text
固定 x，它就是一个数项级数。
用比值法求收敛半径：lim |a_{n+1}/aₙ| = 1/R。
```

绝对收敛的概念在这里变得关键：

```text
收敛区间内部绝对收敛 → 可以逐项求导、逐项积分。
```

**往前连：18 傅里叶级数。**

傅里叶系数是积分，级数的收敛性靠狄利克雷条件。

```text
系数的衰减速度决定了级数收敛得多快。
```

**横向连：11 全微分与多元。**

二重级数、含参级数在数一里不考，但"一致收敛"这个概念来自同一套思想。

```text
这一篇只要求会判数项级数，不要求一致收敛。
```

**和其他学科：**

```text
概率里"概率之和为 1"是级数收敛。
数值计算里"截断误差"是余项估计。
信号处理里"傅里叶级数"是展开。
```

都建立在这一篇的定义上。

### 自检三问

**第一问：为什么"通项趋于 0"不能保证级数收敛？**

因为"趋于 0"只说明了每项越来越小，没说"小得够快"。

```text
调和级数：1/n → 0，但 Σ1/n 发散。
```

它的项确实在变小，可是变小得太慢：

```text
S_{2^m} > 1 + m/2，每翻一倍项数，和至少加 1/2。
```

所以部分和无界。

反过来，"通项不趋于 0"一定能推出"发散"，这个方向是可靠的。

```text
所以判断顺序永远是：先看通项，再看形式。
```

**第二问：比值法和根值法都得到 ρ = 1，为什么就没办法了？**

因为 ρ = 1 这个值，收敛和发散的级数都能取到。

```text
Σ1/n：ρ = 1，发散。
Σ1/n²：ρ = 1，收敛。
```

这两个级数的比值极限都是 1，但敛散相反。

```text
所以 ρ = 1 时，判别法提供的信息量为零。
```

退路是回到比较法，用 p 级数把"1/n^p 里的 p"定出来：

```text
p > 1 收敛，p ≤ 1 发散。
```

**第三问：绝对收敛和条件收敛，为什么必须分开？**

因为它们的"稳定性"完全不同。

```text
绝对收敛：可以任意重排、任意加括号，和不变。
条件收敛：不能重排，重排后和可能变成任何数。
```

典型例子：

```text
Σ(-1)^{n-1}/n = ln2。
重排后可以得到 (3/2)ln2，甚至可以得到任意指定的值。
```

所以在做逐项运算（求导、积分、换序）之前，必须先确认绝对收敛。

```text
这也是幂级数在收敛区间内部才敢逐项求导的原因。
```

## 14. 小结 + 下一篇

没有小结，四个判别法会互相盖住，考场上想不起来先用哪个。

压成一张卡片：

```text
定义：Σuₙ 收敛 ⟺ Sₙ = u₁+…+uₙ 有极限
基准：Σqⁿ（|q|<1 收敛，和 1/(1-q)）
      Σ1/n（发散）
      Σ1/n^p（p>1 收敛，p≤1 发散）
必要：uₙ → 0（不满足则发散，满足不保证收敛）
比较：大的收敛→小的收敛；小的发散→大的发散
比值：ρ = lim u_{n+1}/uₙ，ρ<1 收敛，ρ>1 发散，ρ=1 失效
根值：ρ = lim ⁿ√uₙ，同上
莱布尼茨：交错 + 单调递减 + 趋于 0 → 收敛
绝对收敛：Σ|uₙ| 收敛；否则若原级数收敛，叫条件收敛
```

四步公式的统一形态：

```text
算什么 → 判断无限相加能否得到有限数
逐符号 → Σuₙ、Sₙ、S、余项 rₙ
代数字 → 先算部分和（几何、望远镜），或者用判别法
适用条件 → 正项 / 交错 / 任意项，各有各的工具
```

考场上的判断顺序：

```text
一、通项趋于 0 吗？
二、正项还是交错？
三、有阶乘/指数 → 比值或根值
四、只有幂次 → 比较，抓大头定 p
五、交错 → 莱布尼茨，再判绝对收敛
六、ρ = 1 或失效 → 退回比较或积分判别法
```

三句提醒。

```text
第一句：先看通项，能砍掉一半的题。
第二句：比值和根值算出 1，等于什么都没算。
第三句：判完敛散，还要回答"绝对还是条件"。
```

下一篇把"数"换成"函数"。

```text
这一篇加的是固定的数：u₁ + u₂ + …
下一篇加的是带 x 的项：a₀ + a₁x + a₂x² + …
于是问题从"收不收敛"变成"在哪些 x 上收敛"。
```

问题变成：

```text
高等数学系统讲解 17：幂级数
```

那一篇会回答：

```text
收敛半径怎么求？为什么是 R 这个数？
在收敛区间内部，为什么可以逐项求导、逐项积分？
e^x、sin x、ln(1+x) 的展开式怎么来的？
```
