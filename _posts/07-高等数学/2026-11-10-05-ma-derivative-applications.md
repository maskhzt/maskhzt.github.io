> **读这篇之前，你只需要知道**：导数是"曲线在某一点的切线斜率"，也就是函数在这一点的变化率；函数图像是一条画在坐标系里的线，横轴是输入，纵轴是输出。
> **这篇讲什么**：只盯着 f'(x) 和 f''(x) 的正负号，就能把一条曲线在哪里升、在哪里降、最高点最低点在哪、往上弯还是往下弯全部说清楚，再给它配上一两条永远贴着的直线。
> **一个类比**：开车只看仪表盘的速度和"速度在不在变大"，就能推断这一路是上坡还是下坡、哪一刻正好到坡顶、路面是凹下去还是鼓起来。

前面几篇把导数算出来了。

(x³)' = 3x²，这个动作你已经练熟。

但考试不问你 3x² 等于几。

考试问的是：

```text
这个函数在哪里升、哪里降？
它的最高点在哪？
x 越来越大时，图像贴着什么线走？
```

这些问题的答案，全藏在 f'(x) 和 f''(x) 的**正负号**里。

不求值，只判断符号。

这就是这一篇要做的事。

## 1. 为什么需要它（不给会怎样）

没有这套工具，你会卡在一个很尴尬的位置：导数算得又快又准，一遇到"求最大值"就退回初中办法——描点。

描点的问题在于它靠运气。

```text
f(x) = x³ - 3x² + 1
取 x = -2, -1, 0, 1, 2, 3 描点
```

这些点连起来，像一条先降后升的线。

真实图像在 x = 0 处有一个局部最高点，在 x = 2 处有一个局部最低点。

如果你的采样点刚好是 -2, -1, 1, 2, 3，你会把中间那个"鼓起"整个漏掉。

采样点越稀，漏得越多。

导数给出的判断是**精确的**：

```text
f'(x) > 0 的整段区间，函数就是升的，一个点都不会漏。
```

第二个问题更现实。

数一的解答题里，有一类固定题型叫"求单调区间与极值"，分值常在 10 分上下。

它的评分点是：

```text
定义域 → 求导 → 解 f'(x) = 0 → 列表判号 → 写出区间和极值
```

少了"列表判号"这一步，即使答案对，也会被扣过程分。

第三个问题是不等式证明。

证明 x > 0 时 ln(1+x) < x，用中值定理能证，用单调性也能证，而且更快。

单调性是证明不等式的第一把工具。

所以这一篇不是"导数的补充"，是导数真正开始干活的起点。

顺带说清楚它在中值定理与积分之间的位置。

```text
03 篇：会算 f'(x)
04 篇：知道 f' 的某个中间值必然取到（存在性）
05 篇：只用 f' 和 f'' 的符号，反推出 f 的整张画像
```

三篇连起来，构成"微分学"这条线的完整闭环。

再往下一句，就是积分学。

## 2. 最小模型：两个符号管四件事

先把这个模型说清楚，后面所有内容都是它的展开。

导数 f'(x) 管两件事：升降、极值。

二阶导数 f''(x) 管两件事：弯向、拐点。

```text
f'(x) 的符号  →  曲线往上走还是往下走
f'(x) 变号    →  极值点（山坡的顶或谷的底）
f''(x) 的符号 →  曲线往上弯（碗）还是往下弯（帽）
f''(x) 变号   →  拐点（弯向改变的地方）
```

符号先读一遍：

**f'(x)**：读"f 撇 x"，也叫一阶导数，表示"x 增加一点点时，f 增加得多快"。

**f''(x)**：读"f 两撇 x"，也叫二阶导数，是 f'(x) 再求一次导，表示"斜率本身变化得多快"。

**驻点**：使 f'(x) = 0 的点，读"zhù diǎn"。驻是"停留"的意思，斜率在这里停住了，暂时是平的。

**极值点**：函数在这一点附近取到最大或最小。极大值不是"整个函数的最大值"，只是"这一小片区域里的最大值"。

**拐点**：曲线弯向发生改变的点。拐点是**一个点**，要写成 (x₀, f(x₀))，不能只写横坐标。

**渐近线**：一条直线，曲线越走越贴近它，但通常永远碰不到。

这六个词里，前两个是工具，后四个是结论。

现在补一张图，把 f' 和 f'' 的分工画出来：

```text
        f''<0 帽子形
         ╱‾‾╲
        ╱    ╲        ← 这一段斜率在变小
   ____╱      ╲____
      拐点↑      ↑拐点
   f''>0 碗形    f''>0 碗形
```

一个反直觉的地方：f''(x) 的正负和 f(x) 的正负没有关系。

f(x) = x² 在整个实数上都 ≥ 0，但它的 f''(x) = 2 恒为正。

f(x) = -x² 在整个实数上都 ≤ 0，f''(x) = -2 恒为负。

f(x) = x³ 有正有负，f''(x) = 6x 也有正有负。

两者各说各的。

把两个符号组合起来，就得到四种基本形状：

```text
f' > 0, f'' > 0：升且凹向上，越升越快（像 e^x 的右半边）
f' > 0, f'' < 0：升且凸向上，越升越慢（像 ln x）
f' < 0, f'' > 0：降且凹向上，越降越慢（像 1/x 在第一象限）
f' < 0, f'' < 0：降且凸向上，越降越快（像 -x² 的右半边）
```

画图的全部素材就是这四种形状。

实际动手时，顺序是：

```text
先画定义域和渐近线 → 再标驻点、拐点 → 最后按四种形状连线
```

先标点后连线，比从头画到尾可靠得多。

## 3. 单调性：把 f'(x) 的符号翻译成升降

没有这一节，你就只能看着 f'(x) 的表达式发呆，不知道它到底说明了什么。

单调性的核心只有一句：

```text
f'(x) > 0 → 函数严格递增
f'(x) < 0 → 函数严格递减
```

原因是 f'(x) 就是切线斜率，斜率为正，往右走就往上走。

严格的证明要用拉格朗日中值定理：在区间上任取 x₁ < x₂，存在 ξ 使 f(x₂) - f(x₁) = f'(ξ)(x₂ - x₁)，而 x₂ - x₁ > 0，所以 f' 的符号直接决定差值的符号。

**公式四步：判单调**

第一步，算什么：算出 f'(x) 在哪些区间取正、哪些区间取负。

第二步，逐符号：f'(x) 是导数；f'(x) = 0 的点是驻点，是升降可能改变的地方；f'(x) 不存在的点同样是分界点。

第三步，代数字：以 f(x) = x³ - 3x² + 1 为例。

```text
f'(x) = 3x² - 6x = 3x(x - 2)
令 f'(x) = 0，得 x = 0 或 x = 2
代 x = -1：f'(-1) = 3 + 6 = 9 > 0
代 x = 1 ：f'(1) = 3 - 6 = -3 < 0
代 x = 3 ：f'(3) = 27 - 18 = 9 > 0
```

第四步，适用条件：f 在区间上连续、在区间内部可导；分界点必须取全，包括 f' = 0 的点和 f' 不存在的点；只判断符号的正负，不比较 f' 的绝对值大小。

最后一条常被忽略。

f'(x) = 100 和 f'(x) = 0.01 都是正的，都只说明"函数在升"。

斜率的大小只影响曲线陡不陡，不影响区间怎么划。

现在把三个数字填进表里：

```text
x       (-∞, 0)   0    (0, 2)   2    (2, +∞)
f'(x)      +      0      -      0      +
f(x)      升    极大    降    极小     升
```

结论写成区间形式：

```text
单调递增区间：(-∞, 0] 和 [2, +∞)
单调递减区间：[0, 2]
```

端点写开写闭都不影响结论，因为单调性讨论的是区间内部的走向。

两种写法都被接受，但一套答案里要统一。

一个必须避免的写法：

```text
错误：单调递增区间是 (-∞, 0] ∪ [2, +∞)
```

两个递增区间不能用并集连起来。

理由是"单调递增"要求对区间内**任意**两点都成立：只要 x₁ < x₂，就必须有 f(x₁) < f(x₂)。

而 (-∞,0] ∪ [2,+∞) 不是一条连续的区间，中间断了一截，断的那一截正好是递减的。

抓反例的方法：在并集里挑两个点，让 x₁ < x₂ 却出现 f(x₁) > f(x₂)。

取 x₁ = 1（落在中间那段递减区间上），x₂ = 2。

```text
f(1) = 1 - 3 + 1 = -1
f(2) = 8 - 12 + 1 = -3
```

-1 > -3，也就是 f(x₁) > f(x₂)。

递增被破坏。

所以正确写法是"分开说"：

```text
f 在 (-∞, 0] 上单调递增，在 [2, +∞) 上也单调递增
但不能说 f 在 (-∞,0] ∪ [2,+∞) 上单调递增
```

一句话记住：

```text
单调区间要分开写，用"和"字连，不用"∪"。
```

判号有两个细节容易出错。

一是分界点必须包含 f'(x) 不存在的点。

f(x) = x^(2/3) 在 x = 0 处不可导，而 0 恰好是极小值点，漏掉它就得出错误结论。

二是每个开区间只需代一个点。

理由是：两个相邻分界点之间如果还有一个 f' 的零点，那个零点本身就该是分界点，矛盾。

所以 f' 在相邻分界点之间不会变号，代一个数就够。

## 4. 算一遍：单调区间与极值列表

没有这一节，上面的规则永远停在纸面，考场上写不出那五行表。

题目：求 f(x) = x³ - 3x² + 1 的单调区间与极值。

**第一步，写定义域。**

```text
多项式，定义域是 (-∞, +∞)
```

**第二步，求导并解驻点。**

```text
f'(x) = 3x² - 6x = 3x(x - 2)
3x(x - 2) = 0  →  x = 0 或 x = 2
```

**第三步，列表判号。**

选三个测试点：-1、1、3。

```text
区间        (-∞,0)   x=0   (0,2)   x=2   (2,+∞)
测试点        -1             1             3
f' 的值        9              -3            9
f' 的符号      +       0      -       0      +
f 的走向       升     极大    降     极小    升
```

**第四步，算极值。**

```text
f(0) = 0 - 0 + 1 = 1        → 极大值 1
f(2) = 8 - 12 + 1 = -3      → 极小值 -3
```

**第五步，写结论。**

```text
单调递增区间：(-∞, 0] 和 [2, +∞)
单调递减区间：[0, 2]
极大值 f(0) = 1，极小值 f(2) = -3
```

注意"极大值"和"最大值"的区别在这里就显出来了。

这个函数没有最大值，因为 x → +∞ 时 f(x) → +∞。

它也没有最小值，因为 x → -∞ 时 f(x) → -∞。

但它有极大值 1 和极小值 -3，两个都是"局部冠军"。

再看一个带定义域限制的例子，这是考试里更容易错的形式。

题目：求 f(x) = x + 4/x 在 [1, 4] 上的单调区间与最值。

```text
f'(x) = 1 - 4/x² = (x² - 4)/x²
令 f'(x) = 0：x² = 4，x = 2 或 x = -2
在 [1, 4] 内只有 x = 2
```

判号：

```text
x ∈ [1, 2)：取 x = 1，f'(1) = 1 - 4 = -3 < 0，递减
x ∈ (2, 4]：取 x = 4，f'(4) = 1 - 1/4 = 3/4 > 0，递增
```

所以 x = 2 是极小值点，f(2) = 2 + 2 = 4。

再比端点：f(1) = 1 + 4 = 5，f(4) = 4 + 1 = 5。

```text
最大值 5（在 x = 1 和 x = 4 都取到）
最小值 4（在 x = 2 取到）
```

这个例子的教学价值在于：

极值点只提供"候选"，最值还要和端点比。

第三个例子带参数，是解答题的高频形式。

题目：讨论 f(x) = ln x - ax（a 为常数，x > 0）的单调性。

```text
f'(x) = 1/x - a = (1 - ax)/x
```

分母 x 在定义域内恒正，所以符号完全由分子 1 - ax 决定。

分两类：

```text
a ≤ 0：1 - ax > 0 恒成立，f 在 (0, +∞) 上单调递增
a > 0：驻点 x = 1/a
       x ∈ (0, 1/a) 时 f' > 0，递增
       x ∈ (1/a, +∞) 时 f' < 0，递减
```

a > 0 时的最大值：

```text
f(1/a) = ln(1/a) - a·(1/a) = -ln a - 1
```

这道题考的不是计算，是分类讨论的完整性。

a ≤ 0 和 a > 0 两类都必须写出来，少一类就丢一半分。

## 5. 极值判定：两个充分条件怎么选

没有这一节，你会把所有 f'(x) = 0 的点都当成极值点，然后在一道选择题上丢掉 4 分。

**第一充分条件**：f'(x) 在 x₀ 两侧变号。

```text
左正右负 → 极大值
左负右正 → 极小值
左右同号 → 不是极值
```

**第二充分条件**：f'(x₀) = 0 且 f''(x₀) ≠ 0。

```text
f''(x₀) < 0 → 极大值（开口向下，像帽子顶）
f''(x₀) > 0 → 极小值（开口向上，像碗底）
```

第二充分条件用起来快，因为它只要代一个数。

但它有一个前提：f''(x₀) ≠ 0。

如果 f''(x₀) = 0，第二条件失效，必须退回第一条件。

反例就在这里：

```text
f(x) = x⁴
f'(x) = 4x³，f'(0) = 0
f''(x) = 12x²，f''(0) = 0
```

第二条件判不出来。

但看 f'(x) = 4x³ 在 0 两侧的符号：x < 0 时为负，x > 0 时为正，变号，所以 x = 0 是极小值点，f(0) = 0。

再看：

```text
f(x) = x³
f'(x) = 3x²，f'(0) = 0
f''(x) = 6x，f''(0) = 0
```

同样判不出来。

看 f'(x) = 3x² 在 0 两侧：都为正，不变号，所以 x = 0 **不是**极值点。

同样是 f'(0) = 0 且 f''(0) = 0，一个极值一个不是极值。

这就是为什么第一条件是根本，第二条件只是加速器。

数一的选择题很喜欢在这里设陷阱：

```text
"若 f'(x₀) = 0，则 x₀ 一定是极值点"     ← 错
"若 f'(x₀) = 0 且 f''(x₀) > 0，则 x₀ 是极小值点"  ← 对
"若 f''(x₀) = 0，则 (x₀, f(x₀)) 是拐点"  ← 错
```

第三句的反例是 f(x) = x⁴，f''(0) = 0，但 f'' 在 0 两侧都为正，不变号，所以 (0,0) 不是拐点。

把第二条件用在 §4 的例子上，速度能快一半。

```text
f(x) = x³ - 3x² + 1
f'(x) = 3x² - 6x，驻点 x = 0, 2
f''(x) = 6x - 6
f''(0) = -6 < 0  →  x = 0 是极大值点，极大值 1
f''(2) = 6 > 0   →  x = 2 是极小值点，极小值 -3
```

不用列表，两个数就定了。

代价是必须确认 f'' 在驻点处不为零，而这一步恰好最容易被略过。

选择策略：

```text
f'' 好算、且在驻点处明显不为零 → 用第二条件
f'' 复杂、或驻点处 f'' 可能为零 → 用第一条件列表
```

## 6. 凹凸与拐点

没有这一节，你画出来的曲线只有"升降"，没有"弯法"，图像会画成折线，一看就不对。

凹凸说的是曲线的弯曲方向。

定义要小心，因为不同教材的叫法相反。

本文统一用下面这套：

```text
f''(x) > 0：曲线凹向上，形状像碗 ∪，切线在曲线下方
f''(x) < 0：曲线凸向上，形状像帽 ∩，切线在曲线上方
```

"凹向上"这个词自己就说明了形状：开口朝上。

**公式四步：判凹凸与拐点**

第一步，算什么：算出 f''(x) 的符号，找出 f''(x) = 0 的点和 f'' 不存在的点。

第二步，逐符号：f''(x) 读"f 两撇 x"，是斜率 f'(x) 的导数；f'' > 0 表示斜率在变大，曲线越来越陡地往上拐。

第三步，代数字：以 f(x) = ln(1 + x²) 为例。

```text
f'(x) = 2x / (1 + x²)
f''(x) = [2(1 + x²) - 2x·2x] / (1 + x²)²
       = (2 + 2x² - 4x²) / (1 + x²)²
       = 2(1 - x²) / (1 + x²)²
```

令 f''(x) = 0：1 - x² = 0，x = ±1。

代数字判号：

```text
代 x = 0：f''(0) = 2/1 = 2 > 0
代 x = 2：f''(2) = 2(1 - 4)/25 = -6/25 < 0
代 x = -2：f''(-2) = -6/25 < 0
```

第四步，适用条件：f''(x) 存在；f''(x₀) = 0 只是可疑点，必须验证两侧符号是否变号；分母 (1 + x²)² 恒正，所以符号完全由分子 1 - x² 决定，这类"分母恒正"的观察能省很多力气。

列表：

```text
x       (-∞,-1)   -1    (-1,1)    1    (1,+∞)
f''(x)     -       0       +      0      -
f(x)      凸      拐点    凹     拐点    凸
```

算拐点坐标：

```text
f(-1) = ln(1 + 1) = ln 2
f(1)  = ln 2
```

结论：

```text
凹向上区间：(-1, 1)
凸向上区间：(-∞, -1) 和 (1, +∞)
拐点：(-1, ln 2) 与 (1, ln 2)
```

这道题还有一个额外收获：f(x) = ln(1 + x²) 是偶函数，图像关于 y 轴对称。

算出 x = 1 那一侧，x = -1 那一侧可以直接对称过来。

用对称性检查答案，是考场上的好习惯。

关于拐点，有一个常见误解要说清。

拐点看的是 f'' 的**变号**，不是 f' 的变号。

```text
f'(x) 变号 → 极值点
f''(x) 变号 → 拐点
```

两者可以同时发生，也可以各管各的。

比如 f(x) = x³ - 3x² + 1：

```text
f'(x) = 3x(x - 2)，在 x = 0 和 x = 2 变号 → 两个极值点
f''(x) = 6x - 6，在 x = 1 变号 → 一个拐点 (1, -1)
```

三个点互不重合。

拐点还有一个好用的几何特征：曲线在拐点处**穿过**自己的切线。

```text
拐点：切线一侧曲线在上方，另一侧在下方，切线被穿过
极值点：曲线整段都在切线同侧，不穿过
```

所以题目里出现"曲线穿过切线"这种描述，要想到拐点；出现"曲线与切线只相切不穿过"，要想到极值。

把 §4 那个函数拿出来，补上凹凸这一段，它才是一张完整的画像。

```text
f(x) = x³ - 3x² + 1
f''(x) = 6x - 6 = 6(x - 1)
```

```text
x      (-∞,1)    1    (1,+∞)
f''       -      0       +
f         凸     拐点    凹
```

拐点坐标：

```text
f(1) = 1 - 3 + 1 = -1  →  拐点 (1, -1)
```

把两张表拼起来看，这个函数的完整形状是：

```text
(-∞,0)   升、凸
x = 0    极大值 1
(0,1)    降、凸
x = 1    拐点 (1,-1)
(1,2)    降、凹
x = 2    极小值 -3
(2,+∞)   升、凹
```

六个区间段，四种形状，全部由两个符号决定。

## 7. 渐近线：三类，三种算法

没有这一节，你画的图在两端是"飘"的，不知道它该贴近哪条线，也不知道哪里可以断开。

渐近线一共三类，判断依据都是极限。

**第一类，垂直渐近线。**

如果 x 从某一侧趋近 x₀ 时 f(x) 趋于无穷，那么直线 x = x₀ 是垂直渐近线。

```text
lim(x→x₀⁺) f(x) = ∞ 或 lim(x→x₀⁻) f(x) = ∞  ⇒  x = x₀
```

垂直渐近线只可能出现在"函数没定义"的点，或者定义域边界。

所以找法是：先把分母为零的点、对数的零点、tan 的奇点列出来，逐个算单侧极限。

**第二类，水平渐近线。**

```text
lim(x→+∞) f(x) = b  ⇒  y = b
lim(x→-∞) f(x) = b  ⇒  y = b
```

两个方向要分开算，可能得到两条不同的水平渐近线。

典型例子是 f(x) = arctan x：x → +∞ 时趋于 π/2，x → -∞ 时趋于 -π/2，所以有 y = π/2 和 y = -π/2 两条。

**第三类，斜渐近线。**

这是最容易丢分的一类，因为它要算两个极限。

```text
a = lim(x→∞) f(x)/x      （要求存在、有限、且 a ≠ 0）
b = lim(x→∞) [f(x) - a·x]（要求存在且有限）
则 y = a·x + b 是斜渐近线
```

**公式四步：求斜渐近线**

第一步，算什么：找一条直线 y = ax + b，使得 x → ∞ 时 f(x) 与它的差趋于 0。

第二步，逐符号：a 是这条直线的斜率，用 f(x)/x 的极限算，因为"曲线大致按 a 倍的速度增长"；b 是它在 y 轴上的截距，用 f(x) - ax 的极限算，因为减掉斜率部分后剩下的就是常数偏移。

第三步，代数字：以 f(x) = (x² + 1)/x 为例。

```text
a = lim(x→∞) [(x² + 1)/x] / x
  = lim(x→∞) (x² + 1)/x²
  = lim(x→∞) (1 + 1/x²) = 1

b = lim(x→∞) [f(x) - 1·x]
  = lim(x→∞) [(x² + 1)/x - x]
  = lim(x→∞) [(x² + 1 - x²)/x]
  = lim(x→∞) 1/x = 0
```

所以斜渐近线是 y = x。

第四步，适用条件：a 必须存在且不为 0；a = 0 时不能算斜渐近线，要回到水平渐近线单独判断；x → +∞ 和 x → -∞ 要分别算，两边可能给出不同的 a 和 b。

把垂直渐近线也补上：

```text
x → 0⁺ 时 f(x) = x + 1/x → +∞
x → 0⁻ 时 f(x) = x + 1/x → -∞
所以 x = 0 是垂直渐近线
```

水平渐近线呢？

```text
x → ∞ 时 f(x) = x + 1/x → ∞
```

极限不是有限数，所以**没有**水平渐近线。

这个函数一共两条渐近线：x = 0 和 y = x。

画出来是这样的：

```text
        │        ╱ y = x
        │      ╱
        │    ╱
   ─────┼──╱─────
        │╱
        ╱
      ╱ │
```

曲线分成两支，一支在第三象限贴着 y = x，一支在第一象限贴着 y = x，两支都贴着 x = 0 往上或往下跑。

一个高频陷阱：

```text
f(x) = (x² + 1)/x 有斜渐近线 y = x，同时 x → ∞ 时 f(x) → ∞
```

"函数趋于无穷"和"有斜渐近线"可以同时成立。

水平渐近线要求极限是有限数，斜渐近线不要求。

另一个陷阱：

```text
f(x) = x + sin x
a = lim f(x)/x = lim (1 + sin x / x) = 1
b = lim [f(x) - x] = lim sin x  → 不存在
```

a 算出来了，b 不存在，所以**没有**斜渐近线。

只算 a 就下结论，是这类题最常见的错。

再补一个有理函数的例子，把三类一起查。

题目：求 f(x) = (2x² + 3)/(x² - 1) 的所有渐近线。

```text
x = 1：分母为零，分子为 5 ≠ 0，x → 1 时 f → ∞ → 垂直渐近线 x = 1
x = -1：同理 → 垂直渐近线 x = -1
x → ±∞：分子分母同次，极限为系数之比 2/1 = 2 → 水平渐近线 y = 2
斜渐近线：a = lim f(x)/x = 0，不构成
```

一共三条。

有理函数有一个快速判断法：

```text
分母次数 > 分子次数：水平渐近线 y = 0，另加垂直渐近线
分母次数 = 分子次数：水平渐近线 y = 首项系数之比
分母次数 = 分子次数 + 1：做多项式除法，商就是斜渐近线
```

第三条的依据是：做除法后 f(x) = 商 + 余/分母，x → ∞ 时余项趋于 0，商就是贴着走的那条线。

## 8. 最值：从候选里挑冠军

没有这一节，"求最大值"就永远停在"看起来最高"的层面。

最值分两种场合。

**闭区间上的最值。**

定理保证了：f 在 [a, b] 上连续，则一定有最大值和最小值。

求法是把三类候选点全算一遍，比大小：

```text
候选一：驻点（f'(x) = 0 的点）
候选二：不可导点（f'(x) 不存在的点）
候选三：两个端点 a 和 b
```

为什么只有这三类？

因为最值点如果在区间内部，且那一点可导，那么由费马引理，f' 必须为 0。

所以内部的最值点只能是驻点或不可导点，边界上的只能是端点。

一个完整例子：

题目：求 f(x) = x³ - 3x² + 1 在 [-1, 3] 上的最大值和最小值。

```text
f'(x) = 3x(x - 2)，驻点 x = 0, 2，都在 [-1, 3] 内
没有不可导点

f(-1) = -1 - 3 + 1 = -3
f(0)  = 1
f(2)  = 8 - 12 + 1 = -3
f(3)  = 27 - 27 + 1 = 1
```

比较四个数：最大是 1，最小是 -3。

```text
最大值 1，在 x = 0 和 x = 3 处取到
最小值 -3，在 x = -1 和 x = 2 处取到
```

注意最大值取了两个点，这在填空里要写全，只写一个会扣分。

**开区间或无穷区间上的最值。**

这时端点不能代，只能靠单调性。

做法：

```text
1. 求出所有驻点，把定义域切成若干段
2. 判断每段的升降
3. 唯一的极大值就是最大值，唯一的极小值就是最小值
4. 如果极值点不唯一，或者端点处函数趋于无穷，则最值可能不存在
```

第 3 条要小心，它成立的前提是"唯一"。

如果两个极大值，就得比较它们的大小，还得看端点趋势。

下面是一个应用题，数一喜欢出这种"实际最优化"。

题目：做一个无盖的圆柱形铁桶，容积固定为 V，问底面半径 r 和高 h 各为多少时，用料最省。

**第一步，设变量，写目标函数。**

用料就是表面积。无盖意味着只有底面加侧面：

```text
S = πr² + 2πrh
```

**第二步，用约束消去一个变量。**

容积 V = πr²h，所以：

```text
h = V / (πr²)
```

代入：

```text
S(r) = πr² + 2πr · V/(πr²) = πr² + 2V/r
```

**第三步，求导找驻点。**

```text
S'(r) = 2πr - 2V/r²
令 S'(r) = 0：2πr = 2V/r²  ⇒  πr³ = V  ⇒  r = (V/π)^(1/3)
```

**第四步，验证是最小值。**

```text
S''(r) = 2π + 4V/r³ > 0 （r > 0）
```

二阶导恒正，所以 S 是凹向上的，驻点就是最小值点。

**第五步，回代求 h。**

```text
h = V/(πr²) = πr³/(πr²) = r
```

结论：

```text
当 h = r，即高等于底面半径时，用料最省
```

这个"高等于半径"的结论值得记，它在各类"罐头盒""水桶"题里反复出现。

有盖的版本结论不同：有盖时 S = 2πr² + 2πrh，算出来 h = 2r，高是半径的两倍。

两者的差别只在底面多了一个圆。

再看一个经济类的例子，套路完全一样，只是目标函数换了名字。

题目：某产品的平均成本 c(q) = q²/3 - 3q + 20 + 36/q（q 为产量，单位千件），求平均成本最低时的产量和最低成本。

**第一步，求导。**

```text
c'(q) = 2q/3 - 3 - 36/q²
```

**第二步，解驻点。**

两边乘 3q²（q > 0，可以乘）：

```text
2q³ - 9q² - 108 = 0
```

试 q = 6：

```text
2·216 - 9·36 - 108 = 432 - 324 - 108 = 0
```

所以 q = 6 是一个根，把左边因式分解可以验证它是唯一正根。

**第三步，验证最小值。**

```text
c''(q) = 2/3 + 72/q³ > 0 （q > 0）
```

凹向上，驻点唯一，所以 q = 6 是最小值点。

**第四步，算最低成本。**

```text
c(6) = 36/3 - 18 + 20 + 6 = 12 - 18 + 20 + 6 = 20
```

结论：产量 6 千件时平均成本最低，为 20 元/件。

考场上的实用技巧：

```text
这类题的驻点通常是有理数，先试 q = 2, 3, 4, 5, 6, 8, 10
```

试出来再验二阶导，比硬解三次方程省时间。

## 9. 常见错误

没有这一节，你会把上面所有正确做法在考场上换成一堆似是而非的版本。

**错误一：把 f'(x₀) = 0 当成极值点。**

x³ 在 0 处导数为 0，但不是极值点。必须看变号。

**错误二：解完 f'(x) = 0 就收工。**

漏掉 f' 不存在的点。

f(x) = |x| 在 0 处不可导，但 0 是极小值点。

f(x) = x^(2/3) 在 0 处导数不存在，0 也是极小值点。

**错误三：单调区间用"∪"连。**

前面已经说过，要用"和"或逗号分开。

**错误四：凹凸的叫法搞反。**

考试答题时写"凹向上/凸向上"最保险，因为"凹"这个字单独用，不同教材正好相反。

**错误五：把拐点写成横坐标。**

拐点是点，要写 (1, -1)。

只写 x = 1 是"拐点的横坐标"，不是拐点。

同理，极值要写"极大值 f(0) = 1"，而不是"极大值点 x = 0 是 1"。

**错误六：斜渐近线只算 a。**

b 不存在时就没有斜渐近线，比如 x + sin x。

**错误七：闭区间求最值忘比端点。**

这是最高频的失分点，因为端点值往往不是极值，容易被忘掉。

**错误八：应用题忘了写定义域。**

圆柱的半径 r > 0，这是后面判断"驻点即最值"的依据，不写就少了论证。

**错误九：把"极大值"当成"最大值"。**

极大值只是局部冠军。

f(x) = x³ - 3x² + 1 的极大值是 1，但它没有最大值。

题目问"最大值"时，要么用闭区间端点，要么用单调性说清两端的走向。

**错误十：测试点选在分界点上。**

判号要在开区间内部取点。

在 x = 0 处代 f'(0) = 0，得到的 0 既不是正也不是负，判不出这一段的方向。

**错误十一：只写"驻点唯一，所以最小"。**

这句话要写完整："S''(r) > 0，S 是凹向上的，且驻点唯一，所以该驻点就是最小值点。"

论证过程本身就是分数。

## 10. 数一怎么考

没有这一节，你不知道这些知识会以什么形式出现，练的方向就会偏。

**题型一：选择题，判断极值点个数。**

给一张 f'(x) 的图像或一张表，问 f(x) 有几个极值点。

做法：只看 f' 的变号次数，不看 f' 的高低。

```text
f' 从 + 变 - → 极大值点
f' 从 - 变 + → 极小值点
f' 从 + 变 + → 不是极值点
f' = 0 但不穿过轴（相切）→ 不是极值点
```

第三个要点：看零点的**重数**。

f' 在单重零点两侧变号，在双重零点两侧不变号，在三重零点两侧又变号。

```text
奇重零点 → 变号 → 极值点
偶重零点 → 不变号 → 不是极值点
```

例：f'(x) = (x - 1)(x - 2)²(x - 3)³，问 f 有几个极值点。

```text
零点：x = 1（单重）、x = 2（双重）、x = 3（三重）
x > 3 时三个因子全正，f' > 0
x = 3 是三重零点，变号 → (2,3) 上 f' < 0
x = 2 是双重零点，不变号 → (1,2) 上 f' < 0
x = 1 是单重零点，变号 → (-∞,1) 上 f' > 0
```

于是：升 (-∞,1)，降 (1,3)，升 (3,+∞)。

x = 1 是极大值点，x = 3 是极小值点，x = 2 不是极值点。

答案：两个极值点。

这道题用"重数奇偶"三秒就能判完，用列表代点要算四段。

**题型二：选择题，判断渐近线条数。**

给一个有理函数，问有几条渐近线。

做法：垂直看分母零点，水平看两个方向的极限，斜的看 a 和 b 是否都存在。

三类要全查，别漏。

**题型三：填空题，反求参数。**

例如：已知 x = 1 是 f(x) = x³ + ax² + bx 的极值点，(2, f(2)) 是拐点，求 a 和 b。

```text
f'(x) = 3x² + 2ax + b
f'(1) = 3 + 2a + b = 0

f''(x) = 6x + 2a
f''(2) = 12 + 2a = 0  ⇒  a = -6

代回：3 - 12 + b = 0  ⇒  b = 9
```

这类题的套路固定：极值点给一个方程，拐点给一个方程，正好解两个未知数。

**题型四：解答题，完整画图。**

这是 10 分的大题，要求写全五件事：

```text
1. 定义域
2. 单调区间与极值
3. 凹凸区间与拐点
4. 渐近线
5. 草图
```

下面完整做一遍 f(x) = x·e^(-x)。

**定义域**：全体实数。

**求导**：

```text
f'(x) = e^(-x) + x·(-e^(-x)) = (1 - x)e^(-x)
```

因为 e^(-x) 恒正，所以 f' 的符号完全由 (1 - x) 决定。

```text
x < 1：f' > 0，递增
x > 1：f' < 0，递减
x = 1：f' = 0
```

极大值 f(1) = 1·e^(-1) = 1/e。

**二阶导**：

```text
f''(x) = -e^(-x) + (1 - x)(-e^(-x))
       = e^(-x)[-1 - (1 - x)]
       = e^(-x)(x - 2)
```

```text
x < 2：f'' < 0，凸向上
x > 2：f'' > 0，凹向上
x = 2：f'' = 0 且变号
```

拐点坐标：f(2) = 2e^(-2) = 2/e²。

**渐近线**：

```text
x → +∞：x·e^(-x) → 0，所以 y = 0 是水平渐近线
x → -∞：x·e^(-x) → -∞，没有水平渐近线
垂直渐近线：函数处处有定义，没有
斜渐近线：x → +∞ 时 a = lim f(x)/x = lim e^(-x) = 0，a = 0 不构成斜渐近线
x → -∞ 时 a = lim e^(-x) = +∞，不存在
```

所以只有一条渐近线：y = 0（只在右侧）。

**列表汇总**：

```text
x       (-∞,1)    1     (1,2)     2      (2,+∞)
f'        +       0       -       -        -
f''       -       -       -       0        +
f        升     极大1/e    降    拐点2/e²   降
```

**草图要点**：

```text
从 -∞ 处从下方升起（f 为负，f'' 为负，凸向上）
过原点 (0,0)
在 x = 1 达到最高 1/e ≈ 0.368
在 x = 2 处弯向翻转
之后一直降，无限贴近 y = 0 但不变号（始终为正）
```

画出来：

```text
             ╱‾╲
            ╱   ╲
      ─────╱─────╲────────  y = 0
          ╱        ╲___
         ╱             ‾‾‾──
    ____╱
```

**题型五：证明不等式。**

例：证明 x > 0 时 ln(1 + x) < x。

思路：把不等式移项成一个函数，证明它在 0 右侧恒正。

```text
令 g(x) = x - ln(1 + x)，x ≥ 0
g(0) = 0
g'(x) = 1 - 1/(1 + x) = x/(1 + x)
x > 0 时 g'(x) > 0，所以 g 在 [0, +∞) 上递增
于是 x > 0 时 g(x) > g(0) = 0
即 ln(1 + x) < x
```

这个套路叫"作差 + 单调性"，是中值定理之外最常用的不等式证法。

它的适用条件是：作差后的函数在端点处好算（通常是 0），且导数容易判号。

**题型六：讨论方程 f(x) = 0 的实根个数。**

这是单调性最漂亮的应用。

步骤固定：

```text
1. 求 f'(x)，把定义域切成单调区间
2. 算出每个区间端点处的函数值或极限
3. 在每段上单独用零点定理：两端异号则该段恰有一根
4. 把各段的根数加起来
```

例：讨论 x³ - 3x + 1 = 0 的实根个数。

```text
令 f(x) = x³ - 3x + 1
f'(x) = 3x² - 3 = 3(x - 1)(x + 1)
驻点 x = -1 和 x = 1
```

判号并算值：

```text
x       (-∞,-1)   -1    (-1,1)    1    (1,+∞)
f'         +       0      -       0      +
f         升      3       降      -1     升
```

再看两端：

```text
x → -∞ 时 f(x) → -∞
x → +∞ 时 f(x) → +∞
```

于是每段的结论：

```text
(-∞, -1)：从 -∞ 升到 3，跨过 0 一次  → 一根
(-1, 1) ：从 3 降到 -1，跨过 0 一次  → 一根
(1, +∞) ：从 -1 升到 +∞，跨过 0 一次 → 一根
```

一共三个实根。

得分点在"每段分别用零点定理"，而不是"由图像看出三个根"。

后一种写法在解答题里几乎不给分。

## 11. 和其他章节怎么连

没有这一节，你会觉得这些知识是孤立的技巧，考试一变形就认不出来。

**往回连：03 导数与微分。**

这一篇的所有结论，都建立在"会求导"上。

隐函数求导、参数方程求导、高阶导数，任何一个不熟，这里的题就做不下去。

**往回连：04 微分中值定理。**

单调性的严格证明要用拉格朗日中值定理。

极值的第一充分条件，本质上是把中值定理用在 x₀ 两侧的区间上。

**往前连：06 不定积分。**

知道 f'(x) 的符号能画出 f 的形状；反过来，知道 f 的形状能猜出 f' 的样子。

积分是求导的逆运算，这一篇的每一条规则，在积分里都有对应物。

**往前连：09 反常积分。**

斜渐近线要用 x → ∞ 的极限，反常积分也是。

两者的工具是同一套。

**横向连：12 二重积分、11 多元极值。**

多元极值判定要算 Hessian 矩阵，本质是把"f'' 的符号"推广成"二阶偏导组成的矩阵正定"。

一元这一篇学扎实，多元那一篇就只是换符号。

**横向连：19 微分方程。**

微分方程 y' = f(x, y) 的定性分析要用到单调性和凹凸性，判断解曲线的走向。

**一个整体视角。**

微分的三大应用——极值、最值、曲线形状——本质上都在问同一个问题：

```text
函数在这一点附近长什么样？
```

导数回答"斜率"，二阶导回答"弯曲"，渐近线回答"远处"，最值回答"最高最低"。

四个信息拼起来，就是一张能直接画出来的图。

数一最后那道"画图题"考的不是计算量，是这四条信息是否齐全。

### 自检三问

**第一问：给你一张 f'(x) 的符号表，你能在三十秒内写出单调区间和极值点吗？**

如果不能，说明你还没把"f' 正 → 升"这个翻译练成条件反射。

练法：随便写五个三次函数，只列表不画图，练到不用想。

**第二问：f''(x₀) = 0 为什么不能直接断定 (x₀, f(x₀)) 是拐点？**

因为拐点要求 f'' 在两侧**变号**。

f(x) = x⁴ 在 0 处 f''(0) = 0，但 f'' = 12x² 在两侧都为正，不变号，所以 (0,0) 不是拐点。

反过来，f(x) = x³ 在 0 处 f''(0) = 0，f'' = 6x 两侧变号，所以 (0,0) 是拐点。

**第三问：求斜渐近线时，只算出 a 会漏掉什么？**

会漏掉 b 的存在性检查。

f(x) = x + sin x 的 a = 1 存在，但 b = lim sin x 不存在，所以没有斜渐近线。

只算 a 就会错误地宣布 y = x 是渐近线。

## 12. 小结

没有小结，前面十一条会散成一地零件。

把这一篇压成一张卡片：

```text
f' > 0 → 升        f' 变号 → 极值
f'' > 0 → 凹向上    f'' 变号 → 拐点
渐近线三类：垂直（分母零点）、水平（两端极限）、斜（a 与 b）
最值：驻点 + 不可导点 + 端点，三类候选比大小
```

四步公式在这里其实只有一个：

```text
算什么 → 逐符号 → 代数字 → 适用条件
```

判单调是算 f' 的符号，判凹凸是算 f'' 的符号，判渐近线是算极限，判最值是比数值。

形式不同，步骤相同。

考前一天可以只看这张清单：

```text
1. 先写定义域，一切判断都在定义域内做
2. 求 f'，解 f' = 0，标出 f' 不存在的点
3. 列表代测试点，判 f' 的正负
4. 变号处写极值，正负交界处定升降
5. 求 f''，解 f'' = 0，同样列表判号
6. 变号处写拐点，写成坐标 (x, f(x))
7. 分母零点查垂直渐近线，两端极限查水平渐近线
8. 算 a = lim f(x)/x 和 b，两者都在才有斜渐近线
9. 最值比较驻点、不可导点、端点三类候选
10. 应用题写清定义域和"唯一驻点即最值"的理由
```

十条里，前六条决定图像，后四条决定边界和答案的完整性。
