同一道题，两个人做。

```text
求 lim (cos x)^(1/x²)，x → 0。
```

第一个人从极限定义开始想，写了半页。

第二个人看了一眼指数位置，写下三个字：

```text
1 的无穷次方。
```

然后取对数、用等价无穷小，四行出结果。

两个人的知识储备一样。

差别只在"反应速度"。

这一篇就是把这种反应写成清单。

## 1. 为什么需要它（不给会怎样）

**不给会怎样：知识点会，但考场上想不起来用哪个。**

这是最常见的一种失败。

平时做章节练习，题目就在那一章里，提示已经给了一半。

考场上十道题混在一起，没人告诉你"这题考格林公式"。

于是出现这种场面：

```text
盯着题看了三分钟，
脑子里有七八个公式在转，
不知道先动哪一个。
```

**第二个后果：步骤不成型，算到一半就乱。**

会算的人不是每一步都想得很清楚，而是"下一步该干什么"已经变成习惯。

```text
看到 1^∞ 就取对数，
看到闭合曲线就想格林，
看到 √(a²−x²) 就换 x = a sin t。
```

这些动作不需要现场发明。

**第三个后果：时间不够。**

数一高数部分大约 82 分，考试总时长 180 分钟，还要分给线代和概率。

平均下来每分不到两分钟。

留给你"想用哪个方法"的时间，几乎没有。

所以这一篇的目标很具体：

```text
把"认题"这件事，提前到考试之前完成。
```

## 2. 十类题型的信号表

先看一张总表，后面逐条展开。

先把符号读出来：

```text
∫（积分号）、∬（二重积分号）、∭（三重积分号）
∮（闭合积分号，沿一圈积分）
∂（偏导，读"偏"）、Σ（求和，读 sigma）
lim（极限）、ξ（读"克西"，中值定理里那个点）
```

```text
题面出现                            第一反应
─────────────────────────────────────────────────────
0/0、∞/∞、1^∞、0·∞                  洛必达 / 等价无穷小 / 取对数
"在 x₀ 处的切线、法线"              先求导数值，再用点斜式
"证明存在 ξ 使 …"                   构造辅助函数 + 罗尔定理
∫ 里出现 √(a²−x²)                   三角换元 x = a sin t
区域是圆、环、扇形                   极坐标
闭合曲线、闭合曲面                   格林 / 高斯 / 斯托克斯
"收敛半径""展开成 (x−x₀) 的幂"      比值法 + 逐项求导或积分
右端是 e^{λx}、sin ωx 的二阶方程     特征方程 + 待定特解
"求平面、直线、夹角、距离"           法向量或方向向量 + 叉乘
"最大、最小、最省、最多"             目标函数 + 约束，或定积分建模
```

这张表要背到能条件反射。

下面十节，每一节按同一个格式写：

```text
识别信号 → 固定步骤 → 例题与答案 → 易错点
```

**这张表怎么用。**

不要一次背十行。

按下面的顺序，三天过一轮：

```text
第一天：极限、导数、积分、方程（计算类，占分最多）
第二天：重积分、线面积分、级数（符号类，最容易混）
第三天：证明、空间几何、应用题（结构类，最考思路）
```

每过一类，先在草稿纸上默写"识别信号"三个字后面的内容。

默不出来，就回去看对应那一节。

**三种"变形题"要留神。**

出题人会故意把信号藏起来，常见三种改法：

```text
一、把极限藏在积分里：lim (1/x)∫₀^x f(t)dt，本质是变上限积分求导 + 极限。
二、把格林公式藏在"与路径无关"里：不闭合的曲线，先判 P_y = Q_x。
三、把中值定理藏在数列里：证明数列收敛，用单调有界或拉格朗日。
```

看到这三类，先把外壳剥掉，回到表里找信号。

## 3. 套路一：极限

**识别信号。**

```text
式子长得像 0/0、∞/∞、0·∞、∞−∞、1^∞、0^0、∞^0。
题面出现 "lim"，且变量趋于 0 或无穷。
```

**固定步骤。**

```text
第一步：先代值，判断类型。代进去能算就直接写答案。
第二步：看能不能用等价无穷小。乘除关系里优先用。
第三步：还是不定型，洛必达（注意每次用完要化简）。
第四步：1^∞ 型先取对数，化成 0·∞，再化成 0/0。
第五步：含根号的先有理化，含 e^x−1 的先提公因式。
```

**例题。**

```text
求 lim (cos x)^(1/x²)，x → 0。
```

**第一步，判型。**

x → 0 时 cos x → 1，指数 1/x² → ∞。

这是 1^∞ 型。

**第二步，取对数。**

令 L 为所求，则：

```text
ln L = lim [ln(cos x)] / x²
```

**第三步，把 ln(cos x) 换成等价无穷小。**

ln(cos x) = ln[1 + (cos x − 1)]。

当 x → 0 时 cos x − 1 → 0，所以：

```text
ln[1 + (cos x − 1)] ~ cos x − 1
```

而 cos x − 1 ~ −x²/2。

于是：

```text
ln L = lim (−x²/2) / x² = −1/2
```

**第四步，回代。**

```text
L = e^(−1/2) = 1/√e
```

**答案：1/√e。**

**易错点。**

```text
一、等价无穷小只能在乘除里替换。加减里替换会丢高阶项。
   反例：lim (sin x − x)/x³，直接换 sin x ~ x 会得 0，正确答案是 −1/6。
二、洛必达不是万能。每用一次都要检查是否仍是 0/0 或 ∞/∞。
   用完不化简，越求导越复杂。
三、1^∞ 忘了取对数，直接写 e 的某次方，过程分全丢。
四、x → ∞ 时不能等价无穷小，要换成 1/t，t → 0。
```

## 4. 套路二：导数与切线

**识别信号。**

```text
"在点 (x₀, y₀) 处的切线方程""法线方程"。
"曲线在何处水平""切线与直线平行"。
给出隐函数方程或参数方程，问导数。
```

**固定步骤。**

```text
第一步：确认求导方式（显函数、隐函数、参数方程、变上限积分）。
第二步：求出 y' 在 x₀ 处的值 k。
第三步：写点斜式 y − y₀ = k(x − x₀)。
第四步：法线斜率是 −1/k，写 y − y₀ = −(x − x₀)/k。
第五步："平行于某直线"就是 k 等于那条线的斜率，回头解方程。
```

**例题。**

设 y = y(x) 由方程 e^y + xy = e 确定，求曲线在点 (0, 1) 处的切线方程。

**第一步，确认是隐函数。**

y 没有解出来，直接对两边求导。

**第二步，两边对 x 求导。**

e^y 是复合函数，导数是 e^y · y'。

xy 是乘积，导数是 y + x y'。

```text
e^y · y' + y + x · y' = 0
```

**第三步，解出 y'。**

```text
y'(e^y + x) = −y
y' = −y / (e^y + x)
```

**第四步，代入 (0, 1)。**

```text
k = −1 / (e^1 + 0) = −1/e
```

**第五步，写切线。**

```text
y − 1 = −(1/e)(x − 0)
```

**答案：y = 1 − x/e。**

顺便写法线：

```text
y − 1 = e·x
```

**易错点。**

```text
一、隐函数求导时忘了 y 是 x 的函数，e^y 直接写成 e^y 而不乘 y'。
二、乘积 xy 求导只写 y，漏掉 x y'。
三、切线写成 y − y₀ = k(x − x₀) 时把点代错，尤其是点不在曲线上时。
四、参数方程求导 dy/dx = (dy/dt)/(dx/dt)，不是 dy/dt 乘 dx/dt。
五、变上限积分求导，上限是 x² 时要乘 2x（链式法则）。
```

## 5. 套路三：中值定理证明

**识别信号。**

```text
"证明存在 ξ ∈ (a, b)，使得 …"
"证明至少存在一点 …"
题面给出 f 在闭区间连续、开区间可导。
结论里出现 f'(ξ) 与 f(ξ) 的组合。
```

**固定步骤。**

```text
第一步：把结论整理成"某函数的导数等于 0"的形式。
第二步：倒推辅助函数 F。看 f'(ξ) + p(ξ)f(ξ) = 0 这类形状。
     记公式：f' + p f = 0  ⇔  (f · e^{∫p})' = 0
第三步：验证 F(a) = F(b)。
第四步：罗尔定理，得 F'(ξ) = 0。
第五步：把 F'(ξ) = 0 翻译回题目要的结论。
```

**辅助函数的两条常用口诀。**

```text
见到 f'(ξ) + p(ξ) f(ξ) = 0      → 乘 e^{∫p}
见到 ξ f'(ξ) + n f(ξ) = 0       → 乘 ξ^(n−1)（或考虑 x^n f(x)）
见到 f'(ξ) − λ f(ξ) = 0         → 乘 e^{−λx}
```

**例题。**

设 f 在 [0, 1] 上连续，在 (0, 1) 内可导，且 f(0) = f(1) = 0。

证明：存在 ξ ∈ (0, 1)，使 f'(ξ) = 2ξ f(ξ)。

**第一步，整理结论。**

移项：

```text
f'(ξ) − 2ξ f(ξ) = 0
```

**第二步，倒推辅助函数。**

这个形状是 f' + p f = 0，其中 p = −2x。

按口诀乘 e^{∫p dx} = e^{−x²}：

```text
F(x) = f(x) · e^(−x²)
```

验算一下：

```text
F'(x) = f'(x)e^(−x²) + f(x)·(−2x)e^(−x²)
      = e^(−x²)[f'(x) − 2x f(x)]
```

括号里正是要证的式子。

所以 F'(ξ) = 0 就等价于 f'(ξ) = 2ξ f(ξ)。

**第三步，验证两端相等。**

```text
F(0) = f(0)·e^0 = 0
F(1) = f(1)·e^(−1) = 0
```

两端都是 0。

**第四步，用罗尔定理。**

F 在 [0, 1] 连续、在 (0, 1) 可导（两个因子都满足），且 F(0) = F(1)。

所以存在 ξ ∈ (0, 1)，使 F'(ξ) = 0。

**第五步，翻译回去。**

```text
e^(−ξ²)[f'(ξ) − 2ξ f(ξ)] = 0
```

e^(−ξ²) 永远不为 0，所以：

```text
f'(ξ) = 2ξ f(ξ)
```

**答案：结论成立。**

**易错点。**

```text
一、辅助函数构造对了，但没验 F(a) = F(b)，罗尔用不了。
二、忘了说明"连续、可导"这两个条件，扣步骤分。
三、结论里有两个中值（ξ 和 η）时，要分两次用定理，区间要错开。
四、把"存在 ξ"证成"对任意 ξ"，方向反了。
五、柯西中值定理的分母 g'(ξ) ≠ 0，这个条件要提一句。

```

## 6. 套路四：积分计算

**识别信号。**

```text
∫ 里出现 √(a² − x²)、√(x² + a²)、√(x² − a²)。
∫ 里出现多项式乘 ln x、arctan x、e^x、sin x。
∫ 是有理分式，分母能因式分解。
积分的上下限含参数，或者积分区域要分段。
```

**固定步骤。**

```text
第一步：先看能不能直接套基本积分表。
第二步：有根号先换元。√(a²−x²) 用 x = a sin t，√(x²+a²) 用 x = a tan t。
第三步：两类不同函数相乘，用分部积分，按"反对幂指三"选 u。
第四步：有理分式先拆成部分分式。
第五步：定积分做完记得代上下限，换元必须同时换限。
第六步：对称区间先看奇偶性，能省一半计算。
```

"反对幂指三"是选 u 的顺序：

```text
反三角 → 对数 → 幂函数 → 指数 → 三角
排在前面的当 u，排在后面的进 dv。
```

**例题。**

```text
求 ∫₀¹ x·arctan x dx。
```

**第一步，判型。**

幂函数乘反三角函数，属于必须分部的类型。

按口诀，反三角排第一，所以 u = arctan x。

**第二步，设 u 与 dv。**

```text
u = arctan x,   dv = x dx
du = dx/(1 + x²),   v = x²/2
```

**第三步，套分部公式。**

```text
∫₀¹ x arctan x dx = [x²/2 · arctan x]₀¹ − ∫₀¹ (x²/2)·dx/(1 + x²)
```

**第四步，算第一项。**

```text
[ (1/2)(π/4) − 0 ] = π/8
```

**第五步，处理第二个积分。**

把假分式拆开：

```text
x²/(1 + x²) = 1 − 1/(1 + x²)
```

于是：

```text
∫₀¹ x²/(1 + x²) dx = ∫₀¹ [1 − 1/(1 + x²)] dx
= [x − arctan x]₀¹
= (1 − π/4) − 0
= 1 − π/4
```

**第六步，合并。**

```text
原式 = π/8 − (1/2)(1 − π/4)
     = π/8 − 1/2 + π/8
     = π/4 − 1/2
```

**答案：π/4 − 1/2 ≈ 0.285。**

**用估值检验一下。**

在 [0, 1] 上，arctan x 从 0 涨到 π/4 ≈ 0.785，x 从 0 涨到 1。

被积函数 x·arctan x 最大约 0.785，平均大约 0.3。

积分值约 0.285，落在合理范围。

**易错点。**

```text
一、分部时 u 和 dv 选反。选成 u = x、dv = arctan x dx，越算越复杂。
二、定积分分部后，后半个积分忘了继续带上下限。
三、换元算出原函数后，直接代新变量的上下限，没换回来。
四、拆项时把 x²/(1+x²) 写成 1 + 1/(1+x²)，符号反了。
五、对称区间用了奇偶性，但被积函数既不是奇也不是偶。
```

## 7. 套路五：二重积分与三重积分

**识别信号。**

```text
符号 ∬_D 或 ∭_Ω。
区域由 x² + y² = R²、y = x、y = x² 这类曲线围成。
被积函数里出现 x² + y²、√(x² + y²)、z。
```

**固定步骤。**

```text
第一步：画图。这一步不能跳，图错了后面全错。
第二步：选坐标系。圆、环、扇形用极坐标；球、锥用球坐标；柱体用柱坐标。
第三步：写限。先定外层变量的范围，再定内层。
第四步：看对称性。区域关于坐标轴对称时，奇函数的积分为 0。
第五步：算内层，再算外层。
第六步：三重积分先想"先一后二"还是"先二后一"。
```

**例题一：二重积分（极坐标）。**

```text
计算 ∬_D (x² + y²) dσ，
其中 D 是 1 ≤ x² + y² ≤ 4 且 x ≥ 0、y ≥ 0 的部分。
```

**第一步，画图。**

是一个四分之一圆环，夹在半径 1 与半径 2 之间，落在第一象限。

**第二步，换极坐标。**

```text
x = r cos θ,  y = r sin θ,  x² + y² = r²
dσ = r dr dθ
```

**第三步，写限。**

```text
θ 从 0 到 π/2
r 从 1 到 2
```

**第四步，代入计算。**

```text
∬_D (x² + y²) dσ = ∫₀^(π/2) dθ ∫₁² r² · r dr
```

内层：

```text
∫₁² r³ dr = [r⁴/4]₁² = (16 − 1)/4 = 15/4
```

外层：

```text
(π/2) · (15/4) = 15π/8
```

**答案：15π/8。**

**例题二：三重积分（球坐标）。**

```text
计算 ∭_Ω z dV，
其中 Ω 是上半球体 x² + y² + z² ≤ 1，z ≥ 0。
```

**第一步，判坐标系。**

区域里有 x² + y² + z²，用球坐标。

```text
x = r sin φ cos θ,  y = r sin φ sin θ,  z = r cos φ
dV = r² sin φ dr dφ dθ
```

**第二步，写限。**

```text
r 从 0 到 1
φ 从 0 到 π/2   （上半球）
θ 从 0 到 2π
```

**第三步，代入。**

```text
∭ z dV = ∫₀^(2π) dθ ∫₀^(π/2) dφ ∫₀¹ (r cos φ)·r² sin φ dr
```

**第四步，三个积分各自独立，拆开乘。**

```text
∫₀^(2π) dθ = 2π
∫₀¹ r³ dr = 1/4
∫₀^(π/2) cos φ sin φ dφ = 1/2
```

相乘：

```text
2π · (1/4) · (1/2) = π/4
```

**答案：π/4。**

**检验：用质心公式对一遍。**

上半球的体积是 (2/3)π，质心高度是 3/8。

```text
∭ z dV = 质心高度 × 体积 = (3/8)·(2/3)π = π/4
```

两条路算出同一个数，说明坐标和限都写对了。

**易错点。**

```text
一、极坐标忘了乘 r。dσ = r dr dθ，不是 dr dθ。
二、球坐标忘了乘 r² sin φ。
三、θ 的范围按象限写错，第一象限是 0 到 π/2，不是 0 到 π。
四、φ 是与 z 轴的夹角，不是与 xOy 面的夹角。
五、先画图再写限。图和限不一致时，错的一定是限。

**对称性怎么用（能省一半时间）。**

**第一种：区域对称，函数是奇函数。**

D 关于 y 轴对称时：

```text
被积函数对 x 是奇函数  ⇒  积分为 0
被积函数对 x 是偶函数  ⇒  等于一半区域的 2 倍
```

```text
∬_D x³y dσ，D 是圆盘 x²+y² ≤ 1  →  直接得 0
```

**第二种：轮换对称。**

D 关于直线 y = x 对称时，把 x 和 y 互换，积分值不变：

```text
∬_D f(x, y) dσ = ∬_D f(y, x) dσ
```

利用这一条，常常可以算出 "∬ x² dσ" 与 "∬ y² dσ" 相等，于是：

```text
∬ x² dσ = (1/2) ∬ (x² + y²) dσ
```

右边换成极坐标就好算了。

**三重积分里同样的道理。**

Ω 关于 xOy 面对称时，被积函数对 z 是奇函数，积分为 0。

球坐标里，若被积函数只含 r，则 θ 和 φ 的积分可以先算出来乘在前面。
```

## 8. 套路六：曲线积分与曲面积分

**识别信号。**

```text
∮_L P dx + Q dy 或 ∫_L P dx + Q dy。
∬_Σ 或 ∯_Σ，被积式里出现 dy dz、dz dx、dx dy。
题面说"闭合""沿逆时针""取外侧"。
```

**固定步骤。**

```text
第一步：分第一类还是第二类。有 dx、dy 的是第二类；只有 ds 的是第一类。
第二步：第二类先看曲线（曲面）是否闭合。
     闭合 → 格林（平面）或高斯（空间）。
     不闭合 → 补线或补面，补成闭合再用公式，最后减掉补的部分。
第三步：不是闭合但满足 P_y = Q_x，说明与路径无关，换一条好算的路径。
第四步：注意定向。逆时针为正，外侧为正。
第五步：算完检查符号。
```

**例题一：格林公式。**

```text
计算 ∮_L (x dy − y dx)，其中 L 是圆 x² + y² = 4，取逆时针方向。
```

**第一步，判型。**

有 dx、dy，是第二类曲线积分；L 是闭合曲线。

可以用格林公式。

**第二步，对号入座。**

```text
P = −y,  Q = x
```

**第三步，算偏导。**

```text
∂Q/∂x = 1,  ∂P/∂y = −1
∂Q/∂x − ∂P/∂y = 2
```

**第四步，套格林公式。**

```text
∮_L P dx + Q dy = ∬_D (∂Q/∂x − ∂P/∂y) dσ = ∬_D 2 dσ
```

**第五步，算面积。**

D 是半径 2 的圆，面积 4π。

```text
2 × 4π = 8π
```

**答案：8π。**

**验算：换参数方程也算一遍。**

```text
x = 2cos t, y = 2sin t, t 从 0 到 2π
dx = −2sin t dt, dy = 2cos t dt
```

```text
x dy − y dx = 2cos t·2cos t dt − 2sin t·(−2sin t)dt
= 4(cos²t + sin²t)dt = 4 dt
```

```text
∫₀^(2π) 4 dt = 8π
```

两条路一致。

**例题二：高斯公式。**

```text
计算 ∯_Σ x dy dz + y dz dx + z dx dy，
其中 Σ 是球面 x² + y² + z² = R²，取外侧。
```

**第一步，判型。**

三项都是 dy dz、dz dx、dx dy 的形状，是第二类曲面积分。

曲面闭合，取外侧，用高斯公式。

**第二步，对号入座。**

```text
P = x,  Q = y,  R = z
```

**第三步，算散度。**

```text
∂P/∂x + ∂Q/∂y + ∂R/∂z = 1 + 1 + 1 = 3
```

**第四步，套高斯公式。**

```text
∯_Σ = ∭_Ω 3 dV = 3 × 球的体积
```

**第五步，算体积。**

```text
V = (4/3)πR³
3V = 4πR³
```

**答案：4πR³。**

**补一个"与路径无关"的短例。**

```text
计算 ∫_L 2xy dx + x² dy，
其中 L 是从 (0, 0) 到 (1, 1) 的任意路径。
```

**第一步，验条件。**

```text
P = 2xy,  Q = x²
∂P/∂y = 2x,  ∂Q/∂x = 2x
```

两者相等，且在整个平面上连续，所以积分与路径无关。

**第二步，换一条最好算的路径。**

取折线：先沿 x 轴到 (1, 0)，再竖直向上到 (1, 1)。

第一段 y = 0，dy = 0：

```text
∫ 2x·0 dx + x²·0 = 0
```

第二段 x = 1，dx = 0，y 从 0 到 1：

```text
∫₀¹ 1² dy = 1
```

**答案：1。**

**第三步，用原函数验一遍。**

既然与路径无关，就存在 u 使 du = 2xy dx + x² dy。

观察可知 u = x²y。

```text
u(1, 1) − u(0, 0) = 1 − 0 = 1
```

两条路一致。

这个"找原函数"的办法，在填空题里比换路径更快。

**易错点。**

```text
一、格林公式用错方向。逆时针为正，顺时针要加负号。
二、曲线不闭合就直接用格林，必须补线。
三、补线后忘了减去补的那一段。
四、高斯公式要求取外侧，取内侧要加负号。
五、第一类曲线积分写成 dx，第二类写成 ds，两者不能混。
```

## 9. 套路七：级数敛散与展开

**识别信号。**

```text
Σ 的通项里有 n、n!、a^n。
"判断敛散性""是否绝对收敛"。
"求收敛半径""求收敛域"。
"把 f(x) 展开成 x − x₀ 的幂级数"。
```

**固定步骤。**

```text
第一步：判类型。正项、交错、还是任意项。
第二步：正项级数用比值法或根值法，含 1/n^p 的用 p 级数比较。
第三步：交错级数用莱布尼茨：u_n 单调减且趋于 0。
第四步：任意项先看绝对值级数，绝对收敛就收敛；不绝对再单独判。
第五步：幂级数先算收敛半径 R = 1/ρ，ρ = lim |a_{n+1}/a_n|。
第六步：端点 x₀ ± R 单独代进去，化成数项级数再判。
第七步：求和或展开，套已知展开式，必要时先求导或先积分。
```

**例题一：求和。**

```text
求 Σ (n/2^n)，n 从 1 到 ∞。
```

**第一步，判敛散。**

比值法：

```text
a_{n+1}/a_n = [(n+1)/2^(n+1)] / [n/2^n] = (n+1)/(2n) → 1/2 < 1
```

收敛。

**第二步，找已知展开式。**

已知：

```text
Σ n x^n = x/(1 − x)²，|x| < 1
```

推导来源：先对 Σ x^n = 1/(1−x) 求导，再乘 x。

**第三步，代入 x = 1/2。**

```text
Σ n (1/2)^n = (1/2) / (1 − 1/2)² = (1/2)/(1/4) = 2
```

**答案：和为 2。**

**例题二：函数展开。**

```text
把 f(x) = 1/(x + 2) 展开成 x − 1 的幂级数。
```

**第一步，凑成"1 减某个东西"的形状。**

把分母改写成 3 加 (x − 1)：

```text
x + 2 = 3 + (x − 1) = 3[1 + (x − 1)/3]
```

**第二步，提出常数。**

```text
f(x) = (1/3) · 1/[1 + (x − 1)/3]
```

**第三步，套几何级数。**

1/(1 + u) = Σ (−1)^n u^n，|u| < 1。

这里 u = (x − 1)/3：

```text
f(x) = (1/3) Σ (−1)^n [(x − 1)/3]^n
     = Σ (−1)^n (x − 1)^n / 3^(n+1)
```

**第四步，写收敛域。**

```text
|(x − 1)/3| < 1  ⇒  |x − 1| < 3  ⇒  −2 < x < 4
```

**答案：Σ (−1)^n (x − 1)^n / 3^(n+1)，收敛域 (−2, 4)。**

**易错点。**

```text
一、收敛半径算出 R 就直接写收敛域，忘了单独判端点。
二、端点代进去是交错级数，仍要用莱布尼茨判，不能想当然。
三、展开时中心没对准，把 x − 1 写成 x。
四、逐项求导或积分后，收敛半径不变，但端点可能变。
五、绝对收敛与条件收敛混为一谈。
```

## 10. 套路八：微分方程

**识别信号。**

```text
方程里同时出现 y' 和 y。
二阶方程，右端是 e^(λx)、sin ωx、多项式。
题面给"满足 y(0) = 1"的初值。
```

**固定步骤。**

```text
第一步：判阶数，判线性还是非线性。
第二步：一阶看形状。可分离、齐次（y/x 型）、线性、伯努利。
第三步：二阶常系数，先写特征方程 r² + pr + q = 0。
第四步：按三个根的情况写通解。
第五步：看右端定特解形式，代入定系数。
第六步：有初值就代进去定 C₁、C₂。
```

**右端对应的特解形式。**

```text
右端 P_m(x)e^(λx)：
   λ 不是特征根      → 设 Q_m(x)e^(λx)
   λ 是单根          → 设 x·Q_m(x)e^(λx)
   λ 是重根          → 设 x²·Q_m(x)e^(λx)
右端含 sin ωx 或 cos ωx：
   把 ωi 当 λ 用同样的规则
```

**例题。**

```text
求 y'' − 3y' + 2y = e^(3x) 的通解。
```

**第一步，写特征方程。**

```text
r² − 3r + 2 = 0
(r − 1)(r − 2) = 0
r₁ = 1, r₂ = 2
```

**第二步，写齐次通解。**

两个不同的实根：

```text
Y = C₁e^x + C₂e^(2x)
```

**第三步，定特解形式。**

右端是 e^(3x)，λ = 3。

3 不是特征根（特征根只有 1 和 2），所以设：

```text
y* = A e^(3x)
```

**第四步，代入原方程定 A。**

```text
(y*)' = 3A e^(3x),  (y*)'' = 9A e^(3x)
```

代入左端：

```text
9A e^(3x) − 3·3A e^(3x) + 2A e^(3x) = (9 − 9 + 2)A e^(3x) = 2A e^(3x)
```

右端是 e^(3x)，所以：

```text
2A = 1  ⇒  A = 1/2
```

**第五步，合并。**

```text
y = C₁e^x + C₂e^(2x) + (1/2)e^(3x)
```

**答案：通解如上，C₁、C₂ 为任意常数。**

**再补一个一阶线性的短例。**

```text
求 y' + 2y = 4x 的通解。
```

**第一步，对号入座。**

一阶线性标准形 y' + P(x)y = Q(x)，其中 P = 2、Q = 4x。

**第二步，套通解公式。**

```text
y = e^(−∫P dx) [ ∫ Q e^(∫P dx) dx + C ]
```

先算两个指数：

```text
∫P dx = 2x,  e^(∫P dx) = e^(2x),  e^(−∫P dx) = e^(−2x)
```

**第三步，算括号里的积分。**

```text
∫ 4x e^(2x) dx
```

分部：u = 4x，dv = e^(2x)dx，则 du = 4dx，v = e^(2x)/2。

```text
∫ 4x e^(2x) dx = 2x e^(2x) − ∫ 2 e^(2x) dx = 2x e^(2x) − e^(2x)
```

**第四步，乘回去。**

```text
y = e^(−2x)[2x e^(2x) − e^(2x) + C] = 2x − 1 + C e^(−2x)
```

**答案：y = C e^(−2x) + 2x − 1。**

**验算：代回原方程。**

```text
y' = −2C e^(−2x) + 2
y' + 2y = −2C e^(−2x) + 2 + 2C e^(−2x) + 4x − 2 = 4x
```

成立。

**易错点。**

```text
一、λ 恰好是特征根时，特解没乘 x，代入后系数定不出来。
二、右端是 sin 2x 时，要用 ωi = 2i 去和特征根比，不是用 2。
三、通解忘了写"C₁、C₂ 为任意常数"。
四、给初值时求导求错，C₁、C₂ 解错。
五、一阶线性方程的通解公式里，e^(−∫P dx) 的符号容易反。
```

## 11. 套路九：空间解析几何

**识别信号。**

```text
"求过点 … 的平面方程""求两平面的夹角"。
"求点到平面的距离""判断直线与平面的位置关系"。
"求旋转面方程""这是什么曲面"。
```

**固定步骤。**

```text
第一步：分清要的是法向量还是方向向量。平面要 n，直线要 s。
第二步：给三点或两条线，叉乘出 n 或 s。
第三步：写点法式或对称式。
第四步：算距离、夹角，先套公式再代数。
第五步：旋转面用"绕谁转谁保留，另一个换成平方和开根"。
```

**例题。**

```text
求过 A(1, 2, 0)、B(0, 1, 1)、C(2, 0, 1) 的平面方程。
```

**第一步，造两个平面内的向量。**

```text
AB = (0 − 1, 1 − 2, 1 − 0) = (−1, −1, 1)
AC = (2 − 1, 0 − 2, 1 − 0) = (1, −2, 1)
```

**第二步，叉乘。**

```text
        | i   j   k |
n = AB×AC = | −1  −1   1 |
        |  1  −2   1 |
```

```text
i： (−1)×1 − 1×(−2) = −1 + 2 = 1
j： (−1)×1 − 1×1   = −1 − 1 = −2   （取负后为 2）
k： (−1)×(−2) − (−1)×1 = 2 + 1 = 3
```

```text
n = (1, 2, 3)
```

**第三步，取 A 点写点法式。**

```text
1(x − 1) + 2(y − 2) + 3(z − 0) = 0
```

展开：

```text
x + 2y + 3z − 5 = 0
```

**第四步，验算另外两点。**

```text
B(0, 1, 1)：0 + 2 + 3 − 5 = 0 ✓
C(2, 0, 1)：2 + 0 + 3 − 5 = 0 ✓
```

**答案：x + 2y + 3z = 5。**

**易错点。**

```text
一、叉乘中间那一项忘了负号。
二、平面方程里系数读成方向向量，或反过来。
三、距离公式漏绝对值，算出负数。
四、两平面夹角用 cos 取绝对值，线面夹角用 sin。
五、旋转面忘记正负两个根，或者绕错轴。
```

## 12. 套路十：应用题

**识别信号。**

```text
"求面积、体积、弧长、侧面积"。
"旋转体的体积"。
"最省材料、最大容积、最小成本"。
"变力做功、水压力、质心、平均值"。
```

**固定步骤。**

```text
第一步：建系。把图形放进坐标系，写出边界曲线。
第二步：确定用积分还是用导数。
      求量 → 积分；求最值 → 导数。
第三步：写出"微元"，即一小块的代表量。
第四步：积分求和，定限从图形上读。
第五步：检验。量纲对不对、正负号合不合理、数值是否离谱。
```

**三种最常见的微元。**

```text
面积：   dA = [f(x) − g(x)] dx
体积：   dV = π[f(x)² − g(x)²] dx   （绕 x 轴）
弧长：   ds = √(1 + y'²) dx
```

**例题。**

```text
求由 y = x² 与 y = 2 − x² 围成的区域绕 x 轴旋转所得立体的体积。
```

**第一步，找交点。**

```text
x² = 2 − x²  ⇒  2x² = 2  ⇒  x = ±1
```

两条曲线在 x = ±1 处相交，交点是 (−1, 1) 和 (1, 1)。

在这段区间里，2 − x² 在上，x² 在下。

**第二步，写体积公式。**

绕 x 轴旋转，用垫圈法：

```text
V = π ∫₋₁¹ [(2 − x²)² − (x²)²] dx
```

**第三步，展开被积函数。**

```text
(2 − x²)² = 4 − 4x² + x⁴
减去 x⁴，得 4 − 4x²
```

**第四步，积分。**

```text
V = π ∫₋₁¹ (4 − 4x²) dx
  = π [4x − (4/3)x³]₋₁¹
```

代入上限 1：

```text
4 − 4/3 = 8/3
```

代入下限 −1：

```text
−4 + 4/3 = −8/3
```

相减：

```text
8/3 − (−8/3) = 16/3
```

**第五步，乘 π。**

```text
V = 16π/3
```

**答案：16π/3 ≈ 16.8。**

**用估值检验。**

这块区域最宽处约 2、最高约 2，绕轴转出来的立体大约能装进半径 2、高 2 的圆柱。

圆柱体积 8π ≈ 25，答案 16π/3 ≈ 16.8 小于它，合理。

**如果是"最省材料"型的题。**

```text
第一步：写出目标函数（表面积、成本）。
第二步：用约束条件消掉一个变量。
第三步：求导，令导数为 0。
第四步：验证是极小（二阶导或端点比较）。
第五步：回到原题，写出答案的实际含义。
```

**易错点。**

```text
一、绕 y 轴旋转用了绕 x 轴的公式。
二、两条曲线上下位置搞反，被积函数写反，结果变负。
三、垫圈法忘了平方，写成 π∫[f(x) − g(x)]² dx。
四、定限没有取交点，凭感觉写 0 到 1。
五、最值题求出驻点就停，没有验证是极大还是极小。

```

## 13. 考场顺序与时间分配

套路会了，还得排得开。

这一节讲"先做哪道、后做哪道"。

**总账先算清楚。**

```text
数学一总分 150，考试 180 分钟。
高数约 82 分，线代约 34 分，概率约 34 分。
平均每分钟要拿 0.83 分。
```

换算成时间：

```text
一道 5 分的选择或填空，最多给 4 分钟。
一道 10 分的解答题，最多给 12 分钟。
```

超时的题，多半是方法选错了，不是算得慢。

**第一遍：扫一遍，标三档。**

拿到卷子先花两分钟，把题目分成三档：

```text
A 档：看一眼就知道用什么方法。先做。
B 档：知道考哪一块，但要试一下。第二遍做。
C 档：完全没思路。最后做，或者放弃。
```

标记用符号，不用文字，省时间。

**第二遍：按分值密度做。**

同样是 10 分，一道二重积分可能写 8 行，一道中值定理证明可能写 12 行还容易卡。

先做"单位时间得分高"的题：

```text
计算题优先于证明题。
套路明确的优先于需要构造的。
```

**第三遍：收尾与检查。**

留 10 到 15 分钟，专门做三件事：

```text
一、把没写的题补一个开头（写公式也有分）。
二、检查每道题的答案是否代回原式成立。
三、检查符号、上下限、常数 C。
```

**卡壳的处理办法。**

```text
同一道题想了 5 分钟还没动笔，标记后跳过。
跳过不是放弃，是把时间换到能拿分的地方。
回头再看时，往往一眼就通了。
```

**四条纪律。**

**纪律一：先写"方法名"，再动笔算。**

解答题第一行写清楚用什么方法：

```text
"由格林公式得 …"
"设 F(x) = f(x)e^(−x²)，则 …"
```

这一行本身就有分，而且能防止算到一半忘了自己在干什么。

**纪律二：每一步都写"等号右边是什么"。**

跳步是丢分的主要原因。

尤其是这三处最容易跳：

```text
换元时没写新变量的限。
分部时没写 −∫v du。
求导时没写链式法则的那一项。
```

**纪律三：算完必须验一次。**

不同题型验法不同，但都有十秒版：

```text
极限：代一个接近的数，看数值趋势。
积分：对结果求导，看是否回到被积函数。
微分方程：把解代回原方程。
二重积分：用面积或体积估个数量级。
平面方程：把三个点代进去。
```

**纪律四：不会的题，写"能写的部分"。**

证明题不会构造辅助函数，也可以先写：

```text
"因为 f 在 [a, b] 连续、在 (a, b) 可导，由拉格朗日中值定理 …"
```

写出定理的条件和结论，通常能拿到 2 到 3 分。

空白一定 0 分，写对一句就有一句的分。

**开考前五分钟做什么。**

```text
一、把十类题的顺序在草稿纸角落写一遍（三十秒）。
二、把最不熟的三个公式写在草稿纸上（一分钟）。
三、深呼吸，从 A 档题开始。
```

草稿纸上的那三个公式，建议选自：

```text
格林公式的方向、球坐标的 dV、二阶方程的特解形式。
```

这三处每年都有人写错。

**套路与知识的区别。**

知识回答"为什么"，套路回答"先动哪一步"。

```text
只会知识：考场上从定义想起，慢，而且容易卡。
只会套路：题型一变就废，因为不知道为什么。
```

正确的顺序是先知识、后套路，最后用真题把两者缝起来。

### 自检三问

**第一问：为什么"识别信号"比"记住步骤"更重要？**

因为步骤可以现场推，信号不能现场造。

考场上真正稀缺的是"第一分钟"。

```text
认出 1^∞，剩下四步是机械的。
认不出 1^∞，就会去通分、去平方，越走越远。
```

信号是入口，步骤是走法。

入口错了，走得再熟也没用。

**第二问：中值定理证明题，辅助函数是怎么想出来的？**

不是想出来的，是"倒推"出来的。

从要证的结论出发，把它整理成"某个函数的导数等于 0"：

```text
f'(ξ) + p(ξ)f(ξ) = 0
```

然后回忆乘积求导公式：

```text
(f·g)' = f'g + fg'
```

要让括号里出现 f' + pf，就得让 g'/g = p。

解这个微分方程，g = e^(∫p dx)。

所以辅助函数一定是 f 乘 e^(∫p dx)。

这条推导链一旦想通，就不用背公式了。

**第三问：为什么计算题也要"先判型"？**

因为不同型的题，容错率完全不同。

```text
二重积分算错一个限，整题 0 分。
极限题算错一步，后面还能拿步骤分。
```

判型之后，你会知道这道题该慢在哪一步。

二重、三重积分慢在"画图定限"。

级数慢在"端点单独判"。

微分方程慢在"特解形式"。

把慢的地方放慢，把机械的地方放快，这才是时间管理的真实含义。

## 15. 小结

这一篇压成一张卡片：

```text
十类题，每类四件事：
识别信号 → 固定步骤 → 例题答案 → 易错点。

极限：判型 → 等价 → 洛必达 → 取对数
导数：判求导方式 → 求 k → 点斜式
证明：移项 → 倒推 F → 验两端 → 罗尔
积分：换元 → 分部 → 拆项 → 换限
重积分：画图 → 选坐标 → 定限 → 对称性
线面积分：判类 → 判闭合 → 定向 → 套公式
级数：判型 → 判别法 → 算 R → 端点单独判
方程：判阶 → 特征方程 → 特解形式 → 定常数
空间几何：找 n 或 s → 叉乘 → 写方程
应用题：建系 → 微元 → 积分 → 检验
```

四条纪律再念一遍：

```text
先写方法名，再动笔算。
每一步都写等号右边。
算完必须验一次。
不会的题也要写出能写的部分。
```

三句自检：

```text
看到题先问"这是哪一类"。
动笔前先问"第一步是什么"。
写完先问"这个答案能代回去吗"。
```
