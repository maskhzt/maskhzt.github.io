> **读这篇之前，你只需要知道**：定积分 ∫ₐ^b f(x) dx 是把一根直线段切成小段，每段"高乘长度"再加起来；参数方程 x = x(t)、y = y(t) 用第三个变量 t 描述一条曲线，把 t 从 α 变到 β 就走完整条曲线。
> **这篇讲什么**：把"直线段"换成"一条弯曲的曲线"，两种加法于是分开：只累加函数值的叫第一类，连方向也一起累加的叫第二类；格林公式再把闭合曲线上的累加换成它围出的平面区域上的二重积分。
> **一个类比**：沿着盘山公路推车上山，做的功是把每一小段的"推力 × 小段长度"加起来；如果推的方向和小段方向不一致，只有沿路的那一部分力在起作用，这就是两类曲线积分的差别。

先看一个物理问题。

一个人拖着箱子，沿着一条弯曲的路走。

路不是直线，是曲线。

他每一点的用力方向都不同，大小也不同。

```text
在 A 点用力 10 牛，
走两米到 B 点，用力变成 12 牛，
再走三米到 C 点，用力变成 8 牛……
```

总共做了多少功？

不能直接用"力乘距离"。

因为力在变──这一点和定积分要解决的问题一样。

但还有第二个变化：

```text
力的方向，和路的方向，夹角一直在变。
```

在直线上，只要看"力乘位移"。

在曲线上，还要问"这个力有多少是沿着路的"。

于是同一个"沿曲线累加"，分裂成两种积分：

```text
只管"累加多少"，不管方向 → 第一类曲线积分（对弧长）
连着"方向"一起算 → 第二类曲线积分（对坐标）
```

**这一篇要回答四件事：**

```text
∫_L 和 ds 怎么读？
第一类和第二类有什么本质区别？
格林公式把曲线积分换成了什么？
为什么有些题换个路径答案不变？
```

## 1. 为什么需要它（不给会怎样）

没有这一节，你会以为"积分"都必须在一个区间或者一块区域上做。

曲线不是区间，也不是区域，它是"一条线"。

具体会卡在三个地方。

**第一处，定积分只能处理"直的、沿坐标轴"的线。**

定积分 ∫ₐ^b f(x) dx 的积分范围是 x 轴上的一段。

```text
它的几何意义是：曲线下的面积。
它的物理意义是：沿 x 方向的一段累积。
```

如果路径在平面里拐了弯，比如一段圆弧、一条抛物线，定积分就描述不了。

**第二处，很多物理量必须沿曲线累加。**

```text
一根弯曲的铁丝，密度不均匀，质量是多少？
一个力沿弯曲路径做的功是多少？
流体沿一条闭合回路转了一圈，环流是多少？
```

三个问题的共同点：

```text
累加的范围是一条曲线，不是一块面积。
```

**第三处，有些积分换条路结果就变了，有些不变。**

这两件事差别巨大，必须用不同的工具区分。

```text
重力做功：从三楼到一楼，走楼梯和坐电梯，做功一样。
摩擦力做功：走的路越长，做功越多，和路径有关。
```

前者的积分只跟起点、终点有关，叫**路径无关**。

后者不行。

要证明"路径无关"，靠的不是硬算两条路径，而是一个公式：格林公式。

所以这一章的骨架是：

```text
第一类：只看弧长，没有方向
第二类：看坐标，有方向
格林公式：把闭合曲线上的第二类，换成平面区域上的二重积分
路径无关：格林公式取值为 0 的特殊情形，可以找原函数
```

## 2. 最小模型：第一类曲线积分 ∫_L f ds

没有这一节，∫_L 和 ds 只是一串念不出来的符号。

你会在"沿曲线累加"这句话上停留很久，却写不出一个能算的式子。

先读符号。

```text
∫_L    读作"沿曲线 L 的积分"，L 是曲线（Line 的首字母）
f(x,y) 被积函数，可以是密度、可以是 1、可以是 x²
ds     读作"弧长元"，是曲线上一小段的长度
```

合起来：

```text
∫_L f(x,y) ds
```

它的意思是：

```text
把曲线 L 切成许多小段，每段长 Δs
在每段上挑一点，算出 f 在那里的值
相乘：f × Δs
全部加起来，取极限
```

写成定义：

```text
∫_L f ds = lim_{λ→0} Σ f(ξᵢ, ηᵢ) Δsᵢ
```

λ 是所有小段里最长的那段长度。

**这个积分没有方向。**

```text
从 A 走到 B，和从 B 走到 A，∫_L f ds 是同一个数。
```

原因很直白：ds 是"长度"，长度不分正负。

**它算的是什么？**

```text
f = 1 时，∫_L 1 ds = 曲线 L 的长度。
f = 密度时，∫_L ρ ds = 曲线的质量（一根弯铁丝的重量）。
f = 2πy 时，∫_L 2πy ds = 曲线绕 x 轴旋转所得曲面的面积（08 篇的公式）。
```

第一类曲线积分的几何意义，是"以曲线为底、以 f 为高的曲面的面积"，就像定积分是"以区间为底"的面积。

**怎么算？一招：参数化。**

设曲线用参数方程给出：

```text
x = x(t)，y = y(t)，α ≤ t ≤ β
```

那么弧长元是：

```text
ds = √(x'(t)² + y'(t)²) dt
```

为什么？

```text
t 变一点点 dt，x 变 x'dt，y 变 y'dt。
这一小段在平面上的位移是 (x'dt, y'dt)。
它的长度用勾股定理：√((x'dt)² + (y'dt)²) = √(x'² + y'²) dt。
```

于是：

```text
∫_L f ds = ∫_α^β f(x(t), y(t)) √(x'² + y'²) dt
```

**公式四步：第一类曲线积分。**

**第一步，算什么。**

```text
沿一条曲线，把"函数值 × 小段弧长"加起来。
```

**第二步，逐符号。**

```text
x(t), y(t)  曲线的参数方程
α, β       参数范围，必须 α < β（因为 ds 没有方向）
√(x'²+y'²)  弧长因子，把 dt 换算成弧长
f(x(t),y(t)) 把 x、y 换成 t 的表达式
```

**第三步，代数字。**

L 是从 (0,0) 到 (1,1) 的直线段，f = x + y。

参数化：

```text
x = t，y = t，0 ≤ t ≤ 1
```

算弧长因子：

```text
x' = 1，y' = 1，√(1 + 1) = √2
```

代入：

```text
∫_L (x+y) ds = ∫₀¹ (t + t) √2 dt = √2 ∫₀¹ 2t dt = √2 · 1 = √2
```

**第四步，适用条件。**

```text
第一，曲线要能参数化，且在参数范围内光滑（x'、y' 连续）。
第二，参数范围 α < β，写反了要取绝对值，不能直接写负号。
第三，如果 f 里出现 x、y，必须全部换成 t，积完不能剩 x、y。
```

**常见曲线的弧长因子，值得记住：**

```text
y = f(x)：           ds = √(1 + f'(x)²) dx
x = g(y)：           ds = √(1 + g'(y)²) dy
圆 x = a cosθ, y = a sinθ：ds = a dθ
直线段方向 (1, k)：   ds = √(1 + k²) dx
```

## 3. 算一遍：第一类曲线积分

不动手算两道，弧长因子 √(x'²+y'²) 永远记不住。

看完例题你会发现，难点从来不在概念，而在"这个根号积不积得出来"。

**例 1：一条圆弧。**

L 是上半圆 x² + y² = a²（y ≥ 0），求 ∫_L y ds。

**参数化。**

```text
x = a cosθ，y = a sinθ
上半圆 → θ 从 0 到 π
```

**算弧长因子。**

```text
x' = -a sinθ，y' = a cosθ
√(x'² + y'²) = √(a² sin²θ + a² cos²θ) = a
```

**代入。**

```text
∫_L y ds = ∫₀^π (a sinθ) · a dθ = a² ∫₀^π sinθ dθ
```

而 ∫₀^π sinθ dθ = [-cosθ]₀^π = 1 - (-1) = 2。

所以：

```text
∫_L y ds = 2a²
```

**验算思路：**

y 在这条半圆上的最大值是 a，平均值应该在 a 的一半附近。

半圆长度是 πa。

```text
2a² / (πa) = 2a/π ≈ 0.637a
```

y 沿半圆的平均值正好是 2a/π，和"半圆的重心高度"这个经典结论一致。

对上了。

**顺便：如果把 f 换成 x² + y² 呢？**

在圆上，x² + y² = a²，是个常数。

```text
∫_L (x²+y²) ds = a² ∫_L ds = a² · πa = πa³
```

这里用了"常数可以提出积分号"，以及 ∫_L ds = 曲线长度。

这是个很实用的技巧：

```text
曲线方程本身就是一个恒等式，能直接化简被积函数。
```

**例 2：一条抛物线。**

L 是 y = x² 从 (0,0) 到 (1,1)，求 ∫_L y ds。

**参数化。**

用 x 当参数最简单：

```text
y = x²，0 ≤ x ≤ 1
```

**弧长因子。**

```text
y' = 2x
ds = √(1 + 4x²) dx
```

**代入。**

```text
∫_L y ds = ∫₀¹ x² √(1 + 4x²) dx
```

这个积分要三角换元或分部，属于"能算但费时"的类型。

```text
令 2x = tan t，则 dx = (1/2)sec²t dt，√(1+4x²) = sec t。
x: 0 → 1 对应 t: 0 → arctan2。
```

算下去会得到一串 tan 和 sec 的组合。

**这个例子想说明的是：**

```text
第一类曲线积分的难点不在概念，在"根号能不能积出来"。
选参数时，尽量让 x'² + y'² 变成完全平方。
```

对比三条常见曲线：

```text
直线：√(1 + k²) 是常数，最好算。
圆：√(a² sin² + a² cos²) = a，也好算。
一般曲线：√(1 + f'²) 往往带根号，算不动就换参数。
```

**第一类可以用对称性，这是它比第二类好算的地方。**

因为 ds 没有方向，曲线关于某条轴对称时，可以直接用奇偶性。

```text
L 关于 y 轴对称（左右对称），f 对 x 是奇函数
→ ∫_L f ds = 0
```

例：L 是圆 x² + y² = 1，求 ∫_L x ds。

圆关于 y 轴对称，x 是奇函数，所以答案是 0。

```text
如果硬算：∫₀^{2π} cosθ · 1 dθ = 0，结论一样，但多花时间。
```

对比第二类：

```text
∫_L x dy 在同一个圆上，答案不是 0（等于 π）。
```

原因是 dy 在左右两半上符号相反，破坏了对消的条件。

```text
结论：第一类能放心用对称性，第二类要先看 dx、dy 的方向。
```

## 4. 最小模型：第二类曲线积分 ∫ P dx + Q dy

没有这一节，你只会算一种曲线积分。

遇到 dx、dy 就不知道它在算什么，也看不出它和"做功"有什么关系。

先说清楚它和第一类的区别。

```text
第一类：∫_L f ds   —— 拿函数值乘"长度"
第二类：∫_L P dx + Q dy —— 拿函数值乘"坐标的增量"
```

读法：

```text
∫_L P dx + Q dy
读作"沿 L 的 P 对 x 的积分，加 Q 对 y 的积分"。
```

符号：

```text
P(x,y)  乘 dx 的那一部分（x 方向的"力"）
Q(x,y)  乘 dy 的那一部分（y 方向的"力"）
dx      x 的微小增量，有正负
dy      y 的微小增量，有正负
```

**关键差别：dx 和 dy 是有符号的。**

```text
从 A 走到 B，dx > 0 表示 x 在增加。
从 B 走回 A，同样的路上 dx 就变成负的。
```

所以：

```text
∫_{-L} P dx + Q dy = - ∫_L P dx + Q dy
```

**换方向，第二类积分变号；第一类不变。**

这是两种积分最本质的区别，考试里最爱在这里设陷阱。

**它算的是什么？**

```text
力 F = (P, Q) 沿路径 L 做的功。
```

理由：

```text
一小段位移是 (dx, dy)。
力在这个位移上做的功，是"力与位移的内积"：P dx + Q dy。
沿路径全部加起来，就是总功。
```

**怎么算？还是参数化。**

```text
x = x(t)，y = y(t)，t 从 α 到 β
```

```text
dx = x'(t) dt，dy = y'(t) dt
```

代入：

```text
∫_L P dx + Q dy = ∫_α^β [ P(x(t),y(t)) x'(t) + Q(x(t),y(t)) y'(t) ] dt
```

注意：这里的 α、β 是**路径实际对应的方向**，α 可以大于 β。

如果路径是从 t = 1 走到 t = 0，那么 α = 1、β = 0，积分自然带负号。

**第二类的三种常见写法：**

```text
平面：∫_L P dx + Q dy
空间：∫_L P dx + Q dy + R dz
闭合曲线：∮_L P dx + Q dy（圈上画个小箭头表示方向）
```

**公式四步：第二类曲线积分（直接法）。**

**第一步，算什么。**

```text
把向量场 (P, Q) 沿一条有向曲线做"内积累加"。
```

**第二步，逐符号。**

```text
P, Q        两个分量函数
dx, dy      坐标增量，等于 x'(t)dt、y'(t)dt
α, β        起点和终点对应的参数（注意方向）
```

**第三步，代数字。**

L：抛物线 y = x²，从 (0,0) 到 (1,1)。

求 ∫_L (x² - y) dx + (y² + x) dy。

参数化：x = t，y = t²，t: 0 → 1。

```text
dx = dt，dy = 2t dt
P = x² - y = t² - t² = 0
Q = y² + x = t⁴ + t
```

代入：

```text
∫_L = ∫₀¹ [ 0 · 1 + (t⁴ + t) · 2t ] dt
= ∫₀¹ (2t⁵ + 2t²) dt
= 2/6 + 2/3
= 1/3 + 2/3
= 1
```

答案 1。

**第四步，适用条件。**

```text
第一，曲线要能参数化，且方向明确。
第二，被积函数里的 x、y 要全部换成 t。
第三，最后一步是一次定积分，别在里面再留 x、y。
```

**例：一道必须注意方向的题。**

L 是单位圆 x² + y² = 1，从 (1,0) 出发，逆时针走一圈。

求 ∮_L x dy - y dx。

参数化：

```text
x = cosθ，y = sinθ，θ: 0 → 2π（逆时针）
```

```text
dx = -sinθ dθ，dy = cosθ dθ
x dy - y dx = cosθ · cosθ dθ - sinθ · (-sinθ) dθ
= (cos²θ + sin²θ) dθ
= dθ
```

所以：

```text
∮_L = ∫₀^{2π} dθ = 2π
```

如果改成顺时针（θ: 2π → 0，或者 θ: 0 → -2π），结果就是 -2π。

**这个积分有一个漂亮的几何意义：**

```text
∮_L x dy - y dx = 2 × 曲线围成的面积
```

单位圆面积 π，2π 正好是两倍。

这条公式在第 8 节会由格林公式推出，是"用曲线积分求面积"的根据。

## 5. 两类曲线积分怎么换算

不弄清换算，你会把两类积分当成两门课，各背一套公式。

考场上题目一换写法，就跟不上。

同一个曲线，同一个向量场，两种积分其实是一回事。

差别只在于"怎么把向量场投影到路径方向上"。

**先看几何。**

曲线上一点，沿路径前进方向的单位切向量是：

```text
τ = (cosα, cosβ)
```

其中 cosα、cosβ 是这个方向与 x 轴、y 轴夹角的余弦。

```text
cosα = x'(t) / √(x'²+y'²)
cosβ = y'(t) / √(x'²+y'²)
```

**再看两个微元的关系。**

```text
dx = cosα ds
dy = cosβ ds
```

这句话的意思是：

```text
一小段弧长 ds，在 x 方向上的投影是 dx，在 y 方向上的投影是 dy。
```

和"斜边乘余弦得直角边"是同一件事。

**于是换算公式出来了：**

```text
∫_L P dx + Q dy = ∫_L (P cosα + Q cosβ) ds
```

右边是一个第一类曲线积分，被积函数是"向量场在切线方向上的投影"。

**反过来不好用，这是要提醒的一点。**

能不能把第一类换成第二类？

```text
设 P = f cosα，Q = f cosβ，就能把 f ds 写成 P dx + Q dy。
```

这个写法在纸面上成立，但没用。

因为 P、Q 里含着方向余弦，而方向余弦本身就是从参数方程来的。

绕了一圈，还是回到了参数。

更根本的原因是：ds 无法写成 dx、dy 的线性组合。

```text
dx、dy 是向量 (dx, dy) 的两个分量，
ds 是这个向量的长度。
从分量到长度要开根号，不是线性的。
```

所以换算只有一个方向好用：

```text
第二类 → 第一类：乘方向余弦，机械，不会错。
第一类 → 第二类：没有通用的机械公式，只能回到参数。
```

**什么时候需要换算？**

```text
第一，题目给的场是"向量形式"，要求用第一类算。
第二，物理上要算"通量"或"环流"时，两个形式会互相转换。
第三，格林公式的推导，用的就是换算。
```

**一个具体的换算例子。**

L 是单位圆，逆时针。

求 ∮_L (x + y) dx + (x - y) dy，用第一类验证。

先算直接法：

```text
x = cosθ，y = sinθ
dx = -sinθ dθ，dy = cosθ dθ
(x+y)dx + (x-y)dy
= (cosθ+sinθ)(-sinθ) + (cosθ-sinθ)(cosθ)
= -cosθsinθ - sin²θ + cos²θ - sinθcosθ
= cos2θ - sin2θ
```

```text
∮ = ∫₀^{2π} (cos2θ - sin2θ) dθ = 0 - 0 = 0
```

用换算验证：

```text
cosα = -sinθ，cosβ = cosθ（单位圆的切向量）
P cosα + Q cosβ = (cosθ+sinθ)(-sinθ) + (cosθ-sinθ)(cosθ)
```

这正好是上面同一个式子。

所以还是 0。

**这个例子说明换算公式不是新东西，就是把 dx、dy 拆成 ds 乘余弦。**

## 6. 格林公式：把闭合曲线换成二重积分

先说没有它会怎样。

```text
题目要算 ∮_L P dx + Q dy，L 是一条由三条直线拼成的闭合三角形。
```

直接算要分三段，每段参数化、每段定积分，再相加。

三段里只要有一段算错，全错。

格林公式把这三段一次性换掉。

**公式：**

```text
∮_L P dx + Q dy = ∬_D ( ∂Q/∂x - ∂P/∂y ) dx dy
```

读法：

```text
"沿闭曲线 L 的正向环量，等于它围出的区域 D 上，(Q 对 x 的偏导 减 P 对 y 的偏导) 的二重积分。"
```

**逐符号：**

```text
L        闭曲线，分段光滑，不自交
D        L 围成的平面区域
∮        闭合曲线积分，圈表示首尾相接
正向      沿 L 走时，区域 D 始终在你的左手边
          （对外边界来说，就是逆时针）
∂Q/∂x    Q 对 x 的偏导，把 y 当常数
∂P/∂y    P 对 y 的偏导，把 x 当常数
```

**四步：**

**第一步，算什么。**

```text
把"沿边界的环量"换成"内部每一点的旋转程度的总和"。
```

**第二步，逐符号。**

```text
∂Q/∂x - ∂P/∂y 这个组合，叫"旋度"（平面情形）。
它衡量向量场在这一点"转得有多厉害"。
```

**第三步，代数字。**

L 是三角形 (0,0) → (3,0) → (0,2) → (0,0)，逆时针。

```text
P = 2x - y + 4，Q = 5y + 3x - 6
```

求偏导：

```text
∂Q/∂x = 3
∂P/∂y = -1
∂Q/∂x - ∂P/∂y = 3 - (-1) = 4
```

所以：

```text
∮_L = ∬_D 4 dx dy = 4 × D 的面积
```

三角形面积：

```text
S = (1/2) × 3 × 2 = 3
```

答案：

```text
∮_L = 4 × 3 = 12
```

**第四步，适用条件（三条，缺一不可）。**

```text
第一，L 必须是闭合曲线。
第二，L 必须取正向（逆时针，区域在左手边）。
第三，P、Q 在 D 上必须有连续的一阶偏导（D 内不能有奇点）。
```

**第三条是最容易翻车的地方。**

看这个积分：

```text
∮_L (x dy - y dx)/(x² + y²)
```

L 是单位圆，逆时针。

按公式，P = -y/(x²+y²)，Q = x/(x²+y²)。

算出来 ∂Q/∂x - ∂P/∂y = 0（在原点以外处处为 0）。

如果直接写"答案是 0"，就错了。

因为 P、Q 在原点没有定义，原点就在 D 里面。

**这时候要用"挖洞法"。**

做法：

```text
在原点周围挖一个半径 ε 的小圆 L_ε，
在"大圆和小圆之间"的环形区域 D' 上用格林公式。
```

环形区域的边界是两条曲线：外圈逆时针，内圈顺时针。

```text
∮_{外} + ∮_{内（顺时针）} = ∬_{D'} 0 = 0
```

所以：

```text
∮_{外（逆时针）} = ∮_{小圆（逆时针）}
```

在小圆上，x² + y² = ε²，可以直接算：

```text
x = εcosθ，y = εsinθ
x dy - y dx = ε² dθ
除以 ε² 得 dθ
∮ = ∫₀^{2π} dθ = 2π
```

**答案 2π，和 ε 无关。**

这个结论很值得记住：

```text
绕原点一圈的这个积分，永远是 2π。
绕两圈是 4π，绕三圈是 6π。
不绕原点，就是 0。
```

它衡量的是"曲线把原点围了几次"，几何上叫绕数。

**格林公式的四种用法：**

```text
用法一：把曲线积分换成二重积分（最常见）。
用法二：把二重积分换成曲线积分（少见，但面积题好用）。
用法三：证明路径无关（右端恒为 0 时）。
用法四：求面积：S = (1/2)∮_L x dy - y dx。
```

**面积公式的来历：**

在格林公式里取 P = -y/2，Q = x/2：

```text
∂Q/∂x - ∂P/∂y = 1/2 + 1/2 = 1
```

于是：

```text
∮_L (-y/2) dx + (x/2) dy = ∬_D 1 dx dy = S
```

整理就是 S = (1/2)∮_L x dy - y dx。

椭圆 x²/a² + y²/b² = 1 的面积：

```text
x = a cosθ，y = b sinθ
x dy - y dx = ab cos²θ dθ + ab sin²θ dθ = ab dθ
S = (1/2) ∫₀^{2π} ab dθ = πab
```

一行得出，不用二重积分。

## 7. 算一遍：格林公式的四道题

不看这四个例子，格林公式只是一个记不住的等式。

而它真正难的地方，全都在"不闭合怎么办""有洞怎么办""面积怎么求"这三处。

**第一道：椭圆上的环量。**

求 ∮_L x dy - y dx，L 是椭圆 x²/a² + y²/b² = 1，逆时针。

用格林公式：

```text
P = -y，Q = x
∂Q/∂x = 1，∂P/∂y = -1
∂Q/∂x - ∂P/∂y = 2
```

```text
∮_L = ∬_D 2 dx dy = 2 × πab = 2πab
```

和第 4 节单位圆的结果 2π 一致（取 a = b = 1）。

**第二道：不闭合，先补线。**

求 ∫_L (x² - y) dx + (x + y²) dy，L 是从 (0,0) 沿 y = x² 到 (1,1) 的弧。

L 不闭合，不能直接用格林公式。

补一条从 (1,1) 回到 (0,0) 的线段 L₁，凑成闭合回路。

```text
∮_{L+L₁} = ∬_D (∂Q/∂x - ∂P/∂y) dx dy
```

算旋度：

```text
∂Q/∂x = 1，∂P/∂y = -1
旋度 = 1 - (-1) = 2
```

区域 D 是抛物线与直线 y = x 之间（从 (0,0) 到 (1,1)）的部分。

```text
面积 = ∫₀¹ (x - x²) dx = 1/2 - 1/3 = 1/6
```

所以闭合回路上的积分是 2 × 1/6 = 1/3。

再算补的那条线段 L₁：从 (1,1) 到 (0,0)，沿 y = x。

```text
x = t，y = t，t 从 1 到 0
dx = dt，dy = dt
(x²-y)dx + (x+y²)dy = (t²-t)dt + (t+t²)dt = (2t²)dt
∫_1^0 2t² dt = -2/3
```

所以：

```text
∫_L = ∮ - ∫_{L₁} = 1/3 - (-2/3) = 1
```

答案 1。

**这和直接参数化算出来的结果一样吗？**

直接算：

```text
y = x²，dy = 2x dx
(x² - x²) + (x + x⁴)(2x) = 2x² + 2x⁵
∫₀¹ (2x² + 2x⁵) dx = 2/3 + 1/3 = 1
```

对上了。

**第三道：有奇点，挖洞。**

求 ∮_L (x dy - y dx)/(x²+y²)，L 是椭圆 x²/4 + y² = 1，逆时针。

原点在椭圆内部，是被积函数的奇点。

挖洞：用单位圆 L_ε 把原点围起来。

```text
环形区域上旋度为 0，所以 ∮_{外} = ∮_{小圆}
小圆上的积分 = 2π（第 6 节算过）
```

答案 2π。

注意：**外圈是椭圆还是圆，不影响答案。**

只要它把原点围了一圈，答案就是 2π。

```text
这就是"路径无关"的另一种形态：只看绕数，不看形状。
```

**第四道：用格林公式求面积（摆线一拱）。**

摆线的参数方程：

```text
x = a(t - sin t)，y = a(1 - cos t)，t 从 0 到 2π
```

这一拱曲线与 x 轴围成一块区域。

用面积公式：

```text
S = (1/2) ∮_L x dy - y dx
```

先算微元。

```text
dx = a(1 - cos t) dt
dy = a sin t dt
```

代入 x dy - y dx：

```text
= a(t - sin t) · a sin t dt - a(1 - cos t) · a(1 - cos t) dt
= a² [ (t - sin t) sin t - (1 - cos t)² ] dt
```

把中括号展开：

```text
(t sin t - sin²t) - (1 - 2cos t + cos²t)
= t sin t - (sin²t + cos²t) - 1 + 2cos t
= t sin t - 2 + 2cos t
```

三项分别积：

```text
∫₀^{2π} t sin t dt = [-t cos t + sin t]₀^{2π} = -2π
∫₀^{2π} (-2) dt = -4π
∫₀^{2π} 2cos t dt = 0
```

合计 -6π。

```text
S = (1/2) · a² · (-6π) = -3πa²
```

面积不能是负数。

负号的含义是：这条摆线按 t 增大走的时候是**顺时针**的（拱顶在上，从右往左绕回来）。

```text
取绝对值，S = 3πa²。
```

**这个例子给了一条实用经验：**

```text
用格林公式求面积时，符号只表示绕行方向。
题目问"面积"，就取正值；问"环量"，符号必须保留。
```

顺便记住摆线的两个经典结论：

```text
一拱的长度 = 8a
一拱下方的面积 = 3πa²
```

前者用 ∫_L 1 ds 算，后者用上面这个公式算，两条路都通向 a 的倍数。

## 8. 路径无关与保守场

先说没有它会怎样。

```text
题目说："验证积分与路径无关，并求值。"
```

如果你只会直接算，就只能选一条路径硬算。

但"验证"两个字要求你证明它对**所有**路径都成立，硬算一条不够。

**什么是路径无关？**

```text
在区域 G 内，从 A 到 B 的积分，
不管走哪条路，结果都一样，
就叫"积分与路径无关"。
```

数学写法：

```text
∫_{L₁} P dx + Q dy = ∫_{L₂} P dx + Q dy  （L₁、L₂ 都从 A 到 B）
```

**等价条件有四条，必须一起记：**

```text
第一条：∫_L 与路径无关（只跟起点终点有关）。
第二条：沿 G 内任意闭曲线的 ∮ = 0。
第三条：存在函数 u(x,y)，使 du = P dx + Q dy。
第四条：∂P/∂y = ∂Q/∂x 在 G 内处处成立（G 是单连通区域）。
```

**四条为什么等价？**

```text
第一条 ⟺ 第二条：
  两条从 A 到 B 的路，一去一回组成闭曲线。
  路径无关意味着两条路积分相等，
  也就是"去 - 回 = 0"，即闭合积分 = 0。

第二条 ⟺ 第三条：
  闭合积分恒为 0，说明积分只跟端点有关。
  固定起点，把终点当变量，就定义出一个函数 u。
  这个 u 满足 du = P dx + Q dy。

第三条 ⟺ 第四条：
  du = (∂u/∂x)dx + (∂u/∂y)dy，
  所以 P = ∂u/∂x，Q = ∂u/∂y。
  再求一次偏导：∂P/∂y = ∂²u/∂x∂y，∂Q/∂x = ∂²u/∂y∂x。
  二阶混合偏导连续时两者相等（10 篇的定理）。
```

**第四条的反方向为什么不平凡？**

```text
需要区域"单连通"：区域内没有洞。
有洞时，∂P/∂y = ∂Q/∂x 仍可能成立，但闭合积分不为 0。
```

典型反例就是第 6 节那个：

```text
P = -y/(x²+y²)，Q = x/(x²+y²)
旋度处处为 0，但绕原点一圈的积分是 2π，不是 0。
```

原因是区域"挖掉了原点"，不单连通。

**这告诉我们一件重要的事：**

```text
做题时看到"旋度为 0"，先确认区域里有没有洞。
有洞就要挖洞，不能直接说答案 0。
```

**怎么用第三条？找原函数。**

如果存在 u 使 du = P dx + Q dy，那么：

```text
∫_A^B P dx + Q dy = u(B) - u(A)
```

这个式子是曲线积分版的牛顿-莱布尼茨公式。

**找 u 的两种方法：**

**方法一：凑全微分。**

```text
看到 P dx + Q dy，试着把它凑成 d(某个东西)。
```

例：

```text
2xy dx + x² dy = d(x²y)
```

因为 d(x²y) = 2xy dx + x² dy。

所以从 (0,0) 到 (1,1) 的积分：

```text
u(1,1) - u(0,0) = 1·1 - 0 = 1
```

**方法二：偏积分。**

```text
由 ∂u/∂x = P，对 x 积分得 u = ∫P dx + φ(y)。
再对 y 求偏导，令它等于 Q，解出 φ'(y)，积出 φ(y)。
```

例：P = 2xy，Q = x²。

```text
∂u/∂x = 2xy → u = x²y + φ(y)
∂u/∂y = x² + φ'(y) = Q = x² → φ'(y) = 0 → φ = C
```

所以 u = x²y + C。

**方法三：折线法（选一条好走的路）。**

既然与路径无关，就选最容易算的路径：先水平再竖直。

```text
从 (x₀,y₀) 到 (x,y)，走 (x₀,y₀) → (x,y₀) → (x,y)
```

```text
u = ∫_{x₀}^{x} P(t, y₀) dt + ∫_{y₀}^{y} Q(x, t) dt
```

这个方法在考试里最稳，因为不用动脑筋凑。

**一道综合例题。**

```text
验证 ∫_L (2xy + y²) dx + (x² + 2xy) dy 与路径无关，并求从 (1,0) 到 (2,1) 的值。
```

**验证：**

```text
P = 2xy + y²，∂P/∂y = 2x + 2y
Q = x² + 2xy，∂Q/∂x = 2x + 2y
```

两者相等，且区域是全平面（单连通），所以路径无关。

**求原函数：**

```text
∂u/∂x = 2xy + y² → u = x²y + xy² + φ(y)
∂u/∂y = x² + 2xy + φ'(y) = x² + 2xy → φ'(y) = 0
```

所以 u = x²y + xy²。

**代端点：**

```text
u(2,1) = 4·1 + 2·1 = 6
u(1,0) = 0 + 0 = 0
```

答案 6。

**用折线法验算：**

```text
(1,0) → (2,0)：y = 0，dy = 0，P = 0 → 积分 0
(2,0) → (2,1)：x = 2，dx = 0，Q = 4 + 4t
∫₀¹ (4 + 4t) dt = 4 + 2 = 6
```

合计 6，一致。

**空间中的路径无关，长什么样？**

把 P dx + Q dy 换成 P dx + Q dy + R dz。

判据从两个偏导变成一个"三对"：

```text
∂P/∂y = ∂Q/∂x
∂Q/∂z = ∂R/∂y
∂P/∂z = ∂R/∂x
```

三条同时成立，才叫"旋度为零"。

```text
缺一条，场就有旋转，积分就与路径有关。
```

比如 F = (-y, x, 0)：前两条都不成立（∂P/∂y = -1，∂Q/∂x = 1），所以绕 z 轴转圈的积分不是 0。

它的积分值正好是 2 × 绕 z 轴的面积投影，这就是 15 篇斯托克斯公式的内容。

```text
二维的格林公式，是三维斯托克斯公式在平面上的特例。
所以这一节的"旋度"，在 15 篇会被写成"旋度向量"。
```

## 9. 常见错误

不列一份错误清单，四类失分会反复出现：混类型、丢因子、错方向、误用条件。

**错误一：把两类积分混为一谈。**

```text
第一类 ∫ f ds：无方向，换方向不变号。
第二类 ∫ P dx + Q dy：有方向，换方向变号。
```

判断依据：看题目写的是 ds 还是 dx、dy。

**错误二：第二类积分换方向后忘了变号。**

```text
从 (1,0) 走到 (0,0) 和反过来，答案差一个负号。
```

参数化时把 t 的范围写对，负号会自然出现，不用另外加。

**错误三：第一类积分把参数范围写反。**

```text
∫_α^β 里必须 α < β。
写反了不能直接加负号，要交换上下限并保证被积函数为正。
```

原因：ds 是长度，长度不能是负的。

**错误四：忘了弧长因子。**

```text
错：∫_L f ds = ∫_α^β f(x(t),y(t)) dt
对：∫_L f ds = ∫_α^β f(x(t),y(t)) √(x'²+y'²) dt
```

这是第一类最高频的失分点。

**错误五：格林公式用在非闭曲线上。**

```text
题目给的 L 是开口的，却直接写 ∮ = ∬。
```

两种补救：

```text
补线凑闭合，再减掉补的部分；
或者老老实实参数化直算。
```

**错误六：方向搞错。**

格林公式要求正向（逆时针，区域在左手边）。

```text
顺时针时，答案是公式结果的相反数。
```

**错误七：有奇点还用格林公式。**

```text
被积函数在 D 内某点没定义，却写 ∬_D 旋度。
```

必须先挖洞，或者换区域。

**错误八：路径无关的条件用错。**

```text
只验证了 ∂P/∂y = ∂Q/∂x，没检查区域是否单连通。
```

有洞的区域必须挖洞。

**错误九：原函数求完忘了代端点。**

```text
u = x²y + xy² 只是中间结果，
最后要 u(B) - u(A)。
```

## 10. 数一怎么考

不知道考法，你会把精力放在概念辨析上。

而这一章的分数，几乎全落在"参数化 + 格林公式 + 补线"这三件事上。

**题型一：直接计算第一类曲线积分。**

参数化 + 弧长因子 + 定积分。

难点常被放在"根号能不能积出来"，所以要练熟三类曲线：

```text
直线、圆、抛物线。
```

**题型二：直接计算第二类。**

参数化 + 代 dx、dy + 定积分。

关键是方向。

**题型三：格林公式。**

这是解答题的主力。

常见形态：

```text
给一条闭曲线（三角形、椭圆、圆、分段曲线），求 ∮。
```

步骤固定：

```text
一、判断是否闭合、是否正向。
二、算 ∂Q/∂x - ∂P/∂y。
三、算区域面积（或者做二重积分）。
四、相乘。
```

**题型四：补线凑闭合。**

给的曲线开口，需要补一条简单的线。

```text
补的线通常取：坐标轴上的线段、直线段。
因为它上面 dy = 0 或者 dx = 0，算起来最快。
```

**题型五：挖洞。**

被积函数带 x² + y² 在分母，且区域含原点。

```text
答案通常是 2π 的整数倍。
```

**题型六：路径无关 + 求原函数。**

```text
题目："证明积分与路径无关，并求值。"
或者："求 u 使 du = P dx + Q dy。"
```

两条路都通向 u(B) - u(A)。

**题型七：求面积。**

```text
S = (1/2)∮_L x dy - y dx
```

对星形线、摆线、椭圆这类"参数方程好写、面积不好算"的曲线特别有用。

**题型八：证明题。**

典型：

```text
设 P、Q 在单连通区域内有连续偏导，
证明"∮_L P dx + Q dy = 0 对任意闭曲线成立"蕴含"存在原函数"。
```

思路就是第 8 节的四条等价，一路推过去。

**题型九：含参数的反问题。**

```text
已知 ∮_L a x y² dx + x² y dy = 0 对任意闭曲线成立，求 a。
```

思路：闭合积分恒为 0，说明旋度为 0。

```text
P = a x y²，∂P/∂y = 2a x y
Q = x² y， ∂Q/∂x = 2x y
令 2a x y = 2x y，得 a = 1。
```

这类题只有两步：

```text
第一步，算出旋度。
第二步，令它恒等于 0，比较系数。
```

难的不是方法，是别忘了"恒成立"意味着"对任意 x、y 都成立"，所以系数必须逐个相等。

**一道数一风格的完整题。**

```text
计算 ∮_L (e^x sin y - y) dx + (e^x cos y - 1) dy，
L 是上半圆周 x² + y² = 2x（y ≥ 0），从 (0,0) 到 (2,0)。
```

**第一步，判断。**

L 是开口的（半圆），不闭合。

补一条从 (2,0) 沿 x 轴回 (0,0) 的线段 L₁，构成闭合回路。

**第二步，算旋度。**

```text
P = e^x sin y - y
Q = e^x cos y - 1

∂Q/∂x = e^x cos y
∂P/∂y = e^x cos y - 1

旋度 = e^x cos y - (e^x cos y - 1) = 1
```

**第三步，算二重积分。**

```text
∬_D 1 dx dy = D 的面积
```

D 是上半圆 x² + y² ≤ 2x，即 (x-1)² + y² ≤ 1，半径 1。

半圆面积：

```text
S = π/2
```

所以闭合回路上的积分是 π/2。

**第四步，算补的那条线。**

L₁：从 (2,0) 到 (0,0)，沿 x 轴，y = 0，dy = 0。

```text
被积函数变成 (e^x · 0 - 0) dx = 0
```

积分是 0。

**第五步，得答案。**

```text
∫_L = ∮ - ∫_{L₁} = π/2 - 0 = π/2
```

**答案 π/2。**

**这道题的关键在哪？**

```text
旋度算出来是常数 1，二重积分退化成"算面积"。
指数函数和三角函数看着吓人，其实全部消掉了。
```

这就是格林公式的威力：

```text
它把"被积函数长什么样"变成"旋度长什么样"。
旋度是常数，题就成了一道面积题。
```

## 11. 和其他章节怎么连

不接回其他章节，你会觉得这一章是凭空冒出来的。

其实它就是"定积分弯一下"，再把"降一维"的方向反过来看。

**往回连：07 定积分。**

把 L 取成 x 轴上从 a 到 b 的线段，第一类曲线积分就退化成定积分：

```text
∫_L f ds = ∫_a^b f(x) √(1+0) dx = ∫_a^b f dx
```

第二类也退化：

```text
∫_L P dx + Q dy = ∫_a^b P(x,0) dx（因为 dy = 0）
```

所以曲线积分是定积分的"弯版"。

**往回连：10、11 偏导与全微分。**

格林公式里的 ∂Q/∂x - ∂P/∂y，是全微分的"反对称部分"。

```text
P dx + Q dy 是全微分 ⟺ ∂P/∂y = ∂Q/∂x
```

这句话就是 11 篇的"恰当微分"判据。

曲线积分把它变成了"路径无关"。

**往回连：13 三重积分。**

格林公式是二维版本，高斯公式是三维版本：

```text
格林：闭合曲线 → 平面区域（降一维）
高斯：闭合曲面 → 空间立体（降一维）
```

两者都是"边界上的积分 = 内部的某种导数之和"。

**往前连：15 曲面积分与三大公式。**

斯托克斯公式是格林公式在空间中的推广：

```text
∮_Γ P dx + Q dy + R dz = ∬_Σ (旋度) · n dS
```

格林公式是它的特例（曲面取成平面区域）。

所以这一篇学透，15 篇的斯托克斯就是"加一个 z"。

**横向连：21 空间解析几何。**

空间曲线要参数化，需要认方程：

```text
螺旋线 x = a cos t，y = a sin t，z = bt
两曲面交线：把其中一个当参数
```

认不出曲线，就写不出参数方程，积分就无从下手。

**横向连：08 定积分的应用。**

弧长公式：

```text
s = ∫_a^b √(1 + f'(x)²) dx
```

它就是 ∫_L 1 ds。

曲线积分把"弧长"变成了一个特例（f = 1）。

### 自检三问

**第一问：为什么第一类曲线积分换方向不变号，第二类要变号？**

因为两者的"微元"性质不同。

第一类的微元是 ds，是长度，长度永远为正。

```text
从 A 走到 B，把曲线切成小段，每段长 Δs。
从 B 走到 A，切出来的还是那些小段，长度一样。
```

第二类的微元是 dx、dy，是坐标的增量，有正负。

```text
从 A 走到 B，x 可能增加，dx > 0。
从 B 走回 A，同一段上 x 在减少，dx < 0。
```

所以换方向时，每一项都变号，总和变号。

**第二问：格林公式为什么要求"正向"？**

因为公式的两边都要有"符号一致"的约定。

在推导时，区域被切成小方块，内部相邻两块的公共边上的积分互相抵消。

抵消成立的前提是：绕每一小块时，方向都是"逆时针"。

而外边界的方向，正是这些小方块边界"拼"出来的方向。

```text
如果外边界取顺时针，抵消时符号就反了，公式右端要加负号。
```

所以正向不是习惯问题，是公式成立的条件之一。

**第三问：路径无关的四个等价条件，为什么必须加"单连通"？**

因为第四条推第二条时，要用"区域内的闭曲线都能围出一块完整的区域"。

区域有洞时，绕洞的闭曲线围出的区域里包含洞，洞上函数没定义，格林公式用不了。

```text
典型反例：P = -y/(x²+y²)，Q = x/(x²+y²)。
旋度处处为 0，但绕原点一圈积分是 2π。
```

所以：

```text
旋度为 0 只是"局部"信息，
要推到"整体"（闭合积分为 0），必须区域没有洞。
```

## 12. 小结 + 下一篇

没有小结，这一章会剩下四五个公式，遇题不知道该翻哪一个。

压成一张卡片：

```text
第一类：∫_L f ds，无方向，ds = √(x'²+y'²) dt
第二类：∫_L P dx + Q dy，有方向，换向变号
换算：  P dx + Q dy = (P cosα + Q cosβ) ds
格林：  ∮_L P dx + Q dy = ∬_D (∂Q/∂x - ∂P/∂y) dx dy
         条件：闭合、正向、无奇点
面积：  S = (1/2)∮_L x dy - y dx
路径无关：∮ = 0 ⟺ 存在 u ⟺ ∂P/∂y = ∂Q/∂x（单连通）
```

四步公式的统一形态：

```text
算什么 → 沿一条曲线做累积（带不带方向）
逐符号 → ∫_L、ds 或 dx dy、方向、端点
代数字 → 参数化，把 x、y 换成 t，积一次定积分
适用条件 → 光滑、方向、闭合、单连通
```

考场上的判断顺序：

```text
一、看微元：ds 还是 dx dy？
二、看闭合：闭合 → 想格林；开口 → 想补线或参数化
三、看奇点：分母有 x²+y² 且区域含原点 → 挖洞
四、看旋度：∂Q/∂x - ∂P/∂y 是不是 0 或常数
五、看是否问到"路径无关"或"原函数"
```

三句提醒。

```text
第一句：先判类型再动手，ds 和 dx 是两条完全不同的路。
第二句：格林公式的三个条件，写答案前默念一遍。
第三句：遇到 1/(x²+y²)，第一反应是"有没有洞"，不是"能不能算"。
```
