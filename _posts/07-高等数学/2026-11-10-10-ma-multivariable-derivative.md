> **读这篇之前，你只需要知道**：一元函数 y = f(x) 是"一个输入对应一个输出"，它的导数是切线斜率；平面上一个点用一对数 (x, y) 表示，就像地图上的经纬度；求导就是把"变化量之比的极限"算出来。
> **这篇讲什么**：输入从一个数变成一对数，函数图像从曲线变成曲面；这时候"变化率"不再唯一，得先说明"沿着哪个方向变"，于是有了偏导数。
> **一个类比**：站在一座山坡上，问"这里陡不陡"没法回答，得先问"朝哪个方向走"——朝东走是一个坡度，朝北走是另一个坡度。

拿一块矩形铁板。

板上每一点的温度都不一样：

```text
左下角 20 度，右上角 80 度，中间某点 45 度。
```

温度由两个坐标决定：

```text
T = T(x, y)
```

现在问一个问题：

```text
在 (3, 4) 这一点，温度变化有多快？
```

这个问题没法直接回答。

因为"变化"要先说方向。

朝 x 方向走一步，温度可能升 2 度；朝 y 方向走一步，温度可能升 5 度。

**一元函数没有这个麻烦。**

y = f(x) 只有一个方向可走，导数就是导数。

二元函数有无数个方向，必须一个一个来。

先固定其他方向，只让一个变量动，这就是**偏导数**。

这一篇就干这一件事。

## 1. 为什么需要它（不给会怎样）

没有这一节，你会把一元的所有结论直接搬到多元，然后处处碰壁。

具体会撞上四堵墙。

**第一堵，一个数不够描述位置。**

一元函数说"在 x = 3 处"，位置是一个点。

二元函数说"在 (3, 4) 处"，位置是平面上一个点，需要两个数。

```text
一元：定义域是数轴上的区间
二元：定义域是平面上的一块区域
```

区域的形状五花八门：矩形、圆盘、三角形、被一条曲线切出来的半块。

不会画定义域，后面所有积分都写不对。

**第二堵，"趋近"的方式变多了。**

一元里 x → 0 只有两个方向：从左、从右。

二元里 (x, y) → (0, 0) 有无数条路径：沿 x 轴、沿 y 轴、沿直线 y = kx、沿抛物线 y = x²。

**极限要存在，必须所有路径都通向同一个数。**

一条路径给出不同的值，极限就不存在。

这是多元和一元最大的区别，也是考试第一个考点。

**第三堵，"变化率"必须先指定方向。**

前面铁板的例子已经说明。

偏导数就是"沿坐标轴方向的变化率"。

它只管两个特殊方向，其他方向留给下一篇的方向导数。

**第四堵，几何从曲线变成曲面。**

一元：曲线 + 切线。

二元：曲面 + 切平面。

切平面的方程要用到两个偏导数，下一篇的全微分就是它的另一种写法。

所以这一篇是多元微积分的地基。

地基没打好，全微分、极值、重积分全是空中楼阁。

**再看两个真实场景，体会"多元"为什么绕不开。**

场景一，生产成本。

一家厂生产两种产品，产量分别是 x 和 y，总成本 C = C(x, y)。

想知道"多生产一件 A 产品，成本增加多少"，这就是 ∂C/∂x。

场景二，地形。

一座山的海拔 h = h(x, y)，两个坐标是经纬度。

想知道"往东走一步升高多少"，这就是 ∂h/∂x。

**这两个场景有一个共同点：另一个变量必须被按住。**

问"多生产 A 的成本"，前提是 B 的产量不变。

问"往东走的坡度"，前提是纬度不变。

一旦这个前提变了，答案就变了。

**这就是偏导数名字里"偏"的意思：片面地看一个方向。**

## 2. 最小模型：二元函数与它的定义域

没有这一步，你连题目在说什么都看不清。

先读符号。

```text
z = f(x, y)
```

**z**：因变量，也叫函数值。

**f**：对应规则，读"f"。

**(x, y)**：一对有序实数，是平面上的一个点。

**f(x, y)**：读"f 在 (x, y) 处的值"。

整体读作："z 等于 f 在 x、y 处的值"。

它的意思很朴素：给一对数，按规则算出一个数。

**例一。**

```text
z = x² + y²
```

给 (1, 2)，算出 1 + 4 = 5。

给 (0, 0)，算出 0。

给 (-3, 4)，算出 9 + 16 = 25。

**例二。**

```text
z = √(1 - x² - y²)
```

这个规则有前提：根号里不能是负的。

```text
1 - x² - y² ≥ 0  ⇒  x² + y² ≤ 1
```

所以定义域是单位圆盘，包括边界。

给 (0.6, 0.8)：0.36 + 0.64 = 1，根号里是 0，z = 0。

给 (1, 1)：根号里是 -1，没有意义，这个点不在定义域内。

**例三。**

```text
z = ln(x + y)
```

要求 x + y > 0，定义域是直线 x + y = 0 右上方的半平面。

边界那条直线不算，因为 ln 0 没有定义。

**定义域的画法，三步。**

```text
第一步：找出所有"不能取"的条件（分母为零、根号内为负、对数内非正）
第二步：把这些条件画成平面上的曲线
第三步：判断曲线哪一侧满足要求，涂上阴影
```

**二元函数的图像是曲面。**

```text
        z
        │      ╱
        │    ╱   ← 曲面 z = f(x, y)
        │  ╱
        └────────── y
       ╱
      x
```

定义域是曲面在 xOy 平面上的投影。

曲面上的每一点，对应定义域上的一个点。

**还有一种画法：等值线。**

把 z 固定成常数 c，得到一条曲线 f(x, y) = c。

c 取不同的值，画出一圈一圈的线，像地图上的等高线。

```text
z = x² + y² 的等值线是一圈一圈的同心圆
```

等高线越密，坡度越陡。

这个直觉，下一篇讲梯度时还会用到。

**再练两个定义域，考试常考。**

```text
（1）z = √(x - y) + ln(x + y)
（2）z = 1/√(4 - x² - y²)
```

第一个：根号要求 x - y ≥ 0，对数要求 x + y > 0。

```text
y ≤ x  且  y > -x
```

画出来是一个由两条直线夹出的角形区域。

边界 y = x 可以取，因为根号允许 0；边界 y = -x 不能取，因为对数不允许 0。

第一个是"半开半闭"的区域，不是开区域，也不是闭区域。

第二个：根号在分母上，要求 4 - x² - y² > 0。

```text
x² + y² < 4
```

开圆盘，边界整个不要。

**为什么要区分开区域和闭区域？**

因为有界闭区域上的连续函数一定有最大值和最小值。

开区域没有这个保证。

下一篇求最值时，如果区域是开的，就要额外检查边界附近的行为。

**一个检查习惯。**

写完定义域，随手代一个点进去验。

比如 (1) 代 (2, 1)：x - y = 1 > 0，x + y = 3 > 0，可以。

代 (1, 2)：x - y = -1，根号不行，排除。

代 (-1, 3)：x + y = 2 > 0 但 x - y = -4，排除。

一个点就能验出方向对不对。

## 3. 拆开看：二重极限与连续

没有这一节，"偏导数存在"和"函数连续"的关系会彻底搞混。

先把极限写出来。

```text
lim_{(x,y)→(x₀,y₀)} f(x, y) = A
```

读作："当点 (x, y) 趋于点 (x₀, y₀) 时，f 的极限是 A"。

严格定义要用距离：

设 P = (x, y)，P₀ = (x₀, y₀)，两点距离是

```text
|PP₀| = √((x-x₀)² + (y-y₀)²)
```

定义是：

```text
任给 ε > 0，存在 δ > 0，
只要 0 < |PP₀| < δ，就有 |f(x,y) - A| < ε。
```

**算什么**：不管点从哪个方向靠近 P₀，f 的值都要挤进 A 附近一个很小的范围。

**逐符号**：ε 读"艾普西龙"，是误差上限；δ 读"德尔塔"，是距离上限；|PP₀| 是两点间距离。

**代数字**：f = x² + y²，P₀ = (0,0)，猜 A = 0，取 δ = √ε 即可验证。

**适用条件**：P₀ 必须是定义域的聚点，函数在 P₀ 的某个去心邻域内有定义。

**和一元最大的不同：路径。**

一元只有左右两条路。

二元有无数条路，这就要求"所有路都通向同一个 A"。

反过来用：**只要找到两条路给出不同的值，极限就不存在。**

**经典反例。**

```text
f(x, y) = xy/(x² + y²)，考察 (x,y) → (0,0)
```

沿 x 轴走，即 y = 0：

```text
f(x, 0) = 0/x² = 0  →  0
```

沿 y 轴走，即 x = 0：

```text
f(0, y) = 0/y² = 0  →  0
```

两条轴都给出 0，看起来极限是 0。

再沿直线 y = kx 走：

```text
f(x, kx) = kx²/(x² + k²x²) = k/(1 + k²)
```

这个值和 x 无关，只和斜率 k 有关。

k = 1 时是 1/2，k = 2 时是 2/5，k = 0 时是 0。

**不同的路给出不同的值，所以极限不存在。**

**为什么沿两条轴都等于 0，还不能下结论？**

因为极限要求"所有路径"，而两条轴只是无数条中的两条。

考试里如果只验证了 x 轴和 y 轴就写"极限为 0"，属于逻辑不完整。

正确做法是：要证不存在，找两条路；要证存在，得用定义或夹逼，不能靠列举。

**连续的定义。**

```text
lim_{(x,y)→(x₀,y₀)} f(x, y) = f(x₀, y₀)
```

三个条件缺一不可：函数在 P₀ 有定义、极限存在、两者相等。

**有界闭区域上的连续函数，有最值。**

这条定理和一元一样，但要求"有界"加"闭"。

```text
内部开着的区域，可能取不到最大最小值。
```

下一篇求极值时，条件极值的存在性就靠这条定理。

**怎么证极限存在：夹逼。**

```text
lim_{(x,y)→(0,0)} x²y/(x² + y²)
```

放缩：

```text
|x²y/(x²+y²)| = |y| · x²/(x²+y²) ≤ |y| · 1 = |y|
```

因为 x²/(x²+y²) ≤ 1 恒成立。

而 |y| → 0，所以整个式子趋于 0。

**夹逼的关键：把式子拆成"有界部分 × 趋于 0 的部分"。**

常见的有界部分：

```text
x²/(x²+y²) ≤ 1
|xy|/(x²+y²) ≤ 1/2   （由 2|xy| ≤ x²+y²）
sin(1/(x²+y²)) 有界于 [-1, 1]
```

**极坐标能帮什么忙？**

令 x = r cosθ，y = r sinθ，让 r → 0⁺。

如果化简后极限和 θ 有关，就说明极限不存在。

比如 xy/(x²+y²) = cosθ sinθ，θ 一变值就变，直接判不存在。

但如果化简后和 θ 无关，也不能立刻说存在。

因为 θ 可以随 r 一起变，逼近路径可能是一条螺旋线。

严格证明仍然要靠夹逼或 ε-δ。

**连续函数的运算，和一元一样。**

两个连续函数的和、差、积、商（分母不为零）仍连续。

连续函数的复合仍连续。

所以判断连续时，先看是不是初等函数，再看定义域。

初等函数在定义域内处处连续，这句话在多元也成立。

例外只在分段函数的分界线上，那里必须用定义验。

**一个常考的陷阱：先代 y = kx 再令 k 变。**

这样做能证明不存在，不能证明存在。

答题时写清楚："沿不同直线得到不同值，故极限不存在。"

## 4. 偏导数：把另一个变量按住

没有这一节，"多元的变化率"就无从定义。

先把符号读出来。

```text
∂z/∂x
```

**∂**：读"偏"，也叫"圆 d"，是偏导数的专用符号。

它长得像 d，但不是 d。

**∂z/∂x**：读"z 对 x 的偏导数"，或"偏 z 偏 x"。

它和 dz/dx 的区别在于：d 是一元导数，∂ 是"只让 x 变、别的都不动"。

定义写出来：

```text
∂z/∂x = lim_{Δx→0} [f(x₀+Δx, y₀) - f(x₀, y₀)] / Δx
```

**算什么**：把 y 钉死在 y₀，只看 x 变化时函数值的变化率。

**逐符号**：Δx 读"德尔塔 x"，是 x 的增量；分子是函数值的改变量；分母是自变量的改变量。

**代数字**：f = x²y，在 (1, 2) 处，把 y = 2 钉住，f = 2x²，导数是 4x，在 x = 1 处得 4。

**适用条件**：那个一元极限存在。

**几何意义。**

用平面 y = y₀ 去切曲面，切出一条曲线。

这条曲线在点 P₀ 处的切线斜率，就是 ∂z/∂x 在 P₀ 的值。

```text
        z
        │   ╱ 切线
        │ ╱╱
        │╱    ← 曲面被 y = y₀ 切出的曲线
        └──────── x
```

同理，∂z/∂y 是用平面 x = x₀ 去切。

**求法只有一句话：对一个变量求导时，把另一个当常数。**

这句话说起来简单，做起来有三个细节。

```text
第一，常数求导是 0，不是 1
第二，含另一个变量的因子要整个当常数提出来
第三，链式法则照用，只是内层也当常数处理
```

**例题：偏导也可能不存在。**

```text
z = √(x² + y²)，在 (0, 0) 处
```

按定义：

```text
∂z/∂x|_(0,0) = lim_{Δx→0} [√(Δx²) - 0]/Δx = lim |Δx|/Δx
```

Δx → 0⁺ 时比值是 1，Δx → 0⁻ 时比值是 -1。

左右极限不等，所以偏导不存在。

几何上，这是圆锥的顶点。

沿 x 方向切一刀，截线是一个尖角，尖角处没有切线。

**偏导数本身也是函数。**

求完之后，∂z/∂x 仍然是 x、y 的表达式，每给一个点就有一个值。

所以它能继续求偏导，这就是第 6 节的高阶偏导。

**一个易混点：偏导存在只说明"两条切片光滑"。**

沿 x 方向切、沿 y 方向切，两条截线都可能有切线。

但斜着切一刀，截线可能还是尖的。

这就是为什么偏导存在推不出连续，更推不出可微。

## 5. 算一遍：一道题求两个偏导

没有这道手算，上面三句话还是口号。

题目：

```text
z = x²y + sin(xy)，求 ∂z/∂x 与 ∂z/∂y
```

**先求 ∂z/∂x，把 y 当常数。**

第一项 x²y：y 是常数，x² 求导得 2x，所以这一项是 2xy。

第二项 sin(xy)：外层是 sin，内层是 xy。

内层对 x 求导，y 当常数，得 y。

所以这一项是 cos(xy) · y。

合起来：

```text
∂z/∂x = 2xy + y cos(xy)
```

**再求 ∂z/∂y，把 x 当常数。**

第一项 x²y：x² 是常数，y 求导得 1，所以是 x²。

第二项 sin(xy)：内层 xy 对 y 求导，得 x。

所以是 cos(xy) · x。

合起来：

```text
∂z/∂y = x² + x cos(xy)
```

**代一组数验证。**

取 (x, y) = (1, π/2)。

```text
∂z/∂x = 2·1·(π/2) + (π/2)·cos(π/2) = π + 0 = π
∂z/∂y = 1 + 1·cos(π/2) = 1 + 0 = 1
```

cos(π/2) = 0 这一步让第二项整体消失。

**再看一个"指数在变量上"的。**

```text
z = x^y，x > 0
```

对 x 求偏导，y 是常数，按幂函数求导：

```text
∂z/∂x = y x^(y-1)
```

对 y 求偏导，x 是常数，按指数函数求导：

```text
∂z/∂y = x^y ln x
```

**同一个函数，两边用的公式不一样。**

原因就是"谁是变量、谁是常数"。

这也是偏导数最容易出错的地方：先分清角色，再套公式。

**一个判断口诀。**

```text
求 ∂z/∂x 时，把 y 想成一个具体的数，比如 y = 7。
```

一旦把它想成 7，就不会去对它求导，也不会把含 y 的因子拆开。

对 ∂z/∂y 同理，把 x 想成 3。

这个心理动作，比背规则管用。

**三元函数同理。**

```text
u = xyz + x²
```

```text
∂u/∂x = yz + 2x
∂u/∂y = xz
∂u/∂z = xy
```

每求一个，另外两个全当常数。

**再来一道带分式的，练"常数意识"。**

```text
z = x/y，y ≠ 0
```

对 x 求偏导：y 是常数，x/y 对 x 求导，就是 1/y。

```text
∂z/∂x = 1/y
```

对 y 求偏导：x 是常数，x/y = x·y⁻¹，对 y 求导得 -x y⁻²。

```text
∂z/∂y = -x/y²
```

在 (2, 1) 处：

```text
∂z/∂x = 1/1 = 1
∂z/∂y = -2/1 = -2
```

**验算：用数字代替符号。**

在 (2, 1) 附近取 (2.01, 1)，函数值是 2.01。

原来 2，增加 0.01，所以变化率约 1，与 ∂z/∂x = 1 吻合。

再取 (2, 1.01)，函数值是 2/1.01 ≈ 1.9802，减少约 0.0198，变化率约 -1.98，与 -2 吻合。

**这个"取点验算"的方法，考场上用来检查很快。**

偏导的正负、量级，都能在十秒内估出来。

## 6. 拆开看：高阶偏导与混合偏导

没有这一节，遇到 z_xy 这种记号会不知道从哪下手。

偏导数还是函数，还能再求偏导。

```text
∂/∂x (∂z/∂x) = ∂²z/∂x²，记作 z_xx
∂/∂y (∂z/∂x) = ∂²z/∂x∂y，记作 z_xy
∂/∂x (∂z/∂y) = ∂²z/∂y∂x，记作 z_yx
∂/∂y (∂z/∂y) = ∂²z/∂y²，记作 z_yy
```

**记号读法很重要。**

```text
z_xy 是先对 x 求，再对 y 求。
```

顺序是从左到右，不是从右到左。

这一点各教材略有差异，做题时看题目用的记号，按"先近后远"理解。

**手算一组。**

```text
z = x³y² - 3xy
```

一阶：

```text
z_x = 3x²y² - 3y
z_y = 2x³y - 3x
```

二阶：

```text
z_xx = 6xy²
z_xy = 6x²y - 3
z_yx = 6x²y - 3
z_yy = 2x³
```

**z_xy 和 z_yx 相等。**

这不是巧合。

**定理：如果两个混合偏导数在一点附近连续，那么它们相等。**

数一考的就是这个条件。

如果题目给了一个分段函数，在原点用定义算 z_xy 和 z_yx 可能不相等。

原因就是二阶偏导在原点不连续。

**计算顺序可以换，但要先确认条件。**

考试里绝大多数函数都满足连续条件，所以直接算就行。

只有遇到分段函数、绝对值、根号在原点这类"可疑点"，才需要特别小心。

**反例长什么样，知道一下不吃亏。**

```text
f(x,y) = xy(x² - y²)/(x² + y²)，(x,y) ≠ (0,0)；f(0,0) = 0
```

用定义算，在原点：

```text
f_xy(0,0) = -1，f_yx(0,0) = 1
```

两个混合偏导不相等。

原因是在原点附近，二阶偏导不连续。

**这个反例说明：定理里的"连续"不是废话。**

教材写"若二阶混合偏导连续，则相等"，这个条件必须写上。

数一考概念判断时，会把条件的顺序颠倒来设选项。

## 7. 拆开看：复合函数求导

没有这一节，z = f(u, v) 而 u、v 又是 x、y 的函数时，你会漏项。

先画一张树图。

```text
        z
       ╱ ╲
      u   v
      │   │
      x   x
      y   y
```

从 z 到 x 有几条路？

两条：z → u → x，z → v → x。

**每条路乘起来，所有路加起来。**

```text
∂z/∂x = (∂z/∂u)(∂u/∂x) + (∂z/∂v)(∂v/∂x)
```

这就是多元的链式法则。

**例一。**

```text
z = u²v，u = x + y，v = xy
```

先算四个偏导：

```text
z_u = 2uv，z_v = u²
u_x = 1，u_y = 1
v_x = y，v_y = x
```

代入：

```text
∂z/∂x = 2uv·1 + u²·y = 2(x+y)(xy) + (x+y)²y
∂z/∂y = 2uv·1 + u²·x = 2(x+y)(xy) + (x+y)²x
```

整理第一个：

```text
∂z/∂x = y(x+y)(3x+y)
```

整理第二个：

```text
∂z/∂y = x(x+y)(x+3y)
```

**验算的办法：先代后求。**

把 u、v 代回 z：

```text
z = (x+y)²·xy
```

直接对 x 求偏导，结果应该一样。

两条路都走一遍，能抓出大部分漏项错误。

**例二，只有一条中间变量。**

```text
z = f(x, y)，而 y = y(x)
```

这时 z 最终只是 x 的函数，全导数写成：

```text
dz/dx = ∂z/∂x + (∂z/∂y)·(dy/dx)
```

注意第一项是偏导，不是全导。

这里的 d 和 ∂ 混用，是最容易写错的地方。

**记忆方法：树图上有几条路，就有几项。**

少画一条边，就少一项。

**例三，带具体函数的全导数。**

```text
z = x² + y²，y = sin x，求 dz/dx
```

套公式：

```text
dz/dx = ∂z/∂x + (∂z/∂y)(dy/dx) = 2x + 2y cos x = 2x + 2 sin x cos x
```

代 x = 0，得 0；代 x = π/2，得 π。

**验算：直接代。**

```text
z = x² + sin²x  ⇒  dz/dx = 2x + 2 sin x cos x
```

两条路结果一样。

**例四，一层套两层。**

```text
z = f(u)，u = u(x, y)
```

```text
∂z/∂x = f'(u)·u_x
∂z/∂y = f'(u)·u_y
```

这里 f' 是一元导数，不是偏导。

因为 f 只有一个自变量，用 d 或 ' 都行。

**判断用 d 还是 ∂，只看"这个函数有几个自变量"。**

一个自变量，用 d；多个，用 ∂。

名字跟着函数的身份走，不跟着符号的位置走。

## 8. 拆开看：隐函数求导

没有这一节，方程 x² + y² + z² = 4z 摆在你面前，你连"z 是 x 的函数"这句话都读不出来。

隐函数的意思是：函数关系没有写成 z = f(x, y)，而是藏在一个方程里。

```text
F(x, y, z) = 0
```

在满足一定条件的点附近，这个方程能确定一个 z = z(x, y)。

**公式。**

```text
∂z/∂x = -F_x/F_z
∂z/∂y = -F_y/F_z
```

**这个负号从哪来？**

方程两边对 x 求偏导，y 当常数，z 是 x 的函数。

用链式法则：

```text
F_x + F_z·(∂z/∂x) = 0
```

移项就得到 ∂z/∂x = -F_x/F_z。

负号是移项移出来的，不是背出来的。

**适用条件：F_z ≠ 0。**

分母为零，公式失效，那一点可能对应多条曲线，或者根本没有隐函数。

**几何上看：F_z = 0 意味着什么。**

曲面 F(x, y, z) = 0 在一点的法向量是

```text
(F_x, F_y, F_z)
```

F_z = 0 时法向量与 z 轴垂直，切平面竖直。

竖直的切平面没法写成 z = z(x, y) 的形式。

所以公式失效不是计算问题，是几何上真的解不出来。

**手算一道。**

```text
x² + y² + z² = 4z，求 ∂z/∂x 与 ∂z/∂y
```

先移项，造出 F：

```text
F(x, y, z) = x² + y² + z² - 4z
```

求三个偏导：

```text
F_x = 2x
F_y = 2y
F_z = 2z - 4
```

代入公式：

```text
∂z/∂x = -2x/(2z - 4) = x/(2 - z)
∂z/∂y = -2y/(2z - 4) = y/(2 - z)
```

**验算一遍。**

把方程看成"z 对 x 求导"：

```text
2x + 2z·z_x = 4 z_x
```

移项：

```text
2x = (4 - 2z) z_x  ⇒  z_x = 2x/(4 - 2z) = x/(2 - z)
```

和公式法一致。

注意 z = 2 时，F_z = 0，公式失效，这一点要单独讨论。

**一元的隐函数是同一个套路。**

```text
F(x, y) = 0  ⇒  dy/dx = -F_x/F_y
```

比如 x² + y² = 1：

```text
dy/dx = -2x/2y = -x/y
```

和直接解出 y = ±√(1-x²) 再求导，结果一样。

**什么时候用公式，什么时候直接求？**

方程简单、能解出显式，就直接求。

解不出来，或者解出来很丑，就用公式。

考试里两种都可以，结果必须一致。

**进阶：隐函数的二阶偏导。**

还是 x² + y² + z² = 4z，已经得到

```text
z_x = x/(2-z)
```

再对 x 求一次偏导，注意 z 仍然是 x 的函数。

用商法则：

```text
z_xx = [1·(2-z) - x·(-z_x)]/(2-z)²
```

代 z_x = x/(2-z)：

```text
z_xx = [(2-z) + x²/(2-z)]/(2-z)² = 1/(2-z) + x²/(2-z)³
```

通分：

```text
z_xx = [(2-z)² + x²]/(2-z)³
```

**这里最容易错的一步：第二次求导时，z 不是常数。**

把 z_x 当成一个普通的 x 的函数去求导，遇到 z 就再乘一个 z_x。

漏掉这一层，答案会少一项。

## 9. 常见错误

没有这一节，你会做的题也会被扣分。

**错误一：求偏导时忘了另一个变量是常数。**

```text
错：∂/∂x (x²y) = 2x·y + x²·1
```

第二项 x²·1 是把 y 当成变量了。

正确是 2xy。

**错误二：混合偏导的顺序搞反。**

记号 z_xy 是先对 x 求，再对 y 求。

如果题目明确写了 ∂²z/∂x∂y，要看清楚分母里谁在前。

顺序反了，在混合偏导相等时不影响答案，但在不相等时会直接错。

**错误三：复合函数漏项。**

```text
z = f(u, v)，u = x + y，v = xy
```

求 ∂z/∂x 只写 f_u·u_x，漏掉 f_v·v_x。

树图上 z 到 x 有两条路，就必须有两项。

**错误四：隐函数求导丢负号。**

```text
错：z_x = F_x/F_z
对：z_x = -F_x/F_z
```

负号丢一次，整道题作废。

**错误五：以为偏导存在就能推出连续。**

这是一个流传很广的错误。

反例：

```text
f(x, y) = xy/(x² + y²)，(x,y) ≠ (0,0)；f(0,0) = 0
```

在原点，f(x, 0) = 0 恒成立，所以

```text
f_x(0,0) = lim_{Δx→0} (0 - 0)/Δx = 0
```

同理 f_y(0,0) = 0。

两个偏导都存在。

但前面已经算过，这个函数在原点不连续。

**所以：偏导存在 ≠ 连续 ≠ 可微。**

三者的关系是：

```text
可微 ⇒ 连续 ⇒ 极限存在
可微 ⇒ 偏导存在
偏导存在 ⇏ 连续
偏导连续 ⇒ 可微
```

**错误六：判断极限不存在时，只算了一条路径。**

一条路径给出值，不能证明极限存在；两条路径给出不同值，才能证明不存在。

方向别搞反。

**错误七：分段函数在分界点不用定义，直接套求导公式。**

分界点的偏导，必须回到定义：

```text
f_x(x₀,y₀) = lim_{Δx→0} [f(x₀+Δx, y₀) - f(x₀, y₀)]/Δx
```

直接对表达式求导再代点，经常算出不存在的东西。

**错误八：求二阶偏导时，把一阶结果里的变量当常数。**

比如 z_x = x/(2-z)，再对 x 求导时，z 还要再导一次。

把 z 当常数，会得到 1/(2-z)，少了后面那一项。

**错误九：把"在一点的值"和"偏导函数"混着写。**

∂z/∂x 是一个函数，∂z/∂x 在 (1, 2) 处的值是一个数。

答题时先写函数，再代点，顺序别乱。

如果题目只要值，直接代点能省很多代数运算，但前提是偏导函数本身要写对。

## 10. 数一怎么考

没有这一节，练不到点子上。

数一在这一章有四种出题方式。

**第一种，直接求偏导。**

```text
设 z = arctan(y/x)，求 ∂z/∂x。
```

把 y 当常数：

```text
∂z/∂x = 1/(1 + (y/x)²) · (-y/x²) = -y/(x² + y²)
```

填空题，4 分，三十秒。

**第二种，复合函数求导。**

```text
设 z = f(x²y, x + y)，f 可微，求 ∂z/∂x。
```

设 u = x²y，v = x + y：

```text
∂z/∂x = f_u·(2xy) + f_v·1
```

答案里保留 f_u、f_v 这两个记号，不用求出具体形式。

这类题考的是"结构"，不是"算数"。

**第三种，隐函数求导。**

就是第 8 节那道题的变体。

经常要求"在点 (1, 1, 1) 处的偏导值"。

先代点，再算，数字会简单很多。

**第四种，概念判断。**

```text
下列命题正确的是：
A. 偏导存在则连续
B. 连续则偏导存在
C. 可微则偏导存在
D. 偏导存在则可微
```

答案是 C。

这张关系图必须背下来：

```text
偏导连续 ⇒ 可微 ⇒ 连续
可微 ⇒ 偏导存在
```

反过来一个都不成立。

**分值与时间。**

```text
选择或填空：1 到 2 道，4 到 8 分
解答题：常与全微分、极值合并，10 分
单独出大题：少见
```

这一章是"工具章"，单独考得少，但后面每一章都要用。

**一个时间建议。**

一张卷子里，多元偏导的题通常排在前半段。

遇到复合求导，先花十秒画树，再动笔，总时间反而更短。

不画树直接写，漏项之后再回头检查，至少多花两分钟。

**答题模板。**

求偏导：

```text
第一步：写清对谁求偏导，其余变量当常数
第二步：套一元公式，内层用链式
第三步：化简，必要时代点
```

复合求导：

```text
第一步：设中间变量 u、v，写出 z = f(u, v)
第二步：画树图，数路径
第三步：每条路相乘，所有路相加
```

隐函数：

```text
第一步：移项成 F(x, y, z) = 0
第二步：算 F_x、F_y、F_z
第三步：代公式，检查 F_z ≠ 0
```

**一个提分细节。**

复合求导的答案里，f_u、f_v 的顺序要和题目给的 f 的自变量顺序一致。

题目写 f(x²y, x+y)，第一个位置是 u，第二个是 v。

答案写反了，即使数值对，也会被扣分。

**一道综合小测。**

```text
设 z = f(x + y, xy)，f 可微，求 ∂z/∂x。
```

设 u = x + y，v = xy。

```text
∂z/∂x = f_u·1 + f_v·y
```

再求 ∂z/∂y：

```text
∂z/∂y = f_u·1 + f_v·x
```

两个答案的形式对称，这是这类题的一个信号：结构对，通常八九不离十。

**一道接近真题的解答题。**

```text
设 z = z(x, y) 由 x² + y² + z² = 4 确定，
求在点 (1, 1, √2) 处的两个偏导。
```

第一步，造 F：

```text
F = x² + y² + z² - 4
F_x = 2x，F_y = 2y，F_z = 2z
```

第二步，代公式：

```text
z_x = -x/z，z_y = -y/z
```

第三步，代点：

```text
z_x = -1/√2 = -√2/2
z_y = -1/√2 = -√2/2
```

**几何解读。**

球面在第一卦限的那一片，x 增大时 z 减小，y 增大时 z 也减小。

两个偏导都是负的，符合直觉。

如果算出正的，先检查是不是漏了负号。

## 11. 和其他章节怎么连

没有这一节，多元微积分会散成一堆互不相干的公式。

**往回连：03 导数与微分。**

偏导数就是把一元导数用两次：一次固定 y，一次固定 x。

一元的所有求导公式，在这里原样可用。

**往前连：11 全微分与多元极值。**

全微分 dz = z_x dx + z_y dy，两个系数就是这一篇算的偏导。

极值的必要条件 z_x = 0、z_y = 0，也是偏导。

条件极值的拉格朗日乘数法，要对每个变量求偏导。

**往前连：12 二重积分。**

二重积分的被积函数是二元函数。

积分区域要用不等式描述，正是这一篇说的定义域。

**横向连：05 导数的应用。**

一元极值看 f' 的符号，多元极值看两个偏导同时为零。

思想一样：找"变化率为零"的点。

**一个整体视角。**

一元到多元，变的不是方法，是"维度"。

```text
一元：一个方向，一个导数
多元：多个方向，先固定其余，再逐个求
```

把"固定其余"这四个字记住，偏导、偏导的偏导、隐函数、复合函数，全是它的推论。

**横向连：21 向量代数与空间解析几何。**

曲面 F(x, y, z) = 0 的法向量是 (F_x, F_y, F_z)。

切平面方程是

```text
F_x(P)(x - x₀) + F_y(P)(y - y₀) + F_z(P)(z - z₀) = 0
```

这个公式里三个系数，全是这一篇算的偏导。

下一篇的全微分 dz = z_x dx + z_y dy，本质上是切平面的另一种写法。

**横向连：13 三重积分与 15 曲面积分。**

三重积分的被积函数是三元函数，曲面积分要用到曲面方程的两个偏导。

这一篇的三个变量求偏导、隐函数求偏导，都会在那一章反复出现。

**一条学习建议。**

这一章不要试图背结论。

把"按住其余变量"这句话当操作指令，遇到一个函数就照着做。

做得多了，偏导会变成一种条件反射。

### 自检三问

**第一问：∂ 和 d 到底差在哪？**

d 用于一元，表示"唯一的那个变化率"。

∂ 用于多元，表示"只让一个变量变、其余按住"的变化率。

同一个 z，∂z/∂x 和 ∂z/∂y 通常是两个不同的数，而 dz/dx 只有一个。

到了下一篇，dz 又会出现，那是全微分，表示"所有变量一起变"的总效果。

三个记号：d 是一元，∂ 是偏，d（在 dz 里）是全。

**第二问：为什么偏导数都存在，函数还可能不连续？**

因为偏导只检查了两条特殊路径：沿 x 轴、沿 y 轴。

函数完全可以在两条轴上都很乖，而在斜方向上剧烈跳动。

反例 f = xy/(x²+y²) 就是这样：两条轴上恒为 0，沿 y = x 却趋于 1/2。

连续要求所有路径都收敛到同一个值，偏导只保证了两条。

**第三问：复合函数求导，怎么保证不漏项？**

画树图。

把因变量画在顶上，中间变量画在中间，自变量画在底下。

从顶到底有几条路，公式就有几项；每条路上的偏导相乘。

画完图再写公式，比死记公式可靠得多。

## 12. 小结

没有小结，这一章会剩下"会算但说不清"的状态。

压成一张卡片：

```text
二元函数：z = f(x, y)，定义域是平面区域，图像是曲面
二重极限：所有路径都趋于同一个值才算存在
连续：极限值等于函数值
偏导：∂z/∂x，按住 y，只让 x 变
高阶：z_xx、z_xy、z_yx、z_yy，混合偏导连续则相等
复合：树图几条路，就有几项
隐函数：F(x,y,z)=0，z_x = -F_x/F_z（F_z ≠ 0）
```

**两个必须能画的图。**

图一，曲面加两条截线：

```text
        z
        │    ╱╱
        │  ╱╱   ← 曲面
        │╱╱
        └────── y
       ╱
      x
```

用 y = y₀ 切一刀，得到 ∂z/∂x；用 x = x₀ 切一刀，得到 ∂z/∂y。

图二，复合函数的树图：

```text
      z
     ╱ ╲
    u   v
     ╲ ╱
      x
```

几条路，几项相加。

这两张图画得出来，这一章就通了。

**三个符号，一张对照表。**

```text
dy/dx   一元导数，只有一个方向
∂z/∂x   偏导数，只让 x 动，y 按住
dz      全微分，x 和 y 一起动
```

前两个是这一篇的，第三个是下一篇的。

**三个核心动作。**

```text
求偏导：按住其余，套一元公式
复合：画树图，路径相乘再相加
隐函数：造 F，代 -F_x/F_z
```

考试时先认动作，再动笔，比直接算快。

**一个最常见的疑问：偏导存在，曲面是不是就光滑？**

不一定。

锥面 z = √(x²+y²) 在顶点，两个偏导都不存在，曲面在那里是尖的。

但也可以构造出偏导存在、曲面仍然不光滑的例子。

判断光滑要用"可微"，标准在下一篇给。

所以偏导只是必要工具，不是完整答案。

四步公式的统一形态：

```text
算什么 → 某一个方向上的变化率
逐符号 → ∂ 表示按住其余变量，d 表示一元
代数字 → 把另一个变量当常数，套一元公式
适用条件 → 该点偏导存在；隐函数还要 F_z ≠ 0
```

三句提醒。

```text
第一句：先分清谁是变量、谁是常数，再动笔。
第二句：偏导存在推不出连续，别把结论用反。
第三句：复合求导先画树，隐函数先造 F。
```

最后补一句：偏导是"按住其余、只看一个方向"，全微分是"所有方向一起看"。

两者不是一回事，下一篇开头会把这个区别讲透。

把这两个概念分清，多元微积分的第一道坎就算过去了。

剩下的路，是把它用在曲面、极值和积分上。
