> **读这篇之前，你只需要知道**：导数是"变化率"，y' 表示 y 随 x 变多快；积分是求导的反向操作，知道变化率就能反推出原来的量，但反推出来的结果带一个任意常数，因为"变化率"不记录起点在哪。
> **这篇讲什么**：方程里一旦出现导数，就变成了微分方程；它问的不是"x 等于几"，而是"哪个函数 y 能让这个含导数的等式成立"，这一篇教你把四种常见的一阶方程认出来、然后按固定套路解掉。
> **一个类比**：开车只知道速度表（变化率），想还原出走过的路程（原函数）。速度表告诉你每秒跑多快，但没告诉你从哪儿出发，所以还原出来的路线会整体平移，那个平移量就是常数 C。

先看一个现实问题。

一个培养皿里有 100 个细菌。

它们每小时繁殖，速度正比于当前的数量。

问：10 小时后有多少个？

这句话里有两层信息。

第一层是"速度正比于当前的数量"：

```text
每小时增加的个数 = k × 当前个数
```

k 是一个常数，比如 0.3。

第二层是"现在有 100 个"。

用数学写出来：

```text
y' = k y
y(0) = 100
```

第一条是微分方程，第二条是初始条件。

合起来叫初值问题。

**注意这个方程问的是什么。**

它不问"x 等于几"。

它问的是："哪个函数 y(x)，它的导数等于 k 乘它自己？"

答案是：

```text
y = 100 e^{kt}
```

代 k = 0.3，t = 10：

```text
y = 100 e³ ≈ 2008
```

十小时从 100 涨到 2008。

**这就是微分方程干的事：从"变化规律"算出"未来"。**

## 1. 为什么需要它（不给会怎样）

**第一处，物理定律几乎全部写成微分方程。**

```text
牛顿第二定律：m x'' = F
放射性衰变：N' = −λN
牛顿冷却：T' = −k(T − T环境)
RL 电路：L i' + R i = E
单摆：θ'' + (g/L) sin θ = 0
```

这些定律描述的都是"变化率之间的关系"，不是"数值之间的关系"。

不给微分方程，物理定律就没法写成数学。

**第二处，很多"求曲线"的几何问题会落成微分方程。**

"曲线上任一点的切线斜率等于该点横坐标的两倍"。

这句话直接就是：

```text
y' = 2x
```

解出来 y = x² + C。

不给微分方程，这类问题连式子都列不出来。

**第三处，积分只能处理最简单的一类。**

如果方程长这样：

```text
y' = f(x)
```

那好办，两边积分就行。

但现实里的方程经常是：

```text
y' = f(x, y)
```

右边也带 y。

这时候不能直接积分，因为不知道 y 是什么。

**第四处，考试稳定占分。**

数一每年一道微分方程的题，通常 10 分。

一阶的题几乎必出，因为它计算量适中、套路固定、容易拿满分。

**所以这一篇的核心任务只有一个。**

```text
把 y' = f(x, y) 这种方程，按形状分成四类，
每一类配一个固定的解法。
```

四类是：

```text
可分离变量、齐次、一阶线性、伯努利
```

识别对了，解法就是机械动作。

## 2. 最小模型：y' 和 dy/dx 到底是什么

没有这一节，你会把 y' 当成一个普通的字母，也不知道答案要写成一族函数还是一个数。

先把符号读清楚。

**y' 读作"y 一撇"。**

它表示 y 对 x 的导数：

```text
y' = dy/dx
```

**dy/dx 读作"d y 比 d x"。**

d 读"d"，表示"微小的增量"。

整个符号的意思是：

```text
y 的微小增量 ÷ x 的微小增量
```

也就是"x 变一点点，y 跟着变多少"。

**这两个记号的区别只是方便程度。**

```text
y'     写法短，适合写方程
dy/dx  把 dx 和 dy 分开摆，适合移项
```

在解可分离方程时，会把 dy/dx 当成一个分数，把 dx 乘到右边去。

严格说 dy/dx 不是一个分数，是一个整体记号。

但在解可分离方程这一步，这样操作是合法的。

原因写在 03 篇：dy = y' dx 是微分的定义，两边同乘 dx 只是把这个定义倒过来用。

**阶是什么。**

方程里出现的最高阶导数的阶数。

```text
y' = 2x          一阶（只有一阶导数）
y'' + y = 0      二阶（出现了二阶导数）
y''' = 6         三阶
```

一阶方程里只出现 y'、y、x，不出现 y''。

**什么叫"解"。**

一个函数 y = φ(x)，把它和它的导数代进方程，等式成立。

这就叫解。

验证方法只有一条：**代进去算。**

比如 y = x² + C，代入 y' = 2x：

```text
左边 y' = 2x
右边 2x
相等
```

所以它是解。

**通解与特解。**

通解：含任意常数，且常数的个数等于阶数。

```text
y = x² + C
```

这是一个一阶方程的通解，含 1 个常数。

特解：把常数定下来之后的解。

```text
y = x² + 3
```

**为什么通解一定带常数。**

因为求导会把常数消掉。

```text
(x² + 1)' = 2x
(x² + 5)' = 2x
(x² − 100)' = 2x
```

所有 x² + C 的导数都是 2x。

反过来，知道导数是 2x，只能推出"原函数是 x² 加某个常数"，推不出常数是几。

**几何上，这是一族曲线。**

```text
      │      ╱
      │    ╱   C = 3
      │  ╱
──────┼────────  C = 0
    ╱ │
  ╱   │         C = −2
```

它们形状一样，只是上下平移。

每一条都满足 y' = 2x。

要挑出其中一条，必须再给一个条件。

**初值条件就是这个条件。**

```text
y(0) = 5
```

意思是"曲线过点 (0, 5)"。

代进通解：

```text
5 = 0 + C，所以 C = 5
```

特解是 y = x² + 5。

**公式四步，最基础的那个方程。**

```text
算什么：找一个函数 y，使它的导数等于给定的 f(x)
逐符号：y' 是待求函数的导数，f(x) 是已知函数，C 是任意常数
代数字：y' = 2x → y = x² + C；再过 (0,5) → y = x² + 5
适用条件：右边只含 x 时才能直接积分；含 y 就要分类
```

最后那句是分水岭。

**右边只含 x，直接积分；右边含 y，必须分类。**

这就是后面四节要做的事。

**再补一个几何图像：斜率场。**

把 y' = f(x, y) 里的 f(x, y) 看成"每一点该往哪个方向走"。

在平面上每个点画一小段斜率为 f(x, y) 的短线：

```text
      ╱   ╱   ╱   ╱
    ╱   ╱   ╱   ╱
  ─── ─── ─── ───
    ╲   ╲   ╲   ╲
```

这张图叫方向场或斜率场。

微分方程的解，就是一条"顺着这些短线走"的曲线。

通解是一整族这样的曲线，初值条件决定从哪一条开始走。

这个图像解释了三件事：

```text
为什么解是一条曲线，不是一个数
为什么通解是一族曲线
为什么初值条件能挑出唯一一条
```

**一条必须记住的边界：解只在某个区间上成立。**

微分方程的解不一定是"整条实轴上的函数"。

比如 y = 1/x，它在 x = 0 处断开。

所以严格地说，解要连定义区间一起写：

```text
y = 1/x，x > 0
```

考试里如果初值给在 x = 1，答案就限定 x > 0。

不写区间通常不扣分，但写上去更稳。

## 3. 可分离变量：最基础的一类

没有这一节，连最简单的一类方程也解不动，因为不知道把谁挪到哪一边。

**形状。**

```text
dy/dx = f(x) · g(y)
```

右边能拆成"只含 x 的"乘"只含 y 的"。

这个"能拆开"就是"可分离"的意思。

**解法只有三步。**

```text
第一步：把含 y 的挪到左边，含 x 的挪到右边
第二步：两边各自积分
第三步：化简，写出 y 的表达式（或保留隐式）
```

具体操作：

```text
dy / g(y) = f(x) dx
```

两边积分：

```text
∫ dy/g(y) = ∫ f(x) dx + C
```

**四步公式，可分离版本。**

```text
算什么：把所有 y 集中到一边，所有 x 集中到另一边，然后各积各的
逐符号：g(y) 是 y 的因子，f(x) 是 x 的因子，C 是积分常数
代数字：y' = 2xy → dy/y = 2x dx → ln|y| = x² + C → y = Ce^{x²}
适用条件：右边必须能写成 f(x)g(y) 的乘积；除的时候要检查 g(y) = 0
```

**为什么把 dx 乘过去是合法的。**

严格地说，dy/dx 不是分数。

但 03 篇给过微分的定义：

```text
dy = y' dx
```

也就是说，把导数乘上 dx，得到的就是 y 的微分。

所以从 dy/dx = f(x)g(y) 得到 dy = f(x)g(y) dx，只是把微分的定义倒过来用。

再两边除以 g(y)，就完成了"分离"。

这一步在数学上叫"分离变量"，逻辑是站得住的，不是耍花招。

**唯一的代价是：除以 g(y) 时，g(y) 的零点可能被丢掉。**

这就是下一段要说的事。

**那个"检查 g(y) = 0"很重要。**

两边同时除以 g(y) 时，如果 g(y) 有零点，那个零点对应的常数函数也是解。

比如：

```text
y' = y
```

分离得 dy/y = dx，积分得 ln|y| = x + C，即 y = Ce^x。

但 y = 0 也是解，它在除法时被丢掉了。

y = 0 其实包含在 y = Ce^x 里（取 C = 0），所以这里没丢。

但换成 y' = y²，情况就不同了。

分离得 dy/y² = dx，积分得 −1/y = x + C，即 y = −1/(x+C)。

y = 0 是解，但它不在这个式子里（无论 C 取什么，右边都不为 0）。

这种被丢掉的解叫"奇解"。

数一的选择题会考这一点。

**一个判断技巧。**

除之前先问：g(y) = 0 有没有解？

如果有，这些解要单独写出来，再和通解合并。

## 4. 手算：可分离两例

**例 1：解 y' = 2xy，且 y(0) = 1。**

第一步，分离。

右边 2xy 已经是 (2x)·(y) 的形式，可以拆。

```text
dy/dx = 2x · y
dy/y = 2x dx
```

第二步，两边积分。

```text
∫ dy/y = ∫ 2x dx
ln|y| = x² + C
```

第三步，解出 y。

两边取指数：

```text
|y| = e^{x² + C} = e^C · e^{x²}
y = ±e^C · e^{x²}
```

把 ±e^C 合并成一个新的常数 C₁（它可以是任何非零实数）：

```text
y = C₁ e^{x²}
```

再加上 y = 0 这个解（对应 C₁ = 0）：

```text
y = C e^{x²}，  C 为任意常数
```

第四步，代初值。

```text
y(0) = C e⁰ = C = 1
```

所以 C = 1。

**答案：y = e^{x²}。**

第五步，验算。

```text
y' = 2x e^{x²}
2xy = 2x · e^{x²}
```

相等。

**这道题的形状值得记住。**

```text
y' = k y  →  y = C e^{kx}
```

这是所有"变化率正比于自身"的模型的标准答案。

细菌繁殖、放射性衰变、复利、RL 电路的暂态，全是这个形状。

**例 2：解 dy/dx = (1 + y²)/(1 + x²)，且 y(0) = 1。**

第一步，分离。

右边已经是两个因子的商，可以拆。

```text
dy / (1 + y²) = dx / (1 + x²)
```

第二步，两边积分。

左边是 arctan：

```text
∫ dy/(1+y²) = arctan y
```

右边同理：

```text
∫ dx/(1+x²) = arctan x
```

所以：

```text
arctan y = arctan x + C
```

第三步，代初值定 C。

```text
x = 0, y = 1
arctan 1 = arctan 0 + C
π/4 = 0 + C
C = π/4
```

所以：

```text
arctan y = arctan x + π/4
```

第四步，化成显式。

两边取 tan，用和角公式：

```text
y = tan(arctan x + π/4)
```

设 A = arctan x，则 tan A = x；B = π/4，tan B = 1。

```text
tan(A + B) = (tan A + tan B) / (1 − tan A tan B)
           = (x + 1) / (1 − x)
```

**答案：y = (1 + x)/(1 − x)，定义在 x < 1 上。**

第五步，验算 x = 0。

```text
y(0) = 1/1 = 1
```

对上。

**这道题提醒一件事。**

解出来的经常是隐式：

```text
arctan y = arctan x + C
```

题目如果没要求显式，隐式也算对。

要求显式时，才需要化成 y = …

**两道题的方法对照。**

```text
例 1：右边是乘积，直接分；积分出 ln，要取指数
例 2：右边是商，交叉相乘分；积分出 arctan，要取 tan
```

共同点：

```text
分离 → 积分 → 化简 → 代初值
```

四步，一步不能少。

**第三道练习，只写关键步骤。**

```text
y' = x y²
```

分离：

```text
dy/y² = x dx
```

积分：

```text
−1/y = x²/2 + C
```

解出：

```text
y = −1/(x²/2 + C) = −2/(x² + 2C)
```

加上被丢掉的解 y = 0。

**这里 y = 0 是奇解。**

它不在通解里，因为通解的分子是 −2，永远不为 0。

所以完整答案要写成两行：

```text
y = −2/(x² + C₁)，以及 y = 0
```

考场上如果只写通解，这题会扣分。

**一个口诀。**

```text
除法分离前，先看分母零；
零若是解，单独写一行。
```

## 5. 齐次方程：把 y/x 看成一个整体

没有这一节，遇到"右边只有 y/x 的组合"这种方程，只能干看着。

**形状。**

```text
dy/dx = φ(y/x)
```

右边不能拆成 f(x)g(y)，但它只依赖一个整体：y/x。

**为什么这类方程值得单独一类。**

因为 y/x 有一个几何含义：从原点到点 (x, y) 的连线的斜率。

凡是右边只和这个斜率有关的方程，解出来的曲线族都有一个共同性质：

```text
把图形按同一比例放大缩小，形状不变。
```

这类曲线叫"自相似"。

**解法：换元。**

令：

```text
u = y/x，  即 y = u x
```

u 是一个新的未知函数，也是 x 的函数。

对 y = ux 求导，用乘积法则：

```text
y' = u + x u'
```

这里 u' 表示 du/dx。

把 y' 和 y/x 都换成 u：

```text
u + x u' = φ(u)
```

移项：

```text
x u' = φ(u) − u
```

**现在它变成可分离的了。**

```text
du / (φ(u) − u) = dx / x
```

两边积分，解出 u，再把 u 换回 y/x。

**四步公式，齐次版本。**

```text
算什么：把"依赖 y/x"的方程，通过换元变成"可分离"的方程
逐符号：u = y/x 是新函数，y = ux，y' = u + xu'
代数字：y' = (x²+y²)/(xy) → u + xu' = 1/u + u → xu' = 1/u
适用条件：右边必须能写成只含 y/x 的式子；换元后要记得换回来
```

**怎么判断"只含 y/x"。**

看分子分母的次数是否相同。

```text
(x² + y²)/(xy)    分子二次，分母二次 → 是齐次
(x + y)/(x − y)   分子一次，分母一次 → 是齐次
(x² + 1)/(xy)     分子二次，分母二次，但常数项破坏齐次 → 不是
```

判据：把 x 换成 tx、y 换成 ty，如果整个式子乘以 t 的某次幂后不变，就是齐次。

**一个常见变体。**

有些方程写成微分形式：

```text
P(x, y) dx + Q(x, y) dy = 0
```

如果 P 和 Q 是同次齐次函数，也是齐次方程。

把它改写成 dy/dx = −P/Q，再检验是否只含 y/x。

## 6. 手算：齐次一例

**例 3：解 y' = (x² + y²)/(xy)。**

第一步，整理右边。

分子分母都是二次，先约掉一个 x：

```text
(x² + y²)/(xy) = x/y + y/x = 1/u + u
```

其中 u = y/x。

所以右边确实只含 u。

**答案的形状先看一眼。**

右边 = u + 1/u，是一个"对勾函数"。

意义是：斜率等于"连线斜率"加"连线斜率的倒数"。

第二步，换元。

```text
u + x u' = u + 1/u
```

两边减 u：

```text
x u' = 1/u
```

第三步，分离。

```text
u du = dx / x
```

第四步，两边积分。

```text
∫ u du = u²/2
∫ dx/x = ln|x|
```

所以：

```text
u²/2 = ln|x| + C
```

第五步，换回 y/x。

```text
(y/x)² / 2 = ln|x| + C
y²/(2x²) = ln|x| + C
y² = 2x²(ln|x| + C)
```

**答案：y² = 2x²(ln|x| + C)。**

第六步，验算。

取 C = 0，得 y² = 2x² ln|x|。

这个式子只在 ln|x| ≥ 0，即 |x| ≥ 1 时有实解，说明解的存在区间是受限制的。

这很常见：微分方程的解不一定在整条轴上都有定义。

第七步，看丢解。

第四步除以 u 时，u = 0 被排除。

u = 0 意味着 y = 0，代回原方程：

```text
左边 y' = 0
右边 (x² + 0)/(x·0)，分母为 0，无意义
```

所以 y = 0 不是解，没丢东西。

**这道题的三个检查点。**

```text
第一：右边能不能整理成只含 y/x  —— 能
第二：换元后能不能分离成 u 和 x —— 能
第三：换回 y/x 之后能不能化简   —— 能，写成 y² 的形式
```

三个都对，答案就稳。

**再补一道只写关键步骤的。**

```text
y' = 1 + y/x
```

换元 u = y/x：

```text
u + x u' = 1 + u
x u' = 1
u' = 1/x
u = ln|x| + C
y = x(ln|x| + C)
```

代进原方程验一次：

```text
y' = ln|x| + C + 1 = y/x + 1
```

对上。

**这道题的答案有个名字：对数曲线族。**

它是"斜率比连线斜率大 1"的所有曲线。

## 7. 一阶线性方程：P(x)y = Q(x) 那一类

没有这一节，一阶线性方程只能靠猜，而这个类型是数一出现频率最高的一类。

**标准形。**

```text
y' + P(x) y = Q(x)
```

一个字一个字读：

```text
y'        待求函数的导数
P(x)      已知函数，叫系数函数
y         待求函数本身
Q(x)      已知函数，叫自由项或右端项
```

**"线性"指的是对 y 而言是线性的。**

y 和 y' 都只出现一次，都是一次的，没有 y²、没有 yy'、没有 sin y。

P(x) 和 Q(x) 里可以有 x 的任何花样，不影响"线性"。

**齐次与非齐次。**

```text
Q(x) = 0    叫一阶线性齐次方程
Q(x) ≠ 0    叫一阶线性非齐次方程
```

这里说的"齐次"和上一节的"齐次方程"不是同一个词。

上一节的齐次说的是"y/x 型"，这一节的齐次说的是"右端为零"。

两个名字撞车了，考试里靠上下文区分。

**线性这个词为什么值钱。**

因为它带来一条性质：叠加原理。

如果 y₁ 是 Q₁ 对应的解，y₂ 是 Q₂ 对应的解，那么 y₁ + y₂ 是 Q₁ + Q₂ 对应的解。

验证只要一行：

```text
(y₁ + y₂)' + P(y₁ + y₂) = (y₁' + Py₁) + (y₂' + Py₂) = Q₁ + Q₂
```

这条性质有两个用处。

第一，把复杂的右端拆成几块，分别求解再相加。

第二，它保证了通解一定是"齐次通解 + 一个特解"的形状。

第一条在高阶方程里用得更多，但思想在这里就立住了。

**解法：乘一个积分因子。**

这个方法的思路是：想办法把左边凑成"某个乘积的导数"。

如果左边能写成 (μy)'，那方程就变成：

```text
(μy)' = μQ
```

两边积分就行，因为左边直接就是导数。

**μ 该取什么。**

要求：

```text
(μy)' = μy' + μP y
```

展开左边：

```text
(μy)' = μy' + μ' y
```

对比系数，需要：

```text
μ' = μ P
```

这是一个可分离方程：

```text
dμ/μ = P dx
ln|μ| = ∫P dx
μ = e^{∫P dx}
```

μ 叫积分因子（integrating factor）。

**注意 ∫P dx 不用加常数。**

因为 μ 只是"一个"因子，乘上常数倍不影响效果，取最简单的那个即可。

**四步公式，一阶线性版本。**

```text
算什么：把左边凑成 (μy)' 的形式，让方程变成"直接积分"
逐符号：μ = e^{∫P dx} 是积分因子，P 是 y 的系数，Q 是右端
代数字：y' + y/x = x² → μ = e^{∫dx/x} = x
适用条件：必须先化成标准形 y' + Py = Q，P 的符号不能错
```

**化成标准形这一步最容易错。**

题目给的经常是：

```text
x y' + 2y = x³
```

要先除以 x：

```text
y' + (2/x) y = x²
```

此时 P = 2/x，Q = x²。

直接拿原式的 2 当 P，全错。

**推出最终公式。**

从 (μy)' = μQ 出发，两边积分：

```text
μ y = ∫ μ Q dx + C
```

两边除以 μ：

```text
y = e^{−∫P dx} [ ∫ Q e^{∫P dx} dx + C ]
```

这个公式可以背，但更稳的做法是每次现推。

现推只要四步，比回忆公式可靠。

**现推的四步，写成模板。**

```text
第一步：化标准形，抄下 P 和 Q
第二步：算 μ = e^{∫P dx}
第三步：两边乘 μ，左边写成 (μy)'
第四步：积分，除以 μ，加常数
```

考场上写这四行，比写一行大公式更容易拿分。

因为公式里 e^{−∫P} 和 e^{∫P} 的位置一记错，整题就废了。

而四步里每一步都能自己检查：第三步的自查标准是"左边必须恰好是 (μy)'"。

## 8. 手算：一阶线性一例

**例 4：解 y' + y/x = x²（x > 0），且 y(1) = 1。**

第一步，确认已经是标准形。

```text
y' + P y = Q
P = 1/x，Q = x²
```

第二步，算积分因子。

```text
∫P dx = ∫ dx/x = ln x
μ = e^{ln x} = x
```

这里用了 x > 0，所以 ln x 不用加绝对值。

第三步，两边乘 μ。

```text
x y' + y = x³
```

第四步，认出左边是乘积的导数。

```text
(x y)' = x y' + y
```

所以方程变成：

```text
(x y)' = x³
```

第五步，两边积分。

```text
x y = x⁴/4 + C
```

第六步，解出 y。

```text
y = x³/4 + C/x
```

**这是通解。**

第七步，代初值。

```text
y(1) = 1/4 + C = 1
C = 3/4
```

所以：

```text
y = x³/4 + 3/(4x)
```

**答案：y = x³/4 + 3/(4x)，x > 0。**

第八步，验算。

```text
y' = 3x²/4 − 3/(4x²)
y/x = x²/4 + 3/(4x²)
相加 = 3x²/4 + x²/4 = x²
```

右边是 x²，对上。

**三个值得记住的细节。**

**细节一：μ 的选择不唯一。**

```text
μ = e^{ln x} = x
```

也可以取 μ = 2x，效果一样，因为常数因子最后会约掉。

取最简单的。

**细节二：通解的结构。**

```text
y = x³/4 + C/x
    └─特解─┘ └─齐次解─┘
```

第一项是"非齐次方程的一个特解"。

第二项是"对应齐次方程 y' + y/x = 0 的通解"。

这个结构在高阶方程里还会再出现一次，是整章的主线。

**细节三：解的存在区间。**

x > 0 是题目给的。

如果没有给，要注意 P = 1/x 在 x = 0 处没有定义，解只能在 0 的某一侧。

初值在 x = 1，所以取 x > 0。

**再补一道不带初值的。**

```text
y' + 2xy = 2x e^{−x²}
```

P = 2x，Q = 2x e^{−x²}。

```text
∫P dx = x²
μ = e^{x²}
```

两边乘 μ：

```text
e^{x²} y' + 2x e^{x²} y = 2x
(e^{x²} y)' = 2x
```

积分：

```text
e^{x²} y = x² + C
y = (x² + C) e^{−x²}
```

**答案：y = (x² + C)e^{−x²}。**

验算 x = 0 时 y = C，符合通解带一个常数的要求。

**这一类题的固定动作，四步。**

```text
1. 化标准形，读出 P 和 Q
2. 算 μ = e^{∫P dx}
3. 两边乘 μ，左边写成 (μy)'
4. 积分，除以 μ
```

四步都不难，难在第一步别漏除法。

## 9. 伯努利方程：多一个 y 的幂

没有这一节，右端多一个 y 的平方就成了死题，而那正是数一喜欢加的一层。

**形状。**

```text
y' + P(x) y = Q(x) yⁿ，  n ≠ 0, 1
```

比线性方程多了右边的 yⁿ。

n = 0 时退化成线性。

n = 1 时是可分离（把右边并到左边）。

所以只讨论 n ≠ 0, 1。

**解法：换元把幂消掉。**

令：

```text
z = y^{1−n}
```

求导：

```text
z' = (1−n) y^{−n} y'
```

**为什么这么选。**

因为原方程两边除以 yⁿ 之后，会出现 y^{−n}y' 这个组合。

而 z' 里正好有 y^{−n}y'。

**走一遍流程。**

原方程除以 yⁿ：

```text
y^{−n} y' + P y^{1−n} = Q
```

注意 y^{1−n} 就是 z。

把 y^{−n}y' 换成 z'/(1−n)：

```text
z'/(1−n) + P z = Q
```

两边乘 (1−n)：

```text
z' + (1−n) P z = (1−n) Q
```

**这已经是一个一阶线性方程了。**

解出 z，再换回 y = z^{1/(1−n)}。

**四步公式，伯努利版本。**

```text
算什么：把非线性的 yⁿ 通过换元变成线性方程
逐符号：z = y^{1−n}，n 是右端 y 的指数
代数字：y' − y = y² → n = 2，z = 1/y，z' + z = −1
适用条件：n ≠ 0 且 n ≠ 1；换元后要换回 y
```

**例 5：解 y' = y + y²。**

第一步，写成标准形。

```text
y' − y = y²
```

对照 y' + Py = Qyⁿ：

```text
P = −1，Q = 1，n = 2
```

第二步，换元。

```text
z = y^{1−2} = y^{−1} = 1/y
```

第三步，算 z'。

```text
z' = −y^{−2} y' = −y'/y²
```

从原方程解出 y' = y + y²，代入：

```text
z' = −(y + y²)/y² = −1/y − 1 = −z − 1
```

所以：

```text
z' + z = −1
```

第四步，解这个线性方程。

P = 1，Q = −1。

```text
μ = e^{∫1 dx} = e^x
(z e^x)' = −e^x
z e^x = −e^x + C
z = −1 + C e^{−x}
```

第五步，换回 y。

```text
1/y = C e^{−x} − 1
y = 1/(C e^{−x} − 1)
```

**答案：y = 1/(Ce^{−x} − 1)。**

第六步，验算。

```text
y' = C e^{−x} / (C e^{−x} − 1)²
y + y² = 1/(Ce^{−x}−1) + 1/(Ce^{−x}−1)²
       = [(Ce^{−x}−1) + 1]/(Ce^{−x}−1)²
       = C e^{−x}/(Ce^{−x}−1)²
```

两边相等。

第七步，看丢解。

第四步换元时 z = 1/y，排除了 y = 0。

代 y = 0 回原方程：

```text
左边 0，右边 0 + 0 = 0
```

所以 y = 0 是解，而且是奇解（通解里取不到，因为分子恒为 1）。

完整答案要加上 y = 0。

**四种方程的类型表。**

```text
可分离：右边 = f(x)g(y)              解法：分离后各积各的
齐次  ：右边 = φ(y/x)                解法：u = y/x，化成可分离
线性  ：y' + P y = Q                 解法：乘 μ = e^{∫P dx}
伯努利：y' + P y = Q yⁿ              解法：z = y^{1−n}，化成线性
```

**识别的顺序。**

```text
第一步：能不能拆成 f(x)g(y)？  能 → 可分离
第二步：右边是不是只含 y/x？   是 → 齐次
第三步：y 和 y' 是不是都一次？ 是 → 线性
第四步：右边是不是 Q yⁿ？      是 → 伯努利
```

四步走完还认不出，说明题目超出了数一范围。

按这个顺序走，三秒能定类型。

## 10. 常见错误

**错误一：没化成标准形就取 P。**

```text
错：x y' + 2y = x³，P = 2
对：先除以 x，P = 2/x
```

这是这一章最高频的错误。

**错误二：积分因子算错符号。**

```text
μ = e^{∫P dx}    ← P 的符号照抄，不取负
y = μ^{−1}(∫μQ dx + C)   ← 最后除以 μ
```

有人把 e^{−∫P} 直接当 μ 乘上去，结果整个方程反了。

**错误三：分离后两边都写常数。**

```text
ln|y| + C₁ = x² + C₂
```

两个常数可以合并成一个，写成 ln|y| = x² + C 就够。

写两个不算错，但会让后面的化简变乱。

**错误四：丢解。**

除以 y、y²、1+y² 这类因子时，要检查它是否为零。

零对应的常数函数可能是解，而且常常不在通解里。

**错误五：齐次方程解完忘记回代。**

```text
算出 u = ln|x| + C 就交卷
```

题目要的是 y，必须写 y = x(ln|x| + C)。

**错误六：通解常数个数不对。**

一阶方程的通解含 1 个任意常数。

算出两个常数，说明中间有一步多引入了。

算出零个，说明初值代早了。

**错误七：初值代早了。**

正确顺序：

```text
先求通解（带 C）→ 再代初值定 C
```

如果在分离之后就代初值，会得到一个含 C 的方程，反而绕远。

**错误八：把 dy/dx 当分数用却不说明。**

在可分离方程里，把 dy/dx 拆成 dy 和 dx 是合法的。

理由是 dy = y' dx。

但在别的地方（比如二阶方程）随便拆，容易出错。

**错误九：伯努利换元后忘了 1−n 这个因子。**

```text
z' + (1−n)P z = (1−n)Q
```

两个 (1−n) 都不能漏。

漏一个，解出来就不是原方程的解。

**错误十：答案不带存在区间。**

```text
y = (1 + x)/(1 − x)
```

这个解在 x = 1 处没有定义。

题目若问"解的存在区间"，要答 x < 1（初值在 0 的左侧）。

只写函数表达式，不算完整。

## 11. 数一怎么考

**题型一：识别类型然后求解。**

这是主流题型，通常 10 分。

给一个方程，不给类型提示。

第一步就是判断它属于四类中的哪一类。

判断错了，后面全错。

所以第 9 节那张识别顺序表要背熟。

**题型二：求满足初值的特解。**

比题型一多一步代初值。

注意初值可能给的不是 y(0)，而是 y(1) 或者 y(π/2)。

代的时候别把 x₀ 和 y₀ 搞反。

**题型三：应用题。**

常见三类：

```text
变化率问题：增长、衰变、冷却、混合
几何问题：切线斜率、曲线过定点、面积关系
物理问题：电路、运动、受力
```

**一道变化率题的做法。**

某种放射性物质，衰变速度正比于当前质量，半衰期 100 年。

求 50 年后剩余的比例。

第一步，列方程。

```text
dM/dt = −k M
```

负号表示减少。

第二步，解。

```text
M = M₀ e^{−kt}
```

第三步，用半衰期定 k。

```text
M(100) = M₀/2
M₀ e^{−100k} = M₀/2
e^{−100k} = 1/2
100k = ln 2
k = ln2/100
```

第四步，求 50 年后的比例。

```text
M(50)/M₀ = e^{−50k} = e^{−(ln2)/2} = 1/√2 ≈ 0.707
```

**答案：约剩 70.7%。**

**题型四：几何题。**

例：一条曲线过点 (1, 1)，且它在任一点 (x, y) 处的切线斜率等于 2x/y，求这条曲线。

第一步，把几何语言翻成方程。

```text
切线斜率 = y'
y' = 2x/y
```

第二步，这是可分离的。

```text
y dy = 2x dx
y²/2 = x² + C
y² = 2x² + C₁
```

第三步，代初值。

```text
1 = 2 + C₁
C₁ = −1
```

**答案：y² = 2x² − 1。**

第四步，注意定义域。

y² ≥ 0 要求 2x² ≥ 1，即 |x| ≥ 1/√2。

曲线只在两段上有实解，不是一整条。

**题型五：验证题。**

给一个函数，问它是不是某个方程的解。

做法只有一个：代进去算。

再给一个变体：给一个含参数的函数族，问它满足哪个微分方程。

做法是求导，然后把参数消掉。

比如 y = Cx²，求导得 y' = 2Cx，把 C = y/x² 代回：

```text
y' = 2(y/x²)x = 2y/x
```

所以这个函数族满足 y' = 2y/x。

**题型六：混合问题。**

盐水箱里有 100 升水，溶了 10 千克盐。

每分钟流入 2 升浓度为 0.5 千克/升的盐水，同时流出 2 升混合液。

求 t 分钟后箱内的盐量。

第一步，列方程。

设盐量为 m(t) 千克。

流入速率：

```text
2 × 0.5 = 1（千克/分钟）
```

流出速率等于"流出体积 × 当时浓度"：

```text
2 × m/100 = m/50（千克/分钟）
```

所以：

```text
m' = 1 − m/50
```

第二步，这是线性方程。

```text
m' + m/50 = 1
P = 1/50，Q = 1
μ = e^{t/50}
```

第三步，解。

```text
(m e^{t/50})' = e^{t/50}
m e^{t/50} = 50 e^{t/50} + C
m = 50 + C e^{−t/50}
```

第四步，代初值。

```text
m(0) = 10
10 = 50 + C
C = −40
```

**答案：m = 50 − 40e^{−t/50}。**

第五步，看一眼极限。

t → ∞ 时 m → 50。

这符合直觉：流进来的浓度是 0.5 千克/升，箱内最终也会稳定在这个浓度，100 升就是 50 千克。

**题型七：证明题。**

偶尔会考"证明一阶线性方程的通解公式"。

思路就是第 7 节的构造：

```text
设 μ = e^{∫P dx}
验证 (μy)' = μ(y' + Py) = μQ
两边积分，解出 y
```

写清这三行，证明就完整了。

**时间分配建议。**

```text
识别类型：30 秒
求解：5 到 8 分钟
代初值 + 验算：2 分钟
```

## 12. 和其他章节怎么连

**和 06 篇（不定积分）。**

这一章的计算全是积分。

分离之后要积，乘了 μ 之后要积，换元之后要积。

所以不定积分不熟，这一章写不下去。

**和 03 篇（导数）。**

y' 就是导数。

所有"变化率"的语言，都要先翻译成导数。

**和 07 篇（定积分）。**

带初值的定解问题，可以用变上限积分写成：

```text
y = y₀ + ∫(x₀→x) f(t, y(t)) dt
```

这是微分方程的积分形式，也是数值解法的起点。

**和 20 篇（高阶微分方程）。**

这一章是地基。

高阶方程的解也分"齐次通解 + 非齐次特解"，结构和第 8 节说的一模一样。

二阶常系数方程的特征方程法，本质上就是把二阶降成两个一阶。

**和 16 到 18 篇（级数）。**

有些方程解不出初等函数，就用幂级数设解：

```text
y = Σ aₙ xⁿ
```

代进方程比较系数，逐项定 aₙ。

这条路叫幂级数解法，数一只需知道思路。

**和物理。**

牛顿第二定律 m x'' = F 是二阶方程。

一阶方程处理的是"一阶物理过程"：衰变、冷却、充电。

二阶处理的是"带惯性或回复力的过程"：振动、摆动、LC 振荡。

**一个统一视角。**

这一章的四类方程，本质上都在做同一件事：

```text
想办法把未知函数 y 消掉，或者降成一次，让方程变成"能积分"的样子。
```

可分离：把 x 和 y 分开，各积一次。

齐次：把"两个变量的比值"当成一个新变量。

线性：乘一个因子，把左边变成整体的导数。

伯努利：换一个幂次，把非线性变成线性。

四种手法，同一个目标：**让积分能落地。**

记住这个目标，就不用死记四套流程的细节。

### 自检三问

**第一问：为什么一阶方程的通解恰好含一个任意常数，不多不少？**

因为每积分一次，就产生一个常数。

一阶方程解的过程中，本质上只做了一次"从导数还原函数"的操作，所以只产生一个常数。

从几何上看，通解是一族曲线，它们在每一点有相同的斜率，只是整体上下平移。

要挑出其中一条，需要且只需要一个条件：过一个定点。

一个条件定一个常数，所以常数个数 = 条件个数 = 阶数。

**第二问：可分离方程两边同时积分时，为什么只写一个常数 C？**

因为两边各产生一个常数，但它们都是"任意常数"。

任意常数加任意常数，还是任意常数。

所以可以合并：把右边的 C₂ − C₁ 记成 C。

这不是省略，是合并同类项。

但要小心：合并之后，常数必须仍然可以取遍所有实数。

如果合并时限制了范围（比如只取正数），那就丢解了。

**第三问：一阶线性方程的积分因子 μ = e^{∫P dx}，那个 ∫P dx 要不要加常数？**

不要加。

因为 μ 只需要满足 μ' = μP，而 μ 乘上一个常数倍仍然满足。

也就是说，所有的 e^{∫P dx + C₀} 只差一个常数倍，效果完全一样。

取最简单的那个，即让常数等于 0。

同理，算 ∫P dx 时不必写绝对值：如果 P 的定义域让 ln 出现负数，取绝对值后 μ 只差一个符号，而符号也会被最后的除法约掉。

## 13. 小结

压成一张卡片。

```text
y' = f(x)              直接积分
可分离：y' = f(x)g(y)  分离 → 积分 → 化简
齐次  ：y' = φ(y/x)    u = y/x，y = ux，y' = u + xu'
线性  ：y' + Py = Q    μ = e^{∫P dx}，(μy)' = μQ
伯努利：y' + Py = Qyⁿ  z = y^{1−n}，化成线性
```

四步公式在这一章的统一形态。

```text
算什么 → 找一个函数，使它的导数满足给定的关系
逐符号 → y' 导数，P 是 y 的系数，Q 是右端，μ 是积分因子
代数字 → 每道题都代回原方程验算，这是最可靠的检查
适用条件 → 先化标准形；除因子时查零；解的存在区间要说明
```

四种类型，四个动作。

```text
可分离 → 分开
齐次   → 换元
线性   → 乘因子
伯努利 → 降幂
```

一个必须养成的习惯。

```text
拿到题，先不写，先问：这是哪一类？
```

类型判对了，剩下的都是机械动作。

类型判错了，写得再工整也是零分。

**三个必背的模型解。**

```text
y' = ky        → y = C e^{kx}
y' + ay = b    → y = b/a + C e^{−ax}
y' = y²        → y = −1/(x + C)
```

前两个覆盖了一半以上的应用题。

第三个是"爆炸式增长"的原型：解在有限时间内冲到无穷。

对照着看第一条和第三条的差别：

```text
y' = ky：增长越来越快，但永远到不了无穷
y' = y²：增长快到在 x = −1/C 处直接撑爆
```

差别在于"增长的速度是不是正比于自身的高次幂"。

**最后给一个判类型的自问清单。**

```text
能写成 dy/dx = f(x)g(y) 吗？      能，就是可分离
右边只跟 y/x 有关吗？              是，就是齐次
化成标准形后有 y' + P(x)y 吗？     有，就是线性
右端是 Q(x) 乘 y 的 n 次方吗？     是，就是伯努利
```

四问走完，题目一定落进四类之一。

如果四问都不成立，先看看是不是漏了一步整理。

**最后一个提醒。**

这一章的所有答案，都应该能代回原方程验算。

验算是唯一不依赖记忆的检查手段。

```text
算出 y，求一次导，代进原方程，看两边是否相等。
```

三行字，能救回整道题的分。
