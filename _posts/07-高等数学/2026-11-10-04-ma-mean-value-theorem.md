> **读这篇之前，你只需要知道**：导数是切线斜率，也是瞬时变化率；闭区间上连续的函数一定取到最大值和最小值（02 篇）；函数在极值点附近"先涨后跌"或"先跌后涨"。
> **这篇讲什么**：把"整体平均"和"某一瞬间"连起来——平均变化率一定在某个瞬间被精确取到，这条结论是数一证明题的总入口，也是洛必达法则的来历。
> **一个类比**：区间测速算出你这段路平均时速 120，而限速也是 120；如果你全程每一瞬间都严格低于 120，那平均数绝不可能到 120，所以必然有某一瞬间表盘正好指着 120。


先算一道"生活题"。

```text
一段 120 公里的高速，你开了整整 1 小时。
平均速度 = 120 公里每小时。
限速 120。
```

问：这 1 小时里，有没有哪一瞬间，速度表正好指着 120？

直觉说：有。

但"直觉"不算数，得给出理由。

理由可以这样讲：

```text
假设每一瞬间的速度都严格小于 120。
那么每一小段时间内走过的路程，都小于 120 乘以那段时间。
把所有小段加起来，总路程就严格小于 120 × 1 = 120 公里。
可实际走了 120 公里，矛盾。
所以至少有某一瞬间，速度不小于 120。
```

再补一句：如果速度是连续变化的（车不会瞬间跳变），那么从"某一瞬间 ≥ 120"到"平均 120"，中间必然有一刻正好等于 120。

**这段推理，就是拉格朗日中值定理。**

它说的是：

```text
一段区间上的平均变化率，必然在区间内某一点被精确取到。
```

听起来像废话，但它是整个微分学的枢纽。

因为它是"从整体推局部"的唯一通道：

```text
已知函数在两端的值 → 推出内部某点导数的信息。
```

数一的证明题，八成都在干这件事。

而做这件事需要的工具，一共五个，层层嵌套：

```text
费马引理（极值点导数为零）
   ↓
罗尔定理（两端一样高，中间有水平切线）
   ↓
拉格朗日定理（把"一样高"放开成"任意两端"）
   ↓
柯西定理（把"自变量 x"换成"另一个函数 g"）
   ↓
泰勒定理（把"一阶"推到"n 阶"）
```

这一篇就按这条链往上走，走完再拐回来讲两件事：

```text
证明题里的辅助函数是怎么想出来的。
洛必达法则凭什么成立。
```

## 1. 为什么需要中值定理（不给会怎样）

**第一，导数的信息传不到函数值上。**

知道 f'(x) 在 (0, 1) 内恒大于 0，能不能说 f(1) > f(0)？

能，但凭什么是能？

没有中值定理，这句话只能靠"看图觉得对"。

有了它，一行就证完：

```text
f(1) − f(0) = f'(ξ)(1 − 0) = f'(ξ) > 0
```

**第二，不等式证明没有通用工具。**

证明 x > 0 时 ln(1 + x) < x。

初等办法是构造函数求导再判单调，能做，但每次都要重复劳动。

中值定理给出统一套路：

```text
ln(1 + x) − ln 1 = x/(1 + ξ)，其中 0 < ξ < x。
因为 1 + ξ > 1，所以 x/(1 + ξ) < x。
```

**第三，洛必达法则没有依据。**

求 lim(x→0) sin x / x，洛必达一步得 cos x/1 → 1。

凭什么可以把"两个函数相除的极限"换成"两个导数相除的极限"？

凭柯西中值定理。

没有它，洛必达就是一条来路不明的公式。

**第四，泰勒公式无从建立。**

e^x ≈ 1 + x + x²/2 这类展开，是后面级数（17 篇）、极限计算、误差估计的主力。

它的严格形式（带拉格朗日余项）就是泰勒中值定理。

**第五，方程的根与导数的零点联系不起来。**

"f 有三个零点，则 f' 至少有两个零点"——这句话是罗尔定理的直接推论，也是数一证明题的高频结论。

所以这一篇不是"一堆定理"，而是**一套把函数值和导数值互相转换的机器**。

## 2. 费马引理：极值点处导数为零

先看一个最基本的事实。

```text
如果 f 在 a 处取到极大值（或极小值），且 f 在 a 处可导，
那么 f'(a) = 0。
```

读法：f 撇 a 等于 0。

符号：

```text
极大值：a 附近所有点的函数值都不超过 f(a)。
极小值：a 附近所有点的函数值都不小于 f(a)。
a 必须是区间的内点，端点不算。
```

四步：

```text
① 它在算什么：
   它说"山顶是平的"。曲线在最高点或最低点，切线一定是水平的。

② 符号逐个念：
   f'(a) = 0 表示切线水平，即瞬时变化率为零。

③ 代一组数：
   f(x) = x² − 4x + 3 = (x − 2)² − 1。
   在 x = 2 处取最小值 −1。
   f'(x) = 2x − 4，f'(2) = 0，确实平。

④ 什么时候能用/不能用：
   必须"内点"，端点处即使取到最值，导数也不必为 0。
   必须"可导"。f(x) = |x| 在 0 处取极小值，但 f'(0) 不存在。
   反过来不成立：f'(a) = 0 不代表 a 是极值点（f(x) = x³ 在 0 处）。
```

### 2.1 证明（两行核心）

设 f 在 a 处取极大值，则 a 附近有 f(a + h) ≤ f(a)。

看差商：

```text
h < 0 时：分子 f(a+h) − f(a) ≤ 0，分母 h < 0，所以差商 ≥ 0。
          令 h → 0⁻，得 f'(a) ≥ 0。

h > 0 时：分子 ≤ 0，分母 > 0，所以差商 ≤ 0。
          令 h → 0⁺，得 f'(a) ≤ 0。
```

两个不等式合起来：

```text
0 ≤ f'(a) ≤ 0，所以 f'(a) = 0。
```

**这个证明的思路从哪来？**

要证一个数等于 0，最干脆的办法是证它既 ≥ 0 又 ≤ 0。

而从左边逼近和从右边逼近，差商的符号正好相反，天然给出这两个方向。

这就是为什么费马引理必须假设"可导"：只有可导，左右两个极限才相等；不相等时，一正一负，推不出 0。

| x | 在 0 处就是活例子：左导数 −1，右导数 1，不是 0。

### 2.2 一个容易忽略的限定

```text
极值必须是"内点"的极值。
```

例：f(x) = x 在 [0, 1] 上。

最大值在 x = 1 取到，但 f'(1) = 1 ≠ 0。

原因是 1 是端点，只有左侧有定义，谈不上"两边都往下掉"。

所以后面罗尔定理的结论里，ξ 一定写在开区间 (a, b) 内，端点是排除的。

## 3. 罗尔定理

三个条件，一个结论。

```text
若 f 满足：
  ① 在闭区间 [a, b] 上连续；
  ② 在开区间 (a, b) 内可导；
  ③ f(a) = f(b)；
则存在 ξ ∈ (a, b)，使 f'(ξ) = 0。
```

符号读音：

```text
ξ     读"克西"，希腊字母，表示那个"存在"的点。
(a, b) 开区间，不含端点，因为端点处不保证可导。
```

四步：

```text
① 它在算什么：
   两端一样高的连续曲线，中间必有一处切线水平。
   通俗版：从山脚走到同样高的另一处，路上必然有平路（哪怕是山顶那一瞬）。

② 符号逐个念：
   f(a) = f(b) 是"两端等高"，f'(ξ) = 0 是"某点切线水平"。

③ 代一组数：
   f(x) = x² − 2x − 3 在 [−1, 3] 上。
   f(−1) = 1 + 2 − 3 = 0，f(3) = 9 − 6 − 3 = 0，两端等高。
   f'(x) = 2x − 2，令其为 0 得 ξ = 1。
   1 ∈ (−1, 3)，结论成立。
   验算：f(1) = 1 − 2 − 3 = −4，是抛物线顶点。

④ 什么时候能用/不能用：
   三个条件缺一不可（下面有反例）。
   结论只保证"至少一个"，不保证唯一，也可能有多个。
```

### 3.1 证明：最值定理 + 费马引理

```text
第一步：f 在 [a, b] 上连续，由最值定理，取到最大值 M 与最小值 m。

第二步：分两种情况。
  情况一：M = m。
    此时 f 恒等于这个值，是常数函数，f'(x) 处处为 0。
    任取一个 ξ ∈ (a, b) 即可。
  情况二：M > m。
    因为 f(a) = f(b)，M 与 m 不可能都在端点取到（否则两端同高就都是 M 或都是 m，
    与 M > m 矛盾）。
    所以 M、m 中至少有一个是在内部某点 ξ 取到的。
    这个 ξ 是内点，且 f 在 ξ 处取极值、f 在 ξ 处可导，
    由费马引理，f'(ξ) = 0。

第三步：两种情况下都找到了 ξ，证毕。
```

**这个证明的思路从哪来？**

要证"存在一点导数为 0"，唯一能用的现成结论是费马引理。

费马引理要求"极值点 + 可导"。

可导是条件②给的，那就只剩"怎么保证有极值点"。

答案是最值定理：闭区间连续必有最值。

而"两端等高"这个条件，正好用来保证最值点不会两个都落在端点上。

三个条件各司其职，一个都不能少，这就是为什么定理长这个样子。

### 3.2 三个条件各缺一次会怎样

```text
缺①连续：f(x) = 1/x（x ≠ 0），f(0) = 0，在 [−1, 1] 上。
        f(−1) = −1，f(1) = 1，两端不等高，先不满足③，换一个例子。

换成：f(x) = x（0 ≤ x < 1），f(1) = 0，在 [0, 1] 上。
      f(0) = 0 = f(1)，但 f 在 x = 1 处不连续。
      在 (0, 1) 内 f'(x) = 1，永远不为 0。
      所以不连续时结论失效。

缺②可导：f(x) = |x|，在 [−1, 1] 上。
        f(−1) = 1 = f(1)，连续也满足。
        但 f 在 0 处不可导，而 f' 在别处是 ±1，永不为 0。
        所以不可导时结论失效。

缺③等高：f(x) = x，在 [0, 1] 上。
        连续、可导，但 f(0) = 0 ≠ 1 = f(1)。
        f'(x) = 1，永不为 0。
        所以不等高时结论失效。
```

**记住这三张脸，选择题直接秒判。**

它们也是"为什么定理要写这三个条件"的最好回答：每一条都是被反例逼出来的。

## 4. 拉格朗日中值定理

把罗尔的"两端等高"去掉，就得到微分学最重要的定理。

```text
若 f 在 [a, b] 上连续，在 (a, b) 内可导，
则存在 ξ ∈ (a, b)，使
f(b) − f(a) = f'(ξ) (b − a)
```

也可以写成：

```text
f'(ξ) = [f(b) − f(a)] / (b − a)
```

右边是割线斜率（平均变化率），左边是某点的切线斜率（瞬时变化率）。

四步：

```text
① 它在算什么：
   平均变化率 = 某点的瞬时变化率。
   换句话说：一段路上的"平均速度"，一定在某一瞬间被精确达到。

② 符号逐个念：
   f(b) − f(a) 是函数在两端的差，b − a 是自变量的差，
   两者相除是平均变化率；f'(ξ) 是那一点的瞬时变化率。

③ 代一组数：
   f(x) = ln x 在 [1, e] 上。
   平均变化率 = (ln e − ln 1)/(e − 1) = 1/(e − 1) ≈ 0.582。
   f'(x) = 1/x，令 1/ξ = 1/(e − 1)，得 ξ = e − 1 ≈ 1.718。
   1.718 确实落在 (1, 2.718) 内，结论成立。

④ 什么时候能用/不能用：
   必须闭区间连续、开区间可导。
   结论只保证 ξ 存在，不给位置，也不给唯一性。
   不能对"不连续的函数"用，也不能对"区间外的点"用。
```

### 4.1 证明：把斜的拉平

思路只有一句话：

```text
造一个辅助函数，让它在新坐标系里"两端等高"，然后套罗尔。
```

具体做法：把曲线减去那条割线。

```text
令 g(x) = f(x) − f(a) − [f(b) − f(a)]/(b − a) · (x − a)
```

这个 g 的含义是"曲线与割线的纵向差"。

验证：

```text
g(a) = f(a) − f(a) − 0 = 0
g(b) = f(b) − f(a) − [f(b) − f(a)] = 0
```

两端都是 0，等高。

而 g 连续、可导（它是 f 减去一个一次函数），所以由罗尔定理，存在 ξ：

```text
g'(ξ) = 0
g'(x) = f'(x) − [f(b) − f(a)]/(b − a)
所以 f'(ξ) = [f(b) − f(a)]/(b − a)
```

证毕。

**这个构造是怎么想出来的？**

这是全篇最值得停下来看一眼的地方。

目标是"存在 ξ 使 f'(ξ) = 割线斜率"。

罗尔能给的是"存在 ξ 使 g'(ξ) = 0"。

两者一对比，就差一件事：**把割线斜率减掉。**

于是令 g = f − 割线，这样一来 g' = f' − 割线斜率，g' = 0 就等价于要证的结论。

而"减去割线"之后，g 在两端自然都等于 0，罗尔的条件也自动满足。

**"要证的式子写成 g' = 0，再找 g"——这就是所有中值定理证明的总纲。**

后面第 9 节会把这个动作拆成五种模板。

### 4.2 两种常用变形

```text
形式一（差的形式）：f(b) − f(a) = f'(ξ)(b − a)
形式二（θ 的形式）：f(a + h) − f(a) = f'(a + θh) · h，其中 0 < θ < 1
```

第二种在"证明存在某个介于 0 和 1 之间的数"时好用。

例：证明 lim(h→0) [f(a+h) − f(a)]/h = f'(a) 可以由它推出（把 θ 夹在 0 和 1 之间，h → 0 时 θh → 0）。

### 4.3 两个必须记住的推论

```text
推论一：若在区间 I 上恒有 f'(x) = 0，则 f 在 I 上恒为常数。
推论二：若在区间 I 上恒有 f'(x) > 0，则 f 在 I 上严格单调递增。
```

推论一的证明只要一行：

```text
任取 x₁ < x₂ ∈ I，由拉格朗日，
f(x₂) − f(x₁) = f'(ξ)(x₂ − x₁) = 0 · (x₂ − x₁) = 0，
所以 f(x₂) = f(x₁)。x₁、x₂ 任意，故 f 为常数。
```

**推论一是 06、07 篇的理论依据。**

不定积分里写 "∫f(x)dx = F(x) + C"，那个 C 凭什么加？

就凭"两个原函数之差导数为 0，所以差是常数"。

没有这条推论，不定积分的 "+C" 就是一个说不清的习惯。

推论二则是 05 篇判单调的全部依据。

### 4.4 用拉格朗日证不等式

这是数一最高频的应用，套路固定：

```text
第一步：把不等式整理成 [f(b) − f(a)]/(b − a) 的形状。
第二步：用拉格朗日换成 f'(ξ)。
第三步：利用 ξ 的取值范围，估计 f'(ξ) 的大小。
```

例 1：

```text
题：证明当 x > 0 时，ln(1 + x) < x。
```

```text
取 f(t) = ln(1 + t)，区间 [0, x]（x > 0）。
f 在 [0, x] 上连续、在 (0, x) 内可导。
由拉格朗日：ln(1 + x) − ln 1 = [1/(1 + ξ)] · (x − 0)，其中 0 < ξ < x。
即 ln(1 + x) = x/(1 + ξ)。
因为 ξ > 0，所以 1 + ξ > 1，所以 x/(1 + ξ) < x。
故 ln(1 + x) < x。
```

例 2：

```text
题：证明对任意实数 a、b，|sin a − sin b| ≤ |a − b|。
```

```text
不妨设 a < b（a = b 时两边都是 0，结论直接成立，不必证）。
由拉格朗日：sin b − sin a = cos ξ · (b − a)，ξ ∈ (a, b)。
两边取绝对值：|sin b − sin a| = |cos ξ| · |b − a|。
因为 |cos ξ| ≤ 1，所以 |sin b − sin a| ≤ |b − a|。
```

例 3（方向容易搞反的那种）：

```text
题：证明当 b > a > 0 时，arctan b − arctan a < b − a。
```

```text
由拉格朗日：arctan b − arctan a = [1/(1 + ξ²)](b − a)，ξ ∈ (a, b)。
因为 1/(1 + ξ²) < 1（ξ > 0 时严格小于 1），
所以 arctan b − arctan a < b − a。
```

**第三步的估计方向必须和结论一致。**

要证 "<"，就得让 f'(ξ) < 1；要证 ">"，就得让 f'(ξ) > 1。

估计方向反了，整道题就白写。所以做题时先看结论的符号，再决定往哪边放缩。

## 5. 柯西中值定理

拉格朗日说的是"y 的差 与 x 的差 之比"。

柯西把它推广成"y 的差 与 另一个函数 g 的差 之比"。

```text
若 f、g 在 [a, b] 上连续，在 (a, b) 内可导，且 g'(x) ≠ 0，
则存在 ξ ∈ (a, b)，使
[f(b) − f(a)] / [g(b) − g(a)] = f'(ξ) / g'(ξ)
```

四步：

```text
① 它在算什么：
   两个函数同时在变，问"f 的变化相对于 g 的变化"的平均比值，
   等于某一瞬间"f' 相对于 g'"的比值。

② 符号逐个念：
   g'(x) ≠ 0 保证分母不为 0，也保证 g(b) ≠ g(a)（否则由罗尔，g' 会有零点）。

③ 代一组数：
   f(x) = x²，g(x) = x³，区间 [1, 2]。
   左边 = (4 − 1)/(8 − 1) = 3/7。
   右边 = 2ξ/(3ξ²) = 2/(3ξ)。
   令 2/(3ξ) = 3/7，得 ξ = 14/9 ≈ 1.556。
   1.556 ∈ (1, 2)，成立。

④ 什么时候能用/不能用：
   三个条件：连续、可导、g' ≠ 0。
   ξ 是同一个点，不能对 f 和 g 分别用拉格朗日取两个不同的点。
```

### 5.1 证明：同一个套路再来一次

构造：

```text
h(x) = f(x) − f(a) − [f(b) − f(a)]/[g(b) − g(a)] · [g(x) − g(a)]
```

验证两端：

```text
h(a) = f(a) − f(a) − 0 = 0
h(b) = f(b) − f(a) − [f(b) − f(a)] = 0
```

等高，罗尔给出 ξ 使 h'(ξ) = 0：

```text
h'(x) = f'(x) − [f(b) − f(a)]/[g(b) − g(a)] · g'(x)
令 h'(ξ) = 0 并移项，即得结论。
```

**注意：这里不能对 f 和 g 分别用拉格朗日。**

分别用会得到两个不同的点 ξ₁、ξ₂，而柯西定理要求的是同一个 ξ。

这是柯西定理比拉格朗日强的地方，也是它证明洛必达时不可替代的原因（洛必达要求分子分母在同一点求导）。

### 5.2 拉格朗日是柯西的特例

在柯西定理里取 g(x) = x：

```text
g'(x) = 1，g(b) − g(a) = b − a
代入：[f(b) − f(a)]/(b − a) = f'(ξ)/1 = f'(ξ)
```

正是拉格朗日。

所以三个定理的关系是一条包含链：

```text
罗尔  ⊂  拉格朗日  ⊂  柯西
（f(a)=f(b)）  （g(x)=x）
```

反过来说，它们其实是同一个定理的三张面孔。

## 6. 三个定理的关系：从罗尔到柯西

把这条链画出来：

```text
              费马引理（极值点导数为零）
                    │
                    │ 加上"最值定理"
                    ▼
              罗尔定理（两端等高 → 有一点水平切线）
                    │
                    │ 减去"两端等高"（把曲线减掉割线）
                    ▼
            拉格朗日定理（平均 = 某点瞬时）
                    │
                    │ 把自变量 x 换成函数 g
                    ▼
              柯西定理（两个函数的比）
                    │
                    │ 从一阶推到 n 阶
                    ▼
              泰勒定理（用多项式逼近）
```

**为什么顺序是这样？**

因为每一步都只做一件事：

```text
罗尔 → 拉格朗日：把"等高"这个限制去掉。做法是减掉割线。
拉格朗日 → 柯西：把"分母是 b − a"换成"分母是 g(b) − g(a)"。
柯西 → 泰勒：把"一次多项式"换成"n 次多项式"。
```

理解这条链，比单独背四个定理有用得多。

因为考试出证明题时，你需要的不是"用哪个定理"，而是"这个结论离哪个定理最近"。

一个实用的判断表：

```text
要证 f'(ξ) = 0                    → 罗尔
要证 f'(ξ) = 某个常数 k            → 拉格朗日，或构造 f − kx 用罗尔
要证 f'(ξ) = [f(b) − f(a)]/(b−a)  → 拉格朗日（结论本身就是它）
要证两个差之比相等                 → 柯西
要证 f(ξ) 与某点函数值的关系        → 泰勒
要证存在 ξ 使 f'(ξ) + f(ξ) = 0     → 构造 e^x f(x) 用罗尔
```

这张表在第 9 节会逐条配例题。

## 7. 泰勒中值定理：把"一次"推到"n 次"

拉格朗日做的事情，本质是"用一阶导数和一次函数去逼近"：

```text
f(x) ≈ f(x₀) + f'(x₀)(x − x₀)
```

这就是 03 篇的切线近似。

但它只用到一阶导数，误差不小。

如果手上有二阶、三阶、一直到 n 阶导数，能不能逼近得更准？

能，这就是泰勒公式。

```text
f(x) = f(x₀) + f'(x₀)(x − x₀) + f''(x₀)/2! · (x − x₀)² + … + f⁽ⁿ⁾(x₀)/n! · (x − x₀)ⁿ + Rₙ(x)
```

其中余项写成拉格朗日形式：

```text
Rₙ(x) = f⁽ⁿ⁺¹⁾(ξ)/(n + 1)! · (x − x₀)ⁿ⁺¹，ξ 介于 x₀ 与 x 之间。
```

符号读音：

```text
f⁽ⁿ⁾   读"f 的 n 阶导"，括号是为了和乘方区分。
n!     读"n 的阶乘"，n! = 1 · 2 · 3 … n，并规定 0! = 1。
Rₙ(x)  读"R n x"，第 n 阶余项，代表"多项式没算准的那部分"。
ξ      介于 x₀ 和 x 之间的某个点，与 x 有关。
```

四步：

```text
① 它在算什么：
   用一个 n 次多项式去模仿 f，让它在 x₀ 处的函数值、一阶导、二阶导……
   一直到 n 阶导都与 f 相同；剩下的差别全部塞进 Rₙ。

② 符号逐个念：
   每一项的系数是"该阶导数在 x₀ 的值除以阶乘"，
   (x − x₀)^k 是"离 x₀ 有多远"的 k 次方，离得越远，高阶项影响越大。

③ 代一组数：
   估 e^0.1。取 x₀ = 0，n = 2。
   f(0) = 1，f'(0) = 1，f''(0) = 1。
   e^0.1 ≈ 1 + 0.1 + (1/2)(0.1)² = 1.105。
   真值 1.1051709…，误差约 0.00017。
   余项 R₂ = e^ξ/6 · (0.1)³，ξ ∈ (0, 0.1)，量级约 0.00017，与实测吻合。

④ 什么时候能用/不能用：
   要求 f 在含 x₀ 与 x 的区间上有直到 n + 1 阶的导数。
   求极限时展开到"分子分母同阶"就够，多展开是浪费。
   估值时余项必须写出来，否则不知道误差多大。
```

**x₀ = 0 的特殊情形叫麦克劳林公式**，考试里用得最多。

必须记住的五条：

```text
e^x = 1 + x + x²/2! + x³/3! + … + xⁿ/n! + Rₙ
sin x = x − x³/3! + x⁵/5! − …            （只含奇次项）
cos x = 1 − x²/2! + x⁴/4! − …            （只含偶次项）
ln(1 + x) = x − x²/2 + x³/3 − …          （−1 < x ≤ 1）
1/(1 − x) = 1 + x + x² + x³ + …          （|x| < 1）
(1 + x)^α = 1 + αx + α(α−1)x²/2! + …
```

### 7.1 泰勒公式的两个用途

**用途一：求极限（比洛必达快）。**

```text
题：求 lim(x→0) (e^x − 1 − x)/x²。
```

```text
展开：e^x = 1 + x + x²/2 + o(x²)。
所以 e^x − 1 − x = x²/2 + o(x²)。
原式 = lim [x²/2 + o(x²)]/x² = 1/2。
答案：1/2。
```

用洛必达也能做（两次），但泰勒一步到位，而且不容易算错。

**用途二：证不等式。**

```text
题：证明对任意 x ≠ 0，e^x > 1 + x。
```

```text
由泰勒公式（n = 1）：e^x = 1 + x + e^ξ x²/2，ξ 介于 0 与 x 之间。
因为 e^ξ > 0，x² > 0，所以余项 e^ξ x²/2 > 0。
故 e^x > 1 + x。
```

**这个证明的思路从哪来？**

要证"f(x) > 某个多项式"，就把 f 写成"那个多项式 + 余项"，然后证余项为正。

余项的符号由 f⁽ⁿ⁺¹⁾ 的符号决定，所以这类题的关键是判断高阶导数的正负。

### 7.2 泰勒与拉格朗日的关系

把 n = 0 代进泰勒公式：

```text
f(x) = f(x₀) + f'(ξ)(x − x₀)
移项：f(x) − f(x₀) = f'(ξ)(x − x₀)
```

正是拉格朗日中值定理。

所以泰勒是拉格朗日的推广，拉格朗日是泰勒的最低阶情形。

这条关系值得记，因为它说明整条链是同一个思想的逐层加码：

```text
罗尔 → 拉格朗日：去掉"等高"
拉格朗日 → 泰勒：从"一阶"加到"n 阶"
```

## 8. 洛必达法则：柯西定理的副产品

### 8.1 法则本身

```text
若 lim(x→a) f(x) = lim(x→a) g(x) = 0（或都为 ∞），
f、g 在 a 的去心邻域内可导，且 g'(x) ≠ 0，
且 lim(x→a) f'(x)/g'(x) 存在（或为 ∞），
则 lim(x→a) f(x)/g(x) = lim(x→a) f'(x)/g'(x)。
```

四步：

```text
① 它在算什么：
   0/0 型的极限，可以换成"分子分母各自求导后的极限"，
   因为两者的"归零速度之比"等于"导数之比"。

② 符号逐个念：
   f'/g' 是导数之比，"存在"是前提，不存在时法则不适用，不是"等于无穷"。

③ 代一组数：
   lim(x→0) sin x/x。
   代入是 0/0，用洛必达：lim cos x/1 = cos 0 = 1。
   与 01 篇用夹逼得到的结果一致。

④ 什么时候能用/不能用：
   只能用于 0/0 或 ∞/∞ 型，别的型必须先化成这两种。
   必须验证"导数之比的极限存在"，否则不能下结论。
   多次使用要每次重新验证仍是未定式。
```

### 8.2 它为什么成立

思路只有一句话：

```text
在 [a, x] 上用柯西中值定理，把"函数之比"换成"导数之比"。
```

补上定义 f(a) = g(a) = 0（因为极限是 0，这样补不改变极限），则

```text
f(x)/g(x) = [f(x) − f(a)]/[g(x) − g(a)] = f'(ξ)/g'(ξ)，ξ 介于 a 与 x 之间。
```

当 x → a 时，ξ 被夹在 a 和 x 之间，所以 ξ → a。

于是

```text
lim(x→a) f(x)/g(x) = lim(ξ→a) f'(ξ)/g'(ξ)
```

右边正是洛必达的结论。

**这个证明的关键是"ξ 被夹住了"。**

柯西定理只说 ξ 存在，不说它在哪；但因为 ξ 在 a 和 x 之间，x → a 时它只能跟着 → a。

这个"夹"的动作，是整条证明的枢纽。

### 8.3 三个必须提防的坑

**坑一：不是未定式也硬用。**

```text
错：lim(x→0) (x + 1)/(x + 2)，用洛必达得 1/1 = 1。
对：直接代入得 1/2。
```

不是 0/0 或 ∞/∞，洛必达完全不适用。

**坑二：导数之比的极限不存在，但原极限存在。**

```text
lim(x→∞) (x + sin x)/x。
这是 ∞/∞ 型，但用洛必达得 (1 + cos x)/1，极限不存在。
而原式 = lim(1 + sin x/x) = 1 + 0 = 1，是存在的。
```

所以"洛必达算不出来"不等于"原极限不存在"。

法则只是充分条件，不是必要条件。

**坑三：循环。**

```text
lim(x→∞) e^x/x²，用一次得 e^x/(2x)，再用一次得 e^x/2 → +∞。
两次收敛，没循环。
但 lim(x→∞) x/√(x²+1)，用一次得 √(x²+1)/x，又回到类似形状，来回打转。
```

遇到循环，说明洛必达不灵，换等价替换或直接除以最高次幂。

**这三条坑的共同点是：洛必达是"优先尝试"，不是"必然成功"。**

数一的解答题里，用洛必达之前写一句"这是 0/0 型"，用完之后写一句"仍为 0/0 型，再用一次"，这两句话是给分点。

## 9. 算一遍：验证与证明

这一节分两半：先验证定理（填空式），再做证明题（构造式）。

### 9.1 验证罗尔定理

```text
题：对 f(x) = x³ − 3x 在 [−√3, √3] 上验证罗尔定理。
```

```text
第一步（连续可导）：f 是多项式，在闭区间连续，在开区间可导。
第二步（等高）：f(−√3) = −3√3 + 3√3 = 0，f(√3) = 3√3 − 3√3 = 0。等高。
第三步（求 ξ）：f'(x) = 3x² − 3 = 3(x − 1)(x + 1)。
     令 f'(x) = 0 得 x = 1 或 x = −1。
第四步（检验）：1 和 −1 都在 (−√3, √3) 内（因为 √3 ≈ 1.732 > 1）。
结论：ξ = 1 与 ξ = −1 都满足，定理说的"至少一个"成立。
```

**注意这里的措辞：定理只保证至少一个，实际有两个并不矛盾。**

填空题如果问"求出所有的 ξ"，就都要写。

### 9.2 验证拉格朗日定理

```text
题：对 f(x) = x³ 在 [0, 2] 上验证拉格朗日定理。
```

```text
左边：平均变化率 = (8 − 0)/(2 − 0) = 4。
右边：f'(x) = 3x²，令 3ξ² = 4，得 ξ = ±2/√3。
取正根 ξ = 2/√3 ≈ 1.1547（负根不在区间内）。
检验：1.1547 ∈ (0, 2)，成立。
```

### 9.3 验证柯西定理

```text
题：对 f(x) = x²，g(x) = x³ 在 [1, 2] 上验证柯西定理。
```

```text
左边 = (4 − 1)/(8 − 1) = 3/7。
右边 = f'(ξ)/g'(ξ) = 2ξ/(3ξ²) = 2/(3ξ)。
令 2/(3ξ) = 3/7，得 ξ = 14/9 ≈ 1.556。
检验：1.556 ∈ (1, 2)，且 g'(ξ) = 3ξ² ≠ 0，成立。
```

### 9.4 证明题：结论就是拉格朗日

```text
题：设 f 在 [0, 1] 上连续，在 (0, 1) 内可导，f(0) = 0，f(1) = 1。
    证明存在 ξ ∈ (0, 1)，使 f'(ξ) = 1。
```

```text
证：f 在 [0, 1] 上连续、在 (0, 1) 内可导，
由拉格朗日中值定理，存在 ξ ∈ (0, 1)，使
f(1) − f(0) = f'(ξ)(1 − 0)。
代入 f(0) = 0、f(1) = 1，得 1 = f'(ξ)。
证毕。
```

**这类题的信号是"结论里的常数正好等于端点连线的斜率"。**

看到"f'(ξ) = 某常数"，第一件事是算 (f(b) − f(a))/(b − a)，看是不是同一个数。

### 9.5 证明题：双中值

```text
题：设 f 在 [0, 1] 上连续，在 (0, 1) 内可导，f(0) = 0，f(1) = 1。
    证明存在两个不同的点 ξ、η，使 f'(ξ) + f'(η) = 2。
```

**思路：一个结论里出现两个中值，通常要在两个子区间上各用一次中值定理。**

```text
证：取中点 1/2，把区间分成 [0, 1/2] 和 [1/2, 1]。
在 [0, 1/2] 上用拉格朗日：
  存在 ξ ∈ (0, 1/2)，f(1/2) − f(0) = f'(ξ)(1/2 − 0)，
  即 f'(ξ) = 2f(1/2)。
在 [1/2, 1] 上用拉格朗日：
  存在 η ∈ (1/2, 1)，f(1) − f(1/2) = f'(η)(1 − 1/2)，
  即 f'(η) = 2[1 − f(1/2)]。
两式相加：
  f'(ξ) + f'(η) = 2f(1/2) + 2 − 2f(1/2) = 2。
而 ξ ∈ (0, 1/2)、η ∈ (1/2, 1)，所以 ξ ≠ η。
证毕。
```

**这个构造的关键是"中点"。**

为什么取 1/2？因为结论要的是 f'(ξ) + f'(η) = 2，而 2 正好是把 [0,1] 分成两半后，两个斜率之和。

如果把区间分成 [0, 1/3] 和 [1/3, 1]，两个斜率会带不同的权重，凑不出 2。

所以**双中值题的切分点，是由结论里的系数倒推出来的。**

### 9.6 证明题：导函数有零点

```text
题：设 f 在 [0, 2] 上连续，在 (0, 2) 内可导，且 f(0) = f(1) = f(2) = 0。
    证明在 (0, 2) 内至少存在两点使 f'(x) = 0。
```

```text
证：在 [0, 1] 上用罗尔（f(0) = f(1) = 0），
  存在 ξ₁ ∈ (0, 1)，f'(ξ₁) = 0。
在 [1, 2] 上用罗尔（f(1) = f(2) = 0），
  存在 ξ₂ ∈ (1, 2)，f'(ξ₂) = 0。
因为 ξ₁ < 1 < ξ₂，所以 ξ₁ ≠ ξ₂，是两点。
证毕。
```

**这类题的规律：函数有几个零点，导数就至少有几个零点，具体做法是相邻零点配对用罗尔。**

三个零点配两次罗尔，得两个导数零点；n 个零点配 n − 1 次，得 n − 1 个。

这个结论在 05 篇判断"方程有几个实根"时会反过来用。

## 10. 构造辅助函数的五种套路

中值定理证明题的难点只有一个：辅助函数怎么想出来的。

下面五套模板覆盖数一的绝大多数情况。

总原则先记住：

```text
把要证的结论整理成"某个函数 F 的导数 = 0"的形状，那个 F 就是辅助函数。
```

### 10.1 套路一：结论是 f'(ξ) = k

```text
要证：f'(ξ) = k（k 是常数）
辅助函数：F(x) = f(x) − kx
理由：F'(x) = f'(x) − k，所以 F'(ξ) = 0 就是 f'(ξ) = k。
```

例：

```text
题：设 f 在 [0, 1] 上连续，在 (0, 1) 内可导，f(0) = 0，f(1) = 1。
    证明存在 ξ，使 f'(ξ) = 2ξ。
```

```text
这里 k 不是常数，是 2x，所以不能直接套 f − kx。
把结论移项：f'(ξ) − 2ξ = 0。
找 F 使 F' = f'(x) − 2x。把 f'(x) 还原成 f(x)，把 2x 积回 x²，就得到：
F(x) = f(x) − x²，则 F'(x) = f'(x) − 2x。
验证端点：F(0) = f(0) − 0 = 0，F(1) = f(1) − 1 = 0。
等高，罗尔给出 ξ 使 F'(ξ) = 0，即 f'(ξ) = 2ξ。证毕。
```

**注意"f'(ξ) − 2ξ = 0"的积分是 f(x) − x²。**

所以套路一的完整版是：**把结论里的 f'(x) 换成 f(x)，把其他项积分，就是 F。**

### 10.2 套路二：结论是 f'(ξ) + f(ξ) = 0

```text
辅助函数：F(x) = e^x · f(x)
理由：F'(x) = e^x f(x) + e^x f'(x) = e^x [f(x) + f'(x)]
     e^x 永远不为 0，所以 F'(ξ) = 0 ⇔ f'(ξ) + f(ξ) = 0。
```

例：

```text
题：设 f 在 [0, 1] 上连续，在 (0, 1) 内可导，f(0) = f(1) = 0。
    证明存在 ξ ∈ (0, 1)，使 f'(ξ) + f(ξ) = 0。
```

```text
证：令 F(x) = e^x f(x)。
F 在 [0, 1] 上连续、在 (0, 1) 内可导。
F(0) = e⁰ f(0) = 0，F(1) = e¹ f(1) = 0，等高。
由罗尔，存在 ξ ∈ (0, 1)，F'(ξ) = 0。
而 F'(ξ) = e^ξ[f'(ξ) + f(ξ)]，e^ξ ≠ 0，
所以 f'(ξ) + f(ξ) = 0。证毕。
```

**为什么想到乘 e^x？**

因为要证 f' + f = 0，而 (e^x f)' = e^x(f' + f)。

那个 e^x 是"积分因子"，和微分方程里的做法完全一样（19 篇会再遇到）。

记忆口诀：**看到 f' + f，就乘 e^x；看到 f' − f，就乘 e^(−x)。**

### 10.3 套路三：结论是 ξf'(ξ) + f(ξ) = 0

```text
辅助函数：F(x) = x · f(x)
理由：F'(x) = f(x) + x f'(x)，正好是结论的左边。
```

例：

```text
题：设 f 在 [0, 1] 上连续，在 (0, 1) 内可导，f(1) = 0。
    证明存在 ξ ∈ (0, 1)，使 ξ f'(ξ) + f(ξ) = 0。
```

```text
证：令 F(x) = x f(x)。
F(0) = 0 · f(0) = 0，F(1) = 1 · f(1) = 0，等高。
由罗尔，存在 ξ ∈ (0, 1)，F'(ξ) = 0，
即 f(ξ) + ξ f'(ξ) = 0。证毕。
```

注意这里只用了 f(1) = 0，f(0) 的值不需要给，因为 x = 0 这个因子自动把 F(0) 压成 0。

### 10.4 套路四：结论是两个函数的交叉乘积

```text
要证：f'(ξ) g(ξ) − f(ξ) g'(ξ) = 0
辅助函数：F(x) = f(x)/g(x)
理由：F'(x) = [f'g − fg']/g²，分母不为 0 时，F' = 0 ⇔ 分子 = 0。
```

例：

```text
题：设 f、g 在 [a, b] 上连续，在 (a, b) 内可导，g(x) ≠ 0，
    且 f(a) = f(b) = 0。证明存在 ξ，使 f'(ξ) g(ξ) − f(ξ) g'(ξ) = 0。
```

```text
证：令 F(x) = f(x)/g(x)（g ≠ 0，所以 F 有意义）。
F(a) = 0/g(a) = 0，F(b) = 0/g(b) = 0，等高。
由罗尔，F'(ξ) = 0，即 [f'(ξ)g(ξ) − f(ξ)g'(ξ)]/g²(ξ) = 0。
分母非零，所以分子为 0。证毕。
```

**这类题也可以不构造商，直接对 f/g 用罗尔；**

关键是看结论里 f 与 g 是不是"交叉相乘再相减"的形状。

是，就用商。

### 10.5 套路五：结论含 f(b) − f(a)

```text
不需要构造，直接用拉格朗日或柯西。
```

例：结论是"存在 ξ，使 f'(ξ) = [f(b) − f(a)]/(b − a)"，那就是拉格朗日本身。

例：结论是"存在 ξ，使 [f(b) − f(a)]/[g(b) − g(a)] = f'(ξ)/g'(ξ)"，那就是柯西本身。

**这一类反而是最简单的：认出结论的形状，直接报定理名字。**

### 10.6 一张对照表

```text
结论的形状                        辅助函数 F(x)
f'(ξ) = 0                         f(x)（直接罗尔）
f'(ξ) − k = 0                     f(x) − kx
f'(ξ) − 2ξ = 0                    f(x) − x²
f'(ξ) + f(ξ) = 0                  e^x f(x)
f'(ξ) − f(ξ) = 0                  e^(−x) f(x)
ξ f'(ξ) + f(ξ) = 0                x f(x)
ξ f'(ξ) − f(ξ) = 0                f(x)/x
f'g − fg' = 0                     f(x)/g(x)
含 [f(b) − f(a)]/(b − a)          不构造，用拉格朗日
含 [f(b) − f(a)]/[g(b) − g(a)]    不构造，用柯西
```

**背这张表比背定理本身更有用。**

因为考试给的是结论，你要的是辅助函数，中间那一步就是查表。

## 11. 常见错误

**错误一：罗尔定理不验证 f(a) = f(b)。**

```text
错：f(x) = x 在 [0, 1] 上连续可导，所以存在 ξ 使 f'(ξ) = 0。
对：f(0) = 0 ≠ 1 = f(1)，等高条件不满足，定理不能用（事实上 f' ≡ 1）。
```

**错误二：把 ξ 写成闭区间。**

```text
错：存在 ξ ∈ [a, b]，f'(ξ) = 0
对：存在 ξ ∈ (a, b)
```

端点处只有单侧信息，推不出导数为 0。

**错误三：把"至少一个"说成"唯一一个"。**

罗尔定理只说存在，9.1 节的例子就有两个 ξ。

要说唯一，得再加条件（比如 f' 严格单调）。

**错误四：用中值定理不交代"连续、可导"。**

解答题里这三句话是给分点：

```text
"f 在 [a, b] 上连续"
"f 在 (a, b) 内可导"
"由拉格朗日中值定理"
```

少写第一句，逻辑链就断了。

**错误五：洛必达用于非未定式。**

```text
错：lim(x→1) (x² + 1)/(x + 1) 用洛必达得 2x/1 = 2。
对：直接代入得 2/2 = 1。
```

**错误六：洛必达循环还硬用。**

```text
lim(x→∞) x/√(x² + 1)
用一次洛必达得 √(x²+1)/x，形状没变，再用一次又回去。
正确做法：分子分母同除以 x，得 1/√(1 + 1/x²) → 1。
```

**错误七：泰勒展开阶数不够。**

```text
错：求 lim(x→0)(e^x − 1 − x)/x²，把 e^x 展开成 1 + x + o(x)，
    得 o(x)/x²，判不出来。
对：必须展开到 x²：e^x = 1 + x + x²/2 + o(x²)，得 1/2。
```

判断标准：**分母是几阶，分子就要展开到几阶。**

**错误八：不等式放缩方向反了。**

要证 f(b) − f(a) < b − a，就得让 f'(ξ) < 1。

如果估成 f'(ξ) < 2，什么也证不出来。

**错误九：双中值题用同一个点。**

结论要求 ξ ≠ η，所以必须在两个不相交的子区间上各取一次。

取完要说明"ξ ∈ (0, 1/2)、η ∈ (1/2, 1)，故不同"。

## 12. 数一怎么考

```text
选择/填空：
  1. 洛必达求极限（0/0、∞/∞、1^∞ 转化后）。
  2. 泰勒展开求极限、判无穷小阶。
  3. 判断某函数在给定区间上是否满足中值定理的条件。
解答题：
  4. 证明存在 ξ 满足某等式（构造辅助函数）。
  5. 用中值定理证不等式。
  6. 证明导函数零点个数、方程根的个数。
  7. 双中值问题。
```

### 12.1 例题：泰勒求极限

```text
题：求 lim(x→0) (tan x − x)/x³。
```

```text
展开：tan x = x + x³/3 + o(x³)。
所以 tan x − x = x³/3 + o(x³)。
原式 = lim [x³/3 + o(x³)]/x³ = 1/3。
答案：1/3。
```

如果用洛必达：

```text
第一次：(sec²x − 1)/(3x²) = tan²x/(3x²)。
再用等价替换 tan x ~ x，得 x²/(3x²) = 1/3。
```

两条路都对，但泰勒更短。

**数一的时间分配上，看到 tan、sin、e^x、ln(1+x) 的差式，优先想泰勒。**

### 12.2 例题：构造辅助函数

```text
题：设 f 在 [0, 1] 上连续，在 (0, 1) 内可导，f(0) = 0，f(1) = 1。
    证明存在 ξ ∈ (0, 1)，使 f'(ξ) = 2ξ。
```

```text
证：令 F(x) = f(x) − x²。
F 在 [0, 1] 上连续、在 (0, 1) 内可导。
F(0) = 0 − 0 = 0，F(1) = 1 − 1 = 0，等高。
由罗尔定理，存在 ξ ∈ (0, 1)，F'(ξ) = 0。
而 F'(x) = f'(x) − 2x，所以 f'(ξ) = 2ξ。证毕。
```

**这道题的信号：结论里 f'(ξ) 后面跟着一个具体的 x 表达式。**

套路一是"把 f' 还原成 f，把其余项积分"，正好对上。

### 12.3 例题：证明导函数零点

```text
题：设 f 在 [0, 3] 上连续，在 (0, 3) 内可导，f(0) = f(1) = f(3) = 0。
    证明 f'(x) 在 (0, 3) 内至少有两个零点。
```

```text
证：
在 [0, 1] 上用罗尔：存在 ξ₁ ∈ (0, 1)，f'(ξ₁) = 0。
在 [1, 3] 上用罗尔：存在 ξ₂ ∈ (1, 3)，f'(ξ₂) = 0。
ξ₁ < 1 < ξ₂，故两点不同，至少两个零点。证毕。
```

### 12.4 例题：洛必达与等价替换混用

```text
题：求 lim(x→0) (e^x − 1 − x)/(x − sin x)。
```

```text
分子：e^x − 1 − x = x²/2 + o(x²)，二阶。
分母：x − sin x = x³/6 + o(x³)，三阶。
两者阶数不同，直接比会得到 ∞？不对，要看清：
分子是二阶无穷小，分母是三阶无穷小，比值 = (x²/2)/(x³/6) = 3/x → ∞。
答案：+∞（极限不存在，是无穷大）。
```

**这道题的意义是提醒：先判阶，再决定要不要洛必达。**

阶数不同的时候，答案往往是 0 或 ∞，不需要复杂计算。

### 自检三问

**第一问：罗尔定理的三个条件，各去掉一个，结论会怎样？**

答：都会失效，各有反例。

去掉连续：f(x) = x（0 ≤ x < 1），f(1) = 0，在 [0, 1] 上 f' ≡ 1，没有零点。

去掉可导：f(x) = |x| 在 [−1, 1] 上，f(−1) = f(1) = 1，但 f' 只有 ±1，没有零点。

去掉等高：f(x) = x 在 [0, 1] 上，f(0) ≠ f(1)，f' ≡ 1。

**第二问：拉格朗日定理的结论里，ξ 为什么不能取端点？**

答：因为端点只有单侧信息。

导数在端点处要么没定义，要么只是单侧导数，无法保证"切线平行于割线"。

而且定理的条件只要求开区间内可导，端点的可导性根本没有假设。

**第三问：洛必达法则算不出结果，是否说明原极限不存在？**

答：不能这么说。

洛必达只是充分条件：导数之比的极限存在时，可以推出原极限等于它。

反过来不成立。例：lim(x→∞)(x + sin x)/x = 1，但导数之比 (1 + cos x)/1 没有极限。

遇到洛必达失灵，要换等价替换、泰勒，或者直接除以最高次幂。

## 14. 小结与下一篇

这一篇压成七句话：

```text
1. 费马引理：内点极值 + 可导 ⇒ 导数为 0。
2. 罗尔定理：连续 + 可导 + 两端等高 ⇒ 中间有水平切线。
3. 拉格朗日：平均变化率 = 某点瞬时变化率。
4. 柯西：把拉格朗日里的 x 换成另一个函数 g。
5. 泰勒：把"一次逼近"推到"n 次逼近"，余项用 ξ 表示。
6. 洛必达是柯西定理的推论，只能用于 0/0 与 ∞/∞。
7. 证明题的核心动作：把结论整理成 F'(ξ) = 0，再找出 F。
```

一张必须能画出来的关系图：

```text
费马引理
   ↓（最值定理）
罗尔定理
   ↓（减去割线）
拉格朗日定理 ──→ 洛必达法则（配柯西）
   ↓（换分母）
柯西定理
   ↓（升阶）
泰勒定理
```

一张必须能背出来的辅助函数表：

```text
f' = 0        → f
f' + f = 0    → e^x f
f' − f = 0    → e^(−x) f
xf' + f = 0   → x f
f'g − fg' = 0 → f/g
```

它要回答：

```text
为什么 f' > 0 就单调递增？（答案就在这一篇的推论二）

拐点怎么找？它和极值点有什么区别？
曲线什么时候有渐近线？
```
