> **读这篇之前，你只需要知道**：定积分 ∫ₐᵇ f(x) dx 算的是曲线下的面积，它要求区间 [a, b] 长度有限，且函数在这个区间上不冲到无穷；牛顿-莱布尼茨公式说，这个面积等于原函数在两端相减，即 F(b) - F(a)。
> **这篇讲什么**：区间可以无限长，函数也可以在某个点冲到无穷，面积照样可能是一个有限的数；判断它"收得住"还是"撑爆了"，就是这一篇。
> **一个类比**：往一个无限长、越来越窄的漏斗里倒水，漏斗永远倒不满，可装得下的水也许只有一升——关键看它窄得有多快。

先看一个图形。

曲线 y = 1/x²，从 x = 1 开始，一直往右延伸，与 x 轴围出一块区域。

这块区域向右无限长。

面积是多少？

直觉会说：无限长，当然是无穷大。

答案却是：

```text
面积 = 1
```

一块无限长的区域，面积只有一个单位。

原因是它的高度掉得太快：

```text
x = 1   高 1
x = 2   高 1/4
x = 3   高 1/9
x = 10  高 1/100
```

长度在长，高度在塌，两者打平之后，面积停在了 1。

**"无限"不一定等于"无限大"。**

这句话在 00 篇出现过一次，讲的是级数。

这一篇讲的是它的积分版本。

## 1. 为什么需要它（不给会怎样）

没有这一节，你会以为"积分"这两个字只有一个意思：在有限区间上，对有界函数求面积。

一旦题目里出现无穷或者断裂，你就没有语言描述它。

具体会卡在四个地方。

**第一处，定积分定义不认这种区间。**

定积分的第一条要求是：区间长度有限。

```text
∫₁^∞ (1/x²) dx 这个写法，按定积分定义根本不存在。
```

上限不是一个数，是一个符号。

符号不能直接代进 F(b) - F(a)。

**第二处，函数可能在某个点没有界。**

```text
∫₀¹ (1/√x) dx
```

x 从右边逼近 0 时，1/√x 越来越大，冲向无穷。

在 x = 0 这一点，函数没有值。

这种点叫瑕点，后面第 5 节细讲。

定积分要求被积函数有界，这一条也不满足。

**第三处，后面很多工具要靠它。**

概率论里，连续型随机变量的密度函数要在整条实轴上积分，并且结果等于 1。

```text
∫_{-∞}^{+∞} f(x) dx = 1
```

没有反常积分，这句话写不出来。

数一里的 Γ 函数、某些傅里叶系数、拉普拉斯变换，定义也都是反常积分。

**第四处，考试直接考。**

数一每年都有一道关于敛散性的选择或填空。

题目不长，但四个选项里通常有三个是"看起来像对的"。

判敛的本事，只能在这一篇练。

所以这一篇不是"定积分的补充"，它是把定积分的适用范围从"有限、有界"扩到"无限、无界"的一次改造。

改造的工具只有一个：极限。

**先看一个"不给会怎样"的具体场景。**

一根无限长的杆，线密度按 1/x² 衰减。

总质量是多少？

```text
总质量 = ∫₁^∞ (1/x²) dx
```

如果拒绝定义这个积分，你只能说"杆无限长，质量无限大"。

但物理直觉告诉你，密度掉得这么快，质量应该是一个有限的数。

计算结果正是 1。

**这就是这一章存在的理由：让"无限"变得可以计算。**

**再补一个思维上的坎：为什么不能直接"把区间切成无穷多份"。**

定积分的原始定义是：把 [a, b] 分成 n 份，求和，让 n → ∞。

可如果区间本身无限长，第一步就做不了：怎么切，每一份还是无限长。

所以必须先固定一个有限的 [a, b]，让积分有意义，再让 b 长大。

顺序不能反。

```text
先有限，再无限；先截断，再取极限。
```

这句话是这一章全部定义的骨架。

后面瑕积分也是同一个套路：先把坏点挖掉，让积分有意义，再让洞缩小。

**再看一处：物理里的"无限"全是它。**

无限长杆的质量、无限大平板的电场、点电荷附近的能量，写出来都是反常积分。

物理不会因为区间无限就停下，数学必须跟上。

**两类合称。**

无穷限的、带瑕点的，教材统一叫反常积分，英文 improper integral，有的书译作广义积分。

名字不同，做法是同一套：截断，再取极限。

## 2. 最小模型：把无穷切成有限

没有这个模型，无穷就是一个无法下手的东西。

有了它，无穷变成一个可以一步步逼近的过程。

先把符号读出来：

```text
∫ₐ^∞ f(x) dx
```

**∫**：读"积分号"，来自拉丁文 summa 的首字母，意思是"累加"。

**a**：积分下限，一个确定的数，是起点。

**∞**：读"无穷大"，注意它不是数，是一个"越来越大"的方向。

**∫ₐ^∞**：整体读作"从 a 到正无穷的积分"。

**f(x)**：被积函数，每一处的高度。

**dx**：读"d x"，表示"沿着 x 方向取一个无穷小的宽度"。

这个式子的意思，不是"从 a 一直加到无穷"。

而是：

```text
先积到某个有限的 b，再让 b 往无穷跑。
```

写成定义：

```text
∫ₐ^∞ f(x) dx = lim_{b→+∞} ∫ₐ^b f(x) dx
```

**算什么**：把上限换成一个普通的数 b，算一个正常的定积分，得到一个只与 b 有关的数；再让 b 越来越大，看这个数有没有极限。

**逐符号**：lim 读"极限"；b→+∞ 读"b 趋向正无穷"；∫ₐ^b 是一个正常的定积分，可以用牛顿-莱布尼茨公式算出来。

**代数字**：取 f(x) = 1/x²，a = 1，先算 ∫₁^b x⁻² dx。

**适用条件**：f 在每一个有限区间 [a, b] 上都可积（连续就够），并且上面那个极限存在且是一个有限数。

**为什么不能直接把 ∞ 代进去。**

因为 ∞ 不是数。

F(∞) - F(a) 这种写法只是记号的简写，它背后必须有一个极限过程在支撑。

考试时如果只写 F(∞)，阅卷会认为你没理解定义，扣分。

正确写法始终是：

```text
lim_{b→+∞} [F(x)]ₐ^b
```

三种结局，名字要先定好：

```text
极限存在且有限  →  收敛，这个极限值就叫反常积分的值
极限是 +∞ 或 -∞ →  发散
极限不存在（振荡）→  发散
```

注意第三条：振荡也算发散。

比如 ∫₁^∞ sin x dx，原函数是 -cos x，在 1 与 -1 之间来回摆，没有极限。

它不收敛，也不等于无穷，就是不收敛。

**图形上怎么看。**

```text
y
│╲
│ ╲  面积逐步累积
│  ╲╲
│   ╲ ╲╲
│    ╲   ╲╲╲
└─────┴──────────── x
      a        b → ∞
```

每一个 b 都截出有限的一块，面积是一个确定的数。

b 往右挪，这块面积要么停住（收敛），要么一路涨（发散），要么来回摆（振荡发散）。

**判别流程先给出来，后面逐节填肉。**

```text
第一步：找坏点（无穷限？瑕点？）
第二步：按坏点把积分拆段
第三步：每段和 1/x^p 比阶
第四步：对 p 规则，下结论
第五步：要值就找原函数取极限
```

## 3. 算一遍：∫₁^∞ dx/x²

没有这道手算，定义就只是一行符号。

一步一步来。

**第一步，写出有限截断。**

```text
∫₁^b x⁻² dx
```

**第二步，找原函数。**

x⁻² 的原函数是 -x⁻¹，也就是 -1/x。

**第三步，代上下限。**

```text
∫₁^b x⁻² dx = [-1/x]₁^b = (-1/b) - (-1/1) = 1 - 1/b
```

**第四步，取极限。**

```text
lim_{b→+∞} (1 - 1/b) = 1 - 0 = 1
```

所以：

```text
∫₁^∞ dx/x² = 1
```

收敛，值是 1。

**换一个函数，只把指数从 2 改成 1。**

```text
∫₁^b dx/x = [ln x]₁^b = ln b - ln 1 = ln b
```

b 越大，ln b 越大，没有上界。

```text
lim_{b→+∞} ln b = +∞
```

所以：

```text
∫₁^∞ dx/x 发散
```

两个函数长得很像，一个收敛一个发散。

差别只在"高度掉得快不快"。

用一张表看得更清楚：

```text
b         ∫₁^b 1/x²      ∫₁^b 1/x
10        0.9            2.303
100       0.99           4.605
1000      0.999          6.908
10000     0.9999         9.210
```

第一列在往 1 靠，第二列一直在涨。

这就是"收敛"和"发散"最朴素的区别：**前者有天花板，后者没有。**

**再补一道，指数函数。**

```text
∫₀^∞ e^{-x} dx
```

截断：

```text
∫₀^b e^{-x} dx = [-e^{-x}]₀^b = -e^{-b} + 1
```

取极限：

```text
lim_{b→∞} (1 - e^{-b}) = 1 - 0 = 1
```

收敛，值是 1。

这道题的结果很直观：e^{-x} 从 1 开始往下掉，总面积为 1。

**注意截断点的选择不影响敛散性。**

从 0 截还是从 1 截，从 100 截还是从 1000 截，都只是把 b 换成一个别的起点。

差别只在算出来的值上，而且差的是一个常数的面积。

所以判敛时不必纠结"从哪里开始截"，只关心"尾巴上掉得够不够快"。

## 4. 拆开看：无穷限积分的三种写法

没有这一节，你会把"两端都无穷"当成"一端无穷"来做，答案对不上。

无穷限积分只有三种形状。

**第一种，上限无穷。**

```text
∫ₐ^∞ f(x) dx = lim_{b→+∞} ∫ₐ^b f(x) dx
```

**第二种，下限负无穷。**

```text
∫_{-∞}^b f(x) dx = lim_{a→-∞} ∫ₐ^b f(x) dx
```

**第三种，两端都无穷。**

```text
∫_{-∞}^{+∞} f(x) dx
```

第三种不能直接写成一个极限。

必须先挑一个分界点 c，拆成两段：

```text
∫_{-∞}^{+∞} f(x) dx = ∫_{-∞}^c f(x) dx + ∫_c^{+∞} f(x) dx
```

然后**两段都收敛，整体才收敛**。

只要有一段发散，整体就是发散。

c 取哪里都行，通常取 0，因为算起来省事。

**这里有一个数一很喜欢设的坑。**

有人图省事，写成：

```text
lim_{b→+∞} ∫_{-b}^{b} f(x) dx
```

这叫柯西主值，不是反常积分。

两者只在一种情况下相同：函数是偶函数并且收敛。

差别用例子看最清楚。

取 f(x) = x。

```text
∫_{-b}^{b} x dx = 0，对任何 b 都成立
```

所以主值等于 0。

但拆开算：

```text
∫₀^{+∞} x dx = +∞
∫_{-∞}^0 x dx = -∞
```

两段都发散。

按定义，∫_{-∞}^{+∞} x dx 发散，没有值。

**结论：左右两半必须各自独立地取极限，不能同步对称地跑。**

为什么？因为"两段都收敛"要求的是任意方式趋近都行，而对称跑只是其中一种方式。

一种方式有极限，不代表所有方式都有。

**为什么数学上不把主值直接当定义。**

因为一个量要能用，必须与"怎么逼近"无关。

如果定义成主值，换一种趋近方式就能算出另一个数，这个量就不唯一，后面所有等式都不稳。

拆开判，虽然麻烦，但保证结果只由函数本身决定。

**正确的例子也要看一个。**

```text
∫_{-∞}^{+∞} dx/(1+x²)
```

取 c = 0 拆开：

```text
∫₀^{+∞} dx/(1+x²) = lim_{b→∞} [arctan x]₀^b = π/2 - 0 = π/2
∫_{-∞}^0 dx/(1+x²) = lim_{a→-∞} [arctan x]_a^0 = 0 - (-π/2) = π/2
```

两段都收敛，所以整体收敛，值为 π。

这个函数的图像是钟形，左右对称，面积是 π。

它说明：**拆开不麻烦，拆开才安全。**

## 5. 拆开看：瑕点与瑕积分

没有这一节，你只会处理"区间无限长"，遇到"函数冲到无穷"就无从下手。

先认符号。

```text
瑕点
```

读作"xiá 点"，指函数在这个点附近没有界、冲向无穷的点。

"瑕"是玉上的斑点，意思是这一点有毛病。

函数在瑕点处可能没有定义，也可能有定义但附近无界。

两种都算瑕点。

**例子一。**

```text
f(x) = 1/√x，区间 (0, 1]
```

x → 0⁺ 时 f(x) → +∞，所以 x = 0 是瑕点。

**例子二。**

```text
f(x) = 1/(x - 1)²，区间 [0, 2]
```

x → 1 时 f(x) → +∞，x = 1 是瑕点，而且它在区间内部，不在端点。

**例子三。**

```text
f(x) = ln x，区间 (0, 1]
```

x → 0⁺ 时 ln x → -∞，x = 0 是瑕点。

注意 ln x 在 0 附近是负的、慢慢往下掉，不像 1/√x 那样猛烈上冲。

两者都算无界，但一个积分收敛，一个也收敛，后面的 p 规则会说清差别。

瑕积分的定义，和无穷限是同一个套路：**把坏点挖掉，再让挖掉的洞缩小。**

瑕点在左端点 a 时：

```text
∫ₐ^b f(x) dx = lim_{ε→0⁺} ∫_{a+ε}^b f(x) dx
```

**算什么**：从 a 右边一点点开始积，避开那个坏点；然后让这个"一点点"越来越小，看积分值有没有极限。

**逐符号**：ε 读"艾普西龙"，是一个很小的正数；ε→0⁺ 表示从右边趋近 0；a+ε 是临时的下限。

**代数字**：f(x) = 1/√x，a = 0，b = 1。

**适用条件**：f 在 [a+ε, b] 上可积，并且极限存在且有限。

瑕点在右端点 b 时，把上限换成 b-ε。

瑕点在内部 c 时，必须拆成两段：

```text
∫ₐ^b f dx = ∫ₐ^c f dx + ∫_c^b f dx
```

同样，两段都收敛才算收敛。

**一个必须先做的动作：找瑕点。**

拿到一个积分，先扫一遍区间，看有没有让分母为零、让对数趋于负无穷、让根号内为零的点。

漏掉一个瑕点，后面全错。

**找瑕点的清单，照着扫三遍。**

```text
第一遍看分母：哪里为 0，哪里就是嫌疑点
第二遍看对数：ln(x - c) 在 c 处冲向负无穷
第三遍看幂函数：x^α 在 α < 0 时于 0 处冲向无穷
```

还要看区间端点。

端点 a 处的单侧极限是无穷，a 就是瑕点。

内部点 c 处左右两侧都冲向无穷，c 也是瑕点，而且必须拆两段。

**一个容易骗人的例子。**

```text
∫₀¹ dx/(x² - x)
```

分母 x(x-1) 在 x = 0 和 x = 1 同时为 0。

两个端点都是瑕点，需要拆成 ∫₀^{1/2} 与 ∫_{1/2}^1 两段分别判。

只看到一个，就会得出错误结论。

## 6. 算一遍：四道瑕积分

没有这两道手算，瑕积分的定义就落不了地。

**第一道。**

```text
∫₀¹ dx/√x
```

x = 0 是瑕点。

第一步，挖洞：

```text
∫_ε¹ x^(-1/2) dx
```

第二步，找原函数：

```text
x^(-1/2) 的原函数是 2x^(1/2)，即 2√x
```

第三步，代上下限：

```text
[2√x]_ε¹ = 2√1 - 2√ε = 2 - 2√ε
```

第四步，取极限：

```text
lim_{ε→0⁺} (2 - 2√ε) = 2 - 0 = 2
```

所以：

```text
∫₀¹ dx/√x = 2
```

收敛，值是 2。

注意这个结果不奇怪：函数在 0 附近冲得很高，但冲高的范围极窄，面积仍然是有限的。

**第二道，只把根号去掉。**

```text
∫₀¹ dx/x
```

第一步，挖洞：

```text
∫_ε¹ dx/x = [ln x]_ε¹ = ln 1 - ln ε = -ln ε
```

第二步，取极限：

```text
lim_{ε→0⁺} (-ln ε) = +∞
```

所以发散。

同样是"在 0 处冲到无穷"，1/√x 收敛，1/x 发散。

**第三道，带对数的一道。**

```text
∫₀¹ ln x dx
```

瑕点在 0。

用分部积分，取 u = ln x，dv = dx，则 du = dx/x，v = x：

```text
∫ ln x dx = x ln x - ∫ x · (1/x) dx = x ln x - x
```

代上下限：

```text
[x ln x - x]_ε¹ = (0 - 1) - (ε ln ε - ε) = -1 - ε ln ε + ε
```

关键在 ε ln ε 这一项。

ε → 0⁺ 时，ε 趋于 0，ln ε 趋于 -∞，是"0 乘无穷"型。

用洛必达：

```text
lim_{ε→0⁺} ε ln ε = lim_{ε→0⁺} (ln ε)/(1/ε) = lim (1/ε)/(-1/ε²) = lim (-ε) = 0
```

所以：

```text
∫₀¹ ln x dx = -1 - 0 + 0 = -1
```

收敛，值是 -1。

三道题放在一起，规律已经露头：

```text
1/√x  收敛
1/x   发散
ln x  收敛
```

判别的标准，下一节给出来。

**第四道，瑕点在右端点。**

```text
∫₀¹ dx/√(1-x²)
```

x → 1⁻ 时分母趋于 0，所以 x = 1 是瑕点。

原函数是 arcsin x：

```text
∫₀^{1-ε} dx/√(1-x²) = [arcsin x]₀^{1-ε} = arcsin(1-ε) - 0
```

取极限：

```text
lim_{ε→0⁺} arcsin(1-ε) = arcsin 1 = π/2
```

收敛，值是 π/2。

**这道题值得记住结论**：arcsin 1 = π/2。

它的原函数是反三角函数，积分值是弧长意义下的特殊角，不是面积。

后面算 ∫₀¹ √(1-x²) dx = π/4 时，会用到同一个特殊值。

## 7. p 积分：一张必须背的表

没有这张表，每道判敛题都要从头算一遍极限，考场上时间不够。

所谓 p 积分，就是下面两个家族：

```text
无穷限：∫₁^∞ dx/x^p
瑕积分：∫₀¹ dx/x^p
```

p 是一个常数。

先手算第一个家族。

**p ≠ 1 时。**

```text
∫₁^b x^(-p) dx = [x^(1-p)/(1-p)]₁^b = (b^(1-p) - 1)/(1-p)
```

现在看 b → +∞。

b^(1-p) 的走向，只由指数 1-p 的正负决定：

```text
1 - p < 0，即 p > 1  →  b^(1-p) → 0  →  极限 = (0 - 1)/(1-p) = 1/(p-1)
1 - p > 0，即 p < 1  →  b^(1-p) → +∞ →  极限 = +∞
```

**p = 1 时**，前面已经算过：

```text
∫₁^b dx/x = ln b → +∞
```

合并：

```text
∫₁^∞ dx/x^p：p > 1 收敛，值为 1/(p-1)；p ≤ 1 发散
```

再手算第二个家族。

**p ≠ 1 时。**

```text
∫_ε¹ x^(-p) dx = [x^(1-p)/(1-p)]_ε¹ = (1 - ε^(1-p))/(1-p)
```

看 ε → 0⁺。

```text
1 - p > 0，即 p < 1  →  ε^(1-p) → 0  →  极限 = 1/(1-p)
1 - p < 0，即 p > 1  →  ε^(1-p) → +∞ →  极限 = +∞
```

**p = 1 时**，前面算过，发散。

合并：

```text
∫₀¹ dx/x^p：p < 1 收敛，值为 1/(1-p)；p ≥ 1 发散
```

把两条并排：

```text
无穷限（尾巴长）：p > 1 收敛
瑕积分（尖峰高）：p < 1 收敛
```

**这两条的方向是相反的。**

原因是缺口的形状不同。

无穷远处，1/x^p 慢悠悠地拖着，p 越大掉得越快，越容易收敛。

瑕点处，1/x^p 在零点附近冲得很猛，p 越大冲得越高，越容易发散。

记忆口诀：

```text
远要陡，近要缓
```

"远"指无穷远，要求 p 大；"近"指靠近瑕点，要求 p 小。

**还有一条常用的变体。**

```text
∫₂^∞ dx/(x · ln^p x)
```

做换元 t = ln x，dx = x dt，积分变成：

```text
∫_{ln 2}^∞ dt/t^p
```

这就是无穷限 p 积分。

所以：p > 1 收敛，p ≤ 1 发散。

这道变体是 p 积分和换元的结合，数一考过多次。

**再算一个具体的 p 积分值，练手。**

```text
∫₁^∞ dx/x^{3/2}
```

这里 p = 3/2 > 1，收敛，值按公式是：

```text
1/(p-1) = 1/(3/2 - 1) = 1/(1/2) = 2
```

用定义验证一遍：

```text
∫₁^b x^{-3/2} dx = [-2x^{-1/2}]₁^b = -2/√b + 2 → 2
```

两边一致。

**一个小小的记忆技巧。**

看到 ∫₁^∞，先问"指数比 1 大还是小"。

看到 ∫₀¹，先问"指数比 1 大还是小"，但结论要反过来。

两个问题一模一样，答案相反，这就是最容易错的地方。

## 8. 比较判别法：和谁比

没有这一节，遇到 1/(x³+1) 这种没法直接求原函数的被积式，你就只能干看着。

比较判别法的思路只有一句话：

```text
大的收敛，小的必收敛；小的发散，大的必发散。
```

前提是两个函数都非负。

**基本形式。**

设 0 ≤ f(x) ≤ g(x)，在 [a, +∞) 上成立。

```text
∫ₐ^∞ g dx 收敛  ⇒  ∫ₐ^∞ f dx 收敛
∫ₐ^∞ f dx 发散  ⇒  ∫ₐ^∞ g dx 发散
```

**极限形式，考场上更好用。**

设 f, g ≥ 0，且

```text
lim_{x→+∞} f(x)/g(x) = L
```

那么：

```text
0 < L < +∞：两者同时收敛或同时发散（同阶）
L = 0：g 收敛则 f 收敛（f 比 g 小得多）
L = +∞：g 发散则 f 发散（f 比 g 大得多）
```

**用什么当 g？**

几乎总是用 p 积分：

```text
g(x) = 1/x^p
```

因为它的敛散性已经背下来了。

具体做法叫"抓大头"：只看分子分母里增长最快的那一项。

**例一。**

```text
∫₁^∞ dx/(x³ + 1)
```

x 很大时，分母的主项是 x³，所以

```text
1/(x³+1) ~ 1/x³
```

p = 3 > 1，收敛。

严格写：0 < 1/(x³+1) < 1/x³，而 ∫₁^∞ dx/x³ 收敛，由比较法得收敛。

**例二。**

```text
∫₁^∞ (2 + sin x)/x² dx
```

分子在 1 到 3 之间，所以

```text
0 < (2 + sin x)/x² ≤ 3/x²
```

∫₁^∞ 3/x² dx 收敛，所以原积分收敛。

这类题的关键是：sin x 有界，别去算它的原函数。

**例三。**

```text
∫₁^∞ dx/(2x - 1)
```

x 很大时主项是 2x，所以和 1/x 同阶，p = 1，发散。

**例四，瑕点上的比较。**

```text
∫₀¹ dx/(x + x²)
```

x → 0⁺ 时，x² 比 x 小得多，主项是 x，所以

```text
1/(x+x²) ~ 1/x
```

p = 1，发散。

如果写成 1/(x + √x)，则主项是 √x，p = 1/2 < 1，收敛。

**例五，用等价无穷小。**

```text
∫₀¹ sin x / x² dx
```

x → 0⁺ 时 sin x ~ x，所以

```text
sin x / x² ~ x/x² = 1/x
```

p = 1，发散。

注意：这里不能用"sin x ≤ 1，所以被积式 ≤ 1/x²"去证收敛。

1/x² 在 (0,1] 上确实可积，但被积式是正的、并且比它大，上界给不出收敛结论。

**不等式方向必须对**：要证收敛，得找一个更大的、收敛的函数压住它；要证发散，得找一个更小的、发散的函数垫在下面。

方向搞反，是这一章最常见的失分点。

**例六，分子分母都带项。**

```text
∫₁^∞ (x + 1)/(x³ + 2) dx
```

分子的大头是 x，分母的大头是 x³，所以整体像 x/x³ = 1/x²。

p = 2 > 1，收敛。

**例七，瑕点上的等价无穷小。**

```text
∫₀^1 dx/sin x
```

x → 0⁺ 时 sin x ~ x，所以

```text
1/sin x ~ 1/x
```

p = 1 ≥ 1，发散。

**例八，对数出现在分母。**

```text
∫₂^∞ dx/(x ln²x)
```

这是第 7 节那条变体，p = 2 > 1，收敛。

如果把平方去掉，变成 ∫₂^∞ dx/(x ln x)，则发散。

对数因子只是"伴奏"，决定敛散的还是 x 的幂次。

**例九，被积式不是单调的。**

```text
∫₁^∞ (3 + cos x)/x² dx
```

cos x 在 -1 到 1 之间，分子在 2 到 4 之间，整体被 4/x² 压住，收敛。

遇到三角因子，先想"它有没有界"，而不是"它的原函数是什么"。

**瑕点上最常用的四个等价无穷小。**

```text
sin x ~ x          （x → 0）
1 - cos x ~ x²/2   （x → 0）
ln(1 + x) ~ x      （x → 0）
e^x - 1 ~ x        （x → 0）
```

判断时把 x 换成 x - c，就得到 c 附近的版本。

比如 x → 1 时 sin(x-1) ~ x - 1。

这四个替换，只在乘除结构里成立，加减结构要小心。

## 9. 常见错误

没有这一节，你会把会的题做错。

**错误一：两端无穷不拆，直接对称取极限。**

```text
错：∫_{-∞}^{+∞} x dx = lim_{b→∞} ∫_{-b}^{b} x dx = 0
```

正确做法是拆成两段，各自判，结论是发散。

**错误二：把"发散"说成"等于无穷"。**

发散的意思是极限不存在，不等于有一个值叫无穷。

答题时写"发散"或"不收敛"，不要写"= ∞"。

**错误三：p 规则记反。**

```text
错：∫₁^∞ dx/x^0.5 收敛（以为指数小就好）
对：p = 0.5 ≤ 1，发散
```

**错误四：漏找瑕点。**

```text
∫₀² dx/(x-1)²
```

瑕点在 x = 1，区间内部。

必须拆成 ∫₀¹ 与 ∫₁²，两段都发散，所以整体发散。

如果直接代原函数 -1/(x-1)，会算出 -1 - 1 = -2 这种荒唐结果。

**错误五：把瑕点和无穷限混在一起，只判一头。**

```text
∫₀^∞ dx/x²
```

x = 0 是瑕点，上限又是无穷。

要拆成 ∫₀¹ 与 ∫₁^∞ 两段。

第一段 p = 2 ≥ 1，发散。

所以整体发散，尽管第二段收敛。

**错误六：分部积分后忘了端点极限。**

```text
∫₀^∞ x e^{-x} dx
```

分部得到 [-x e^{-x}]₀^∞ + ∫₀^∞ e^{-x} dx。

第一项要单独算极限，b e^{-b} → 0，不能直接写 0 了事。

**错误七：把收敛的反常积分当成普通定积分，随意拆项。**

只有收敛时才允许拆成两个收敛的积分相加。

两个都发散的反常积分，不能相减。

**错误八：用比较法时不管符号。**

比较判别法的前提是被积函数非负。

如果 f(x) 会变号，正确的做法是先取绝对值，判 ∫|f| 是否收敛。

∫|f| 收敛叫绝对收敛，此时 ∫f 一定收敛。

∫|f| 发散而 ∫f 收敛，叫条件收敛，比如 ∫₁^∞ sin x / x dx。

符号一乱，大小关系就失效了。

**错误九：把无穷限积分和瑕积分当成两种无关的技术。**

它们其实是同一套动作：把一个"坏点"换成参数，算有限部分，再取极限。

无穷限的坏点在最右边，瑕积分的坏点在区间内部或端点上。

认清这一点，拆段的时候就不会乱。

**错误十：换元之后不换积分限。**

```text
∫₁^∞ dx/x²
```

令 x = 1/t，则 dx = -dt/t²，且

```text
dx/x² = (-dt/t²)·t² = -dt
```

再看端点：x = 1 对应 t = 1，x = +∞ 对应 t = 0⁺。

所以

```text
∫₁^∞ dx/x² = ∫₁^0 (-dt) = ∫₀¹ dt = 1
```

上下限从"1 到 ∞"变成"0 到 1"，中间还翻了一次方向。

漏改一个，答案就错。

**换元三件事：换被积式、换微分、换积分限。**

三件缺一不可。

## 10. 数一怎么考

没有这一节，你不知道练到什么程度算够。

数一在这一章只有三种出题方式。

**第一种，判敛选择或填空。**

题干给一个积分，四个选项问收敛还是发散。

例题：

```text
下列反常积分收敛的是：
A. ∫₁^∞ dx/√x
B. ∫₁^∞ dx/(x+1)
C. ∫₁^∞ dx/x³
D. ∫₀¹ dx/x
```

逐个判：

```text
A：p = 1/2 ≤ 1，发散
B：与 1/x 同阶，p = 1，发散
C：p = 3 > 1，收敛
D：瑕积分，p = 1 ≥ 1，发散
```

答案 C。

这类题的时间应该控制在四十秒以内：先认类型，再对 p，再比阶。

**第二种，计算。**

要求算出收敛积分的值。

例题：

```text
计算 ∫₀^∞ x e^{-x} dx
```

第一步，截断：

```text
∫₀^b x e^{-x} dx
```

第二步，分部积分，取 u = x，dv = e^{-x} dx，则 du = dx，v = -e^{-x}：

```text
∫ x e^{-x} dx = -x e^{-x} + ∫ e^{-x} dx = -x e^{-x} - e^{-x}
```

第三步，代上下限：

```text
[-x e^{-x} - e^{-x}]₀^b = (-b e^{-b} - e^{-b}) - (0 - 1) = 1 - b e^{-b} - e^{-b}
```

第四步，取极限：

```text
b e^{-b} → 0，e^{-b} → 0
所以值 = 1
```

这道题的两个易错点：一是 b e^{-b} 要单独说明趋于 0；二是别忘了下限代入会翻出 +1。

**第三种，含参数讨论。**

例题：

```text
讨论 ∫₁^∞ dx/x^p 的敛散性，p 为实常数。
```

答案就是第 7 节的表：

```text
p > 1 收敛，值 1/(p-1)
p ≤ 1 发散
```

写解答时要分 p = 1 与 p ≠ 1 两种情况，因为原函数的形式不同。

漏掉 p = 1，会丢一半分。

**第四种，瑕点上的分部积分。**

例题：

```text
计算 ∫₀¹ x ln x dx
```

瑕点在 0。

分部，取 u = ln x，dv = x dx，则 du = dx/x，v = x²/2：

```text
∫ x ln x dx = (x²/2) ln x - ∫ (x²/2)(1/x) dx = (x²/2) ln x - x²/4
```

代上下限，下限用 ε：

```text
[(x²/2) ln x - x²/4]_ε¹ = (0 - 1/4) - ((ε²/2) ln ε - ε²/4)
```

关键极限：

```text
lim_{ε→0⁺} ε² ln ε = 0
```

所以：

```text
∫₀¹ x ln x dx = -1/4 - 0 + 0 = -1/4
```

注意结果是负的。

ln x 在 (0,1) 上是负的，x 是正的，所以被积函数为负，面积为负，符合预期。

**分值与时间。**

```text
选择或填空：1 道，4 分
计算大题：偶尔单独出，10 分
判敛证明：极少单独出，更多作为二重积分、微分方程的一步
```

练的重点排序：

```text
第一，p 积分两条结论，必须条件反射
第二，抓大头比较，必须三十秒内定出 p
第三，瑕点必须找全
第四，分部积分的端点极限要会写
```

**答题模板，三行写完。**

```text
第一行：写出截断后的定积分，标明参数 b 或 ε
第二行：求原函数，代上下限，得到只含参数的式子
第三行：取极限，写"收敛，值为 …"或"发散"
```

判敛题不需要写原函数，只需要写比较对象和结论：

```text
因为 0 ≤ f(x) ≤ 1/x²，且 ∫₁^∞ dx/x² 收敛，所以原积分收敛。
```

一句话一分，关键在"比较对象选对"。

**时间分配。**

判敛题四十秒，计算题八分钟，含参讨论十分钟。

超过时间还没定出 p，说明抓大头抓错了，回头重看分母的最高次。

## 11. 和其他章节怎么连

没有这一节，这一章会变成孤立的判敛技巧。

**往回连：06 不定积分。**

反常积分的计算，最后一步永远是"找原函数"。

原函数找不出来，极限就写不下去。

所以 06 篇的基本积分表，在这里还要再用一遍。

**往回连：07 定积分。**

定义里的 ∫ₐ^b 就是普通定积分。

牛顿-莱布尼茨公式在这里照样用，只是代入的端点要先取极限。

一句话：反常积分 = 定积分 + 一个极限。

**往前连：16 数项级数。**

有一个工具叫积分判别法：

```text
Σ 1/n^p 与 ∫₁^∞ dx/x^p 同敛散
```

所以 p 级数在 p > 1 时收敛，和这一篇的结论是同一件事。

级数那一章会直接引用这里的表。

**横向连：13 三重积分与 12 二重积分。**

无界区域上的重积分，也靠"先截断再取极限"。

思想完全一样，只是维数变高。

**横向连：概率论。**

连续型随机变量的密度要满足

```text
∫_{-∞}^{+∞} f(x) dx = 1
```

正态分布的密度能积出 1，靠的就是 ∫_{-∞}^{+∞} e^{-x²} dx = √π 这个反常积分。

数一不考这个积分的计算，但要求你知道它收敛。

**一个整体视角。**

反常积分做的事，是把"有限"这个前提拿掉。

拿掉之后，原来所有结论都不再自动成立，必须重新用极限验证一遍。

这套"先截断、再取极限"的动作，在后面每一章都会再出现：无界区域的重积分、无界函数的拉普拉斯变换、发散级数的求和。

学会一次，到处能用。

**往前连：12 二重积分。**

无界区域上的二重积分，定义同样是先截断再取极限。

差别只是把"一维区间变长"换成"平面区域变大"，极限的语言完全一样。

**一个常被问到的问题：反常积分能不能换元？**

能，但有两条要求。

一是换元函数要单调、可导，把无穷限换成另一个无穷限或者一个瑕点。

二是换完之后仍然按反常积分处理，端点处照样取极限。

比如 ∫₁^∞ dx/x²，令 x = 1/t，就变成 ∫₀¹ dt，瑕点从无穷远搬到了 0。

**顺带一个经典结果：∫₀^∞ sin x / x dx = π/2。**

这个积分收敛，但不是绝对收敛。

判它收敛要用狄利克雷判别法，数一不要求掌握。

提到它，是为了说明一件事：

```text
收敛不只有"掉得快"一种方式，正负抵消也能让面积停住。
```

这一篇的 p 判据只管非负、单调的情形，遇到振荡要另想办法。

### 自检三问

**第一问：为什么 ∫₁^∞ dx/x 发散，而 ∫₁^∞ dx/x² 收敛？差别到底在哪一步？**

差别在取极限那一步。

两者的原函数分别是 ln x 和 -1/x。

代入上限 b 之后，ln b 无界地涨，-1/b 却趋于 0。

从图像上看，1/x 下方的面积按"对数速度"增长，永远不停；1/x² 下方的面积有一个总上限 1。

判别的时候不必每次算，直接看 p：p > 1 收敛。

**第二问：瑕积分和无穷限积分的 p 规则为什么方向相反？**

因为缺口的几何形状相反。

无穷远处，函数是"长长地拖一条尾巴"，p 越大尾巴越细，越容易收敛，所以要 p > 1。

瑕点处，函数是"在一点上冲一根尖峰"，p 越大尖峰越高，越容易撑爆，所以要 p < 1。

一个看长度，一个看高度。

**第三问：两端都无穷的反常积分，为什么不能写成 lim_{b→∞} ∫_{-b}^{b}？**

因为那只是无数种趋近方式中的一种，而且是对称的一种。

反常积分要求的是：无论上限、下限各自怎么跑，极限都存在且相同。

对称跑法即使有极限，也只说明这一个特殊路径有值，不能代表整体。

典型反例是 f(x) = x：对称积分为 0，但左右两段各自发散。

正确做法是拆成两段，分别判。

## 12. 小结

没有小结，这一章会剩下"一堆会算但说不清"的题。

压成一张卡片：

```text
无穷限：∫ₐ^∞ f dx = lim_{b→∞} ∫ₐ^b f dx
瑕积分：∫ₐ^b f dx = lim_{ε→0⁺} ∫_{a+ε}^b f dx
双侧或内部瑕点：必须拆开，两边都收敛才算收敛
p 积分（无穷远）：p > 1 收敛，值 1/(p-1)
p 积分（瑕点）：p < 1 收敛，值 1/(1-p)
比较法：抓大头，和 1/x^p 比阶
```

四步公式在这一章的统一形态：

```text
算什么 → 把无穷或瑕点换成参数，算有限积分
逐符号 → 参数是 b 或 ε，最后取极限
代数字 → 找原函数，代两端，算极限
适用条件 → 每段都收敛，整体才收敛
```

考场上的判断顺序：

```text
1. 先扫区间，找瑕点，找无穷限
2. 有几种"坏"就拆几段
3. 每段抓大头，定出 p
4. 对 p 规则，得敛散
5. 要算值，再找原函数取极限
```

**三个必须记住的数。**

```text
∫₁^∞ dx/x² = 1
∫₀^∞ e^{-x} dx = 1
∫₀¹ dx/√x = 2
```

它们是三个原型：一个无穷限收敛，一个无穷限收敛且被积函数单调，一个瑕积分收敛。

判敛题里遇到相似的式子，先和这三个比。

**两个词分清：敛散说的是积分，不是函数。**

函数有界，积分可能发散：1/x 在 [1, +∞) 上不超过 1，积分却发散。

函数无界，积分可能收敛：1/√x 在 (0, 1] 上冲向无穷，积分却是 2。

所以判断永远看积分值，不看函数本身大不大。

**一个检查习惯。**

算完一道反常积分，回头问两句：

```text
段拆够了吗？
极限真的取了吗？
```

这两句能拦下大部分低级错误。

三句提醒。

```text
第一句：先判类型，再动手算，别一上来就找原函数。
第二句：瑕点比无穷限更容易漏，拿到题先看分母。
第三句：写"发散"就够，不要写"等于无穷"。
```
