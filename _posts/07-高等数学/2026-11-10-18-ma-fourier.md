> **读这篇之前，你只需要知道**：周期函数是"过一段就重复一遍"的函数，重复的那段长度叫周期；奇函数满足 f(−x) = −f(x)，图像关于原点对称，偶函数满足 f(−x) = f(x)，图像关于纵轴对称；定积分算面积，且 ∫₋ₐᵃ（奇函数）dx = 0，∫₋ₐᵃ（偶函数）dx = 2∫₀ᵃ。
> **这篇讲什么**：任何一个"不太坏"的周期函数，都能拆成一串正弦波和余弦波相加，拆出来的每一项前面的倍数就是傅里叶系数；这一篇教你怎么把那些倍数算出来，以及在哪一点上级数等于原函数。
> **一个类比**：一个乐音。你听到的是整体音色（方波），但它其实是基音加一串泛音（sin x、sin 2x、sin 3x…）叠出来的；傅里叶系数就是每个泛音的音量旋钮拧到了几档。

先看一个东西。

一个方波。

在一个周期里，它的值只有两个：

```text
−π < x < 0    取 −1
 0 < x < π    取  1
```

图像是两段水平线，中间一个垂直的跳变。

```text
 1 ┤        ┌────────
   │        │
 ──┼────────┘────────
   │
−1 ┤────────┘
   −π       0       π
```

它处处是平的，只有两个跳变点。

现在问一个问题：

```text
能不能只用光滑的正弦波，把这个带跳变的方波拼出来？
```

直觉说不能。

正弦波是光滑的，怎么加都不会跳出直角。

答案是能。

```text
方波 = (4/π) · ( sin x + sin 3x/3 + sin 5x/5 + … )
```

取前一项，是一条正弦曲线。

取前三项，开始有方波的形状。

取前一百项，除了跳变点附近，几乎就是方波。

**一堆光滑的曲线，可以拼出一个有直角的东西。**

这句话就是傅里叶级数。

它和幂级数是同一件事的两个方向：

```text
幂级数：用 1, x, x², x³, … 去拼函数
傅里叶：用 1, cos x, sin x, cos 2x, … 去拼函数
```

## 1. 为什么需要它（不给会怎样）

**第一处，幂级数管不了方波。**

17 篇的展开式要求函数能求任意阶导数。

方波在 x = 0 处直接跳变，一阶导数都不存在。

泰勒系数 aₙ = f⁽ⁿ⁾(0)/n! 根本算不出来。

所以幂级数这条路，对方波是死的。

**第二处，幂级数只管"一点附近"。**

e^x 的展开在整条轴上收敛，但每多一项，精度集中在 x = 0 附近。

要让 x = 10 也算得准，需要几十项。

傅里叶级数不一样：它在整个周期上"均匀用力"。

因为它用的基函数 cos nx、sin nx 本身就是周期的，和要描述的对象同频。

**第三处，现实世界里到处都是周期现象。**

```text
交流电：50 Hz 的正弦，但电网里的波形并不纯
声音：乐音 = 基频 + 泛音
心跳：心电图是一个准周期信号
机械振动：发动机的振动可以分解成各阶谐波
```

不把这些拆成"每一阶多大"，就没法分析、没法滤波、没法压缩。

mp3 压缩的原理就是：把音频做傅里叶分解，人耳听不见的那些频率直接扔掉。

**第四处，偏微分方程靠它解。**

热传导方程：

```text
∂u/∂t = a² ∂²u/∂x²
```

初始温度分布 u(x, 0) = f(x) 随便给。

解法是：把 f 展成傅里叶级数，每一项单独求时间演化，再叠加。

没有傅里叶级数，这类方程解不出来。

**第五处，考试直接考。**

数一每年必有一道傅里叶的题。

要么求系数，要么写展开式，要么用展开式反算某个数项级数的和。

计算量不大，但符号错一个就全错。

**所以这一篇解决的是一个"幂级数解决不了"的问题。**

幂级数要求函数光滑，傅里叶只要求"分段单调、没有无穷跳变"。

门槛低了，适用范围就宽了。

## 2. 最小模型：三角级数长什么样

没有这一节，你只知道"要拆成正弦波"，不知道拆几项、每一项前面乘什么。

先看定义式。

```text
f(x) ~ a₀/2 + Σ(n=1→∞) ( aₙ cos nx + bₙ sin nx )
```

这个式子要一个字一个字读。

```text
f(x)      要展开的那个函数，周期是 2π
~         读"约等于号"，在收敛点上是等号，在间断点上要修正
a₀/2      读"a 零 除以 二"，是一个常数项
Σ(n=1→∞)  读"sigma，n 从 1 到无穷"
aₙ        读"a 下标 n"，第 n 个余弦项的系数
cos nx    读"cos n x"，n 倍角的余弦
bₙ        读"b 下标 n"，第 n 个正弦项的系数
sin nx    读"sin n x"，n 倍角的正弦
n         第几次谐波
```

**三个角色。**

**n 是谐波次数。**

n = 1 那一项叫基波，周期是 2π。

n = 2 那一项叫二次谐波，周期是 π。

n = 3 那一项周期是 2π/3。

频率一次比一次高，所以叫"谐波"。

**aₙ 和 bₙ 是每一阶的音量。**

它们由 f 决定，算出来是具体的数。

**a₀/2 是"平均水平"。**

它等于 f 在一个周期上的平均值：

```text
a₀/2 = (1/(2π)) ∫(−π→π) f(x) dx
```

一个周期上的平均高度。

**为什么要有 cos 又有 sin。**

因为 cos 是偶函数，sin 是奇函数。

任何函数都能拆成偶部加奇部：

```text
f(x) = [f(x) + f(−x)]/2 + [f(x) − f(−x)]/2
```

前一半是偶的，后一半是奇的。

cos nx 全体负责偶的那一半，sin nx 全体负责奇的那一半。

**一个关键限制：周期必须对齐。**

上面这个式子只适用于周期为 2π 的函数。

原因很直接：cos nx 和 sin nx 的周期都是 2π/n，它们的共同周期是 2π。

如果 f 的周期是 4π，那这套基函数对不上，得换。

第 7 节讲一般周期 2l 的版本。

**为什么偏偏挑 cos 和 sin 这族函数。**

三个理由。

第一，它们自己过一圈就回到原处。

cos(x + 2π) = cos x，sin 同理。

所以它们天生适合描述"重复"。

第二，它们互相正交。

正交意味着"你算你的，我算我的"，求某一阶系数时，别的阶不会干扰。

这一条保证了系数公式能写成单独一个积分。

第三，它们是简谐振动的基本形态。

弹簧、单摆、交流电、声波，最基础的模型都是 A sin(ωt + φ)。

用振动的基本形态去拆任意周期信号，物理上最自然。

**部分和长什么样。**

记前 N 项的和为 S_N(x)：

```text
S_N(x) = a₀/2 + Σ(n=1→N) (aₙ cos nx + bₙ sin nx)
```

N 越大，越接近 f。

方波的情形：

```text
N = 1   一条正弦曲线
N = 3   顶部开始变平，但两侧有鼓包
N = 11  主体像方波，跳变点附近有过冲
N → ∞  除跳变点外处处等于方波
```

**跳变点附近那个过冲，叫吉布斯现象（Gibbs phenomenon）。**

它的高度不随 N 增大而消失，只往跳变点靠。

这是傅里叶级数在间断点附近的一个固有毛病，第 5 节会说清楚。

**公式四步，定义式版本。**

```text
算什么：把周期函数 f 拆成一串不同频率的正弦、余弦之和
逐符号：a₀/2 平均值，aₙ 余弦系数，bₙ 正弦系数，n 谐波次数
代数字：方波的 aₙ 全是 0，bₙ 只有奇数项非零，b₁ = 4/π
适用条件：f 周期为 2π，且满足狄利克雷条件；间断点上取左右极限平均
```

## 3. 正交性：三个系数公式是怎么来的

没有这一节，三个系数公式只能死记，题目一换形式就失效。

这一节回答一个必须回答的问题：

```text
凭什么 aₙ 就等于 (1/π)∫ f(x) cos nx dx？
```

答案来自三角函数系的一条性质：正交性。

**先把"正交"这个词说清楚。**

两个函数在 [−π, π] 上正交，意思是它们的乘积在这个区间上的积分为 0：

```text
∫(−π→π) g(x) h(x) dx = 0
```

这个词是从向量借来的。

两个向量垂直，点积为 0；两个函数"垂直"，积分（可以理解成连续版本的点积）为 0。

**三角函数系的三条正交关系。**

第一条，两个不同的余弦：

```text
∫(−π→π) cos mx · cos nx dx = 0，  m ≠ n
```

第二条，两个不同的正弦：

```text
∫(−π→π) sin mx · sin nx dx = 0，  m ≠ n
```

第三条，一个余弦乘一个正弦：

```text
∫(−π→π) cos mx · sin nx dx = 0，  对一切 m, n
```

**为什么第一条成立。**

用积化和差：

```text
cos mx · cos nx = [cos(m+n)x + cos(m−n)x] / 2
```

当 m ≠ n 时，m+n 和 m−n 都不是 0。

而 cos kx 在整整一个周期上的积分是 0：

```text
∫(−π→π) cos kx dx = [sin kx/k] from −π to π = 0，  k ≠ 0
```

两项都是 0，加起来还是 0。

第三条同理，因为 sin nx 是奇函数，cos mx 是偶函数，乘积是奇函数，在对称区间上积分为 0。

**同一函数自己乘自己，积分不是 0。**

```text
∫(−π→π) cos²nx dx = π，  n ≥ 1
∫(−π→π) sin²nx dx = π，  n ≥ 1
∫(−π→π) 1² dx = 2π
```

前两条用降幂公式算：

```text
cos²nx = (1 + cos 2nx)/2
积分得 π + 0 = π
```

第三个就是区间长度 2π。

**这三个"自身积分"的值，就是系数公式里的分母。**

**现在推系数。**

假设已经成立：

```text
f(x) = a₀/2 + Σ(k=1→∞) (a_k cos kx + b_k sin kx)
```

要求 aₙ，就把两边同乘 cos nx，再从 −π 到 π 积分。

右边逐项积分，大部分项会消失。

先看常数项：

```text
∫ (a₀/2) cos nx dx = (a₀/2) ∫ cos nx dx = 0，  n ≥ 1
```

再看余弦项，k ≠ n 时：

```text
∫ a_k cos kx cos nx dx = a_k · 0 = 0
```

k = n 时：

```text
∫ aₙ cos²nx dx = aₙ π
```

再看正弦项，全部为 0：

```text
∫ b_k sin kx cos nx dx = 0
```

所以右边只剩一项：

```text
∫(−π→π) f(x) cos nx dx = aₙ π
```

解出：

```text
aₙ = (1/π) ∫(−π→π) f(x) cos nx dx，  n = 1, 2, 3, …
```

**同样的手法求 bₙ。**

两边乘 sin nx，积分。

剩下的只有 bₙ π。

```text
bₙ = (1/π) ∫(−π→π) f(x) sin nx dx，  n = 1, 2, 3, …
```

**a₀ 单独处理，这里就是"除以 2"的来源。**

两边直接积分，不乘任何东西。

```text
∫ f(x) dx = ∫ (a₀/2) dx + 0 + 0
         = (a₀/2) · 2π
         = a₀ π
```

解出：

```text
a₀ = (1/π) ∫(−π→π) f(x) dx
```

**现在把 a₀ 和 aₙ 的公式放在一起看。**

```text
a₀ = (1/π) ∫ f(x) dx          ← 相当于 n = 0 的情形，但 cos 0x = 1
aₙ = (1/π) ∫ f(x) cos nx dx   ← n ≥ 1
```

如果写成统一形式：

```text
aₙ = (1/π) ∫ f(x) cos nx dx，  n = 0, 1, 2, …
```

那么常数项就应该是 a₀，而不是 a₀/2。

但为了让 n = 0 时"自身积分"也符合规律，需要特殊处理。

n = 0 时，∫cos²0x dx = ∫1 dx = 2π，是 n ≥ 1 时那个 π 的两倍。

所以 n = 0 的系数要比公式给出的少一半。

这就是为什么级数里写 a₀/2 而不写 a₀。

**一句话记住。**

```text
公式统一按 aₙ = (1/π)∫f cos nx 记（n 从 0 开始），
级数里常数项写 a₀/2，等于把这个统一的系数折一半。
```

这样记不会错，也不会在 a₀ 上纠结。

**四步公式，系数版本。**

```text
算什么：求每一阶谐波的振幅，也就是 f 在 cos nx、sin nx 上的投影长度
逐符号：(1/π) 是归一化因子，来自 ∫cos²nx = π；积分区间是整整一个周期
代数字：方波的 b₁ = (1/π)∫(−π→π) f sin x dx = 4/π
适用条件：积分区间必须是一个完整周期；奇偶性可以先化简
```

**几何类比，帮助记住这套逻辑。**

把一个向量 v 投到一组正交基 e₁, e₂, … 上：

```text
v = c₁e₁ + c₂e₂ + …
cₖ = (v · eₖ) / (eₖ · eₖ)
```

傅里叶系数就是同一个公式：

```text
aₙ = (f · cos nx) / (cos nx · cos nx) = (1/π)∫f cos nx
```

分母 (cos nx · cos nx) = π 就是"基向量的长度平方"。

所以傅里叶展开就是"把函数投影到一组正交基上"。

这不是比喻，是同一个数学结构。

## 4. 手算：三道系数计算

**例 1：求方波的傅里叶级数。**

定义：

```text
f(x) = −1，  −π < x < 0
f(x) =  1，   0 < x < π
f(x + 2π) = f(x)
```

第一步，看奇偶性。

f(−x) = −f(x)，所以 f 是奇函数。

奇函数乘 cos nx（偶）是奇函数，在对称区间上积分为 0。

```text
aₙ = 0，  n = 0, 1, 2, …
```

**这一步能省掉一半计算，必须先看。**

第二步，算 bₙ。

```text
bₙ = (1/π) [ ∫(−π→0) (−1)·sin nx dx + ∫(0→π) 1·sin nx dx ]
```

先算第一段：

```text
∫(−π→0) (−sin nx) dx = [cos nx / n] from −π to 0
                     = (1/n)[cos 0 − cos(−nπ)]
                     = (1 − cos nπ)/n
```

再算第二段：

```text
∫(0→π) sin nx dx = [−cos nx / n] from 0 to π
                 = (1/n)[−cos nπ + cos 0]
                 = (1 − cos nπ)/n
```

两段相加：

```text
bₙ = (1/π) · 2(1 − cos nπ)/n
```

第三步，化简。

cos nπ = (−1)ⁿ，所以：

```text
bₙ = 2(1 − (−1)ⁿ) / (nπ)
```

分奇偶讨论：

```text
n 为偶数：(−1)ⁿ = 1，分子为 0，bₙ = 0
n 为奇数：(−1)ⁿ = −1，分子为 4，bₙ = 4/(nπ)
```

第四步，写出级数。

```text
f(x) ~ (4/π) [ sin x + sin 3x/3 + sin 5x/5 + … ]
```

**答案：方波的傅里叶级数是 (4/π)Σ(k=0→∞) sin(2k+1)x/(2k+1)。**

第五步，代一个点验算。

取 x = π/2。

左边 f(π/2) = 1。

右边：

```text
sin(π/2) = 1
sin(3π/2) = −1
sin(5π/2) = 1
sin(7π/2) = −1
```

所以：

```text
1 = (4/π)[ 1 − 1/3 + 1/5 − 1/7 + … ]
```

整理：

```text
π/4 = 1 − 1/3 + 1/5 − 1/7 + …
```

**这是莱布尼茨公式，现在被"算"出来了。**

它不再是需要背的结论，而是方波展开在 x = π/2 处的一个特例。

**例 2：求锯齿波 f(x) = x（−π < x < π，2π 周期延拓）的傅里叶级数。**

第一步，看奇偶性。

x 是奇函数。

```text
aₙ = 0，  n = 0, 1, 2, …
```

第二步，算 bₙ，用分部积分。

```text
bₙ = (1/π) ∫(−π→π) x sin nx dx
```

分部积分，取 u = x，dv = sin nx dx。

则 du = dx，v = −cos nx/n。

```text
∫ x sin nx dx = −x cos nx/n + ∫ cos nx/n dx
              = −x cos nx/n + sin nx/n²
```

第三步，代上下限。

上限 x = π：

```text
−π cos nπ/n + sin nπ/n² = −π(−1)ⁿ/n
```

下限 x = −π：

```text
−(−π)cos(−nπ)/n + sin(−nπ)/n² = π(−1)ⁿ/n
```

相减：

```text
−π(−1)ⁿ/n − π(−1)ⁿ/n = −2π(−1)ⁿ/n
```

第四步，乘 1/π。

```text
bₙ = −2(−1)ⁿ/n = 2(−1)ⁿ⁺¹/n
```

第五步，写级数。

```text
f(x) ~ 2 [ sin x − sin 2x/2 + sin 3x/3 − sin 4x/4 + … ]
```

**答案：x ~ 2Σ(n=1→∞) (−1)ⁿ⁺¹ sin nx / n。**

第六步，代一个点验算。

取 x = π/2，左边等于 π/2。

右边各项：

```text
sin(nπ/2) = 1, 0, −1, 0, 1, 0, …
```

所以右边是：

```text
2[ 1 − 1/3 + 1/5 − … ] = 2 · π/4 = π/2
```

对上。

**例 3：把 f(x) = x 在 [0, π] 上展成余弦级数。**

注意题目的变化。

f 只在一半区间上有定义。

"展成余弦级数"的意思是：先做偶延拓，把 f 补成一个偶函数，再展开。

第一步，偶延拓。

```text
f(−x) = f(x) = −x，  −π < x < 0
```

补出来的函数像一条折线：

```text
        ╱╲
      ╱    ╲
    ╱        ╲
───┴──────────┴───
  −π    0     π
```

它关于纵轴对称。

第二步，偶函数只有余弦项。

```text
bₙ = 0，  n = 1, 2, …
```

第三步，算 a₀。

区间对称、被积函数是偶的，可以把积分折成两倍：

```text
a₀ = (1/π) ∫(−π→π) f(x) dx
   = (2/π) ∫(0→π) x dx
   = (2/π) · π²/2
   = π
```

第四步，算 aₙ。

```text
aₙ = (2/π) ∫(0→π) x cos nx dx
```

分部积分，取 u = x，dv = cos nx dx。

则 du = dx，v = sin nx/n。

```text
∫ x cos nx dx = x sin nx/n + cos nx/n²
```

代上下限：

上限 π：

```text
π sin nπ/n + cos nπ/n² = (−1)ⁿ/n²
```

下限 0：

```text
0 + cos 0/n² = 1/n²
```

相减：

```text
[(−1)ⁿ − 1]/n²
```

乘 2/π：

```text
aₙ = (2/π) · [(−1)ⁿ − 1]/n²
```

第五步，分奇偶。

```text
n 为偶数：(−1)ⁿ = 1，分子为 0，aₙ = 0
n 为奇数：(−1)ⁿ = −1，分子为 −2，aₙ = −4/(πn²)
```

第六步，写级数。

```text
f(x) ~ π/2 − (4/π) [ cos x + cos 3x/9 + cos 5x/25 + … ]
```

**答案：x ~ π/2 − (4/π)Σ(k=0→∞) cos(2k+1)x/(2k+1)²，0 < x < π。**

第七步，代 x = 0 验算。

左边：偶延拓后 f(0) = 0。

右边：

```text
0 = π/2 − (4/π) [ 1 + 1/9 + 1/25 + … ]
```

整理：

```text
1 + 1/9 + 1/25 + … = π²/8
```

**又白得一个数项级数的和。**

**三道题的对照。**

```text
例 1：奇函数，只有 bₙ，bₙ 的分子带 1 − cos nπ
例 2：奇函数，只有 bₙ，靠分部积分，系数带 1/n
例 3：偶延拓，只有 aₙ，靠分部积分，系数带 1/n²
```

三条经验。

```text
第一，先看奇偶，能省一半积分。
第二，系数带 1/n 说明函数有跳变；带 1/n² 说明函数连续但导数有跳变。
第三，算出级数后，代一个特殊点，往往能得到一个数项级数的和。
```

**系数衰减的快慢，决定逼近的快慢。**

方波的系数是 4/(nπ)，按 1/n 衰减。

x² 的系数是 4(−1)ⁿ/n²，按 1/n² 衰减。

x 的余弦级数系数是 −4/(πn²)，也按 1/n² 衰减。

规律是：

```text
函数跳变 → 系数 ~1/n，收敛慢，跳变点附近有过冲
函数连续、导数跳变 → 系数 ~1/n²，收敛快，图形光滑
```

这个规律有两个用处。

一是自查：如果题目给的函数是连续的，算出来的系数却是 1/n，多半算错了。

二是判断取几项够用：1/n² 衰减的级数取十项就相当准，1/n 衰减的级数取十项还差得远。

## 5. 狄利克雷条件：级数到底收敛到谁

没有这一节，你会把级数在跳变点的值写成函数值，这是这一章最常见的丢分点。

上一节每次写级数，用的都是 `~` 而不是 `=`。

为什么不敢写等号。

因为傅里叶级数不一定收敛，即使收敛，也不一定收敛到 f(x)。

**先看一个具体的疑问。**

方波在 x = 0 处，函数值是多少？

定义里写的是：−π < x < 0 取 −1，0 < x < π 取 1。

x = 0 这一点，两边都没包含。

f(0) 没有定义。

但级数在 x = 0 处是：

```text
(4/π)(sin 0 + sin 0/3 + …) = 0
```

级数给出 0，而函数在那一点根本没有值。

左右极限分别是 −1 和 1，平均是 0。

**这不是巧合。**

**狄利克雷条件（Dirichlet conditions）。**

设 f 在 [−π, π] 上满足三条：

```text
第一条：除有限个第一类间断点外，处处连续
第二条：只有有限个极值点（等价于可以分成有限段单调）
第三条：在端点处，f(−π⁺) 和 f(π⁻) 存在
```

那么 f 的傅里叶级数处处收敛，且：

```text
在连续点 x 处，级数的和 = f(x)
在间断点 x 处，级数的和 = [f(x⁺) + f(x⁻)] / 2
在端点 x = ±π 处，级数的和 = [f(−π⁺) + f(π⁻)] / 2
```

**第一类间断点是什么。**

左极限和右极限都存在，但不相等（跳跃），或者相等但不等于函数值（可去）。

方波在 x = 0 处是跳跃间断，属于第一类。

**为什么间断点取平均。**

可以从"部分和"的角度看。

S_N(x) 是有限项的和，它是连续的。

当 N → ∞ 时，S_N 在跳变点两侧分别逼近 −1 和 1。

在跳变点本身，它取的是两侧的"折中值"，因为级数的每一项在 x = 0 处都是 sin 0 = 0。

折中值正好是 (−1 + 1)/2 = 0。

更一般的证明要用狄利克雷积分，数一不要求。

**考试只需要做对两件事。**

第一，判断 f 是否满足三条（题目给的函数几乎都满足）。

第二，在间断点代公式算收敛值，别直接代 f(x)。

**吉布斯现象。**

即使 N 很大，S_N 在跳变点附近仍然有约 9% 的过冲。

这个过冲不随 N 增大而消失，只是宽度变窄、往跳变点挤。

```text
        ╭─╮  ← 过冲，高度约 1.09
   ┌────╯ ╰────
───┘
```

原因是：用连续函数去逼近一个跳变，误差不可能在整条线上都趋于 0。

逐点收敛成立（除跳变点外），一致收敛不成立。

这句话说明：`~` 换成 `=` 时，必须限定"在哪些点上"。

**所以正确的写法是这样的。**

```text
f(x) = (4/π)Σ sin(2k+1)x/(2k+1)，  x ≠ 0, ±π, ±2π, …
在 x = 0, ±π, ±2π, … 处，级数的和是 0
```

写成一行也可以：

```text
(4/π)Σ … = [f(x⁺) + f(x⁻)]/2，  对一切 x
```

右边这个写法把连续点和间断点统一了。

连续点上 f(x⁺) = f(x⁻) = f(x)，平均还是 f(x)。

**这就是为什么答案里写"和函数"比写"等于 f"更稳。**

**拿锯齿波验一遍。**

例 2 的 f(x) = x，在 (−π, π) 内连续，但在端点接不上。

周期延拓之后，x = π 处的左极限是 π，右极限（从 −π 过来）是 −π。

所以 x = π 是一个跳跃间断点。

按公式，级数在 x = π 处应该等于：

```text
(π + (−π)) / 2 = 0
```

级数本身呢。

```text
2Σ(−1)ⁿ⁺¹ sin(nπ)/n
```

sin(nπ) = 0 对每个 n 成立，所以级数等于 0。

对上。

**再看 x = π/2。**

这一点连续，所以级数应该等于 f(π/2) = π/2。

第 4 节已经算过，确实等于 π/2。

**两个点合起来说明一件事。**

同一个级数，在连续点取 f 的值，在间断点取平均。

判断某一点连续不连续，要看"周期延拓之后"，不是看原来那段区间。

这一步最容易漏。

**再补一句关于端点的话。**

区间给的是 (−π, π) 或者 [−π, π)，端点写不写进定义域，不影响傅里叶系数。

因为改一个点的函数值，积分不变。

但它会影响"级数在那一点收敛到谁"这个结论。

所以题目问"和函数在 x = π 的值"时，必须用左右极限平均，不能用 f(π)。

**一句话总结这一节。**

```text
傅里叶级数收敛到"函数值"，只在该点连续时才对；
不连续的地方，它收敛到左右极限的平均值。
```

## 6. 正弦级数与余弦级数

没有这一节，题目只给一半区间时，你连第一步该补哪一半都不知道。

这一节讲一个考试高频的操作：只给一半区间。

**情形一：f 是奇函数。**

如果 f(−x) = −f(x)，那么：

```text
aₙ = 0，  n = 0, 1, 2, …
```

级数只剩正弦项，叫正弦级数。

系数公式里的积分可以折半：

```text
bₙ = (2/π) ∫(0→π) f(x) sin nx dx
```

**为什么能折半。**

因为 f(x) sin nx 是奇函数乘奇函数，乘积是偶函数。

偶函数在 [−π, π] 上的积分等于 2 倍在 [0, π] 上的积分。

**情形二：f 是偶函数。**

如果 f(−x) = f(x)，那么：

```text
bₙ = 0，  n = 1, 2, …
aₙ = (2/π) ∫(0→π) f(x) cos nx dx，  n = 0, 1, 2, …
```

级数只剩余弦项，叫余弦级数。

**情形三：f 只在 [0, π] 上有定义。**

这才是考试真正的情形。

题目会说"将 f(x) 在 [0, π] 上展开成正弦级数"或"展开成余弦级数"。

两个说法的含义是把 f 延拓到 [−π, π]：

```text
展开成正弦级数 = 做奇延拓：f(−x) = −f(x)
展开成余弦级数 = 做偶延拓：f(−x) = f(x)
```

**两种延拓给出两个完全不同的级数。**

但它们都在 (0, π) 内收敛到原来的 f。

在端点 x = 0 和 x = π 上，两个级数的值可能不同：

```text
奇延拓：f(0⁺) 与 f(0⁻) = −f(0⁺) 平均，得 0
偶延拓：f(0⁺) 与 f(0⁻) = f(0⁺) 平均，还是 f(0⁺)
```

所以奇延拓的级数在 x = 0 处总是 0。

偶延拓的级数在 x = 0 处总是 f(0⁺)。

**怎么选。**

看题目要求，题目说哪个就用哪个。

如果题目没说，看哪个更省事：

```text
f 在 [0, π] 上本身是奇函数的"半个"，用正弦级数顺手
f 是偶函数的"半个"（比如 |x|、x²、cos x），用余弦级数顺手
```

**为什么考试总给一半区间。**

不是因为数学上更简单，而是因为它对应真实的测量场景。

一根杆，只有 x ≥ 0 的那一半能测到温度。

一段弦，只有 0 到 π 那一段能拨动。

测不到的那一半，只能靠"假设它怎么对称"来补。

假设成奇对称，就得到正弦级数；假设成偶对称，就得到余弦级数。

**两种假设给出的答案都对，但描述的是两个不同的物理情形。**

这就是为什么题目必须明确说"展成正弦级数"。

它不只是数学要求，是在指定一个物理假设。

**再看例 3 的意义。**

例 3 的 f(x) = x 在 [0, π] 上，看起来是"斜线"，不像偶函数。

但题目要求余弦级数，就必须做偶延拓。

延拓之后变成一条 V 形折线，是偶函数。

这个"看起来不像但要硬做"的情形，是考试最常见的陷阱。

**反过来，同一个 f(x) = x 展成正弦级数是什么。**

奇延拓之后就是例 2 的锯齿波。

结果：

```text
x ~ 2Σ(−1)ⁿ⁺¹ sin nx/n，  0 < x < π
```

**同一个函数，两个级数。**

```text
正弦级数：2[sin x − sin 2x/2 + sin 3x/3 − …]
余弦级数：π/2 − (4/π)[cos x + cos 3x/9 + cos 5x/25 + …]
```

在 (0, π) 内两者都等于 x。

在 x = 0 处，前者给 0，后者给 π/2。

在 x = π 处，前者给 0，后者给 π/2。

差异全部来自延拓方式。

## 7. 一般周期 2l 的版本

没有这一节，题目里的周期只要不是 2π，整套公式就用不上。

前面所有公式都假设周期是 2π。

现实的信号周期是任意的，比如 0.02 秒（50 Hz 交流电）。

**换元，把任意周期化到 2π。**

设 f 的周期是 2l，定义在 [−l, l] 上。

**l 的物理含义是"半个周期"。**

交流电的周期是 0.02 秒，所以 2l = 0.02，l = 0.01。

440 Hz 的 A 音周期约 0.0023 秒，l ≈ 0.0011。

所以 l 是一个具体的数，不是抽象符号。

**令：**

```text
t = πx / l
```

当 x 从 −l 走到 l，t 从 −π 走到 π。

定义新函数：

```text
F(t) = f(lt/π)
```

F 的周期是 2π，可以直接套前面的全部结论。

**套完再换回来。**

展开式：

```text
f(x) ~ a₀/2 + Σ(n=1→∞) [ aₙ cos(nπx/l) + bₙ sin(nπx/l) ]
```

系数：

```text
aₙ = (1/l) ∫(−l→l) f(x) cos(nπx/l) dx，  n = 0, 1, 2, …
bₙ = (1/l) ∫(−l→l) f(x) sin(nπx/l) dx，  n = 1, 2, …
```

**怎么记住这个变化。**

只有两处变了：

```text
第一，cos nx 变成 cos(nπx/l)，sin 同理
第二，系数前面的 1/π 变成 1/l
```

判断对不对，用 l = π 检验。

代 l = π：

```text
cos(nπx/π) = cos nx
1/l = 1/π
```

完全退化成第 3 节的公式。

**正交性也跟着变。**

```text
∫(−l→l) cos(nπx/l) cos(mπx/l) dx = 0，  m ≠ n
∫(−l→l) cos²(nπx/l) dx = l
```

自身积分从 π 变成 l，所以归一化因子从 1/π 变成 1/l。

**一个具体的例子。**

设 f(x) = x，定义在 [−1, 1] 上，周期 2。

此时 l = 1。

```text
aₙ = 0（奇函数）
bₙ = ∫(−1→1) x sin(nπx) dx
```

分部积分：

```text
∫ x sin(nπx) dx = −x cos(nπx)/(nπ) + sin(nπx)/(n²π²)
```

代上下限 ±1：

先记原函数：

```text
F(x) = −x cos(nπx)/(nπ) + sin(nπx)/(n²π²)
```

在上限 x = 1：

```text
F(1) = −cos(nπ)/(nπ) + sin(nπ)/(n²π²)
     = −(−1)ⁿ/(nπ) + 0
```

在下限 x = −1：

```text
F(−1) = −(−1)cos(−nπ)/(nπ) + sin(−nπ)/(n²π²)
      = (−1)ⁿ/(nπ) + 0
```

相减：

```text
F(1) − F(−1) = −2(−1)ⁿ/(nπ)
```

所以：

```text
bₙ = 2(−1)ⁿ⁺¹/(nπ)
```

写出来：

```text
f(x) ~ (2/π) Σ(n=1→∞) (−1)ⁿ⁺¹ sin(nπx)/n
```

**检查端点。**

x = 1 处，f 的周期延拓在 1 处左右极限是 1 和 −1，平均 0。

级数在 x = 1 处：sin(nπ) = 0，和为 0。

对上。

## 8. 常见错误

**错误一：a₀ 的公式记错。**

```text
错：a₀ = (2/π)∫(−π→π) f dx
对：a₀ = (1/π)∫(−π→π) f dx
```

那个 2 是给"半区间积分折半"用的，用在全区间就重复了。

记住 a₀/2 是平均值：

```text
a₀/2 = (1/(2π))∫ f dx  ← 这个一定对
```

**错误二：把 a₀/2 里的 1/2 丢掉。**

级数写 a₀/2 + Σ…，不是 a₀ + Σ…。

如果 a₀ 算出来是 π，那常数项是 π/2。

例 3 的答案 π/2 就是这么来的，不是 π。

**错误三：周期 2l 的题里混用两套公式。**

用 cos(nπx/l) 就必须配 1/l。

用 cos nx 就必须配 1/π 且 l 必须等于 π。

混着用必错。

**错误四：奇函数还在算 aₙ。**

不是错，是浪费时间。

而且算完往往因为符号出错。

先判断奇偶，是这类题的第一动作。

**错误五：间断点直接代 f(x)。**

方波在 x = 0 处 f 没定义。

此时级数的和是 [f(0⁺) + f(0⁻)]/2 = 0。

代 f(0) 会直接卡住，因为根本没这个值。

**错误六：bₙ 从 n = 0 开始。**

b₀ 对应 sin 0 = 0，没有意义。

正弦项的 n 从 1 开始，余弦项和常数项才从 0 开始。

**错误七：半区间展开时用 1/π 而不是 2/π。**

只在 [0, π] 上积分时，必须乘 2/π。

```text
aₙ = (2/π)∫(0→π) f cos nx dx
```

这个 2 就是"把半区间补齐成一整个周期"的补偿。

**错误八：以为级数处处等于 f。**

跳变点上不等于。

吉布斯现象说过，跳变点附近还有过冲。

写答案时要说明"在连续点处等于 f，在间断点处等于左右极限平均"。

## 9. 数一怎么考

**题型一：给一个分段函数，求傅里叶级数。**

最常见，通常是解答题。

标准五步：

```text
1. 画图，看奇偶
2. 算 a₀（多数题里是 0 或 π）
3. 算 aₙ 或 bₙ（看奇偶，只算非零的那一支）
4. 分奇偶化简，写出通项
5. 说明收敛性：连续点等于 f，间断点等于平均
```

**题型二：只求某一个系数。**

比如"求 a₅"。

不用写整个级数，直接代 n = 5 算积分。

省时间，但要注意分奇偶时的化简规则。

**题型三：正弦级数或余弦级数。**

关键动作是"延拓"。

题目给 [0, π]，你要自己补出 [−π, 0]。

补错了，系数全错。

**题型四：用展开式求数项级数的和。**

这是傅里叶最漂亮的应用，也是数一喜欢设的"第二问"。

例：求 Σ(n=1→∞) 1/n²。

用 f(x) = x² 在 [−π, π] 上的展开。

第一步，f 是偶函数，bₙ = 0。

第二步，算 a₀：

```text
a₀ = (1/π)∫(−π→π) x² dx = (1/π)·(2π³/3) = 2π²/3
```

所以常数项是 a₀/2 = π²/3。

第三步，算 aₙ。

```text
aₙ = (1/π)∫(−π→π) x² cos nx dx
   = (2/π)∫(0→π) x² cos nx dx
```

分部积分两次：

```text
∫ x² cos nx dx = x² sin nx/n + 2x cos nx/n² − 2 sin nx/n³
```

代 0 到 π：

```text
在 π 处：0 + 2π(−1)ⁿ/n² − 0
在 0 处：0 + 0 − 0
```

所以：

```text
aₙ = (2/π)·2π(−1)ⁿ/n² = 4(−1)ⁿ/n²
```

第四步，写展开式。

```text
x² = π²/3 + 4Σ(n=1→∞) (−1)ⁿ cos nx / n²，  −π ≤ x ≤ π
```

第五步，代 x = π。

左边 π²。

右边 cos nπ = (−1)ⁿ：

```text
π² = π²/3 + 4Σ (−1)ⁿ(−1)ⁿ/n² = π²/3 + 4Σ 1/n²
```

解出：

```text
Σ(n=1→∞) 1/n² = π²/6
```

**答案：π²/6。**

第六步，换一个点还能得别的。

代 x = 0：

```text
0 = π²/3 + 4Σ(−1)ⁿ/n²
```

解出：

```text
Σ(n=1→∞) (−1)ⁿ⁻¹/n² = π²/12
```

**一次展开，两个和。**

这正是傅里叶级数在数一卷里的典型用法。

**题型五：给级数反求函数值。**

比如已知 f 的展开式，求 f(π/2)。

直接代 x = π/2 算级数，或者反推 f 在原点的值。

**题型六：判断级数在某一点收敛到几。**

题目会给一个分段函数和一个具体的点，问"级数在该点的和"。

三步：

```text
1. 判断该点是连续点还是间断点（按周期延拓后的情形）
2. 连续点直接代 f
3. 间断点算左右极限，取平均
```

比如方波在 x = 0：左右极限 1 和 −1，平均 0，答案 0。

方波在 x = π/2：连续，直接代 1，答案 1。

**题型七：已知展开式，反求某个系数或某个积分。**

比如"已知 f 的傅里叶级数，求 a₃"。

不必重新积分，从展开式里读出 cos 3x 前面的系数即可。

或者反过来：题目给一个形如 ∫f cos 3x dx 的式子，要你把它和 a₃ 联系起来。

关系是：

```text
∫(−π→π) f(x) cos 3x dx = π a₃
```

这一步靠的就是系数公式。

**时间分配建议。**

```text
求系数并写展开式：8 到 10 分钟
只求一个系数：3 分钟
用展开式求和：5 分钟
```

写展开式时，分奇偶那一步别跳。

阅卷看的就是通项写对没有。

**一个通用的应试顺序。**

```text
第一眼：看周期是不是 2π，不是就先换元
第二眼：看奇偶，定下只算哪一支
第三眼：算 a₀，再算非零的那一支
第四眼：分奇偶化简，写成通项
第五眼：写收敛性说明，标出间断点
```

五步走完，这道题的分数就齐了。

多数人丢分不在积分算错，而在第五步没写或者写错。

## 10. 和其他章节怎么连

**和 17 篇（幂级数）。**

两章是同一个思想的两套基函数。

```text
幂级数：基是 1, x, x², …       在 x₀ 附近逼近
傅里叶：基是 1, cos nx, sin nx  在整个周期上逼近
```

共同点：都是把函数写成"基函数的线性组合"，系数都靠"内积"算出来。

不同点：幂级数要求光滑，傅里叶只要求分段单调。

**和 16 篇（数项级数）。**

傅里叶级数是数项级数求和的工厂。

```text
x = π/2 代入方波 → π/4 = 1 − 1/3 + 1/5 − …
x = π   代入 x²   → π²/6 = Σ1/n²
x = 0   代入例 3  → π²/8 = Σ1/(2k+1)²
```

这三个和，16 篇里只能证明"收敛"，算不出值。

**和 07 篇（定积分）。**

傅里叶系数的计算全是定积分。

而且九成要用分部积分。

所以分部积分不熟，这一章一道题都算不完。

**和 02 篇（连续与间断）。**

间断点的分类直接决定收敛值。

第一类间断点取平均，第二类间断点（无穷或振荡）傅里叶级数可能不收敛。

**和多元部分（12 到 15 篇）。**

傅里叶级数在二维、三维的推广就是多重傅里叶级数。

图像压缩（JPEG）用的是二维离散余弦变换，本质是二维傅里叶。

**和后续课程。**

信号与系统、数字信号处理、偏微分方程，全部以这一章为起点。

数一考的是最基础的那一层：算系数、写展开、验收敛点。

### 自检三问

**第一问：为什么级数里写 a₀/2，而系数公式里 a₀ = (1/π)∫f dx？这个 2 是哪来的？**

来自 n = 0 时"自身积分"是 2π 而不是 π。

n ≥ 1 时，∫cos²nx dx = π，归一化因子是 1/π。

n = 0 时，cos 0x = 1，∫1 dx = 2π，是两倍。

如果强行用统一公式 a₀ = (1/π)∫f dx，那么级数里的常数项就该是 a₀ 的一半，才能配平。

所以写成 a₀/2。

换个说法：a₀/2 就是 f 在一个周期上的平均值，这个解释不需要记 2 在哪。

**第二问：方波在 x = 0 处，级数收敛到几？为什么不是 1 也不是 −1？**

收敛到 0。

因为狄利克雷条件规定：间断点的收敛值是左右极限的平均。

f(0⁺) = 1，f(0⁻) = −1，平均是 0。

从级数本身也能看出来：每一项都是 sin n·0 = 0，所以部分和恒为 0。

两个角度给出同一个答案。

**第三问：同一个 f(x) = x 在 [0, π] 上，正弦级数和余弦级数为什么完全不同？它们都收敛到 x 吗？**

因为延拓方式不同。

正弦级数来自奇延拓，补出来是锯齿波；余弦级数来自偶延拓，补出来是 V 形折线。

在开区间 (0, π) 内，两个级数都收敛到 x，因为那一段上原函数相同。

但在端点 x = 0 和 x = π 上，两者的值不同：奇延拓给 0，偶延拓给 f(0⁺) 和 f(π⁻)。

所以"展开成什么级数"必须先说清延拓方式，否则答案不唯一。

## 11. 小结

压成一张卡片。

```text
展开式：f(x) ~ a₀/2 + Σ(aₙ cos nx + bₙ sin nx)
a₀ = (1/π)∫(−π→π) f dx
aₙ = (1/π)∫(−π→π) f cos nx dx，  n ≥ 1
bₙ = (1/π)∫(−π→π) f sin nx dx，  n ≥ 1
正交性：∫cos mx cos nx = 0 (m≠n)，= π (m=n≥1)
收敛值：连续点取 f(x)，间断点取 [f(x⁺)+f(x⁻)]/2
奇函数：只有 bₙ，用 (2/π)∫(0→π)
偶函数：只有 aₙ，用 (2/π)∫(0→π)
周期 2l：cos nx → cos(nπx/l)，1/π → 1/l
```

四步公式在这一章的统一形态。

```text
算什么 → 求每一阶谐波的振幅，即 f 在 cos nx 或 sin nx 上的投影
逐符号 → 1/π 来自自身积分 π，积分区间是一个完整周期
代数字 → 方波 b₁ = 4/π，锯齿波 bₙ = 2(−1)ⁿ⁺¹/n，x² 的 aₙ = 4(−1)ⁿ/n²
适用条件 → 狄利克雷三条件；间断点取平均；端点用延拓值
```

三个必须记住的展开。

```text
方波：(4/π)(sin x + sin 3x/3 + sin 5x/5 + …)
锯齿：2(sin x − sin 2x/2 + sin 3x/3 − …)
x²  ：π²/3 + 4Σ(−1)ⁿ cos nx/n²
```

三个顺手得到的和。

```text
π/4  = 1 − 1/3 + 1/5 − …
π²/6 = 1 + 1/4 + 1/9 + …
π²/8 = 1 + 1/9 + 1/25 + …
```

三个习惯。

```text
第一，动笔前先判奇偶，能省一半积分。
第二，算完代一个特殊点验算，顺便白得一个级数和。
第三，答案里写清"在哪些点等于 f"，别只写一个 ~。
```

一个提醒。

```text
傅里叶级数不是"把 f 换成另一串东西"，
而是"把 f 拆成不同频率的成分，看每一份占多少"。
```

这句才是这一章真正要带走的东西。

**再补一个自查方法。**

算完一组系数，把 n = 1 和 n = 2 代进去，看数值合不合理。

如果算出的 b₁ 比函数的最大值还大十倍，多半是漏了 1/π 或者多乘了 2。

系数是"振幅"，振幅不该远超原函数的高度。
