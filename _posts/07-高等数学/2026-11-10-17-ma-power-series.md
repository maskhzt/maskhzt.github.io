> **读这篇之前，你只需要知道**：级数是"无限多个数相加"，它可能加出一个有限值（收敛），也可能一路涨到无穷（发散）；等比级数 1 + q + q² + … 在 |q| < 1 时收敛到 1/(1−q)，这是全篇唯一必须背下来的砖。
> **这篇讲什么**：把级数的每一项都换成"系数乘 x 的 n 次方"，于是加出来的结果不再是数，而是一个关于 x 的函数；这一篇教你怎么确定它在哪些 x 上收得住、收住之后是哪个函数、以及反过来怎么把已知函数写成这种样子。
> **一个类比**：一把可以伸缩的尺子。x 是你要量的长度，系数 aₙ 是尺子上的刻度。x 太长了，尺子就崩断（发散）；x 在量程内，尺子读数稳定（收敛）；量程的边界就是收敛半径。

先看一件很日常的事。

按下计算器，输入 37，再按 sin，屏幕显示：

```text
0.6018150232…
```

计算器里并没有一张"0 到 90 度的正弦表"。

它做的是乘法和加法：

```text
sin x = x − x³/3! + x⁵/5! − x⁷/7! + …
```

把 37 度换成弧度，约等于 0.6457718。

代进去算前四项：

```text
x          = 0.6457718
x³/3!      = 0.0448811
x⁵/5!      = 0.0009356
x⁷/7!      = 0.0000093
```

交替加减：

```text
0.6457718 − 0.0448811 + 0.0009356 − 0.0000093 = 0.6018170
```

和计算器的 0.6018150 差在小数点后第六位。

再加一项就追上了。

**一个三角函数，被拆成了一串幂函数的加法。**

这句话就是整篇的主题。

它同时逼出三个问题：

```text
第一，这串加法在哪些 x 上收得住？
第二，收住之后，和是哪个函数？
第三，给定一个函数，怎么反过来写出这串幂？
```

三个问题，对应三节：收敛半径、和函数、函数展开。

## 1. 为什么需要它（不给会怎样）

先不给它，看会卡在哪里。

卡住的地方有五个，一个比一个硬。

**第一处，e^x、sin x、ln x 这些函数"算不出来"。**

你只能说"查表"或者"按计算器"。

但计算器内部是幂级数，数学用表是幂级数算出来的。

没有幂级数，这些函数就只是一个符号，不能变成一个数。

工程上要算 e^{0.3} 精确到小数点后六位，靠的就是展开。

**第二处，数项级数只能判敛散，给不出值。**

16 篇里证明了：

```text
1 − 1/2 + 1/3 − 1/4 + … 收敛
```

但收敛到几？

那一篇答不出来。

有了幂级数，答案是 ln 2：

```text
ln(1+x) = x − x²/2 + x³/3 − …
```

代 x = 1，右边就是上面那串，左边是 ln 2。

**第三处，有些极限用洛必达要算很多遍。**

```text
lim(x→0) (sin x − x) / x³
```

洛必达一次，变成 (cos x − 1)/(3x²)。

再一次，变成 −sin x/(6x)。

再一次，变成 −cos x/6。

三次才出结果，每次都要检查是不是 0/0。

用展开，一行写完：

```text
sin x = x − x³/6 + …
sin x − x = −x³/6 + …
除以 x³ 得 −1/6 + …
```

**第四处，有些积分积不出来。**

```text
∫ e^{−x²} dx
```

这个积分没有初等原函数。

但 e^{−x²} 可以展开：

```text
e^{−x²} = 1 − x² + x⁴/2! − x⁶/3! + …
```

逐项积分：

```text
∫ e^{−x²} dx = x − x³/3 + x⁵/(5·2!) − x⁷/(7·3!) + …
```

正态分布的概率计算、误差函数，全靠这一手。

**第五处，微分方程经常没有初等解。**

```text
y' = 1 + xy²
```

这个方程解不出初等函数。

但可以设 y = Σaₙxⁿ，代进去比较系数，逐项定出 aₙ。

这叫幂级数解法，数一只需要知道有这条路。

**所以幂级数不是"级数那一章的补充"。**

它是把函数翻译成多项式的通道。

多项式只有加法和乘法两种运算，这是人算得动、机器也算得快的运算。

翻译过去，求导、积分、求极限、近似、解方程，全部变成对系数动手。

## 2. 最小模型：幂级数长什么样

没有这一节，你只会看到一串符号，不知道 aₙ 和 x 各自在管什么，也写不出一个具体的数。

先看定义式。

```text
Σ(n=0→∞) aₙ (x − x₀)ⁿ
```

这个符号要一个一个读出来。

```text
Σ          读 "sigma"，意思是"把后面那一串东西加起来"
n=0→∞      读 "n 从 0 到无穷"，n 是求和的下标
aₙ         读 "a 下标 n"，叫第 n 项的系数，是一个固定的数
x₀         读 "x 零"，叫展开中心，也是一个固定的数
(x − x₀)ⁿ  读 "x 减 x 零的 n 次方"
```

把它摊开写，就看得清结构：

```text
a₀ + a₁(x−x₀) + a₂(x−x₀)² + a₃(x−x₀)³ + …
```

三个角色分工很明确。

**aₙ 决定每一项有多大。**

它是一串给定的数，和 x 无关。

比如 aₙ = 1/n!，就是 1, 1, 1/2, 1/6, 1/24, …

**x₀ 决定从哪里展开。**

x₀ = 0 时，式子退化成最简单的样子：

```text
a₀ + a₁x + a₂x² + a₃x³ + …
```

这种情形有个专门的名字，叫麦克劳林级数（Maclaurin series）。

数一考的大多数题，中心都是 0。

**x 是自变量，可以随便取。**

关键的一步在这里：

x 一旦取定，整个幂级数就退化成一个普通的数项级数。

比如取 x = 2，aₙ = 1/n!，x₀ = 0：

```text
Σ 2ⁿ/n! = 1 + 2 + 2 + 4/3 + 2/3 + …
```

这就是 16 篇里学过的正项级数。

所以幂级数的敛散性，不是一个"是"或"否"。

而是一个"x 的范围"：

```text
x 落在某个范围里，收敛。
x 落在这个范围外，发散。
```

这个"范围"就叫收敛域。

**第二个必须说清的概念：收敛点与发散点。**

```text
收敛点：把这个 x 代进去，得到的数项级数收敛。
发散点：代进去之后发散。
收敛域：所有收敛点组成的集合。
```

**两个小约定，先说清楚。**

第一个，n 从 0 开始，所以第一项是 a₀(x−x₀)⁰。

而 (x−x₀)⁰ = 1，哪怕括号里是 0，只要 x ≠ x₀ 就成立。

所以第一项就是一个常数 a₀，它是整个级数的"底价"。

第二个，0! = 1。

这不是规定出来的怪事，是从阶乘的递推关系倒推出来的：

```text
1! = 1
2! = 2·1!
3! = 3·2!
n! = n·(n−1)!
```

要让 n = 1 时这条式子也成立，必须有 1! = 1·0!，所以 0! = 1。

这就是为什么 e^x 的展开式里第一项是 x⁰/0! = 1，而不是"除以 0"。

**第三个概念：和函数。**

在收敛域上，每个 x 都对应一个和。

把这些和当成 x 的函数，记作 s(x)：

```text
s(x) = Σ(n=0→∞) aₙ (x − x₀)ⁿ
```

s 读作"和函数"，英文 sum function。

它回答的问题是："这串无限加法，最后加出了哪个函数？"

比如 aₙ = 1/n!，x₀ = 0，那么：

```text
s(x) = 1 + x + x²/2! + x³/3! + … = e^x
```

**公式四步，先把定义式走一遍。**

```text
算什么：把一串系数 aₙ 和一堆 x 的幂配起来，得到一个关于 x 的函数
逐符号：Σ 求和，aₙ 系数，x₀ 中心，x 自变量，n 从 0 到无穷
代数字：aₙ = 1/n!，x₀ = 0，取 x = 1，得 1 + 1 + 1/2 + 1/6 + … = e
适用条件：只在收敛域内这个等式才成立，域外写等号是错的
```

最后那句是重点。

**很多人在收敛域外写等号。**

比如：

```text
1 + 2 + 4 + 8 + … = 1/(1−2) = −1
```

这个式子是错的。

1/(1−x) = 1 + x + x² + … 只在 |x| < 1 时成立。

x = 2 时左边发散，右边是 −1，两边根本不相等。

所以每次写展开式，收敛域必须跟着写。

## 3. 收敛半径 R：为什么收敛域一定是一段区间

没有这一节，你会以为收敛域要么是一个点、要么是整条轴，遇到"中间一段"就无从解释。

先问一个问题。

收敛域会不会长成这种奇怪的样子：

```text
在 x = 1 收敛，在 x = 2 发散，在 x = 3 又收敛？
```

不会。

理由是阿贝尔定理（Abel's theorem）。

**阿贝尔定理的完整表述。**

设幂级数 Σaₙ(x−x₀)ⁿ 在 x₁ 处收敛，且 x₁ ≠ x₀。

那么对一切满足 |x − x₀| < |x₁ − x₀| 的 x，级数绝对收敛。

设它在 x₂ 处发散。

那么对一切满足 |x − x₀| > |x₂ − x₀| 的 x，级数发散。

**为什么是这样。**

先看收敛那一半。

在 x₁ 处收敛，说明通项 aₙ(x₁−x₀)ⁿ 趋于 0（收敛的必要条件）。

趋于 0 的数列一定有界，于是存在一个 M，使：

```text
|aₙ(x₁−x₀)ⁿ| ≤ M，对一切 n 成立
```

现在换一个更靠近中心的 x，记：

```text
q = |x − x₀| / |x₁ − x₀|
```

因为 |x−x₀| < |x₁−x₀|，所以 0 ≤ q < 1。

把通项改写：

```text
|aₙ(x−x₀)ⁿ| = |aₙ(x₁−x₀)ⁿ| · qⁿ ≤ M qⁿ
```

右边是一个收敛的等比级数（因为 q < 1）。

由比较判别法，左边收敛。

而且加的是绝对值，所以是绝对收敛。

**发散那一半是同一句话的反面。**

如果在某个更远的点收敛，按前半段，所有更近的点都收敛，包括 x₂。

这和 x₂ 发散矛盾。

**定理的几何含义画出来是这样的。**

```text
      绝对收敛区            绝对收敛区
   ←──────────────┐    ┌──────────────→
                  │    │
──────────┬───────┼────┼───────┬──────────
        x₀−R     x₀   x₀+R
                  │    │
              收敛半径 R
```

收敛点集合一定是"以 x₀ 为中心的一段"，不可能断开。

这段的半径，就叫收敛半径，记作 R。

R 读作"收敛半径"，英文 radius of convergence。

**R 只有三种可能。**

```text
R = 0        只在 x = x₀ 这一点收敛
R 是正数    在 (x₀−R, x₀+R) 内绝对收敛，外面发散
R = +∞      对一切实数 x 都收敛
```

R = 0 的例子：

```text
Σ n! xⁿ
```

只有 x = 0 能让它收敛。

R = +∞ 的例子：

```text
Σ xⁿ/n!
```

对任何 x 都收敛，因为阶乘长得比任何指数都快。

**三个名词要分清。**

```text
收敛半径 R：一个数，控制开区间
收敛区间：(x₀−R, x₀+R)，开区间，不含量端点
收敛域：收敛区间再加上端点判定后留下的点
```

三者的关系：

```text
收敛域 = 收敛区间 ∪ {收敛的端点}
```

**这里藏着考试第一个大坑。**

R 只管开区间。

端点上收不收敛，R 一点信息都没给。

必须把 x = x₀ − R 和 x = x₀ + R 分别代回原级数，当成数项级数重新判。

所以完整的收敛域可能长成四种样子：

```text
(x₀−R, x₀+R)     两端都发散
[x₀−R, x₀+R)     左端收敛
(x₀−R, x₀+R]     右端收敛
[x₀−R, x₀+R]     两端都收敛
```

R = +∞ 时，收敛域就是整条实轴。

R = 0 时，收敛域只有 {x₀} 一个点。

**四步公式，收敛域版本。**

```text
算什么：先定 R，再定两个端点的敛散，最后拼成集合
逐符号：R = 1/ρ，ρ 是相邻系数比的极限，端点要代回原级数
代数字：aₙ = 1/n，得 ρ = 1，R = 1，中心 0，端点 ±1 分别判
适用条件：ρ 必须存在（含为 +∞ 的情形）；端点不能靠 ρ 判断
```

## 4. 求 R 的三条路

没有这一节，每道题的 R 都得靠猜，缺项级数更是连下手的地方都没有。

**路线一：比值法。**

```text
ρ = lim(n→∞) |aₙ₊₁ / aₙ|
R = 1/ρ
```

ρ 读作"rho"，是相邻两个系数的绝对值之比的极限。

**为什么这么算。**

把幂级数当成等比级数看。

相邻两项的比是：

```text
|aₙ₊₁(x−x₀)ⁿ⁺¹| / |aₙ(x−x₀)ⁿ| = |aₙ₊₁/aₙ| · |x−x₀|
```

当 n 很大时，前面那个因子趋近于 ρ。

所以整个比值趋近于：

```text
ρ · |x − x₀|
```

等比级数收敛的条件是公比的绝对值小于 1：

```text
ρ · |x − x₀| < 1
```

解出：

```text
|x − x₀| < 1/ρ
```

右边就是 R。

**两个极端情形。**

```text
ρ = 0     → R = +∞（除以 0 得无穷大）
ρ = +∞    → R = 0（1 除以无穷大得 0）
```

**路线二：根值法。**

```text
ρ = lim(n→∞) ⁿ√|aₙ|
R = 1/ρ
```

ⁿ√ 读作"n 次根号"。

这条路线在 aₙ 里带 n 次方的时候好用。

比如 aₙ = (n/(2n+1))ⁿ，比值法会很啰嗦，根值法一步出结果：

```text
ⁿ√|aₙ| = n/(2n+1) → 1/2
R = 2
```

**路线三：缺项级数。**

这是最容易错的一类。

看这个级数：

```text
Σ x^{2n} / 4ⁿ = 1 + x²/4 + x⁴/16 + …
```

x 的幂只出现偶数次，这叫缺项。

如果硬套比值法，aₙ 该怎么取？

取 aₙ = 1/4ⁿ（只管偶数项），得到 ρ = 1/4，R = 4。

代回去检验：x = 3 时，通项是 9ⁿ/4ⁿ = (9/4)ⁿ，趋于无穷，发散。

所以 R = 4 是错的。

正确的 R 是 2。

**错在哪。**

因为 aₙ₊₁/aₙ 描述的是"相邻两个系数"，而这里相邻两个非零项之间隔了一个 0。

那个 0 被漏掉了。

**两个正确做法。**

做法一，换元：

```text
令 t = x²，级数变成 Σ tⁿ/4ⁿ
这是标准幂级数，ρ = 1/4，R_t = 4
所以 |t| < 4，即 |x²| < 4，即 |x| < 2
```

做法二，直接对通项用比值法：

```text
uₙ = x^{2n}/4ⁿ
|uₙ₊₁/uₙ| = |x²|/4
要求小于 1，得 |x| < 2
```

做法二的好处是：它对任何级数都成立，不管缺不缺项。

因为比值判别法本来就是判"数项级数"的，把 x 当参数即可。

**一句话记住。**

```text
系数法（比值、根值）只认 aₙ，缺项时会漏；
通项法只认 uₙ，永远不错，但要把 x 留在式子里。
```

## 5. 手算：四道求收敛域

这一节的四道题，覆盖考试能出的全部四种情况。

**例 1：求 Σ(n=1→∞) xⁿ/n 的收敛域。**

第一步，认系数。

```text
aₙ = 1/n
```

第二步，算 ρ。

```text
|aₙ₊₁/aₙ| = |(1/(n+1)) / (1/n)| = n/(n+1)
lim(n→∞) n/(n+1) = 1
ρ = 1
```

第三步，得 R。

```text
R = 1/ρ = 1
```

中心是 0，所以收敛区间是 (−1, 1)。

第四步，两个端点分别代回原级数。

先代 x = 1：

```text
Σ 1ⁿ/n = Σ 1/n = 1 + 1/2 + 1/3 + …
```

这是调和级数，16 篇里判过，发散。

再代 x = −1：

```text
Σ (−1)ⁿ/n = −1 + 1/2 − 1/3 + …
```

这是交错级数。

用莱布尼茨判别法：1/n 单调减少，且趋于 0。

所以收敛。

第五步，拼起来。

```text
收敛域 = [−1, 1)
```

**答案：R = 1，收敛域 [−1, 1)。**

**例 2：求 Σ(n=1→∞) (x−2)ⁿ / (n·3ⁿ) 的收敛域。**

第一步，认系数和中心。

```text
aₙ = 1/(n·3ⁿ)
x₀ = 2
```

第二步，算 ρ。

```text
aₙ₊₁/aₙ = [1/((n+1)3ⁿ⁺¹)] · [n·3ⁿ/1]
        = n / (3(n+1))
lim = 1/3
ρ = 1/3
```

第三步，得 R。

```text
R = 3
```

中心是 2，收敛区间是：

```text
(2 − 3, 2 + 3) = (−1, 5)
```

第四步，判端点。

左端点 x = −1，代入 x − 2 = −3：

```text
Σ (−3)ⁿ/(n·3ⁿ) = Σ (−1)ⁿ/n
```

交错调和级数，收敛。

右端点 x = 5，代入 x − 2 = 3：

```text
Σ 3ⁿ/(n·3ⁿ) = Σ 1/n
```

调和级数，发散。

第五步，拼起来。

```text
收敛域 = [−1, 5)
```

**答案：R = 3，收敛域 [−1, 5)。**

这道题提醒一件事：

中心 x₀ 不是 0 的时候，端点要先算 x₀ ± R，再代回 x − x₀。

很多人把 x = 3 当成端点，那是把中心当 0 了。

**例 3：求 Σ(n=1→∞) n! xⁿ 的收敛域。**

```text
aₙ = n!
aₙ₊₁/aₙ = (n+1)!/n! = n + 1
lim(n→∞) (n+1) = +∞
所以 ρ = +∞
R = 1/ρ = 0
```

R = 0 表示收敛区间退化成一点。

只剩中心 x = 0。

代 x = 0，每一项都是 0，级数收敛（和为 0）。

代任何 x ≠ 0，通项 n!xⁿ 的绝对值趋于无穷，发散。

```text
收敛域 = {0}
```

**答案：R = 0，收敛域只含一点 x = 0。**

这个结论有实际用途。

它说明：系数长得太快（像阶乘那样），级数就只在一点活。

**例 4：求 Σ(n=0→∞) x^{2n} / 4ⁿ 的收敛域。**

这是缺项级数，用换元法。

第一步，换元。

```text
令 t = x²
原式 = Σ tⁿ/4ⁿ
```

第二步，对新级数求半径。

```text
系数 bₙ = 1/4ⁿ
bₙ₊₁/bₙ = 4ⁿ/4ⁿ⁺¹ = 1/4
ρ = 1/4
R_t = 4
```

第三步，换回 x。

新级数在 |t| < 4 时收敛，所以：

```text
|x²| < 4
|x| < 2
```

所以原级数的收敛半径 R = 2。

第四步，判端点。

x = 2 时，通项：

```text
2^{2n}/4ⁿ = 4ⁿ/4ⁿ = 1
```

通项不趋于 0，发散。

x = −2 时同理，通项也是 1，发散。

第五步，拼起来。

```text
收敛域 = (−2, 2)
```

**答案：R = 2，收敛域 (−2, 2)。**

**四道题的类型对照。**

```text
例 1：标准型，一端收敛一端发散 → [−1, 1)
例 2：中心非零       → 先算 x₀±R，再代
例 3：R = 0 的退化情形
例 4：缺项，必须换元或对通项做
```

考场上先花三秒给题目归个类，再动手，能省一半时间。

**再补一个检验习惯。**

算出 R 之后，随手取一个区间内的数和一个区间外的数，各代一次。

如果区间内的数发散，或者区间外的数收敛，说明 R 算错了。

这个检验只要十秒，却能拦下大部分符号错误。

## 6. 和函数：只有两个动作

没有这一节，收敛域算出来了却回答不了"和是几"，这一章就只剩一半。

收敛域定了，接下来问：和是多少？

和函数记作 s(x)：

```text
s(x) = Σ aₙ(x − x₀)ⁿ，x 在收敛域内
```

求和的难点在于：级数里带着 n。

带 n 的项不能直接套等比公式。

**能用的动作只有两个。**

```text
求导：把分母上的 n 消掉，或者把 n 提到分子前
积分：把分子上的 n 消掉
```

**为什么这两个动作合法。**

因为幂级数在收敛区间内部可以逐项求导、逐项积分。

而且求导、积分之后，收敛半径 R 不变。

这条性质叫"逐项可导、逐项可积"，条件是 |x−x₀| < R。

严格地说，幂级数在收敛区间内的任何闭子区间上一致收敛，所以可以交换求和与求导、求积分的次序。

数一不需要写这段证明，但要知道它成立的边界：**只开区间内部，不含端点。**

**唯一必须背的砖。**

```text
1/(1−x) = 1 + x + x² + x³ + … = Σ xⁿ，  −1 < x < 1
```

这块砖是等比级数求和公式：

```text
首项 1，公比 x，和 = 1/(1−x)，收敛条件是 |x| < 1
```

其他所有和函数，都是这块砖变形出来的。

**四块派生砖。**

把 x 换成 −x：

```text
1/(1+x) = 1 − x + x² − x³ + … = Σ (−1)ⁿxⁿ，  −1 < x < 1
```

对 1/(1−x) 求导：

```text
1/(1−x)² = 1 + 2x + 3x² + … = Σ (n+1)xⁿ，  −1 < x < 1
```

对 1/(1+x) 积分：

```text
ln(1+x) = x − x²/2 + x³/3 − … = Σ (−1)ⁿ⁻¹xⁿ/n，  −1 < x ≤ 1
```

把 1/(1+x²) 积分：

```text
arctan x = x − x³/3 + x⁵/5 − … = Σ (−1)ⁿx^{2n+1}/(2n+1)，  −1 ≤ x ≤ 1
```

注意最后两个的端点变了。

求导让端点更容易发散，积分让端点更容易收敛。

这是第 9 节要专门讲的坑。

**四步公式，求和函数版本。**

```text
算什么：把一个陌生的幂级数，认成某块砖的导数或积分
逐符号：先凑成 Σ(某式)ⁿ 的形状，再用求导或积分对齐
代数字：Σ xⁿ/n → 求导得 Σ xⁿ⁻¹ = 1/(1−x) → 积分回 −ln(1−x)
适用条件：整个过程只在 |x−x₀| < R 内合法；端点另验
```

**求和函数的标准流程，五步。**

```text
第一步：看系数，n 在分母还是分子
第二步：n 在分母 → 先求导；n 在分子 → 先积分（或先提 x）
第三步：把剩下的部分凑成等比级数，套 1/(1−q)
第四步：反向做一次（求导的积分回去，积分的求导回去），补常数
第五步：用 s(x₀) 或某一特殊点的值定常数
```

第四步的"补常数"最容易漏。

求导会把常数项消掉，积分回去必须把常数补回来。

补的办法是代一个已知点。

最常用的是 x = x₀，此时所有含 (x−x₀) 的项都是 0，和函数等于 a₀。

## 7. 手算：两个和函数

**例 5：求 s(x) = Σ(n=1→∞) n xⁿ⁻¹ 的和函数。**

第一步，看结构。

系数是 n，在分子上。

这种形状正好是"求导"能产生的。

第二步，从砖出发。

```text
Σ(n=0→∞) xⁿ = 1/(1−x)，  |x| < 1
```

第三步，两边对 x 求导。

左边逐项求导：

```text
d/dx [1 + x + x² + x³ + …] = 0 + 1 + 2x + 3x² + …
```

也就是：

```text
Σ(n=1→∞) n xⁿ⁻¹
```

右边求导：

```text
d/dx [1/(1−x)] = 1/(1−x)²
```

第四步，写成等式。

```text
Σ(n=1→∞) n xⁿ⁻¹ = 1/(1−x)²，  |x| < 1
```

**答案：s(x) = 1/(1−x)²，收敛域 (−1, 1)。**

第五步，代一个数验算。

取 x = 1/2：

```text
左边 = 1 + 2(1/2) + 3(1/4) + 4(1/8) + …
     = 1 + 1 + 0.75 + 0.5 + 0.3125 + …
     ≈ 4
右边 = 1/(1 − 1/2)² = 1/(1/4) = 4
```

对上。

**顺手得到第二个结果。**

两边乘 x：

```text
Σ(n=1→∞) n xⁿ = x/(1−x)²，  |x| < 1
```

这个式子在"数项级数求和"里出现频率极高。

比如求 Σ n/2ⁿ：

```text
代 x = 1/2，得 (1/2)/(1/2)² = 2
```

**例 6：求 s(x) = Σ(n=1→∞) xⁿ/n 的和函数。**

第一步，看结构。

n 在分母上。

求导正好能把分母的 n 消掉。

第二步，先求导。

```text
s'(x) = Σ(n=1→∞) n xⁿ⁻¹/n = Σ(n=1→∞) xⁿ⁻¹
```

第三步，认出这是等比级数。

```text
Σ(n=1→∞) xⁿ⁻¹ = 1 + x + x² + … = 1/(1−x)，  |x| < 1
```

第四步，积分回去。

```text
s(x) = ∫₀ˣ dt/(1−t) + C
```

算这个积分：

```text
∫ dt/(1−t) = −ln|1−t|
从 0 到 x：[−ln|1−x|] − [−ln 1] = −ln|1−x|
```

所以：

```text
s(x) = −ln|1−x| + C
```

第五步，定常数。

代 x = 0：

```text
左边 s(0) = Σ 0ⁿ/n = 0
右边 = −ln 1 + C = C
```

所以 C = 0。

**答案：s(x) = −ln(1−x)，|x| < 1。**

在 |x| < 1 内，1−x 是正的，绝对值可以去掉。

第六步，端点补判。

x = 1：级数变成 Σ1/n，调和级数，发散。

x = −1：级数变成 Σ(−1)ⁿ/n。

这是交错级数，1/n 单调减且趋于 0，收敛。

和是多少？

代进和函数：

```text
s(−1) = −ln(1 − (−1)) = −ln 2
```

所以：

```text
Σ(n=1→∞) (−1)ⁿ/n = −ln 2
```

这正是 16 篇留下的那个悬念，现在有答案了。

**完整结论：**

```text
Σ xⁿ/n = −ln(1−x)，  收敛域 [−1, 1)
```

注意：和函数只在 |x| < 1 内由逐项积分得到，x = −1 的和是另外验出来的。

**例 7：求 s(x) = Σ(n=1→∞) n(n+1) xⁿ 的和函数。**

第一步，看结构。

n(n+1) 是二次的。

这需要求两次导。

第二步，从 x²/(1−x) 出发。

先看：

```text
Σ(n=0→∞) xⁿ⁺² = x² + x³ + x⁴ + … = x²/(1−x)
```

第三步，两边求两次导。

第一次：

```text
Σ(n=0→∞) (n+2) xⁿ⁺¹ = d/dx [x²/(1−x)]
```

算右边：

```text
d/dx [x²/(1−x)] = [2x(1−x) + x²]/(1−x)² = (2x − x²)/(1−x)²
```

第二次求导：

```text
Σ(n=0→∞) (n+2)(n+1) xⁿ = d/dx [(2x−x²)/(1−x)²]
```

这个导数算起来啰嗦，换个方式。

直接对 x²/(1−x) 用二阶导的公式：

```text
d²/dx² [x²/(1−x)] = 2/(1−x)³
```

这个结果可以直接验证：把 x²/(1−x) 写成 −x − 1 + 1/(1−x)，求二阶导只剩最后一项的贡献。

而左边：

```text
d²/dx² Σ xⁿ⁺² = Σ (n+2)(n+1) xⁿ
```

所以：

```text
Σ(n=0→∞) (n+2)(n+1) xⁿ = 2/(1−x)³
```

第四步，把下标换成题目要的样子。

题目要 n(n+1)xⁿ，n 从 1 开始。

令 m = n + 1，则 n = m − 1，n+2 = m+1：

```text
Σ(m=1→∞) (m+1)m x^{m−1} = 2/(1−x)³
```

两边乘 x：

```text
Σ(m=1→∞) m(m+1) x^m = 2x/(1−x)³
```

**答案：s(x) = 2x/(1−x)³，|x| < 1。**

第五步，验算。

取 x = 1/2：

```text
左边 = 1·2·(1/2) + 2·3·(1/4) + 3·4·(1/8) + …
     = 1 + 1.5 + 1.5 + 1.09375 + …
     ≈ 8（继续加会收敛到 8）
右边 = 2(1/2)/(1/2)³ = 1/(1/8) = 8
```

对上。

**三道题的共同点。**

```text
例 5：n 在分子 → 求导
例 6：n 在分母 → 积分
例 7：n 的二次式 → 求两次导，或先配 x 的幂再求导
```

判断的依据只有一条：**让 n 从"障碍"变成"常数"。**

具体分两种：

```text
分母有 n（形如 Σ xⁿ/n）：
  先求导，n 被约掉，剩下等比级数，积回去

分子有 n（形如 Σ n xⁿ⁻¹）：
  本身已经是某个等比级数求导的结果，直接认出来，不用积分
```

所以两种情形的动作方向相反：

```text
分母有 n → 求导开路
分子有 n → 从求导后的砖倒推
```

一个自检办法：

```text
做完之后，把结果求导（或积分）一次，
看能不能回到题目给的级数。
```

能回去，方向和系数就都对。

## 8. 展开：把函数写成幂级数

没有这一节，你只会按计算器，不知道屏幕上那些数字是怎么算出来的，也写不出考试要的展开式。

这一节是反方向。

给定 f(x)，找一串 aₙ，使得：

```text
f(x) = Σ aₙ (x − x₀)ⁿ
```

**两条路。**

**路一：直接法（泰勒系数）。**

```text
aₙ = f⁽ⁿ⁾(x₀) / n!
```

f⁽ⁿ⁾ 读作"f 的 n 阶导数"。

这条路要算 n 阶导数，还要验证余项趋于 0。

数一里只对少数函数走得通。

**路二：间接法（用已知展开式变形）。**

从必背的五个展开式出发，通过四类操作得到新的：

```text
代换：把 x 换成 x²、−x、2x
求导
积分
四则运算（乘、除、部分分式）
```

考试九成以上用间接法。

**四步公式，展开版本。**

```text
算什么：找系数 aₙ，使 f(x) 在一段区间内等于 Σaₙ(x−x₀)ⁿ
逐符号：aₙ = f⁽ⁿ⁾(x₀)/n!，是第 n 项系数
代数字：f = e^x，x₀ = 0，aₙ = 1/n!，得 1 + x + x²/2! + …
适用条件：余项趋于 0；x 落在收敛域内（两条都要）
```

**必背的五个展开式，连收敛域一起背。**

```text
1/(1−x) = Σ xⁿ                     −1 < x < 1
e^x     = Σ xⁿ/n!                  −∞ < x < +∞
sin x   = Σ (−1)ⁿ x^{2n+1}/(2n+1)!  −∞ < x < +∞
cos x   = Σ (−1)ⁿ x^{2n}/(2n)!      −∞ < x < +∞
ln(1+x) = Σ (−1)ⁿ⁻¹ xⁿ/n            −1 < x ≤ 1
```

**e^x 的展开怎么来的。**

设：

```text
e^x = a₀ + a₁x + a₂x² + …
```

代 x = 0：

```text
e⁰ = 1 = a₀
```

两边求导：

```text
e^x = a₁ + 2a₂x + 3a₃x² + …
```

再代 x = 0：

```text
1 = a₁
```

再求导：

```text
e^x = 2a₂ + 6a₃x + …
```

代 x = 0：

```text
1 = 2a₂，a₂ = 1/2
```

规律出来了：

```text
aₙ = 1/n!
```

所以：

```text
e^x = 1 + x + x²/2! + x³/3! + …，  −∞ < x < +∞
```

**这个级数有一个漂亮的性质。**

对它逐项求导，得到它自己：

```text
d/dx [Σ xⁿ/n!] = Σ n xⁿ⁻¹/n! = Σ xⁿ⁻¹/(n−1)! = Σ x^m/m!
```

求导不变，这正是 e^x 的定义性质。

**sin x 和 cos x 的展开。**

用同样的递推法。

设 sin x = Σ bₙxⁿ。

b₀ = sin 0 = 0。

b₁ = cos 0 = 1。

每求一次导，sin → cos → −sin → −cos → sin，循环一圈四次。

代 x = 0 得到：

```text
b₀ = 0
b₁ = 1
b₂ = 0
b₃ = −1/3!
b₄ = 0
b₅ = 1/5!
```

只有奇数次项非零，符号 +、−、+、− 交替。

```text
sin x = x − x³/3! + x⁵/5! − x⁷/7! + …
```

写成通项：

```text
sin x = Σ(n=0→∞) (−1)ⁿ x^{2n+1}/(2n+1)!
```

同理：

```text
cos x = Σ(n=0→∞) (−1)ⁿ x^{2n}/(2n)!
```

两个级数的收敛半径都是 +∞。

原因是阶乘在分母上，长得比 x 的任何次幂都快。

**ln(1+x) 的展开。**

不从导数出发，从积分出发更省事。

起点是：

```text
1/(1+t) = 1 − t + t² − t³ + …，  |t| < 1
```

两边从 0 到 x 积分：

```text
∫₀ˣ dt/(1+t) = ln(1+x)
```

右边逐项积分：

```text
∫₀ˣ (1 − t + t² − …) dt = x − x²/2 + x³/3 − …
```

所以：

```text
ln(1+x) = x − x²/2 + x³/3 − x⁴/4 + …
```

通项：

```text
Σ(n=1→∞) (−1)ⁿ⁻¹ xⁿ/n
```

**收敛域要单独说。**

积分不改变收敛半径，所以 R = 1。

端点 x = 1：

```text
1 − 1/2 + 1/3 − 1/4 + …
```

交错级数，收敛，和是 ln 2。

端点 x = −1：

```text
−1 − 1/2 − 1/3 − …
```

发散。

所以 ln(1+x) 的展开域是 (−1, 1]。

**为什么积分后 x = 1 反而收敛了。**

因为在 |x| = 1 处，原来的通项是 xⁿ，大小恒为 1，不趋于 0。

积分后的通项是 xⁿ/n，大小是 1/n，趋于 0。

除以 n 让端点活了下来。

**例 8：把 f(x) = 1/(x² − 3x + 2) 展开成 x 的幂级数。**

第一步，分解分母。

```text
x² − 3x + 2 = (x−1)(x−2)
```

第二步，部分分式。

```text
1/[(x−1)(x−2)] = A/(x−1) + B/(x−2)
```

通分：

```text
1 = A(x−2) + B(x−1)
```

代 x = 2：1 = B(1)，B = 1。

代 x = 1：1 = A(−1)，A = −1。

所以：

```text
f(x) = −1/(x−1) + 1/(x−2)
```

第三步，改写成"1 减 某物"的形状。

```text
−1/(x−1) = 1/(1−x)
1/(x−2) = −1/(2−x) = −(1/2)·1/(1 − x/2)
```

第四步，各自套砖。

```text
1/(1−x) = Σ xⁿ，  |x| < 1
(1/2)·1/(1−x/2) = (1/2)Σ (x/2)ⁿ = Σ xⁿ/2ⁿ⁺¹，  |x/2| < 1
```

第五步，合并。

```text
f(x) = Σ xⁿ − Σ xⁿ/2ⁿ⁺¹
     = Σ (1 − 1/2ⁿ⁺¹) xⁿ
```

收敛域取两个条件的交集：

```text
|x| < 1 且 |x| < 2，即 |x| < 1
```

**答案：f(x) = Σ(n=0→∞) (1 − 2^{−(n+1)}) xⁿ，收敛域 (−1, 1)。**

第六步，验算常数项。

代 x = 0：

```text
f(0) = 1/2
级数常数项 = 1 − 1/2 = 1/2
```

对上。

**例 9：把 sin x / x 展开，并求它在 x = 0 处的极限。**

第一步，先展开 sin x。

```text
sin x = x − x³/3! + x⁵/5! − …
```

第二步，整式除以 x。

```text
sin x / x = 1 − x²/3! + x⁴/5! − …
```

第三步，求极限。

x → 0 时，除第一项外全部趋于 0。

```text
lim(x→0) sin x/x = 1
```

这就是两个重要极限之一。

**它现在是"算出来"的，不是"记住"的。**

第四步，说清适用条件。

这个展开在 x ≠ 0 时成立。

x = 0 时右边等于 1，左边没定义，但极限存在且等于 1。

所以这个等式可以理解成"把 sin x/x 连续延拓到 x = 0"。

**三个必须会自己推的展开。**

```text
e^x：从 (e^x)' = e^x 出发，逐次求导定系数
sin x / cos x：从循环求导出发，只有隔项非零
ln(1+x)：从 1/(1+x) 积分，端点单独判
```

考场上如果忘了符号，用 x = 0 附近的值验一次：

```text
sin 0.1 ≈ 0.0998334
0.1 − 0.001/6 = 0.0998333
```

对上就说明符号没错。

## 9. 常见错误

**错误一：把 R 当成收敛域。**

```text
错：Σ xⁿ/n 的收敛域是 (−1, 1)
对：Σ xⁿ/n 的收敛域是 [−1, 1)
```

R 只给开区间，端点必须另判。

这是本章第一名丢分点。

**错误二：判端点时代错了级数。**

求 Σ(x−2)ⁿ/(n3ⁿ) 的端点，要代 x = −1 和 x = 5。

有人代成 x = ±3，那是把 R 当成了端点坐标。

正确做法是先算 x₀ − R 和 x₀ + R。

**错误三：缺项级数直接用系数比。**

```text
错：Σ x^{2n}/4ⁿ，aₙ = 1/4ⁿ，得 R = 4
对：R = 2
```

要么换元，要么对通项做比值。

**错误四：求导、积分后沿用原来的端点结论。**

```text
Σ xⁿ      收敛域 (−1, 1)，两端都发散
Σ xⁿ/n    收敛域 [−1, 1)，左端收敛
```

同一个 R，端点结论完全不同。

**错误五：积分回去忘了补常数。**

```text
s'(x) = 1/(1−x) → s(x) = −ln(1−x) + C
```

C 必须用 s(x₀) = a₀ 定出来。

多数题里 C = 0，但不能默认。

**错误六：展开时漏写收敛域。**

数一解答题里，展开式不写收敛域通常扣 1 分。

它不是可选项，是答案的一部分。

**错误七：ln(1+x) 和 ln(1−x) 混。**

```text
ln(1+x) = x − x²/2 + x³/3 − …   符号交替
ln(1−x) = −x − x²/2 − x³/3 − …  全是负号
```

区别来自 1/(1+x) 和 1/(1−x) 的符号。

**错误八：在收敛域外写等号。**

```text
1 + 2 + 4 + … = −1
```

这是把解析延拓的值当成了级数的和。

级数在 |x| ≥ 1 时根本不收敛，等号无意义。

## 10. 数一怎么考

**题型一：求收敛半径与收敛域。**

出现频率：几乎每年一道，选择题或填空题。

标准四步：

```text
1. 认 aₙ 和 x₀
2. 算 ρ = lim|aₙ₊₁/aₙ|（缺项就换元）
3. R = 1/ρ，写出开区间
4. 两个端点代回原级数，用 16 篇的判别法判
```

**题型二：求和函数。**

通常是解答题的一小问，或者大题的第一步。

标准五步就是第 6 节那张流程表。

**题型三：函数展开。**

要求写出前几项并给出通项与收敛域。

常用手段按频率排序：

```text
1. 部分分式 + 套 1/(1−q) 砖
2. 对已知展开式积分（出 ln、arctan）
3. 对已知展开式求导（出分母平方）
4. 代换（把 x 换成 −x、x²、2x）
```

**题型四：用展开算极限。**

这类题比洛必达快得多。

```text
lim(x→0) (e^x − 1 − x)/x²
```

展开：

```text
e^x = 1 + x + x²/2 + …
e^x − 1 − x = x²/2 + …
除以 x² 得 1/2 + …
```

**答案：1/2。**

对比洛必达：要求两次导，每次都得确认 0/0。

**题型五：用幂级数求数项级数的和。**

思路是把数项级数认成某个幂级数在某点的值。

```text
求 Σ(n=1→∞) n/2ⁿ
```

认出来：

```text
Σ n xⁿ = x/(1−x)²
代 x = 1/2：得 (1/2)/(1/2)² = 2
```

**答案：2。**

再如：

```text
求 Σ(n=1→∞) 1/(n·2ⁿ)
```

这是 Σ xⁿ/n 在 x = 1/2 的值：

```text
−ln(1 − 1/2) = −ln(1/2) = ln 2
```

**答案：ln 2。**

**题型六：证明题（少但会出）。**

常见两种：

```text
证明某个幂级数满足某个微分方程（逐项求导后代入）
证明某个和函数的不等式（在收敛区间内取端点极限）
```

**题型七：已知和函数，反求系数或某一点的值。**

这类题是题型二的逆运算，考的是"系数唯一性"。

幂级数的系数由和函数唯一确定：

```text
aₙ = s⁽ⁿ⁾(x₀) / n!
```

所以知道 s(x) 的封闭形式，就能反推每一个 aₙ。

例：已知 Σ aₙxⁿ = 1/(1−x)²，求 aₙ。

从第 6 节的砖直接读出：

```text
1/(1−x)² = Σ (n+1) xⁿ
```

所以 aₙ = n + 1。

如果不想背这块砖，也可以两边乘 (1−x)² 再比较系数。

**一个时间分配建议。**

```text
求收敛域：3 到 5 分钟，必须拿满分
求和函数：6 到 8 分钟，写清五步
函数展开：5 分钟，含收敛域
```

这三类合起来，数一里稳定占 10 分左右。

## 11. 和其他章节怎么连

**和 16 篇（数项级数）。**

幂级数在固定 x 处就是数项级数。

判端点的工具全部来自 16 篇：正项用比值、根值、比较；交错用莱布尼茨。

所以 16 篇不熟，这一章的端点就判不动。

**和 04 篇（泰勒中值定理）。**

泰勒公式是有限项：

```text
f(x) = f(x₀) + f'(x₀)(x−x₀) + … + f⁽ⁿ⁾(x₀)(x−x₀)ⁿ/n! + Rₙ(x)
```

幂级数是无限项：

```text
f(x) = Σ f⁽ⁿ⁾(x₀)(x−x₀)ⁿ/n!
```

两者的桥是余项 Rₙ。

余项趋于 0，泰勒公式就升级成幂级数。

所以"能不能展开"这个问题，本质是"余项收不收得住"。

**和 06、07 篇（积分）。**

逐项积分就是积分工具的直接应用。

反过来，很多积分积不出来，展开后逐项积分就出来了。

```text
∫ sin(x²) dx、∫ e^{−x²} dx、∫ sin x/x dx
```

这三个都是"积不出但能展开"的典型。

**和 02 篇（极限）。**

等价无穷小替换，本质是泰勒展开取第一项。

```text
sin x ~ x        取到一阶
1 − cos x ~ x²/2 取到二阶
```

所以等价无穷小不能随便替换加减法中的项，因为那等于只保留了一阶，把高阶项丢了。

用展开就不会犯这个错。

**和 18 篇（傅里叶级数）。**

两章在结构上是平行的。

```text
幂级数：用 1, x, x², x³, … 这族函数去逼近 f
傅里叶：用 1, cos x, sin x, cos 2x, … 这族函数去逼近 f
```

幂级数擅长描述"局部"（在 x₀ 附近），傅里叶擅长描述"整体周期"。

同一个函数可以两种都展开，用哪个看问题的性质。

**和 19、20 篇（微分方程）。**

幂级数解法：

```text
设 y = Σ aₙxⁿ，代入方程，比较同次幂系数，逐个定 aₙ
```

这条路能解很多没有初等解的方程。

数一只需要知道思路，不要求熟练。

### 自检三问

**第一问：为什么收敛域一定是一段以 x₀ 为中心的区间，不可能断成两截？**

因为阿贝尔定理给了一个"单向"的结论。

在某个点收敛，所有比它更靠近中心的点都绝对收敛。

在某个点发散，所有比它更远离中心的点都发散。

于是收敛点的集合必然是"距离中心小于某个值"的全部点。

这种集合只能是区间，不可能出现"近的散、远的收"。

R 就是这个分界距离。

**第二问：逐项求导、逐项积分为什么 R 不变，端点却会变？**

R 由系数之比 aₙ₊₁/aₙ 的极限决定。

求导把 aₙ 变成 (n+1)aₙ₊₁，系数比多了一个因子 (n+1)/n，极限是 1。

积分把 aₙ 变成 aₙ/(n+1)，系数比多了一个因子 n/(n+1)，极限也是 1。

所以 ρ 不变，R 不变。

但端点上判的是"通项趋于 0 的速度"。

乘一个 n，通项变大，更容易发散；除以一个 n，通项变小，更容易收敛。

所以端点结论会翻。

典型对比：

```text
Σ xⁿ    在 x = −1 发散（通项不趋于 0）
Σ xⁿ/n  在 x = −1 收敛（通项是 1/n）
```

**第三问：端点为什么必须代回原级数，不能继续用比值法？**

因为比值法在 ρ|x−x₀| = 1 时失效。

此时比值判别法的极限正好等于 1，判不出任何结论。

这不是计算失误，是判别法本身的能力边界。

端点处必须换成 16 篇的其他工具：正项用比较、p 级数；交错用莱布尼茨。

代回原级数还有一个好处：能顺便算出端点的和。

## 12. 小结

没有小结，这一章会剩下"会算但说不清在算什么"的状态。

压成一张卡片。

```text
定义：Σ aₙ(x−x₀)ⁿ，中心 x₀，系数 aₙ
收敛半径：ρ = lim|aₙ₊₁/aₙ|，R = 1/ρ（ρ=0 则 R=∞）
收敛域：先写 (x₀−R, x₀+R)，再把两个端点代回原级数分别判
和函数：逐项求导或逐项积分，凑成 1/(1−q) 的形状，反做一次补常数
展开：从五个必背式子出发，靠代换、求导、积分、部分分式变形
```

五个必背展开式，再抄一遍。

```text
1/(1−x) = 1 + x + x² + …            |x| < 1
e^x     = 1 + x + x²/2! + …         全轴
sin x   = x − x³/3! + x⁵/5! − …     全轴
cos x   = 1 − x²/2! + x⁴/4! − …     全轴
ln(1+x) = x − x²/2 + x³/3 − …       −1 < x ≤ 1
```

四步公式在这一章的统一形态。

```text
算什么 → 定 R、求和、写展开，三件事各自的"算什么"不同
逐符号 → aₙ 系数、x₀ 中心、n 下标、ρ 极限
代数字 → 每道题至少代一组数验算
适用条件 → 只看 |x−x₀| < R；端点另判；展开式必须带收敛域
```

三个习惯。

```text
第一，算出 R 后立刻代一个内点和一个外点验一次。
第二，写展开式时先写收敛域，再写等式。
第三，求和函数时，反做之后先代 x₀ 定常数。
```

两个容易混的词，最后分清。

```text
收敛区间：开区间，只由 R 决定
收敛域：集合，由 R 加端点判定共同决定
```

下一篇换一族函数。

这一篇用的是 1, x, x², x³ 这族幂函数。

它们描述的是"在某一点附近"的样子。

下一篇用的是 1, cos x, sin x, cos 2x 这族三角函数。

它们描述的是"在一个周期上"的样子。

问题变成：

```text
高等数学系统讲解 18：傅里叶级数
```

那一篇会回答：

```text
为什么用 cos 和 sin 当基函数？
a₀/2 前面的 1/2 是哪来的？
间断点上级数收敛到哪个值？
```
